# 100HTML — 用 HTML 构建你的 AI 工具工作流

> 在线体验：<https://100html.com>  
> 本目录文件会在 `./deploy.sh` 构建时复制到 `dist/`（若 `dist/` 内尚无同名文件则使用此处版本）。

完整项目说明、微型产品理念与分类介绍，请访问站内首页或（若已同步）查看本仓库根目录 `README.md` 的完整版。

## 快速开始

```bash
git clone https://github.com/loresun/100html.git
cd 100html
npx serve .
```

API Key 等在浏览器本地配置，详见 <https://100html.com/tools/ai_basics/guide.html>。
