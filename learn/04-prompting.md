# 04｜提示词工程与思维框架

## 目标与收益

- 掌握提示词的结构化表达。
- 形成可复用的提示词资产库。
- 能让模型输出更稳定、更可控。

## 新手入门步骤

1. 先写“角色”与“任务”。
2. 再补“输出格式”。
3. 最后补“风格与长度”。

## 核心框架

### 1. 基础结构（指令 + 背景 + 输出要求）

```
你是 {角色}
请在 {背景} 下完成 {任务}
输出要求：{格式/风格/长度/结构}
```

示例：

```
你是资深新媒体编辑
请在“睡眠改善”主题下为小红书生成文案
输出要求：标题 1 条 + 正文 200-300 字 + 1 个行动号召
```

### 2. 多步提示（拆解链路）

- 第一步：输出大纲（标题/结构）
- 第二步：扩写正文（每段 3-5 句）
- 第三步：润色与格式化

### 3. 约束优先级

- **格式 > 风格 > 细节 > 创意**
- 若输出必须结构化，明确「禁止发挥」

## 提示词资产化

- 建立「场景 - 模板 - 示例」三层结构。
- 每个模板包含：变量列表、默认参数、输出样例。
- 高价值提示词应进入“模板库”。

## 新手提示词模板（可直接用）

### 模板 1：结构化分析

```
你是高级分析师
请根据以下背景生成一个 4 列表格：问题、原因、影响、解决方案
背景：{背景内容}
输出要求：表格形式，语言简洁
```

### 模板 2：内容生成

```
你是新媒体编辑
请生成一篇短文
主题：{主题}
对象：{对象}
风格：{风格}
长度：{字数范围}
输出：标题 + 正文 + 行动号召
```

### 模板 3：标题生成

```
你是内容策划
请生成 10 条标题，每条不超过 18 个字
主题：{主题}
风格：{风格}
```

## 实践任务

1. 为一个工具设计 3 条提示词模板。
2. 给每条模板补充「最佳输出示例」。
3. 建立一个你自己的“提示词资产库”。
4. 让朋友使用你的模板，收集反馈。

## 常见坑

- 只描述目标，没有输出格式。
- 让模型自我“理解需求”，导致偏题。
- 没有示例，导致输出稳定性差。

## 延伸阅读与练习

- 练习：为同一任务写出“高控制”与“高自由”两种模板。
- 练习：把一个长提示词拆分成可复用模块。
