# 09｜拿到这个文件包后怎么学习

## 目标与收益

- 让新手在 1-2 天内理解项目结构与使用方式。
- 学会如何阅读现有文档并快速上手。
- 形成自己的学习节奏与复用方法。

## 快速上手路线（48 小时）

### Day 1：熟悉与体验

1. 打开 `index.html`，浏览所有工具入口。
2. 随机挑 3 个工具体验输出差异。
3. 阅读 `README.md`，理解项目定位与功能类别。
4. 进入 `learn/`，按顺序阅读 01-04 章。

### Day 2：实践与复用

1. 选择 1 个工具深入研究（例如 `xhs_generator.html`）。
2. 记录它的输入字段、输出格式与默认参数。
3. 把它的提示词复制到你的“提示词库”。
4. 按 05-06 章建议，尝试小改版。

## 项目结构认知

- `index.html`：总入口与工具列表。
- `*.html`：单文件工具（每个工具一个场景）。
- `docs/`：项目说明与规划文档。
- `learn/`：学习路径与实践教程。
- `llm-tutorials/`：模型与平台相关资料。

## 学习方法（新手可照抄）

- **先体验**：先用再改，感受输入与输出的关系。
- **再拆解**：用“输入 → 提示词 → 输出”拆成三层。
- **最后复用**：把好用的提示词保存成模板。

## 实践任务

1. 写出你最喜欢的 3 个工具名称和理由。
2. 画出其中 1 个工具的“输入 → 输出”流程图。
3. 记录你最常用的 5 个提示词变量（主题、对象、风格、长度、格式）。

## 常见坑

- 一上来就改代码，没看懂结构。
- 只看工具界面，不看提示词逻辑。
- 没有建立自己的提示词库。
