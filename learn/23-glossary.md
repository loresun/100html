# 23｜术语表与概念速查

## 目标与收益

- 用最少的时间找到关键术语的含义。
- 避免概念混淆（如 API 与模型、上下文与记忆）。
- 作为全套 Learn 文档的“随手翻阅”页面。

## 核心术语

### API
应用程序接口，用于把提示词发送给模型并获取输出。

### 模型（Model）
执行推理与生成的“引擎”，不同模型能力不同。

### 上下文窗口
一次请求中模型可看到的信息上限，超出会被截断。

### Prompt / 提示词
你给模型的指令或要求，决定输出方向与格式。

### 系统/开发/用户消息
对话角色优先级：系统 > 开发 > 用户。

### 温度（temperature）
控制输出随机性；越高越发散，越低越稳定。

### Token
模型处理的最小文本单位，影响上下文上限与费用。

### 流式输出（streaming）
模型边生成边返回，提升交互体验。

### 幻觉（Hallucination）
模型输出看似合理但不准确的信息，需要校验。

### RAG
检索增强生成：先查资料，再用模型组织答案。

### Few-shot
在提示词中给 1-3 个示例，引导输出结构。

## 快速使用建议

- 遇到术语不确定，先在这里查定义。
- 看不懂上下文限制，先理解“Token + 窗口”。
- 开始写提示词时优先关注“角色、格式、边界”。

## 延伸阅读与练习

- 练习：用自己的话解释 5 个术语。
- 练习：把常用术语做成桌面便签。
