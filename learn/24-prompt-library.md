# 24｜Prompt 模板库与任务配方

## 目标与收益

- 提供可直接复制的提示词模板。
- 把“任务结构”固化为可复用的配方。
- 帮新手快速跑通第一个可用结果。

## 通用模板（万能型）

```
你是{角色}。
在{场景}下，为{对象}生成{内容类型}。
风格：{风格}。
长度：{字数}。
输出格式：{格式}。
约束：{限制条件}。
```

## 内容创作模板

### 1) 小红书文案

```
你是小红书资深内容策划。
主题：{主题}
受众：{人群}
风格：{风格}
输出：标题 3 个 + 正文 1 篇（分段）+ CTA 1 句。
```

### 2) 视频脚本

```
你是短视频编导。
目标：{目标}
受众：{人群}
结构：开场钩子 → 三段核心 → 结尾 CTA。
输出格式：分镜 + 口播文案。
```

### 3) 会议纪要

```
你是会议记录助手。
输入是会议内容，请输出：
- 会议结论
- 关键决策
- 待办清单（负责人 + 截止时间）
```

## 结构化输出模板

### JSON 输出

```
请输出 JSON，结构如下：
{
  "title": "",
  "summary": "",
  "items": [
    {"name": "", "desc": ""}
  ]
}
```

### 表格输出

```
请以 Markdown 表格输出：
| 项目 | 内容 | 备注 |
| --- | --- | --- |
| ... | ... | ... |
```

## 实践任务

1. 选择一个模板，替换变量并在任意工具中试用。
2. 将有效的模板保存为“场景-版本号”。
3. 用同一模板生成 2 个版本并对比差异。

## 常见坑

- 模板太长，反而降低稳定性。
- 没写输出格式，结果无法直接用。
- 任务边界不清晰，导致内容偏题。
