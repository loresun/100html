# 10｜改成你自己的工具（定制与创作）

## 目标与收益

- 学会把现有工具改成“你自己的版本”。
- 掌握最关键的修改点：输入字段、提示词、输出模板。
- 能从 0 到 1 做一个新工具。

## 定制三步法

### 1. 改输入

- 把“主题/对象/风格”换成你的场景字段。
- 举例：把“标题/正文”改成“课程大纲/卖点文案”。

### 2. 改提示词

- 保留结构，替换场景与输出要求。
- 使用 04 章的提示词模板结构。

### 3. 改输出

- 输出格式要跟你的使用场景一致。
- 可加“复制/导出”按钮。

## 新工具创建流程

1. 复制一个最相似的工具 HTML 文件。
2. 修改标题、说明文字与输入字段。
3. 调整提示词模板。
4. 运行并测试输出格式。
5. 加入示例输入，提升可用性。

## 新手模板（可直接替换）

```
你是{角色}
请完成{任务}
背景：{背景}
输出要求：{格式 + 风格 + 长度}
```

## 实践任务

1. 复制一个工具并改成自己的场景。
2. 为它写一个 3 行“使用说明”。
3. 做 2 次实际输出，迭代提示词。

## 常见坑

- 只改 UI 不改提示词，导致输出不匹配。
- 没有示例输入，用户不知道怎么用。
- 输出格式不固定，无法复用。
