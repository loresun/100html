# 19｜新手最常见疑问清单（从他们出发）

## 目标与收益

- 站在新手角度识别真实疑问与卡点。
- 判断现有文档是否已覆盖，避免“讲了但没解决”。
- 帮你更有针对性地完善教程与工具说明。

## 新手画像（用于对照）

- 用过 Gemini 或类似工具做过简单对话。
- 可能跟着教程改过 HTML，但不熟悉前端结构。
- 听说过 API，但对成本、参数、错误处理不清楚。
- 想做一个“自己的工具”，却不知道从哪里下手。

## 新手最常见的疑问（问题 → 是否已覆盖）

### 1. 我到底要先学什么？

- 疑问：先看 README 还是先看工具？
- 覆盖情况：已在 `learn/09-using-this-repo.md` 与 `learn/15-repo-docs-map.md` 给出顺序。
- 补充建议：在 `index.html` 增加“新手入口”按钮。

### 2. 为什么我输入了主题却输出很差？

- 疑问：输出“跑题/格式乱/太空泛”。
- 覆盖情况：已在 `learn/01-foundations.md`、`learn/03-chat-parameters.md` 解释。
- 补充建议：提供“提示词示例 + 结果对比图”。

### 3. 需要懂代码吗？

- 疑问：我不是程序员还能改吗？
- 覆盖情况：`learn/10-customize-and-build.md` 提供无代码改造流程。
- 补充建议：补一份“最小改动示例”。

### 4. API Key 放在前端安全吗？

- 疑问：会不会泄露？别人能看到吗？
- 覆盖情况：`learn/06-frontend-only-stack.md` 已说明本地存储。
- 补充建议：增加“风险提示与最佳实践”。

### 5. 为什么有时完全没有输出？

- 疑问：是不是模型挂了？还是网络问题？
- 覆盖情况：`learn/11-debugging.md` 提供排查步骤。
- 补充建议：在工具里加入更友好的错误提示。

### 6. 我怎么把它改成自己的工具？

- 疑问：改哪里？改提示词还是 UI？
- 覆盖情况：`learn/10-customize-and-build.md` 提供三步法。
- 补充建议：提供“改造前后对比案例”。

### 7. 我做的工具能给团队用吗？

- 疑问：如何分享？能不能多人同时使用？
- 覆盖情况：`learn/13-team-usage.md` 有团队使用建议。
- 补充建议：提供“内部部署流程图”。

### 8. 需要花多少钱？会不会很贵？

- 疑问：API 调用成本多少？
- 覆盖情况：`learn/02-model-capabilities.md` 提到成本思路。
- 补充建议：新增“成本估算表模板”。

### 9. 提示词到底要写多长？

- 疑问：越长越好吗？
- 覆盖情况：`learn/04-prompting.md` 已说明结构化更重要。
- 补充建议：提供“短提示词 vs 长提示词”对比。

### 10. 我做的工具能卖吗？

- 疑问：能收费吗？怎么定价？
- 覆盖情况：`learn/07-launch-and-business.md` 说明交付与收费。
- 补充建议：加“最低可收费版本（MVP）示例”。

## 新手常见误区（提醒清单）

- 认为“提示词写得越多越好”。
- 只看 UI，不看提示词逻辑。
- 追求高模型，不看成本与稳定性。
- 不保存模板，导致每次重新写。
