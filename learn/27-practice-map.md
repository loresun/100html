# 27｜学习章节与工具练习映射

## 目标与收益

- 明确每个学习章节可以用哪些工具练习。
- 让新手快速建立“学 → 做”的闭环。

## 章节 → 工具建议

| 章节 | 练习方向 | 推荐工具示例 |
| --- | --- | --- |
| 01 基础认知 | 任务拆解、结构化输出 | `xhs_generator.html`、`content_calendar_planner.html` |
| 03 对话参数 | 参数对比、温度实验 | `llm_playground.html` |
| 04 提示词工程 | 模板优化、Few-shot | `prompt_optimizer.html` |
| 05 HTML 工作流 | 输入/输出结构 | `html_tool_builder.html` |
| 06 纯前端架构 | API 配置与保存 | 任意带设置面板工具 |
| 10 自定义工具 | 改字段、改提示词 | 任意同类工具 |
| 11 调试排错 | 错误提示与日志 | `debug_companion.html` |
| 12 产品介绍 | 功能说明与卖点 | `product_showcase.html` |
| 20 API 基础 | API Key 与流式 | `llm_playground.html` |
| 24 Prompt 模板库 | 模板套用与复用 | `prompt_asset_manager.html` |

> 说明：工具示例来自根目录 HTML 文件，可按需替换。

## 实践任务

1. 选一个章节，挑选 1 个工具练习。
2. 记录输入、输出与改进点。
3. 把过程整理成 1 段复盘。
