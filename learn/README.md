# Learn｜从 0 到 1 的 AI 前端应用学习路径

> 面向「无后端、低成本、纯前端」的 AI 产品从入门到上线的完整学习路线。
> 参考项目现有文档的使用方式：模块化拆分、逐步实践、可复用模板。

## 你将学到什么

- **大模型基础知识**：理解模型能力边界、推理 vs 生成、常见误区。
- **不同模型能力差异**：语言模型、视觉模型、检索增强（RAG）的适用场景。
- **对话核心机制**：消息结构、参数配置、上下文管理、输出控制。
- **提示词工程**：从基础指令到多步任务拆解与提示词资产化。
- **HTML 工作流搭建**：用单文件 HTML 构建稳定的 AI 交互流程。
- **产品上线与商业化**：从需求验证、发布上线到交付收费。
- **拿到文件包后的学习方法**：如何学习、改造、排错、创作。
- **对外介绍与团队使用**：如何介绍产品、如何内部复用。

## 使用方式（建议）

- **顺序学习**：按编号阅读，逐步建立完整的能力体系。
- **场景学习**：根据你当前阶段选择对应章节深入。
- **练习驱动**：每章都有「实践任务」，直接在本项目的 HTML 工具中复用。

---

## 文档结构说明

每一章包含以下内容：

- **目标与收益**：学完能做什么
- **关键概念**：必备知识点
- **核心方法**：可复用步骤与模板
- **实践任务**：可直接落地到本项目的操作
- **常见坑**：避免浪费时间
- **延伸阅读与练习**：进一步巩固

> 这是一套完整可持续迭代的学习系统，后续内容越丰富，前面的结构越完善。
