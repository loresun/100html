# 15｜仓库文档导航（从哪里看起）

## 目标与收益

- 清楚知道仓库里有哪些文档。
- 知道不同文档的用途与阅读顺序。

## 核心文档

- `README.md`：项目总览与工具清单。
- `learn/`：学习路径与实践教程。
- `docs/`：项目规划与进展记录。
- `llm-tutorials/`：模型平台与教程资料。

## 推荐阅读顺序（新手版）

1. `README.md`（理解整体）
2. `learn/01-04`（理解模型与提示词）
3. `learn/05-06`（理解工具与架构）
4. `learn/09-11`（学会改造与排错）
5. `learn/12-14`（学会介绍与团队使用）

## 实践任务

1. 按顺序阅读并写下 5 条收获。
2. 选一个文档为团队做 10 分钟分享。
