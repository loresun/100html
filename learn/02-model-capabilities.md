# 02｜模型能力与选型

## 目标与收益

- 能区分不同类型模型的能力与边界。
- 知道在不同任务里怎么选模型、怎么混用模型。
- 具备“用更少成本获得更稳定结果”的模型配置思维。

## 新手先懂的 3 件事

1. 模型不是越大越好，适合更重要。
2. 文案/改写用语言模型，分析/逻辑用推理模型。
3. 图片理解需要视觉或多模态模型。

## 关键概念

- **语言模型（LLM）**：擅长文本理解、生成与结构化输出。
- **视觉模型（VLM）**：理解图像、图文对齐、提取信息。
- **多模态模型**：同时处理文字与图像输入。
- **推理模型**：更擅长多步逻辑与复杂问题拆解。
- **成本与延迟**：模型越强大，单次调用成本越高。

## 能力对比（简表）

| 场景 | 推荐模型 | 为什么 | 典型输出 |
| --- | --- | --- | --- |
| 内容生成/改写 | 语言模型 | 语言表达与风格控制强 | 标题、正文、文案 |
| 结构化分析 | 推理模型 | 多步逻辑，稳定性高 | 表格、步骤、框架 |
| 图片理解 | 视觉模型 | OCR/图文理解 | 图片描述、信息提取 |
| 图文联合创作 | 多模态模型 | 输入/输出协同 | 图配文、视觉脚本 |

## 选型策略

### 1. 任务拆分选型

- **先推理 → 后生成**：先用推理模型生成结构，再用 LLM 填充文字。
- **先理解 → 后转化**：视觉模型提取信息，再交给 LLM 输出内容。

### 2. 预算优先策略

- 日常任务：用成本低的模型跑主流程。
- 关键结果：用高质量模型进行“最终润色”。

### 3. 稳定性优先策略

- 重要输出要降低随机性（低 temperature）。
- 多轮对话使用结构化上下文摘要。

## 新手选型流程（照着选）

1. 先判断任务：是“写内容”还是“做分析”？
2. 写内容：先用 LLM；做分析：先用推理模型。
3. 如果涉及图片：增加视觉模型。
4. 成本不够：先跑低成本模型，再用高质量模型润色。

## 实践任务

1. 选一个“分析 + 写作”的任务。
2. 设计「推理模型 + 生成模型」两步流程。
3. 写出你自己的“模型路由规则”（什么时候用哪个模型）。

## 常见坑

- 用单一模型强行解决所有问题。
- 忽略模型输出稳定性与成本。
- 过度追求最强模型，导致产品成本不可控。

## 新手小抄

- 写作：LLM
- 逻辑：推理模型
- 图片：视觉/多模态
- 低成本优先：先低后高

## 延伸阅读与练习

- 练习：列出 5 个任务，并为每个任务选择最合适的模型。
- 练习：设计一个“低成本 → 高质量”的两阶段提示词流程。
