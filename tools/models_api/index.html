什么是"动态加载与解析"？

这个页面展示了一种强大的前端模式：配置驱动的 UI 渲染。 所有你看到的 9 个功能，都不是事先写死的 HTML，而是：

1. 读取 JSON 配置

程序启动时，自动从 prompts.json 读取所有功能定义。

2. 动态渲染组件

根据 JSON 中的 type 字段（text, select, range...），实时生成对应的 UI 控件。

3. 无需修改 HTML

添加新功能？只需在 JSON 里加几行配置，页面自动更新！

核心技术：Alpine.js x-for 循环 + x-if/x-show 条件渲染
