什么是粗野主义?

Neo-Brutalism 是对现代 Web 设计"精致感"的反叛。它拥抱原始的 HTML 结构、高饱和度的撞色、粗重的黑色边框和默认字体。

视觉特征

  • 粗黑色边框
  • 硬阴影 (Hard Shadows)
  • 复古 Web 安全色
  • 非对称布局
