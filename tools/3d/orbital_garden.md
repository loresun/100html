# Orbital Garden 3D（轨道花园）

## 目标
把 AI 回复转译成「轨道花园」——多层轨道、星体与轨迹光带。用户输入一句话，DeepSeek 输出结构化参数与一句解读，让用户感受 AI 回复如何影响 3D 动画。

## 交互
- 输入一句话或问题
- AI 返回轨道数量、半径、色彩、星体尺寸与旋转节奏
- 3D 中展示多层轨道、发光星体与漂浮回应

## AI 输出规范（JSON）
```json
{
  "summary": "一句话解读",
  "palette": ["#34D399", "#A78BFA", "#FBBF24"],
  "orbitCount": 5,
  "radii": [1.6, 2.2, 3.1, 4.0, 4.6],
  "speeds": [0.6, 0.4, 0.3, 0.25, 0.2],
  "planetSizes": [0.18, 0.22, 0.12, 0.2, 0.16],
  "halo": 0.7
}
```

## 渲染要点
- 轨道环线为发光线条
- 星体带有轻微呼吸亮度
- 背景星空 + 雾化光晕
