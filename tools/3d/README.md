# 3D + DeepSeek 演示工具

这里包含多个基于 Three.js 的 3D 交互 demo，每个 demo 都对应一份分析用的 MD 说明文件。

| Demo | 说明文件 | HTML |
| --- | --- | --- |
| Mood Curve 3D | `mood_curve.md` | `mood_curve.html` |
| Particle Poem 3D | `particle_poem.md` | `particle_poem.html` |
| Orbital Garden 3D | `orbital_garden.md` | `orbital_garden.html` |
| Photo Orbit 3D | `photo_orbit.md` | `photo_orbit.html` |

使用说明：
1. 打开任意 HTML 文件。
2. 右上角设置 DeepSeek API Key（读取/写入 `localStorage.global_llm_config`）。
3. 输入内容，生成对应 3D 可视化效果。
