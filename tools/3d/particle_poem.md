# Particle Poem 3D（粒子诗歌云）

## 目标
将一句话转换成「粒子诗歌星云」。DeepSeek 生成诗意短句、关键词与色彩，前端将关键词映射为 3D 粒子群和漂浮文字，展示动态云团。

## 交互
- 输入一句话/主题
- AI 生成诗意短句 + 关键词 + 配色
- 关键词用浮动粒子+发光文字展示

## AI 输出规范（JSON）
```json
{
  "poem": "一两句短诗",
  "keywords": ["海风", "月光", "远航", "回忆"],
  "palette": ["#38BDF8", "#F472B6", "#FCD34D"],
  "density": 0.8,
  "drift": 0.6,
  "spark": 0.7
}
```

## 渲染要点
- 粒子云团随时间轻微漂移
- 关键词以柔光文字漂浮在粒子群中
- 背景为柔雾渐变
