编校配置

顺序模式： 按顺序逐部分编校，后续部分基于前面已编校的结果，保持整体延续性和连贯性。适合需要前后呼应的文档。
并行模式： 所有部分同时并行编校，速度快。每部分独立处理（但包含上下文参考）。适合段落相对独立的文档。

应用预设后可继续编辑，支持自定义细节。

💡 上下文编校机制
分段编校时，系统会自动为每个部分提供"上一部分 + 当前部分 + 下一部分"的上下文，确保编校结果与前后内容保持连贯。

超级编校编辑器 - 使用指南

快速入门

  1. 配置 DeepSeek API Key（点击右上角"API 设置"）
  2. 导入文档（支持 .docx / .txt / .md）或直接粘贴内容
  3. 选择编校模式：全文编校（短文）或 分段编校（长文）
  4. 点击"生成差异对比"查看修改内容
  5. 下载编校后的文档

功能说明

📁 文档导入 & 预览

支持上传 .docx、.txt、.md 格式文件，或直接粘贴文本。导入后会自动显示预览。

💡 提示：Word 文档会自动提取纯文本，保留段落结构。

✂️ 自动拆分段落

将长文档按字数阈值拆分为多个部分，便于分段处理。

📊 默认每部分约 300 字，可在"编校配置"中调整。

📝 内容压缩提取

使用 AI 对原文进行摘要提炼，输出：

  • 80-150 字的精炼摘要
  • 3-6 条核心要点
  • 关键风险或注意事项（如有）
📄 全文编校

适合 1000 字以下的短文档，一次性提交给 AI 进行全文润色。

⚠️ 注意：长文档建议使用"分段编校"，避免超出 API 限制。

📑 分段编校

适合长文档，按字数拆分后逐部分编校。支持两种模式：

顺序模式

按顺序逐部分编校，后续部分基于前面已编校的结果，保持整体延续性和连贯性。

并行模式

所有部分同时并行编校，速度快，但每部分独立处理（仍有上下文参考）。

🔍 差异对比

生成原文与编校稿的差异视图：

  • 绿色下划线 = 新增内容
  • 红色删除线 = 删除内容
⚙️ 编校配置说明
分段字数阈值

每部分的目标字数。300-500 字适合大多数场景。

编校提示词模板

预设 4 种模式：文字润色、逻辑提取、标题整理、翻译校对。可自定义编辑。

常见问题

Q: 编校后的内容会丢失格式吗？

A: 会保留段落结构，但不会保留复杂格式。建议在原文中使用纯文本或简单换行。

Q: 为什么分段编校比全文编校慢？

A: 长文档被拆分成多个部分，每个部分都需要单独调用 API。如果选择并行模式会快很多。

Q: 可以只修改部分段落吗？

A: 可以直接编辑"逐段编校结果"中的内容，或在"编校稿"面板中手动修改。
