AI 智能编辑器 - 使用指南

快速入门

  1. 配置 DeepSeek API Key（点击右上角"API 设置"）
  2. 在编辑器中输入文章内容
  3. 按 Tab 键续写内容
  4. 选中已有文字，可进行润色/改写/翻译等操作
  5. 所有修改记录保存在右侧历史栏，可随时查看

核心功能详解

1 Tab 续写

触发方式：在编辑区将光标放在任意位置，按 Tab 键

工作原理：AI 会读取光标前后的上下文，自动续写下一句话或下一段内容

效果：续写的内容会以绿色标记显示，1秒后淡入正文

💡 使用技巧：

  • 在上文写完后按 Tab，AI 会自然衔接
  • 可以在"预设配置"中修改续写的提示词
  • 续写适合：灵感枯竭、接续思路、扩展内容
2 选中润色

触发方式：选中一段文字，会自动弹出修改气泡框

工作原理：在弹窗中输入修改需求（如"改得更简洁"、"翻译成英文"），AI 会基于选中内容进行改写

效果：修改后的内容会以蓝色高亮显示

💡 快捷指令（点击可直接使用）：

润色一下，让语言更通顺 改写得更幽默风趣一点 精简这段文字 扩写这段内容，增加细节 翻译成英文

💡 自定义指令：

也可以在弹窗中输入任意需求，如"改成对话体"、"增加比喻"、"突出重点"等

3 修改历史

位置：编辑器右侧边栏

内容：记录所有 AI 修改，包括：

  • 操作类型（续写 / 改写）
  • 修改时间
  • 原始内容 vs 修改后内容（差异对比）
  • 修改提示词（如"改写成更幽默"）
  • V4 Pro 模型的思考过程（点击可展开）

💡 功能说明：

  • • 点击 按钮可将原文复制到剪贴板
  • • 点击"清空"可删除所有历史记录
  • • 历史记录自动保存在本地，刷新页面不丢失
