如何使用 ICS 日历文件

🍎

macOS

✅ 直接双击 .ics 文件，系统会自动用「日历」应用打开，点击「添加」即可导入。

🪟

Windows

✅ 直接双击 .ics 文件：

  • • Windows 10/11: 自动用「日历」应用打开
  • • 安装了 Outlook: 自动导入到 Outlook 日历
📱

iPhone / iPad

通过 AirDrop 或邮件发送 .ics 文件到手机，点击文件后选择「添加到日历」。

🤖

Android

通过文件管理器打开 .ics 文件，选择使用「Google 日历」或其他日历应用导入。

🌐

网页版日历

  • Google Calendar: 设置 → 导入与导出 → 导入
  • Outlook Web: 日历 → 添加日历 → 从文件上传
  • iCloud 日历: 设置 ⚙️ → 导入日历

💡 小贴士

ICS 是国际通用的日历格式标准 (iCalendar)，几乎所有日历应用都支持。「系列日历」可以一次性导入多个事件！
