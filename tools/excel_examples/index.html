使用说明

  • 每个页面均支持上传 Excel 或 CSV 文件，字段名需与示例文件一致。
  • 点击「载入内嵌 Demo 数据」即可快速体验，无需下载文件。
  • 所有图表由 Chart.js 渲染，数据解析由 SheetJS 完成，可直接复用。
