流式输出演示

理解 LLM 的"打字机效果"：如何实现实时显示 AI 回复，无需等待完整响应

1 什么是流式输出？

流式输出 (Streaming) 是一种实时传输技术，AI 会一点一点地返回结果，而不是等待全部生成完毕后再一起返回。

对比

传统模式 (等待)
AI 先思考 10 秒 → 一次性返回全部内容
流式模式 (实时)
AI 边思考边返回 → 用户实时看到内容增加

为什么需要流式输出？

用户体验更好：不用长时间等待
实时反馈：看到 AI "正在思考"
提前中断：不想看了可以随时停止
降低延迟感知：感觉响应更快

2 技术原理

HTTP 请求对比 
// 传统请求：等待完整响应
const response = await fetch(url, { stream: false });
const data = await response.json();
// AI 生成 1000 字 = 等待 10 秒 → 一次性收到 1000 字

// 流式请求：实时接收数据块
const response = await fetch(url, { stream: true });
const reader = response.body.getReader();
while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    // 每收到一批数据就处理
    const chunk = new TextDecoder().decode(value);
    processChunk(chunk);
}
// AI 生成 1000 字 = 每隔几十毫秒收到一批数据 → 实时显示

数据块格式

服务器返回的数据使用 data: {...} 格式，每行一个数据块。

3 代码实现

使用 simple-llm-api.js 的流式方法 
// 创建 LLM 客户端
const llm = createLLM('your-api-key');

// 方法1: 使用 for...of 遍历
async function demo1() {
    for await (const chunk of llm.stream('讲一个故事')) {
        // 每收到一个数据块就追加到显示区域
        document.getElementById('output').innerHTML += chunk;
    }
}

// 方法2: 使用 Generator 手动控制
async function demo2() {
    const generator = llm.stream('写一首诗');
    let result = '';
    
    while (true) {
        const { value, done } = await generator.next();
        if (done) break;
        result += value;
        updateDisplay(result);  // 实时更新显示
    }
}

// 方法3: 停止流式输出
async function demo3() {
    const generator = llm.stream('写很长的文章');
    let result = '';
    
    for await (const chunk of generator) {
        result += chunk;
        updateDisplay(result);
        
        // 如果用户点击停止，或者达到某个条件
        if (shouldStop) {
            generator.return();  // 停止生成
            break;
        }
    }
}

关键点

  • • 使用 for await...of 遍历生成器
  • • 每个 chunk 是一段文本，不是完整回复
  • • 调用 generator.return() 可以提前停止

5 进阶技巧与最佳实践

打字机效果

让文字一个一个出现，更有"AI 正在打字"的感觉。 

// 打字机效果：添加短暂延迟
for await (const chunk of llm.stream(text)) {
    for (const char of chunk) {
        output += char;
        updateDisplay(output);
        await sleep(30);  // 每个字延迟 30ms
    }
}

Markdown 渲染

在流式输出的同时渲染 Markdown 格式。 

// 使用 marked.js 实时渲染
for await (const chunk of llm.stream(text)) {
    rawOutput += chunk;
    html = marked.parse(rawOutput);
    display.innerHTML = html;
}
