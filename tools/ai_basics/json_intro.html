什么是 JSON？

JSON 是 JavaScript Object Notation 的缩写。 别被这个英文名吓到——它其实就是一种组织数据的格式，就像我们用表格整理信息一样简单。

{ }

用生活中的例子理解 JSON

想象你要向朋友介绍一个人，你会怎么说？

日常说法

"这是小明，今年 25 岁，是个程序员，喜欢打篮球和弹吉他，目前单身。"

JSON 写法 
{
  "name": "小明",
  "age": 25,
  "job": "程序员",
  "hobbies": ["篮球", "吉他"],
  "single": true
}

核心思想：JSON 就是把信息用 "键": 值 的形式一条一条列出来， 用大括号 { } 包起来。就这么简单！

JSON 语法速查表

字符串 (String) "文字"

文字内容，必须用英文双引号包裹

"name": "DeepSeek"
数字 (Number) 123

整数或小数，不需要引号

"price": 99.9
布尔值 (Boolean) true/false

只有"是"或"否"两种状态

"isVIP": true
数组 (Array) [...]

多个值的列表，用方括号和逗号

"tags": ["AI", "教程"]
对象 (Object) {...}

嵌套的 JSON，可以层层嵌套

"author": {"name": "小明"}
空值 (Null) null

表示"没有值"或"不知道"

"nickname": null

为什么 AI 对话要用 JSON？

因为 JSON 是程序之间"说话"的通用语言！

1

结构化 = 不会误解

自然语言有歧义，而 JSON 的键值对格式非常明确。"role": "user" 就是用户，不可能被理解成别的。

2

通用性 = 全球通用

几乎所有编程语言都能读写 JSON。无论是 Python、JavaScript 还是 Java，大家都"认识"它。

3

可扩展 = 灵活添加

想加新字段？直接加一行就行。比如想告诉 AI 使用中文回复，加个 "language": "zh" 即可。

动手试试：读懂一段 AI 对话的 JSON 

{
  "model": "deepseek-v4-flash",
  "messages": [
    {
      "role": "system",
      "content": "你是一个翻译助手"
    },
    {
      "role": "user",
      "content": "请把 Hello World 翻译成中文"
    }
  ],
  "temperature": 0.7,
  "stream": false
}

这段 JSON 告诉 AI 什么？

  • • 使用 deepseek-v4-flash 模型
  • • 你的身份是"翻译助手"
  • • 用户问的是"把 Hello World 翻译成中文"
  • • 创造力系数 0.7（中等随机）
  • • 不用流式输出，一次返回全部

新手常见错误

用了中文引号

错误："name" → 正确："name"
JSON 必须用英文半角双引号 "，中文引号 "" 会报错。

最后一项多加了逗号

错误：{"a": 1, "b": 2,}
最后一个键值对后面不能有逗号！这是最常见的语法错误。

键名没加引号

错误：{name: "小明"} → 正确：{"name": "小明"}
JSON 的键名（左边的部分）也必须用双引号包裹。

总结：30 秒记住 JSON

1. 大括号 { } 包裹整个对象

2. "键": 值 成对出现，用冒号分隔

3. 逗号 分隔多个键值对（最后一个不加）

4. 方括号 [ ] 表示数组（列表）

5. 双引号 必须是英文半角
