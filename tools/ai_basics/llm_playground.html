关于这个实验室

这里展示了与大语言模型 (LLM) 交互的核心概念。你可以亲身体验 流式输出 (Streaming) 的即时感， 探索 温度 (Temperature) 对创造力的影响，学习如何利用 提示词模板 (Prompt Templates) 组装输入， 以及如何让 AI 输出 结构化 JSON 数据 并渲染为 UI 卡片。

3. 提示词组装 (Prompt Assembly)

在开发应用时，我们通常不会让用户直接写 Prompt，而是提供表单，后台将输入填入预设模板。

const prompt = ` 你是一位 {{ promptVars.role || '{role}' }}。 请用 {{ promptVars.tone || '{tone}' }} 语气， 完成以下任务：{{ promptVars.task || '{task}' }}。 `;

4. 结构化输出与渲染 (JSON & UI)

大模型不仅能聊天，还能充当“后端接口”。通过强制 JSON 输出，我们可以将 AI 的回答直接渲染成漂亮的 UI 卡片。

RAW JSON RESPONSE
{{ jsonRaw }}

{{ item.name }}

{{ item.type }}

{{ item.description }}

{{ tag }}
Rarity: {{ item.rarity }} ID: #{{ idx + 1 }}

5. 记忆的本质 (Context & History)

AI 本身是"健忘"（无状态）的。要让它"记得"之前的对话，开发者必须在每次请求时，把历史聊天记录打包一起发送。

模式 A: 无记忆 (Stateless) 每次只发当前句

8. 工具调用 (Function Calling / Tool Use)

AI 只能输出文本，但通过 "Function Calling"，它可以输出一个 JSON 指令来“指挥”代码执行操作（如查天气、查库存）。

{{ step.content }}

9. 异步并行 (Async Parallelism)

AI 请求通常很慢。如果需要做多件事（比如生成 3 个不同标题），串行（排队做）会非常慢，而 并行（一起做）可以节省大量时间。

任务 3: 公众号标题

10. 思维链 (Chain of Thought)

对于复杂逻辑题，直接问 AI 可能会出错。但如果要求它 "一步步思考" (Let's think step by step)，它的推理能力会大幅提升。

逻辑陷阱题

“我有 3 个苹果。昨天我吃掉了 1 个。今天我又买了两袋苹果，每袋有 5 个。但我回家的路上不小心掉了一袋，里面的苹果滚得满地都是，我只捡回了 2 个。请问我现在一共有几个苹果？”
