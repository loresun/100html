1. Prompt 是什么？

Prompt（提示词）是你给 AI 的指令或问题。好的 Prompt = 清晰的需求描述 + 必要的上下文信息。

模糊的 Prompt

"写一个网页"

AI 无法理解你的具体需求，生成的内容可能完全不符合预期。

清晰的 Prompt

"创建一个个人介绍网页，包含：
- 标题：'我的个人主页'
- 段落：介绍我的名字、职业、爱好
- 一个‘联系我’按钮
- 使用蓝色主题"

AI 能准确理解需求，生成符合预期的代码。

💡 Prompt 写作公式

我要创建一个 [页面类型]，包含 [功能列表]，风格是 [风格描述]，要求 [特殊需求]。

2. 如何描述你的需求

好的需求描述应该包含以下几个要素：

1

页面类型

说明你要创建什么样的页面

"个人简历页面"、"产品展示页"、"表单收集页"、"工具页面"
2

功能列表

列出页面需要包含的元素和功能

"一个标题、一个自我介绍段落、一个技能列表、一个联系表单"
3

风格要求

描述视觉风格和交互方式

"简洁现代的风格"、"使用蓝色主题"、"卡片式布局"、"响应式设计"
4

参考示例

如果有参考页面，可以提供给 AI

"参考 xxx.html 的布局风格"、"参考小红书的卡片样式"

3. 生成和保存代码

当 AI 生成代码后，你需要正确地保存和使用它。

保存步骤

1. 复制代码

从 AI 响应中复制完整的 HTML 代码

2. 创建文件

在 VS Code 中新建文件，命名为 xxx.html

3. 保存运行

保存后用 Live Server 打开查看效果

模板提示词

请帮我创建一个 HTML 页面，满足以下要求：

1. 页面类型：[如：个人主页/工具页面/登录页]
2. 主要功能：
   - [功能1]
   - [功能2]
   - [功能3]
3. 风格要求：[如：简洁现代/卡通可爱/专业商务]
4. 配色方案：[如：蓝色主题/绿色主题/黑白配]
5. 交互需求：[如：点击按钮弹出提示/表单提交功能]

参考现有页面：[xxx.html]，保持类似的代码结构。

4. 迭代优化代码

第一版代码往往不完美，需要通过多次对话来优化。

常用优化指令

"把蓝色改成绿色" - 修改颜色
"增加一个返回顶部按钮" - 添加功能
"把卡片改成圆角" - 调整样式
"简化代码，去掉不需要的部分" - 精简代码
"这段代码报错，请修复" - 修复错误

迭代示例

# 第一次对话

用户："创建一个个人主页"

AI：生成了初始版本

# 第二次对话

用户："把背景改成浅蓝色，添加技能卡片"

AI：修改了样式和内容

# 第三次对话

用户："技能卡片改成一排三个，添加动画效果"

AI：优化了布局和交互
