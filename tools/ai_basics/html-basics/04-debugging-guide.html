1. 控制台查错

浏览器控制台（Console）是查看 JavaScript 错误的最佳工具。

Syntax Error

语法错误 - 代码写错了

Uncaught SyntaxError: Unexpected token '{'

Reference Error

引用错误 - 变量未定义

Uncaught ReferenceError: xxx is not defined

Type Error

类型错误 - 调用了错误类型的方法

Uncaught TypeError: xxx is not a function

Network Error

网络错误 - 请求失败

Failed to fetch

💡 打开控制台的方法

F12 键
Cmd+Option+I (Mac)
Ctrl+Shift+I (Windows)
右键 → 检查

2. 网络请求错误

调用 API 时常见的 HTTP 状态码。

状态码 名称 含义 解决方法
400 Bad Request 请求参数错误 检查请求格式和参数
401 Unauthorized 未授权/Key 错误 检查 API Key 是否正确
403 Forbidden 没有权限访问 检查权限设置
404 Not Found 资源不存在 检查 URL 是否正确
429 Too Many Requests 请求过于频繁 降低请求频率
500 Server Error 服务器内部错误 稍后重试或联系服务方

3. HTML 常见错误

以下是 HTML 编写中最常见的错误及其修复方法。

标签未闭合

每个打开的标签都必须关闭

❌ <div>内容</p>
✅ <div>内容</div>

属性值缺少引号

属性值必须用引号包围

❌ <a href=example.com>
✅ <a href="example.com">

路径错误

文件路径大小写敏感，要用正斜杠

❌ src="Images/img.png" (Windows 路径)
✅ src="./assets/images/img.png"

4. 修复策略

遇到错误时的标准排查流程。

1

阅读错误信息

错误信息通常会告诉你问题所在，包括文件名和行号。

2

定位问题代码

根据错误提示的行号，找到对应的代码位置。

3

复制错误信息给 AI

把错误信息和相关代码一起给 AI，让它帮你分析和修复。

4

验证修复结果

保存后刷新页面，确认错误已解决。
