1. CSS 基础概念

CSS（层叠样式表）用于控制网页的外观。理解选择器和属性是基础。

选择器

选择要样式的 HTML 元素

.className {} / #idName {} / element {}

属性与值

定义元素的样式效果

color: red; / font-size: 16px;

常见属性速查

属性 作用 示例
color 文字颜色 color: #333;
font-size 字体大小 font-size: 16px;
background 背景颜色 background: #f0f0f0;
border 边框 border: 1px solid #ccc;
border-radius 圆角 border-radius: 8px;

2. 布局系统

CSS 提供了多种布局方式，最常用的是 Flexbox 和 Grid。

Flexbox 弹性盒子

适合一维布局（单行或单列）

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 16px;
}

Grid 网格布局

适合二维布局（行和列）

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}

💡 快速上手建议

对于大多数工具页面，Flexbox 足够应对 90% 的布局需求。 只需要记住 display: flex 和 justify-content、align-items 就能做很多布局。

3. 间距与大小

控制元素的大小和间距是页面美观的关键。

外边距 margin

元素外部的间距

margin: 16px;

内边距 padding

元素内部的间距

padding: 24px;

宽高 width/height

元素的尺寸大小

width: 100%;

margin/padding 简写

/* 四周统一 */ margin: 16px;

/* 上下 左右 */ margin: 16px 24px;

/* 上 左右 下 */ margin: 16px 24px 8px;

/* 上 右 下 左 */ margin: 16px 24px 8px 12px;

4. 颜色系统

CSS 支持多种颜色表示方式，常用的有以下几种。

颜色名称

预定义的颜色名称

color: red;

十六进制

#RRGGBB 格式

color: #ff0000;

RGB

红绿蓝三原色

color: rgb(255, 0, 0);

RGBA

带透明度的 RGB

color: rgba(255,0,0,0.5);
