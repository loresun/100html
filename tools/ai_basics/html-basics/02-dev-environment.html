1. 代码编辑器：VS Code

VS Code（Visual Studio Code） 是目前最流行的代码编辑器，免费、强大、插件丰富，是前端开发者的首选。

下载安装

访问 code.visualstudio.com，点击下载按钮。

macOS · Windows · Linux

必备插件

安装以下插件让开发更高效：

  • • Live Server - 本地实时预览
  • • HTML Snippets - HTML 代码提示
  • • Prettier - 代码格式化

💡 使用技巧

VS Code 常用快捷键：

Cmd/Ctrl + B Toggle 侧边栏
Cmd/Ctrl + ` 打开终端
Cmd/Ctrl + S 保存文件
! + Tab 生成 HTML 模板

使用 Live Server 实时预览

安装 Live Server 插件后，你可以：

  1. 1 右键点击 HTML 文件，选择 "Open with Live Server"
  2. 2 浏览器会自动打开页面，每次保存文件都会自动刷新
  3. 3 修改代码 → 保存 → 查看结果，无需手动刷新

2. 浏览器开发者工具

浏览器开发者工具（DevTools）是调试网页的利器，每个前端开发者都必须掌握。

Chrome / Edge

按 F12 或 Cmd+Option+I 打开

Firefox

按 F12 或 Cmd+Option+I 打开

Safari

先开启开发菜单：偏好设置 → 高级 → 显示开发菜单

DevTools 核心面板

Elements（元素）

查看和修改 HTML 结构、CSS 样式，实时预览效果。

Console（控制台）

查看 JavaScript 错误、执行代码、打印调试信息。

Network（网络）

查看页面加载的所有请求，调试 API 调用。

Device Mode

模拟不同设备和屏幕尺寸，测试响应式效果。

3. 浏览器必备插件

以下浏览器插件能让你的开发工作更加高效。

JSON Viewer

格式化显示 JSON 数据，方便调试 API 响应。

Chrome Firefox

WhatFont

点击页面任意文字，立即显示字体名称、大小、颜色等信息。

Chrome Safari

ColorZilla

从网页中提取任意颜色，获取完整的颜色代码。

Chrome Firefox

4. 完整开发工作流

让我们把这些工具串联起来，形成一个完整的开发流程。

1

打开项目

用 VS Code 打开你的项目文件夹

File → Open Folder → 选择你的项目目录
2

创建/编辑文件

在 VS Code 中编写 HTML、CSS、JavaScript 代码

新建文件 → 输入代码 → Cmd+S 保存
3

实时预览

右键 HTML 文件 → Open with Live Server

修改代码 → 自动刷新 → 浏览器查看效果
4

调试优化

打开浏览器 DevTools，排查问题并优化

F12 打开 DevTools → Console 查看错误 → Elements 调整样式
