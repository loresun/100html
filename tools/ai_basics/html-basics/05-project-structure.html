1. 典型项目结构

一个 HTML 工具项目通常包含以下文件和文件夹。 

my-tool/
├── index.html          # 主页面（必需）
├── assets/
│   ├── css/
│   │   └── style.css   # 样式文件
│   ├── js/
│   │   └── main.js     # 脚本文件
│   └── images/
│       └── logo.png    # 图片资源
├── data/
│   └── config.json     # 配置文件
└── README.md           # 项目说明

HTML 文件

页面的骨架结构，定义了页面内容和布局。

CSS 文件

页面的外观样式，控制颜色、布局、动画等。

JS 文件

页面的交互逻辑，处理用户操作和数据。

2. HTML 页面组成

一个完整的 HTML 页面由几个主要部分组成。

<head> 头部

包含页面元数据，不显示在页面上。

<head>
    <meta charset="UTF-8">           <!-- 字符编码 -->
    <meta name="viewport" ...>        <!-- 移动端适配 -->
    <title>页面标题</title>           <!-- 浏览器标签显示 -->
    <script src="..."></script>      <!-- 引入 JS -->
    <link rel="stylesheet" ...>       <!-- 引入 CSS -->
</head>

<body> 主体

页面的可见内容。

<body>
    <header>页面头部</header>
    <main>主要内容</main>
    <footer>页面底部</footer>
</body>

3. JavaScript 逻辑分层

一个工具的 JavaScript 代码通常分为几个层次。

数据层

定义数据、状态、配置项等。

const config = { apiKey: '' };
const data = ref([]);

逻辑层

处理业务逻辑、数据转换等。

function processData() { ... }
async function fetchAPI() { ... }

交互层

处理用户事件、响应用户操作。

button.onClick = () => { ... }
input.onChange = (e) => { ... }

视图层

更新页面显示、渲染内容。

element.innerHTML = ...
element.classList.add(...)

4. CSS 样式组织

了解 CSS 的常见组织方式。

内联样式

直接写在标签上

<div style="color: red;">

内部样式表

写在 <style> 标签中

<style>.cls { ... }</style>

外部样式表

单独的 .css 文件

<link rel="stylesheet" href="...">

CSS 框架

如 Tailwind CSS

<div class="p-4 bg-blue-500">
