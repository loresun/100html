1. 免费部署平台推荐

以下平台都支持免费托管静态 HTML 页面，适合个人项目。

GitHub Pages

最适合开发者，稳定可靠

  • • 完全免费
  • • 无限流量
  • • 自定义域名

Vercel

部署简单，速度快

  • • 5 秒部署
  • • 自动 HTTPS
  • • 全球 CDN

Netlify

拖拽部署，易上手

  • • 拖拽上传
  • • 自动构建
  • • 表单功能

2. GitHub Pages 部署教程

GitHub Pages 是最推荐的部署方式，以下是详细步骤。

1

创建 GitHub 仓库

访问 github.com，创建新仓库，命名为 你的用户名.github.io

2

上传文件

把 index.html 和相关文件拖拽到仓库中

3

启用 Pages

Settings → Pages → Source 选择 "main" 分支 → Save

4

访问你的网站

几分钟后，访问 https://你的用户名.github.io

3. Vercel 快速部署

Vercel 部署更简单，适合快速上线。

方法一：拖拽部署（最简单）

  1. 访问 vercel.com，注册账号
  2. 把包含 index.html 的文件夹拖到网页上
  3. 自动部署，即刻上线

方法二：命令行部署

npm i -g vercel
vercel

4. 分享你的工具

部署完成后，可以通过多种方式分享给你的朋友和用户。

直接分享链接

把网址链接发送给朋友，他们打开就能使用。

生成二维码

用二维码生成器把链接转成二维码，方便手机访问。

开源分享

把源码放到 GitHub，让更多人参与改进。

写使用文档

写一个简单的 README 说明如何使用你的工具。
