HTML 是什么？

HTML = 超文本标记语言（HyperText Markup Language）。它是用来描述网页结构的语言。

💡 生活化比喻

想象你要建一座房子：
• HTML = 房子的骨架结构（哪里是墙，哪里是门，哪里是窗）
• CSS = 装修材料（墙是什么颜色，门是什么材质）
• JavaScript = 电器和开关（灯怎么亮，门怎么自动打开）

HTML 的核心特点

标记语言

用标签（Tag）来标记内容，如 <h1> 表示标题，<p> 表示段落。

层级结构

标签可以嵌套，形成树形结构，就像文件夹里的子文件夹一样。

浏览器理解

所有浏览器（Chrome、Edge、Safari）都能直接读取和渲染 HTML 文件。

纯文本

HTML 文件本质上是纯文本，用任何编辑器（记事本、VS Code）都能编写。

编写你的第一个 HTML 文件

跟随以下步骤，在 3 分钟内创建你的第一个 HTML 文件。

1

创建文件

在电脑上新建一个文本文件，重命名为 my-first-page.html。
💡 提示：确保文件后缀是 .html 而不是 .txt

2

写入内容

用任意文本编辑器打开文件，输入以下代码： 

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>这是我用 HTML 写的第一个网页。</p>
</body>
</html>
3

在浏览器中打开

双击这个 HTML 文件，它会在你的默认浏览器中打开。你应该能看到：

Hello, World!

这是我用 HTML 写的第一个网页。

🎉 恭喜！你已经完成了第一个网页！

这就是 HTML 的魔力——简单、直接、即时可见。

常用标签速查表

以下是最常用的 HTML 标签，记住这些你就能应对 80% 的基础需求。

标签 名称 示例 说明
<h1>~<h6> 标题

标题文字

 h1 最大，h6 最小
<p> 段落

这是一段文字...

 用于普通文本
<a href=""> 链接 点击跳转 href 属性填写目标地址
<img src=""> 图片 🖼️ 图片 src 填写图片地址
<div> 容器
区块
 用于分组和布局
<span> 行内容器 一段文字文字 用于行内分组
<ul>/<li> 列表
  • 项目1
  • 项目2
 无序列表
<button> 按钮 可点击的元素
<input> 输入框 用户输入区域
<!-- 注释 --> 注释 不显示的内容 代码说明，不被浏览器显示

⚠️ 注意事项

  • • 大多数标签是成对出现的，如 <标签>内容</标签>
  • • 标签可以嵌套，但要注意正确闭合：<a><b>内容</b></a>
  • • 属性值通常需要用引号包围：href="https://..."

动手实践：创建一个工具页面

现在让我们综合运用所学知识，创建一个简单的工具页面。

🎯 任务目标

创建一个"欢迎卡片"页面，包含：

  • 一个大标题（H1）
  • 一段介绍文字（P）
  • 一个"了解更多"链接（A）
  • 一个点击按钮（BUTTON）

📝 参考代码

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的欢迎卡片</title>
</head>
<body>
    <div style="text-align: center; padding: 50px;">
        <h1 style="color: #16a34a;">欢迎来到 HTML 世界</h1>
        <p>这是一个使用纯 HTML 创建的欢迎页面。</p>
        <p>从这里开始，你将学会创建各种工具！</p>
        
        <a href="https://www.google.com">了解更多</a>
        <br><br>
        <button onclick="alert('Hello!')">点击我</button>
    </div>
</body>
</html>

💡 进阶挑战

尝试修改代码：把标题颜色改成蓝色，添加更多段落，更改按钮点击后的提示内容。
