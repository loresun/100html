1 概述

simple-llm-api.js 是一个专为教学目的设计的 LLM API 封装库，简化了与大语言模型 API 的交互过程。

代码简洁

约 160 行代码，核心逻辑一目了然

易于学习

专为初学者设计，注释详细

开箱即用

支持 DeepSeek 和 OpenAI 两大平台

2 快速开始

基本用法 
<!-- 1. 引入库 -->
<script src="simple-llm-api.js"></script>

<!-- 2. 使用 -->
<script>
    // 创建客户端
    const llm = createLLM('your-api-key');

    // 发送对话
    const result = await llm.chat('你好，请介绍一下自己');
    console.log(result.content);
</script>

3 API_CONFIG

预定义的 API 配置常量，包含支持的模型和服务商信息。

配置结构 
const API_CONFIG = {
    // DeepSeek API 配置
    deepseek: {
        endpoint: 'https://api.deepseek.com/chat/completions',
        defaultModel: 'deepseek-v4-flash'
    },
    // OpenAI API 配置
    openai: {
        endpoint: 'https://api.openai.com/v1/chat/completions',
        defaultModel: 'gpt-4'
    }
};

// 访问配置
console.log(API_CONFIG.deepseek.endpoint);
// 输出: https://api.deepseek.com/chat/completions

4 SimpleLLM 类

C 构造函数

new SimpleLLM(config)

创建一个 LLM 客户端实例。

参数：

config (Object) - 配置对象，包含：

  • apiKey - API 密钥
  • endpoint - API 地址（可选，默认使用 DeepSeek）
  • model - 模型名称（可选，默认使用 deepseek-v4-flash）
  • systemPrompt - 系统提示词（可选）

M 方法

chat(message, options?) 发送对话请求

发送对话消息，获取 AI 的完整回复。

参数：

  • message (string) - 用户消息
  • options (Object, 可选) - 请求选项

options 支持：

  • temperature - 0-1 之间的数值，控制回复的随机性
  • maxTokens - 最大生成 token 数
  • model - 覆盖默认模型

返回值：

Promise<{ content: string, usage: object }>

返回包含回复内容和 token 使用量的对象

stream(message, options?) 流式输出

流式输出回复，实现打字机效果。

参数：同 chat()

返回值：

AsyncGenerator<string>

每次 yield 一个文本片段

setApiKey(key) 设置 API Key

设置或更新 API Key。

参数： key (string) - 新的 API Key

setSystemPrompt(prompt) 设置系统提示词

设置系统提示词，影响 AI 的行为和角色。

参数： prompt (string) - 系统提示词

5 createLLM 函数

便捷函数，快速创建 LLM 客户端。

函数签名 
createLLM(apiKey, options?)
使用示例 
// 最简用法
const llm = createLLM('sk-xxx');

// 带配置
const llm = createLLM('sk-xxx', {
    systemPrompt: '你是一个专业助手',
    model: 'deepseek-v4-flash'
});

// 链式调用
const result = await createLLM('sk-xxx').chat('你好');

6 完整示例

完整示例代码 推荐从这里开始学习 
<script src="simple-llm-api.js"></script>
<script>
    // 1. 创建客户端
    const llm = createLLM('your-api-key', {
        systemPrompt: '你是一个专业、有帮助的AI助手'
    });

    // 2. 发送对话
    async function main() {
        try {
            // 基础调用
            const result = await llm.chat('请用一句话介绍你自己');
            console.log('AI 回复:', result.content);
            console.log('Token 使用量:', result.usage);

            // 流式输出
            console.log('\n流式输出演示:');
            for await (const chunk of llm.stream('讲一个笑话')) {
                process.stdout.write(chunk);
            }
        } catch (error) {
            console.error('调用失败:', error.message);
        }
    }

    main();
</script>

错误处理

常见的错误类型包括：
• 401 - API Key 无效
• 429 - 请求频率限制
• 500 - 服务器内部错误
