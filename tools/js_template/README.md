# JS 公共库能力清单

本目录收录了多个实用 JavaScript 公共库的 demo 与用途说明，便于在大模型工具集成中快速复用。

| 库 | 简介 | 能力效果 | 大模型对接价值 |
| --- | --- | --- | --- |
| Lodash | 实用函数工具库，提供数据处理、集合操作等能力。 | 快速完成数组去重、对象合并、深拷贝等高频操作。 | 在提示词或结构化输出中，对模型返回的数组/对象进行清洗与归一化。 |
| Axios | Promise 风格的 HTTP 客户端。 | 更简洁地请求 API、处理拦截器与错误重试。 | 用于把模型请求封装成可复用 API 层。 |
| Day.js | 轻量级日期时间处理库。 | 方便格式化、计算时间差、处理时区。 | 在模型输出的时间信息上做统一格式化与校验。 |
| Chart.js | 简洁易用的图表绘制库。 | 快速展示柱状图、折线图、饼图等。 | 将模型生成的数据结构转成可视化报表。 |
| D3.js | 数据驱动文档的可视化库。 | 构建交互式、高度可定制的数据图形。 | 对模型生成的复杂数据做高级可视化。 |
| Apache ECharts | 功能强大的数据可视化库。 | 支持复杂图表、地图和交互式仪表盘。 | 将模型分析结果输出为仪表盘。 |
| Anime.js | 轻量动画库。 | 便捷实现 UI 微交互与动效。 | 用于生成更具表现力的模型输出展示。 |
| GSAP | 高性能动画平台。 | 提供时间轴与复杂动画编排。 | 适配模型生成的交互流程动效。 |
| SortableJS | 拖拽排序列表库。 | 快速构建可拖拽排序的列表。 | 支持模型产出的步骤或卡片拖拽排序。 |
| JSZip | 在浏览器中创建 ZIP。 | 将多个文件打包下载。 | 把模型生成的多份文件打包导出。 |
| FileSaver.js | 浏览器端保存文件。 | 将 Blob 或文本直接下载。 | 一键导出模型结果为本地文件。 |
| PapaParse | CSV 解析与生成库。 | 快速解析 CSV 或导出表格。 | 处理模型生成的表格数据。 |
| SheetJS (xlsx) | Excel 文件处理库。 | 解析和生成 Excel 文件。 | 把模型输出结构化数据导出 Excel。 |
| PDF-Lib | 浏览器端创建或修改 PDF。 | 生成 PDF 报告或合并 PDF。 | 把模型生成的报告导出为 PDF。 |
| jsPDF | 前端 PDF 生成库。 | 快速导出文本 PDF。 | 导出模型生成的内容为 PDF。 |
| html2canvas | 将 DOM 转为 Canvas。 | 截图页面或生成图片。 | 将模型生成的排版结果导出为图片。 |
| Clipboard.js | 复制到剪贴板工具。 | 支持点击按钮复制文本。 | 一键复制模型输出内容。 |
| Tippy.js | 轻量级提示气泡库。 | 快速创建提示信息。 | 在模型输出界面展示辅助说明。 |
| SweetAlert2 | 美观的弹窗提示库。 | 替代原生 alert。 | 用弹窗反馈模型调用状态。 |
| Notyf | 简洁通知提示库。 | 显示成功/错误通知。 | 提示模型请求结果。 |
| iziToast | 可定制的 toast 提示。 | 多样化通知风格。 | 展示模型运行的阶段反馈。 |
| Flatpickr | 轻量日期选择器。 | 替代原生日期输入。 | 统一收集模型参数中的日期。 |
| Pickr | 颜色选择器。 | 让用户选择颜色主题。 | 控制模型生成的视觉风格色彩。 |
| noUiSlider | 范围滑块组件。 | 用于输入范围数据。 | 设置模型参数阈值与温度。 |
| localForage | 异步本地存储封装。 | 优雅地存取 IndexDB/LocalStorage。 | 缓存模型历史输出或草稿。 |
| idb-keyval | 极简 IndexedDB Key-Value 存储。 | 轻量级持久化数据。 | 缓存模型使用偏好与参数。 |
| RxJS | 响应式编程库。 | 处理异步流、事件流。 | 管理模型流式输出与事件。 |
| Redux | 状态管理库。 | 集中管理应用状态。 | 维护模型输出、用户设置等状态。 |
| Immer | 不可变数据更新工具。 | 更易维护的状态更新逻辑。 | 安全地更新模型会话数据。 |
| nanoid | 小巧的随机 ID 生成库。 | 生成短且唯一的 ID。 | 给模型生成的卡片或会话打标。 |
| UUID | UUID 生成库。 | 生成全局唯一标识。 | 给模型任务或批次生成标识。 |
| validator.js | 字符串校验工具库。 | 校验邮箱、URL 等。 | 验证模型输出是否符合格式。 |
| DOMPurify | HTML 清理库。 | 防止 XSS，清洗 HTML。 | 过滤模型生成的 HTML 内容。 |
| Marked | Markdown 解析器。 | 把 Markdown 转为 HTML。 | 渲染模型输出的 Markdown。 |
| Showdown | Markdown 转换器。 | 支持 Markdown 到 HTML。 | 渲染模型生成的 Markdown 内容。 |
| Turndown | HTML 转 Markdown 工具。 | 从网页内容提取 Markdown。 | 将模型生成的 HTML 回转为 Markdown。 |
| Prism.js | 代码高亮库。 | 为代码块添加语法高亮。 | 显示模型生成的代码片段。 |
| Highlight.js | 自动检测语言的高亮库。 | 自动高亮代码块。 | 让模型输出代码更清晰。 |
| Fuse.js | 模糊搜索库。 | 在数据集中快速检索。 | 在模型生成的资料库中做搜索。 |
| Lunr.js | 客户端全文检索库。 | 构建本地搜索索引。 | 索引模型生成的知识库。 |
| FlexSearch | 高速全文检索库。 | 性能更佳的搜索体验。 | 用于模型知识库检索。 |
| ApexCharts | 现代图表库。 | 漂亮的交互式图表。 | 可视化模型执行指标。 |
| Cytoscape.js | 图网络可视化库。 | 绘制知识图谱。 | 展示模型推理出的关系网络。 |
| Mermaid | 文本生成图表。 | 流程图、时序图快速生成。 | 模型生成 Mermaid 文本后直接渲染。 |
| vis-network | 网络关系图组件。 | 快速展示节点关系。 | 展示模型生成的关系数据。 |
| Three.js | 3D 渲染库。 | 创建 3D 场景与模型。 | 展示模型生成的 3D 视觉内容。 |
| p5.js | 创意编程库。 | 快速绘制互动图形。 | 用来生成模型可视化和互动展示。 |
| CountUp.js | 数字滚动动画。 | 展示数值增长效果。 | 展示模型生成统计指标的动态效果。 |
| Micromodal | 无依赖的模态框库。 | 快速弹出模态窗口。 | 展示模型输出的详情信息。 |
| Shepherd.js | 产品引导/新手教程库。 | 创建多步骤引导流程。 | 引导用户理解模型工具的使用流程。 |
| Moment.js | 经典时间处理库。 | 格式化、解析时间。 | 兼容旧项目的时间处理需求。 |
| date-fns | 现代日期工具集。 | 支持函数式日期处理。 | 统一格式化模型时间输出。 |
| qs | 查询字符串解析与序列化。 | 处理 URL 参数。 | 解析模型服务回调参数。 |
