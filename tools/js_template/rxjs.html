⏱️ 实时数据流 (interval)

📝 代码
const stream$ = interval(500).pipe(
  take(20),
  map(n => n * 2)
);

stream$.subscribe(value => {
  console.log(value);
});

📝 代码
fromEvent(input, 'input').pipe(
  map(e => e.target.value),
  debounceTime(300),
  distinctUntilChanged(),
  filter(text => text.length > 2)
).subscribe(value => {
  // 执行搜索
});
