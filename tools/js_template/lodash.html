_.cloneDeep() 对象深拷贝

解决 JS 引用传递问题，确保完全独立的副本。

const objects = [{ 'a': 1 }, { 'b': 2 }];

const shallow = _.clone(objects);
shallow[0] === objects[0]; // true
const objects = [{ 'a': 1 }, { 'b': 2 }];

const deep = _.cloneDeep(objects);
deep[0] === objects[0]; // false
