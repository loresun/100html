# 求职者需求分析

## 目标人群
- 应届生/转行者：缺乏项目经验与求职流程意识，需要“从 0 到 1”的指导。
- 有经验求职者：希望更高效地匹配岗位、提升简历通过率与面试表现。
- 已拿 Offer 的候选人：需要理性对比与谈判支持，降低决策焦虑。

## 典型痛点
1. **信息不对称**：JD 看不懂、职责与要求拆解困难，导致投递方向不清晰。
2. **简历竞争力不足**：缺乏关键词、成果表达不清晰，ATS 过滤率高。
3. **面试准备无体系**：不知如何准备高频问题、STAR 案例与自我介绍结构。
4. **投递与跟进混乱**：记录零散、反馈慢、复盘不足。
5. **Offer 决策压力大**：多 Offer 对比缺少框架，谈薪话术拿捏不准。

## 解决目标
- 提供 **清晰的岗位匹配与差距分析**，帮助求职者聚焦最合适的岗位与提升路径。
- 输出 **高通过率的简历优化建议**，包含关键词、亮点重写与结构优化。
- 构建 **面试准备工具链**，覆盖自我介绍、STAR 行为面试、反问清单等。
- 形成 **投递与复盘闭环**，让求职节奏可控、可迭代。
- 支持 **Offer 对比与谈判**，降低决策成本、提升收益。

## 工具设计原则
- 以“任务导向”为主，输入少量关键字段即可生成可执行结果。
- 输出以清单、表格、分步骤建议为主，强调可落地性。
- 默认提供模板化结构，方便复制到 Notion/Excel/简历工具。
- 使用 Alpine.js 规避 Vue 与图标冲突，确保 Lucide 图标稳定渲染。
