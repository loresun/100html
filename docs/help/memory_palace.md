# 记忆宫殿生成器 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景：**
当你需要记忆一组信息（如知识点、演讲要点、购物清单）时，传统方法可能枯燥且容易遗忘。这个工具将抽象信息转化为具体的“房间意象”，让你在脑海中构建一座宫殿，每个房间存放一个记忆点。例如，准备产品发布会时，你可以输入“创新点、用户反馈、价格策略”，它会生成对应的房间描述，帮助你通过空间联想来记忆。

**适合情况：**
- 记忆结构化的列表信息（用逗号分隔的条目）
- 需要快速创建可视化记忆线索
- 学习或演讲前的要点整理

**不适合情况：**
- 记忆长篇连续文本（如文章段落）
- 需要精确复现原文的场景
- 对生成内容有严格准确性要求的专业领域

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本输入框，默认显示“产品卖点,用户痛点,解决方案,行动号召”
- 你可以直接修改这些内容，用逗号分隔不同的记忆点

**操作步骤：**
1. **准备内容**：在文本框中输入要记忆的信息，每条用逗号隔开（例如：“牛顿第一定律,相对论,量子力学”）
2. **点击生成**：按下“生成记忆宫殿”蓝色按钮
3. **查看结果**：页面下方会显示生成的房间列表，每个房间对应一个记忆点的意象描述
4. **配置API**：首次使用需点击右上角齿轮图标，输入你的DeepSeek API Key并保存

**输出结果示例：**
```
房间 1
一个摆满苹果的实验室，牛顿的雕像静静站立，苹果从树上缓缓落下

房间 2
扭曲的时空走廊，时钟以不同速度滴答作响，爱因斯坦的黑板写满公式

房间 3
微观粒子舞动的暗室，薛定谔的猫在透明盒子中若隐若现
```

**容易忽略的细节：**
- 输入时**建议用逗号分隔**，但AI也能理解其他分隔方式
- 生成前**必须配置API Key**，否则会报错
- 房间生成是**随机的**，同一内容多次生成可能得到不同意象
- 可以点击右上角“返回首页”跳转到其他页面（如果有的话）

## 【三】核心结构拆解（学习重点）

**页面由三个关键模块组成：**

1. **输入与控制模块**（顶部卡片区域）
   - **职责**：接收用户输入，触发生成过程，显示错误信息
   - **包含**：文本输入框、生成按钮、错误提示
   - **逻辑**：用户输入 → 点击按钮 → 验证输入 → 调用AI

2. **输出展示模块**（中部网格区域）
   - **职责**：以卡片形式展示生成的房间意象
   - **包含**：房间编号、意象描述
   - **逻辑**：接收AI返回的文本 → 按行分割 → 清理格式 → 渲染卡片

3. **配置管理模块**（设置弹窗）
   - **职责**：管理API配置，持久化保存
   - **包含**：API Key输入框、模型选择、保存按钮
   - **逻辑**：打开设置 → 修改配置 → 保存到本地存储 → 关闭弹窗

**输入 → 处理 → 输出链路：**
```
用户输入文本 → 拼接Prompt → 调用DeepSeek API → 解析AI回复 → 分割为房间列表 → 渲染卡片动画
```

**最值得学习的设计：**
- **渐进式UI反馈**：生成时按钮禁用、加载状态、错误提示、卡片淡入动画
- **配置持久化**：使用localStorage保存API设置，避免每次刷新重新输入
- **模块化弹窗**：设置面板作为独立覆盖层，不干扰主流程

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt的角色：**
在这个页面中，Prompt是连接用户输入和AI生成的“翻译器”。它将用户提供的原始文本（如逗号分隔的列表）转化为AI能理解的创作任务。

**解决的问题类型：**
解决的是“**生成问题**”——AI不是理解用户输入的含义，而是根据指令创作出对应的可视化描述。

**Prompt中的关键变量：**
1. **系统指令**：`“你是记忆训练教练，为每条信息设计一个房间意象。”`
   - 设定AI的角色和专业领域
2. **用户内容**：`“内容：${用户输入}”`
   - 提供需要转换的原始信息
3. **格式要求**：`“请为每条内容生成一个可视化房间意象，逐条输出。”`
   - 指定输出结构和形式

**如果只改Prompt，不改代码：**
- 改系统指令为`“你是科幻作家”` → 房间意象会变得更具科幻色彩
- 改格式要求为`“用一句话描述”` → 输出会更简洁
- 增加`“每个房间必须包含一种颜色”` → 所有意象都会包含颜色元素
- 删除`“逐条输出”` → AI可能返回一段连贯的文字，破坏卡片分割逻辑

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构，替换场景**（最安全）
- 保留所有代码结构
- 修改标题和描述（如改为“诗歌意象生成器”）
- 修改输入框提示（如“输入诗句关键词，用逗号分隔”）
- 修改系统Prompt中的角色（如“你是古代诗人”）

**第二步：调整输入字段**
- 增加一个下拉菜单选择“意象风格”（如：唯美、豪放、婉约）
- 将这个选择加入到Prompt中：`“请以${风格}风格为每个关键词生成意象”`
- 只需修改Vue的data部分和Prompt拼接逻辑

**第三步：改变输出形式**
- 将房间卡片改为“诗句卡片”
- 增加一个“复制全部”按钮
- 修改CSS样式，更换颜色主题
- 这些改动集中在HTML模板和CSS部分

**从哪里下手最安全？**
从**修改文本内容**开始：标题、描述、输入提示、系统Prompt。这些改动不会破坏程序逻辑，却能立即改变工具的气质和用途。

## 【六】3–5个可直接尝试的改造方向

1. **增加记忆强度控制**
   - 在输入框下方添加滑块：“意象夸张程度”
   - 将滑块值映射到API的`temperature`参数（0.3-1.0）
   - 低值产生更常规的意象，高值产生更奇特、难忘的意象

2. **支持多模型切换**
   - 在设置中增加OpenAI、Claude等API选项
   - 根据选择调用不同的API端点
   - 比较不同模型生成的意象特点

3. **添加房间可视化**
   - 为每个房间生成对应的DALL-E图像
   - 在卡片中显示缩略图，点击查看大图
   - 需要调用图像生成API，增加“生成图片”按钮

4. **拆分为多步骤向导**
   - 第一步：输入记忆内容
   - 第二步：选择宫殿风格（古典、现代、科幻）
   - 第三步：预览并调整生成的房间
   - 使用Vue组件拆分为多个`<div v-if="step===1">`

5. **添加记忆测试功能**
   - 生成宫殿后，隐藏房间描述，只显示编号
   - 让用户回忆每个房间对应的原始内容
   - 提供“显示答案”和“重新测试”按钮
   - 增强工具的实际记忆训练价值

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明：**

1. **不适合精确记忆**
   - AI生成的意象是创造性的，可能与原始信息有偏差
   - 如果你需要一字不差地记忆法律条文或医学剂量，请使用闪卡工具（如Anki）

2. **不适合长篇内容**
   - 输入框设计为简短列表，长篇文本会被AI截断或处理不当
   - 对于长文章记忆，考虑使用“思维导图生成器”或“摘要工具”

3. **不适合实时协作**
   - 没有用户账户系统，所有数据保存在本地
   - 如果需要团队共享记忆宫殿，应改用Notion或Miro等协作工具

4. **不适合专业记忆训练**
   - 缺少记忆科学中的“间隔重复”算法
   - 专业记忆运动员应使用定制软件（如Memrise专业版）

5. **API依赖风险**
   - 完全依赖DeepSeek API的可用性
   - 如果API服务中断或变更，工具将无法使用
   - 重要用途应考虑实现本地模型后备方案

**如果你需要：**
- **记忆外语单词** → 使用Quizlet或Duolingo
- **记忆历史事件时间线** → 使用Timeline类工具
- **记忆复杂概念关系** → 使用思维导图软件
- **团队知识共享** → 使用Wiki或共享文档
