# 表格数据智能分析器 - 帮助与学习指南

## 【一】这个网页解决了什么问题？

想象一下，你从 Excel 或业务系统里导出了一份销售、用户或运营数据。面对密密麻麻的数字，你想快速了解：
*   “这个月的销售额趋势是涨还是跌？”
*   “哪些数据点看起来不太正常？”
*   “和上个月比，关键指标变化大吗？”
*   “从这些数据里，我能得到什么具体的行动建议？”

这个网页就是你的“AI 数据分析助手”。它让你无需学习复杂的统计软件或编写代码，只需粘贴数据，就能获得一份结构清晰、包含洞察和建议的分析报告。

**适合的场景：**
*   **快速数据探索**：拿到一份新数据，想快速了解整体情况。
*   **日常业务复盘**：每周/每月的销售、运营数据回顾，需要提炼要点。
*   **生成报告草稿**：为正式报告或会议准备初步的数据分析和洞察。
*   **非技术人员的分析需求**：市场、运营、销售等岗位人员需要数据支持决策时。

**不适合的场景：**
*   **需要精确统计建模**（如回归分析、假设检验）。
*   **处理超大规模数据集**（如百万行以上），这更适合专业的数据分析工具。
*   **需要实时、高频的数据分析**。
*   **数据清洗和预处理**（如合并多表、处理复杂缺失值）。它更适合分析已经相对规整的表格数据。

## 【二】使用方式（给第一次接触的人）

1.  **准备输入**：页面的核心输入是一个**文本框**。你可以直接从 Excel 或类似软件中**复制并粘贴**整张表格，也可以点击“上传 CSV 文件”按钮上传文件。
2.  **配置分析**（可选）：
    *   **数据类型**：告诉 AI 你的数据是关于“销售”、“用户”还是其他类型，帮助它更好地理解上下文。
    *   **分析维度**：勾选你关心的分析方向，比如“趋势分析”、“异常检测”等。默认选项已覆盖常见需求。
3.  **开始分析**：点击绿色的 **“开始智能分析”** 按钮。
4.  **获取结果**：等待片刻（时间取决于数据量和网络），右侧会生成一份 **Markdown 格式的报告**。报告通常包括数据概览、关键指标、趋势分析、异常点、可视化建议和商业洞察。
5.  **使用结果**：你可以**复制**报告文本，或**导出**为 `.md` 文件用于后续编辑。

**容易忽略的细节：**
*   **首次使用需配置**：第一次点击“分析”按钮时，会弹出设置窗口，要求你填入 **DeepSeek API Key**。你需要先去 DeepSeek 平台注册并获取 Key。
*   **数据格式**：最好确保第一行是表头（列名），这样 AI 更容易理解。从 Excel 直接复制粘贴的效果通常很好。
*   **“深度分析过程”**：这是一个可折叠区域，点击后可以看到 AI 在生成最终答案前的“思考过程”，对于理解 AI 的逻辑很有帮助。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

1.  **控制面板模块（左侧）**
    *   **职责**：接收用户的所有输入和配置。
    *   **子模块**：
        *   **数据输入区**：接收核心数据（粘贴或上传）。
        *   **配置区**：让用户选择数据类型和分析维度，细化任务指令。
        *   **执行区**：“开始分析”按钮，触发整个流程。
    *   **逻辑**：用户在此模块完成所有设置 → 点击按钮 → 数据与配置被组合，准备发送给 AI。

2.  **结果展示模块（右侧）**
    *   **职责**：直观、结构化地呈现 AI 的分析成果。
    *   **子模块**：
        *   **空状态**：引导用户开始操作。
        *   **分析过程**：可选查看的 AI 推理链，增加透明度和可信度。
        *   **分析报告**：核心输出区，将 AI 返回的 Markdown 文本渲染成易读的格式。
        *   **操作区**：提供复制、导出等实用功能。
    *   **逻辑**：接收来自 AI 的流式响应 → 实时更新显示 → 提供结果再利用的途径。

3.  **AI 引擎模块（不可见，在代码中）**
    *   **职责**：作为“大脑”，处理数据并生成洞察。
    *   **逻辑**：将**控制面板**收集的信息，精心构造为 `系统提示词(System Prompt)` 和 `用户提示词(User Prompt)` → 调用 DeepSeek API → 将返回的文本流推送给**结果展示模块**。

**最值得学习的设计：**
**“配置即 Prompt”** 的设计思想。用户在前端界面上的每一个选择（如勾选“异常检测”），都不是直接操作复杂的算法，而是在动态地、友好地**组装一个给 AI 的详细指令（Prompt）**。这使得复杂的数据分析任务变得极其简单和可定制。整个页面的核心，就是一套优秀的 **“用户友好指令生成器”**。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt 的角色**：它是连接“用户原始需求”和“AI 具体能力”的**翻译官**和**任务说明书**。在这个网页中，Prompt 将用户粘贴的杂乱数据和对分析维度的模糊勾选，转化成了一个结构化、专业性极强的分析任务。
*   **解决什么问题**：它同时解决了 **“理解问题”** 和 **“生成问题”**。
    *   **理解**：通过 `系统提示词`，告诉 AI “你是一位专业的数据分析师...”，并规定了详细的分析维度和输出格式。
    *   **生成**：通过 `用户提示词`，提供具体数据，要求 AI 执行上述理解后的任务，生成最终报告。
*   **关键变量**：
    1.  **`form.dataType`**（数据类型）：在系统提示词中映射为具体的领域描述（如“销售数据”），让 AI 调用相关知识。
    2.  **`form.analyzeTrend` 等复选框**：被动态组装成 `analysisRequirements` 列表，插入系统提示词，明确告诉 AI 要做什么。
    3.  **`form.tableData`**：作为用户提示词的核心内容，是 AI 分析的具体对象。
*   **只改 Prompt 的后果**：如果你只修改代码中的 `systemPrompt` 和 `userPrompt` 字符串模板，而不改动任何界面代码，那么：
    *   网页的**外观和操作方式完全不变**。
    *   但 AI 生成的**报告风格、分析深度、侧重点会彻底改变**。例如，你可以把 Prompt 改成让 AI 生成一段数据背后的故事，或者一份给董事会的极简摘要。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个“替换-调整-创新”的路径，安全地创建你自己的 AI 工具：

**第一步：保持骨架，替换场景（最安全）**
*   **目标**：做一个功能完整但主题不同的新工具。
*   **操作**：
    1.  复制整个 HTML 文件。
    2.  修改标题，如改为“**周报智能生成器**”。
    3.  将左侧“数据输入”的提示文字改为“粘贴你本周的工作清单或关键词...”。
    4.  将“数据类型”选项改为“周报风格”，如“简洁型”、“详细型”、“向上汇报型”。
    5.  将“分析维度”改为“包含要素”，如“重点工作”、“成果量化”、“后续计划”、“心得体会”。
*   **效果**：你得到了一个结构一模一样，但用于生成周报的新工具。此时只需微调 Prompt。

**第二步：调整输入与 Prompt 核心**
*   **目标**：让工具更贴合你的新场景。
*   **操作**：
    1.  在 `analyzeData` 函数中，重写 `systemPrompt`。告诉 AI 新角色，如“你是一位高效的职场助手，擅长将零散的工作内容整理成结构清晰的周报。”
    2.  设计新的输出格式模板，用 Markdown 定义周报的标题、章节。
    3.  根据第一步新增的选项（如“周报风格”），在 Prompt 中动态引用它们。
*   **效果**：工具的核心逻辑（输入-配置-调用AI-输出）未变，但产出的内容完全定制化了。

**第三步：改变输出或交互形式**
*   **目标**：在功能稳定的基础上优化体验。
*   **操作**：
    1.  **输出形式**：除了 Markdown，可以让 AI 直接生成 HTML 片段，或适配 Notion 的格式。
    2.  **交互形式**：增加一个“历史记录”面板，将每次的分析结果保存下来。
    3.  **输入形式**：除了文本框，可以增加多个短文本输入框，分别填写“本周完成”、“遇到问题”、“下周计划”，让输入更结构化。
*   **效果**：你的工具开始有了独特的体验和优势。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“分析视角”输入框**：在配置区增加一个文本输入框，让用户输入“请重点关注利润率”或“从市场扩张的角度分析”等自定义指令。将这个指令作为变量插入到 `userPrompt` 中，实现更灵活的分析。
2.  **切换 AI 模型/供应商**：代码中现在固定使用 DeepSeek API。你可以：
    *   在设置弹窗中增加一个下拉菜单，让用户选择 `OpenAI (GPT-4o)`、`Claude` 或 `DeepSeek`。
    *   根据选择，动态修改代码中 `fetch` 请求的 URL、Headers 和 Body 结构。
    *   **价值**：让用户根据对结果质量、速度、成本的不同需求进行选择。
3.  **分步引导与结果细化**：将单次分析拆成两个页面或两个步骤：
    *   **第一步：数据概览**。AI 快速解读数据，生成字段说明和初步观察。
    *   **第二步：深度分析**。基于第一步的结果，让用户选择 1-2 个最感兴趣的字段进行深入挖掘（如“请深入分析‘销售额’和‘订单数’的关系”）。
    *   **价值**：交互更人性化，分析更聚焦，尤其适合列数很多的宽表。
4.  **集成简单图表**：利用前端图表库（如 Chart.js 或 Apache ECharts）。
    *   在 AI 的“可视化建议”部分，不仅输出文字，还让 AI 输出符合图表库要求的**数据格式**或**配置代码**。
    *   在结果展示区，解析 AI 返回的这部分代码，动态渲染出图表预览。
    *   **价值**：报告从纯文本升级为图文并茂，实用性大增。
5.  **本地缓存与示例数据**：
    *   **缓存**：使用 `localStorage` 不仅保存 API Key，也保存用户最近几次输入的数据（经匿名化处理），方便快速重试或对比。
    *   **示例**：在数据输入框旁边增加一个“加载示例数据”按钮，点击后自动填入几行预设的销售或用户数据。这是帮助新用户理解工具用途的绝佳方式。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精确的、可重复的统计计算**：AI 的分析是基于模式识别和语言生成，虽然计算能力很强，但其生成的百分比、平均值等**不应作为财务、审计等严肃场景下的精确依据**。它更适合提供“洞察”、“方向”和“草稿”。
*   **不适合替代专业 BI 工具**：如果你需要连接数据库、进行实时数据刷新、制作复杂的交互式仪表盘、或进行跨多个数据集的关联分析，你应该使用 **Tableau, Power BI, FineBI 等专业商业智能工具**。
*   **不适合处理高度敏感数据**：数据会被发送到第三方 AI 服务商（如 DeepSeek）的服务器进行处理。**切勿上传包含个人隐私信息（PII）、公司核心机密或任何敏感数据**。对于敏感数据，应考虑部署本地开源的 AI 模型。
*   **不适合完全自动化的决策**：它生成的“商业建议”是基于数据模式的推理，具有启发价值，但**不能替代人类的商业判断和决策**。请始终将其视为一位提供参考意见的“聪明助手”。
