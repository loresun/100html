# 选题评估雷达 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你有一个内容创作或产品开发的初步想法时，比如想写一本书、做一个课程、开发一个应用，但不确定这个想法是否值得投入时间和资源。这个工具能帮你快速梳理思路，从市场、竞争、用户等多个角度审视你的选题，避免“拍脑袋”决策。

**适合情况**：
- 内容创作者（作家、博主、课程设计师）在确定选题方向时
- 产品经理或创业者评估新点子时
- 团队头脑风暴后需要结构化评估时
- 需要向他人（如编辑、投资人）展示选题价值时

**不适合情况**：
- 需要深度市场调研数据（如市场规模、增长率等硬数据）
- 已经进入执行阶段，需要详细的项目管理
- 需要多人协作的复杂评估流程
- 涉及法律、财务等专业领域的风险评估

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面左侧有5个输入框：
1. **选题名称/方向** - 你的核心想法（如“30岁女性财务自救”）
2. **目标读者画像** - 你想服务的人群（如“一二线城市职场女性”）
3. **市场阶段** - 当前市场状况（如“热点上升期”或“红海”）
4. **主要竞品书名** - 已有的类似作品
5. **差异化点** - 你的独特之处

**用户通常会做哪几步操作？**
1. 点击右上角齿轮图标，输入你的DeepSeek API密钥（首次使用需要）
2. 在左侧填写你的选题相关信息
3. 点击“生成评估报告”按钮
4. 查看右侧生成的AI提示词和评估框架

**输出结果长什么样？**
- **AI提示词区域**：显示将发送给AI的完整指令，包含你填写的所有信息
- **评估维度列表**：显示4个核心评估方向
- **交付物建议列表**：显示最终报告应包含的内容

**容易忽略的使用细节**
1. **API配置是必须的**：虽然页面能生成提示词，但要获得真正的AI评估报告，需要先配置API密钥
2. **输入可以留空**：如果某个信息不确定，可以留空或简单描述，系统会用默认文本替代
3. **提示词可复制使用**：生成的提示词可以直接复制到其他AI工具中使用
4. **配置是全局的**：设置的API密钥会保存在浏览器中，其他工具也能读取

## 【三】核心结构拆解（学习重点）

**页面由哪几个关键模块组成？**

1. **配置模块**（右上角）
   - 职责：管理API密钥，显示配置状态
   - 设计亮点：使用模态框（弹窗）避免页面跳转，体验流畅

2. **输入模块**（左侧卡片）
   - 职责：收集用户选题信息
   - 包含：5个输入字段 + 生成按钮
   - 设计亮点：清晰的标签和占位符，引导用户填写

3. **输出预览模块**（右侧卡片）
   - 职责：展示AI提示词和评估框架
   - 包含：提示词展示区、评估维度、交付物建议
   - 设计亮点：代码块样式展示提示词，视觉上区分“给AI的指令”和“给用户的说明”

**输入 → 处理 → 输出 的逻辑链路**
```
用户填写信息 → 点击生成按钮 → 拼接成完整提示词 → 显示在右侧
                                     ↓
                             同时生成评估维度和交付物建议
```

**最值得学习的设计**
**“所见即所得”的提示词生成器**：这个页面最巧妙的地方在于，它把复杂的AI交互拆解成了两步：
1. 先让用户看到“将要发送给AI的指令是什么”
2. 用户确认无误后，再实际调用AI

这样做的好处是：
- 降低用户对“黑箱”的恐惧
- 让用户学习到如何构造有效的AI指令
- 即使没有API密钥，也能了解工具的工作原理

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接用户输入和AI能力的“翻译器”。它把用户零散的想法，转换成AI能理解的结构化任务。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。这个Prompt告诉AI：“基于这些信息，生成一份评估报告”，而不是“理解这个选题是什么”。

**Prompt中的关键变量**
```javascript
`你是一名图书选题评估专家。请基于以下信息输出选题评估报告。\n\n
选题：${topic}\n
目标读者：${audience}\n
市场阶段：${market}\n
竞品：${competitors}\n
差异化：${diff}\n\n

输出要求：
1) 市场需求与趋势判断（3 点）
2) 竞品对比与空白机会（表格）
3) 受众痛点匹配度评分（1-10 分）
4) 风险点与规避策略（3 条）
5) 是否立项的结论 + 说明`
```

**关键变量**：topic, audience, market, competitors, diff（对应5个输入框）

**如果只改Prompt，不改代码，会发生什么变化？**
- 改变**角色设定**：如从“图书选题评估专家”改为“短视频内容策划师”
- 改变**输出格式**：如从“报告”改为“思维导图大纲”
- 改变**评估维度**：如增加“变现潜力分析”或减少“风险分析”
- 改变**语气风格**：如从正式报告改为轻松的建议清单

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径**

**第一步：保持结构不变，替换使用场景**
- 把“选题评估”换成你的场景，如“健身计划评估”、“旅行路线规划”
- 只修改文字：标题、描述、输入框标签、按钮文字
- **不要动任何代码结构**，先让页面能跑起来

**第二步：调整输入字段**
- 增加或减少输入框数量
- 修改输入类型：如把文本框改为下拉选择、单选按钮
- 示例：健身计划评估 → 增加“当前体能水平”、“可用时间”等字段

**第三步：改写Prompt模板**
- 在`generateBtn`的点击事件中，找到拼接prompt的代码
- 按照你的新场景重写prompt文本
- 确保prompt中的变量名与输入框ID对应

**第四步：改变输出展示**
- 修改右侧的“评估维度”和“交付物建议”列表
- 可以增加新的展示区域，如“预计效果预览”、“资源需求清单”

**从哪里下手最安全？**
从**文字替换**开始最安全。先改所有看得见的文字内容，确保理解每个部分的作用后，再修改代码逻辑。

## 【六】3–5个可直接尝试的改造方向

**1. 增加“评估模板”选择功能**
- 在输入区域上方添加下拉菜单
- 选项如：“图书选题”、“视频课程”、“社交媒体内容”
- 选择不同模板时，自动切换对应的Prompt和评估维度
- **实现提示**：给每个模板准备不同的prompt字符串数组

**2. 添加“历史记录”功能**
- 每次生成的评估保存到本地
- 在页面底部添加历史记录列表
- 点击历史记录可重新加载当时的输入
- **实现提示**：使用`localStorage`存储JSON格式的历史数据

**3. 实现真正的AI调用（当前页面只生成提示词）**
- 在生成按钮旁添加“调用AI”按钮
- 使用配置的API密钥调用DeepSeek API
- 在页面下方新增“AI评估结果”展示区域
- **实现提示**：先学习简单的fetch API调用，从返回纯文本开始

**4. 优化为“分步引导”式输入**
- 将5个输入框拆成3个步骤
- 每完成一步，显示进度条和下一步按钮
- 在每一步给出填写建议（如“竞品分析小技巧”）
- **实现提示**：用CSS隐藏/显示不同的步骤容器

**5. 增加“导出功能”**
- 添加“导出为Markdown”或“复制到剪贴板”按钮
- 将生成的提示词和评估框架格式化为可分享的文档
- 甚至可以生成简单的PDF预览
- **实现提示**：使用`navigator.clipboard.writeText()`实现复制功能

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明**

1. **不是市场调研工具**
   - 它不会帮你搜索真实的市场数据
   - 所有分析基于你提供的信息和AI的推理
   - **如果需要真实数据**：应使用专业调研工具或人工调研

2. **不是决策系统**
   - 它提供的是“评估框架”和“思考角度”
   - 最终决策仍需人工判断
   - **如果需要自动化决策**：需要更复杂的规则引擎和数据分析

3. **不是协作工具**
   - 所有输入和输出都在单个浏览器中
   - 无法多人同时编辑或评论
   - **如果需要团队协作**：应使用Notion、飞书等协作平台

4. **不是专业咨询替代品**
   - 对于法律、金融、医疗等专业领域
   - AI的评估可能不准确或不全面
   - **如果需要专业建议**：请咨询相关领域的专家

**如果用户想做X，应该换什么工具**
- 如果想做**详细的市场规模分析** → 使用行业报告数据库、Google Trends
- 如果想做**竞品功能对比** → 使用竞品分析模板、SWOT分析工具
- 如果想做**用户调研** → 使用问卷工具、用户访谈模板
- 如果想做**项目规划** → 使用项目管理软件（如Trello、Notion）

---

**记住**：这个工具的价值在于“快速启动思考”，而不是“替代思考”。把它当作你的数字头脑风暴伙伴，而不是决策权威。
