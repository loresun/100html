# Mood Curve 3D · 帮助文档

## 【一】这个网页解决了什么问题？

这个网页是一个**情绪可视化工具**，它解决了“如何将抽象的心情感受转化为直观、美观的3D视觉体验”的问题。

**使用场景**：
- 当你经历了一段复杂的心情波动（如“考试后的放松与焦虑交织”），想用一种艺术化的方式记录和回顾它。
- 当你难以用语言精确描述自己的情绪状态，希望通过AI的“翻译”和3D图形的“演绎”来探索和表达。
- 当你需要为一个创意项目（如音乐、写作、设计）寻找视觉灵感，想从一种情绪基调出发，生成与之匹配的动态图形。

**适合情况**：
- 个人情绪记录与艺术化表达。
- 作为演示工具，向他人展示某种情绪氛围的视觉概念。
- 学习如何将AI文本生成与3D网页图形（Three.js）结合。

**不适合情况**：
- 需要精确、量化的情绪分析或心理学评估。
- 需要实时、高频次的心情追踪（如每天多次记录）。
- 在没有网络或无法调用AI API的环境下使用。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：点击页面右上角的 **“DeepSeek 设置”** 按钮。在弹出的窗口中，输入你的DeepSeek API Key（需要自行申请），选择模型，然后点击“保存”。（如果暂时没有API Key，也可以直接使用，但只能看到默认的演示曲线）。

2.  **核心操作**：
    - **输入**：在页面左侧的输入框中，用一句话描述你的心情。例如：“像晚风一样轻松，却带一点点不舍”。
    - **生成**：点击旁边的 **“生成曲线”** 按钮。
    - **等待**：页面左上角的状态提示会显示“DeepSeek 正在绘制曲线…”。稍等片刻（通常几秒到十几秒），AI会分析你的描述并生成一组参数。

3.  **查看结果**：
    - **3D视图**：页面中央会出现一条根据你心情生成的、带有流动光粒子的3D霓虹管道。你可以用鼠标拖拽旋转视角，用滚轮缩放，全方位观察这条“心情曲线”。
    - **文字卡片**：左侧面板下方会更新一张卡片，显示AI为这次心情生成的“标题”和一段简短的“故事性描述”。

4.  **容易忽略的细节**：
    - **视角控制**：生成曲线后，一定要试试用鼠标左键拖拽旋转，用鼠标滚轮缩放，这是体验3D效果的核心。
    - **状态提示**：左上角的灰色小字（状态栏）会告诉你当前是否已配置API Key、生成进度或错误信息，是重要的反馈渠道。
    - **演示模式**：如果没有配置API Key，点击生成后，页面会使用一个固定的默认曲线，并将你的输入文字作为标题，以此进行演示。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

1.  **用户交互与配置模块（左侧面板 & 设置弹窗）**
    - **职责**：负责所有用户输入和配置。包括接收心情文本、保存和管理API Key、显示状态和AI生成的故事。
    - **输入**：用户的心情描述文字、API Key。
    - **输出**：触发AI调用指令、更新界面文字提示。

2.  **AI 逻辑与数据处理模块（JavaScript 中的 `callDeepSeek` 及相关函数）**
    - **职责**：作为“翻译官”和“参数生成器”。它将用户的口语化心情描述，通过精心设计的Prompt，转化为AI能理解的指令，并请求AI返回一组结构化的JSON参数。
    - **处理**：构建Prompt -> 调用DeepSeek API -> 解析返回的JSON数据。
    - **输出**：一组包含曲线类型、颜色、振幅、粒子数量等参数的JSON对象。

3.  **3D 渲染与可视化模块（Three.js 相关的所有代码）**
    - **职责**：作为“视觉化执行者”。它接收AI生成的参数（或使用默认参数），利用Three.js库在网页中创建3D场景、摄像机、灯光，并根据参数动态生成曲线几何体、材质和流动的粒子动画。
    - **输入**：AI生成的参数对象。
    - **输出**：在Canvas画布上实时渲染出的3D动态图形。

**逻辑链路**：
`用户输入心情文本` -> `AI模块构建Prompt并调用API` -> `AI返回JSON参数` -> `3D模块接收参数，重建曲线和粒子` -> `渲染循环驱动动画，用户交互控制视角`

**最值得学习的设计**：
**“参数化生成”的桥梁设计**。整个应用没有让AI直接生成图像或代码，而是让它生成一组**控制3D图形属性的参数**（如`curveType`, `amplitude`, `palette`）。这既降低了AI任务的复杂度（生成结构化数据比生成代码或图片更稳定），又将创意控制权部分交给了AI，同时保证了前端渲染的性能和可靠性。这是一种非常优雅且实用的“AI + 传统图形学”结合方式。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色**：它是一个**“参数化指令翻译器”**。它的任务不是直接“理解”心情，而是将模糊的心情描述，翻译成一套可供3D引擎使用的、精确的、数值化的“视觉配方”。

2.  **解决的是“生成问题”**：它解决的是“根据X（心情描述），生成Y（视觉参数）”的**生成问题**。AI的“理解”服务于“生成”这套参数。

3.  **Prompt中的关键变量**：
    - **指令角色**：`你是一个情绪视觉设计师。` – 赋予AI特定的身份，引导其从设计角度思考。
    - **用户输入**：`“${mood}”` – 这是核心变量，是Prompt动态变化的部分。
    - **输出格式约束**：`只返回 JSON，不要任何多余文字。` – 这是保证程序能稳定处理结果的关键，强制AI输出机器可读的数据。
    - **参数范围限定**：例如 `amplitude(0.6-2.2)` – 为每个数值参数设定了合理范围，防止AI生成过于夸张导致渲染异常的数值。

4.  **如果只改Prompt，不改代码**：
    - 你可以改变AI的“创作风格”。例如，将角色改为`“你是一个赛博朋克风格的建筑设计师”`，AI生成的曲线参数可能会更偏向于硬朗、冷色调。
    - 你可以调整生成参数的维度。例如，在Prompt中增加`“complexity（复杂度）”`字段，AI可能会在返回的JSON中加入这个新参数，但**前端代码因为不认识这个参数，会忽略它**。要让新参数生效，必须同时修改前端`createCurve`函数来使用它。

## 【五】如何模仿它，做出你自己的版本？

遵循“先替换，再调整，后创新”的安全路径：

**第一步：保持结构不变，替换核心主题**
这是最安全的一步。不要动任何Three.js和AI调用代码。
- **目标**：做一个“**音乐波形可视化器**”。
- **操作**：
    1.  将页面标题、提示文字中的“心情”全部替换为“音乐感受”或“歌曲描述”。
    2.  将输入框的提示语改为：“例如：一首激昂澎湃的电子乐，中间有舒缓的钢琴间奏”。
    3.  修改Prompt中的角色和指令：`你是一个音乐可视化设计师。根据“${description}”生成3D音频波形参数...`。
    4.  至此，你已经有了一个能根据音乐描述生成3D曲线的新应用，虽然底层还是曲线，但概念已完全不同。

**第二步：调整输入字段或Prompt参数**
在第一步成功的基础上进行。
- **操作**：
    1.  在左侧面板增加一个`“强度”`下拉菜单（选项：柔和、中等、强烈），这个值会传入Prompt。
    2.  修改Prompt，加入这个变量：`...根据“${description}”和${intensity}的强度，生成3D音频波形参数...`。
    3.  观察AI生成的参数是否会因“强度”不同而产生变化。

**第三步：改变输出形式或展示方式**
开始修改最引人注目的3D部分，但从小处着手。
- **操作**：
    1.  在`createCurve`函数里，找到控制曲线粗细的代码（`0.14 + energy * 0.08`）。尝试修改这个公式，让曲线随`amplitude`（振幅）变化更明显。
    2.  找到粒子材质（`MeshStandardMaterial`），尝试将`emissiveIntensity`（自发光强度）与某个AI参数（比如`energy`）关联，让粒子的亮度动态变化。
    3.  至此，你的应用在视觉上已经有了独特的个性。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加多元输入，丰富Prompt上下文**：
    - **操作**：在输入框旁增加一个“颜色倾向”选择器（如：冷色/暖色/梦幻），或一个“情绪强度”滑块。
    - **效果**：将这些选择的值也放入Prompt中，AI生成的颜色方案（`palette`）和曲线振幅（`amplitude`）将更贴合用户的额外意图。

2.  **更换或扩展AI模型与API**：
    - **操作**：在设置弹窗中增加一个“API提供商”下拉框，支持DeepSeek、OpenAI GPT、Claude等。为不同提供商编写对应的API调用函数和Prompt微调版本。
    - **效果**：用户可以对比不同AI对同一心情的“视觉解读”，体验会非常有趣。

3.  **拆分页面，增加“画廊”功能**：
    - **操作**：创建第二个HTML页面（如`gallery.html`）。每当生成一条满意的曲线，点击“保存到画廊”按钮，将当前参数和标题保存到浏览器的`localStorage`中。在画廊页面，以缩略图列表形式展示所有保存的曲线，点击可跳回主页面并加载该参数。
    - **效果**：应用从一个单次工具，变成了一个可积累、可回顾的创作集。

4.  **优化交互，加入声音反馈**：
    - **操作**：使用Web Audio API。根据曲线的`energy`（能量）或粒子运动速度，生成简单的环境音效（如轻微的嗡鸣声）。粒子流动越快，音调越高。
    - **效果**：从纯视觉体验升级为“视听联觉”体验，沉浸感大幅提升。

5.  **参数微调面板**：
    - **操作**：在生成曲线后，在左侧面板下方展开一个高级区域，将AI生成的关键参数（如`amplitude`, `turns`）以滑块的形式展示出来，并允许用户手动微调。调整滑块时，3D曲线实时更新。
    - **效果**：将AI的“初稿”与用户的“精修”结合起来，满足用户更深层的创作控制欲。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做严肃的心理评估或治疗工具**：
    - **局限性**：它生成的曲线是基于美学和隐喻的视觉化，而非科学的心理测量。曲线“低落”不代表抑郁，颜色“暗淡”也不代表情绪消极。
    - **正确做法**：如果需要情绪评估，应使用专业的心理学量表或咨询专业人士。

2.  **不适合生成精确、可复现的特定3D模型**：
    - **局限性**：它生成的是参数化、程序化的曲线，每次对同一描述生成的结果都可能不同，且无法生成一个具体的、如汽车或人像的3D模型。
    - **正确做法**：如需生成特定3D模型，应使用专业的3D建模软件（Blender, Maya），或专门用于3D生成的AI工具（如Tripo AI, Meshy）。

3.  **不适合在性能较低的设备上作为常驻后台应用**：
    - **局限性**：3D实时渲染（尤其是大量粒子）会持续消耗GPU和CPU资源。
    - **正确做法**：生成并欣赏后，可以关闭页面。如需长时间展示，应考虑导出为视频，或在服务器端渲染成视频后播放。
