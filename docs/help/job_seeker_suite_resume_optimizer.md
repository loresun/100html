# 简历定制与 ATS 优化器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你需要针对某个具体岗位修改简历时，这个工具能帮你快速分析岗位要求，并给出具体的优化建议。它特别适合：
- 你看到心仪的招聘信息（JD），但不确定自己的简历如何匹配
- 你的简历内容很多，但不知道哪些是重点，哪些需要改写
- 你想让简历通过公司的简历筛选系统（ATS），但不知道系统会识别哪些关键词
- 你想突出自己的某项优势，但不知道如何在简历中有效表达

**不适合的情况：**
- 如果你只是想写一份通用简历，不针对特定岗位
- 如果你需要完整的简历模板设计（它不提供排版和样式）
- 如果你希望AI直接生成虚构的工作经历（它基于你提供的真实经历进行优化）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
左侧有四个输入框：
1. **目标岗位**：你想申请的职位名称（如“数据分析师”）
2. **岗位描述**：从招聘网站复制的完整职位描述
3. **现有简历内容**：你现在的简历文本（可以是完整简历，也可以是重点经历）
4. **想突出的优势**：你特别想让HR看到的技能或特质

**用户通常会做哪几步操作？**
1. 点击右上角齿轮图标，输入你的DeepSeek API Key（需要先注册获取）
2. 在左侧填写上述四个信息（岗位描述和现有简历最重要）
3. 点击“生成优化方案”按钮
4. 等待几秒到几十秒，右侧会显示优化结果
5. 可以点击“复制”或“导出”按钮保存结果

**输出结果长什么样？**
结果会以清晰的Markdown格式显示，通常包含：
- **ATS关键词清单**：招聘描述中提到的技能、工具、行业术语
- **简历要点重写**：将你的经历用更专业、更量化的方式改写
- **缺失信息与补充建议**：指出你的简历缺少哪些关键信息
- **简历结构优化提示**：建议如何调整内容的顺序和重点

**有哪些容易忽略的使用细节？**
1. **API Key需要先配置**：不配置Key直接点生成会弹窗提示
2. **模型选择**：右上角有V3（普通）和R1（推理）两种模型，R1会显示思考过程但可能更慢
3. **自定义提示词**：在设置中可以添加额外要求，比如“更偏向互联网大厂风格”
4. **导出功能**：除了复制，还可以导出为TXT或JSON格式，JSON包含思考过程

## 【三】核心结构拆解（学习重点）

这个页面由**三个核心模块**组成：

**1. 输入配置模块（左侧面板）**
- **职责**：收集用户的所有个性化信息
- **包含**：四个输入字段 + 生成/清空按钮
- **设计亮点**：字段顺序符合用户思考逻辑（先看岗位→再看要求→对照自己→突出优势）

**2. AI处理与输出模块（右侧面板）**
- **职责**：显示AI生成的结果，提供操作入口
- **包含**：结果展示区 + 复制/导出按钮 + 思考过程折叠面板
- **设计亮点**：用Markdown渲染让结果更易读，思考过程默认折叠不干扰主内容

**3. 系统配置模块（设置弹窗）**
- **职责**：管理API密钥和个性化提示词
- **包含**：API Key输入 + 自定义提示词 + 模型选择
- **设计亮点**：配置自动保存到本地存储，下次打开无需重复输入

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入 → 拼接成Prompt → 调用DeepSeek API → 流式接收结果 → 实时渲染Markdown
```

**最值得学习的设计：**
**流式处理与实时渲染**。当AI生成内容时，页面不是等全部生成完才显示，而是一边接收一边显示。这通过`stream: true` API参数和`TextDecoder`逐块解析实现，用户体验更好。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接用户输入和AI能力的“翻译器”。它把零散的用户信息（岗位、简历等）组织成AI能理解的完整任务描述。

**它解决的是“理解问题”还是“生成问题”？**
主要是**理解问题**。Prompt告诉AI：“现在你是一个简历顾问，用户给了你这些信息，请按照这个结构输出建议。”AI基于这个理解来生成具体内容。

**哪些信息是Prompt中的关键变量？**
1. **角色设定**：“资深简历顾问，擅长ATS优化”
2. **用户提供的四个字段**：目标岗位、岗位描述、现有简历、优势
3. **输出格式要求**：“使用中文，输出Markdown，按四个部分组织”
4. **自定义追加内容**：用户可以在设置中添加的特殊要求

**如果只改Prompt，不改代码，会发生什么变化？**
- 改角色设定（如“你是一名HR总监”）→ AI会以不同身份视角给出建议
- 改输出结构（如增加“薪资谈判建议”）→ AI会输出新的内容模块
- 改语言风格（如“用更活泼的语气”）→ 整个结果的表达方式会变化
- 加限制条件（如“每条建议不超过50字”）→ 输出会更简洁

## 【五】如何模仿它，做出你自己的版本？

**安全的下手路径：**

**第一步：替换使用场景，保持结构不变**
- 把“简历优化”换成其他场景，如“小红书文案优化”、“周报生成器”、“学习计划制定”
- 保持左侧输入、右侧输出的基本布局
- 只修改文字标签和提示语

**第二步：调整输入字段和Prompt**
- 根据新场景设计3-5个关键输入字段
- 重写Prompt中的角色设定和任务描述
- 调整输出结构的标题和顺序

**第三步：改变输出形式或展示方式**
- 如果新场景需要表格，修改Markdown渲染或改用表格组件
- 如果不需要思考过程，隐藏相关代码
- 调整导出格式（如导出为PDF、图片等）

**最小可行改动示例（改为“周报生成器”）：**
1. 输入字段改为：本周工作、下周计划、遇到的问题、想突出的成果
2. Prompt改为：“你是一名项目经理，请帮我将以下内容整理成专业周报...”
3. 输出结构改为：本周总结、成果展示、下周计划、风险提示

## 【六】3–5个可直接尝试的改造方向

**1. 增加历史记录功能**
- 在右侧添加“历史生成”侧边栏
- 每次生成的结果自动保存（可命名）
- 点击历史记录可重新加载和对比
- **技术实现**：用`localStorage`存储数组，添加管理界面

**2. 支持多轮对话优化**
- 当前是“一次性生成”，改为“对话式优化”
- 生成结果后，用户可以说“第一条再详细些”或“换个表达方式”
- AI基于之前的对话历史继续优化
- **技术实现**：将之前的消息也加入`messages`数组发送

**3. 集成多个AI模型/平台**
- 除了DeepSeek，增加OpenAI、Claude、智谱等选项
- 在设置中让用户选择不同模型
- 甚至可以同时生成多个版本让用户对比
- **技术实现**：抽象API调用层，根据选择调用不同端点

**4. 增加简历模板和样式选择**
- 提供几种常见的简历排版模板
- 优化结果可以直接套用模板预览
- 支持一键导出为美观的PDF
- **技术实现**：用CSS定义多个模板类，用jsPDF库生成PDF

**5. 添加ATS模拟打分**
- 在结果顶部显示“ATS匹配度：85%”
- 列出匹配的关键词和缺失的关键词
- 给出具体的提分建议
- **技术实现**：用简单的文本匹配算法计算关键词覆盖率

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不生成虚构内容**：它只优化你提供的内容，不会凭空编造经历
2. **不涉及简历设计**：只关注文字内容，不管排版、颜色、字体等视觉设计
3. **不保证通过筛选**：ATS系统算法复杂，关键词匹配只是其中一环
4. **不替代人工审核**：最好将AI建议作为参考，最终要自己判断和调整

**如果用户想做X，应该换什么工具：**
- **想要完整简历设计**：用Canva、稿定设计等在线设计工具
- **想要AI直接生成虚构经历**：这不道德且风险高，不建议
- **想要专业的职业咨询**：找人力资源顾问或职业规划师
- **想要批量投递和管理**：用拉勾、Boss直聘等招聘平台的简历投递功能

---

**最后提醒**：这个工具的核心价值是“针对性优化”。它教会我们的设计思路是：**明确场景 → 收集关键信息 → 通过Prompt规范输出 → 提供便捷的操作闭环**。你可以把这个模式应用到无数其他场景中。
