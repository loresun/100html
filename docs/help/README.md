# 工具帮助文档目录

本目录包含 AI 内容创作工坊各工具的详细帮助文档。

## 目录结构

```
docs/help/
├── README.md                 # 本文件
├── categories/               # 分类说明文档
│   ├── ai_basics.md          # AI基础知识分类
│   ├── office.md             # 职场办公提效分类
│   └── ...
├── meeting_minutes.md        # 智能会议纪要助手
├── ppt_architect.md          # PPT 架构生成器
├── excel_helper.md           # Excel 智能伴侣
└── ...
```

## 文档格式规范

每个工具帮助文档应包含以下结构：

```markdown
# 工具名称

## 功能介绍

工具的核心功能和使用场景描述

## 快速上手

1. 第一步
2. 第二步
3. ...

## 功能详解

### 功能模块 1

详细说明...

### 功能模块 2

详细说明...

## 高级用法

进阶技巧和最佳实践

## 常见问题

### Q: 问题 1

A: 答案 1

### Q: 问题 2

A: 答案 2

## 更新日志

- 2026-01-05: 初始版本
```

## 复杂度等级说明

| 等级 | 标签 | 说明                       |
| ---- | ---- | -------------------------- |
| 1    | 入门 | 适合新手，操作简单直接     |
| 2    | 基础 | 需要少量配置，容易上手     |
| 3    | 中等 | 功能丰富，需要一定了解     |
| 4    | 进阶 | 功能复杂，适合有经验的用户 |
| 5    | 专家 | 深度功能，需要专业知识     |
