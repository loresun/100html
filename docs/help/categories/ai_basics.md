## 核心概念速览

### API Key

访问 AI 服务的"钥匙"，需要在 DeepSeek 平台申请。

### Prompt

给 AI 的指令或问题，设计好的 Prompt 是获得好结果的关键。

### Token

AI 处理文本的基本单位，中文大约 1 字 = 2 个 token。

### 温度 (Temperature)

控制 AI 输出的随机性，0 表示确定性，2 表示高创意。

### 流式输出 (Streaming)

让 AI 的回答"打字机式"逐字显示，提升用户体验。
