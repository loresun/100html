# 社恐破冰话题生成器 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你参加一个聚会、会议或相亲，面对陌生人时不知道如何开口，尴尬地玩手机。这个工具就是你的“社交急救包”。它根据具体的社交场景（如饭局、电梯遇见）和对方的基本信息（年龄、职业），为你生成自然、不尴尬的破冰话题和后续聊天方向。

**适合情况：**
- 社交场合中需要快速找到聊天切入点
- 与陌生人或不太熟悉的人初次交流
- 希望避免冷场和尴尬的沉默
- 需要一些启发来开启对话

**不适合情况：**
- 深度、长期的社交关系建立
- 需要高度个性化、情感共鸣的对话
- 替代真实的社交技巧学习和练习
- 处理复杂的人际关系问题

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **社交场景**：从下拉菜单中选择（饭局、相亲、电梯等）
2. **对方年龄**：填写大致年龄段（如“25-30岁”）
3. **对方职业**：填写职业信息（如“程序员”）
4. **兴趣爱好**：可选填写对方的兴趣（如“摄影”）

**用户通常会做哪几步操作？**
1. 根据实际情况填写或选择四个输入项
2. 点击绿色的“生成破冰话题”按钮
3. 等待几秒钟（会有加载动画）
4. 查看生成的3-5个话题卡片

**输出结果长什么样？**
每个话题卡片包含：
- **话题标题**：具体的开场白问题
- **推荐理由**：为什么这个话题适合当前场景
- **后续问题树**：如果对方回答了，可以接着问什么

**容易忽略的使用细节：**
1. **必须选择社交场景**：这是必填项，否则按钮不可用
2. **高级设置**：右上角齿轮图标可以设置API密钥和修改提示词
3. **模型切换**：右上角可以切换V3（常规）和R1（推理）模型
4. **防重复点击**：点击后按钮会禁用，防止重复生成

## 【三】核心结构拆解（学习重点）

**页面由哪几个关键模块组成？**
1. **配置模块**（顶部导航栏）：模型选择、设置入口
2. **输入模块**（场景设置卡片）：收集用户输入的四个字段
3. **控制模块**（生成按钮）：触发AI生成的核心操作
4. **输出模块**（话题卡片）：展示生成结果的区域
5. **设置面板**（模态窗口）：高级配置界面

**每个模块承担什么职责？**
- **配置模块**：管理技术层面的选择（模型、API密钥）
- **输入模块**：收集业务层面的信息（场景、人物特征）
- **控制模块**：连接输入和输出，调用AI服务
- **输出模块**：格式化展示AI生成的内容
- **设置面板**：提供定制化能力（修改提示词）

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入（场景+人物信息）
    ↓
拼接成用户提示词
    ↓
+ 系统提示词（设计原则+格式要求）
    ↓
发送给DeepSeek API
    ↓
解析返回的JSON数据
    ↓
渲染为话题卡片（带动画效果）
```

**最值得学习的设计：**
**结构化提示词设计**：系统提示词不仅告诉AI“做什么”，还规定了“如何做”（设计原则）和“输出格式”（JSON结构）。这种设计确保了：
1. 输出质量可控（遵循四个设计原则）
2. 数据结构一致（便于前端解析和展示）
3. 可维护性强（修改提示词即可调整生成逻辑）

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是页面的“大脑”和“规则手册”。它定义了：
- AI的角色身份（社交心理学专家）
- 生成内容的质量标准（四个设计原则）
- 输出的数据结构（JSON格式）

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**，但也包含理解：
- **理解部分**：让AI理解“什么是好的破冰话题”
- **生成部分**：指导AI按照特定格式生成具体内容

**Prompt中的关键变量：**
1. **角色定义**：“社交心理学专家” - 设定专业背景
2. **设计原则**：四个具体原则 - 控制生成质量
3. **输出格式**：JSON结构 - 确保数据可解析
4. **数量要求**：“生成3-5个” - 控制输出量

**如果只改Prompt，不改代码，会发生什么变化？**
1. 改**角色定义** → AI会以不同身份生成话题（如“幽默大师”、“心理咨询师”）
2. 改**设计原则** → 话题风格会变化（如更正式、更幽默、更深度）
3. 改**输出格式** → 前端可能无法正确解析（除非新格式兼容）
4. 改**数量要求** → 生成的话题数量会变化

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改“社交场景”选项和页面标题
- 例如：改成“面试问题生成器”、“约会话题生成器”
- 保持：输入字段数量、按钮样式、卡片布局

**第二步：调整输入字段或Prompt**
- 修改输入字段标签（如“对方年龄”→“面试岗位”）
- 微调系统提示词中的场景描述和角色
- 保持JSON输出格式不变，只改字段含义

**第三步：改变输出形式或展示方式**
- 修改卡片样式（颜色、布局）
- 增加新的展示元素（如评分、标签）
- 添加交互功能（收藏、分享）

**最安全的下手点：**
从**修改系统提示词**开始。这是纯文本修改，不需要懂代码：
1. 复制默认提示词
2. 把“社恐破冰”改成你的场景（如“产品需求调研”）
3. 调整设计原则（如从“真诚不做作”改成“专业深入”）
4. 测试效果

## 【六】3–5个可直接尝试的改造方向

**1. 增加输入维度，提升个性化**
- **增加**：“对话目的”（结交朋友、商务合作、寻求帮助）
- **增加**：“自身特点”（你的兴趣爱好、擅长领域）
- **增加**：“文化背景”（对方可能的文化或地域特点）
- **效果**：生成的话题更精准、更个性化

**2. 扩展输出形式，增强实用性**
- **增加**：“风险提示”（哪些话题可能踩雷）
- **增加**：“语气建议”（用轻松还是正式的语气）
- **增加**：“开场白示例”（完整的一句话怎么说）
- **改为**：对话流程图而不仅是列表

**3. 拆分为多页面流程，引导用户**
- **第一页**：选择场景类型（社交、工作、学习）
- **第二页**：填写详细信息（当前页面）
- **第三页**：生成并编辑（可微调生成的话题）
- **好处**：用户体验更流畅，可收集更多信息

**4. 优化交互体验，增加实用功能**
- **添加**：“一键复制”每个话题到剪贴板
- **添加**：“收藏”功能，保存喜欢的话题
- **添加**：“历史记录”，查看之前生成的话题
- **添加**：“分享”功能，生成图片或链接分享

**5. 更换或扩展AI服务**
- **更换**：使用OpenAI、Claude等其他模型
- **扩展**：同时调用多个模型，对比结果
- **增加**：本地模型支持（如Ollama）
- **增加**：模型参数调节（温度、top_p）

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**
1. **不适合替代真实社交练习**
   - 这是“话题灵感工具”，不是“社交能力培训”
   - 真实社交需要眼神交流、语气把握、即时反应

2. **不适合处理复杂人际关系**
   - 无法处理冲突解决、情感支持、深度沟通
   - 对于敏感话题（政治、宗教、隐私）建议谨慎

3. **不适合完全依赖AI生成**
   - 生成的话题需要结合实际情况判断
   - AI可能不了解最新的网络流行语或文化梗

4. **不适合需要即时互动的场景**
   - 有网络延迟，不适合“实时提词”
   - 在信号差的环境无法使用
