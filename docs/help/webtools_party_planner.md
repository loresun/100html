# 聚会策划工具 - 学习与使用指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你需要组织一场小型聚会（如生日派对、朋友聚餐、家庭烧烤）时，这个工具能帮你集中管理所有筹备细节。你不再需要同时在手机备忘录、聊天记录和纸质清单之间来回切换，所有信息都保存在一个地方。

**适合情况**：
- 组织10-30人的中小型聚会
- 需要跟踪宾客确认状态
- 需要管理简单的待办事项和采购清单
- 希望数据能自动保存，下次打开还能看到

**不适合情况**：
- 大型活动（如婚礼、公司年会）需要更专业的工具
- 需要多人协作编辑（这个工具是单人使用的）
- 需要预算管理、座位安排等复杂功能
- 需要分享给其他人查看或编辑

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **活动基本信息**：主题、时间、地点
2. **宾客名单**：逐个添加宾客姓名
3. **筹备待办**：需要完成的任务
4. **采购清单**：需要购买的物品

**用户通常会做哪几步操作？**
1. 先填写顶部的活动主题、时间和地点
2. 在左侧“宾客名单”区域添加所有邀请的宾客
3. 为每个宾客点击状态按钮（✓ 确认 / ? 待定 / ✗ 拒绝）
4. 在右侧添加筹备任务（如“预定场地”）并勾选完成
5. 在下方添加采购物品（如“饮料”）并勾选完成

**输出结果长什么样？**
- 页面顶部会显示活动概要
- 左侧宾客列表会实时显示确认人数
- 右侧任务和采购项被勾选后会显示删除线
- 所有数据会自动保存在你的浏览器中

**容易忽略的使用细节：**
1. **按回车键快速添加**：在输入框输入内容后，按回车键就能直接添加，不用点“+”按钮
2. **宾客状态切换**：每个宾客名字右侧有三个小图标，分别代表“确认”、“待定”、“拒绝”
3. **鼠标悬停显示删除**：把鼠标放在宾客、任务或采购项上，右侧会出现删除按钮
4. **数据自动保存**：关闭页面再打开，所有内容都在，但仅限于同一台电脑的同一个浏览器

## 【三】核心结构拆解（学习重点）

这个页面由**四个独立模块**组成，每个模块职责清晰：

### 模块1：活动信息卡（顶部）
- **职责**：收集活动的基本元数据
- **输入**：用户填写主题、时间、地点
- **输出**：显示在页面最显眼的位置
- **设计亮点**：使用视觉层次（大标题、小标签）引导用户先填写最重要信息

### 模块2：宾客管理（左侧主区域）
- **职责**：管理邀请名单和确认状态
- **输入**：宾客姓名、确认状态
- **处理**：实时统计确认人数
- **输出**：带状态标记的列表、顶部确认人数统计
- **设计亮点**：状态切换使用图标按钮，比下拉菜单更直观快速

### 模块3：任务管理（右上区域）
- **职责**：跟踪筹备进度
- **输入**：任务名称、完成状态
- **输出**：带复选框的列表，完成的任务有删除线
- **设计亮点**：极简的“+ 添加待办事项”输入框，鼓励用户快速记录

### 模块4：采购管理（右下区域）
- **职责**：管理需要购买的物品
- **输入**：物品名称、购买状态
- **输出**：与任务管理类似的清单界面
- **设计亮点**：复用任务管理的交互模式，降低学习成本

**逻辑链路**：
```
用户输入 → 数据更新 → 自动保存到本地存储 → 界面实时刷新
```

**最值得学习的设计**：
1. **状态驱动的UI**：宾客的三种状态用不同颜色和图标表示，一目了然
2. **渐进式交互**：从基本信息→宾客→任务→采购，符合实际策划流程
3. **数据持久化**：使用localStorage自动保存，无需“保存”按钮
4. **响应式布局**：在手机和电脑上都能良好显示

## 【四】Prompt / AI 逻辑是如何被设计的？

> **注意**：当前版本没有使用AI功能。这是一个纯前端工具，所有逻辑都在浏览器中运行。

**如果我们要为它添加AI功能**，可以这样设计：

**Prompt可能扮演的角色**：
1. **智能建议生成**：根据活动主题自动推荐任务和采购项
2. **宾客状态预测**：基于历史数据预测哪些宾客可能确认
3. **预算估算**：根据宾客人数和活动类型估算花费

**Prompt解决的是“生成问题”**：
- 输入：“周末烧烤派对，15人，户外”
- AI输出：["准备烧烤架和炭火", "购买一次性餐具", "准备防蚊用品"]

**关键变量**：
- 活动类型（主题）
- 宾客人数
- 活动地点（室内/户外）
- 预算范围

**如果只改Prompt，不改代码**：
- 可以改变AI建议的详细程度
- 可以调整建议的针对性（如更侧重美食或娱乐）
- 可以改变输出的格式（列表、段落、表格）

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径**：

**第一步：保持结构不变，替换使用场景**
- 将“聚会策划”改为“旅行规划”
- 模块对应关系：
  - 宾客名单 → 同行人员
  - 筹备待办 → 行程安排
  - 采购清单 → 行李清单
- 只改文字和图标，不动代码结构

**第二步：调整数据字段**
- 在活动信息卡中：
  - “时间”改为“出发日期”和“返回日期”（两个字段）
  - “地点”改为“目的地”
- 在人员模块中：
  - 状态按钮改为“已购票”、“待购票”、“不参加”
- 这些改动只需要修改HTML中的标签和x-model绑定的字段名

**第三步：改变展示方式**
- 为行程安排添加时间字段
- 为行李清单添加分类（衣物、电子、证件）
- 添加“行程总览”卡片显示关键信息
- 这些改动需要添加新的数据字段和界面元素

**从哪里下手最安全？**
1. 先改所有看得见的文字（标题、标签、占位符）
2. 然后改颜色主题（把orange换成其他颜色）
3. 最后考虑添加或删除小的功能模块

## 【六】3–5个可直接尝试的改造方向

### 1. 添加预算管理模块
- **具体操作**：在采购清单下方添加“预算”模块
- **字段设计**：物品、预算金额、实际金额、差额
- **技术实现**：新增一个shopping数组，每个物品包含price和actualPrice字段
- **效果**：自动计算总预算和实际花费，超支时变红

### 2. 改为多人协作版本
- **具体操作**：添加“分享”按钮生成链接
- **技术选择**：使用Firebase或Supabase作为后端
- **交互优化**：每个修改显示最后编辑者和时间
- **效果**：多个朋友可以一起编辑同一个聚会计划

### 3. 添加AI智能建议
- **具体操作**：在空白处添加“AI建议”按钮
- **API选择**：使用OpenAI GPT或本地运行的LLM
- **Prompt设计**：“根据[主题][人数][地点]推荐10个必备任务和采购项”
- **效果**：点击后自动填充任务和采购清单

### 4. 优化移动端体验
- **具体操作**：将左右布局改为上下堆叠
- **交互优化**：添加底部导航栏快速切换模块
- **技术实现**：使用Tailwind的响应式类（如`md:grid-cols-2`改为`grid-cols-1`）
- **效果**：在手机上单列显示，操作更顺手

### 5. 添加导出功能
- **具体操作**：在右上角添加“导出”按钮
- **格式选择**：PDF、图片、或文本
- **技术实现**：使用html2canvas生成图片，或jsPDF生成PDF
- **效果**：可以将计划分享到社交媒体或打印出来

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性：
1. **不适合大型活动**：没有座位安排、邀请函设计、供应商管理等功能
2. **没有预算跟踪**：只能记录买什么，不能记录花了多少钱
3. **无法多人协作**：数据只存在你的电脑上，别人看不到也改不了
4. **没有提醒功能**：不会在活动前一天提醒你该做什么
5. **依赖浏览器**：换电脑或清空缓存就会丢失所有数据

### 如果用户想做X，应该换什么：
- **想做婚礼策划** → 使用专业工具如“婚礼纪”或“Zola”
- **需要团队协作** → 使用Notion、Trello或Asana创建共享看板
- **需要复杂预算** → 使用Excel或Google Sheets制作详细表格
- **需要手机提醒** → 使用日历应用（Google日历、苹果日历）设置提醒
- **需要长期保存** → 定期手动导出数据，或改用有云同步功能的应用
