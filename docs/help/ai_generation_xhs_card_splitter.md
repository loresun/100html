# 小红书卡片拆分器 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你需要将一篇长文章（比如产品介绍、教程、清单列表）制作成适合在小红书等平台发布的“卡片式”图片时，这个工具可以帮你自动完成。它解决了手动截图、排版、计算每张图片放多少文字的繁琐过程。

- **适合情况**：你需要将结构清晰的文字内容（如带标题、列表的Markdown）快速拆分成多张风格统一、可直接发布的图片。例如，制作一个“10个护肤技巧”的系列笔记。
- **不适合情况**：处理纯图片、复杂表格、需要精细交互设计的内容，或者希望生成视频、动态H5等多媒体形式。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    - **主内容区**：在左侧“内容输入”的大文本框里，粘贴或输入你的文章。支持使用Markdown语法（如 `# 标题`、`- 列表`）。
    - **顶部/底部文案**：可以自定义每张卡片顶部（如“@我的账号”）和底部（如“关注收藏”）的固定文字。
    - **版式参数**：可以滑动调整正文字号、行距，以及选择导出图片的清晰度。

2.  **用户通常会做哪几步操作？**
    1.  在左侧输入或粘贴你的长文。
    2.  （可选）调整顶部/底部文案，让它更符合你的账号风格。
    3.  （可选）微调字号和行距，确保预览的卡片看起来舒适、美观。
    4.  查看右侧自动生成的卡片预览。
    5.  点击“批量导出”或某张卡片下的“单张导出”按钮，下载PNG格式的图片。

3.  **输出结果长什么样？**
    - 输出是一系列尺寸为600x800像素（或2倍高清）的PNG图片。
    - 每张图片具有统一的圆角卡片设计，包含你自定义的页眉、页脚，以及被自动拆分到刚好填满卡片的内容。
    - 卡片右下角会显示当前页码（如“2/5”）。

4.  **有哪些容易忽略的使用细节？**
    - **“填入示例”按钮**：如果你不确定格式，点一下它会填入一个示例，你可以基于此修改。
    - **预览是缩小的**：右侧预览区为了同时展示多张卡片，比例是缩小的。导出的图片是原始高清尺寸。
    - **拆分是自动的**：你不需要手动分页，工具会根据你设置的字号和行距，自动计算内容何时该换到下一张卡片。
    - **使用Markdown**：用 `#`、`##` 写标题，用 `-` 写列表，能让内容结构更清晰，拆分效果更好。

## 【三】核心结构拆解（学习重点）

这个页面可以看作由三个核心模块组成：

1.  **控制面板模块（左侧）**
    - **职责**：接收用户的所有输入和配置。它是整个应用的“大脑”和“控制台”。
    - **包含**：文本输入框、文案配置输入框、样式调节滑块。
    - **逻辑**：用户在此模块的任何操作，都会立刻被监听，并触发后续的“处理”流程。

2.  **预览与输出模块（右侧）**
    - **职责**：直观展示处理结果，并提供导出功能。它是“成果展示厅”和“出货码头”。
    - **包含**：按顺序排列的卡片预览图、“单张导出”按钮。
    - **逻辑**：它被动接收来自“处理引擎”生成好的HTML片段，并将其渲染成视觉化的卡片。

3.  **处理引擎模块（隐藏在代码中）**
    - **职责**：这是最核心的部分，负责将“输入文本”按照“样式规则”拆分成适合“卡片尺寸”的多个片段。
    - **关键算法**：
        - **测量**：用一个隐藏的“测量卡片”计算当前样式下，卡片主体部分能容纳多少高度的HTML内容。
        - **分词与拆分**：利用 `marked` 库将Markdown文本解析成令牌（如标题、段落、列表），然后根据测量高度，智能地将过长的段落按句号、感叹号等标点拆分成更小的块。
        - **组装分页**：将拆分后的内容块依次放入“当前页”，一旦超过测量高度，就完成当前页，剩余的块开始新的一页。
    - **最值得学习的设计**：**“测量-拆分”的分离设计**。它没有硬编码“每页多少字”，而是动态创建一个隐藏的、样式完全相同的卡片来测量实际渲染高度，这使得拆分算法非常精准，且能自适应任何字体、行距的设置。这是将**内容（HTML）、样式（CSS）、布局（高度）** 三者结合解决问题的经典思路。

**输入 → 处理 → 输出链路**：
`用户输入文本/样式` → `引擎解析Markdown为令牌` → `根据测量高度拆分令牌` → `生成多个HTML片段` → `片段被送入预览模块渲染` → `用户触发导出，将HTML片段转为Canvas并下载为PNG`。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个网页中，**没有使用传统的“Prompt”和AI模型**。它解决的是一个**确定性的格式转换与排版问题**，而非需要理解语义或生成新内容的问题。

- **它的核心是“算法逻辑”而非“Prompt”**：逻辑被硬编码在 `splitContent()`, `splitTextToChunks()`, `measureHeight()` 这些函数中。这些函数定义了如何根据标点符号、段落和预设高度来拆分文本。
- **如果类比为Prompt**：那么用户的“输入文本”和“样式设置”就是给这个拆分算法的“指令”。算法严格地执行“按句拆分，确保每页不超限”的规则。
- **关键变量**：在这个逻辑中，`contentHeight`（卡片内容区最大高度）和 `splitTextToChunks` 函数中的拆分规则（如按`[。！？.!?；;]`标点拆分）是核心变量。
- **如果只改逻辑，不改界面**：例如，修改 `splitTextToChunks` 函数，让它按逗号拆分而不是句号，那么生成的卡片内容断句位置就会完全改变。或者调整测量逻辑，让每页预留一些空白，整体的排版感觉也会变化。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个安全的路径，逐步打造自己的工具：

1.  **第一步：替换场景与视觉风格（最安全）**
    - **目标**：先做出一个能跑通的、属于你主题的版本。
    - **操作**：
        - 修改 `title` 和页面标题，例如改为“知识卡片生成器”。
        - 替换颜色主题：将代码中所有的 `rose`（玫红色）替换成另一种主色，如 `blue`。
        - 修改卡片尺寸：调整 `.card-shell` 的 `width` 和 `height`，以及 `exportCanvas` 函数中的 `width`、`height` 参数，适应其他平台（如微博、知乎）的图片比例。
        - 更新示例内容 `addSample` 函数，填入你所在领域（如编程、健身、美食）的示例文本。

2.  **第二步：调整输入与处理逻辑**
    - **目标**：让工具更贴合你的具体需求。
    - **操作**：
        - **增加输入项**：在左侧面板添加一个输入框，让用户能上传或输入卡片背景图的URL。
        - **修改拆分逻辑**：在 `splitTextToChunks` 函数中，调整拆分规则。比如，对于代码教程，你可能想按“代码块”来拆分，而不是按标点。
        - **简化或复杂化**：如果你只想拆分纯文本，可以移除对Markdown (`marked`库) 的支持，让逻辑更简单。

3.  **第三步：改变输出与展示形式**
    - **目标**：提供差异化的结果。
    - **操作**：
        - **输出格式**：修改 `exportCanvas` 函数，除了PNG，尝试提供PDF或WebP格式的导出选项。
        - **预览交互**：让预览卡片可以点击放大查看，或者增加一个“模拟小红书App”的展示框。
        - **分享功能**：增加一个按钮，将生成的图片序列直接打包成ZIP下载，或模拟发布到某个平台（需后端支持）。

**从哪里下手最安全？** 从**第一步**开始。只改动颜色、文字、尺寸这些视觉和配置项，不触碰核心的JavaScript拆分逻辑。这样你能立即看到一个属于你的“皮肤版”工具，建立信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“主题模板”选择**：
    - 在控制面板增加一个下拉菜单，提供“简约白”、“深夜黑”、“春日绿”等几套预设的配色方案（包括卡片背景色、文字色、主题色）。选择后，通过JavaScript动态替换CSS变量或类名。

2.  **引入AI进行智能摘要或润色**：
    - 在“内容输入”区旁增加一个“AI优化”按钮。点击后，将当前文本通过API（如OpenAI GPT、文心一言）发送，请求其将长文改写成更口语化、更适合小红书的短句集合，然后替换原有输入。这解决了“内容本身不适合拆分”的问题。

3.  **从URL或文件导入内容**：
    - 增加一个“导入”区域，允许用户粘贴文章链接（通过简单的后端服务或浏览器扩展提取正文），或上传.txt/.md文件，自动将内容填入输入框，提升输入效率。

4.  **优化为“分步式”工作流页面**：
    - 将当前单页应用拆成多个步骤页：
        - **步骤1：输入内容**（当前左侧面板）。
        - **步骤2：调整样式与预览**（当前右侧面板放大，并强化样式控件）。
        - **步骤3：导出与分享**（展示所有生成图片，并提供批量操作和分享选项）。
    - 这能引导用户更清晰地完成操作，尤其适合内容更复杂的场景。

5.  **增加“元素拖拽”手动微调**：
    - 在预览卡片上，允许用户拖动某个段落或图片，从一个卡片移动到另一个卡片，覆盖自动拆分的结果。这给了用户最终的控制权，处理自动拆分可能不合理的情况。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做专业的平面设计**：它生成的卡片是标准化的模板。如果你需要高度定制化、带有复杂图形、特殊字体排版的视觉设计（如海报、 Banner），应使用 Figma、Canva 或 Adobe Illustrator 等专业设计工具。
2.  **不适合处理流式或实时内容**：它是为了一次性处理一篇完整的静态文本。不能用于直播字幕截图、实时聊天记录长图生成等场景。
3.  **不适合替代内容发布平台**：它只是一个内容**格式化**工具。最终的发布、运营、互动仍需在小红书、微博等平台完成。它不提供 scheduling（定时发布）、数据分析、评论管理等功能。
4.  **不适合无结构的长篇大论**：如果输入的是完全没有段落、标题、列表的“意识流”长文，自动拆分的效果会很差，可能得到意义不完整的句子片段。在这种情况下，要么先手动整理内容结构，要么考虑使用前述的“AI润色”改造方向。
