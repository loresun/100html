# 智能求职招聘助手 - 学习与使用指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象你正在找工作，面对一份招聘要求（JD），不确定自己的简历是否匹配，也不知道如何修改。或者你是一名HR，需要快速写出一份吸引人的招聘文案。这个网页就像一个“求职招聘双面助手”，能同时帮助求职者和招聘方。

**适合的情况：**
- **求职者**：需要评估简历与岗位的匹配度、优化简历、准备面试、撰写求职信
- **HR/招聘人员**：需要快速生成专业、有吸引力的岗位描述（JD）
- **学生/转行者**：缺乏经验，需要指导如何呈现自己的优势
- **中小公司**：没有专业HR团队，需要快速制作招聘文案

**不适合的情况：**
- 需要真人一对一深度咨询（如职业规划、薪资谈判策略）
- 处理高度机密的简历或公司信息（所有内容会发送给AI服务商）
- 替代专业的简历设计或招聘系统（这是内容生成工具，不是管理系统）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- **求职者视角**：你的简历内容 + 目标岗位的招聘描述（JD）
- **HR视角**：岗位基本信息（名称、公司、职责、要求等）

**用户通常会做哪几步操作？**
1. **选择视角**：点击顶部“求职者视角”或“HR/猎头视角”
2. **填写内容**：
   - 求职者：粘贴简历和JD → 选择功能（匹配/优化/面试/求职信）
   - HR：填写岗位信息表单 → 选择JD风格
3. **点击生成**：等待AI分析并生成结果
4. **查看结果**：阅读分析报告或生成的内容
5. **复制/导出**：将结果保存到本地

**输出结果长什么样？**
- **简历匹配**：综合评分（如85%）+ 分项得分 + 详细分析报告（Markdown格式）
- **简历优化**：优化后的简历内容（带格式建议）
- **面试助手**：预测问题 + 回答建议 + 准备要点
- **求职信/JD生成**：完整的、可直接使用的文档

**有哪些容易忽略的使用细节？**
1. **示例加载**：每个输入框旁有“加载示例”按钮，点击可查看格式参考
2. **模型选择**：导航栏可切换“快速”和“深度”模式，后者思考更深入但更慢
3. **设置API密钥**：首次使用需点击右上角设置按钮，输入DeepSeek API密钥
4. **多选功能**：优化方向和面试类型支持多选，AI会综合处理
5. **复制导出**：结果区域右上角有复制和导出按钮

## 【三】核心结构拆解（学习重点）

**页面由哪几个关键模块组成？**
1. **视角切换模块**（顶部标签）：决定整个页面的功能导向
2. **输入配置模块**（中部表单）：收集用户需求和数据
3. **AI处理引擎**（隐藏的逻辑层）：将输入转化为Prompt发送给AI
4. **结果展示模块**（底部区域）：格式化呈现AI返回的内容
5. **设置管理模块**（弹窗）：管理API配置和模型选择

**每个模块承担什么职责？**
- **视角切换**：像“模式选择器”，切换后改变所有下方组件的功能和文案
- **输入配置**：像“需求收集表”，结构化地获取用户的具体要求
- **AI处理引擎**：像“翻译官”，把用户需求翻译成AI能理解的Prompt
- **结果展示**：像“报告生成器”，把AI的原始回复美化、结构化
- **设置管理**：像“控制面板”，管理工具的基础配置

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入（简历/JD/表单）
    ↓
前端验证（检查必填项）
    ↓
构建Prompt（根据功能组合模板）
    ↓
调用AI API（DeepSeek）
    ↓
解析响应（提取评分/内容/推理过程）
    ↓
格式化展示（评分卡片 + Markdown渲染）
    ↓
用户操作（复制/导出/继续修改）
```

**哪一部分是“这个网页最值得学习的设计”？**
**动态Prompt构建系统**最值得学习。它没有写死Prompt，而是：
1. 根据用户选择的“功能标签”选择不同的Prompt模板
2. 将表单数据智能地插入到模板的对应位置
3. 根据用户选择的“风格”、“方向”等选项调整Prompt的语气和要求
4. 对“深度思考”模型和“快速”模型使用不同的Prompt结构

这种设计让一个页面支持8种以上不同的AI任务，而代码结构依然清晰。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt在这里是“任务说明书”+“格式要求”+“风格指南”的三合一。它告诉AI：
1. **要做什么**（分析匹配度/优化简历/生成JD）
2. **按什么格式回答**（先给评分，再分点分析，用Markdown）
3. **用什么语气和风格**（专业/热情/简洁等）

**它解决的是“理解问题”还是“生成问题”？**
两者都有，但更偏向“结构化生成问题”：
- **理解部分**：让AI理解“简历匹配度”应该从哪些维度评估
- **生成部分**：要求AI按照特定格式生成内容（如求职信要有称呼、正文、落款）

**哪些信息是 Prompt 中的关键变量？**
1. **用户输入的内容**：简历文本、JD文本、表单数据
2. **用户选择的选项**：优化方向、面试类型、文档风格
3. **系统指令**：输出格式、评分标准、思考深度要求
4. **角色设定**：让AI扮演“资深HR顾问”或“职业规划师”

**如果只改 Prompt，不改代码，会发生什么变化？**
- **改变评分维度**：从“技能/经验/文化”改为“硬技能/软技能/潜力”
- **改变输出格式**：从Markdown列表改为表格对比
- **改变分析深度**：从简单建议改为逐句点评
- **改变专业领域**：从通用岗位改为特定行业（如程序员、设计师）
- **改变语气风格**：从正式专业改为轻松幽默

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景**（最安全）
- 将“求职招聘”改为“学习辅导”
- 求职者 → 学生，HR → 教师
- 简历匹配 → 知识点掌握度评估
- 简历优化 → 学习计划优化
- 面试助手 → 考试准备助手
- 求职信生成 → 学习报告生成

**第二步：调整输入字段或 Prompt**
- 修改表单字段：从“工作经历”改为“已学章节”
- 调整Prompt模板：将职业术语改为教育术语
- 改变评分维度：从岗位匹配度改为知识点掌握度

**第三步：改变输出形式或展示方式**
- 将环形评分改为进度条
- 增加可视化图表（如知识点掌握雷达图）
- 添加“错题本”导出功能

**从哪里下手最安全？**
从**修改文案和选项**开始最安全：
1. 先改所有显示文字（标题、标签、提示语）
2. 再改选项内容（优化方向、风格类型）
3. 然后改示例数据
4. 最后考虑改Prompt模板

这样即使改错了，页面也不会崩溃，功能依然可用。

## 【六】3–5 个可直接尝试的改造方向

**1. 增加“对话式优化”功能**
- **现状**：一次性生成结果，用户需要手动修改输入再重新生成
- **改造**：在结果区域增加“继续优化”按钮，让用户可以：
  - 说“这里再详细一点”
  - 说“换个更正式的说法”
  - 说“缩短到200字以内”
- **技术实现**：保存对话历史，每次追加到Prompt中

**2. 增加“多版本对比”功能**
- **现状**：一次只生成一个版本的结果
- **改造**：让AI同时生成2-3个不同风格的版本（如：简洁版/详细版/亮点突出版）
- **展示方式**：用标签页或并排对比，让用户选择最喜欢的
- **价值**：帮助用户理解不同表达方式的效果

**3. 增加“本地模板库”功能**
- **现状**：用户需要每次都粘贴简历/JD
- **改造**：允许用户保存多个“简历模板”或“JD模板”
- **实现**：使用浏览器的localStorage存储，添加管理界面
- **进阶**：支持导入/导出模板文件

**4. 增加“行业专家模式”**
- **现状**：使用通用的评估标准
- **改造**：让用户选择行业（互联网/金融/制造业等）
- **实现**：根据不同行业加载不同的Prompt模板和关键词库
- **示例**：程序员岗位重点看技术栈和项目经验，销售岗位重点看业绩数据

**5. 优化为“分步引导式”界面**
- **现状**：所有输入框一次性展示
- **改造**：将长表单拆解为3-4个步骤，每步有进度指示
- **优势**：降低用户认知负担，提高完成率
- **示例**：
  - 第1步：基本信息
  - 第2步：核心要求
  - 第3步：风格选择
  - 第4步：生成结果

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不替代人类判断**：AI的评分和建议仅供参考，不能完全替代HR或职业顾问的专业判断
2. **不保证结果质量**：生成内容的质量取决于输入质量和AI模型的当前状态
3. **不处理敏感信息**：不要输入身份证号、银行卡号、具体公司机密等敏感信息
4. **不支持复杂格式**：主要处理纯文本，对简历的排版设计帮助有限
5. **不提供实时更新**：行业趋势、薪资数据等可能不是最新的

**如果用户想做 X，应该换什么工具或方式：**
- **想做专业的简历设计** → 使用Canva、Photoshop或专业简历设计网站
- **需要深度职业规划** → 咨询职业顾问或参加职业规划课程
- **管理招聘全流程** → 使用招聘管理系统（如Moka、北森）
- **进行模拟面试** → 使用带视频录制和反馈的面试练习平台
- **需要法律合规审查** → 咨询人力资源法务专家

---

**最后提醒**：这个工具的最佳使用方式是“辅助思考”，而不是“替代思考”。把它当作一个24小时在线的智能助手，帮你拓宽思路、提供参考，但最终的决定和判断还需要你自己的智慧。
