# 涨薪幅度计算器 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象你正在规划职业发展，或者刚刚收到一份新的工作邀约。你手头有当前的薪资和新工作的薪资，但你想知道这个变化到底有多大意义。这个网页就像一个“薪资变化翻译器”，帮你把枯燥的数字变成直观的百分比、月增额等容易理解的信息。

**适合情况：**
- 对比两个工作机会的薪资差异
- 评估公司内部调薪的幅度
- 计算跳槽带来的实际收入变化
- 快速验证HR提供的涨薪比例是否正确

**不适合情况：**
- 需要计算税后实际到手金额（不包含税务计算）
- 需要对比福利、股票期权等非现金收入
- 需要长期薪资增长预测（如未来5年的复合增长率）
- 需要地区生活成本调整后的实际购买力对比

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你需要填写两个核心数字：
1. **当前月薪** - 你现在每个月的基本工资
2. **新工作月薪** - 新工作或调薪后的月薪

**操作步骤：**
1. 在“当前月薪”输入框中输入你现在的月薪数字
2. 在“新工作月薪”输入框中输入新工作的月薪数字
3. 点击蓝色的“计算结果”按钮

**输出结果长什么样？**
你会看到两个清晰的结果卡片：
- **涨薪幅度**：显示百分比，如“+25.0%”
- **每月增加**：显示具体的金额增加，如“+¥2,500”

**容易忽略的细节：**
- 输入时不需要输入货币符号（¥）或千位分隔符
- 数字可以带小数点，比如15000.5
- 页面会自动保存你上次输入的值（刷新后还在）
- 结果会立即显示，不需要等待加载

## 【三】核心结构拆解（学习重点）

这个页面采用了**“工具容器+具体工具”**的模块化设计：

### 1. 导航模块
- **职责**：提供返回入口和设置入口
- **特点**：固定在顶部，始终可见

### 2. 工具信息模块
- **职责**：显示当前工具的名称和描述
- **特点**：动态加载，根据工具类型变化

### 3. 输入计算模块（涨薪计算器的核心）
- **职责**：接收用户输入、执行计算、展示结果
- **结构**：
  - 输入区域：两个并排的数字输入框
  - 计算按钮：触发计算逻辑
  - 结果区域：以卡片形式展示计算结果

### 4. 设置面板模块
- **职责**：管理API配置（虽然涨薪计算器不需要API）
- **特点**：模态框形式，不影响主操作

**输入→处理→输出链路：**
```
用户输入数字 → 点击计算按钮 → JavaScript执行公式计算 → 格式化结果显示
```

**最值得学习的设计：**
**“字段配置化”设计** - 注意看代码中的`tool.fields`部分。涨薪计算器的输入字段（当前月薪、新工作月薪）不是硬编码在HTML里的，而是通过一个配置对象动态生成的。这意味着：
- 要添加新字段（如“年终奖”），只需修改配置，不用改HTML
- 同样的HTML结构可以服务多种不同的计算器
- 字段的标签、单位、最小值等属性都可以配置

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个具体的涨薪计算器中，**没有使用AI或Prompt**。它是一个纯数学计算工具。

但是，页面架构为AI工具预留了接口（通过设置面板中的API配置）。如果我们要为这个计算器添加AI功能，可以这样设计：

**假设的AI应用场景：**
- 用户输入薪资后，AI可以给出市场对比建议
- AI分析涨薪幅度是否合理

**Prompt设计思路：**
```
你是一个薪资分析专家。用户提供了以下信息：
当前月薪：{currentSalary}元
新工作月薪：{newSalary}元
涨薪幅度：{percentage}%

请根据行业标准，分析这个涨幅是否合理，并给出建议。
```

**关键变量：**
- `{currentSalary}` - 当前薪资
- `{newSalary}` - 新工作薪资
- `{percentage}` - 计算出的涨薪百分比

**如果只改Prompt：**
- 可以改变AI回复的风格（从专业分析变成幽默调侃）
- 可以增加更多分析维度（如城市生活成本、行业水平）
- 可以提供不同的建议角度（职业发展 vs 生活质量）

## 【五】如何模仿它，做出你自己的版本？

**安全改造路径：**

### 第一步：保持结构不变，替换使用场景（最安全）
1. 复制整个HTML文件，重命名为`my_calculator.html`
2. 修改标题和描述，比如改成“投资收益计算器”
3. 修改输入字段配置：
   - 将“当前月薪”改为“投资本金”
   - 将“新工作月薪”改为“预期收益”
   - 修改单位从“元”改为“元”或“%”

### 第二步：调整计算逻辑
1. 找到计算函数（在`standalone.js`中，对应`calculate`函数）
2. 修改计算公式：
   ```javascript
   // 原来的涨薪计算
   const percentage = ((newSalary - currentSalary) / currentSalary) * 100;
   const monthlyIncrease = newSalary - currentSalary;
   
   // 改为投资收益率计算
   const returnRate = ((expectedReturn - principal) / principal) * 100;
   const profit = expectedReturn - principal;
   ```

### 第三步：改变输出展示
1. 修改结果标签：
   - “涨薪幅度” → “投资收益率”
   - “每月增加” → “总利润”
2. 可以增加第三个结果显示，如“年化收益率”

**从哪里下手最安全？**
从**修改文字和标签**开始，这是零风险的操作。先让页面显示你的新工具名称和字段标签，确保页面能正常显示，再逐步修改计算逻辑。

## 【六】3–5 个可直接尝试的改造方向

### 1. 增加更多计算维度
- **操作**：在配置中添加第三个字段“年终奖比例”
- **效果**：计算包含年终奖的总包涨幅
- **代码修改点**：修改`tool.fields`数组，增加新字段配置

### 2. 添加历史记录功能
- **操作**：在结果下方添加“保存本次计算”按钮
- **效果**：用户可以保存多次计算结果进行对比
- **实现思路**：使用`localStorage`存储历史记录，新增一个历史记录展示区域

### 3. 可视化结果展示
- **操作**：用图表替代纯数字显示
- **效果**：添加一个进度条或饼图展示涨薪比例
- **技术选择**：使用简单的CSS进度条，或引入轻量图表库如Chart.js

### 4. 增加分享功能
- **操作**：添加“生成分享图”按钮
- **效果**：将计算结果生成图片，方便分享到社交媒体
- **技术方案**：使用html2canvas库将结果区域转为图片

### 5. 多货币支持
- **操作**：在输入框旁添加货币选择下拉框
- **效果**：支持人民币、美元、欧元等多种货币计算
- **关键点**：需要实时汇率API，或固定汇率换算

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性：
1. **不计算税后收入** - 这是税前数字对比，实际到手金额受税务影响
2. **不考虑通货膨胀** - 没有考虑货币时间价值
3. **不包含福利对比** - 只计算现金工资，忽略社保、公积金、股票等
4. **没有地域调整** - 同样的薪资在不同城市购买力不同
5. **一次性计算** - 不支持多阶段涨薪或未来预测

### 如果需要做以下事情，请换工具：

**如果想计算税后实际收入：**
- 使用专业的薪资计算器，如各地的“个税计算器”
- 需要输入社保公积金比例、专项附加扣除等

**如果想做长期职业规划：**
- 使用Excel或专业财务软件
- 需要计算复合增长率、考虑通胀因素

**如果想全面对比工作机会：**
- 制作一个对比表格
- 包含薪资、福利、发展空间、工作强度等多维度

**如果想分析行业薪资水平：**
- 使用招聘网站提供的薪资报告工具
- 或咨询专业的薪酬调研机构
