# 通用海报/社媒卡片结构生成器 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你是一个运营、设计师或内容创作者，需要为一次新品发布或活动制作社交媒体海报。你脑子里有主题和卖点，但面对空白的画布，却不知道如何安排标题、图片和按钮的位置，也不确定哪种风格更适合你的平台。这个网页就是你的“版式灵感助手”。

**适合的使用场景：**
- 快速为小红书、微博、朋友圈等平台生成海报的版式草图和文案结构。
- 在正式设计前，快速探索多种布局可能性，与团队沟通创意方向。
- 当你缺乏设计灵感，需要一些结构化的建议来启动项目。

**不适合的情况：**
- 它**不生成**最终的海报图片，只提供文字版的结构描述和建议。
- 它**不适合**需要高度定制化、复杂交互或动态效果的设计。
- 它**不能替代**专业的设计软件（如 Figma, Photoshop）来完成最终视觉稿。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你需要填写或选择左侧面板中的几项信息：
1.  **基础信息**：你的活动“主题”、产品的“核心卖点关键词”以及希望用户采取的“行动号召”（如“立即购买”）。
2.  **目标平台**：选择海报将发布在哪个平台（小红书、微博或朋友圈）。
3.  **版式与风格偏好**：选择一种视觉风格倾向（如“简洁留白”、“高能视觉”）。
4.  **输出设置**：勾选你希望生成的结果中包含哪些部分（如主视觉建议、文案结构等）。

**用户通常会做哪几步操作？**
1.  在左侧表单中，依次填写或选择上述信息。
2.  点击页面顶部或左侧底部的 **“生成结构方案”** 按钮。
3.  查看右侧区域生成的 **2-3个版式方案**。
4.  如果对某个方案感兴趣，可以点击方案底部的 **“复制方案”** 按钮，将内容复制到剪贴板，方便粘贴到文档中与团队讨论。

**输出结果长什么样？**
每个方案都是一个独立的卡片，包含：
-   **方案标题和标签**（如“小红书 简洁留白方案”）。
-   **版式结构**：用文字描述海报的布局分区（例如：“上方大标题占位，左对齐；中部主视觉占60%面积”）。
-   **文案布局**：为你生成的标题、副标题和行动号召文案示例。
-   **主视觉建议**：关于图片或图形风格的提示词（如“极简背景”、“清晰产品特写”）。
-   **排版细节**：具体的排版建议（如“采用12栅格，标题跨8栏”）。

**有哪些容易忽略的使用细节？**
-   **输出设置是开关**：如果你不勾选“包含主视觉建议”，生成的方案中就不会有这部分内容。你可以根据需求灵活组合。
-   **平台影响结构**：选择不同的平台（如小红书 vs 微博），生成的版式结构模板会完全不同，因为它考虑了各平台的常见图片比例和用户阅读习惯。
-   **“复制方案”功能**：这个按钮复制的是当前方案的**纯文本总结**，而不是代码或图片，方便你保存和分享创意。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为两大模块：

**1. 控制面板模块（左侧）**
*   **职责**：收集用户的所有创作意图和偏好。它像一个“需求收集器”，把模糊的想法（主题、风格）变成程序可以处理的明确参数。
*   **子模块**：
    *   **基础信息输入区**：获取内容核心（是什么、好在哪、要用户做什么）。
    *   **平台选择区**：确定设计约束（尺寸、平台调性）。
    *   **风格选择区**：定义视觉基调。
    *   **输出设置区**：控制生成内容的详细程度。

**2. 方案展示模块（右侧）**
*   **职责**：根据控制面板的输入，组合并呈现最终的结构化方案。它像一个“方案组装车间”，将不同的模板零件（结构、文案、提示）按照规则拼装起来。
*   **子模块**：每个生成的方案卡片，内部又分为结构、文案、视觉建议、排版细节等区块，清晰展示方案的全貌。

**输入 → 处理 → 输出 的逻辑链路：**
1.  **输入**：用户在左侧表单填写 `form` 对象中的所有数据（主题、平台、风格等）。
2.  **处理**：点击生成按钮后，`generateLayouts` 函数被触发。它根据 `form.platform` 选择对应的**版式结构模板**，根据 `form.style` 选择对应的**视觉提示**和**排版细节模板**，再结合用户输入的主题、关键词等，填充到**文案模板**中。
3.  **输出**：将上述处理好的模板数据组合成2-3个完整的 `layout` 对象，并渲染到右侧的卡片列表中。

**最值得学习的设计：**
**“模板化”的内容生成策略**。这是本页面的精髓。它没有使用复杂的AI，而是预先为不同平台和风格设计好了多套“零件”（结构数组、视觉提示数组等）。生成时，只是根据用户选择，像搭积木一样选取对应的零件进行组合。这种方法简单、可控、速度快，非常适合解决结构固定、需求明确的场景。对于初学者来说，理解这种“数据驱动UI”和“模板组合”的思想，比学习复杂的算法更有普适价值。

## 【四】Prompt / AI 逻辑是如何被设计的？

严格来说，这个页面**没有使用外部的AI或大语言模型(LLM)**。它内部实现的是一种 **“模拟AI”** 或 **“规则引擎”** 的逻辑。

1.  **Prompt 扮演的角色**：在本页中，用户的输入（主题、关键词等）可以被视为一种 **“内部Prompt”**。它们不是发送给ChatGPT的指令，而是用于填充本地预设模板的变量。
2.  **解决什么问题**：它解决的是 **“生成问题”**——根据有限的、结构化的输入，生成结构化的输出方案。但它解决问题的深度依赖于预设模板的丰富程度。
3.  **关键变量**：`form.topic`（主题）、`form.keywords`（关键词）、`form.platform`（平台）、`form.style`（风格）。这四个变量是选择不同模板和填充内容的核心依据。
4.  **如果只改“Prompt”（即模板数据），不改代码**：
    *   在 `structureTemplates` 里为“抖音”添加新的结构数组，就能支持新平台。
    *   在 `visualHints` 里为“赛博朋克”风格添加新的提示词数组，就能扩展风格库。
    *   在 `copyTemplates` 里修改文案的组合方式，就能改变生成的文案语气。
    *   **你会发现，页面的功能边界和智能程度，完全由这些内置的模板数据决定**。这是一种低代码、高灵活性的设计思路。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个安全的路径，逐步创建自己的工具：

**第一步：保持结构不变，替换使用场景（最安全）**
不要改动任何页面布局和JS函数结构。只修改文字和模板数据。
*   **目标**：做一个“短视频脚本结构生成器”。
*   **操作**：
    1.  将标题改为“短视频脚本结构生成器”。
    2.  将左侧“基础信息”的标签改为“视频主题”、“核心信息点”、“期望观众行动”。
    3.  将“目标平台”改为“抖音”、“B站”、“视频号”。
    4.  将“版式与风格偏好”改为“搞笑段子”、“知识科普”、“情感故事”。
    5.  在JS的 `structureTemplates` 对象中，为每个平台定义几种经典的视频节奏结构（如“黄金5秒开头+痛点阐述+解决方案展示+结尾互动”）。
    6.  在 `copyTemplates` 中，定义几种开场白、转场话术和结尾语的模板。
    7.  将右侧输出模块的标题改为“生成的脚本结构”，并将“版式结构”、“文案布局”等部分替换为“视频节奏”、“口播文案”、“画面建议”。

**第二步：调整输入字段或逻辑**
在第一步成功的基础上，增加或减少输入项。
*   **操作**：为“短视频脚本生成器”增加一个“视频时长”选项（如30秒、1分钟、3分钟），并在生成逻辑中，让 `structureTemplates` 根据时长选择更简略或更详细的结构模板。

**第三步：改变输出形式或展示方式**
当核心功能稳定后，优化展示效果。
*   **操作**：不再用纯文字列表描述“视频节奏”，而是用一条横向的时间轴来可视化展示“开头-发展-高潮-结尾”几个部分的时间占比和内容要点。

## 【六】3–5 个可直接尝试的改造方向

1.  **接入真实AI API，提升创意多样性**：
    *   **操作**：将 `generateLayouts` 函数中的模板组合逻辑，替换为调用 OpenAI GPT 或 文心一言 等模型的 API。将左侧表单数据构造成一个更灵活的Prompt（例如：“请为[主题]设计一个适合[平台]的[风格]海报，突出[关键词]，行动号召是[CTA]。请提供版式结构、文案和视觉建议。”）。
    *   **效果**：方案将不再受限于预设模板，每次生成都有新意，并能理解更复杂的用户指令。

2.  **增加“灵感库”或“案例参考”模块**：
    *   **操作**：在页面底部或侧边栏增加一个区域，预先存放一些优秀的、真实的海报案例截图或链接。每个案例可以打上“平台”和“风格”标签。当用户选择某个平台和风格时，高亮显示相关的案例。
    *   **效果**：为用户提供更直观的视觉参考，弥补纯文字结构描述的不足。

3.  **将输出方案可视化预览**：
    *   **操作**：在每个方案卡片上，增加一个“预览”按钮。点击后，利用HTML和CSS，在模态框或卡片内动态渲染一个简单的、基于当前方案描述的静态区块图（用不同颜色的`<div>`块代表标题区、图片区、按钮区）。
    *   **效果**：让抽象的文字结构立刻变得直观可视，用户体验大幅提升。

4.  **支持方案混合编辑与导出**：
    *   **操作**：允许用户点击不同方案中的某个部分（如A方案的标题+B方案的视觉建议）进行“混合”。提供一个“导出简报”功能，将最终选定的方案组合，生成一份格式优美的PDF或Markdown文档。
    *   **效果**：工具从一个灵感生成器，升级为一个简易的创意工作台，实用性更强。

5.  **拆分为多页面工作流**：
    *   **操作**：将当前单页面的功能拆解。第一页只负责“输入需求”，第二页展示“多个方案”让用户选择，第三页对“选定方案”进行细节微调和预览。
    *   **效果**：流程更清晰，适合更复杂、步骤更多的专业场景，也便于在每个步骤做更深入的引导。

## 【七】这个网页不适合做什么？（边界提醒）

-   **不适合生成最终设计稿**：它产出的是“设计说明书”，而不是“设计成品”。你不能指望它直接输出一张可用的JPG/PNG海报图片。
-   **不适合高度定制化的专业设计**：对于品牌视觉规范极其严格、需要特殊构图或艺术化表达的项目，这种基于通用模板的工具给出的建议会显得过于基础和泛化。
-   **不适合动态与交互设计**：它只考虑静态海报的版式。如果你需要设计网页、APP界面、或带有复杂动画的物料，这个工具的结构模板完全不适用。
-   **如果需要做它不适合的事**：
    *   生成最终图片：请使用 **Canva、Figma、Photoshop** 或 **AI绘画工具（如Midjourney + 具体描述）**。
    *   专业品牌设计：请寻求**专业设计师**或使用**品牌设计管理系统**。
    *   动态交互设计：请学习**UI/UX设计工具（Figma, Sketch）** 和**动效设计原理**。
