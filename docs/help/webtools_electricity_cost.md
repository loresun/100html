# 用电成本计算器 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你刚搬进新家，想估算一下每月电费开支。或者你正在考虑购买一台大功率电器（比如空调、电热水器），想知道它每天会消耗多少电费。这个网页就像一个“电费估算助手”，让你不用自己查公式、做计算，快速得到结果。

**适合情况：**
- 快速估算单一电器的耗电成本
- 比较不同电器或不同使用习惯下的电费差异
- 作为个人预算规划的小工具

**不适合情况：**
- 精确的电费账单计算（因为实际电费可能有阶梯电价、峰谷电价等复杂规则）
- 企业级或工业级的用电成本分析
- 需要长期跟踪和统计的用电管理

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你会看到几个输入框，通常包括：
- **电器功率**：单位是“瓦”（W），比如空调可能是1500W
- **使用时长**：单位是“小时”（h），比如每天用3小时
- **电价**：单位是“元/度”，比如0.6元一度电

**操作步骤：**
1. 在对应的输入框中填写数值
2. 点击“计算结果”按钮
3. 查看下方显示的计算结果

**输出结果长什么样？**
结果会以卡片形式展示，可能包括：
- **每日耗电量**：X度
- **每日电费**：Y元
- **每月电费**：Z元（按30天估算）

**容易忽略的细节：**
- 输入时要注意单位匹配（功率用瓦，不是千瓦）
- 电价要填写当地的实际电价，默认值可能不准确
- 计算结果只是估算，实际电费可能因季节、用电时段等有所不同

## 【三】核心结构拆解（学习重点）

这个网页采用了**模块化设计**，理解这个结构是学习的关键：

**1. 配置管理模块**
- **职责**：管理整个页面的工具配置和数据
- **位置**：`x-data="webtoolPage('electricity_cost')"` 初始化
- **作用**：根据传入的工具ID（如`electricity_cost`）加载对应的工具配置

**2. 工具类型分发模块**
- **职责**：根据工具类型显示不同的界面
- **位置**：多个`x-show="tool.type === 'xxx'"`部分
- **作用**：像一个大路由器，`formula`类型显示计算器，`timer`显示计时器，等等

**3. 输入-处理-输出链路**
```
用户输入 → Alpine.js数据绑定 → 计算函数处理 → 结果展示
```
- **输入**：通过`x-model`绑定到`tool.values`对象
- **处理**：`calculate(tool)`函数执行具体计算逻辑
- **输出**：结果写入`tool.result`，模板自动更新显示

**4. 最值得学习的设计**
**“配置驱动”的界面生成**：页面的字段、标签、单位都是通过配置对象动态生成的，而不是硬编码在HTML中。这意味着：
- 添加新工具只需修改配置，不改HTML
- 界面布局自动适应字段数量
- 代码复用性极高

## 【四】Prompt / AI 逻辑是如何被设计的？

**注意**：当前版本的用电成本计算器**没有使用AI功能**，它是一个纯计算工具。但页面预留了AI配置接口，我们可以分析其设计思路：

**Prompt的角色**（在AI工具中）：
- 解决“理解问题”：将用户输入转化为AI能处理的结构化请求
- 解决“生成问题”：指导AI按照特定格式输出结果

**关键变量设计**：
如果这是一个AI工具，Prompt中可能包含：
- 用户输入的数值（功率、时长、电价）
- 计算规则和公式
- 输出格式要求

**只改Prompt的效果**：
如果保持代码不变，只修改Prompt：
- 可以改变AI的“思考方式”（比如从估算改为精确计算）
- 可以调整输出的详细程度（简单结果 vs 详细分析）
- 可以添加新的分析维度（环保建议、省电技巧等）

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：替换使用场景（最安全）**
保持现有结构，创建一个新的计算工具，比如：
- **水费计算器**：用水量 × 水价
- **燃气费计算器**：用气量 × 燃气价
- **网费分摊计算器**：总网费 ÷ 使用人数

只需修改工具配置中的字段标签和计算公式。

**第二步：调整输入字段**
在现有基础上增减字段：
- 增加“使用天数”字段
- 增加“季节系数”（夏季用电多）
- 将单一电价改为“阶梯电价”多个输入

**第三步：改变输出形式**
- 将简单数字改为图表展示
- 添加对比功能（新旧电器对比）
- 增加“省电建议”文字输出

**从哪里下手最安全？**
从**修改配置对象**开始！在`standalone.js`中找到`electricity_cost`的配置，复制一份，修改字段和计算逻辑，这是风险最小的方式。

## 【六】3–5 个可直接尝试的改造方向

**1. 增加“电器库”选择功能**
- 预设常见电器及其功率（空调、冰箱、电视等）
- 用户选择电器后自动填充功率值
- 可以保存自定义电器

**2. 添加“多电器同时计算”**
- 允许添加多个电器条目
- 分别设置每个电器的使用时长
- 计算总耗电量和总电费

**3. 集成真实电价API**
- 调用电力公司API获取实时电价
- 根据用户位置自动匹配电价
- 显示峰谷电价差异

**4. 增加“省电模式”建议**
- 根据计算结果给出省电建议
- “如果每天少用1小时，每月可省X元”
- 推荐节能电器购买建议

**5. 数据可视化改造**
- 将月电费用柱状图展示
- 添加“电费占比”饼图（占月收入比例）
- 历史记录趋势图

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明：**

1. **不适合精确计费**
   - 没有考虑阶梯电价（用得越多单价越高）
   - 没有区分峰谷时段电价
   - 没有计算基础电费（有些地区有固定月租）

2. **不适合复杂场景**
   - 无法处理商业用电（三相电、功率因数等）
   - 不能计算光伏发电、储能系统的收益
   - 没有考虑电器待机功耗

3. **不适合专业分析**
   - 缺少历史数据对比
   - 没有能效等级分析
   - 无法生成专业报告

**如果用户想做X，应该换什么工具？**

- **想做精确的家庭电费管理** → 使用“网上国网”等电力公司官方APP
- **需要企业级用电分析** → 使用专业的能源管理系统（EMS）
- **想要长期用电习惯跟踪** → 使用智能插座配套的APP
- **需要复杂的节能方案设计** → 咨询专业的能源审计服务
