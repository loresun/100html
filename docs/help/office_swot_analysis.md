# SWOT 分析生成器 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你有一个新点子，比如“开一家宠物主题书店”或“开发一个帮助老年人使用手机的App”。你感觉这个想法不错，但不确定它是否真的可行，或者会遇到哪些挑战。自己一个人想，很容易漏掉关键点。

这个网页就像一个**随时在线的战略顾问**。你只需要简单描述你的想法，它就能在几秒钟内，帮你从四个关键维度（优势、劣势、机会、威胁）进行系统性的分析，并给出初步的战略建议。

*   **适合在什么情况下使用？**
    *   **头脑风暴初期**：快速评估一个初步想法的可行性。
    *   **项目启动前**：为你的商业计划书或项目提案补充一个结构化的分析框架。
    *   **个人决策**：比如评估“是否要换工作”、“是否要学习一门新技能”。
    *   **团队讨论**：生成一个基础分析报告，作为团队深入讨论的起点。

*   **不适合什么情况？**
    *   **需要精确数据和市场调研的深度报告**：AI的分析基于通用知识，无法获取最新的、特定行业的机密数据。
    *   **替代专业咨询**：对于涉及重大投资或法律风险的决策，仍需咨询人类专家。
    *   **动态、实时的竞争分析**：无法跟踪竞争对手每小时的变化。

## 【二】使用方式（给第一次接触的人）

1.  **准备输入**：在页面中央的大输入框里，用一句话描述你的项目或想法。例如：“在大学城开一家24小时自习室”或“做一个AI辅助的旅行规划工具”。
2.  **配置API（首次使用必需）**：点击右上角的“设置”按钮。在弹出的窗口中，输入你的DeepSeek API Key（你需要先在DeepSeek官网注册并获取），然后点击“保存”。
3.  **开始分析**：点击“开始分析”按钮。页面会显示加载动画，表示AI正在思考。
4.  **查看结果**：稍等片刻，页面下方会展开一个清晰的四象限矩阵：
    *   **优势 (绿色)**：你的想法内在的有利条件。
    *   **劣势 (红色)**：你的想法内在的不利条件。
    *   **机会 (蓝色)**：外部环境中可以利用的有利趋势。
    *   **威胁 (橙色)**：外部环境中可能构成风险的因素。
    *   矩阵下方还会提供一段**核心战略建议**，帮助你综合看待这四个方面。

*   **输出结果长什么样？**
    结果以视觉化的卡片形式呈现，每个象限一个卡片，配有醒目的颜色和图标。内容是以要点列表的形式展示，清晰易读。

*   **容易忽略的使用细节：**
    *   **模型切换**：页面右上角有“V3”和“R1”两个按钮。V3速度更快，适合快速生成；R1思考更深，适合复杂想法，但速度稍慢且可能更贵。你可以根据需求切换。
    *   **错误提示**：如果分析失败，页面顶部会出现一个红色的错误提示框，里面会有具体原因（如API Key错误、网络问题等），这是排查问题的关键。
    *   **数据保存**：你输入的API Key和选择的模型会保存在浏览器的本地存储中，下次打开页面无需重新配置。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块，它们像流水线一样工作：

1.  **配置与输入模块**
    *   **职责**：获取用户最核心的两样东西——**API访问权限**和**待分析的项目描述**。
    *   **包含**：右上角的“设置”弹窗（用于配置API Key和模型）、页面中央的输入框和“开始分析”按钮。
    *   **逻辑**：用户配置 → 输入想法 → 触发分析。

2.  **AI处理与通信模块（大脑）**
    *   **职责**：这是页面的“隐形引擎”。它负责将用户的输入打包成一个AI能理解的指令（Prompt），并通过网络发送给DeepSeek的AI模型，最后把AI返回的杂乱文本整理成干净的数据。
    *   **包含**：`generateSWOT`函数中的`prompt`变量和`fetch`网络请求代码。
    *   **逻辑**：拼接Prompt → 发送API请求 → 接收响应 → 清洗数据（去除Markdown标记）→ 解析为JSON对象。

3.  **结果展示模块**
    *   **职责**：将AI处理后的结构化数据，以美观、直观的方式呈现给用户。
    *   **包含**：SWOT四象限网格（`.swot-grid`）和底部的“核心战略建议”卡片。
    *   **逻辑**：接收JSON数据 → 用`v-for`循环将数组渲染成列表项 → 根据不同的象限应用不同的颜色和图标。

*   **最值得学习的设计：**
    **“Prompt工程 + 结构化输出”的完整闭环**。这个页面没有让AI自由发挥写一篇文章，而是通过精心设计的Prompt，严格约束AI输出一个格式固定的JSON对象。前端代码再把这个JSON对象直接映射到页面上。这种设计使得**AI成为了一个可控的、可编程的数据服务**，而不是一个黑盒聊天机器人。这是将AI能力产品化的一个经典模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt扮演的角色**：它扮演了**指令官**和**格式规范员**的双重角色。它首先告诉AI“你是谁”（战略专家），然后告诉AI“做什么”（对特定项目做SWOT分析），最后严格规定“输出格式”（必须是一个特定结构的JSON）。
*   **解决什么问题**：它主要解决的是**“生成问题”**——生成一个符合SWOT框架的分析。但它也部分解决了“理解问题”，因为它将用户模糊的项目描述，引导至一个专业的分析框架下去理解。
*   **关键变量**：Prompt中只有一个关键变量：`“${project.value}”`。这是用户输入的项目描述，被动态插入到固定的Prompt模板中。
*   **如果只改Prompt，不改代码，会发生什么？**
    *   **改变分析框架**：你可以把Prompt里的“SWOT分析”改成“PEST分析”（政治、经济、社会、技术），AI就会从这四个维度输出分析，但页面展示的还是SWOT的四块，看起来会牛头不对马嘴。
    *   **改变输出结构**：如果你在Prompt的JSON模板里增加一个字段，比如 `“riskLevel”: “高/中/低”`，AI会在JSON里返回这个字段，但页面上不会显示它，因为前端没有为这个字段设计展示位置。
    *   **改变分析风格**：你可以修改Prompt开头的描述，如“你是一个挑剔的风险投资家…”，AI会以更苛刻、更关注投资回报的角度进行分析，从而改变生成内容的角度和语气。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的AI工具：

1.  **第一步：替换核心场景与框架（最安全）**
    *   **做什么**：保持所有代码结构完全不变。只修改两处文字：① 页面标题和说明；② Prompt中的分析框架。
    *   **例如**：做一个“个人职业规划建议器”。把标题改成“职业规划AI助手”，把Prompt中的“SWOT分析”和JSON字段名改成 `“skills“（现有技能）, “gaps“（能力缺口）, “marketDemand“（市场需求）, “learningPath“（学习路径）`。这样，你就得到了一个全新主题的工具。

2.  **第二步：调整输入与输出展示**
    *   **做什么**：根据你的新场景，增加或修改输入项。同时，调整结果展示模块的布局和样式，以匹配新的数据结构。
    *   **例如**：在“职业规划器”中，除了“当前职位”输入框，可以增加一个“目标行业”下拉选择框。然后，将四象限展示改为一个时间轴或技能雷达图的展示方式（这需要引入新的图表库）。

3.  **第三步：升级交互与功能**
    *   **做什么**：在基础功能跑通后，增加更高级的交互。例如，允许用户对AI生成的结果进行编辑、保存为图片、或者基于某一条建议进行更深度的追问。
    *   **例如**：在每个生成的建议旁边加一个“深入探讨”按钮，点击后会用该建议作为新的Prompt，让AI展开详细说明。

**从哪里下手最安全？** **从第一步开始。** 只修改文字和Prompt，不碰代码逻辑和页面结构。你能立即看到一个完全不同主题的应用跑起来，这会给你巨大的信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加上下文输入，让分析更精准**：
    *   **操作**：在输入框下方增加几个可选填的文本框，如“目标用户”、“所在城市”、“预算规模”。将这些信息也加入到Prompt中，例如：`请结合[目标用户]和[所在城市]的市场情况，对项目“${project}”进行分析…`
    *   **效果**：AI的分析将更具针对性，减少泛泛而谈。

2.  **切换或融合多个AI模型/API**：
    *   **操作**：在设置弹窗中，增加一个“API服务商”下拉菜单，选项包括DeepSeek、OpenAI、智谱AI等。根据选择，动态修改代码中`fetch`请求的URL和请求头。
    *   **效果**：用户可以灵活选择自己拥有密钥或更偏好的模型，也能对比不同模型的分析结果差异。

3.  **将单次分析扩展为多轮对话**：
    *   **操作**：在生成的结果卡片上，为每一个“优势”、“劣势”等条目添加一个“？”图标。点击后，在当前页面下方或侧边栏展开一个聊天区域，自动发送一条Prompt如：“请详细解释一下，为什么‘[点击的条目内容]’是该项目的一个优势？并给出一个具体案例。”
    *   **效果**：工具从一个“分析报告生成器”升级为一个“战略分析顾问”，互动性大大增强。

4.  **优化结果的可共享性与持久化**：
    *   **操作**：在结果区域顶部添加“保存本次分析”、“生成分享链接”、“导出为图片”按钮。利用浏览器本地存储保存历史记录，或生成一个包含加密数据的URL。
    *   **效果**：分析结果可以保存、分享给团队成员，方便后续讨论和回顾。

5.  **增加示例库和引导**：
    *   **操作**：在输入框下方或旁边，增加一个“看看例子”的链接。点击后弹出几个经典案例（如“特斯拉进入中国市场”、“某网红奶茶店扩张”），用户可以直接点击案例填入输入框。
    *   **效果**：降低新用户的使用门槛，让他们快速理解工具的能力和输入格式。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精确的财务预测或市场数据查询**：AI不知道某条街具体的租金，也无法给出精确的“每月潜在客户数”。它提供的是基于通用知识的逻辑推演和常见模式识别。
*   **不适合处理高度敏感或机密信息**：虽然API调用是加密的，但将你的核心商业机密输入到一个第三方AI模型中，始终存在潜在风险。切勿输入未公开的专利细节、核心客户名单等。
*   **不适合替代人类的核心决策**：这个工具输出的是一份“草稿”或“清单”，它的价值在于启发思考和查漏补缺。最终的判断、权衡和决策，必须由你自己或你的团队来完成。AI无法为你承担决策的责任。
*   **如果用户需要的是**：包含真实数据图表、详细竞品对比、法律政策解读的**正式商业计划书**，那么应该使用专业的市场调研工具、咨询公司服务，并亲自进行大量的数据收集和分析工作。本工具可以作为这项工作的**起点**，但绝非**终点**。
