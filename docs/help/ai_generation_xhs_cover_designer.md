# 小红书封面设计器 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你是一个小红书博主、内容创作者或电商运营。你需要为你的笔记、商品或活动制作一个吸引眼球的封面图。你不想花时间学习复杂的专业设计软件（如PS），但又希望封面能快速、美观地完成，最好还能有一些“爆款”灵感。这个工具就是为你准备的。

*   **适合什么情况？**
    *   快速制作社交媒体（小红书、朋友圈等）的封面图。
    *   需要AI提供文案灵感，打破创作瓶颈。
    *   希望在线编辑，无需安装软件，操作直观。
    *   对设计有一定要求，但不想从头开始。

*   **不适合什么情况？**
    *   需要制作印刷级精度的海报或物料。
    *   需要处理复杂的图层、滤镜或特效。
    *   需要团队协作或版本管理。
    *   对图片的最终文件大小、格式有非常专业的要求。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **主题描述**：在左侧“AI灵感”面板的文本框中，输入你想制作封面的主题，如“露营装备开箱”。
    *   **设计元素**：通过点击按钮，添加预设的文字、形状。
    *   **背景**：选择纯色或上传自己的图片作为背景。
    *   **编辑操作**：在画布上直接点击、拖拽、缩放任何元素；选中后，在右侧面板修改其颜色、字体、大小等属性。

2.  **用户通常会做哪几步操作？**
    1.  **获取灵感**：在“AI灵感”面板输入主题，点击“生成爆款标题”，从AI给出的结果中选择一个喜欢的，点击它即可添加到画布中央。
    2.  **搭建框架**：切换到“文字 & 素材”面板，点击“大标题”、“副标题”等按钮，添加更多文字层级。点击形状按钮添加装饰。
    3.  **美化背景**：切换到“背景”面板，选择一个预设颜色，或上传一张精美的图片作为背景。
    4.  **精细调整**：在画布上选中任意元素，在右侧“属性编辑”面板中修改其内容、颜色、字体、阴影等，直到满意。
    5.  **导出成品**：点击顶部导航栏的红色“导出封面”按钮，一张高清的PNG图片就会下载到你的电脑中。

3.  **输出结果长什么样？**
    导出的是一张**3:4比例**、高清的PNG图片，尺寸为900x1200像素（内部画布450x600，导出时放大2倍以保证清晰度）。图片内容就是你最终在画布上看到的设计。

4.  **有哪些容易忽略的使用细节？**
    *   **首次使用需配置API**：要使用AI生成标题功能，必须先点击顶部导航栏的“设置”按钮（齿轮图标），填入你的DeepSeek API Key。
    *   **画布缩放**：画布右下角有缩放控制按钮（+/-），可以放大查看细节或缩小看整体效果，这**不会**影响最终导出图片的质量。
    *   **元素层级**：当多个元素重叠时，可以在右侧属性面板使用“上移一层/下移一层”来调整前后关系。
    *   **直接编辑文字**：在画布上**双击**文字，可以直接进入编辑模式修改内容。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个核心模块，像一个在线设计工作室：

1.  **导航与控制模块（顶部）**
    *   **职责**：提供全局功能入口（返回、设置、导出）和状态显示（AI模型选择）。
    *   **逻辑**：用户在这里进行最终操作（导出）和全局配置。

2.  **素材与灵感库（左侧面板）**
    *   **职责**：作为“工具箱”和“灵感源泉”。分为三个标签页：
        *   **AI灵感**：负责接收用户主题，调用AI API，并将生成的文案列表展示给用户选择。
        *   **文字 & 素材**：提供预设的文本模板（大标题、副标题）和基础几何形状，用户一键添加。
        *   **背景**：管理画布的底色和背景图片。
    *   **逻辑**：`用户选择/输入` → `模块处理（如调用AI）` → `生成可添加至画布的元素`。

3.  **设计与预览区（中间画布）**
    *   **职责**：这是设计的“主舞台”。使用 **Fabric.js** 这个强大的Canvas库来承载所有可视化元素（文字、形状、图片），并处理所有交互（选中、拖拽、缩放、旋转）。
    *   **逻辑**：接收来自左侧面板的新元素，或响应用户在画布上的直接操作，实时渲染出视觉结果。

4.  **属性编辑器（右侧面板）**
    *   **职责**：这是一个“上下文菜单”。当用户在画布上选中某个元素时，此面板动态显示该元素的所有可编辑属性（如文字内容、颜色、字体）。
    *   **逻辑**：`画布选中事件` → `同步选中对象的属性到面板` → `用户在面板修改` → `实时同步修改回画布对象`。

**最值得学习的设计：**
**“状态同步”与“职责分离”**。整个应用的核心是中间那个Fabric.js画布对象。左侧面板和右侧面板都不直接操作DOM来改变外观，而是通过调用画布对象的方法（如 `add()`, `set()`) 来增删改元素。画布的任何变化（如选中状态）又会通过事件监听，同步更新到Vue的响应式数据中，从而驱动右侧面板的显示。这种**以Canvas绘图库为核心，用Vue管理界面状态**的模式，是构建此类可视化编辑工具的经典架构。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色**：在这里，Prompt是**内容生成器**。它不是一个聊天助手，而是一个专门为“生成小红书爆款标题”这个垂直任务定制的指令模板。
2.  **解决的问题**：它主要解决**“生成问题”**。当用户缺乏文案灵感时，AI根据Prompt的指引，将模糊的“主题”转化为具体、有吸引力的标题选项。
3.  **关键变量**：
    *   **系统指令**：`“你是一个小红书爆款文案专家...生成5个极具吸引力的封面大标题。要求：简短有力（8字以内）、带情绪、有冲击力、包含痛点或爽点。只返回纯文本列表，每行一个。”` 这定义了AI的角色、任务、格式和风格。
    *   **用户输入**：`aiPrompt.value`（如“夏季防晒测评”）。这是变量部分，被插入到对话中。
4.  **如果只改Prompt，不改代码**：
    *   你可以彻底改变这个工具的功能。例如，将系统指令改为“你是一个菜谱作家...”，用户输入“西红柿”，那么生成的结果就会从“防晒标题”变成“西红柿创意菜名”。
    *   你可以调整生成风格。例如，把要求改成“温柔治愈的10字以内文案”，AI输出的语调就会完全不同。
    *   代码无需改动，工具就从“封面设计器”变成了“文案灵感生成器”或“菜名生成器”，但前端界面依然通用。

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

1.  **第一步：替换场景，保持骨架**
    *   **最安全的起点**：不要动核心的Canvas和Vue逻辑。
    *   **做什么**：把“小红书封面”这个主题换成你的目标，比如“**微信公众号头图设计器**”、“**电商Banner制作工具**”或“**个人简历头像装饰器**”。
    *   **具体操作**：修改页面标题、Logo、预设文字模板（把“大标题”改成“文章标题”、“商品卖点”等）、预设背景颜色（换成你目标场景的常用色系）。

2.  **第二步：改造输入与Prompt**
    *   **做什么**：根据新场景，调整左侧“AI灵感”面板的功能。
    *   **具体操作**：
        *   修改文本框的提示语，如从“输入封面主题”改为“输入文章核心观点”。
        *   **关键**：重写API调用中的 **System Prompt**。如果你的新工具是生成“金句”，Prompt就改为“你是一个哲学家，请根据用户主题生成3句富有哲理的短句...”。
        *   调整生成结果的默认样式（`addText`函数里的`fontSize`, `fill`等参数），使其更符合新场景的审美。

3.  **第三步：定制输出与交互**
    *   **做什么**：改变画布规格和导出设置。
    *   **具体操作**：
        *   修改 `initCanvas` 函数中的 `width` 和 `height`。公众号头图可能是900x383，Banner可能是1200x400。
        *   在“背景”面板增加更多符合新场景的预设模板，比如“渐变背景”、“纹理背景”。
        *   在“文字 & 素材”面板添加新形状或图标（如箭头、对话框），这需要学习一点Fabric.js的图形API。

完成这三步，你就拥有了一个属于你自己的、功能完整的在线设计工具雏形。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“模板”功能**：
    *   **操作**：在左侧面板新增一个“模板”标签页。里面放置几个预先用代码设计好的完整封面（例如，设置好背景、标题位置和样式的JSON数据）。用户点击即可一键加载到画布，然后只需修改文字内容。
    *   **价值**：极大提升零基础用户的制作速度，是工具产品化的关键一步。

2.  **接入文生图API，生成背景**：
    *   **操作**：在“背景”面板增加一个“AI生成背景”按钮。调用如DALL-E、Stable Diffusion的API，根据用户输入的主题词（如“夏日海滩”、“科技感线条”）生成一张背景图，并自动设置为画布背景。
    *   **价值**：将AI能力从“文案”扩展到“视觉”，实现真正的AI辅助设计。

3.  **增加“历史记录”与“撤销/重做”**：
    *   **操作**：利用Fabric.js的序列化能力（`canvas.toJSON()`），在用户每次操作后，将当前画布状态保存到一个数组里。然后提供“撤销”、“重做”按钮，点击时从数组中恢复对应的画布状态（`canvas.loadFromJSON()`）。
    *   **价值**：这是专业设计工具的必备功能，能有效防止误操作，提升用户体验。

4.  **拆分为“创作”与“管理”页面**：
    *   **操作**：将当前页面作为“编辑页”。再创建一个“作品库”页面，使用 `localStorage` 或 `IndexedDB` 保存用户的作品（即画布的JSON数据），并展示为缩略图列表。用户可以打开旧作品继续编辑。
    *   **价值**：让工具从一个单次使用的页面，升级为一个有数据沉淀的轻量级应用。

5.  **优化属性面板，增加“样式预设”**：
    *   **操作**：在右侧属性面板中，为文字增加“样式预设”按钮，如“霓虹灯效果”、“金属质感”、“毛笔字”。点击后，自动组合设置文字的`fill`、`stroke`、`shadow`等属性。
    *   **价值**：降低用户调出高级效果的难度，让设计更“傻瓜化”。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做复杂的图像处理**：它无法进行抠图、磨皮、调色、添加复杂滤镜等操作。如果需要，你应该使用 **Photoshop、Canva 或 Photopea** 等专业或半专业图像处理工具。
*   **不适合做矢量图形编辑**：虽然可以画基础形状，但无法进行锚点编辑、路径运算等矢量操作。这类需求应使用 **Figma、Adobe Illustrator** 或 **Inkscape**。
*   **不适合做动画或交互式内容**：它导出的是静态图片。如果需要制作动态封面（如GIF）或可交互的H5页面，你需要学习 **CSS动画、Lottie或专业的动画工具**。
*   **不适合无网络环境使用**：它的AI功能严重依赖API调用。如果需要在完全离线的环境下工作，你需要移除AI模块，或者寻找可以本地部署的AI模型方案。
