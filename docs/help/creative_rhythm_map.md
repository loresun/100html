# 生活节奏地图 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你想要回顾自己一天的状态起伏，但不知道如何从零散的时间记录中看出规律时，这个工具能帮你把“感觉”变成“图表”，再用AI帮你分析。

**适合情况**：
- 想了解自己一天中精力变化的规律
- 需要简单记录工作/学习节奏
- 希望获得关于时间安排的客观反馈
- 想用可视化方式追踪状态变化

**不适合情况**：
- 需要精确到分钟的时间管理（如番茄钟）
- 需要团队协作或分享数据
- 需要长期历史数据对比分析
- 涉及隐私敏感信息的详细记录

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本输入框，默认有三行示例
- 每行格式：`时间, 事件描述, 能量值(1-10)`
- 例如：`14:30, 团队会议, 7`

**用户通常会做哪几步操作？**
1. **输入数据**：在左侧文本框中按格式写下你一天的关键时刻
2. **生成图表**：点击“生成节奏图”按钮，右侧会显示能量变化曲线
3. **获取解读**：点击“AI 解读”按钮，等待AI分析你的节奏
4. **配置API**：首次使用需要点击右上角设置图标，输入DeepSeek API Key

**输出结果长什么样？**
- **左侧**：一个平滑的折线图，X轴是时间，Y轴是能量值（1-10）
- **右侧**：AI生成的文字分析，包含三个部分：
  1. 能量高峰和低谷总结
  2. 两个可调整的建议点
  3. 一句鼓励的话

**容易忽略的使用细节：**
1. **格式必须正确**：逗号是英文逗号，时间、事件、能量值之间用逗号分隔
2. **能量值是数字**：必须是1-10之间的整数，AI会据此分析
3. **需要API Key**：第一次使用“AI 解读”前，必须先配置API
4. **数据不会保存**：刷新页面后输入的内容会丢失（除非你复制保存）

## 【三】核心结构拆解（学习重点）

**页面由四个关键模块组成：**

1. **输入与图表模块**（左侧卡片）
   - **职责**：接收用户输入、验证格式、绘制可视化图表
   - **输入** → 用户按格式输入文本
   - **处理** → 解析文本为结构化数据 → 用Chart.js绘制折线图
   - **输出** → 显示能量变化曲线

2. **AI解读模块**（右侧卡片）
   - **职责**：调用AI API、展示分析结果
   - **输入** → 结构化的事件数据
   - **处理** → 构建Prompt → 调用DeepSeek API → 接收响应
   - **输出** → 格式化的文字建议

3. **配置模块**（设置弹窗）
   - **职责**：管理API配置、持久化存储
   - **输入** → 用户输入的API Key和模型选择
   - **处理** → 保存到浏览器localStorage
   - **输出** → 配置信息供API调用使用

4. **UI装饰模块**（图标、样式、布局）
   - **职责**：提供美观的视觉体验
   - 使用Tailwind CSS + 毛玻璃效果
   - Lucide图标库提供简洁图标

**最值得学习的设计：**
- **“输入-处理-展示”的清晰分离**：数据流非常明确，每个模块职责单一
- **即时的视觉反馈**：输入后立即能看到图表，符合“所见即所得”原则
- **配置与使用的解耦**：API配置独立存储，不影响核心功能逻辑

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色：**
Prompt是“翻译官”，它把结构化的数据（时间、事件、能量值）转换成AI能理解的分析任务。

**解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。AI不需要“理解”复杂的人类情感，而是按照明确的指令格式，基于数值规律生成结构化的建议。

**Prompt中的关键变量：**
```javascript
const prompt = `以下是用户一天的节奏记录（时间/事件/能量1-10）：
${数据行}

请输出：
1. 能量波峰/低谷总结
2. 适合调整的两个点
3. 一句鼓励。
控制在 120 字以内。`;
```
- **数据行**：用户输入的具体事件
- **输出格式**：明确的三个部分要求
- **字数限制**：控制输出长度

**如果只改Prompt，不改代码，会发生什么变化？**
- 改**输出格式要求** → AI会按新格式组织回答
- 改**分析角度**（如“从工作效率角度分析”） → AI会调整分析重点
- 改**字数限制** → 回答会变长或变短
- 改**语气设定**（系统提示） → AI会改变教练风格

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 把“生活节奏”换成“学习专注度”、“运动强度”、“情绪变化”
- 只改文字描述（标题、说明文字），不动代码结构
- 示例：改成“学习专注地图”，能量值改为“专注度(1-10)”

**第二步：调整输入字段或Prompt**
- 增加/减少输入字段：比如增加“地点”或“同伴”
- 修改Prompt的分析角度：让AI从不同维度分析
- 示例：分析学习节奏时，Prompt可以要求“找出最佳学习时间段”

**第三步：改变输出形式或展示方式**
- 图表类型：把折线图改成柱状图、雷达图
- 展示布局：把左右布局改成上下布局
- 交互方式：增加点击图表点查看详情的功能

**从哪里下手最安全？**
从**修改文字和Prompt**开始最安全，因为：
1. 不会破坏现有功能
2. 立即能看到效果变化
3. 不需要懂复杂的JavaScript

## 【六】3–5个可直接尝试的改造方向

**1. 增加分类标签输入**
- 在每行数据后增加一个分类字段，如“工作/生活/休息”
- 在图表上用不同颜色区分分类
- AI分析时可以按类别给出建议

**2. 换成其他模型或API**
- 将DeepSeek换成OpenAI GPT、Claude或国内其他大模型
- 只需修改`callLLM`函数中的API端点、headers和body格式
- 可以增加模型选择，让用户自由切换

**3. 拆分成“记录”和“分析”两个页面**
- 页面一：专注数据输入和日常记录
- 页面二：查看历史图表和AI分析
- 用localStorage或简单后端存储多日数据

**4. 优化交互体验**
- 增加“示例数据”按钮，一键填充不同类型示例
- 实现图表点的悬停提示，显示完整事件信息
- 添加“导出图片”功能，保存图表为图片
- 增加数据验证的实时提示（格式错误时立即提示）

**5. 增加对比功能**
- 允许输入两天的数据，用双折线图对比
- AI分析两天的差异和改进点
- 示例：“今天 vs 昨天”的能量变化对比

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不适合做精确的时间管理**
   - 它记录的是“关键点”而非“完整时间线”
   - 如果你需要精确的“时间块”管理，应该用专门的番茄钟或日历工具

2. **不适合长期数据追踪**
   - 数据只存在当前页面，刷新就丢失
   - 如果需要月度/年度报告，应该用电子表格或专业习惯追踪App

3. **不适合深度心理分析**
   - AI分析基于简单的数值规律，不是专业心理咨询
   - 如果涉及情绪困扰或心理健康问题，请寻求专业帮助

4. **不适合团队或共享使用**
   - 没有用户系统，没有数据共享功能
   - 如果需要团队节奏同步，应该用协作工具如Notion、Trello

5. **不适合处理复杂数据**
   - 只能处理“时间,事件,数值”这种简单格式
   - 如果需要多维度分析（如地点、人物、工具），需要更复杂的数据结构

**如果用户想做X，应该换什么工具：**
- 想做**详细时间记录** → 用“时间块”、“番茄Todo”
- 想做**长期习惯追踪** → 用“习惯清单”、“Loop Habit Tracker”
- 想做**团队节奏同步** → 用“Notion日历”、“Google Calendar”
- 想做**专业状态分析** → 咨询时间管理教练或使用专业分析工具

---

**最后提醒**：这个网页的核心价值在于“简单问题 + 清晰可视化 + AI辅助解读”的组合。学习时，重点理解这种“小切口、深挖掘”的设计思路，而不是追求功能的复杂性。
