# 习惯连续天数工具 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你想要养成一个新习惯（比如每天阅读、运动、早起），但总是坚持几天就中断时，这个工具能帮你清晰地看到自己的“连续坚持天数”。它就像一个简单的习惯打卡器，让你直观地了解自己的坚持情况。

**适合情况**：
- 个人习惯养成（健身、学习、早睡等）
- 短期目标追踪（21天挑战、30天计划）
- 需要可视化反馈的简单习惯管理

**不适合情况**：
- 需要团队协作的习惯打卡
- 复杂的习惯数据统计（如频率分析、趋势图表）
- 需要提醒功能的习惯管理
- 长期（超过一年）的习惯追踪

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 习惯名称（比如“每天跑步”）
- 开始日期（你从哪天开始坚持的）
- 今天是否完成了这个习惯（通过勾选完成状态）

**用户通常会做哪几步操作？**
1. 进入页面后，在“习惯名称”输入框中填写你的习惯
2. 在“开始日期”选择你开始坚持的日期
3. 每天回到这个页面，勾选“今日已完成”的复选框
4. 页面会自动计算并显示你已经连续坚持了多少天

**输出结果长什么样？**
- 一个醒目的数字显示“连续天数”
- 可能还会有一些鼓励性的文字提示
- 如果中断了，连续天数会重置为0

**有哪些容易忽略的使用细节？**
- 日期选择器可能默认是今天，记得改成你实际开始的日期
- 如果某天忘记打卡，第二天再打卡时连续天数可能不会正确累积
- 数据通常保存在浏览器本地，换设备或清除缓存后记录会丢失

## 【三】核心结构拆解（学习重点）

这个页面采用了**模块化设计**，主要分为：

**1. 配置模块（顶部）**
- 职责：让用户设置习惯的基本信息
- 包含：习惯名称输入框、开始日期选择器

**2. 打卡模块（中部）**
- 职责：记录每日完成情况
- 包含：完成状态复选框、打卡按钮

**3. 展示模块（下部）**
- 职责：显示统计结果和反馈
- 包含：连续天数显示、鼓励文字、历史记录

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入习惯信息 → 每日打卡记录 → 系统计算连续天数 → 显示结果和反馈
```

**最值得学习的设计：**
- **状态持久化**：使用浏览器本地存储保存习惯数据，页面刷新后数据不丢失
- **自动计算逻辑**：根据打卡记录自动计算连续天数，包括处理中断情况
- **极简交互**：整个工具只有一个主要操作（打卡），降低使用门槛

## 【四】Prompt / AI 逻辑是如何被设计的？

**注意**：从提供的代码看，这个页面目前**没有使用AI功能**。它是一个纯前端计算工具。

**如果未来要加入AI，可能会这样设计：**
- **Prompt角色**：分析用户的坚持模式，给出个性化建议
- **解决的问题**：理解“为什么用户会中断”并生成“如何改进”的建议
- **关键变量**：用户的坚持历史、中断模式、习惯类型
- **只改Prompt的效果**：改变AI反馈的语气、建议的侧重点、鼓励的方式

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 将“习惯打卡”改为其他需要每日记录的场景
- 例如：每日心情记录、每日饮水记录、每日学习时长记录
- 只需修改文字标签，不改变代码结构

**第二步：调整输入字段**
- 增加或减少输入项
- 例如：心情记录可以增加“心情描述”文本框
- 饮水记录可以增加“饮水量”数字输入
- 修改对应的数据存储字段即可

**第三步：改变计算逻辑**
- 修改连续天数的计算方式
- 例如：心情记录可以计算“连续开心天数”
- 饮水记录可以计算“连续达标天数”
- 只需修改`calculateStreak()`函数

**第四步：改变展示方式**
- 修改结果显示的样式
- 例如：用表情符号代替数字
- 用进度条代替文字提示
- 修改HTML模板和CSS样式

**从哪里下手最安全？**
从**修改文字内容**开始最安全，比如把“习惯名称”改成“项目名称”，把“连续天数”改成“持续天数”。这样不会破坏原有逻辑。

## 【六】3–5 个可直接尝试的改造方向

**1. 增加“目标天数”功能**
- 在配置模块增加“目标连续天数”输入框
- 在展示模块增加进度条，显示“当前/目标”
- 当达到目标时显示庆祝动画

**2. 添加“中断原因”记录**
- 当用户某天没有打卡时，弹出选择框询问原因
- 原因选项：太忙、忘记、不想做、其他
- 在历史记录中显示中断原因，帮助用户分析

**3. 实现“周视图/月视图”**
- 增加日历视图，直观显示哪些天打卡了
- 用不同颜色标记：完成、中断、未到日期
- 帮助用户看到自己的坚持模式

**4. 添加“成就系统”**
- 设置里程碑：连续7天、21天、30天等
- 达到里程碑时显示成就徽章
- 增加分享功能，让用户分享成就

**5. 本地数据导出/导入**
- 增加“导出数据”按钮，生成JSON文件
- 增加“导入数据”功能，从文件恢复记录
- 防止因清除浏览器数据导致记录丢失

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不适合复杂习惯管理**：只能记录“做/没做”，不能记录“做了多少”、“质量如何”
2. **没有提醒功能**：完全依赖用户主动打开页面打卡
3. **没有社交功能**：无法和朋友一起打卡、互相监督
4. **数据分析有限**：只能看到连续天数，没有趋势分析、统计图表

**如果用户想做以下事情，应该换工具：**
- **想要详细数据分析** → 使用专业习惯追踪App（如Habitica、Loop）
- **需要团队协作打卡** → 使用共享文档或专门团队应用
- **需要智能提醒** → 使用手机日历或待办事项应用
- **需要长期复杂记录** → 使用电子表格或数据库应用
