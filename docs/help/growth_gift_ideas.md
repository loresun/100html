# 送礼指南针 - AI 选礼专家 · 帮助与学习文档

---

## 【一】这个网页解决了什么问题？

**使用场景：**
当你需要为特定的人挑选一份合适的礼物，但又缺乏灵感、不了解对方喜好，或者担心礼物不合时宜时，这个工具可以帮你。它就像一个懂人情世故的“送礼参谋”，根据你提供的基本信息（如关系、预算、场合），快速生成一份个性化的礼物清单，并附上推荐理由和贺卡词。

**适合情况：**
- 为生日、纪念日、节日等特定场合选礼。
- 对收礼人的喜好了解有限，需要拓宽思路。
- 希望礼物能体现出用心和思考，而非随意购买。
- 预算有限，需要找到性价比高或意义非凡的选项。

**不适合情况：**
- 需要购买实物商品并直接下单（它只提供建议，不涉及购买）。
- 对礼物有非常具体、专业的要求（如特定型号的电子产品）。
- 收礼人的情况极其复杂，需要深度、长时间的沟通才能理解。

## 【二】使用方式（给第一次接触的人）

**1. 页面输入是什么？**
你需要填写或选择四个关键信息：
- **送给谁？**：从预设关系中选择（如女友/老婆、父母长辈等）。
- **预算区间**：选择你能接受的价格范围。
- **送礼场合**：填写具体的场合，如“生日”、“升职庆祝”。
- **更多信息**：填写收礼人的兴趣、爱好或明确不喜欢的物品（雷点）。

**2. 用户通常会做哪几步操作？**
- **第一步**：首次使用需点击右上角齿轮图标，在弹窗中输入你的 DeepSeek API Key 并保存。
- **第二步**：在左侧“收礼人画像”区域，依次选择或填写上述四项信息。
- **第三步**：点击“✨ 开启灵感指南”按钮。
- **第四步**：等待几秒钟，右侧区域会生成并展示礼物推荐列表。

**3. 输出结果长什么样？**
右侧会显示一个礼物卡片列表。每张卡片包含：
- **礼物名称和编号**（如 #1 星空投影灯）
- **礼物分类标签**（如“家居好物”）
- **推荐理由**：一段文字，解释为什么这个礼物适合该收礼人和场合。
- **搭配贺卡词**：一句可以直接写在贺卡上的温馨话语。

**4. 有哪些容易忽略的使用细节？**
- **API Key 是必须的**：不配置就无法使用，这是调用 AI 能力的“钥匙”。
- **“更多信息”是点睛之笔**：这里填写的信息越具体（如“她最近在学油画”、“他对香水过敏”），生成的推荐就越精准。
- **错误日志**：如果生成失败，页面顶部会出现一个红色错误区域，里面包含了技术原因，方便排查问题（如 API Key 错误、网络问题）。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

**1. 用户输入与配置模块**
- **职责**：收集用户需求（收礼人信息）和系统配置（API Key）。
- **组成**：左侧的表单区域 + 右上角的设置弹窗。
- **逻辑**：用户填写信息 → 信息被存储在 Vue 的响应式变量中 → 点击按钮触发后续动作。

**2. AI 处理与通信模块**
- **职责**：将用户输入打包成 AI 能理解的指令（Prompt），并调用外部 AI API 获取结果。
- **组成**：`generateGifts` 函数中的 `prompt` 字符串和 `fetch` API 调用。
- **逻辑**：用户点击按钮 → 函数组装 Prompt → 向 DeepSeek API 发送请求 → 接收 AI 返回的文本。

**3. 结果展示与反馈模块**
- **职责**：将 AI 返回的原始数据（JSON）解析并美观地展示给用户，同时处理加载和错误状态。
- **组成**：右侧的结果展示区、加载动画骨架屏、错误日志显示区。
- **逻辑**：收到 AI 响应 → 尝试解析 JSON → 成功则渲染为礼物卡片列表，失败则显示错误信息。

**最值得学习的设计：**
**“输入-处理-展示”的清晰分离与状态管理。** 页面通过 Vue 的响应式数据（如 `isGenerating`, `gifts`）无缝地管理了“等待加载”、“展示结果”、“显示错误”三种核心状态，并通过条件渲染（`v-if`/`v-else`）平滑切换，用户体验非常完整。这是构建交互式 AI 应用的基础框架。

## 【四】Prompt / AI 逻辑是如何被设计的？

**1. Prompt 扮演的角色**
Prompt 在这里是 **“任务指令书”** 和 **“输出格式约束器”**。它告诉 AI 两件事：第一，你的角色和任务是什么（送礼专家）；第二，你必须按照什么格式来回答（严格的 JSON 数组）。

**2. 解决的是“生成问题”**
它主要解决 **“生成问题”** —— 根据有限的、结构化的输入信息，创造性地生成一系列符合要求的礼物方案。它并不需要深度“理解”复杂的人类情感，而是基于常识和模式进行组合与推荐。

**3. Prompt 中的关键变量**
Prompt 中嵌入了四个由用户输入决定的变量：
- `{target.value}`：收礼人关系
- `{budget.value}`：预算区间
- `{occasion.value}`：送礼场合
- `{extraInfo.value}`：额外信息
这些变量是每次请求的“个性化”部分，使同一个 Prompt 能产生千变万化的结果。

**4. 如果只改 Prompt，不改代码，会发生什么？**
- **改变推荐风格**：将“极具品味的送礼专家”改为“搞笑幽默的送礼鬼才”，AI 推荐的礼物和理由风格会大变。
- **调整输出结构**：修改 JSON 里的字段，比如增加 `"purchaseLink"`（购买链接）字段，AI 就会尝试在回复中提供这个新信息。
- **改变任务本质**：如果把推荐礼物改成“为这次送礼策划一个惊喜环节”，那么整个页面的功能就完全变了，但页面布局和交互依然有效。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，逐步替换核心部分，创造出属于你的 AI 工具：

**第一步：保持结构不变，替换使用场景（最安全）**
- **目标**：做一个“旅行规划助手”。
- **操作**：
  1. 修改页面标题和文案，如“送礼指南针”改为“旅行规划师”。
  2. 将左侧输入表单的标签和选项替换掉。例如：
    - “送给谁？” → “旅行者类型？”（选项：独自旅行、情侣、家庭亲子等）
    - “预算区间” → “旅行预算”
    - “送礼场合” → “旅行目的地/主题”
    - “更多信息” → “偏好与限制”（如“喜欢美食、有老人同行”）

**第二步：调整输入字段或 Prompt**
- **目标**：让 AI 解决新场景的问题。
- **操作**：
  1. 根据“旅行规划”场景，重写 `generateGifts` 函数中的 Prompt。
  2. 例如：“你是一个资深旅行规划师，请根据以下信息推荐一个3天的旅行计划...必须返回一个 JSON 数组，包含 `day`（第几天）、`morning`（上午安排）、`afternoon`（下午安排）、`reason`（推荐理由）等字段。”
  3. 同时，修改结果展示模板，将礼物卡片的字段名对应替换为旅行计划的字段。

**第三步：改变输出形式或展示方式**
- **目标**：让展示效果更符合新内容。
- **操作**：
  1. 旅行计划可能更适合用时间轴展示。你可以将 `.gift-card` 的样式改为时间线样式。
  2. 可以增加地图预览、图片插槽等新的 UI 组件。
  3. 这一步可以大胆尝试，因为前两步已经保证了核心功能（输入 → AI处理 → 输出）是跑通的。

**从哪里下手最安全？**
**从修改 Prompt 和表单的文案开始。** 这不会破坏任何代码逻辑，却能立刻改变整个应用的面貌和用途，让你快速验证新想法。

## 【六】3–5 个可直接尝试的改造方向

1. **增加“礼物风格”单选按钮组**
   - **操作**：在表单中添加一个“风格”选项，如“实用型”、“浪漫型”、“创意型”、“奢华型”。
   - **效果**：将这个选项加入 Prompt，AI 的推荐会更具风格倾向性，满足更细分的需求。

2. **本地缓存历史推荐结果**
   - **操作**：使用 `localStorage` 在生成礼物后，将本次的输入和输出一起保存下来。在页面底部新增一个“历史记录”折叠面板来展示。
   - **效果**：用户可以回顾和比较自己之前的灵感，避免重复生成，体验更完整。

3. **接入多模型 API，增加“智能体”选择**
   - **操作**：在设置弹窗中，除了 API Key，增加一个“模型”下拉选择框（如 DeepSeek、GPT-4o-mini、GLM等）。修改 `fetch` 请求的 URL 和参数以适应不同模型。
   - **效果**：用户可以选择不同“性格”或能力的 AI 来获取建议，对比结果更有趣。

4. **为每个礼物推荐添加“一键搜索”功能**
   - **操作**：在每个礼物卡片的底部增加一个“去电商平台看看”的小按钮。点击后，自动用礼物名称拼接成搜索链接（如 `https://search.jd.com/search?keyword=${encodeURIComponent(gift.name)}`）并在新窗口打开。
   - **效果**：将“灵感”与“行动”连接起来，工具实用性大大增强。

5. **优化交互：添加输入示例和标签提示**
   - **操作**：在“更多信息”文本框下方，用浅色小字添加几个示例标签，如“点击填充示例：<span class='text-rose-400 cursor-pointer' @click='extraInfo="喜欢咖啡、养猫"'>咖啡与猫</span> | <span class='text-rose-400 cursor-pointer'>运动达人</span>”。
   - **效果**：降低用户输入门槛，明确告知哪些信息是有效的，引导用户提供高质量输入。

## 【七】这个网页不适合做什么？（边界提醒）

1. **不适合作为最终的购物决策工具**
   - **局限性**：它生成的推荐基于 AI 的通用知识和你的简短描述，可能忽略某些品牌的最新款、本地小众精品或收礼人极其私密的偏好。
   - **应该怎么做**：将其视为“灵感启发器”和“初选清单”。生成列表后，你应该结合对收礼人的了解，亲自去电商平台或实体店核实、比较后再购买。

2. **不适合处理高度专业化或涉及安全健康的礼品**
   - **局限性**：对于如专业摄影器材、精密仪器、婴幼儿特定食品、保健品等，AI 可能缺乏足够专业、即时的知识，或无法承担推荐不当的责任。
   - **应该怎么做**：此类需求应咨询领域内的专家、资深用户或查阅专业的评测报告。

3. **不适合替代深度的人际沟通**
   - **局限性**：礼物背后是情感。这个工具无法理解你和收礼人之间复杂的情感历史、未说出口的期待或正在发生的矛盾。
   - **应该怎么做**：最重要的礼物是“用心”。在关键的人际关系中，最好的礼物往往来自于你平时的观察、倾听和沟通。这个工具是帮你把“用心”具体化，但不能替代“用心”本身。
