# 灵感转盘 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你需要创意灵感，但大脑一片空白时。比如：
- 短视频创作者想不出新点子
- 文案策划需要不同角度的切入思路
- 设计师寻找配色或构图灵感
- 学生做项目时需要打破常规思维

**适合情况**：
- 需要快速获得多样化创意提示
- 希望打破思维定式，引入随机性
- 想要结合特定情绪和场景进行创作

**不适合情况**：
- 需要深度、专业的行业分析
- 要求100%准确或可立即执行的方案
- 涉及敏感或需要严格保密的内容

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. 主题输入框：填写你想要获得灵感的领域（如“短视频创作”）
2. API密钥：首次使用需要在设置中配置DeepSeek API Key

**用户通常会做哪几步操作？**
1. 点击右上角齿轮图标，输入你的API密钥并保存
2. 在主题输入框填写你的创作领域
3. 点击“开始旋转”按钮，转盘会随机旋转
4. 转盘停止后，系统会自动生成“角度+情绪+场景”组合
5. 点击“生成灵感提示”按钮，等待AI生成结果

**输出结果长什么样？**
- 三个随机标签：角度（如“反差”）、情绪（如“兴奋”）、场景（如“夜晚”）
- AI生成的灵感提示：通常是2句简洁、有行动性的创意建议
- 示例输出：“在深夜的办公室，用反差手法制造惊喜。让观众从疲惫中突然兴奋起来。”

**容易忽略的使用细节**
1. **必须配置API密钥**：不配置就无法生成内容
2. **转盘角度影响结果**：每次旋转都会重新随机组合三个要素
3. **可以多次尝试**：对同一主题，可以多次旋转获得不同组合
4. **主题越具体越好**：“美食短视频”比“短视频”效果更好

## 【三】核心结构拆解（学习重点）

**页面由四个关键模块组成：**

1. **转盘控制模块**
   - 职责：提供视觉交互，随机生成三个创意维度
   - 组成：彩色转盘 + 旋转按钮 + 角度显示
   - 逻辑：点击旋转 → 随机角度 → 映射到三个列表 → 显示结果

2. **参数显示模块**
   - 职责：展示当前选中的创意参数
   - 组成：主题输入框 + 三个标签展示区
   - 逻辑：接收转盘结果 → 格式化显示 → 等待用户确认

3. **AI生成模块**
   - 职责：调用AI API生成创意提示
   - 组成：生成按钮 + 加载状态 + 结果展示区
   - 逻辑：收集所有参数 → 构建Prompt → 调用API → 显示结果

4. **配置管理模块**
   - 职责：管理API密钥和模型选择
   - 组成：设置弹窗 + 输入框 + 保存功能
   - 逻辑：用户输入配置 → 保存到本地存储 → 后续调用使用

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入主题 → 旋转转盘 → 随机选择(角度+情绪+场景) → 
构建Prompt → 调用AI API → 解析返回 → 显示创意提示
```

**最值得学习的设计：**
**“转盘作为随机化器”**的设计思路。它把抽象的随机选择变成了直观的物理交互，让用户感觉是在“抽奖”而不是“设置参数”，增加了趣味性和期待感。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色：**
Prompt是连接用户意图和AI能力的“翻译器”。它将转盘生成的随机参数转化为AI能理解的任务描述。

**解决的是“理解问题”还是“生成问题”？**
主要解决“生成问题”。系统已经理解了用户的需求（通过参数组合），Prompt的作用是告诉AI：“用这些参数，生成具体可执行的创意。”

**Prompt中的关键变量：**
```javascript
`主题：${topic.value}
角度：${result.value.angle}
情绪：${result.value.emotion}
场景：${result.value.scene}
请输出 2 句灵感提示，简洁有行动性。`
```
- `topic.value`：用户输入的主题
- `result.value`：转盘生成的三个随机参数
- 指令部分：“输出2句灵感提示，简洁有行动性”

**如果只改Prompt，不改代码，会发生什么变化？**
1. 改输出格式：如“请输出5个关键词” → 结果变成关键词列表
2. 改创意风格：如“用诗歌形式表达” → 结果变成诗句
3. 改详细程度：如“详细描述执行步骤” → 结果更具体
4. 改目标受众：如“面向儿童解释” → 语言更简单

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景**
- 将“创意灵感”换成其他领域，如：
  - 健身计划生成器
  - 旅行路线推荐
  - 菜谱创意生成
- 只需修改：页面标题、描述、主题提示词

**第二步：调整输入字段或Prompt**
- 增加/减少输入字段：
  - 健身版：增加“健身目标”、“可用时间”、“器材”
  - 旅行版：增加“预算”、“天数”、“偏好”
- 修改Prompt模板，让AI输出对应格式

**第三步：改变输出形式或展示方式**
- 从“文本提示”改为：
  - 清单列表
  - 步骤流程图
  - 时间线规划
  - 对比表格

**最安全的下手点：**
从**修改三个随机列表**开始。把`angles`、`emotions`、`scenes`数组换成你领域相关的选项，这是零风险、立即见效的改动。

## 【六】3–5个可直接尝试的改造方向

1. **增加“难度级别”选择**
   - 在转盘旁添加“简单/中等/困难”按钮
   - 将难度参数加入Prompt：“请生成{难度}级别的创意”
   - 效果：让创意更适合用户当前水平

2. **改为多模型支持**
   - 在设置中增加其他AI模型选项（如GPT-4、Claude）
   - 根据模型特性调整Prompt模板
   - 效果：比较不同模型的创意质量

3. **添加“灵感收藏夹”功能**
   - 在每个生成结果旁添加“收藏”按钮
   - 新增页面展示所有收藏的灵感
   - 效果：建立个人创意库，方便回顾

4. **实现“组合锁定”功能**
   - 允许用户固定某个参数（如锁定“情绪：兴奋”）
   - 只随机化其他两个参数
   - 效果：在保持某些喜好的情况下探索变化

5. **增加“历史记录”面板**
   - 显示最近10次生成的参数组合和结果
   - 添加“再次使用此组合”按钮
   - 效果：避免错过好的随机组合

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不适合深度专业咨询**
   - 如果你需要法律、医疗、金融等专业建议
   - 应该：咨询持证专业人士，而非AI创意工具

2. **不适合精确方案制定**
   - 如果你需要可立即执行、无风险的商业计划
   - 应该：使用专业规划工具或雇佣顾问

3. **不适合内容直接复制使用**
   - AI生成的创意需要人工筛选和优化
   - 应该：将灵感作为起点，而非最终成品

4. **不适合高度个性化需求**
   - 如果你需要基于大量个人数据的定制建议
   - 应该：使用能接入个人数据的专业系统

5. **不适合实时协作**
   - 页面是单人使用的工具
   - 如果需要团队头脑风暴：应该使用协作白板工具（如Miro、Figma）

**记住**：这个工具是“创意火花发生器”，不是“完整解决方案生成器”。它的价值在于打破思维惯性，提供新鲜角度，真正的创作还需要你的专业判断和后续加工。
