# 视频钩子优化器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你需要制作短视频（如抖音、B站内容）时，最关键的挑战是如何在视频开头的3-5秒内抓住观众的注意力，让他们愿意继续看下去。这个工具就是帮你批量生成这些“黄金开场句”的。

**适合什么情况：**
- 你有一个视频主题，但不知道如何开场
- 你想为同一个主题准备多个不同风格的开场，测试哪个效果更好
- 你需要快速产出大量钩子文案，节省构思时间
- 你的目标是在特定平台（如抖音、B站）发布内容

**不适合什么情况：**
- 你需要完整的视频脚本（这个工具只生成开场部分）
- 你的内容不需要“抓眼球”（如严肃的教学视频、纪录片）
- 你已经有了明确的创意方向，不需要AI辅助构思

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **视频主题**（必填）：你想制作的视频内容，如“如何3个月从0到10万粉丝”
2. **目标人群**（可选）：你的视频想吸引谁，如“想做自媒体的年轻人”
3. **视频平台**：选择发布平台，如抖音、B站等
4. **钩子类型**：选择1-5种开场风格（悬念型、痛点型等）
5. **每类生成数量**：每种类型生成2-5个版本
6. **额外要求**（可选）：如“突出专业性”、“适合知识类账号”

**用户通常会做哪几步操作？**
1. 填写视频主题（这是必须的）
2. 选择2-3种你喜欢的钩子类型（默认已选好三种）
3. 点击“生成黄金3秒钩子”按钮
4. 等待10-20秒，查看右侧生成的结果
5. 点击任意钩子卡片复制文案，或使用“复制全部”批量导出

**输出结果长什么样？**
生成的结果会按钩子类型分组显示，例如：
- **悬念型**（3个版本）
  1. “你知道90%的自媒体人都卡在哪一步吗？”
  2. “为什么你的视频总是没流量？秘密就在这里...”
  3. “三个月从0到10万粉，我只做了这三件事”

每个钩子都是一个独立的卡片，点击即可复制。

**有哪些容易忽略的使用细节？**
1. **必须先配置API Key**：第一次使用需要点击右上角“设置”，输入DeepSeek API Key
2. **钩子类型可以多选**：不要只选一种，多选几种能得到更丰富的创意
3. **额外要求很重要**：如果你有特殊风格需求，一定要在这里说明
4. **生成后可以联动**：页面底部的“前往直播脚本工具”可以继续完善完整话术

## 【三】核心结构拆解（学习重点）

**页面由哪几个关键模块组成？**
1. **输入配置模块**（左侧面板）
   - 主题/人群/平台的基础信息收集
   - 钩子类型选择器（多选）
   - 数量控制和额外要求

2. **AI生成引擎模块**（隐藏在后台）
   - API调用封装
   - Prompt构建逻辑
   - JSON结果解析

3. **结果展示模块**（右侧面板）
   - 按类型分组显示
   - 交互式复制功能
   - 批量导出操作

4. **状态管理模块**（贯穿始终）
   - 用户输入状态
   - 生成加载状态
   - 配置和本地存储

**每个模块承担什么职责？**
- **输入模块**：收集用户意图，转化为结构化数据
- **AI引擎**：将结构化数据转化为AI能理解的Prompt，调用API，解析返回结果
- **展示模块**：将AI返回的JSON数据可视化，提供便捷的复制和导出
- **状态模块**：确保页面状态一致，记住用户配置

**输入 → 处理 → 输出 的逻辑链路：**
```
用户填写表单 → 构建Prompt → 调用DeepSeek API → 解析JSON → 分组渲染 → 用户复制使用
```

**哪一部分是“这个网页最值得学习的设计”？**
**Prompt的模块化构建**最值得学习。它没有把整个请求写成一个长字符串，而是：
1. 用`##`分隔不同信息区块
2. 动态插入用户选择的钩子类型描述
3. 明确指定输出格式为JSON
4. 包含平台特化要求

这种设计让Prompt既灵活又可控，是AI应用开发的核心技巧。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是“翻译官”——它把用户在前端表单中的选择，翻译成AI能理解的创作指令。它告诉AI：“用户想要这样的东西，请你用这样的格式给我”。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**，但也解决了部分理解问题。因为：
- 系统Prompt定义了AI的角色（顶级短视频编导）
- 用户Prompt明确了生成的具体要求（字数、类型、数量）
- 输出格式约束确保结果能被程序解析

**哪些信息是Prompt中的关键变量？**
1. `{this.input.topic}` - 视频主题
2. `{this.input.selectedHookTypes.map(...)}` - 钩子类型列表
3. `{this.input.countPerType}` - 每个类型的生成数量
4. `{this.getPlatformName()}` - 平台名称

**如果只改Prompt，不改代码，会发生什么变化？**
1. **改系统Prompt**：改变AI的“人设”，比如改成“脱口秀编剧”，生成的钩子会更幽默
2. **改输出要求**：比如把“15-30字”改成“10-15字”，钩子会更短更精炼
3. **改输出格式**：如果去掉JSON格式要求，页面就无法正确解析结果
4. **增加约束**：比如加上“不能使用感叹号”，所有钩子都会更平实

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景**
- 把“视频钩子”换成“文章标题”
- 把“黄金3秒”换成“爆款标题”
- 修改钩子类型：悬念型→疑问型、痛点型→共鸣型等
- **这是最安全的起点**，你只需要改文字，不用动代码结构

**第二步：调整输入字段或Prompt**
- 增加“文章类型”选择（干货、故事、评测等）
- 增加“关键词”输入框
- 修改Prompt中的角色设定和输出要求
- 此时开始接触AI逻辑，但页面布局不变

**第三步：改变输出形式或展示方式**
- 把分组展示改成瀑布流展示
- 增加“点赞/收藏”交互
- 添加“一键生成配图建议”功能
- 这里需要修改前端渲染逻辑

**从哪里下手最安全？**
从**修改`hookTypes`数组**开始。在代码第150行左右，找到`hookTypes`的定义，尝试：
1. 修改`label`和`description`
2. 增加或减少类型数量
3. 修改`example`中的示例

这样你就能立即看到界面变化，而不会破坏核心功能。

## 【六】3–5个可直接尝试的改造方向

**1. 增加“语气风格”选择**
- 在输入面板添加单选按钮：幽默风趣 / 专业严谨 / 亲切温暖
- 在Prompt中加入：“请使用${语气风格}的语气”
- 效果：同一主题能产出不同风格的钩子

**2. 替换为本地模型或免费API**
- 使用Ollama + 本地模型（如Qwen2.5）
- 或换成Groq、OpenRouter等支持免费额度的服务
- 修改`fetch`请求的URL和headers即可

**3. 拆分成“快速生成”和“深度优化”两个模式**
- 快速模式：只生成基础钩子，秒级响应
- 深度模式：分析竞品、结合热点，生成更优质的钩子
- 用两个不同的Prompt和API参数实现

**4. 增加“钩子评分”功能**
- 生成后，让AI对每个钩子打分（1-10分）
- 给出评分理由：“这个钩子悬念强，但不够口语化”
- 帮助用户筛选最优选项

**5. 创建“钩子库”和收藏功能**
- 将生成的钩子保存到本地数据库
- 允许用户收藏喜欢的钩子
- 添加搜索和分类功能，积累自己的素材库

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不生成完整内容**：它只做“开场3秒”，不负责视频的中间和结尾
2. **创意依赖AI**：所有产出都基于AI的“理解”，可能缺乏真正的人类洞察
3. **平台限制**：虽然支持多个平台，但无法深度结合每个平台的最新算法变化
4. **无法测试效果**：它只能生成钩子，无法预测哪个钩子实际数据会更好

**如果用户想做X，应该换什么工具：**
- **想做完整视频脚本** → 使用配套的“直播脚本工具”或Notion AI
- **需要结合实时热点** → 使用抖音创作助手、微博热搜工具
- **要分析钩子实际效果** → 需要AB测试工具+数据分析平台
- **需要高度原创、有深度的开场** → 还是需要人类编剧的创意
