# 冥想脚本定制器 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：
想象一下，你是一位冥想初学者，或者是一位想为朋友、学员提供个性化引导的冥想带领者。你希望获得一份符合特定需求（比如缓解焦虑、帮助睡眠）的冥想引导词，但又不想花费大量时间去研究、写作，或者购买昂贵的专业服务。这个工具就像一个“冥想脚本速成助手”，让你通过简单的选择，快速获得一份结构完整、语言专业的引导词。

**适合情况**：
- 个人冥想练习，需要一份新的引导词来保持新鲜感。
- 冥想带领者或老师，需要快速生成不同主题的脚本作为参考或素材。
- 想体验不同冥想风格（如身体扫描、慈心冥想）的探索者。
- 需要一个结构清晰、语言温和的文本，用于自己录音或练习。

**不适合情况**：
- **需要实时互动或反馈的冥想**：这是一个文本生成工具，无法像真人老师一样根据你的呼吸、状态进行实时调整。
- **处理严重心理问题**：生成的脚本是通用引导，不能替代专业的心理治疗或一对一指导。
- **追求极致个性化**：虽然可以输入个性化需求，但其核心是基于模板和AI理解生成的，深度和独特性有限。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面左侧是一个表单，你需要填写或选择：
1.  **冥想目的**：从下拉菜单选择（如“缓解焦虑”、“改善睡眠”）。
2.  **时长**：点击按钮选择（5、10、20分钟）。
3.  **引导风格**：从下拉菜单选择（如“温柔缓慢”、“简洁有力”）。
4.  **个性化需求（可选）**：在文本框里写下你的特殊要求（如“加入海洋的意象”）。
5.  **背景音乐建议**：从下拉菜单选择（如“自然声音”、“颂钵音”）。

**用户通常会做哪几步操作？**
1.  **配置**：首次使用时，点击右上角的齿轮图标，在弹出的“高级设置”中填入你的DeepSeek API密钥（这是调用AI服务所必需的）。
2.  **定制**：在左侧表单中，根据你的喜好选择或填写各项参数。
3.  **生成**：点击绿色的“生成冥想脚本”按钮。
4.  **使用结果**：等待片刻，右侧区域会显示生成的完整冥想脚本。你可以“复制”文本，或“导出”为TXT文件保存。

**输出结果长什么样？**
输出是一个结构清晰的Markdown文本，通常包括：
- **标题**：如“冥想脚本：缓解焦虑 (10分钟)”
- **分章节**：“准备阶段”、“核心练习”、“结束阶段”
- **引导词正文**：使用第二人称“你”，包含大量“...”表示的停顿提示。
- **练习要点**：一些关键提示。
- 整体语言风格会符合你选择的“引导风格”。

**有哪些容易忽略的使用细节？**
1.  **API密钥是必须的**：不填写密钥，点击生成会直接弹出设置窗口。你需要自行注册DeepSeek平台获取。
2.  **模型选择**：右上角有“V3”和“R1”按钮，代表不同的AI模型（聊天模型和推理模型），可以切换试试效果，R1可能逻辑更强但速度稍慢。
3.  **个性化需求是加分项**：虽然可选，但填写具体需求（如“我希望引导词更简短一些”）能让结果更贴近你的想象。
4.  **实时流式输出**：生成时，文字是一个字一个字出现的（流式输出），这表示它正在“创作”，而不是从数据库里调取。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

**1. 用户输入模块（左侧卡片）**
*   **职责**：收集用户的所有定制化需求。它把复杂的冥想脚本创作，抽象成了几个简单的选择题和填空题。
*   **设计亮点**：使用了**约束性选择**（下拉菜单、按钮）而非完全开放输入。这降低了用户的使用门槛，也保证了输入信息的结构化，让后续的AI处理更精准。

**2. AI处理与输出模块（右侧卡片）**
*   **职责**：
    *   **状态管理**：显示“等待生成”、“生成中”、“展示结果”三种状态，并有对应的UI（图标、动画）。
    *   **内容展示与处理**：将AI返回的Markdown文本渲染成美观的HTML格式。
    *   **结果操作**：提供“复制”和“导出”功能，让生成的内容能被方便地使用。
*   **设计亮点**：**状态驱动的UI**。`isGenerating` 这个变量控制着整个右侧区域的显示内容，逻辑非常清晰。

**3. 配置与管理模块（设置弹窗）**
*   **职责**：管理应用的“发动机”（API密钥）和“大脑”（系统提示词）。这是工具能运行和定制其“专业领域”的核心。
*   **设计亮点**：将关键但低频的操作（配置API）收纳在弹窗中，保持了主界面的简洁。

**逻辑链路**：
`用户选择输入` → `点击生成按钮` → `前端组合用户输入和系统提示词` → `调用DeepSeek API` → `接收流式数据并实时显示` → `最终呈现完整脚本`

**最值得学习的设计**：
**“系统提示词 + 用户输入”的双层结构**。系统提示词（`DEFAULT_SYSTEM_PROMPT`）定义了AI的“专业身份”和必须遵守的“创作宪法”（如结构、语言、停顿规则）。用户输入则是在这个宪法框架下的“具体法案”。这种设计将**领域知识（冥想引导原则）** 和 **用户个性化需求** 完美分离，使得改变领域（如把冥想换成健身指导）时，只需重写系统提示词，而前端逻辑几乎不用动。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt的角色**：
在这个页面中，Prompt（特别是系统提示词）扮演着**“专家教练”**和**“内容规范”**的双重角色。它不是在回答一个简单问题，而是在**执行一个复杂的创作任务**。

**解决的是“生成问题”**：
它主要解决“如何根据一组参数生成一份高质量、符合专业规范的冥想脚本”这一**生成问题**。它确保了生成的内容不是随意的散文，而是有结构、有节奏、符合冥想引导原则的专用文本。

**关键变量**：
系统提示词中的关键变量是那些**规则描述**，例如：
*   **身份指令**：“你是一位专业的MBSR冥想引导师”
*   **结构规则**：“结构完整：开场引导、核心练习、结束引导”
*   **格式规则**：“输出格式（Markdown）：# 标题 ## 章节”
*   **风格规则**：“语言特点：第二人称‘你’，现在时态”
用户输入（目的、时长、风格等）则是传递给这位“教练”的**具体任务要求**。

**如果只改Prompt，不改代码，会发生什么？**
整个应用的生产内容将彻底改变。例如：
*   将系统提示词改为“你是一位专业的健身教练，擅长制定家庭健身计划”，那么输入“目的”可以变成“增肌”、“减脂”，“时长”变成“15分钟”、“30分钟”，输出就会变成一份健身计划。
*   修改提示词中的“输出格式”，生成的文本结构也会随之改变。
*   调整“语言特点”，生成内容的语气和用词会发生根本变化。
**这证明了：前端界面只是收集参数的表单，而Prompt才是定义这个工具“是什么”的灵魂。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的AI内容生成工具：

**第一步：替换核心场景与领域知识（最安全）**
1.  **复制整个HTML文件**，改个名字，比如 `my_recipe_generator.html`。
2.  **修改标题**和界面文字，将“冥想”相关词汇全部替换成你的目标领域，例如“健身”、“食谱创作”、“旅行计划”。
3.  **重写 `DEFAULT_SYSTEM_PROMPT`**。这是最关键的一步。你需要用新领域的专业知识来填充它。例如，做食谱生成，就要定义身份（“你是米其林厨师”）、结构（“包含：菜名、简介、食材、步骤、窍门”）、语言风格（“生动诱人”）。
4.  **此时运行，它已经是一个新的生成器了**，只是输入表单还是冥想的。

**第二步：调整输入字段**
1.  根据新领域，修改左侧表单的选项。例如：
    *   `冥想目的` -> `菜肴类型`（中餐、西餐、甜品）
    *   `时长` -> `烹饪时长`（快手菜、周末大餐）
    *   `引导风格` -> `口味风格`（清淡、香辣、酸甜）
    *   `个性化需求` -> `特殊要求`（不要香菜，需要高蛋白）
    *   `背景音乐建议` -> `搭配建议`（推荐配酒或饮料）
2.  修改对应的 `v-model` 绑定变量名（如 `input.purpose` 改为 `input.cuisineType`），保持前后一致。

**第三步：改变输出形式与细节**
1.  调整右侧结果区域的标题和提示信息。
2.  根据新内容的特点，微调UI颜色和图标（可选，用Tailwind CSS改颜色很方便）。
3.  优化导出文件的内容和文件名。

按照这个顺序，你每一步都能看到可运行的结果，风险最低。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“难度级别”或“受众”输入**：
    *   **操作**：在表单中添加一个下拉菜单，选项如“初学者”、“进阶练习者”、“儿童适用”。
    *   **实现**：在 `input` 对象中新增一个属性（如 `level`），在系统提示词和用户Prompt中增加对这个变量的描述和运用逻辑（例如：“针对初学者，语言要更加简单，避免专业术语”）。

2.  **切换或支持多个AI模型/API**：
    *   **操作**：在“高级设置”中，增加一个API提供商的选择（如DeepSeek, OpenAI, 智谱AI），并对应不同的密钥输入框和模型选择。
    *   **实现**：修改 `apiConfig` 对象，增加 `provider` 和 `apiBaseURL` 等字段。在 `generateScript` 函数中，根据选择动态构建请求的URL和头部信息。

3.  **将长脚本拆分为“步骤卡片”或加入语音朗读**：
    *   **操作**：生成脚本后，不要一次性显示大段文本，而是用JavaScript按章节（如“准备阶段”、“核心练习”）拆分成多个可折叠/展开的卡片。
    *   **更进阶**：集成浏览器Web Speech API，添加一个“朗读”按钮，将生成的文本转换为语音，模拟冥想引导。
    *   **实现**：利用 `marked` 解析后的HTML结构，或者根据Markdown的标题（`##`）来分割内容，动态生成多个UI组件。

4.  **优化交互：保存“配方”与历史记录**：
    *   **操作**：添加一个“保存此配置”按钮，将当前的表单选择（`input`对象）保存到浏览器的 `localStorage` 中，并提供一个历史列表供快速调用。
    *   **实现**：创建一个数组用于存储历史配置，每次保存时push进去。在页面侧边或底部展示这个列表，点击即可自动填充表单并生成。

5.  **引入“示例库”或“灵感”功能**：
    *   **操作**：在页面初始状态或生成区为空时，展示几个经典的、预定义的冥想脚本示例。
    *   **实现**：预先写好几个高质量的脚本文本，存放在一个JavaScript数组或对象中。根据用户选择的“目的”，可以推荐或直接显示对应的示例，让用户先有直观感受。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合作为医疗或心理治疗工具**：生成的冥想脚本是通用的健康辅助内容，不能诊断、治疗任何生理或心理疾病。如果用户有严重的焦虑症、失眠症或其它健康问题，应建议其寻求医生或专业心理咨询师的帮助。
2.  **不适合需要深度个性化调整的场景**：AI无法理解用户独特的人生经历、创伤或极其细微的偏好。如果用户需要一份针对其个人重大事件（如哀伤辅导）的引导，真人导师的共情和灵活调整是不可替代的。
3.  **不适合实时带领团体冥想**：此工具生成的是静态文本。带领团体冥想需要观察现场氛围、回应参与者问题、动态调整节奏，这是当前技术无法做到的。
4.  **不适合生成极度创新或艺术化的内容**：AI基于已有模式生成内容。如果你需要一份前所未有的、充满诗意隐喻和哲学深度的先锋冥想体验脚本，最好还是依靠人类创作者的天才。

**总结**：这个网页是一个优秀的**“结构化内容生成”** 模板。它教会我们如何用前端界面降低用户输入难度，如何用Prompt封装领域知识，以及如何将两者结合来打造一个实用的轻量级AI工具。它的价值在于其**可迁移的设计模式**，而非仅仅是“冥想”这个应用本身。
