# 人设打造师 (Persona Architect) 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你打算在社交媒体（如小红书、抖音、B站）上创建一个新账号，但不知道如何定位自己。你不想只是“又一个分享者”，而是希望打造一个**有记忆点、有差异化、能持续吸引粉丝**的独特人设。

这个网页就像一个**专业的“人设顾问”**，通过与你进行几轮深度对话，挖掘你的背景、特长和想法，最终为你生成一份结构化的“人设方案”。它解决了“**如何从零开始，系统性地构建一个吸引人的线上身份**”的问题。

*   **适合在什么情况下使用？**
    *   你是一个内容创作者新手，想找到自己的独特定位。
    *   你有一个模糊的方向（比如“想做职场博主”），但不知道如何具体化、差异化。
    *   你需要一份清晰、可执行的“人设指南”，来指导未来的内容创作和视觉风格。
    *   你想快速获得一些创意灵感，比如账号昵称、Slogan、选题方向。

*   **不适合什么情况？**
    *   你已经有了非常成熟、固定的账号人设，只是想微调。
    *   你需要的是**内容批量生成工具**（如写文章、做视频脚本）。
    *   你需要的是**数据分析工具**（如粉丝画像分析、竞品分析）。

## 【二】使用方式（给第一次接触的人）

1.  **准备工作**：点击右上角的“设置”按钮，输入你的 DeepSeek API Key，并选择你喜欢的模型（“V3-快”或“R1-深”）。保存后关闭弹窗。
2.  **开始对话**：在左侧聊天框，AI会先向你打招呼。你需要按照它的引导，先介绍你的**基本背景**（例如：“我是一名工作了5年的程序员”）和**想做的账号类型**（例如：“我想做一个分享科技生活方式的账号”）。
3.  **回答追问**：AI会根据你的回答，提出3-4个追问（例如：“你觉得自己最与众不同的科技使用习惯是什么？”）。请认真思考并回答，你的回答越具体、越有细节，最终生成的人设就越独特。
4.  **查看结果**：完成几轮对话后，AI会停止提问，并在**右侧区域**生成一份完整的“人设卡片”。这张卡片会包含你的账号昵称、Slogan、标签、口头禅、视觉建议和首发选题。
5.  **导出结果**：你可以点击右下角的“导出人设卡片”按钮，将这份方案保存为JSON文件，方便后续参考。

*   **输出结果长什么样？**
    右侧会生成一张视觉精美的卡片，分为几个模块：
    *   **核心定位卡**：包含你的账号昵称、一句响亮的口号（Slogan）和一段简介。
    *   **差异化标签**：从“身份”、“性格”、“记忆点”三个维度给你打上标签。
    *   **内容风格指南**：列出你的“口头禅”和“视觉风格建议”。
    *   **首发爆款选题**：提供3个具体的、可立即着手制作的选题方向。

*   **有哪些容易忽略的使用细节？**
    *   **API Key是必须的**：没有它，AI无法工作。第一次使用务必先设置。
    *   **模型选择**：“R1-深”模型会进行深度思考，生成的结果可能更精细，但速度稍慢，且思考过程可以展开查看。
    *   **按Enter发送**：在输入框里按`Enter`键可以直接发送消息，无需点击发送按钮。
    *   **重置对话**：如果对当前对话不满意，可以点击输入框下方的“重置”按钮重新开始。

## 【三】核心结构拆解（学习重点）

这个网页可以清晰地分为三个核心模块，它们协同工作，完成“信息收集 -> 分析处理 -> 结果呈现”的完整链路。

1.  **交互问诊模块（左侧）**
    *   **职责**：模拟真人顾问，通过多轮对话引导用户，收集构建人设所需的原始信息。这是整个应用的“输入引擎”。
    *   **逻辑**：用户输入 -> 记录到对话历史 -> 判断当前步骤 -> 调用AI生成下一个问题或最终结果 -> 将AI回复展示给用户。

2.  **AI逻辑与状态管理模块（核心JS逻辑）**
    *   **职责**：这是网页的“大脑”。它管理对话轮次（`step`），判断何时该追问、何时该生成最终结果。它负责组装发送给AI的指令（Prompt），并处理AI返回的数据。
    *   **逻辑**：
        *   **输入**：用户的每次回答。
        *   **处理**：`sendMessage`函数判断`step`值。如果未完成，调用`generateFollowUpQuestion`组装“追问Prompt”；如果已完成，调用`generateFinalPersona`组装“生成人设Prompt”。
        *   **输出**：将处理好的Prompt发送给DeepSeek API，并将返回的文本或JSON数据更新到页面对应的状态（`chatHistory`或`finalPersona`）。

3.  **人设展示模块（右侧）**
    *   **职责**：将AI生成的、结构化的JSON数据，以美观、易读的卡片形式可视化呈现出来。这是整个应用的“输出终端”。
    *   **逻辑**：当`finalPersona`这个数据变量被填充后，Vue会自动触发页面重新渲染，将JSON中的各个字段（如`name`, `tags`, `topics`）填充到预设好的HTML模板中，形成最终卡片。

*   **哪一部分是“这个网页最值得学习的设计”？**
    **“分步式信息收集”与“状态驱动UI”的结合。**
    它没有用一个冗长的表单让用户一次性填写所有信息，而是通过**多轮对话（状态`step`控制）** 来渐进式地挖掘信息，用户体验更自然。同时，整个页面的显示/隐藏、输入框的禁用/启用、右侧是空状态还是结果卡片，都完全由几个核心状态变量（`isFinished`, `finalPersona`等）驱动。这种设计让逻辑非常清晰，易于维护和扩展。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt 在这个页面中扮演什么角色？**
    Prompt在这里扮演了**双重角色**：
    1.  **“访谈官”脚本**：在追问阶段（`generateFollowUpQuestion`），Prompt定义了AI的行为（“专业的新媒体人设顾问”）、目标（“收集信息”）和提问策略（“提一个最有价值的追问”）。
    2.  **“架构师”指令**：在最终生成阶段（`generateFinalPersona`），Prompt则变成了一个严格的**输出格式指令**，要求AI扮演“顶尖的品牌人设架构师”，并必须按照指定的JSON结构返回结果。

*   **它解决的是“理解问题”还是“生成问题”？**
    两者都有，但侧重点不同。
    *   **追问阶段**：主要是“理解问题”。AI需要理解用户的历史回答，并基于此提出一个逻辑连贯的新问题。
    *   **生成阶段**：主要是“生成问题”。AI需要基于所有对话记录，进行创造性综合，生成一个全新的、结构化的方案。

*   **哪些信息是 Prompt 中的关键变量？**
    1.  **`context`（对话历史）**：这是最重要的变量，包含了所有原始信息。
    2.  **`step`（当前轮次）**：在追问Prompt中，它让AI知道访谈进度。
    3.  **`totalSteps`（总轮次）**：同上，帮助AI把握节奏。
    4.  **`systemPrompt`中的JSON结构**：在生成阶段，这是强制AI输出格式的“硬约束”，是获得结构化数据的关键。

*   **如果只改 Prompt，不改代码，会发生什么变化？**
    变化会非常直接和明显：
    *   修改追问阶段的Prompt，可以改变AI的**提问风格和挖掘方向**。比如，你可以让它更侧重于挖掘用户的“情感故事”或“专业知识”。
    *   修改生成阶段的`systemPrompt`中的JSON结构，会直接改变**最终人设卡片的组成部分**。比如，你可以增加一个“内容禁忌”字段，或删除“视觉风格”字段。只要代码中展示模块引用了这些字段，页面就会自动适应新的数据结构。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全路径”，逐步替换，最终做出一个完全属于你的应用：

1.  **第一步：替换核心场景与UI文案**
    *   **最安全**：保持所有代码结构、Vue状态和CSS样式完全不变。
    *   **只修改**：页面标题、AI的欢迎语、追问Prompt中的角色描述（如把“新媒体人设顾问”改成“健身计划顾问”）、以及右侧卡片的所有标题文字（如把“差异化标签”改成“体能评估标签”）。
    *   **效果**：你会立刻得到一个外观一样，但主题完全不同的应用（比如“健身计划制定师”）。

2.  **第二步：调整输入字段与追问逻辑**
    *   在第一步的基础上，修改`generateFollowUpQuestion`函数中的Prompt。改变它追问的方向和问题数量（调整`totalSteps`）。
    *   例如，对于“健身顾问”，追问方向可以改为：“日常活动量”、“伤病历史”、“饮食偏好”、“健身目标（增肌/减脂/塑形）”。

3.  **第三步：重构输出数据结构与展示**
    *   这是最大的一步，但也是创造性的核心。
    *   修改`generateFinalPersona`函数中的`systemPrompt`，设计一个全新的JSON结构来承载你的新场景所需的数据。
    *   同时，修改右侧的HTML模板，使用Vue的指令（`v-for`, `{{ }}`）来绑定和展示你新JSON结构里的字段。
    *   例如，对于“健身顾问”，输出结构可能包含：`{ “planName”: “”, “weeklySchedule”: […], “dietTips”: […], “precautions”: […] }`，然后设计对应的卡片来展示这些内容。

**从哪里下手最安全？**
从**第一步**开始。仅仅修改文字，就能让你快速验证新想法，且几乎不会引入代码错误。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“人设参考”输入**：在聊天开始前，增加一个可选输入框，让用户输入1-2个他们欣赏的博主或账号。在生成最终Prompt时，将这个信息加入，要求AI“分析参考账号的优点，并避免同质化”，从而生成更具借鉴意义和差异化的方案。
2.  **切换模型或API提供商**：代码中API调用部分（`callDeepSeek`函数）是封装的。你可以很容易地修改它为调用OpenAI的GPT、Claude或国内的其他大模型。只需修改`fetch`的URL、请求头（`Authorization`）和请求体格式即可。这是学习不同API调用方式的绝佳练习。
3.  **拆分为“访谈”与“灵感库”两个页面**：
    *   **访谈页**：专注于对话和生成，生成的人设卡片可以有一个“保存到灵感库”按钮。
    *   **灵感库页**：使用`localStorage`或模拟后端，列出所有历史生成的人设卡片，支持搜索、分类和再次编辑。这能立刻将工具升级为个人知识库。
4.  **优化交互：增加中途编辑与回退**：目前对话不能回退。可以增加一个功能，允许用户点击某条历史消息进行编辑，然后重置此后的所有对话和状态。这能极大提升使用的容错率和灵活性。
5.  **丰富结果展示：增加“内容示例”**：在最终卡片中，增加一个模块，要求AI根据生成的人设，直接写一段示例文案（如一条小红书笔记开头、一条微博文案）。让结果从“规划”延伸到“实操演示”，价值感更强。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精准的用户画像分析**：它生成的人设基于你主观的、有限的对话输入，而非真实的粉丝数据、行为数据或市场数据。它是一个“创意启动器”，而非“数据分析报告”。
*   **不适合生成可直接发布的深层次内容**：它提供的选题方向和风格建议是提纲和灵感，无法替代你深入的思考、专业的资料搜集和具体的文案撰写。你不能指望它直接产出干货满满的千字长文或视频分镜脚本。
*   **不适合作为唯一的决策依据**：人设是否成功，最终需要经过市场检验（发布内容、观察数据、收集反馈）。这个工具给出的方案是一个高质量的**假设**和**起点**，你需要用它来指导实践，并在实践中不断调整。
*   **如果你需要的是上述功能**：你应该转向更专业的工具，例如：
    *   用户画像分析：使用**社交媒体平台自带的创作者中心数据分析工具**（如抖音创作服务平台、小红书专业号后台）。
    *   内容深度生成：使用**专门的文案写作AI工具**，并为其提供更详细的指令和上下文。
    *   竞品分析：使用**数据平台**（如新榜、飞瓜数据）或**手动进行系统的内容拆解**。
