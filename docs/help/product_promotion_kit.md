# 促销活动文案套装 - 学习指南

## 【一】这个网页解决了什么问题？

想象一下，你是一名电商运营或市场专员，需要为即将到来的“双11”或“618”活动准备宣传文案。你需要为活动的不同阶段（预热、爆发、收尾）和不同渠道（朋友圈、社群、短信等）撰写多版本文案。手动构思不仅耗时，还容易遗漏或风格不统一。

这个网页就是你的“AI文案助理”。它帮你一次性生成一套结构完整、风格匹配、渠道适配的促销文案套装。你只需输入产品信息和活动要求，它就能为你规划好整个营销周期的文案。

**适合场景：**
*   电商、零售、品牌的市场运营人员，需要快速产出促销活动文案。
*   小型商家或个人卖家，缺乏专业的文案策划能力。
*   需要为同一活动在不同平台发布差异化内容时。

**不适合场景：**
*   需要撰写深度品牌故事、长篇文章或技术性极强的产品说明。
*   需要完全原创、无任何模板痕迹的创意文案。
*   活动策略复杂，需要结合实时数据（如库存、点击率）动态调整文案。

## 【二】使用方式（给第一次接触的人）

1.  **准备工作**：首次使用时，点击右上角的“设置”按钮，输入你的 DeepSeek API Key（需要自行申请）。这个 Key 会保存在你的浏览器本地。
2.  **填写活动信息**：
    *   **活动类型**：点击选择，如“双11”、“周年庆”。
    *   **产品名称**：填写你要推广的产品，如“智能保温杯”。
    *   **价格信息**：填写原价、促销价和优惠描述（如“立省100元”）。
    *   **核心卖点**：（可选）填写产品优势，如“24小时保温”。
    *   **输出渠道**：选择你需要文案的平台，如“朋友圈”、“社群”。
    *   **额外要求**：（可选）提出特殊要求，如“文案要活泼”、“突出限量感”。
3.  **生成文案**：点击红色的 **“🔥 生成促销文案套装”** 按钮。稍等片刻，AI 会为你生成全套文案。
4.  **查看与使用结果**：
    *   右侧会展示一个漂亮的摘要卡片。
    *   通过上方的标签（🔥预热期、💥爆发期、⏰收尾期）切换查看不同阶段的文案。
    *   在每个阶段内，可以筛选查看特定渠道（如只看“朋友圈”）的文案。
    *   每个文案都有“复制”按钮，可以单独复制。也可以“复制当前阶段”或“导出完整文案套装”为一个 Markdown 文件。

**容易忽略的细节：**
*   **API Key 是必须的**：不设置就无法生成，但只需设置一次。
*   **产品名称和活动类型是必填项**，否则生成按钮是灰色的。
*   **“额外要求”是让文案更贴合你想法的关键**，善用它。
*   生成的文案是 **“套装”**，包含三个阶段、多个渠道、每个渠道三个版本，内容非常丰富，不要只看第一眼就下结论。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个大模块，像一个高效的生产流水线：

1.  **输入控制面板（左侧）**
    *   **职责**：收集用户所有原始需求。它把复杂的文案策划需求，拆解成一个个简单的表单选项和输入框（活动类型、产品、价格、渠道等）。
    *   **设计亮点**：使用了**可视化选择**（图标卡片选活动类型、表情标签选渠道），比下拉菜单更直观友好，符合营销场景的氛围。

2.  **AI 处理引擎（核心逻辑，不可见）**
    *   **职责**：这是页面的大脑。它把左侧收集到的零散信息，按照预设的规则，组装成一个给 AI（DeepSeek）的详细“工作任务单”（即 Prompt），然后调用 API，并处理返回的 JSON 数据。
    *   **输入→处理→输出链路**：
        *   **输入**：用户填写的表单数据 (`input` 对象)。
        *   **处理**：`generateCopy` 函数将 `input` 数据拼接成结构化的 Prompt，发送给 AI API。
        *   **输出**：接收 AI 返回的 JSON，解析成页面能展示的结构 (`result` 对象)。

3.  **结果展示与操作系统（右侧）**
    *   **职责**：将 AI 生成的、结构化的数据 (`result` 对象) 清晰、美观地呈现给用户，并提供便捷的操作（复制、筛选、导出）。
    *   **设计亮点**：采用了 **“阶段-渠道”二维导航**。用户先选阶段（时间维度），再选渠道（平台维度），能快速定位到所需文案。每个文案卡片设计精致，操作按钮触手可及。

**最值得学习的设计：**
**“结构化输入”到“结构化输出”的完整映射**。整个应用的核心思想是：把复杂的创意生成任务，通过表单进行**结构化**，然后利用 AI 实现**批量化、标准化**产出。这不仅提高了效率，更保证了产出内容在框架上的统一性。这是将 AI 能力产品化的一个经典思路。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt 的角色**：它是连接用户意图和 AI 能力的“翻译官”和“项目经理”。它把用户简单的输入，转化成一个 AI 能精确理解的、包含背景、角色、任务和格式要求的详细指令。
*   **解决什么问题**：它同时解决了“理解问题”和“生成问题”。
    *   **理解**：通过 `systemPrompt` 设定 AI 的角色（电商运营专家）和输出格式（JSON）。
    *   **生成**：通过 `userPrompt` 详细描述任务，包括活动信息、分阶段分渠道的要求、各渠道的字数限制。
*   **Prompt 中的关键变量**：
    *   `eventLabel`, `productName`, `originalPrice` 等：来自用户输入的具体信息。
    *   `channelLabels`：用户选择的渠道，会被动态插入到输出格式的示例中，指导 AI 生成对应键值。
    *   严格的 **JSON 结构描述**：这是最关键的部分，它明确告诉 AI 返回的数据必须是什么样子（`warmup` 对象下包含 `moments` 数组等）。
*   **如果只改 Prompt，不改代码**：
    *   你可以彻底改变这个工具的功能。例如，将促销文案生成改为“短视频脚本生成”或“周报生成器”。
    *   你可以调整文案风格，比如把 `systemPrompt` 中的“电商运营专家”改为“幽默的段子手”，生成的文案风格会大变。
    *   你可以增加或减少输出结构，比如要求为每个版本再生成一个标题，那么就需要在 Prompt 的 JSON 示例里体现出来（但前端展示代码可能需要相应调整才能完美显示新数据）。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的 AI 工具：

**第一步：替换“场景”和“输入项”（最安全）**
保持所有代码结构不变，只修改文字和输入字段。例如，做一个 **“小红书笔记灵感生成器”**。
*   修改标题和图标。
*   将“活动类型”改为“笔记类型”（如好物分享、旅行攻略、美食探店）。
*   将“产品名称”改为“笔记主题”。
*   将“价格信息”改为“产品特点/地点信息”。
*   将“输出渠道”固定为“小红书”。
*   修改 `eventTypes` 和 `channels` 数组里的数据。

**第二步：改造 Prompt 以匹配新场景**
在 `generateCopy` 函数中，重写 `systemPrompt` 和 `userPrompt`。
*   `systemPrompt`: “你是一位资深小红书爆款文案写手...”
*   `userPrompt`: 重新描述任务，比如“请为‘好物分享’类笔记生成 3 个不同风格的正文版本，每个版本包含标题和正文，风格包括：真诚分享型、夸张安利型、干货测评型...”

**第三步：调整结果展示界面**
根据新 Prompt 可能返回的数据结构，微调右侧的展示模板。如果新结构只是文案内容，原有的卡片式展示可能完全适用。如果需要展示标题、正文、标签等，则需修改 `x-for` 循环内的 HTML 结构。

**从哪里下手最安全？**
从 **第一步** 开始。先不改任何逻辑代码，只做“文本替换”和“数据替换”（如 `eventTypes`）。这样你能立刻看到一个外观全新、但功能类似的应用，建立信心。然后逐步深入第二步和第三步。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“文案风格”选择**：在输入面板增加一个单选或下拉框，让用户选择“风格”，如“激情促销风”、“理性对比风”、“温情故事风”。将这个变量传入 Prompt，指导 AI 生成不同口吻的文案。
2.  **接入多模型 API**：在设置弹窗中增加一个“模型选择”下拉框（如 DeepSeek、GPT-4o、Claude等）。在 `generateCopy` 函数中根据选择动态修改请求的 URL 和参数。这能让用户对比不同模型的输出效果。
3.  **增加“灵感参考”功能**：在生成按钮旁增加一个“随机灵感”小按钮。点击后，用一组预设的、有趣的产品描述和卖点，快速填充表单，帮助用户打开思路。
4.  **优化交互体验**：
    *   **分步生成**：不要一次性生成所有内容。可以先让用户生成“预热期”文案，满意后再继续生成“爆发期”，减少等待时间，也方便中途调整要求。
    *   **文案编辑与微调**：允许用户直接在生成的文案卡片上点击进行微调修改，并提供一个“基于此版本重新生成”的按钮，实现人机协同创作。
5.  **拆分为多页面/工作流**：将工具扩展为一个迷你工作流。
    *   **页面一**：活动策划与信息输入（即当前页面）。
    *   **页面二**：文案生成与预览。
    *   **页面三**：文案效果评估与数据看板（可模拟展示点击率、转化率等，需连接后端）。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合生成法律、医疗等专业领域的严谨文本**：AI 可能产生事实性错误或表述不准确，此类文案需专业人士审核。
*   **不适合替代深度创意和策略思考**：它提供的是基于模板和信息的批量文案，无法替代人类对品牌调性、市场情绪和长远营销策略的深度规划。
*   **不适合处理实时个性化**：它无法根据用户的实时行为数据（如浏览记录）生成“千人千面”的文案。
*   **如果用户的需求是**：为一个全新的、没有成熟模板的复杂项目（如一场大型线下事件的全案策划）从零开始构思，那么应该使用更通用的 AI 对话工具（如 ChatGPT 网页版），进行多轮、自由的头脑风暴和内容创作，而不是使用此类结构化工具。
