# 拖延症诊断与治疗 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你面对一项任务（如写报告、学习、健身）时，明明知道应该去做，却总是找借口拖延，并因此感到焦虑、自责或无力。你不知道自己为什么拖延，也不知道如何有效开始。这个工具就像一个“心理教练”，帮你分析拖延背后的心理原因，并提供一套可立即执行的行动方案。

**适合情况：**
- 你正被某个具体任务拖延所困扰，想了解原因。
- 你需要一个结构化的、基于心理学的方法来打破拖延循环。
- 你希望获得个性化的、可操作的建议，而不是泛泛而谈的“鸡汤”。

**不适合情况：**
- 需要即时、高频互动的心理咨询或治疗。
- 拖延行为已严重影响到日常生活、工作或健康，需要专业医疗干预。
- 你只是想找一个“替你做决定”的工具，而不是进行自我反思。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你需要填写四个关键信息：
1.  **拖延的任务**：一个具体的任务名称（如“完成季度总结PPT”）。
2.  **拖延行为描述**：详细描述你是怎么拖延的、拖延了多久、以及拖延时的感受。
3.  **任务难度感受**：从下拉菜单中选择你对这个任务难度的主观感受。
4.  **截止时间**：选择任务的紧急程度。

**用户通常会做哪几步操作？**
1.  **首次使用**：点击右上角的齿轮图标，在弹出的设置窗口中输入你的 DeepSeek API Key 并保存。
2.  **描述问题**：在左侧“拖延症诊断”区域，依次填写上述四个输入项。
3.  **开始诊断**：点击“开始诊断”按钮。
4.  **查看报告**：等待片刻，右侧“诊断报告”区域会生成一份详细的 Markdown 格式报告。
5.  **使用工具**：在等待或阅读报告时，可以使用下方的“番茄钟计时器”来立即开始一段专注工作。

**输出结果长什么样？**
输出是一份结构清晰的诊断报告，通常包含：
-   **拖延类型**：将你的行为归类（如完美主义型、畏难型）。
-   **根因分析**：从心理、认知、环境等层面分析你为什么拖延。
-   **治疗方案**：提供具体的行为实验方法（如2分钟启动法）。
-   **行动清单**：列出今天就能开始的3-5个具体步骤。
如果选择了“深度思考”模型，你还可以点击展开查看AI的推理过程。

**有哪些容易忽略的使用细节？**
-   **API Key是必须的**：第一次使用前，务必在设置中配置好API Key，否则无法生成报告。
-   **描述越具体越好**：在“拖延行为描述”中，详细描述你的行为（如“我打开文档，然后刷了2小时短视频”），AI的分析会更精准。
-   **利用“思考过程”**：如果报告的建议你觉得不够贴切，展开“深度思考过程”看看AI是如何一步步推导的，这能帮你更好地理解自己的问题。
-   **番茄钟是独立工具**：即使不生成诊断报告，你也可以单独使用番茄钟来辅助专注。

## 【三】核心结构拆解（学习重点）

这个页面由三个主要模块组成，逻辑清晰，职责分明：

**1. 用户输入与状态管理模块（左侧面板）**
*   **职责**：收集用户关于拖延任务的所有关键信息（任务、行为、难度、截止时间），并管理这些数据的状态。
*   **组成**：四个表单字段（输入框、文本域、下拉菜单）和一个触发按钮。
*   **逻辑**：用户填写 → 数据被实时绑定到 `formData` 对象 → 点击按钮时，验证数据并触发“生成”函数。

**2. AI 诊断与报告生成模块（核心引擎）**
*   **职责**：将用户输入结构化，调用AI API，处理返回的流式数据，并最终渲染出可读的报告。
*   **组成**：`generate` 函数、API 配置、Prompt 模板、流式数据处理逻辑。
*   **逻辑**：`formData` + `系统Prompt` → 拼接成完整的用户请求 → 调用 DeepSeek API → 流式接收数据 → 分离“思考内容”和“最终回答” → 更新页面上的 `reasoningContent` 和 `result`。

**3. 结果展示与工具模块（右侧面板）**
*   **职责**：清晰、友好地展示AI生成的内容，并提供额外的实用工具。
*   **组成**：报告展示区（支持Markdown）、思考过程折叠面板、复制/导出按钮、独立的番茄钟计时器。
*   **逻辑**：接收 `result` 和 `reasoningContent` 数据 → 用 `marked` 库将Markdown转换为HTML渲染 → 提供结果复用工具（复制、导出）和行为启动工具（番茄钟）。

**最值得学习的设计：**
**“输入-处理-输出”的清晰分离与状态驱动**。整个应用围绕几个核心的“状态变量”（如 `formData`, `result`, `isLoading`）运转。UI只是这些状态的映射。这种设计使得：
-   业务逻辑（AI调用）与界面逻辑完全解耦。
-   增加新功能（如新的输入字段）只需修改状态和对应的UI部分，不会影响其他模块。
-   流式数据的处理被优雅地封装在 `generate` 函数中，用户体验流畅。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt 在这里扮演 **“专家系统框架”** 的角色。它不是一个简单的提问，而是为AI设定了一个专业的身份、明确的任务流程和严格的输出格式。

**它解决的是“理解问题”还是“生成问题”？**
两者兼有，但更侧重于 **“结构化生成”**。
1.  **理解**：系统Prompt让AI以“心理咨询师和行为治疗专家”的视角来“理解”用户描述的拖延问题。
2.  **生成**：它更关键的作用是指引AI按照“识别类型 → 分析根因 → 提供方案 → 列出步骤”这个固定流程来“生成”内容，并确保输出是格式规范的Markdown。

**哪些信息是 Prompt 中的关键变量？**
-   **角色与领域**：`心理咨询师和行为治疗专家`、`行为心理学`。
-   **任务流程**：`识别拖延类型`、`根因分析`、`行为实验方案`、`个性化建议` 这四个固定步骤。
-   **输出格式**：明确的Markdown标题结构（`#`、`##`）。
用户填写的 `formData` 会被动态拼接到一个更简单的用户Prompt中，作为专家进行分析的具体案例。

**如果只改 Prompt，不改代码，会发生什么变化？**
你可以彻底改变这个工具的应用领域，而无需改动一行前端代码。例如：
-   将系统Prompt改为“你是资深职业规划师…”，输入字段改为“当前职业”、“困惑”、“技能”，它就变成了一个**职业规划咨询工具**。
-   将系统Prompt改为“你是创意写作教练…”，输入字段改为“故事类型”、“卡住的情节”、“角色设定”，它就变成了一个**写作障碍突破工具**。
**Prompt定义了工具的“灵魂”，而前端代码只是提供了与这个灵魂对话的“身体”。**

## 【五】如何模仿它，做出你自己的版本？

遵循以下路径，你可以安全、高效地创建一个全新的AI工具：

**第一步：替换核心场景与Prompt（最安全）**
-   **做什么**：完全保留现有的页面布局、输入表单和代码结构。
-   **改什么**：
    1.  修改 `index.html` 中的 `<title>` 和页面大标题。
    2.  修改 `apiConfig.systemPrompt`，将其重写为你新领域专家的Prompt（例如“健身教练”、“学习策略顾问”）。
    3.  修改左侧输入表单的 `label` 和 `placeholder`，使其匹配新场景的输入需求（例如将“拖延的任务”改为“健身目标”）。
-   **效果**：你立即得到了一个在新领域下运行的工具原型。

**第二步：调整输入与输出数据结构**
-   **做什么**：根据新场景的需要，增加、删除或修改输入字段。
-   **改什么**：
    1.  在 `formData` 对象中增加或删除属性（如增加 `currentWeight`, `targetWeight`）。
    2.  在HTML模板中增加或删除对应的表单控件，并使用 `v-model` 与 `formData` 的新属性绑定。
    3.  在 `generate` 函数中，更新 `userPrompt` 的拼接逻辑，包含新的字段。
-   **效果**：你的工具能收集更贴合场景的信息，生成更精准的回答。

**第三步：定制化输出展示与交互**
-   **做什么**：让结果的展示方式更符合你的内容特点。
-   **改什么**：
    1.  修改系统Prompt中的 **输出格式** 部分，定义新的章节标题。
    2.  在CSS中（`.prose` 部分）调整报告内容的样式，比如改变标题颜色、字体。
    3.  可以增加新的交互，比如为报告中的每个建议添加“标记为完成”的复选框。
-   **效果**：提升用户体验，使工具更具专业性和粘性。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“历史记录”功能**：
    -   **操作**：在 `localStorage` 中创建一个数组，每次生成报告后，将 `formData`、`result` 和时间戳保存进去。在页面左侧或新增一个面板，列出所有历史记录，点击可以重新加载查看。
    -   **价值**：用户可以追踪自己不同任务的拖延模式和治疗进展，工具实用性大增。

2.  **切换或支持多模型/多API**：
    -   **操作**：在设置弹窗中，增加一个API提供商的下拉选择（如DeepSeek、OpenAI、智谱AI）。为 `apiConfig` 增加 `provider` 和 `baseURL` 等字段，在 `generate` 函数中根据选择动态构建请求URL和头部信息。
    -   **价值**：提高工具的灵活性和可用性，用户可以根据成本、速度、效果选择不同的模型。

3.  **将“番茄钟”与“诊断”联动**：
    -   **操作**：在生成的“行动清单”中，为每个步骤旁边添加一个“开始番茄钟”的小按钮。点击后，自动将番茄钟的默认时间调整为该步骤的推荐时长（可从Prompt中让AI返回），并开始计时。
    -   **价值**：从“分析诊断”到“行动执行”形成闭环，极大提升工具的行动导向性。

4.  **优化为多步骤引导式问卷**：
    -   **操作**：将当前单页表单拆分成多个步骤。例如，第一步只填写任务，点击“下一步”后显示关于行为描述的问题，再下一步是难度和截止时间。使用Vue的 `v-if` 或组件来控制步骤显示。
    -   **价值**：降低用户首次使用的认知负荷，尤其适合问题更复杂、需要更多输入的场景。

5.  **增加社交分享或匿名社区功能**：
    -   **操作**：在报告底部添加“分享我的经历”按钮。点击后，可以匿名将“任务类型”和“行动清单”发布到一个简单的公共时间线（初期可用 `localStorage` 模拟，后期接入后端）。
    -   **价值**：让用户感到不是独自在战斗，通过观察他人的挑战和方案获得启发，增加工具粘性。

## 【七】这个网页不适合做什么？（边界提醒）

-   **不适合替代专业心理治疗或医疗诊断**：本工具基于通用的行为心理学模型提供建议，适用于常见的、情境性的拖延问题。它**不能**诊断或治疗注意力缺陷多动障碍（ADHD）、抑郁症、焦虑症等可能表现为拖延的临床心理疾病。如果拖延已严重损害你的社会功能、或伴随持续的情绪低落、自我价值感极低，请务必寻求注册心理咨询师或精神科医生的帮助。

-   **不适合处理极度复杂或模糊的问题**：工具的分析依赖于你提供的、相对结构化的信息。如果你面临的问题极其复杂、涉及多重人生目标、价值观冲突或伦理困境（如“我该不该换工作/离婚”），AI可能无法给出足够深入和负责任的建议。这类问题更适合与人生导师、职业顾问或信任的亲友进行深度探讨。

-   **不适合作为完全自动化的决策工具**：工具输出的“行动清单”是建议，而非指令。它缺乏对你个人全部历史、具体环境细节和实时情绪的完全了解。**你始终是自己生活的最终决策者**。请批判性地采纳AI的建议，结合自身判断进行调整，并对自己选择的行为负责。
