# 危机公关模拟 - AI 创意生成器 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页是一个**危机公关实战模拟训练器**。想象一下，你是一家公司的公关负责人，突然遭遇了数据泄露、产品安全或高管丑闻等危机。面对咄咄逼人的记者，你需要在高压下快速、得体地回应，保护公司声誉。

- **使用场景**：
  - **公关/市场/品牌从业者**：在真实危机发生前，进行无风险的模拟演练。
  - **企业管理者/创业者**：学习如何在公众面前应对突发负面事件。
  - **学生/求职者**：准备面试中可能遇到的“危机处理”案例分析题。
  - **沟通技巧学习者**：练习在压力下保持冷静、清晰、有同理心的表达。

- **适合情况**：当你需要**练习**或**体验**危机沟通的紧张感，并希望获得即时反馈时。
- **不适合情况**：如果你需要处理**真实**的公关危机、撰写**正式**的官方声明，或进行**团队协作**的危机管理演练。它只是一个**单人模拟训练工具**。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    - 首先，你需要从下拉菜单中选择一个**危机场景**（如“大规模数据泄露事件”）。
    - 进入模拟后，在底部的输入框中，以**公司发言人**的身份，输入你的回应。

2.  **用户通常会做哪几步操作？**
    - **第一步：选择场景** - 从三个预设的危机场景中选一个。
    - **第二步：进入模拟** - 点击“进入发布会现场”，AI记者会立刻向你提出尖锐问题。
    - **第三步：回应记者** - 在输入框中，构思你的回答，然后发送。AI记者会根据你的回答，提出下一个问题。这个过程可以反复进行。
    - **第四步：结束复盘** - 当你觉得演练得差不多了，点击“结束并复盘”。AI公关专家会对你刚才的所有回答进行评分和分析。

3.  **输出结果长什么样？**
    - **模拟过程**：界面像一个聊天窗口，左边是AI记者的提问（灰色气泡），右边是你的回答（蓝色气泡）。
    - **复盘报告**：点击“结束并复盘”后，会弹出一个窗口，里面是一份结构化的分析报告，从多个维度（如信息控制力、同理心等）给你打分，并提供具体的改进建议。

4.  **有哪些容易忽略的使用细节？**
    - **API设置**：页面右上角的齿轮图标可以打开设置面板。如果你有自己的AI API（如DeepSeek），可以在这里配置，否则会尝试使用一个默认的Key。
    - **“放弃并重置”**：这个按钮会直接清空当前对话，回到场景选择页面，不会生成复盘报告。
    - **复盘模型**：系统在生成复盘报告时，可能会自动切换到一个更擅长分析的AI模型（如“thinking”模型），以获得更深刻的分析。

## 【三】核心结构拆解（学习重点）

这个页面由四个清晰的核心模块组成：

1.  **场景配置模块** (`#setup-container`)
    - **职责**：让用户选择训练主题，是模拟的“启动器”。
    - **逻辑**：用户选择 → 点击开始 → 触发整个模拟流程。

2.  **对话模拟模块** (`#chat-container-wrapper`)
    - **职责**：这是**核心交互区**。它模拟新闻发布会现场，展示AI记者与用户的实时对话。
    - **逻辑**：
        - **输入**：用户输入的回应文本。
        - **处理**：将用户输入和历史对话一起，发送给AI API，请求生成下一个记者提问。
        - **输出**：在聊天界面中展示记者的新问题。
    - **最值得学习的设计**：**“对话状态”的完整管理**。页面不仅记录对话内容，还维护着一个 `conversationHistory` 数组，里面包含了给AI的“系统指令”（扮演记者）、所有历史问答。这使得每次交互都是基于完整上下文的，模拟非常连贯。

3.  **复盘分析模块** (`#analysis-modal`)
    - **职责**：在模拟结束后，提供专业、结构化的反馈。这是**价值升华**的部分。
    - **逻辑**：将整个对话历史整理成文本，嵌入一个精心设计的“分析提示词”（Prompt）中，发送给AI，请求其以“危机公关专家”的身份生成报告。

4.  **系统设置模块** (`#settings-panel`)
    - **职责**：管理应用与AI服务（后端）的连接参数，使工具可以灵活适配不同的AI接口。

**整体逻辑链路**：
**选择场景** → **加载记者角色设定** → **用户与AI记者对话** → **收集完整对话记录** → **用另一套Prompt请求AI分析** → **获得结构化复盘报告**。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，**Prompt（提示词）是驱动整个模拟的“灵魂剧本”**。

1.  **扮演什么角色？**
    - **在模拟阶段**：Prompt 用于**定义AI记者的角色、性格和提问风格**（例如：“扮演《科技前沿》的资深调查记者，敏锐、问题尖锐…”）。它解决的是“**生成问题**”——让AI能持续提出符合场景的、有挑战性的问题。
    - **在复盘阶段**：另一个Prompt 用于**定义AI分析专家的视角和分析框架**（例如：“你是一位顶级的危机公关专家，请从以下五个维度进行分析…”）。它解决的是“**理解与评价问题**”——让AI能基于对话记录，进行结构化评估。

2.  **关键变量是什么？**
    - **记者Prompt中的变量**：`{公司名}`（如“星云科技”）、`{事件详情}`（如“数据泄露”）、`{记者身份}`、`{提问焦点}`。这些变量被硬编码在 `crisisScenarios` 对象里。
    - **分析Prompt中的变量**：整个**对话记录文本**。这是动态生成的，包含了用户的所有表现。

3.  **如果只改Prompt，不改代码，会发生什么？**
    - **改变记者Prompt**：AI记者的**提问风格和攻击点**会完全不同。比如，把记者从“尖锐调查”改成“温和求证”，整个模拟的难度和氛围就变了。
    - **改变分析Prompt**：复盘报告的**分析维度和输出格式**会改变。比如，增加“媒体关系处理”维度，或要求输出一个SWOT分析，报告就会以新的形式呈现。
    - **结论**：**Prompt决定了AI的行为和产出内容**。修改Prompt是成本最低、效果最直接的“玩法”定制方式。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个“三步替换法”，安全地创建属于自己的模拟训练器：

**第一步：替换核心场景与角色（最安全、最直观）**
- **目标**：做一个“**产品经理需求评审模拟器**”。
- **操作**：
    1.  修改 `crisisScenarios` 对象。把“数据泄露”换成“一个模糊的用户需求”，把“记者”换成“挑剔的研发工程师”。
    2.  例如：`pm_review: { title: “模糊的需求文档”， engineer: “资深后端工程师”， system_prompt: “你将扮演一位经验丰富但怕麻烦的后端工程师。面对产品经理提出的一个逻辑模糊、边界不清的需求，你的目标是刨根问底，找出所有技术实现上的漏洞和歧义点。你会追问‘这个状态机具体有哪几种状态？’‘异常流程怎么处理？’‘这个数据和那个系统的数据如何同步？’。你的语气直接，略带不耐烦。” }`
    3.  修改页面上的标题和提示文字，如“选择一个评审场景”、“作为产品经理澄清需求…”。

**第二步：调整输入与交互细节**
- **目标**：让交互更贴合新场景。
- **操作**：
    1.  将输入框的提示语从“作为发言人回应…”改为“作为产品经理，请澄清需求…”。
    2.  将“结束并复盘”按钮的文案改为“结束并获取评审意见”。
    3.  在复盘报告的Prompt中，将分析维度从“信息控制力、责任担当”等，改为“需求明确性、逻辑严谨性、可实施性”等。

**第三步：改变输出形式或增加功能**
- **目标**：深化应用价值。
- **操作**：
    1.  除了文字复盘，可以要求AI在分析后，**自动生成一份优化后的需求要点清单**。
    2.  在设置中，增加一个“角色性格强度”滑块，让用户选择工程师是“温和探讨型”还是“犀利挑战型”。

**从哪里下手最安全？**
从 **第一步** 开始。直接修改 `crisisScenarios` 这个JavaScript对象，并相应地改几个网页标题和按钮文字，你就能立刻得到一个完全不同主题的对话模拟器。代码的主体结构（聊天、发送、接收）完全不需要动。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“自定义危机”输入**：
    - **操作**：在场景选择下拉框旁边，增加一个“自定义”选项。选择后，弹出表单让用户填写“公司名称”、“事件简述”、“涉及方”等。前端动态将这些信息拼接到一个通用的记者Prompt模板中。
    - **效果**：工具从一个固定场景训练器，升级为一个可应对任意假想危机的灵活工具。

2.  **引入“多轮次”与“分数系统”**：
    - **操作**：不要一次对话就结束。可以设定模拟进行3-5个问答回合后自动结束。每一轮，AI不仅提问，还根据用户的回答**实时给出本轮得分**（如“本轮责任担当：+2分”），并在聊天框侧面显示一个动态更新的总分进度条。
    - **效果**：增加游戏的即时反馈和挑战性，学习过程更像闯关。

3.  **更换或扩展AI后端**：
    - **操作**：在设置面板的模型列表里，加入支持 **OpenAI GPT-4o**、**Claude 3.5** 或 **国内月之暗面/智谱** 等模型的API端点选项。只需修改 `callApi` 函数中的请求头 (`headers`) 和请求体 (`body`) 格式，以适配不同厂商的API规范。
    - **效果**：可以体验不同AI模型的“演技”（提问风格）和“智慧”（分析深度）。

4.  **优化复盘报告的展示形式**：
    - **操作**：不要只展示一大段文字。将AI返回的文本解析成更友好的格式。例如，用不同颜色的进度条可视化五个维度的分数；把“核心建议”做成可折叠的卡片列表；甚至用 `chart.js` 画一个雷达图来展示能力维度。
    - **效果**：复盘报告一目了然，更具专业感和冲击力，方便用户快速抓住重点。

5.  **拆分为“训练模式”与“挑战模式”**：
    - **操作**：在首页增加一个模式选择。“训练模式”下，用户每次发送回答后，AI可以给出小提示（如：“这个回答在体现同理心方面可以加强”）。而“挑战模式”下，AI记者会更咄咄逼人，且没有中途提示，最后只有一个冷酷的最终评分。
    - **效果**：适应不同水平用户的需求，从学习到实战，梯度分明。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合用于真实的危机决策**：这个工具的所有反馈都基于AI对语言模式的生成和理解，**并非真正的公关智慧或法律建议**。在真实危机中，你必须依赖专业的公关团队、法律顾问和公司高层决策。
- **不适合评估团队协作**：它模拟的是单人面对媒体的场景。真实的危机处理是一个团队行动，涉及内部沟通、法律、运营等多部门协作，这个工具无法模拟。
- **不适合生成可直接发布的官方文书**：AI生成的发言内容可能存在风险、不准确或不符合公司正式语态。所有输出都应被视为“练习草稿”，需要由人类专家严格审核和重写。
- **如果你的需求是**：进行**多人角色扮演**、管理**漫长的危机时间线**、或者处理**涉及具体法律条文和财务数据**的复杂案例，你应该寻找更专业的**商业模拟软件**或**聘请咨询公司进行定制化培训**。
