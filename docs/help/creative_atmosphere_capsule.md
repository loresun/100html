# 今日气氛胶囊 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你刚经历了一个特别的时刻——也许是午后的一场小雨，也许是咖啡馆里的一段独处时光。你想把这种“感觉”记录下来，但普通的日记显得平淡，发朋友圈又觉得不够特别。这时，你需要一个能帮你把零散的“天气”、“心情”、“场景”组合成一段有画面感、有温度的文字描述的工具。

**“今日气氛胶囊”就是这样一个工具。** 它像一个创意催化剂，帮你将日常的碎片感受，封装成一张可以分享、可以回味的“氛围卡片”。

*   **适合使用的情况：**
    *   记录日常中值得品味的瞬间（如：微雨的早晨、加班的深夜）。
    *   为社交媒体（朋友圈、小红书）创作有格调的配文。
    *   作为写作或创意的灵感启动器。
    *   进行简单的情绪梳理和自我觉察。

*   **不适合使用的情况：**
    *   需要长篇、结构化的日记或文章。
    *   需要精确、客观的事实记录（如工作日志）。
    *   需要深度心理分析或专业情绪辅导。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置：** 页面右上角有一个齿轮图标⚙️，点击它。在弹出的窗口中，输入你的 **DeepSeek API Key**（你需要自行在 DeepSeek 官网申请），然后点击“保存配置”。这是让网页“活”起来的关键一步。

2.  **输入你的“氛围原料”：**
    *   **天气：** 描述外部环境（如：阳光明媚、阴雨绵绵、大雪初霁）。
    *   **心情：** 描述内心感受（如：雀跃、宁静、淡淡的忧伤）。
    *   **场景：** 描述具体地点或事件（如：书房窗边、下班路上、与朋友视频）。

3.  **生成：** 点击 **“生成气氛”** 按钮。稍等片刻，你会看到右侧的“胶囊卡片”区域发生变化。

4.  **查看结果：**
    *   **色彩：** 卡片上方会出现一组随机变化的柔和色彩，为你的氛围定下视觉基调。
    *   **文字：** 卡片主体会生成一段约80字左右的、富有诗意的氛围描述，并附上一句行动建议。例如：“微雨让咖啡店的玻璃蒙上一层薄雾，空气里是豆子烘焙的焦香和雨水的清冽。心情像杯中的拿铁，表面平静，底下有温柔的漩涡。建议：给想念的人发一条‘下雨了’的消息。”

5.  **容易忽略的细节：**
    *   **API Key 是必需的**，且需要正确配置，否则会报错。
    *   输入框可以为空，AI 会使用默认词（如“平静”、“日常”）进行补充。
    *   每次点击“生成气氛”，色彩组合都会随机变化。
    *   生成的文字可以直接复制使用。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

1.  **控制模块（左侧卡片）**
    *   **职责：** 接收用户输入，触发生成动作，并显示可能的错误。
    *   **组成：** 三个输入框 + 一个生成按钮 + 错误提示区。
    *   **逻辑：** 用户填写信息 → 点击按钮 → 模块收集数据并调用处理模块。

2.  **展示模块（右侧卡片）**
    *   **职责：** 可视化地呈现生成结果。
    *   **组成：** 标题 + 色彩调色板 + 文字展示区。
    *   **逻辑：** 接收来自处理模块的“色彩数组”和“文本内容” → 更新界面进行渲染。

3.  **逻辑处理模块（隐藏在代码中）**
    *   **职责：** 协调所有操作，是页面的“大脑”。
    *   **关键功能：**
        *   **随机色彩：** 从预设的几组配色中随机挑选一组。
        *   **构造 Prompt：** 将用户的输入整理成 AI 能理解的指令。
        *   **调用 AI API：** 与 DeepSeek 服务器通信，获取生成的文本。
        *   **状态管理：** 控制加载状态、错误提示和配置弹窗。

**输入 → 处理 → 输出 的逻辑链路：**
用户输入（天气、心情、场景）→ 点击生成 → **① 随机选取配色** → **② 拼接成完整 Prompt** → **③ 调用 AI API** → **④ 接收 AI 返回的文本** → 同时将 **① 的配色** 和 **④ 的文本** 输出到展示模块。

**最值得学习的设计：**
**“氛围感”的即时可视化反馈。** 在等待 AI 生成文字的同时，程序会先随机更换一组配色。这个细微的设计极大地提升了体验：它让等待过程不再枯燥，色彩的提前变化让用户对即将生成的“氛围”有了一个初步的、感性的预期，实现了从“输入”到“输出”的平滑过渡。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt 的角色：** 它是用户与 AI 之间的“翻译官”和“导演”。它把用户零散的几个关键词，翻译成一个完整的、有明确要求的创作任务，并指导 AI 以特定的风格（诗意、简洁）和格式（80字内，含建议）来执行。

*   **解决的问题：** 它主要解决的是“生成问题”。用户提供了“原材料”（关键词），但不知道如何组织成优美的文字。Prompt 定义了生成的目标、风格和边界。

*   **Prompt 中的关键变量：**
    1.  **系统指令 (`system`):** `你是一位氛围策展人，用简洁诗意的语言描述气氛。` —— 这设定了 AI 的“人设”和文风。
    2.  **用户输入 (`user`):** `天气：${weather}\n心情：${mood}\n场景：${scene}` —— 这是核心的变量信息，来自用户的输入框。
    3.  **任务指令:** `请生成一段 80 字以内的气氛描述，并给出一句行动建议。` —— 这是对输出结果的具体格式和内容要求。

*   **如果只改 Prompt，不改代码，会发生什么？**
    整个网页的“产出”性质会完全改变。例如：
    *   将系统指令改为 `你是一位毒舌评论家`，输出会变得犀利讽刺。
    *   将任务指令改为 `请生成一首五言绝句`，输出会变成古诗。
    *   在用户输入部分增加 `时间：${time}`，并在表单中增加“时间”输入框，AI 就能将时间元素融入氛围描述。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的 AI 小工具：

1.  **第一步：替换“场景”与“外壳”**
    *   **目标：** 先跑通整个流程，获得成就感。
    *   **操作：** 保持所有代码结构完全不变，只修改文字内容。
    *   **例如：** 把“今日气氛胶囊”改为“职场沟通助手”。把输入框的提示文字改为“沟通对象：”、“沟通目的：”、“我的情绪：”。把标题和说明文字也相应修改。此时，点击生成，它还是会输出一个“氛围描述”，但这证明你的基础框架是能工作的。

2.  **第二步：调整输入与 Prompt**
    *   **目标：** 让工具真正为你想要的场景服务。
    *   **操作：** 在 HTML 中增加或减少输入框（如增加“对方性格”输入框）。然后，在 JavaScript 的 `generateCapsule` 函数里，找到拼接 `payload` 的那行代码，按照新的输入框变量修改 Prompt 模板。比如：`const payload = `沟通对象：${form.value.target}\n我的目标：${form.value.goal}\n...请生成一段得体的沟通开场白...`;`

3.  **第三步：改变输出与展示形式**
    *   **目标：** 优化结果呈现，使其更符合你的需求。
    *   **操作：** 你可以修改右侧展示卡片。例如，不再显示随机色彩，而是显示一个代表“沟通风格”的图标（如“正式”、“轻松”）。或者，将 AI 返回的文本拆分成“核心要点”和“话术示例”两个部分来展示。

**从哪里下手最安全？**
从 **第一步** 开始。只改文字不改代码逻辑，风险为零，能帮你快速理解页面各个部分是如何对应起来的。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格选择器”输入：** 在生成按钮上方增加一个下拉菜单，让用户选择“文风”，如“诗意”、“幽默”、“科幻”。将这个选项作为变量加入到 Prompt 中（例如：“请以[幽默]的风格生成...”）。这能极大地提升生成结果的可控性和趣味性。

2.  **更换或扩展 AI 模型/API：** 代码中已经为配置不同的 DeepSeek 模型留出了接口。你可以尝试将其改造成支持 OpenAI (GPT)、Claude 或国内其他大模型的工具。只需在设置弹窗增加模型选择，并修改 `callLLM` 函数中的请求地址和参数格式即可。

3.  **增加“历史记录”功能：** 将每次生成的“胶囊”（包括输入参数、配色、生成文本和时间戳）保存到浏览器的 `localStorage` 中。然后在页面底部或一个新页面里展示出来，形成一个可回顾的“氛围日记本”。

4.  **优化交互体验：**
    *   **回车键提交：** 为输入框绑定键盘事件，当用户按下回车键时，自动触发 `generateCapsule` 函数。
    *   **示例填充：** 在输入框旁边增加一个“举个栗子🌰”按钮，点击后自动用优美的示例填充三个输入框，引导用户理解该如何使用。
    *   **加载动画：** 将按钮的 `:disabled` 状态做得更明显，或者添加一个旋转的加载图标，让等待反馈更清晰。

5.  **拆分为多页面应用：** 将“设置页面”、“生成页面”和“历史记录页面”拆分成独立的 HTML 文件。通过导航栏或链接跳转。这可以让项目结构更清晰，也是学习单页应用(SPA)之前很好的练习。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合进行精确或专业的创作：** 它生成的文字是创意性和感受性的，**不适合**用于需要严格准确性的场景，如法律文书、医疗建议、学术论文的撰写。
*   **不适合处理复杂逻辑或长篇内容：** 它的设计是轻量、快速的。如果你需要 AI 进行复杂的推理、分析长文档、或者编写千字以上的文章，应该使用更专业的 AI 写作平台或直接与 ChatGPT 等工具进行多轮深度对话。
*   **隐私提醒：** 你输入的天气、心情、场景信息以及生成的文本，都会通过互联网发送到 DeepSeek 的服务器。**请勿输入任何个人敏感信息、密码、隐私内容。** 这是一个展示技术原理的示例工具，并非高安全级别的产品。
*   **依赖性与成本：** 它完全依赖第三方 AI API（DeepSeek）的服务。如果该 API 服务不可用、更改或开始收费，这个网页的功能将受到影响。自己制作版本时，需要考虑到 API 的调用成本和稳定性。
