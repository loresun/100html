# 商务谈判练习室 - 帮助与学习指南

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页是一个**商务谈判模拟训练器**。它主要解决以下场景中的问题：

**使用场景：**
- **场景一：面试准备** - 你即将参加一个重要的薪酬谈判，但缺乏实战经验，心里没底。这个工具可以让你在零风险的环境下，与一个“资深HR”反复练习，找到最佳话术。
- **场景二：业务实战前演练** - 你是一名采购经理，下周要和供应商谈一个百万订单。你可以在这里设定好你的目标（单价、交货期）和底线，提前模拟整个谈判过程，预判对方的反应。
- **场景三：学习谈判理论** - 你刚学习了“BATNA”（最佳替代方案）、“价值创造”等谈判概念，但不知道如何在现实中运用。这个工具提供了一个结构化的框架，让你把理论付诸实践，并获得AI的复盘反馈。

**适合情况：**
- 需要快速、低成本地进行谈判模拟练习。
- 希望通过结构化（目标、底线）的方式准备谈判。
- 想获得一个“第三方视角”来复盘自己的谈判策略。

**不适合情况：**
- **真实的法律或合同谈判**：这只是一个模拟器，无法替代真实的法律咨询和复杂的商业尽职调查。
- **需要处理极端情绪或复杂人际关系的谈判**：AI对手的“情绪”是模拟的，无法完全复现真人谈判中的微妙心理战。
- **需要即时、多轮复杂数据计算的谈判**：它侧重于语言和策略的交互，不适合模拟涉及大量实时数据演算的场景（如金融衍生品交易）。

## 【二】使用方式（给第一次接触的人）

**第一步：设定场景**
1.  打开页面，你会看到一个“设定你的谈判场景”区域。
2.  **选择预设场景**：从下拉菜单中选一个，比如“与供应商进行价格谈判”。
3.  **填写你的信息**：
    *   **你的角色**：输入你扮演的角色，如“采购经理”。
    *   **你的谈判目标**：用SMART原则描述你想达成的具体结果，例如“单价≤$15，2周内交货”。
    *   **你的谈判底线**：描述你的“BATNA”（最佳替代方案），即什么条件下你会放弃谈判，例如“单价>$18或交货>1个月，就找备选供应商”。
4.  点击 **“开始谈判”**。

**第二步：进行模拟对话**
1.  页面会切换到一个类似微信的聊天界面。AI对手（如“供应商销售总监”）会先发言。
2.  在底部的输入框中，**输入你的回应**，就像真的在聊天一样。你可以报价、提问、让步、施加压力。
3.  点击发送按钮（或按回车键），AI会基于它的“秘密目标”和“底线”来回复你。
4.  如此往复，进行多轮对话，直到你觉得谈判可以告一段落。

**第三步：获取复盘报告**
1.  对话结束后，点击右下角的 **“结束谈判并复盘”** 按钮。
2.  会弹出一个窗口，AI会扮演“哈佛谈判学教授”，根据你设定的目标、底线和完整的对话记录，给你一份**结构化评分报告**。
3.  报告会从“谈判结果”、“价值创造”、“价值获取”、“策略运用”几个维度给你打分（满分10分），并给出具体的改进建议。

**输出结果什么样？**
- **对话过程**：一个左右分明的聊天记录，你的话在右侧（蓝色气泡），AI的话在左侧（灰色气泡）。
- **复盘报告**：一个带有评分和分点建议的详细文档，会用加粗字体突出关键结论。

**容易忽略的细节：**
- **“API设置”齿轮图标**：在页面右上角。如果你有自己的AI API（如DeepSeek、豆包），可以在这里配置，否则会使用默认设置。
- **你的“目标”和“底线”是秘密**：AI对手只知道你的开场陈述（目标），但不知道你的详细底线（BATNA）。同样，你也不知道AI的底线。这模拟了真实谈判中的信息不对称。
- **复盘模型可能不同**：生成对话的AI模型和生成复盘报告的AI模型可能是不同的（后者可能更擅长分析），这是为了优化效果的设计。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个核心模块，像一个流水线：

**1. 场景配置模块 (`#setup-container`)**
*   **职责**：收集用户的“模拟参数”。这是整个应用的“导演台”。
*   **输入**：用户选择的场景、自定义的角色、目标、底线。
*   **处理**：将这些参数与预设的AI对手信息（角色、目标、底线）打包，形成一个完整的“谈判剧本”。
*   **输出**：一个包含双方所有信息的 `negotiationData` 对象。

**2. 对话模拟模块 (`#chat-container-wrapper`)**
*   **职责**：执行“谈判剧本”，管理对话流程。
*   **输入**：上一步生成的 `negotiationData`。
*   **处理**：
    *   **核心**：根据`negotiationData`，动态生成一个给AI的 **“角色扮演Prompt”**（在 `createNegotiatorPrompt` 函数中）。这个Prompt告诉AI：“你现在是XX角色，你的秘密目标是…，你的底线是…，现在对手说了XX，请开始对话。”
    *   将用户每轮输入和AI回复记录到 `conversationHistory` 数组中。
    *   通过调用AI API，获取AI的回应。
*   **输出**：可视化的聊天记录和内部的对话历史数组。

**3. 复盘分析模块 (`#analysis-modal`)**
*   **职责**：对模拟过程进行“赛后总结”。
*   **输入**：完整的 `negotiationData` 和 `conversationHistory`。
*   **处理**：
    *   生成另一个 **“分析型Prompt”**（在 `createAnalysisPrompt` 函数中）。这个Prompt告诉AI：“你现在是哈佛教授，这是背景和全部对话，请从以下几个维度进行分析…”
    *   调用（可能不同的）AI模型来生成结构化报告。
*   **输出**：一份包含评分和建议的复盘报告。

**4. 系统配置模块 (`#settings-panel`)**
*   **职责**：管理应用的“发动机”（AI API）。让应用可以灵活切换不同的AI服务。
*   **输入**：用户输入的API地址、密钥和模型选择。
*   **处理/输出**：将配置保存到浏览器的本地存储(`localStorage`)，供其他模块调用。

**逻辑链路：**
**用户输入场景参数** → **打包成“谈判剧本”** → **用“角色Prompt”启动AI对话** → **多轮交互，记录历史** → **用“分析Prompt”请求复盘** → **输出报告**

**最值得学习的设计：**
**“双Prompt引擎”设计**。这是本页面的精髓。它没有用一个复杂的程序逻辑去模拟谈判策略，而是用两个精心设计的Prompt（一个用于“角色扮演对话”，一个用于“结构化分析”）来驱动AI完成核心任务。这极大地简化了代码复杂度，将“智能”部分外包给了大语言模型，前端只负责流程控制和界面展示。这是一种非常高效且易于维护的AI应用架构。

## 【四】Prompt / AI 逻辑是如何被设计的？

**1. Prompt扮演的角色：**
在这个页面中，Prompt不是简单的提问，而是 **“角色定义卡”** 和 **“任务说明书”**。它设定了AI的行为边界、知识背景和输出格式。

**2. 解决的是“生成问题”还是“理解问题”？**
主要是 **“生成问题”**。它要求AI根据给定的角色、目标和对话历史，生成符合上下文的、策略性的下一句对话。复盘Prompt则要求AI根据既定格式“生成”一份分析报告。AI的“理解”能力被用于消化这些复杂的指令和上下文。

**3. Prompt中的关键变量：**
- **角色变量**：`${negotiationData.ai_role}`（AI扮演谁），`${negotiationData.user_role}`（用户是谁）。
- **秘密信息变量**：`${negotiationData.ai_goal}`（AI目标），`${negotiationData.ai_batna}`（AI底线）。这些是驱动AI行为的核心。
- **用户输入变量**：`${negotiationData.user_goal}`（用户开场白），以及对话历史中用户的每一条消息。
- **结构化输出要求**：在复盘Prompt中，明确的“### 分析要求”和“### 输出格式”是关键，它们强制AI生成我们想要的格式。

**4. 如果只改Prompt，不改代码，会发生什么？**
整个应用的行为会发生**根本性改变**。例如：
- 修改角色扮演Prompt中的“你的性格沉着、老练”为“你的性格急躁、强势”，AI对手的谈判风格会完全不同。
- 在复盘Prompt中增加一个分析维度“**情绪管理能力**”，那么生成的报告就会多出这一项的评分和建议。
- 如果把场景从“商务谈判”改成“医患沟通”，只需修改Prompt中的角色、目标描述，整个应用就变成了一个医患沟通练习工具。**代码几乎不用动**。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，逐步打造一个属于自己的模拟训练器：

**第一步：替换核心场景与数据（最安全）**
*   **目标**：先做出一个“换皮”版本，理解数据流动。
*   **操作**：
    1.  找到 `scenarios` 对象。把里面的三个场景（价格谈判、薪酬谈判、项目延期）换成你自己的，比如“**客户投诉处理练习**”、“**产品需求评审模拟**”、“**家长会沟通演练**”。
    2.  对应修改每个场景下的 `title`（标题）、`ai_role`（AI角色）、`ai_goal`（AI目标）、`ai_batna`（AI底线）。
    3.  修改HTML中“你的角色”、“你的目标”等输入框的提示文字（`placeholder`），使其符合新场景。
*   **效果**：你立刻得到了一个全新领域的练习工具，而所有代码逻辑都是通的。

**第二步：调整Prompt，塑造AI行为**
*   **目标**：让AI的对话和复盘更贴合你的新领域。
*   **操作**：
    1.  修改 `createNegotiatorPrompt` 函数中的提示文本。例如，对于“客户投诉处理”，可以把“经验丰富的商务人士”改成“资深客户服务专家”，把“谈判策略”的描述改成“沟通与安抚策略”。
    2.  修改 `createAnalysisPrompt` 函数中的分析维度和要求。例如，把“价值创造”改成“共情能力”，把“策略运用”改成“问题解决步骤”。
*   **效果**：AI的对话质量和复盘角度将变得高度专业化。

**第三步：改变输入与输出形式**
*   **目标**：优化用户体验，使其更匹配特定流程。
*   **操作**：
    1.  **增加输入**：在设定区域，为客户投诉场景增加一个“客户情绪等级（1-5星）”的下拉菜单。
    2.  **修改输出**：在复盘报告中，除了文字，是否可以要求AI生成一个简单的“本次沟通情绪曲线图”的描述？
    3.  **调整UI**：改变颜色主题（如从商务蓝改为客服绿），调整聊天气泡的样式。
*   **效果**：你的工具从“通用框架”变成了一个“量身定制”的专业产品。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加多轮次与存档功能**
    *   **操作**：在页面顶部增加一个“历史练习”下拉菜单。每次开始新练习时，将 `negotiationData` 和 `conversationHistory` 连同时间戳一起保存到 `localStorage`。用户可以加载历史记录，回顾或继续之前的练习。
    *   **价值**：让练习具有连续性，方便追踪进步。

2.  **引入“策略提示”与实时反馈**
    *   **操作**：在聊天界面侧边栏增加一个可折叠的“策略工具箱”。根据用户输入的关键词（如“报价”、“拒绝”、“期限”），实时显示简单的谈判技巧提示（如：“尝试将价格与交货期捆绑谈判”）。这可以通过简单的JavaScript字符串匹配实现。
    *   **价值**：在练习中提供即时指导，学习效果更好。

3.  **切换或融合多种AI模型**
    *   **操作**：在API设置中，允许用户为“对话模拟”和“复盘分析”分别选择不同的模型。甚至可以在代码中写死：对话用快速便宜的模型（如DeepSeek-Chat），复盘用更强但更慢的推理模型（如DeepSeek-Reasoner）。
    *   **价值**：在效果和成本/速度间取得最佳平衡。

4.  **增加“角色视角切换”功能**
    *   **操作**：在复盘报告出来后，增加一个按钮：“**切换到对手视角查看**”。点击后，用同样的对话历史，但以AI对手的“秘密目标”和“底线”为基准，生成一份“对手是如何看待这场谈判的”简短报告。
    *   **价值**：极大地提升换位思考能力，这是谈判中的高阶技能。

5.  **输出可分享的报告链接**
    *   **操作**：将关键的谈判设定和对话历史压缩成一个字符串，作为URL参数。在复盘页面生成一个“分享此报告”按钮，点击后生成一个包含这些参数的短链接。别人打开链接，可以看到这场谈判的复盘（甚至可以只读方式重现对话过程）。
    *   **价值**：方便用于教学、讨论或向导师求助。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合作为法律或决策的唯一依据**：AI生成的对话和建议是基于模式识别的，可能包含错误、偏见或不切实际的假设。**切勿**将模拟结果直接用于真实的合同条款或重大商业决策。
- **不适合模拟高度依赖非语言信息的沟通**：真实的谈判中，语气、表情、肢体语言、沉默都传递着大量信息。这个纯文本工具无法模拟这些维度，因此可能让你低估实际沟通的复杂度。
- **不适合处理极度开放或创造性的场景**：它的运行依赖于预设的场景结构和目标。如果你需要一个完全自由、没有预设规则的“头脑风暴”伙伴或“创意生成器”，这个工具的限制会显得过多。
- **如果用户想做**：**进行一场有法律约束力的真实谈判**。
    - **应该换用**：聘请专业的律师、谈判顾问，并使用专业的合同管理与协作平台。
- **如果用户想做**：**深度分析自己与某个特定真实对手的过往沟通模式**。
    - **应该换用**：使用专业的对话分析软件，或由人类教练进行一对一的案例分析。
