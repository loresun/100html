# 三年后会感谢的决定 - AI 未来推演 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
当你站在人生的十字路口，面对一个重要的选择（比如“是否要辞职创业”、“是否要学习一门新技能”），感到犹豫不决时，这个工具可以帮你。它利用 AI 的想象力，为你描绘出做出这个决定后，未来三年可能发生的故事、挑战和成果。它不是一个算命工具，而是一个“思维推演器”，帮你把模糊的担忧和期待，转化为具体、有画面感的未来场景，从而增强你的决策信心。

**适合什么情况？**
- **决策前期的探索阶段**：你想了解一个决定的长期影响，但自己难以系统思考。
- **需要情感激励**：你希望看到一个积极、鼓舞人心的未来图景，来克服当下的畏难情绪。
- **个人规划**：你想为自己设定一个中长期目标，并了解实现路径上的关键节点。

**不适合什么情况？**
- **需要精确财务或风险评估**：它不提供具体的财务数据或概率分析。
- **紧急决策**：AI 生成需要时间，不适合需要在几分钟内做出的决定。
- **替代专业咨询**：对于涉及法律、医疗、重大投资的决策，应咨询相关领域专家。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **核心决定**：一个文本框，让你输入正在纠结的决定（例如：“是否开始学习编程”）。
2.  **（可选）背景信息**：一个可展开的面板，让你补充个人现状、目标和可用资源，使推演更贴合你。

**用户通常会做哪几步操作？**
1.  **输入决定**：在主输入框写下你的决定。如果没灵感，可以点击下方的“热门话题”按钮快速填充。
2.  **（可选）补充信息**：点击“添加更多背景信息”，填写你的个人情况，这会让 AI 的推演更个性化。
3.  **开始推演**：点击“开始推演未来”按钮（或按 `Ctrl+Enter`）。
4.  **等待与阅读**：等待约10-30秒，AI 会生成一份未来三年的“时间线报告”。
5.  **保存结果**：阅读后，可以使用顶部的按钮将结果保存为文本、JSON 或图片。

**输出结果长什么样？**
结果会以**时间线**的形式展示：
- **三年分三阶段**：第一年（播种期）、第二年（成长期）、第三年（收获期）。
- **每年一个卡片**：包含一个主题标题、一段生动的场景描述、以及几个具体的关键成果。
- **总结语**：最后会有一段以“三年后的你”的口吻写的话，感谢现在的自己。

**有哪些容易忽略的使用细节？**
1.  **快捷键**：在输入框按 `Ctrl+Enter` 可以直接开始推演，效率更高。
2.  **背景信息自动保存**：你填写的高级信息会自动保存在浏览器里，下次打开页面还会在。
3.  **必须先配置 API**：第一次使用前，需要点击右上角的齿轮图标，填入你自己的 DeepSeek API Key。
4.  **预设按钮是捷径**：下方的“热门话题”按钮可以一键填充常见决定，方便你快速体验。

## 【三】核心结构拆解（学习重点）

这个页面由几个清晰的模块组成，像一个流水线工厂：

1.  **输入与配置模块**
    - **职责**：收集用户的核心决定和个性化背景信息；管理 API 密钥等设置。
    - **包含**：主输入框、高级信息折叠面板、设置弹窗。
    - **逻辑**：用户输入 → 数据被存储在变量中 → 为下一步生成做好准备。

2.  **AI 交互与处理模块（核心引擎）**
    - **职责**：将用户输入打包成 AI 能理解的指令（Prompt），调用 AI 接口，并把 AI 返回的杂乱文本解析成结构化的数据。
    - **逻辑**：拼接 Prompt → 调用 `callLLM` 函数发送请求 → 用 `parseResponse` 函数解析返回的 JSON 或文本 → 产出结构化的 `timeline` 和 `summary` 数据。

3.  **结果展示与动画模块**
    - **职责**：将处理好的结构化数据，以美观、有动效的方式呈现给用户。
    - **包含**：时间线容器、逐年卡片、加载动画、思考提示语。
    - **逻辑**：收到 `timeline` 数组 → 循环生成每个时间线卡片 → 应用渐入动画和样式。

4.  **输出与导出模块**
    - **职责**：允许用户将生成的结果持久化保存。
    - **包含**：“保存文本”、“保存 JSON”、“保存图片”按钮。
    - **逻辑**：将 `timeline` 和 `summary` 数据格式化为不同格式（纯文本、JSON、PNG图片）→ 触发浏览器下载。

**最值得学习的设计：**
**“输入-处理-展示”的清晰分离**。整个应用像一条流水线：`用户输入` → `AI处理（黑盒）` → `数据解析` → `UI渲染`。这种结构让代码易于维护。如果你想替换 AI 服务（比如从 DeepSeek 换成 OpenAI），你几乎只需要修改 `callLLM` 这个函数；如果你想改变时间线的外观，也只需要修改结果展示模块的 HTML 和 CSS，不会影响到其他部分。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 扮演的角色：**
在这个页面中，Prompt 是**指挥 AI 工作的“剧本”和“格式要求”**。它告诉 AI 要扮演什么角色（人生规划顾问）、完成什么任务（推演三年变化）、以及**必须按照什么格式（严格的 JSON 结构）** 来回答。

**它解决的是“生成问题”还是“理解问题”？**
主要是**“生成问题”**。AI 的核心任务是根据用户提供的决定和背景，**创造性地生成**一段关于未来的、连贯且鼓舞人心的叙述。它也需要“理解”用户的输入，但重点在于利用这种理解去进行有逻辑的想象和构建。

**Prompt 中的关键变量：**
1.  **系统指令（System Role）**：定义了 AI 的“人设”和核心任务框架。
2.  **用户决定（User Decision）**：这是整个推演的起点，是最关键的变量。
3.  **用户背景信息**：这些是可选但重要的变量，让 AI 的生成内容从“通用建议”变为“个性化推演”。

**如果只改 Prompt，不改代码，会发生什么？**
变化会非常明显且直接：
- **改变风格**：把系统指令中的“人生规划顾问”改成“科幻作家”，AI 可能会生成一个充满科技感的未来故事。
- **改变结构**：把要求返回的 JSON 格式从三年改成五年，AI 就会生成五年的推演（但前端页面可能无法正确显示，因为代码预期是三年）。
- **改变深度**：在 Prompt 中要求“重点分析前六个月会遇到的三个具体困难”，AI 的回复就会更侧重于短期挑战。

**简单来说，Prompt 是驱动这个应用大脑的“程序”，修改它就等于修改了应用的“思维方式”。**

## 【五】如何模仿它，做出你自己的版本？

如果你想做一个类似但主题不同的工具，请遵循以下安全路径：

**第一步：替换核心场景与视觉主题（最安全）**
- **做什么**：保持所有代码结构完全不变。
- **改哪里**：
    1.  修改网页标题和描述。
    2.  修改主输入框的提示文字（如改成“你正在策划一个什么活动？”）。
    3.  修改预设按钮的文字（如改成“生日派对”、“公司团建”、“婚礼”）。
    4.  修改 CSS 中的颜色渐变（如把深空蓝紫色主题改成温馨的橙黄色主题）。
- **效果**：你立刻得到了一个外观不同、但功能一模一样的工具，比如“AI 活动策划推演器”。

**第二步：调整输入字段和 Prompt**
- **做什么**：让工具解决一个新问题。
- **改哪里**：
    1.  在“高级信息”面板中，将“个人背景”、“目标期望”等标签和提示文字，改成与新场景相关的字段（如“活动类型”、“预算范围”、“参与人数”）。
    2.  **最关键的一步**：重写 `callLLM` 函数中的 `system` 提示词。将角色从“人生规划顾问”改为“资深活动策划师”，将输出格式要求从“三年时间线”改为“活动筹备时间线（如：三个月前、一个月前、一周前、当天）”。
- **效果**：工具的核心逻辑（输入→调用AI→解析→展示）没变，但因为它收到了新的“工作指令”（Prompt），所以产出的内容完全变成了活动策划方案。

**第三步：改变输出形式**
- **做什么**：让结果的展示方式更适合新内容。
- **改哪里**：
    1.  修改时间线部分的 HTML 结构。比如把“年”改成“阶段”，把三个卡片改成四个卡片。
    2.  调整对应的 CSS 类名和样式（如 `.year-1` 改成 `.phase-1`）。
    3.  修改导出函数中的文件名和内容格式。
- **效果**：工具的界面和产出物都完全贴合你的新场景。

**从哪里下手最安全？**
从 **第一步** 开始。只修改文字和颜色，不碰任何 JavaScript 逻辑。这样你能立即看到一个属于你的“皮肤”，建立信心。然后再尝试第二步，修改 Prompt，这是功能变化的核心。最后再根据需求调整前端展示细节。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“推演视角”选择**：
    - **操作**：在输入区增加一个单选按钮组，让用户选择“乐观推演”、“保守推演”或“挑战推演”。
    - **实现**：将这个选择作为变量加入到发送给 AI 的 Prompt 中。例如，在 Prompt 末尾加上“请从[用户选择的视角]进行推演，重点描述...”。
    - **效果**：用户可以获得不同侧重点的未来图景，工具实用性大增。

2.  **替换为本地模型或其它 API**：
    - **操作**：修改 `callLLM` 函数。
    - **实现**：如果你想使用 OpenAI 的 GPT-4，只需将 API 端点、请求头格式和模型名称替换成 OpenAI 的规范。如果想尝试本地运行的 Ollama，则请求地址改为 `http://localhost:11434/api/chat`，并调整请求体格式。
    - **效果**：可以降低成本、提高速度、或利用不同模型的特长。

3.  **增加“历史记录”页面**：
    - **操作**：将每次生成的结果（包括输入和输出）保存到浏览器的 `localStorage` 或 `IndexedDB` 中。
    - **实现**：创建一个新的 `history.html` 页面，读取存储的数据，以列表形式展示所有过去的推演。点击可以查看详情。
    - **效果**：用户可以回顾和比较自己不同时期的想法和规划，工具从一个单次工具变成了一个成长记录簿。

4.  **优化交互：增加步骤引导**：
    - **操作**：为第一次访问的用户添加一个“引导遮罩”。
    - **实现**：使用 `intro.js` 这类库，或者自己写一个简单的 `div` 覆盖层，用箭头和文字提示用户第一步输入什么、第二步点击哪里、第三步如何保存。
    - **效果**：极大降低新用户的学习成本，提升体验。

5.  **引入社交分享优化**：
    - **操作**：优化“保存图片”的功能，生成更适合分享到社交媒体（如小红书、朋友圈）的方形或长图卡片。
    - **实现**：在 `html2canvas` 配置中，单独截取总结语卡片或者设计一个包含二维码和 Logo 的分享专用模板，然后生成图片。
    - **效果**：让用户更愿意传播你的工具，形成自增长。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做精确预测**：AI 的推演是基于语言模式和常见逻辑的“合理想象”，并非真实的预测。它不能告诉你“创业成功率是多少”或“股票会不会涨”。
2.  **不适合替代专业评估**：对于涉及法律合同、医疗诊断、心理咨询、重大财务投资等需要专业资质和责任的决策，**绝对不要**依赖此工具的结果做最终决定。它只能作为启发思路的辅助。
3.  **不适合处理极度模糊或过于宏大的问题**：输入如“如何获得幸福？”或“世界和平如何实现？”，AI 可能无法给出有意义的、个性化的三年推演，结果会非常空泛。
4.  **不适合需要实时数据或计算的场景**：它无法接入实时房价、汇率数据，也无法进行复杂的数学建模或财务计算。

**如果你想做的是：**
- **财务计算器**：应该使用 Excel、专业财务软件或编写专门的算法。
- **决策矩阵分析**：应该使用 SWOT 分析模板或专业的决策分析工具。
- **基于真实数据的趋势预测**：应该学习数据分析，使用 Python（Pandas, Scikit-learn）或 BI 工具（如 Tableau）。
