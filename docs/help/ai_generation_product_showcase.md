# 产品展示图生成器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
你是一名电商卖家或内容创作者，手头有一张普通的产品照片（比如用手机拍的），但你需要一张专业、吸引人的产品展示图用于商品详情页、社交媒体或广告投放。你没有专业的设计软件技能，也没有时间或预算请设计师。这个工具让你上传产品图，选择想要的场景风格，就能快速生成一张看起来像是专业摄影师在精心布置的场景中拍摄的精修图。

**适合什么情况？**
- 为电商平台（淘宝、亚马逊、独立站）快速制作商品主图
- 为社交媒体（小红书、抖音、Instagram）制作吸引眼球的产品宣传图
- 需要批量、快速产出不同风格的产品图进行A/B测试
- 个人卖家或小团队缺乏专业设计资源时

**不适合什么情况？**
- 需要精确控制产品在场景中的位置、角度、光照细节（这是专业修图软件的工作）
- 需要生成完全虚构、现实中不存在的新产品（这是AI绘画工具的工作）
- 对图片的版权、商标、文字有严格合规要求（建议人工审核）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **产品图片**：点击左侧“上传产品图”区域，上传一张你的产品照片（建议白底或背景干净）
2.  **场景选择**：在“场景选择”区域，点击你想要的背景风格（如“简约白底”、“书桌场景”）
3.  **促销标签**（可选）：在“促销标签”区域，勾选并选择或自定义一个促销标签文字

**用户通常会做哪几步操作？**
1.  **配置API**：首次使用，点击右上角“模型配置”，填入从火山引擎获取的API Key和Endpoint ID，然后保存。
2.  **上传图片**：点击左侧虚线框，选择你的产品照片。
3.  **选择风格**：浏览6个预设场景，点击一个你喜欢的。
4.  **添加标签**（可选）：如果需要，打开“添加促销标签”开关，选择标签类型。
5.  **生成图片**：点击底部大大的“生成精修图”按钮。
6.  **获取结果**：等待几秒到几十秒，右侧会显示生成好的图片，你可以下载、复制或预览。

**输出结果长什么样？**
生成后的图片会显示在右侧，看起来像是你的产品被“放置”在了你选择的场景中（如咖啡桌、户外），并且图片质量高、光线专业。如果选择了促销标签，图片上会有一个美观的标签角标。图片下方会显示场景名称和分辨率信息，并提供下载等操作按钮。

**有哪些容易忽略的使用细节？**
- **API配置是必须的**：不配置API密钥，点击生成会弹窗提示，这是最关键的一步。
- **图片质量影响效果**：上传“白底或干净背景”的产品图效果最好，背景杂乱会影响AI识别和合成。
- **模型选择**：在设置中可以选择不同的AI模型版本，4.5版通常比4.0版效果更好。
- **水印开关**：在设置中可以选择关闭水印，让生成的图片更干净。
- **重新生成**：对同一张图、同一个场景，多次点击“生成精修图”或“重新生成”，可能会得到略有不同的结果，因为AI有一定随机性。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个主要模块，像一个流水线工厂：

**1. 配置与输入模块（左侧面板）**
- **职责**：收集用户的所有“创作指令”。它像是一个控制台，负责接收原始素材（产品图）和用户需求（场景、标签）。
- **包含**：图片上传区、场景选择器、促销标签设置区。
- **逻辑**：用户在此模块的所有选择，都会被转化为程序内部的变量（如 `selectedScene`, `addPromoTag`），等待被“组装”成发给AI的指令。

**2. 控制与逻辑模块（JavaScript `productApp` 函数）**
- **职责**：整个应用的大脑和调度中心。它管理所有状态（如图片是否上传、是否正在生成），并处理核心业务逻辑。
- **关键函数**：
    - `handleImageUpload`: 处理图片上传，转换为程序可用的Base64格式。
    - `generate`: **核心函数**，它根据左侧模块收集的变量，拼接成一段给AI的“描述文字”（Prompt），然后调用API。
    - `callImageAPI`: 负责与火山引擎的AI服务通信，发送Prompt和产品图，取回生成的结果。
- **逻辑链路**：`用户操作` → `更新状态变量` → `点击生成` → `拼接Prompt` → `调用API` → `接收图片` → `更新结果状态` → `界面刷新显示`。

**3. 展示与输出模块（右侧面板）**
- **职责**：向用户呈现最终成果，并提供成果的后续操作。它是这个工具的“成果展示厅”。
- **包含**：加载动画、空状态提示、结果图片展示区、操作按钮组（下载、复制、预览）。
- **设计亮点**：它根据`isGenerating`（是否生成中）和`result`（是否有结果）这两个状态，智能地切换显示“空状态”、“加载中”和“结果”，用户体验流畅。

**4. 全局辅助模块（导航栏、设置弹窗、全屏预览）**
- **职责**：提供应用的全局设置和增强功能。
- **包含**：
    - **导航栏**：显示当前模型，提供设置入口。
    - **设置弹窗**：管理AI模型、API密钥等核心配置，并利用`localStorage`在本地保存。
    - **全屏预览**：提供一个沉浸式的看图模式。

**最值得学习的设计：状态驱动的UI**
这个页面最精妙的地方在于**用数据状态控制界面显示**。你看代码中大量的 `x-show`（Alpine.js的指令），它们都绑定在 `productImage`, `isGenerating`, `result` 这些状态变量上。例如：
- 没有上传图片时，生成按钮是灰色的 (`!productImage`)。
- 点击生成后，按钮文字变成“生成中...”，右侧显示加载动画 (`isGenerating = true`)。
- 生成成功后，加载动画消失，结果图片和操作按钮出现 (`result` 有值且 `isGenerating = false`)。
这种设计让界面逻辑非常清晰，代码易于维护。你想改界面显示？先去改对应的状态变量。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt在这里是**连接用户意图与AI能力的翻译官**。用户通过点击按钮选择“咖啡桌场景”，这是一个抽象意图。Prompt的任务是将这个意图，结合产品图，翻译成AI能听懂的、具体的图像描述指令。

**它解决的是“理解问题”还是“生成问题”？**
它主要解决**“生成问题”**。这个工具的核心是“图生图”（Image-to-Image），AI已经“看到”了你上传的产品。Prompt的作用是告诉AI：“请根据你看到的这个产品，在‘咖啡桌’这样的背景下，用‘专业摄影’的风格，重新画一张图。” 它是在引导AI如何“加工”和“再创作”已有的视觉信息。

**哪些信息是 Prompt 中的关键变量？**
在 `generate()` 函数里拼接的Prompt中，关键变量来自用户选择：
1.  **场景描述 (`scene.desc` 和 `scene.name`)**：如 `"Product photography: 文创、办公用品. Background: 书桌场景."`。这是决定背景环境的核心。
2.  **固定质量指令**：如 `"High-quality, professional, 4K resolution, studio lighting."` 和 `"Style: Clean, modern, e-commerce product shot."`。这部分是保证出图质量的“咒语”，通常固定不变。
3.  **促销标签指令**：根据用户选择，动态添加如 `'Add promotion tag: "Best Seller"'` 的指令。这是决定是否添加以及添加什么文字标签的关键。

**如果只改 Prompt，不改代码，会发生什么变化？**
效果会立竿见影，因为AI完全按Prompt的描述来生成图片。
- **改场景描述**：比如把 `"Background: 书桌场景."` 改成 `"Background: A futuristic spaceship control panel."`，生成的图片背景会从书桌变成飞船操控台。
- **改风格指令**：比如把 `"Clean, modern"` 改成 `"Vintage, film grain, 1990s advertisement style"`，图片的整体色调和质感会变得复古。
- **改标签指令**：可以控制标签的位置、样式，比如改成 `"Add a large, red, 'SALE' sticker on the top-right corner."`。
**提示**：修改时最好保持英文，因为当前对接的AI模型对英文Prompt理解更好。

## 【五】如何模仿它，做出你自己的版本？

这是一个经典的“表单输入 + AI处理 + 结果展示”应用。你可以按以下安全路径模仿：

**第一步：替换核心概念，保持骨架不变（最安全）**
- **目标**：做一个“**AI食谱生成器**”。
- **操作**：
    1.  把“产品图上传”改成“**上传食材照片**”（代码中改文字和图标，上传逻辑完全复用）。
    2.  把“场景选择”改成“**菜系风格选择**”（如中餐、西餐、日料、素食。复用 `scenes` 数组，改 `name`, `desc`, `icon`）。
    3.  把“促销标签”改成“**饮食限制**”（如“无麸质”、“低卡路里”。复用开关和下拉框逻辑）。
    4.  把“生成精修图”改成“**生成创意食谱**”。
    5.  右侧结果区，把展示图片改成展示**生成的食谱文字**。
- **此时**：界面布局、交互逻辑、状态管理全部没变，你只是换了文字和图标。

**第二步：调整AI交互逻辑（修改大脑）**
- **目标**：让应用从“生成图片”变成“生成文本”。
- **操作**：
    1.  在 `generate()` 函数里，根据你新的输入（食材、菜系、限制），拼接一个新的、用于生成文本的Prompt。例如：`"Based on the image of ingredients, generate a creative recipe for Chinese cuisine that is gluten-free. Provide ingredients and steps."`
    2.  将 `callImageAPI` 函数重命名为 `callTextAPI`，并修改其内部逻辑，调用一个**文本生成模型**的API（如ChatGPT、文心一言的API），发送你拼接好的Prompt。
    3.  修改 `result` 对象的结构，不再存储图片URL，而是存储生成的食谱文本。
- **此时**：应用的核心功能已彻底改变，但前端界面到后端调用的流程依然清晰。

**第三步：改变输出展示形式（装修展厅）**
- **操作**：修改右侧结果展示区的HTML，从显示 `<img>` 标签，改为用一个 `<div>` 或 `<pre>` 标签来优雅地展示多行食谱文本。可以增加“复制文本”按钮替换“复制图片”按钮。
- **此时**：一个全新的“AI食谱生成器”就诞生了。

**从哪里下手最安全？**
从**第一步**开始最安全。先不要动任何JavaScript逻辑，只修改HTML里的文字、`scenes`数组里的内容。这样你能立刻看到一个外观上完全不同的新应用，并且所有按钮功能都正常（虽然点生成可能报错，因为API没改）。这能给你最大的信心和可视化的进展。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格强度”滑块**：
    - **操作**：在场景选择下方增加一个滑块（`<input type="range">`），绑定到一个新变量如 `styleStrength`（范围0.1-1.0）。
    - **修改**：在 `callImageAPI` 函数中，将这个变量的值赋给请求体中的 `strength` 字段（图生图API常用参数）。`strength`值越低，AI越忠实于原图；值越高，AI发挥创意越多，背景变化越大。
    - **效果**：用户可以在“微调原图”和“彻底换背景”之间自由控制。

2.  **增加“多图生成”和“历史记录”**：
    - **操作**：
        - 修改生成按钮，旁边加一个“生成4张”的选项。
        - 修改 `callImageAPI` 请求，加入 `n: 4` 参数（如果API支持）。
        - 将返回的多张图片保存在一个数组如 `historyResults` 中。
        - 在结果区下方，用缩略图网格展示所有历史生成结果，点击可放大。
    - **效果**：提高创作效率，方便用户挑选最满意的一张。

3.  **更换为开源或免费的AI后端**：
    - **操作**：研究并接入其他AI绘画API，如：
        - **Replicate**：提供Stable Diffusion等众多开源模型，有免费额度。
        - **OpenAI DALL-E 3**：图像生成质量高。
        - **本地部署SD**：如果你有显卡，可搭建本地服务，将API地址指向 `http://localhost:7860`。
    - **修改**：只需重写 `callImageAPI` 函数，根据新API的文档调整请求格式和参数。
    - **效果**：降低成本或获得不同风格的出图效果。

4.  **拆分为“快速模式”和“专家模式”**：
    - **操作**：
        - “快速模式”就是现在的页面，选项简单。
        - 增加一个“专家模式”切换按钮。点击后，展开更多高级选项，如：
            - **负面Prompt**：输入不希望出现在图中的内容（如“丑陋的，模糊的”）。
            - **种子值**：固定一个数字，可以让每次生成的结果都一致，便于微调。
            - **采样器选择**：不同的算法影响出图速度和风格。
    - **效果**：满足小白用户快速出图和专业用户精细控制的不同需求。

5.  **优化交互：拖拽上传与即时预览**：
    - **操作**：
        - 为图片上传区域添加 `@drop` 和 `@dragover` 事件监听，支持拖拽文件上传。
        - 在用户选择场景后，**不立即调用API**，而是在右侧用一个半透明的蒙版，模拟出产品图放在该场景下的**布局预览**（纯前端实现，用CSS叠加）。
    - **效果**：提升工具的专业感和用户体验的流畅度。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做高精度、与实物完全一致的产品图**：AI生成具有随机性和艺术加工性。如果你需要一张完全准确、用于产品说明书或工程图纸的图片，请使用3D建模软件（如Blender）或专业摄影。
2.  **不适合处理带有复杂透明背景（如毛发、玻璃）的产品**：当前的图生图技术对于需要精细抠图再合成的任务（如将一只猫完美融入新背景）效果不佳，边缘会不自然。这类任务需要专业的图像编辑软件（如Photoshop）或专门的AI抠图工具。
3.  **不适合作为唯一的商业图片来源**：由于AI生成内容可能存在版权不确定性（取决于训练数据）以及可能的生成瑕疵，在重要的商业合同、品牌广告中，建议将AI生成图作为灵感草图或初稿，最终由设计师审核并定稿。
4.  **不适合生成包含特定真人肖像或受版权保护元素的图片**：这可能导致肖像权或版权纠纷。生成此类图片需格外谨慎，并确保你有相应的权利或授权。

**总结**：这个工具是一个强大的“创意加速器”和“效率工具”，它能将普通的想法快速可视化。但它不是“真理生成器”，它的输出需要你的审美判断和后续处理。理解它的边界，才能更好地利用它。
