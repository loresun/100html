# 情绪日记分析师 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景：**
当你经历了一天，心里有很多感受，但自己理不清头绪时，这个网页就像一个“情绪翻译官”。它帮你把模糊的感受变成清晰的分析，告诉你今天主要是什么情绪、为什么会有这些情绪，以及可以怎么做来调节。

**适合的情况：**
- 想通过写日记来了解自己的情绪模式
- 感到情绪复杂，需要外部视角帮助分析
- 希望获得具体的情绪调节建议
- 想可视化地看到自己的情绪状态（通过雷达图）

**不适合的情况：**
- 需要即时心理咨询或危机干预（应寻求专业帮助）
- 需要诊断心理疾病
- 需要与他人实时讨论情绪问题
- 只想简单记录，不需要深度分析

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **日期**：选择今天或任何你想记录的日期
2. **日记内容**：写下今天发生的事情和你的感受
3. **情绪标签**（可选）：快速点击选择你感受到的情绪

**用户通常会做哪几步操作？**
1. 打开页面，看到温暖的橙色界面
2. 在左侧“今天的心情”区域写下日记
3. （可选）点击下方的情绪标签，如“😊 快乐”、“😰 焦虑”
4. 点击“开始情绪分析”按钮
5. 如果是第一次使用，会弹出设置窗口让你输入API Key
6. 等待几秒钟，右侧就会显示分析结果

**输出结果长什么样？**
分析结果分为三部分：
1. **情绪雷达图**：一个六边形的图表，六个角代表不同情绪（快乐、悲伤等），颜色越深表示强度越高
2. **深度分析**：AI用温暖的语言分析你的情绪模式、触发因素和思维习惯
3. **调节建议**：提供3-5条具体可行的行动建议，比如“尝试深呼吸5分钟”

**容易忽略的使用细节：**
- 右上角可以切换V3（快速）和R1（深度）两种AI模型
- 点击“设置”可以自定义AI的分析风格（通过修改提示词）
- 分析结果可以点击“复制”按钮保存到剪贴板
- 雷达图下方的数字可以直接看到每个情绪的具体分数

## 【三】核心结构拆解（学习重点）

这个页面由四个主要模块组成：

**1. 输入模块（左侧卡片）**
- **职责**：收集用户的情境信息
- **包含**：日期选择器、日记文本框、情绪标签按钮、分析按钮
- **设计亮点**：情绪标签提供了“快速输入”的选项，降低了写作门槛

**2. AI处理模块（隐藏的逻辑层）**
- **职责**：将用户输入转化为结构化请求，调用AI API
- **关键设计**：精心设计的Prompt（提示词）告诉AI如何分析、以什么格式返回
- **输入→处理→输出链路**：
  用户日记 → 拼接成Prompt → 发送给DeepSeek API → 解析JSON响应 → 更新页面数据

**3. 可视化模块（雷达图）**
- **职责**：将抽象的情绪数据转化为直观的图形
- **实现方式**：用SVG绘制六边形雷达图，每个维度对应一种情绪
- **值得学习的设计**：数据可视化让分析结果“一目了然”，比纯文字更有冲击力

**4. 文本输出模块（分析结果）**
- **职责**：展示AI的深度分析和建议
- **技术细节**：使用Markdown格式，通过marked.js渲染成美观的HTML
- **设计亮点**：分“深度分析”和“调节建议”两个板块，逻辑清晰

**最值得学习的设计：**
**模块化的数据流设计**。整个页面围绕一个核心数据对象（`analysis.value`）工作：
- 输入模块修改日记数据
- AI处理模块获取数据、调用API、更新分析结果
- 可视化模块和文本输出模块自动响应数据变化并更新显示

这种“单一数据源”的设计让代码结构非常清晰，也容易扩展。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是“AI分析师的工作说明书”。它告诉AI：
1. 你扮演什么角色（专业情绪心理分析师）
2. 按什么框架分析（情绪识别→触发因素→认知模式→身心反应→调节建议）
3. 用什么语气说话（温暖、共情、通俗易懂）
4. 输出什么格式（严格的JSON结构）

**它解决的是“理解问题”还是“生成问题”？**
主要是“理解问题”。AI需要理解用户日记中的复杂情绪，但Prompt让它按照专业框架来理解，而不是随意发挥。

**Prompt中的关键变量：**
1. **系统提示词**：定义AI的“人格”和分析框架
2. **用户提示词**：包含具体的日记内容、日期、用户选择的标签
3. **输出格式约束**：强制要求返回特定结构的JSON，方便前端解析

**如果只改Prompt，不改代码，会发生什么变化？**
- 改分析框架：比如增加“社会支持系统分析”，AI就会多分析这一项
- 改输出格式：如果JSON结构变了，前端可能解析失败
- 改语气风格：从“温暖共情”改成“冷静客观”，整个分析读起来感觉完全不同
- 改专业深度：增加或减少专业术语的使用

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最安全：只改文字和主题颜色
- 例如改成“学习笔记分析器”：
  - 日记框→学习内容框
  - 情绪标签→知识点标签（理解、困惑、掌握等）
  - 情绪分析→学习效果分析
  - 调节建议→学习建议

**第二步：调整输入字段和Prompt**
- 修改输入框的提示文字
- 调整情绪标签为你的场景需要的标签
- **关键**：重写系统提示词，告诉AI新的分析框架
- 例如对于学习分析：“你是一位学习教练，分析学生的学习状态、理解难点、提供改进方法...”

**第三步：改变输出形式**
- 雷达图的六个维度改成你的场景需要的维度
- 分析文本的标题和结构微调
- 可以增加新的输出模块，比如“行动计划表”、“进度时间线”

**从哪里下手最安全？**
从**文字替换**开始。先不改代码逻辑，只改页面上显示的所有文字，确保你理解每个部分的作用。然后改颜色主题，最后才调整数据结构和Prompt。

## 【六】3–5个可直接尝试的改造方向

**1. 增加“情绪时间线”功能**
- **怎么做**：在本地存储每次分析的结果，增加一个“历史记录”页面
- **效果**：可以看到情绪随时间的变化趋势
- **技术实现**：用`localStorage`存储每次的日期、情绪分数、分析摘要

**2. 支持多模型对比**
- **怎么做**：在设置中增加OpenAI、Claude等API选项
- **效果**：可以对比不同AI的分析风格和深度
- **技术实现**：抽象API调用层，支持不同服务商的接口格式

**3. 增加“情绪调节工具包”**
- **怎么做**：根据分析结果，动态推荐具体工具
- **效果**：从“给建议”升级到“提供工具”
- **具体实现**：
  - 如果焦虑值高→显示“5分钟正念呼吸”引导音频
  - 如果悲伤值高→显示“感恩日记”模板
  - 如果愤怒值高→显示“情绪释放写作”提示

**4. 改为“团队情绪看板”**
- **怎么做**：增加用户登录，支持多人共享情绪状态
- **效果**：管理者可以看到团队整体情绪健康度
- **技术实现**：需要后端支持，但可以先做原型：每个人分析后生成分享链接

**5. 增加“语音输入”和“语音反馈”**
- **怎么做**：集成浏览器语音识别和语音合成API
- **效果**：不用打字就能记录，AI分析可以用语音读出来
- **技术实现**：`SpeechRecognition`和`SpeechSynthesis` API，注意兼容性

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不是心理咨询替代品**
   - 如果持续情绪低落、焦虑严重影响生活，请寻求专业心理咨询
   - AI无法建立真实的治疗关系，也无法处理危机情况

2. **不适合深度心理分析**
   - 无法分析童年经历、潜意识、复杂心理创伤
   - 分析基于单篇日记，缺乏长期背景信息

3. **不适合群体治疗或家庭治疗**
   - 无法处理人际关系中的复杂情绪动态
   - 没有安全机制保护隐私（所有数据经过第三方API）

4. **不适合需要即时反馈的场景**
   - API调用有延迟，不适合情绪崩溃时的即时支持
   - 没有离线功能，断网时完全无法使用

**如果你需要：**
- **专业诊断** → 使用专业心理评估工具或咨询心理医生
- **实时交流** → 使用心理咨询热线或即时聊天服务
- **隐私绝对保护** → 使用本地运行的AI模型（如Ollama）
- **长期跟踪** → 使用专业的情绪追踪APP（如Daylio、Moodnotes）

---

**最后提醒**：这个网页是一个很好的“学习原型”，它展示了如何将AI能力封装成对用户友好的工具。你可以借鉴它的设计模式，但一定要清楚它的边界，特别是在涉及心理健康这样的敏感领域时。
