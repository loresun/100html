# 人生剧本改写师 - 帮助文档

---

## 【一】这个网页解决了什么问题？

**使用场景**：
当你发现自己总在重复某些不愉快的人生模式时，比如：
- 总是陷入相似的感情困境
- 在工作中不断遇到相同的人际冲突
- 面对机会时习惯性退缩
- 内心有个声音总在说“我不够好”

这个工具就像一位“心理编剧”，帮你识别这些重复模式背后的“人生剧本”，然后和你一起设计一个更健康、更自由的新剧本。

**适合**：
- 想要自我探索和成长的个人
- 心理咨询师或教练作为辅助工具
- 写作时想要深入理解角色动机
- 任何想要改变思维和行为模式的人

**不适合**：
- 需要紧急心理危机干预的情况
- 替代专业心理治疗（特别是严重心理问题）
- 需要即时、简短建议的场景
- 纯粹娱乐或玩笑式的使用

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **重复出现的模式**：描述你生活中反复出现的问题或困境
2. **早年经历（可选）**：童年时期的重要事件或家庭环境
3. **核心信念**：你内心深处对自己或世界的根本看法
4. **理想剧本方向**：从下拉菜单中选择你希望改变的方向

**用户通常会做哪几步操作？**
1. 点击右上角的“设置”按钮，输入你的 DeepSeek API Key
2. 在左侧表单中填写你的“人生剧本”信息
3. 点击“改写人生剧本”按钮
4. 等待 AI 分析并生成新的剧本方案
5. 阅读结果，可以点击“复制”保存内容

**输出结果长什么样？**
结果会以清晰的 Markdown 格式呈现，包含：
- 🎭 你的旧剧本分析（识别问题）
- ✨ 新剧本设计（解决方案）
- 🌱 30 天改写计划（行动指南）

**容易忽略的使用细节**：
1. **必须先配置 API Key**：否则点击按钮只会弹出设置窗口
2. **“早年经历”是可选的**：如果你不确定或不想分享，可以留空
3. **模型选择**：右上角可以切换 V3（标准）和 R1（推理）模型
4. **系统提示词可修改**：在高级设置中可以完全改变 AI 的分析框架

## 【三】核心结构拆解（学习重点）

**页面由三个关键模块组成：**

1. **输入模块（左侧卡片）**
   - **职责**：收集用户的人生模式信息
   - **包含**：四个输入字段 + 一个提交按钮
   - **设计亮点**：字段顺序符合心理分析逻辑（现象 → 根源 → 信念 → 目标）

2. **输出模块（右侧卡片）**
   - **职责**：展示 AI 生成的分析和建议
   - **状态**：空状态提示 → 生成中动画 → 结果展示
   - **设计亮点**：使用“幕布拉开”动画增强仪式感

3. **配置模块（模态窗口）**
   - **职责**：管理 API 密钥和系统提示词
   - **存储**：使用 localStorage 保存配置
   - **设计亮点**：与主应用分离，避免干扰主要流程

**输入 → 处理 → 输出 的逻辑链路：**
```
用户填写表单 → 点击按钮 → 验证配置 → 拼接 Prompt → 调用 API
    ↓
流式接收响应 → 实时显示 → 解析 Markdown → 最终展示
```

**最值得学习的设计：**
**“剧本改写”的隐喻框架**。整个界面不是冷冰冰的“问题分析工具”，而是有故事感的“剧本工坊”。从视觉设计（黄色渐变、卡片边框）到交互语言（“改写剧本”、“新剧本”），都在强化这个隐喻，让用户更容易进入深度反思的状态。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt 是**专业的心理分析框架**。它把 AI 从“通用聊天机器人”变成了“专业的交互分析心理学家”。

**它解决的是“理解问题”还是“生成问题”？**
两者都有，但更偏向**结构化生成**。它确保 AI 的输出：
1. 有固定的分析框架（剧本识别 → 功能分析 → 新设计 → 实施路径）
2. 有统一的输出结构（三个主要部分，每个部分有子标题）
3. 保持一致的风格（温暖、赋能、不评判）

**Prompt 中的关键变量：**
1. **角色定义**：“专业的交互分析（TA）心理学家”
2. **分析框架**：四个明确的步骤
3. **输出结构**：用 Markdown 标题强制分块
4. **风格指令**：“温暖、赋能、不评判”

**如果只改 Prompt，不改代码，会发生什么变化？**
- 改成“职业规划师” → 分析人生模式对职业的影响
- 改成“创意写作教练” → 把人生模式变成角色设定
- 改成“认知行为治疗师” → 使用 CBT 框架分析
- 简化 Prompt → 得到更简短、更通用的建议

**代码只是管道，Prompt 才是灵魂。**

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 把“人生剧本”改成“商业计划分析”
- 输入字段改为：当前业务问题、市场环境、核心优势、目标方向
- 视觉主题从黄色（温暖）改成蓝色（专业）

**第二步：调整输入字段和 Prompt**
- 根据新场景增减字段（如增加“预算限制”、“时间框架”）
- 重写系统 Prompt，定义新的专业角色和分析框架
- 保持输出结构（问题分析 → 解决方案 → 行动计划）

**第三步：改变输出形式或展示方式**
- 如果生成的是数据，可以增加图表展示
- 如果生成的是步骤，可以做成可勾选的清单
- 增加“保存为 PDF”或“分享链接”功能

**从哪里下手最安全？**
从 **Prompt 和 CSS 颜色** 开始。这两个改动：
1. 不会破坏现有功能
2. 能立即看到效果变化
3. 风险最小，最容易调试

## 【六】3–5 个可直接尝试的改造方向

1. **增加“情绪标签”输入**
   - 在“重复模式”旁增加情绪选择器（沮丧、焦虑、愤怒等）
   - Prompt 中加入：“请特别关注用户的[情绪]情绪，提供针对性的情绪调节策略”
   - 效果：让分析更个性化，建议更精准

2. **换成多轮对话模式**
   - 当前：一次性输入 → 一次性输出
   - 改造：允许用户对 AI 的分析进行追问
   - 实现：保存对话历史，每次都在上下文基础上继续
   - 价值：更像真实的心理咨询过程

3. **拆分成“分析”和“行动”两个页面**
   - 页面一：专注深度分析（当前功能）
   - 页面二：专注计划执行（增加每日打卡、进度追踪）
   - 好处：符合“认知 → 行动”的真实改变过程

4. **增加“剧本库”和“案例分享”**
   - 保存用户的历史剧本（匿名化）
   - 允许浏览他人的改写案例（获得共鸣和启发）
   - 技术：需要后端存储，但可以从 localStorage 的本地保存开始

5. **优化为“渐进式改写”**
   - 当前：直接给完整的30天计划
   - 改进：先给第一周的3个小步骤
   - 一周后，根据用户反馈生成下一周计划
   - 更符合行为改变的“小步快跑”原则

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不是心理治疗替代品**
   - 如果：你正在经历严重抑郁、焦虑或创伤
   - 应该：寻求专业心理咨询师或精神科医生的帮助
   - 理由：AI 缺乏临床判断能力和危机干预能力

2. **不适合快速决策**
   - 如果：你需要马上决定“要不要换工作”或“要不要分手”
   - 应该：与信任的朋友、家人或导师深入交谈
   - 理由：重大决策需要情感支持和现实考量，而不仅是认知分析

3. **无法验证建议的有效性**
   - 如果：你想知道某个建议“是否真的适合你”
   - 应该：在小范围内尝试，观察自己的真实感受和结果
   - 理由：AI 的建议基于模式识别，而非对你的深入了解

4. **不适合处理复杂系统问题**
   - 如果：你的问题涉及家庭系统、组织文化或社会结构
   - 应该：考虑家庭治疗、组织咨询或社会支持资源
   - 理由：个人视角的剧本分析可能忽略系统层面的影响因素

**记住**：这个工具最好的使用方式是——**作为自我探索的起点，而不是终点**。用它来提出问题、获得视角，但最终的答案和行动，需要你在真实生活中去发现和创造。
