# 小费/AA 计算器 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你和朋友聚餐后，面对账单需要计算小费、分摊费用，或者你想快速进行一些日常的单位换算、记录临时笔记、管理一个简单的待办清单。这个网页就是一个**个人工具箱**，它把十几种常用的小工具（计算器、计时器、记账本等）集成在一个简洁的页面里。

*   **适合的场景**：当你需要快速、轻量地完成一个简单的计算或记录任务，不想打开复杂的软件或下载专门的App时。例如，在餐厅结账时算小费、学习时用番茄钟计时、临时记录一笔开销、或者快速生成一个随机密码。
*   **不适合的场景**：处理大量、复杂或需要长期、专业管理的数据。例如，管理一个包含数百条记录的复杂项目、进行专业的财务分析、或者编辑长篇文档。它更适合“用完即走”的临时性任务。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   页面中央是一个大的工具区域。根据你选择的工具不同，输入框会变化。例如，选择“小费计算器”，你会看到“账单金额”、“小费比例”、“人数”等输入框。

2.  **用户通常会做哪几步操作？**
    *   **第一步：选择工具**。虽然当前页面标题是“小费计算器”，但从代码结构看，这是一个**多功能工具箱**。实际使用中，你可能需要通过导航栏或某种方式（代码中未直接显示切换UI，但逻辑支持）在不同工具（如公式计算、计时器、清单、记账等）间切换。
    *   **第二步：填写参数**。在工具对应的输入框中填入数字或文字。
    *   **第三步：触发计算/操作**。点击工具下方的按钮，如“计算结果”、“开始”、“添加”、“生成结果”等。
    *   **第四步：查看结果**。结果会直接显示在按钮下方，可能是数字、列表或一段处理后的文本。

3.  **输出结果长什么样？**
    *   结果通常以一个带有边框的卡片形式呈现，清晰地区分了标签（如“每人应付”）和数值。
    *   对于列表类工具（如记账、清单），结果是一条条可操作的记录，你可以勾选完成或删除。

4.  **有哪些容易忽略的使用细节？**
    *   **自动保存**：注意“笔记工具”的文本区域，代码中设置了 `@input.debounce.400ms`，这意味着你输入内容后，系统会在你停止输入400毫秒后自动保存，无需手动点击保存按钮。
    *   **设置入口**：页面右上角的齿轮图标（⚙️）点击后可以配置API（如DeepSeek的API密钥），这说明部分工具（可能是文本处理类）背后接入了AI能力。
    *   **响应式布局**：在电脑和手机上，工具的输入框和结果展示的布局会自动调整，以更好地适应屏幕。

## 【三】核心结构拆解（学习重点）

这个页面的设计精髓在于 **“一套框架，多种工具”** 的模块化思想。

*   **关键模块与职责**：
    1.  **工具调度器**：页面最核心的逻辑是 `x-data="webtoolPage('tip_calculator')"`。它像一个总控中心，根据传入的工具ID（如 `'tip_calculator'`）加载对应的工具配置（名称、描述、类型、字段等）。
    2.  **工具类型模板**：页面主体部分由一系列 `x-show="tool.type === 'xxx'"` 的区块组成。每个区块对应一种工具类型（如 `formula`， `timer`， `list`， `ledger` 等）。这是一种非常清晰的 **“条件渲染”** 模式。
    3.  **数据与视图绑定**：每个工具模板内的输入框都通过 `x-model` 绑定到 `tool` 对象的具体属性上（如 `tool.values[field.key]`， `tool.duration`）。用户修改输入，数据立即更新；程序修改数据，视图也立即更新。
    4.  **操作函数**：每个工具区块下的按钮（如“计算结果”、“开始”）都绑定了特定的函数（如 `calculate(tool)`， `startTimer(tool)`）。这些函数负责处理绑定的数据，并更新结果。

*   **输入 → 处理 → 输出 逻辑链路**：
    *   **输入**：用户在特定工具模板的输入框中填写数据。
    *   **处理**：用户点击按钮，触发对应的JavaScript函数。该函数读取 `tool` 对象中绑定的数据，执行计算、计时、添加条目等逻辑。
    *   **输出**：处理函数将结果写回 `tool` 对象的某个属性（如 `tool.result`， `tool.items`）。由于数据是绑定的，页面会自动更新，将新的结果显示出来。

*   **最值得学习的设计**：
    **基于数据驱动的UI渲染**。整个页面的形态（显示哪个工具、有哪些输入框、结果如何展示）完全由一个核心的 `tool` 数据对象和它的 `type` 属性决定。要增加一个新工具类型，你只需要：1）在数据层定义好这种类型的结构和默认值；2）在HTML中为它新增一个对应的模板区块。这种设计使得功能扩展变得非常规范和简单。

## 【四】Prompt / AI 逻辑是如何被设计的？

从代码中可以看到设置面板可以配置DeepSeek API，但页面上没有直接显示调用AI的工具模板。AI能力很可能被集成在某个工具类型中（例如 `type` 为 `generator`（生成器）或 `text`（文本工具）的部分）。

*   **Prompt扮演的角色**：在这些工具中，Prompt（提示词）是**连接用户简单输入和AI复杂能力的桥梁**。例如，在“随机名称生成器”工具中，Prompt可能将用户输入的“性别”和“风格”变量，组合成一段给AI的指令，如“生成5个{风格}风格的{性别}中文名字”。
*   **解决什么问题**：它主要解决**生成问题**。用户提供种子或要求，AI根据Prompt的指导生成符合预期的内容（如代码、文案、方案）。
*   **关键变量**：Prompt中的关键变量通常来自 `tool.values` 对象或 `tool.input` 文本框。这些变量会被“填入”预设的Prompt模板中。
*   **只改Prompt的影响**：如果不改动任何HTML和JS代码，只修改工具数据中预设的Prompt模板，那么工具的行为会发生根本性变化。例如，一个“文章总结”工具，可以通过修改Prompt变成“翻译工具”或“风格改写工具”。**Prompt定义了工具的核心能力**。

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径是从“替换”开始，而不是“重写”。**

1.  **第一步：替换工具场景与数据**
    *   这是最核心的一步。找到代码中定义工具数据的地方（可能在 `standalone.js` 里）。不要动HTML结构，只修改其中一个工具的数据对象。
    *   **例如**：把“小费计算器”（`type: 'formula'`）的字段从 `[{label: '账单金额', ...}, {label: '小费比例', ...}]` 改成 `[{label: '本金', ...}, {label: '年利率%', ...}, {label: '存款年限', ...}]`，并修改对应的计算函数 `calculate`，使其计算复利。你就得到了一个“复利计算器”。

2.  **第二步：调整输入与输出形式**
    *   在第一步的基础上，如果新的工具需要不同的输入（如下拉选择、单选按钮），可以去对应的工具模板（如 `<!-- 公式计算器 -->` 那个 `div`）里，模仿现有结构，将 `input` 标签替换为 `select` 标签。
    *   同样，调整结果显示的模板，使其更符合新工具的需求。

3.  **第三步：增加一个新的工具类型**
    *   当你熟悉了前两步，可以尝试新增一个 `type`。首先，在JavaScript中创建这个新类型的数据结构和处理函数。然后，在HTML中复制一个现有的工具模板区块（如 `generator` 的区块），修改 `x-show` 条件为你的新类型，并根据需要调整内部的HTML结构。这是从“模仿”走向“创造”的关键一步。

## 【六】3–5 个可直接尝试的改造方向

1.  **为现有工具增加“历史记录”功能**：例如，在计算器工具中，每次计算的结果不仅显示，还可以自动添加到下方的一个历史列表中。这需要你扩展 `tool` 对象，增加一个 `history` 数组，并在计算函数中做 `push` 操作。
2.  **将工具数据持久化到本地**：目前工具数据可能只在当前页面生命周期内存在。你可以使用浏览器的 `localStorage` API，在 `init()` 函数中读取，在每个工具的保存/修改函数中写入。这样关闭浏览器再打开，你的待办清单、记账记录都还在。
3.  **创建“工作流”或“工具组合”**：在页面顶部增加一个区域，允许用户将几个工具（如“计时器”->“笔记”）组合成一个快捷操作。例如，点击“开始学习”按钮，自动启动一个25分钟的番茄钟，并在计时结束后，自动聚焦到笔记工具的输入框。
4.  **优化移动端体验**：虽然用了Tailwind CSS，但可以进一步优化。例如，为计时器、秒表工具在移动端添加全屏模式，并显示更大的数字；为清单工具的“删除”按钮增加滑动操作确认。
5.  **扩展AI工具集**：利用已有的API配置模块，创建更多基于Prompt的AI工具。例如，创建一个“周报生成器”，输入几个关键词和项目名称，调用AI生成一段周报草稿。关键在于设计好Prompt模板和用户输入字段。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做复杂项目管理**：它的清单和记账工具极其轻量，没有分类、筛选、统计图表、多人协作等功能。如果需要这些，应该使用像Trello、Notion或专业的记账软件。
*   **不适合处理敏感数据**：虽然可以配置API Key，但整个应用运行在浏览器端，数据默认存储在本地。**切勿用它来记录密码、保存真正的机密信息或进行涉及真实货币的复杂财务计算**。
*   **不适合替代专业软件**：它的单位转换、文本处理等功能都是最基础的。对于工程师，它不能替代专业的代码编辑器或计算平台；对于设计师，它不能替代图形处理软件。它的定位是 **“快捷便利贴”** ，而不是 **“重型工作站”**。
*   **不适合长期、大量的内容创作**：笔记工具只是一个简单的文本框，没有富文本格式、文件夹管理、版本历史。长期写作应使用Obsidian、语雀、Notion等专业笔记应用。
