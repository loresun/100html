# 成本毛利与投放计算器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
假设你是一位电商运营、产品经理或小店主，正在策划一次商品促销活动。你需要快速回答几个关键问题：如果定价49元、打8折、成本18元、投放2万元广告，最终能赚多少钱？ROI（投资回报率）是多少？至少要卖出多少本才能不亏本？

这个工具就是你的“财务速算助手”。它把复杂的利润计算（涉及定价、折扣、成本、佣金、广告费等多个变量）变成一个直观的仪表盘。你只需调整几个数字，就能立刻看到所有关键财务指标的变化，帮助你快速决策，比如“要不要增加广告预算？”或“这个折扣力度是否可行？”

**适合情况：**
- 快速评估单次营销活动或单个产品的盈利前景。
- 向团队演示不同定价、成本或投放策略下的财务影响。
- 作为学习财务测算的入门工具，理解各成本项如何影响最终利润。

**不适合情况：**
- 管理包含数百个SKU（库存单位）的复杂库存或财务系统。
- 进行需要复杂税务计算、现金流预测或长期财务建模的深度分析。
- 处理实时变动的数据（如动态定价、实时库存成本）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面左侧是输入区，分为两大块：
1.  **基础参数**：包括商品定价、折扣率、单册生产成本、物流包装费、平台佣金率和预计销售量。
2.  **投放与其他成本**：包括广告投放预算和其他一次性固定成本（如设计费、拍摄费）。

所有输入框都预填了示例数值，你可以直接修改。

**用户通常会做哪几步操作？**
1.  **理解参数**：先扫一眼每个输入项的名称，了解它们代表什么。
2.  **修改数值**：根据你的实际情况，修改对应的数字。例如，把你的产品成本填入“单册成本”，把你的广告计划填入“投放预算”。
3.  **点击计算**：修改后，点击蓝色的 **“计算结果”** 按钮。
4.  **查看结果**：右侧的“测算结果”区域会立刻更新。

**输出结果长什么样？**
右侧会显示五个醒目的卡片，分别是：
-   **预计实收 GMV**：打折后，你总共能收到多少钱。
-   **总成本**：生产、物流、佣金、广告等所有成本加起来的总和。
-   **毛利**：实收金额减去总成本，即你这次活动大概能赚多少钱。
-   **投放 ROI**：毛利除以广告花费，数字越大说明广告效率越高（例如ROI=2，意味着每花1元广告费，赚回2元毛利）。
-   **盈亏平衡销量**：估算需要卖出多少册，才能刚好覆盖所有成本（不赚不赔）。

**有哪些容易忽略的使用细节？**
-   **单位**：注意“定价”、“成本”等单位是“元”，而“折扣率”、“佣金率”是百分比（输入80代表80%）。
-   **自动计算**：页面加载后和每次点击按钮都会计算。但如果你只修改了数字没有点击按钮，结果不会更新。
-   **API设置**：右上角的齿轮按钮可以设置DeepSeek API Key，但**本计算器核心功能（财务计算）完全不需要API**。这个设置是为未来可能增加的AI分析功能预留的，目前不影响使用。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

**1. 输入控制模块（左侧面板）**
-   **职责**：收集用户所有的业务假设和参数。
-   **组成**：两组表单字段（基础参数、投放成本）和一个触发按钮。
-   **逻辑**：用户在此模块设定所有“如果……”。它是整个计算的起点。

**2. 计算引擎模块（JavaScript函数 `updateResults`）**
-   **职责**：执行所有数学运算，是页面的“大脑”。
-   **逻辑链路**：
    1.  **获取输入**：从输入控制模块读取每个输入框的数值。
    2.  **处理计算**：按照“成本构成提示”中的公式，一步步算出中间值（如实际售价、佣金）和最终结果（收入、成本、利润、ROI、盈亏平衡点）。
    3.  **准备输出**：将计算好的数字格式化为带货币符号或特定单位的字符串。

**3. 结果展示模块（右侧面板）**
-   **职责**：清晰、突出地呈现计算结论。
-   **组成**：五个结果卡片和一个公式提示区。
-   **逻辑**：接收来自计算引擎模块格式化好的结果字符串，并更新到对应的HTML元素中。

**最值得学习的设计：清晰的“数据流”分离**
这个页面最棒的设计在于，**输入、计算、展示三者完全分离**。
-   输入模块只负责“拿数据”。
-   计算函数只负责“算数据”，它不关心数据从哪里来、算完后去哪里。
-   展示模块只负责“显示数据”。

这种结构让代码易于理解和修改。例如，如果你想增加一个“税费”输入项，你只需要：1) 在HTML输入模块加一个输入框；2) 在计算函数里读取这个新值并加入公式；3) 在展示模块决定是否要新增一个结果显示项。三者改动互不干扰。

## 【四】Prompt / AI 逻辑是如何被设计的？

**重要提示：在当前提供的代码版本中，AI（DeepSeek）功能并未被实际调用。** 页面包含了API Key的配置界面和相关代码，但计算逻辑完全由本地JavaScript完成。

因此，我们可以探讨其 **“预留的”AI设计思路**：
-   **Prompt可能扮演的角色**：在未来，Prompt可能被用来让AI基于计算结果提供“解读”或“建议”。例如：“根据当前参数，ROI为1.5，属于行业中等水平。建议可以尝试将折扣率调整到85%，观察对盈亏平衡点的影响。”
-   **解决“生成问题”**：它要解决的不是理解用户输入的数字，而是**生成人类语言的洞察、分析和优化建议**。
-   **关键变量**：Prompt中很可能会包含计算引擎模块产出的所有关键结果（如 `grossProfit`, `roiValue`, `breakEvenVolume`）作为变量，让AI基于这些具体数字进行分析。
-   **只改Prompt的影响**：如果未来接入了AI，那么只修改Prompt（而不改计算代码），会彻底改变AI输出的内容和风格。比如，从提供“运营建议”变为生成“给投资人的一句话总结”，或者从“中文分析”变为“英文报告”。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，逐步打造属于你的计算器：

**第一步：保持结构不变，替换使用场景（最安全）**
-   **目标**：先做出一个能跑通的、属于你的工具。
-   **操作**：
    1.  复制整个HTML文件。
    2.  修改 `<title>` 和 `<h1>` 中的标题，例如改为“**健身房会员盈利测算器**”。
    3.  修改左侧所有输入项的 `<label>` 文字。例如，“定价”改为“月费”，“单册成本”改为“单会员服务成本”，“销售量”改为“预计会员数”，“投放预算”改为“市场推广预算”。
    4.  修改右侧结果展示的文字，使其符合新场景。
    5.  此时先**不要动JavaScript计算逻辑**。点击计算，你会看到数字在变，但结果可能不对（因为公式还是卖书的）。没关系，第一步的目标是让界面变成你的。

**第二步：调整计算逻辑（核心改造）**
-   **目标**：让计算符合你的业务逻辑。
-   **操作**：
    1.  找到 `updateResults` 函数。
    2.  根据你的新业务，重新设计计算公式。例如，健身房收入 = 月费 * 会员数 * 12（年化）；成本可能包括教练工资、场地租金（可放入“其他固定成本”）。
    3.  在“成本构成提示”区域更新你的公式说明。
    4.  逐个测试你的新公式，确保结果合理。

**第三步：改变输出形式或展示方式（优化体验）**
-   **目标**：让结果展示更贴心。
-   **操作**：
    1.  可以增加结果类型，比如在右侧增加“**会员年均价值**”卡片。
    2.  可以美化结果，例如当利润为负数时，将数字显示为红色。
    3.  可以增加图表（需要引入图表库），用更直观的方式展示成本构成。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“场景预设”功能**：
    -   **操作**：在输入区上方添加几个按钮，如“保守方案”、“激进方案”。点击后，JavaScript自动将对应的一组预设值填入各个输入框。
    -   **价值**：用户可以快速在不同策略间切换对比，无需手动逐个修改。

2.  **实现“实时计算”**：
    -   **操作**：移除“计算结果”按钮，并为每个输入框添加 `oninput` 或 `onchange` 事件监听，使其在用户输入或修改后自动触发 `updateResults` 函数。
    -   **价值**：体验更流畅，结果随参数调整实时变化，像真正的仪表盘。

3.  **可视化成本构成**：
    -   **操作**：引入一个简单的图表库（如Chart.js），在结果区域下方增加一个饼图或环形图，展示“生产成本”、“物流成本”、“佣金”、“广告”、“其他成本”各自在总成本中的占比。
    -   **价值**：一眼看清最大的成本项在哪里，便于优化。

4.  **接入AI，生成简要报告**：
    -   **操作**：真正调用DeepSeek API。在结果区域下方增加一个“AI分析”板块和一个“生成分析”按钮。点击后，将关键参数和结果组装成一段Prompt，发送给AI，并将返回的分析文本显示出来。
    -   **价值**：从提供数字升级到提供见解，工具价值大增。

5.  **增加“分享”功能**：
    -   **操作**：将当前的所有输入参数和计算结果编码成一个URL链接（使用URL的hash或query参数）。添加一个“复制分享链接”按钮。
    -   **价值**：方便用户将测算好的方案直接发送给同事或上级讨论。

## 【七】这个网页不适合做什么？（边界提醒）

-   **不适合做精确的财务会计**：这是一个**测算工具**，用于快速估算和决策支持。它没有考虑增值税、所得税、坏账计提、资产折旧等复杂的会计科目，不能替代专业的财务软件或会计师的工作。
-   **不适合处理多期/动态数据**：它计算的是“一次活动”或“一个阶段”的静态快照。如果你的成本随时间剧烈波动，或者你想做未来12个月逐月的现金流预测，你需要使用电子表格（如Excel/Google Sheets）或更专业的财务建模工具。
-   **不适合作为唯一决策依据**：计算结果是基于你的输入假设。如果“预计销售量”这个关键假设本身就不准，那么所有结果都会失真。这个工具帮你算“如果……会怎样”，但不能告诉你“销售量到底是多少”。后者需要市场分析和数据支持。

**总结**：把它看作你决策过程中的“计算器”和“思考支架”，而不是最终的“财务判决书”。
