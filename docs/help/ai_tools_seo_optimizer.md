# SEO 标题/描述优化器 - 帮助文档

---

## 【一】这个网页解决了什么问题？

这个网页是一个**AI驱动的SEO内容创作助手**。它主要解决内容创作者（如博主、营销人员、网站运营者）在发布文章或网页时，如何快速生成能吸引点击、符合搜索引擎规则的标题和描述的问题。

*   **适合的场景**：
    *   你写了一篇博客，但想不出一个足够吸引人、又能被搜索引擎“看见”的好标题。
    *   你需要为同一个内容（如产品介绍、活动页面）生成多个不同风格的标题，用于A/B测试。
    *   你有一篇长文章，需要快速提炼出核心关键词和一段简洁有力的摘要（Meta Description）。
    *   你需要针对不同的平台（如百度、Google、微信）调整标题和描述的长度与风格。

*   **不适合的场景**：
    *   你需要对现有网站的整个SEO结构（如站点地图、内链）进行深度分析。
    *   你需要进行关键词的搜索量、竞争度等市场数据分析。
    *   你需要生成完整的文章内容，而不仅仅是标题和描述。

## 【二】使用方式（给第一次接触的人）

1.  **准备工作**：首次使用时，点击右上角的“设置”按钮，输入你的DeepSeek API Key并保存。这是让AI为你工作的“钥匙”。

2.  **核心输入**：
    *   **选择平台**：根据你的内容主要发布在哪个搜索引擎（百度、Google或微信），点击对应的卡片。
    *   **选择输入方式**：
        *   **“输入标题优化”**：如果你已经有一个初步的标题，直接输入到这里。
        *   **“从内容生成”**：如果你有一整篇文章，把内容粘贴进来，AI会帮你提炼。
    *   **（可选）目标关键词**：输入你希望标题和描述中重点包含的词，用逗号隔开。
    *   **调整生成数量**：滑动滑块，决定让AI为你生成几个备选标题（3-10个）。

3.  **关键操作**：点击绿色的 **“🔍 生成 SEO 优化方案”** 按钮。

4.  **查看结果**：等待几秒后，右侧会展示完整的优化方案，包括：
    *   **提取的关键词**：AI从你输入的内容中识别出的核心词。
    *   **优化后的标题**：多个带有评分、长度提示和优化说明的标题选项。
    *   **Meta Description**：一段适合放在网页描述标签里的文字。
    *   **搜索结果预览**：模拟你的标题和描述在搜索引擎中显示的样子。
    *   **优化建议**：几条关于如何进一步优化内容的提示。

5.  **输出与操作**：
    *   你可以点击每个标题旁边的“复制”图标，单独复制喜欢的标题。
    *   可以点击“复制全部”按钮，一次性拿走所有标题。
    *   可以点击“导出 SEO 优化报告”，将整个方案保存为Markdown文件。

6.  **容易忽略的细节**：
    *   **字符限制条**：标题下方的彩色进度条直观显示了当前长度是否在平台推荐范围内（绿色为佳，黄色警告，红色超标）。
    *   **评分与说明**：每个标题都有AI给出的评分和简短说明，告诉你它为什么好，这是选择标题的重要参考。
    *   **平台差异**：切换“百度”、“Google”时，标题和描述的长度限制会自动变化，预览样式也可能微调。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个大模块，像一条高效的生产线：

1.  **输入控制面板（左侧）**
    *   **职责**：收集用户的所有创作意图和原材料。它像一个“需求收集器”，把零散的信息（平台、原始内容、关键词偏好）结构化地整理好。
    *   **包含子模块**：平台选择器、输入模式切换器、原始内容输入区、关键词输入区、数量控制器、生成触发器。

2.  **AI处理引擎（不可见，在代码中）**
    *   **职责**：这是网页的“大脑”。它接收左侧整理好的结构化信息，组装成一份详细的“工作指令”（Prompt），发送给DeepSeek AI API，并等待AI返回加工好的“产品”（JSON格式的结果）。
    *   **关键流程**：`用户输入` → `组装Prompt` → `调用API` → `解析JSON响应` → `将数据交给展示模块`。

3.  **结果展示面板（右侧）**
    *   **职责**：将AI返回的原始数据（JSON）进行美观、直观的视觉化呈现，并提供便捷的交互操作（复制、导出）。它像一个“产品包装和交付车间”。
    *   **包含子模块**：关键词展示区、标题列表区（含评分和进度条）、描述展示区、搜索预览模拟器、建议列表、导出功能。

**最值得学习的设计**：
*   **“输入-处理-输出”的清晰分离**：三个模块各司其职，代码结构清晰，易于维护和修改。比如，你想换一个AI模型，只需要修改“处理引擎”中的API调用部分。
*   **基于状态的前端交互**：整个页面使用Alpine.js管理状态（如`input`、`result`、`isGenerating`）。UI只是状态的反映。例如，`isGenerating`为`true`时，按钮显示加载动画，右侧显示加载提示。这种设计让交互逻辑非常简洁。
*   **即时、可视化的反馈**：标题的字符进度条、评分颜色、搜索预览，这些设计让抽象的SEO规则（如“标题不宜过长”）变得具体可见，用户体验极佳。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，**Prompt是给AI下达的“精确生产指令”**。它解决的是 **“生成问题”**：我们不是让AI去理解一个复杂问题，而是告诉它我们想要什么格式和内容的产品。

1.  **Prompt的角色**：它是连接用户输入和AI能力的桥梁。它将用户选择的平台、输入的内容、关键词等变量，嵌入到一个结构化的任务描述中，确保AI输出我们期望的、格式统一的结果。

2.  **关键变量**：
    *   `目标平台`和`字符限制`：来自用户选择的平台卡片。
    *   `目标关键词`：来自用户的可选输入。
    *   `原始标题`或`文章内容`：来自用户的主要输入。
    *   `生成数量`：来自滑块的控制。
    *   `输出格式`：严格要求AI返回一个包含`titles`、`description`、`keywords`、`tips`四个字段的JSON对象。

3.  **如果只改Prompt，不改代码**：
    *   **改变风格**：将Prompt中的“你是一位专业的SEO优化专家”改为“你是一位擅长制造爆款标题的社交媒体专家”，AI生成的标题风格会从“专业、精准”转向“活泼、吸睛”。
    *   **改变任务**：修改“输出要求”部分，例如增加“生成5个带emoji的标题”，AI的输出内容会立刻随之改变。
    *   **改变格式**：如果要求AI返回XML或纯文本列表，而前端代码仍试图解析JSON，页面就会出错。这说明了Prompt与前端代码解析逻辑必须匹配。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你自己的AI内容生成工具：

**第一步：替换核心场景与UI文案（最安全）**
*   **目标**：先做一个能跑通的“换皮”版本。
*   **操作**：
    1.  修改`<title>`和顶部导航栏中的“SEO 标题/描述优化器”为你工具的名字，例如“小红书爆款标题生成器”。
    2.  修改左侧“目标平台”的三个选项，例如换成“小红书”、“抖音”、“知乎”。
    3.  修改“输入标题优化”和“从内容生成”等所有界面文字，使其符合你的新场景。
    4.  此时，工具的逻辑完全没变，只是看起来是另一个东西。

**第二步：调整Prompt与输入字段**
*   **目标**：让AI为你新的场景服务。
*   **操作**：
    1.  在代码中找到 `systemPrompt` 和 `userPrompt` 字符串。
    2.  重写它们。例如，将“SEO优化专家”改为“小红书平台运营专家”，将“标题字符限制”改为“小红书笔记标题限制（20字以内）”。
    3.  根据新场景，增加或删除输入字段。比如，增加一个“笔记类型”下拉选择（穿搭、美妆、美食）。
    4.  修改 `platforms` 数组中的 `titleLimit` 和 `descLimit` 值为新平台的推荐值。

**第三步：改变输出展示方式**
*   **目标**：让结果展示更贴合新场景。
*   **操作**：
    1.  在右侧结果区域，将“Meta Description”模块改为“笔记正文开头”或“视频文案”。
    2.  将“搜索结果预览”模块的样式改成模拟小红书或抖音的界面样式。
    3.  调整评分标准或进度条的判断逻辑（`getScoreColor`、`getCharBarClass`函数），使其符合新平台的规则。

完成这三步，你就拥有了一个全新的工具。整个过程你都没有触碰最复杂的AI通信逻辑（`fetch`请求），风险最低。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格模板”选择**：
    *   **操作**：在输入面板增加一个下拉菜单，选项如“专业严谨”、“幽默风趣”、“紧迫感强”、“疑问式”。
    *   **实现**：将这个选项作为变量加入到`userPrompt`中，例如：“请生成...，标题风格要求为：`${selectedStyle}`。”

2.  **接入多模型API，实现降级备用**：
    *   **操作**：在设置弹窗中，允许用户填写多个API Key（如OpenAI、DeepSeek、智谱）。
    *   **实现**：修改`generateSEO`函数，尝试按顺序调用多个API，第一个失败或超时后自动尝试下一个，提高工具可用性。

3.  **增加历史记录与收藏功能**：
    *   **操作**：在页面底部或侧边栏增加一个区域。
    *   **实现**：每次生成后，将输入参数和结果摘要（如第一个标题）用`localStorage`保存起来。用户可以查看历史记录，并将满意的结果“收藏”到另一个列表。

4.  **优化为多步骤向导式界面**：
    *   **操作**：将当前的单页界面拆分成几个步骤：“1. 输入内容 -> 2. 选择平台与风格 -> 3. 预览与调整 -> 4. 导出”。
    *   **实现**：利用Alpine.js的`x-show`控制不同步骤`<div>`的显示隐藏。这能让复杂工具的流程更清晰，尤其适合后续增加更多高级选项。

5.  **增加“实时优化建议”**：
    *   **操作**：在用户输入标题或内容时，实时给出基础建议。
    *   **实现**：监听输入框的`x-model`变化，用简单的JavaScript函数（不调用AI）进行基础检查，如：“检测到标题没有数字，添加数字可能提升点击率”、“当前长度已超过平台限制X字符”。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合替代专业的SEO审计工具**：它只优化单篇内容的“标题”和“描述”，不分析网站技术健康度（如加载速度、移动适配）、外链质量、网站结构等更深层次的SEO因素。这类工作需使用Ahrefs、SEMrush等专业工具。

2.  **不适合进行关键词深度研究**：它只能基于你给的内容提取或融入关键词，无法告诉你哪些关键词搜索量大、竞争小、有商业价值。你需要使用百度指数、Google Keyword Planner等工具进行前期研究。

3.  **生成的标题不一定保证“爆款”**：AI的推荐基于常见的SEO原则和模式，但内容的最终成功还取决于内容质量、受众情绪、时机等多种因素。它提供的是高质量的“备选项”，而非成功的“保证书”。

4.  **不适合处理极度专业化或机密内容**：所有输入的内容都会被发送到第三方AI API。对于法律、医疗等高度专业领域，或涉及未公开商业机密的内容，请谨慎使用，或考虑部署私有化模型。

**总结**：将这个工具视为一位 **“不知疲倦的初级SEO文案助手”** 。它能高效地完成基础、重复性的构思工作，为你提供灵感和选项，但最终的决策、更深度的策略分析，以及对专业性与机密性的把控，仍需由你——这个领域的专家——来完成。
