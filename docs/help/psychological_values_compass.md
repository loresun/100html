# 价值观罗盘 - 帮助与学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：
想象一下，当你面临一个重要的选择（比如换工作、处理家庭关系、规划未来方向），或者只是感觉生活有些迷茫，不清楚什么对自己真正重要时，这个网页就像一个“心理导航仪”。它帮助你梳理内心真正看重的东西（价值观），并基于这些价值观，为你提供清晰的行动方向和决策参考。它特别适合在需要自我反思、做重大决定或希望生活更有方向感时使用。

**适合情况**：
- 个人成长与自我探索
- 面临职业或人生选择时
- 希望检查自己的日常行为是否与内心追求一致
- 感到迷茫，需要重新找到生活重心

**不适合情况**：
- 需要即时、具体的心理咨询或危机干预
- 寻求绝对正确的“标准答案”（价值观是个人化的）
- 处理非常复杂、需要法律或专业领域知识的具体问题

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **价值观选择**：从16个预设的价值观标签（如“家庭”、“事业成就”、“健康”等）中，勾选3-5个你认为最重要的。
2.  **当前困境（可选）**：可以描述你正面临的具体选择或困惑。
3.  **指引目标**：从下拉菜单中选择你希望获得帮助的类型，比如“澄清价值观”或“决策指导”。

**用户通常会做哪几步操作？**
1.  **配置**：首次使用时，点击右上角的设置按钮，输入你的 DeepSeek API Key（这是让AI工作的“钥匙”）。
2.  **选择与填写**：在“价值观探索”卡片中，勾选价值观，并可选地填写困境和选择目标。
3.  **生成**：点击“生成价值观罗盘”按钮。
4.  **阅读与行动**：等待片刻，阅读AI生成的详细报告，并思考其中的建议。

**输出结果长什么样？**
结果是一份结构清晰、文字详尽的个人化报告，通常包括：
-   **你的核心价值观**：对你所选价值观的深度解读。
-   **价值观地图**：分析这些价值观之间的关系。
-   **对齐度检查**：指出你生活中哪些方面已与价值观一致，哪些需要调整。
-   **行动清单**：提供10-15个具体、可操作的小建议，帮你将价值观融入生活。
-   **决策建议**：如果你填写了困境，这里会有针对性的分析。
-   **反思问题**：提供几个问题，帮助你持续进行自我觉察。

**有哪些容易忽略的使用细节？**
1.  **API Key 是必须的**：没有它，页面无法工作。你需要去 DeepSeek 官网注册并获取。
2.  **价值观需要排序**：虽然页面是勾选，但系统提示词中要求“按重要性排序”。勾选的顺序会被视为你的排序，所以请按重要程度依次勾选。
3.  **困境描述越具体越好**：虽然可选，但详细的描述能让AI的分析更贴合你的实际情况。
4.  **可以切换模型**：右上角的“V3”和“R1”按钮可以切换不同的AI模型（普通对话 vs 深度推理），体验不同的回答风格和深度。
5.  **结果可以复制**：生成报告后，点击右上角的“复制”按钮，可以保存文本到其他地方。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个模块，像一个高效的生产线：

1.  **配置与控制模块（头部导航栏）**
    *   **职责**：管理页面的全局设置。它是整个应用的“控制面板”。
    *   **内容**：模型切换按钮、设置入口。它不直接参与内容生成，但决定了内容生成的“引擎”和“燃料”（API Key）。
    *   **逻辑**：用户在此配置基础资源（API Key）和选择工具（模型）。

2.  **输入收集模块（主内容区上部卡片）**
    *   **职责**：收集用户的所有个性化信息。它是整个应用的“原料采集站”。
    *   **内容**：价值观复选框、困境文本框、目标下拉菜单、“生成”按钮。
    *   **逻辑**：用户在此提供“我是谁”、“我有什么问题”、“我想要什么”。点击按钮后，将这些信息打包，准备发送给处理模块。

3.  **AI处理与展示模块（主内容区下部）**
    *   **职责**：与AI通信，接收、处理并优雅地展示结果。它是“核心加工厂”和“产品展示厅”。
    *   **内容**：加载动画、结果展示区（支持Markdown渲染）。
    *   **逻辑**：收到输入数据 → 显示加载状态 → 将数据+系统指令发送给AI API → 以流式传输接收AI回复 → 实时渲染为美观易读的文章。

4.  **系统指令模块（设置弹窗）**
    *   **职责**：定义AI的“角色”和“工作流程”。它是整个AI应用的“灵魂”和“操作手册”，虽然隐藏，但至关重要。
    *   **内容**：一个可编辑的长文本区域（`systemPrompt`）。
    *   **逻辑**：这段文本定义了AI的心理学家角色、分析框架和输出格式，确保每次生成的结果都结构一致、专业有用。

**最值得学习的设计**：
**“系统指令驱动”的架构**。整个应用的核心不是复杂的代码逻辑，而是一份精心编写的 `systemPrompt`。前端代码主要负责收集用户输入，并将其与这份“灵魂指令”一起发送给AI。这意味着，要改变这个应用的功能（比如从“价值观分析”变成“职业规划师”），你主要需要修改的是 `systemPrompt`，而不是重写大量代码。这种将业务逻辑“外包”给大语言模型的设计思路，是现代AI应用开发的关键。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：在这个页面中，Prompt（特别是`systemPrompt`）扮演着**总导演和编剧**的角色。它不直接生成答案，而是设定场景、角色、分析方法和输出格式，指导AI如何利用用户输入来“表演”出一份价值观分析报告。
*   **解决的问题**：它同时解决了“理解问题”和“生成问题”。
    1.  **理解问题**：通过“你是一位ACT心理学家...”等描述，让AI理解它需要以何种专业视角来看待用户输入。
    2.  **生成问题**：通过“输出结构：## 核心价值观...”等严格规定，让AI知道最终需要生成一个什么样格式、包含哪些章节的内容。
*   **关键变量**：
    *   **`${input.dilemma ? '## 基于价值观的决策建议...' : ''}`**：这是一个条件语句。如果用户填写了困境，这部分内容就会出现在指令中，要求AI生成“决策建议”章节；如果没填，这行指令就是空的。这是**让Prompt动态适应不同用户输入**的精妙技巧。
    *   **理论基础和分析框架**：这些是指导AI思考过程的“思维链”，确保分析的专业性和深度。
*   **如果只改Prompt，不改代码**：应用的功能会发生**根本性变化**。例如，将`systemPrompt`中的角色从“心理学家”改为“资深职业规划师”，将分析框架从价值观改为“技能、兴趣、市场趋势”，那么这个应用就会立刻从一个价值观探索工具，变成一个职业规划工具。输入框可能不需要改，但输出的内容将完全不同。这证明了Prompt是此类AI应用的“核心资产”。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全、渐进地创建属于你的AI工具：

**第一步：保持结构不变，替换使用场景（最安全）**
不要改动任何HTML和JS代码。只修改`DEFAULT_SYSTEM_PROMPT`里的内容。
*   **想做什么？** 比如做一个“旅行规划师”。
*   **怎么改？**
    1.  把角色描述改成“你是一位资深旅行策划师”。
    2.  把“价值观”输入框的标签（在HTML里）改成“你想去的旅行目的地类型”（如海滩、山脉、城市、美食）。
    3.  把`valueOptions`数组里的值换成“放松、探险、文化、摄影、亲子”等旅行主题。
    4.  重写`systemPrompt`，将分析框架改为“根据用户选择的旅行主题、预算（可新增输入框）、时间，推荐目的地、行程安排和注意事项”。
    5.  困境文本框可以改为“特别需求或限制”。

**第二步：调整输入字段或Prompt**
在第一步成功的基础上，根据新场景的需要，增加或修改输入项。
*   **例如**：为“旅行规划师”增加“预算范围”（数字输入框）、“出行天数”（数字输入框）、“出行人群”（单选：独自、情侣、家庭）。
*   **关键**：确保在`systemPrompt`和生成请求的`userPrompt`中，用上这些新变量（如`${input.budget}`）。

**第三步：改变输出形式或展示方式**
当功能稳定后，可以优化结果展示。
*   **例如**：旅行规划的结果，除了文字，是否可以用一个更视觉化的“每日行程表”来展示？你可以尝试用不同的HTML结构（如表格、时间轴）来渲染AI生成的Markdown内容，或者引导AI生成更结构化的数据（如JSON），再用代码解析成图表。

**从哪里下手最安全？**
**从修改 `DEFAULT_SYSTEM_PROMPT` 开始**。这是整个应用的“大脑”。先想清楚你想要AI扮演什么角色、解决什么问题、输出什么格式。用一个文本编辑器单独修改和测试这个Prompt，直到你觉得它能在聊天界面里很好地工作。然后再将它放回网页中，这样风险最小。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“价值观强度”滑块**：目前价值观只有“选中”和“排序”。可以为每个选中的价值观增加一个滑块（1-10分），让用户评价其当前生活中的“实现程度”或“重视程度”。将这个分数加入`userPrompt`，AI就能给出更具针对性的“提升建议”。
2.  **本地记忆与历史记录**：利用浏览器的`localStorage`，不仅保存API Key，还可以保存每次生成的“价值观罗盘”结果，形成一个历史列表。用户可以回顾自己价值观的演变过程。
3.  **输出多样化**：除了现在的文章式报告，可以增加输出选项。例如，让AI生成一个**简短的核心价值观宣言（一句话）**，或一个**本周首要行动（一个具体任务）**。这满足了用户“快速获取要点”的需求。
4.  **社交分享图**：设计一个简单的模板，将AI生成的核心价值观和一句鼓舞人心的话，叠加在精美的背景图上，生成一张可保存或分享的图片。这可以利用`html2canvas`等库实现。
5.  **多模型支持**：目前只支持DeepSeek。可以在设置中增加一个“API提供商”下拉菜单，支持OpenAI、Claude等。这需要抽象出一个统一的请求函数，根据选择拼接不同的API URL和请求头。这是学习如何设计“可插拔”AI后端的绝佳练习。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做专业的心理诊断或治疗**：它只是一个基于AI的自我反思工具，不能替代专业心理咨询师、治疗师的诊断和治疗。如果用户有严重的情绪困扰、抑郁、焦虑或其他心理疾病，应建议其寻求合格的专业帮助。
*   **不适合做出具有法律或重大财务后果的决策**：虽然它能提供基于价值观的决策参考，但对于离婚、重大投资、法律诉讼等事宜，其建议不具备专业效力。用户应咨询律师、财务顾问等专业人士。
*   **不适合处理高度模糊或信息不全的复杂系统问题**：AI的分析基于你提供的有限信息。对于像“如何拯救地球气候变化”或“如何经营好我的跨国企业”这类极其复杂的问题，单靠这个工具的输出是远远不够的。
*   **如果用户想做X**：例如，如果用户想进行专业的职业能力测评，他应该使用像MBTI、霍兰德职业兴趣测试等经过信效度检验的专业工具，或咨询职业规划师。本工具可以作为一个有价值的补充（澄清职业选择背后的价值观），但不能作为唯一依据。
