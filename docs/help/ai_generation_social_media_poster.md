# 社交媒体配图生成器 - 帮助与学习指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你是一名社交媒体运营者、内容创作者或小商家。你需要为即将发布的小红书笔记、公众号文章或朋友圈广告制作一张吸引眼球的配图。你没有专业的设计软件技能，也没有时间从零开始构思。这个工具就是你的“AI设计助手”。你只需要告诉它“我要发什么内容”、“在哪个平台发”、“想要什么感觉”，它就能在几秒钟内为你生成几张不同风格的配图供你选择。

**适合什么情况？**
- 需要快速为社交媒体内容（如新品发布、活动宣传、知识分享）制作配图。
- 缺乏专业设计资源或技能，但希望图片看起来专业、有吸引力。
- 需要一次性获得多个设计选项，以便挑选最合适的。
- 希望图片能符合特定平台（如小红书、抖音）的尺寸和风格偏好。

**不适合什么情况？**
- 需要高度定制化、包含复杂品牌元素（如特定Logo、字体）的设计。
- 需要生成完全写实、与真实产品分毫不差的照片。
- 需要处理或编辑已有的图片（如抠图、调色）。
- 对图片的版权有极其严格的要求（AI生成图片的版权归属需注意）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **平台选择**：你想在哪个社交媒体发布？（小红书、公众号、朋友圈等）
2.  **设计风格**：你想要图片看起来是什么感觉？（简约商务、清新文艺等）
3.  **配图内容**：
    *   **主题/文案**：你要宣传的核心内容是什么？（必填）
    *   **关键元素**：你希望图片里出现什么物品或场景？（可选，如“咖啡、书籍”）
    *   **文字标题**：是否要在图片上直接添加文字？添加什么文字？

**用户通常会做哪几步操作？**
1.  **配置**：点击右上角“模型配置”，填入你的AI服务API密钥（这是使用AI功能的前提）。
2.  **构思**：在左侧面板，依次选择“平台”、“风格”，并填写“配图内容”。
3.  **生成**：点击底部大大的“生成配图”按钮。
4.  **挑选与下载**：在右侧查看生成的几张图片，选择最喜欢的，点击图片右下角的下载按钮保存。

**输出结果长什么样？**
- 右侧会以网格形式展示1-4张图片（数量可设置）。
- 每张图片都是根据你的要求生成的、符合所选平台尺寸的视觉图。
- 图片下方会显示它是哪种“风格变体”（如主要风格、配色变体），方便你区分。
- 生成过的图片会缩略图形式保存在页面底部的“最近生成”区域。

**有哪些容易忽略的使用细节？**
1.  **必须先配置API**：首次使用或更换模型后，**必须**点击“模型配置”并正确填写对应AI服务的API Key和必要参数，否则无法生成图片。
2.  **“关键元素”是提示词**：这里填写的词（如“星空、城堡”）会直接影响AI生成的画面内容，是让图片更贴近你想法的关键。
3.  **批量生成是默认的**：工具默认一次生成3张不同微调的图片，这是为了给你提供选择。你可以在“模型配置”中修改数量。
4.  **历史记录可复用**：底部“最近生成”的缩略图，点击后可以快速将其重新加载到主展示区查看。

## 【三】核心结构拆解（学习重点）

这个页面是一个经典的 **“配置-生成-展示”** 单页应用，可以拆解为四个核心模块：

1.  **配置管理模块**
    *   **职责**：管理整个应用的“大脑”（AI模型）设置。它不直接参与单次生成任务，但为生成任务提供基础能力（如使用哪个API、用什么密钥）。
    *   **位置**：通过“模型配置”按钮触发的弹窗。
    *   **逻辑**：用户输入API配置 → 保存到浏览器本地存储 → 后续所有AI调用都使用此配置。

2.  **参数输入模块**
    *   **职责**：收集用户本次任务的具体要求，是AI的“创作指令集”。
    *   **位置**：页面左侧的所有卡片（选择平台、设计风格、配图内容）。
    *   **逻辑**：用户选择平台和风格，输入文案和关键词 → 这些数据被存储在应用的状态变量中（如 `selectedPlatform`, `content.text`）→ 等待生成指令。

3.  **Prompt 引擎模块**
    *   **职责**：这是**最值得学习的核心设计**。它不是一个可见的UI部件，而是一段逻辑代码（`buildPrompts` 函数）。它的任务是将用户输入的**结构化参数**，翻译成AI模型能理解的**自然语言指令（Prompt）**。
    *   **逻辑链路**：
        输入（平台、风格、文案等）→ **Prompt引擎处理**（拼接成一段英文指令，如“Create a 简约商务 style poster for 小红书...”）→ 输出（一个或多个文本Prompt）→ 发送给AI图像生成API。

4.  **结果展示与交互模块**
    *   **职责**：呈现AI的生成结果，并提供后续操作（下载、查看历史）。
    *   **位置**：页面右侧的“生成结果”区域。
    *   **逻辑**：收到AI返回的图片URL → 以卡片网格形式渲染 → 用户可下载单张或全部 → 结果自动存入历史记录。

**最值得学习的设计：**
**Prompt引擎的抽象层设计**。它把复杂的AI绘画提示词工程，封装成了一个简单的表单操作。用户无需学习“masterpiece, best quality, 8k”等咒语，只需进行业务意义上的选择（平台、风格），由引擎负责将其转化为有效的Prompt。这种“将专业复杂性隐藏于友好界面之后”的思路，是构建实用AI应用的关键。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：Prompt在这里是**生成问题的指令**。它直接告诉AI模型“画一幅什么样的画”。网页本身不负责理解图片内容，只负责组织和发送生成指令。
*   **解决什么问题**：它解决的是“**生成问题**”——如何将用户模糊的、多维度（平台、风格、内容）的需求，精确地传达给一个文本到图像的AI模型，以生成符合预期的图片。
*   **关键变量**：Prompt模板中嵌入了几个关键变量，它们直接来自用户输入：
    *   `{style.name}`：设计风格（如“简约商务”）。
    *   `{platform.name}`：目标平台（如“小红书”）。
    *   `{content.text}`：核心文案。
    *   `{content.keywords}`：画面元素关键词。
    *   `{platform.ratio}`：图片比例。
*   **只改Prompt的后果**：如果只修改`buildPrompts`函数中的Prompt模板语句（例如，将英文指令改为更详细的中文描述，或增加“电影感灯光”、“柔焦效果”等具体质量要求），**生成的图片风格和质量会立即发生变化**，而网页的界面和操作流程完全不变。这证明了Prompt是控制AI输出的“软开关”。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你自己的AI工具：

**第一步：保持结构不变，替换使用场景（最安全）**
*   **目标**：先做出一个能跑通的“克隆体”。
*   **操作**：
    1.  复制整个HTML文件。
    2.  修改标题和导航栏文字，例如将“社交媒体配图生成器”改为“**电商产品海报生成器**”。
    3.  修改左侧的“平台”模块为“**产品类目**”（如服装、数码、美食），并更新对应的图标和尺寸（可以仍用社交媒体尺寸，或改为通用海报尺寸）。
    4.  修改“设计风格”模块为“**海报风格**”（如促销风、极简风、复古风）。
    5.  修改“配图内容”的提示文字，使其更贴合电商场景（如“产品卖点描述”、“核心促销信息”）。
*   **此时**：你已经有了一个外观全新的工具，但内核（生成逻辑、API调用）完全一样。

**第二步：调整输入字段或Prompt**
*   **目标**：让工具更贴合新场景的需求。
*   **操作**：
    1.  在“配图内容”部分增加新字段，例如“**产品颜色**”、“**目标受众**”（如年轻人、家庭主妇）。
    2.  修改`buildPrompts`函数，将新增的字段也拼接到最终的Prompt指令中。例如：`Target audience: ${this.content.audience}`。
    3.  微调Prompt的固定描述部分，使其更符合电商海报的术语，例如强调“突出产品主体”、“背景干净”等。
*   **此时**：你的工具在功能上已经为电商场景做了定制。

**第三步：改变输出形式或展示方式**
*   **目标**：优化结果展示，提升用户体验。
*   **操作**：
    1.  在结果卡片上，除了下载按钮，可以增加一个“**应用到模板**”按钮（假设你后续有模板系统）。
    2.  可以改变历史记录的展示方式，例如按“产品类目”筛选历史生成图。
    3.  可以尝试不同的布局，比如将单张结果图放大预览，两侧放置其他变体。
*   **此时**：你的工具拥有了独特的交互和外观。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“负面提示词”输入框**：
    *   **操作**：在“配图内容”区域添加一个文本框，标签为“不希望出现的元素”。
    *   **逻辑**：将用户输入的内容，通过 `negative_prompt` 参数传递给AI API（许多图像生成API支持此参数）。这能有效避免生成图中出现不想要的东西（如“文字水印”、“丑陋的手”）。
    *   **价值**：大幅提升生成结果的精准度和可控性。

2.  **集成多模型，并添加“对比模式”**：
    *   **操作**：在“模型配置”中增加如OpenAI DALL-E 3、Midjourney（通过第三方代理）等选项。
    *   **逻辑**：生成时，可以同时或用相同Prompt调用两个不同的模型。
    *   **展示**：在结果区域，将同一Prompt下不同模型生成的结果并列展示，并标注模型名称。这能帮助用户直观感受不同模型的风格差异。

3.  **拆解流程，增加“Prompt预览与编辑”步骤**：
    *   **操作**：在点击“生成配图”后，先弹出一个新页面或弹窗，展示即将发送给AI的完整Prompt。
    *   **逻辑**：允许用户在此直接编辑和优化这段Prompt文本，确认后再真正调用API。
    *   **价值**：面向进阶用户，提供更深度的控制权，也是一个很好的Prompt学习窗口。

4.  **优化体验：添加“灵感库”或“风格参考图”**：
    *   **操作**：在页面顶部或侧边栏增加一个“灵感”板块。
    *   **逻辑**：内置一些优秀的社交媒体配图案例（可以是图片URL），并解析出它们对应的“平台”、“风格”和“关键词”标签。用户点击某张参考图，可以一键将这些标签填入左侧的表单中。
    *   **价值**：解决用户“不知道怎么写”的痛点，通过案例降低使用门槛。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精准的品牌视觉输出**：AI生成的图片在颜色、字体、Logo细节上无法做到与品牌手册100%一致。它适合产生“创意”和“初稿”，最终的商用设计仍需设计师在专业软件中校准。
*   **不适合生成具有明确版权的特定内容**：例如，你不能指望它生成一张与“米老鼠”或“钢铁侠”完全一致的、可商用的图片，这涉及版权和模型知识边界问题。
*   **不适合作为图片编辑工具**：它不能对上传的现有照片进行修改（如换背景、P掉路人）。如果你需要这个功能，应该寻找在线的PS工具或专门的AI修图网站。
*   **不适合零成本无限使用**：它依赖后台的付费AI API（如豆包、智谱）。生成图片会产生费用，且API通常有调用频率限制。如果希望完全免费，你需要寻找免费的替代API或模型，但这通常意味着功能、速度或质量的妥协。

希望这份指南能帮助你不仅用好这个工具，更能理解其设计精髓，从而创造出属于你自己的、解决特定问题的AI应用。
