# 对话式写作助手 - 学习指南

--------------------------------

### 【一】这个网页解决了什么问题？

想象一下，你正在写一篇文章、一份报告，或者一个社交媒体帖子。你有了一个初步的想法，但不知道如何展开；或者你写了一段文字，总觉得不够好，但又说不出哪里不好。这时，你需要的不是一个冰冷的工具，而是一个能和你“对话”的伙伴。

这个网页就是一个**对话式的写作伙伴**。它通过聊天的方式，帮助你一步步打磨文字。你可以告诉它你的想法，它会帮你构思大纲；你可以给它一段草稿，它会帮你润色优化；你可以提出各种要求，比如“换个风格”、“写得更详细些”，它会根据你的反馈不断调整。

**适合的场景：**
*   **写作构思与头脑风暴**：当你只有一个模糊主题，需要理清思路、搭建框架时。
*   **内容扩写与丰富**：当你有一段核心内容，但需要扩展成更完整、更生动的段落时。
*   **文字润色与风格调整**：当你写完初稿，需要优化表达、调整语气（如更正式、更轻松）时。
*   **持续迭代与修改**：当你需要根据反馈，对同一段内容进行多次、不同方向的修改时。

**不适合的场景：**
*   **需要一次性生成长篇、结构固定的文档**（如合同、标准报告）。它更适合**迭代式、对话式**的创作。
*   **需要100%准确无误的事实性内容**（如数据报告、新闻稿）。AI可能会“编造”信息，需要你仔细核实。
*   **完全替代人类编辑的深度校对**。它可以优化表达，但无法完全替代对逻辑、情感和深层含义的把握。

### 【二】使用方式（给第一次接触的人）

1.  **准备工作**：首次使用时，点击右上角的**齿轮图标（设置）**，在弹出的窗口中输入你的 DeepSeek API Key。这是让网页能调用 AI 模型的“钥匙”。（Key 仅保存在你的浏览器里，很安全）。

2.  **开始对话**：
    *   点击左侧边栏的 **“新建对话”** 按钮。
    *   在页面中央的**大输入框**里，像和朋友聊天一样，输入你的写作需求。例如：“我想写一篇关于‘如何高效学习’的文章，请帮我构思一个大纲。”
    *   按 **`Enter`** 键发送，或者点击输入框右侧的 **“发送”** 按钮。

3.  **与AI协作**：
    *   AI 会以 Markdown 格式（带标题、列表、引用块等）回复你。
    *   你可以基于它的回复，继续提出要求。比如：“把第二点‘制定计划’展开写得更详细一些”、“把整段的语气调整得更幽默一点”。
    *   页面下方和消息旁有一些**快捷按钮**（如“继续写下去”、“换种表达”），点击可以快速发送常见指令。

4.  **管理你的创作**：
    *   左侧边栏会保存你所有的**对话记录**，点击可以随时切换回之前的创作。
    *   在 AI 的回复下方，可以**复制**内容，或者让 AI **重新生成**上一条回复。
    *   写作完成后，可以通过底部按钮**导出所有对话**为 Markdown 文件。

5.  **输出结果什么样？**
    *   AI 的回复会以**格式清晰的文本块**呈现，包含标题、段落、列表、代码块等。
    *   如果你选择了“深度思考”模型，还可以点击 **“查看思考过程”**，了解 AI 是如何一步步推理出最终答案的。

**容易忽略的细节：**
*   **系统提示词**：点击右上角的**星星图标**，可以设置 AI 的“人设”，比如把它变成“小红书博主”或“学术写作助手”，这会彻底改变它的回复风格。
*   **模型选择**：顶部可以选择“快速”或“深度思考”模型。后者回复更慢，但逻辑更严谨，且会展示思考过程。
*   **停止生成**：如果 AI 回复到一半你觉得不对，可以点击**红色的“停止”按钮**立即中断。
*   **快捷键**：在输入框里，按 `Shift + Enter` 是换行，直接按 `Enter` 是发送。

### 【三】核心结构拆解（学习重点）

这个页面不是一个简单的“输入-输出”框，而是一个**完整的多对话写作工作台**。它的核心结构可以分为四个模块：

1.  **对话管理模块（左侧边栏）**
    *   **职责**：负责创建、保存、切换和删除不同的“写作会话”。每个会话都是独立的，方便你同时进行多个写作项目。
    *   **关键设计**：使用 `localStorage` 在浏览器本地保存所有对话数据，刷新页面也不会丢失。这是构建“可用”Web应用的基础。

2.  **聊天交互模块（主区域）**
    *   **职责**：这是用户与AI直接交互的界面。负责显示历史消息、渲染Markdown、处理用户输入和快捷操作。
    *   **关键设计**：**消息的响应式更新**。当AI流式回复时，页面上的文字是逐字“打”出来的，这通过不断更新Vue的响应式数据来实现，体验非常流畅。

3.  **AI引擎模块（背后逻辑）**
    *   **职责**：负责与DeepSeek API通信。它组装对话历史（包含隐藏的“系统提示词”），发送请求，并以**流式（Stream）** 的方式接收和处理AI返回的数据。
    *   **关键设计**：**流式处理与中断机制**。不是等AI全部生成完再显示，而是一边接收一边显示。同时，通过 `AbortController` 实现了“停止生成”功能，这是良好用户体验的关键。

4.  **配置模块（设置弹窗）**
    *   **职责**：管理API Key和系统提示词。这是控制AI行为的关键开关。
    *   **关键设计**：**提示词预设系统**。提供了几个写好的“角色”模板，让用户一键切换AI的写作风格，极大提升了工具的灵活性和实用性。

**输入 → 处理 → 输出 的逻辑链路：**
1.  **输入**：用户在输入框写下请求 → 点击发送。
2.  **处理**：
    *   Vue 将这条消息添加到当前对话的 `messages` 数组中。
    *   调用 `generateResponse` 函数，该函数将**系统提示词 + 全部历史消息**组装成API要求的格式。
    *   使用 `fetch` 向DeepSeek API发送请求，并开启 `stream: true` 模式。
3.  **输出**：
    *   API 返回一个数据流。
    *   网页通过 `reader.read()` 不断读取数据流中的片段。
    *   每收到一个包含新内容的片段，就立即更新Vue中对应的AI消息对象的 `content` 属性。
    *   由于Vue是响应式的，页面上的DOM会自动更新，实现“打字机”效果。

**最值得学习的设计：**
**“系统提示词 + 对话历史”的上下文管理**。这是所有对话式AI应用的核心。本网页将“系统提示词”作为一条隐藏的、每次请求都携带的指令，它定义了AI的固定角色和风格。而用户的每次对话，都作为历史记录传递下去，使AI能理解上下文，实现真正的“对话”。这种分离（固定指令 vs. 动态历史）的设计非常清晰，是模仿和改造的基石。

### 【四】Prompt / AI 逻辑是如何被设计的？

在这个网页中，**Prompt（提示词）是AI的“灵魂”和“工作说明书”**。

1.  **扮演的角色**：
    *   **系统提示词**：扮演**总导演**的角色。它不参与具体对话，但在后台默默规定AI的“人设”（你是专业的写作助手）、职责（构思、扩写、润色）和回复规范（用Markdown、主动询问）。它决定了AI的**基础行为模式**。
    *   **用户消息**：扮演**具体指令**的角色。它告诉AI在当前回合要完成什么具体任务（“润色这段文字”）。

2.  **解决的问题**：它同时解决了“理解问题”和“生成问题”。
    *   **理解问题**：通过系统提示词，让AI理解它需要扮演的**角色**和需要遵守的**规则**。
    *   **生成问题**：通过用户消息和对话历史，让AI理解用户的**具体需求**和**对话上下文**，从而生成符合要求的文本。

3.  **关键变量**：
    *   **`systemPrompt`**：这是最大的变量。你可以把它从“写作助手”改成“代码调试助手”、“健身教练”、“电影评论家”，AI的行为会随之彻底改变。
    *   **对话历史 (`messages`)**：这是动态增长的变量。它保证了对话的连续性，让AI记得你之前说过什么。
    *   **用户当前输入 (`userInput`)**：这是触发每次生成的具体指令。

4.  **如果只改Prompt，不改代码，会发生什么？**
    *   改变**系统提示词**：AI的**核心身份和能力**会变。例如，改成“你是一个严格的英语语法老师”，那么AI之后的所有回复都会聚焦于纠正你的语法，即使你问它如何写故事。
    *   改变**用户输入**：AI的**单次回复内容**会变。这是最直接的操作。
    *   这意味着，**在不改动一行代码的情况下，你就能将这个“写作助手”改造成“英语老师”、“面试模拟官”、“创意头脑风暴伙伴”等无数种工具**。Prompt是成本最低、效果最显著的改造杠杆。

### 【五】如何模仿它，做出你自己的版本？

如果你想做一个类似的对话式AI工具，请遵循以下路径，从易到难：

**第一步：替换核心场景与提示词（最安全、最快见效）**
*   **目标**：先做出一个“能用”的、属于你自己领域的工具。
*   **操作**：
    1.  复制整个HTML文件。
    2.  修改 `<title>` 和顶部导航栏中的“对话式写作助手”为你工具的名字（如“AI编程助手”）。
    3.  修改 `defaultSystemPrompt` 变量中的内容。这是最关键的一步！根据你的新场景重写。例如，做编程助手，就写“你是一个资深程序员，擅长解答代码问题、调试错误和教授编程概念...”。
    4.  修改 `quickCommands`（快捷指令）和 `promptPresets`（提示词预设）数组，让它们符合你的新场景（如“解释这段代码”、“优化这个函数”、“用Python实现”）。
*   **至此，你已经有了一个功能完整、但主题不同的新工具。**

**第二步：调整输入与输出形式**
*   **目标**：让交互更符合你的专业领域。
*   **操作**：
    1.  **输入**：如果除了文字还需要其他输入（如上传代码文件、选择编程语言），可以在输入区域上方添加额外的表单控件（下拉框、文件上传按钮）。
    2.  **输出**：如果AI回复的内容有特殊展示需求（如代码需要高亮、数据需要图表），可以增强 `renderMarkdown` 函数，或者引入专门的库（如 `highlight.js` 用于代码高亮）。
    3.  修改空状态页面的插图和引导文案，使其更贴合你的新工具。

**第三步：更换或扩展AI后端**
*   **目标**：获得不同的AI能力或降低成本。
*   **操作**：
    1.  **更换API**：将代码中 `fetch` 请求的URL从 `https://api.deepseek.com/v1/chat/completions` 换成其他提供商的（如OpenAI、Claude、国内大模型）。同时需要调整请求头和参数格式。
    2.  **支持多模型**：在模型选择器中增加更多选项，并在 `generateResponse` 函数中根据选择调用不同的API。
    3.  **本地模型**：如果你有技术能力，甚至可以尝试使用 `Ollama` 等工具运行本地模型，将API地址指向本地服务。

**记住：先从第一步开始。成功运行起来，会给你巨大的信心。**

### 【六】3–5 个可直接尝试的改造方向

1.  **增加“知识库”或“参考文档”上传功能**：
    *   **操作**：在输入框附近添加一个“上传文档”按钮。用户上传PDF/TXT文件后，你在调用API前，先将文档内容进行总结或提取关键信息，然后拼接到系统提示词或用户消息中。这样AI就能基于你提供的特定资料来回答，实现“定制化知识问答”。
    *   **价值**：从通用写作工具变为**个人或企业的专属知识顾问**。

2.  **实现“对话分支”或“版本回溯”**：
    *   **操作**：当用户对某条AI回复点击“重新生成”时，不要覆盖原消息，而是创建一个平行的“分支对话”。在UI上，可以设计成树状结构或时间线视图，让用户能清晰地看到不同生成路径的结果并随时切换。
    *   **价值**：更好地支持**创意探索和决策比较**，保留思维过程。

3.  **集成文本编辑器功能**：
    *   **操作**：将AI回复区域从简单的Markdown渲染，升级为一个轻量级的**富文本编辑器**（例如使用 `Tiptap` 或 `Quill`）。允许用户直接在AI生成的内容上进行编辑、批注、高亮，然后可以将编辑后的内容再次发送给AI进行下一步处理。
    *   **价值**：将“对话”与“编辑”无缝融合，形成**真正的人机协同写作流**。

4.  **增加语音输入与输出**：
    *   **操作**：利用浏览器的 `Web Speech API`，在输入框旁增加一个麦克风按钮，支持语音输入。同时，在AI回复旁增加一个喇叭按钮，点击后使用 `SpeechSynthesis` 将文本朗读出来。
    *   **价值**：提升易用性和多场景适用性，例如在移动端、或为视力障碍用户提供便利。

5.  **设计“工作流”或“模板”**：
    *   **操作**：预设几个完整的写作流程，如“小红书爆款文案生成”、“技术博客写作”、“周报生成”。用户选择后，工具会自动通过多轮预设的提问（如“产品名称？”、“目标人群？”、“核心卖点？”）引导用户输入，然后一次性生成结构完整的初稿。
    *   **价值**：从自由对话升级为**结构化、向导式的生产力工具**，降低用户的心智负担。

### 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合生成需要绝对精确和法律责任的内容**：例如法律合同、医疗诊断建议、财务投资预测。AI可能产生看似合理实则错误或有风险的输出，必须由专业人士审核。
2.  **不适合完全替代需要深度人类情感和共情的工作**：例如心理辅导、情感安慰、重要的道歉信或情书。AI缺乏真实的情感体验，其回应可能流于表面或模式化。
3.  **不适合处理实时性、动态性极强的任务**：例如基于最新新闻的评论、实时股票分析。它的知识有截止日期，且无法主动获取最新信息（除非你手动喂给它）。
4.  **不适合作为唯一的信息来源进行学习或研究**：AI可能“一本正经地胡说八道”（产生幻觉）。对于关键知识，务必通过权威渠道交叉验证。

**如果你想做上述事情，应该：**
*   对于1和2，应该将本工具定位为**人类专家的辅助工具**，用于生成初稿或提供思路，但最终决策和定稿必须由人完成。
*   对于3，需要寻找或开发能集成**实时数据API**（如新闻接口、股票接口）的工具。
*   对于4，应该使用专业的学术数据库、搜索引擎或教育平台。

**总结**：这个网页是一个强大的**创意协作和内容生产启动器**，但它不是万能的“答案机器”。理解它的边界，才能更好地利用它的长处。
