# AI 绘图提示词生成器 - 学习指南

---

## 【一】这个网页解决了什么问题？

**使用场景：**
当你有一个画面构思（比如“一只猫在月光下看书”），但不知道如何用专业的英文术语向AI绘图工具（如Midjourney、Stable Diffusion）描述时，这个工具可以帮你。它就像一个“翻译官”，把你的中文想法，结合你选择的风格、光线等参数，转换成AI能理解的高质量英文指令（Prompt）。

**适合什么情况？**
- **初学者入门AI绘画**：不知道专业关键词怎么写。
- **效率提升**：想快速生成结构清晰、包含负面提示词的完整Prompt。
- **灵感探索**：通过选择不同的风格、光线组合，看看专业Prompt会是什么样。

**不适合什么情况？**
- **直接生成图片**：它只生成文字指令，你需要把指令复制到真正的AI绘图工具里才能出图。
- **极度精细的控制**：它提供的是通用模板和关键词库，对于需要极其特殊、小众风格或复杂构图控制的场景，可能不够用。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **核心描述**：一个文本框，用中文写下你想画的画面。
2.  **各种选择器**：像点菜一样，选择目标平台、艺术风格、画面比例、光线效果、镜头角度等。
3.  **额外关键词**：一个可选的输入框，可以手动添加一些你知道的英文关键词。

**用户通常会做哪几步操作？**
1.  **描述画面**：在“画面描述”框里写下你的想法，比如“一位宇航员在太空咖啡馆喝咖啡”。
2.  **选择平台**：点选你打算使用的AI工具，比如Midjourney。
3.  **定制风格**：勾选你喜欢的风格，比如“赛博朋克”、“3D渲染”。
4.  **调整参数**：选择画面比例（如16:9）、光线（如霓虹灯）、镜头角度（如广角）。
5.  **点击生成**：按下“🎨 生成 Prompt”按钮。
6.  **复制结果**：等待几秒后，复制生成的英文Prompt去你的AI绘图工具使用。

**输出结果长什么样？**
生成的结果会以几个清晰的卡片展示：
-   **主 Prompt**：一长串专业的英文关键词，按重要性排列。
-   **负面提示词**：告诉AI要避免画出的东西（如模糊、多余的手指）。
-   **参数建议**：包含你刚才选择的比例、质量等参数的命令。
-   **中英对照**：解释主Prompt里关键词的中文意思。
-   **一键复制完整命令**：一个按钮直接复制整合了以上所有信息的完整指令。

**有哪些容易忽略的使用细节？**
1.  **API Key**：第一次使用前，需要点击右上角“设置”图标，填入你自己的DeepSeek API Key。这是工具调用AI大脑的“钥匙”。
2.  **词库功能**：右上角的“词库”按钮里藏着一个宝库，里面有分类好的高质量英文关键词（带中文翻译），点击可以直接添加到“额外关键词”里。
3.  **模型切换**：顶部有“V3”和“R1”按钮。R1是“深度思考”模型，生成速度稍慢，但过程更严谨，且会展示它的思考过程，适合学习Prompt构建逻辑。
4.  **风格多选**：艺术风格是可以多选的，组合出更独特的风格。

## 【三】核心结构拆解（学习重点）

这个页面可以看作一个 **“参数化Prompt工厂”** ，由三大模块组成：

**1. 输入控制面板（左侧）**
-   **职责**：收集用户的所有创作意图和参数偏好。它把模糊的“想法”转化为结构化的“数据”。
-   **组成**：描述文本框 + 多个参数选择器（平台、风格、比例等）。每个选择器都对应最终Prompt的一个维度。

**2. AI处理引擎（背后，不可见）**
-   **职责**：是整个工具的大脑。它接收左侧面板的结构化数据，按照预设的规则（即**系统Prompt**），调用DeepSeek API，生成专业的绘图指令。
-   **关键设计**：它不是一个简单的翻译器，而是一个**遵循严格指令的Prompt工程师**。系统Prompt规定了输出的格式（JSON）、内容结构（主Prompt、负面词等）和优化原则。

**3. 结果展示与输出模块（右侧）**
-   **职责**：将AI生成的结果进行美观、模块化的呈现，并提供便捷的复制操作。
-   **组成**：多个结果卡片（主Prompt、负面词、参数等）+ 复制按钮。设计上区分明显，让用户一目了然。

**输入 → 处理 → 输出 的逻辑链路：**
```
你的中文描述 + 选择的参数
    ↓ (点击生成按钮)
被组装成一个给AI的“任务请求”（User Prompt）
    ↓
发送给DeepSeek API，并附上“工程师工作手册”（System Prompt）
    ↓
AI（DeepSeek模型）根据手册处理请求，生成结构化JSON
    ↓
JSON结果被解析，填充到右侧各个展示卡片中
    ↓
你复制结果，用于真正的AI绘图
```

**最值得学习的设计：**
**“系统Prompt工程”与“前端参数化”的紧密结合。** 前端每一个下拉框、按钮的选择，最终都转化为自然语言描述，插入到给AI的User Prompt中。而System Prompt则像一个严格的质检员和格式员，确保AI的输出每次都符合我们想要的、可直接使用的格式。这种设计将复杂的AI能力封装成了一个傻瓜式的表单操作，极大降低了使用门槛。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
它是整个工具的 **“灵魂”和“生产蓝图”**。前端界面只是收集原材料，而Prompt（特别是System Prompt）定义了如何将这些原材料加工成最终产品（可用的绘图指令）的完整工艺流程和质检标准。

**它解决的是“理解问题”还是“生成问题”？**
两者皆有，但更偏向 **“结构化生成问题”**。
-   **理解**：AI需要理解用户的中文描述和各类参数选择。
-   **生成**：更重要的是，AI需要根据一套明确的规则（“按重要性排序关键词”、“包含质量词”、“生成负面词”），生成格式严格、内容专业的英文文本。

**哪些信息是Prompt中的关键变量？**
在给AI的User Prompt中，以下内容是从前端动态获取并填入的：
-   `【中文描述】`：用户输入的核心内容。
-   `【配置参数】`：包括`目标平台`、`画面风格`、`画面比例`等所有用户在前端选择的值。这些是**关键变量**，它们直接决定了生成Prompt的细节。

**如果只改Prompt，不改代码，会发生什么变化？**
变化会非常巨大且直接：
1.  **改变输出格式**：修改System Prompt中要求的JSON字段，比如增加一个`colorPalette`（色彩调色板）字段，那么AI就会开始生成这项内容，但前端可能无法显示它。
2.  **改变生成风格**：修改System Prompt中的指令，如把“包含画面质量词”改为“避免使用过于常见的质量词，追求独特描述”，那么生成的Prompt风格会立刻从“主流高质量”转向“小众文艺”。
3.  **适配新平台**：在User Prompt中增加对新平台（如`Leonardo.ai`）的说明和格式要求，AI就能开始为该平台生成Prompt。
**这证明了Prompt是控制AI行为的核心杠杆。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，逐步打造自己的AI工具：

**第一步：保持核心结构不变，替换使用场景（最安全）**
-   **目标**：做一个“AI周报生成器”。
-   **操作**：
    -   将左侧输入面板的标签全改掉：“画面描述”改为“本周工作摘要”，“艺术风格”改为“汇报风格”（如：正式、轻松、数据驱动）。
    -   将右侧输出模块的标题改掉：“主Prompt”改为“周报内容”，“负面提示词”改为“注意事项”。
    -   修改System Prompt和User Prompt，让AI的角色从“Prompt工程师”变成“部门经理”，任务是“根据每周工作摘要和选择的汇报风格，生成一份结构清晰的周报”。

**第二步：调整输入字段或Prompt逻辑**
-   在“周报生成器”中，增加一个“重点突出”多选框，选项包括“突出成果”、“反思不足”、“寻求支持”。
-   在User Prompt中增加对应变量：`【重点突出】：`。
-   在System Prompt中增加对应指令：“根据用户选择的重点，调整周报内容的详略和语气”。

**第三步：改变输出形式或展示方式**
-   周报生成后，除了显示全文，可以增加一个“生成PPT大纲”按钮。
-   点击后，调用另一个AI接口（或同一个接口但不同Prompt），将周报内容转换为PPT大纲格式（标题、要点列表）并展示出来。

**从哪里下手最安全？**
从 **第一步** 开始最安全。因为你不需要改动任何JavaScript逻辑，只需要进行“文本替换”（前端标签、Prompt文本）和“概念映射”（把绘画的概念换成你新场景的概念）。这能让你立刻看到效果，建立信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“灵感激发”输入**：
    -   **操作**：在输入区增加一个“参考图片URL”的输入框。
    -   **改造**：在User Prompt中加入“这是参考图片的链接：[用户输入的URL]，请分析其风格和构图，并融入到你生成的Prompt中。” 这样就从“文字生Prompt”进阶到“图+文生Prompt”。

2.  **切换或增加AI模型/API**：
    -   **操作**：在设置弹窗中，增加一个“模型提供商”下拉框，选项包括DeepSeek、OpenAI、Claude等。
    -   **改造**：修改`callDeepSeekStream`函数，根据用户选择，动态改变API请求的URL、Headers和Body结构。这能让你体验不同模型生成Prompt的差异。

3.  **拆解为“学习模式”与“生产模式”**：
    -   **操作**：在顶部增加模式切换标签。
    -   **改造**：
        -   **学习模式**：侧重展示和解释。生成Prompt后，每个关键词都可以点击，弹出小窗解释其含义和为何被添加。
        -   **生产模式**：追求极简和速度。只显示最核心的Prompt和“一键复制”按钮。

4.  **优化交互：增加“Prompt历史”与“收藏夹”**：
    -   **操作**：在页面底部或侧边栏增加一个区域。
    -   **改造**：使用浏览器的`localStorage`，将每次生成的Prompt（连同当时的输入参数）保存下来。用户可以回顾历史记录，并将满意的结果收藏，方便下次直接调用或微调。

5.  **引入“风格强度”滑块**：
    -   **操作**：在每个已选择的艺术风格标签旁，增加一个从0到100的滑块。
    -   **改造**：在User Prompt中，将“画面风格：赛博朋克、3D渲染”改为“画面风格：赛博朋克(强度80%)、3D渲染(强度50%)”。让AI对风格关键词的运用更有层次感。

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1.  **不保证出图质量**：它生成的是“指令”，最终图片质量取决于你使用的AI绘图工具及其模型版本、渲染算力。一个好的Prompt只是成功的一半。
2.  **非精准视觉控制**：对于需要精确控制物体位置、空间关系、复杂光影交互的场景（例如：“请让猫的左耳尖恰好触碰到从窗户数第三道阳光”），这种基于自然语言描述和通用关键词的方法难以实现，需要借助ControlNet、IP-Adapter等更专业的图像控制技术。
3.  **无法替代人类创意**：它是一个强大的辅助和翻译工具，但画面的核心创意、情感和故事性依然来源于你。它无法理解“孤独”、“希望”等抽象概念的深层内涵，只能通过关联的关键词去近似表达。

**如果你想做X，应该换什么工具或方式：**
-   **如果你想直接得到图片**：请使用Midjourney、DALL-E、Stable Diffusion WebUI等真正的AI绘图平台。
-   **如果你想对生成图片进行精细的局部修改**：请学习使用Photoshop的AI功能，或SD WebUI的Inpainting/Outpainting。
-   **如果你想基于一张现有图片生成类似风格的图片**：应该使用具备“图生图”功能或“风格参考”功能的绘图工具，而不是本提示词生成器。
