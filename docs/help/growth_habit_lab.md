# 微习惯实验室 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景**：当你想要培养一个新习惯，但觉得目标太大、无从下手时，这个工具可以帮你。比如你想“每天阅读”，但不知道具体怎么做才能坚持下来。它会把你的大目标拆解成接下来7天里，每天一个非常小、几乎不可能失败的具体行动。比如“今天把书放在床头”、“明天打开书看一页”。

**适合情况**：
- 想开始一个新习惯，但缺乏具体计划
- 需要把模糊目标（如“更健康”）变成可执行步骤
- 希望获得一个循序渐进的启动方案

**不适合情况**：
- 需要长期（超过7天）的详细规划
- 已经形成习惯，需要进阶训练
- 需要专业医疗或心理咨询指导

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本框，让你输入想培养的习惯（例如：“每天冥想”、“学习编程”）
- 右上角的设置按钮，用于配置AI API（第一次使用前需要设置）

**用户通常会做哪几步操作？**
1. **首次设置**：点击右上角齿轮图标 → 输入你的DeepSeek API Key → 选择模型 → 保存
2. **输入目标**：在文本框里写下你的习惯目标
3. **生成计划**：点击“生成7天实验”按钮
4. **查看结果**：等待几秒钟，下方会显示7天的具体任务

**输出结果长什么样？**
- 7个卡片，按Day 1到Day 7排列
- 每个卡片包含一句具体的行动指令
- 例如输入“每天阅读”可能得到：
  - Day 1：把想读的书放在显眼位置
  - Day 2：打开书，阅读任意一页
  - Day 3：阅读5分钟

**容易忽略的使用细节**
1. **必须配置API Key**：第一次使用时，不配置API Key会报错
2. **目标要具体**：输入“每天运动”比“变健康”效果更好
3. **可以修改目标**：生成后如果觉得不合适，可以修改目标重新生成
4. **计划是建议性的**：这些任务只是起点，你可以根据实际情况调整

## 【三】核心结构拆解（学习重点）

**页面由哪几个关键模块组成？**

1. **配置模块**（右上角设置）
   - 职责：管理AI API的访问凭证
   - 特点：使用localStorage保存配置，避免每次输入

2. **输入模块**（文本框 + 按钮）
   - 职责：接收用户目标，触发生成流程
   - 特点：简单的表单交互，有加载状态提示

3. **AI处理模块**（隐藏的逻辑层）
   - 职责：构造Prompt，调用AI API，解析返回结果
   - 特点：封装了完整的API调用流程

4. **输出展示模块**（7天任务卡片）
   - 职责：清晰展示生成的计划
   - 特点：使用渐入动画，视觉层次分明

**输入 → 处理 → 输出 的逻辑链路**
```
用户输入目标 → 点击生成 → 构造Prompt → 调用AI API → 解析AI回复 → 清洗数据 → 渲染卡片
```

**最值得学习的设计**
- **渐进式任务生成**：不是一次性给完整计划，而是从“最小可执行”开始
- **错误处理与状态管理**：有明确的加载状态、错误提示
- **配置持久化**：API设置一次，后续自动记住
- **视觉反馈**：按钮禁用状态、卡片动画，让用户感知到系统状态

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是“翻译官”，把用户模糊的目标翻译成AI能理解的具体指令，再把AI的专业知识翻译成用户能执行的步骤。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。AI已经理解“习惯养成”这个概念，Prompt的作用是：
1. 告诉AI要扮演什么角色（习惯养成教练）
2. 规定输出格式（7天，每行一句）
3. 提供具体目标上下文

**Prompt中的关键变量**
```javascript
`目标：${goal.value}\n请拆成 7 天的微习惯任务，每行一句。`
```
- `goal.value`：用户输入的具体目标
- “7天”：限制时间范围
- “微习惯任务”：定义任务性质（小、易执行）
- “每行一句”：规定输出格式

**如果只改Prompt，不改代码，会发生什么变化？**
- 改“7天”为“21天” → 生成三周计划
- 改“微习惯任务”为“详细步骤” → 任务描述更详细
- 改“每行一句”为“包含时间和地点” → 输出包含更多细节
- 改系统提示中的角色 → AI会用不同风格回复（如“严厉教练”vs“温柔伙伴”）

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从安全到进阶）**

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改标题和提示语
- 例如改成“学习计划生成器”，Prompt改为“请拆成7天的学习任务”
- 这一步几乎不用改代码，只改文字内容

**第二步：调整输入字段或Prompt**
- 增加一个输入框：如“当前水平”（初学者/进阶）
- 修改Prompt：`目标：${goal}，当前水平：${level}，请生成适合的7天计划`
- 这一步需要增加数据绑定，但页面结构不变

**第三步：改变输出形式或展示方式**
- 把7天卡片改成日历视图
- 增加“标记完成”功能
- 添加“导出为图片”按钮
- 这一步需要改动UI和交互逻辑

**最安全的下手点**：从**修改Prompt和界面文字**开始。这是零风险、立即见效的改动。

## 【六】3–5个可直接尝试的改造方向

1. **增加个性化输入**
   - 添加“难度选择”：简单/中等/挑战
   - 添加“可用时间”：每天5分钟/15分钟/30分钟
   - 修改Prompt：`目标：${goal}，难度：${difficulty}，每天可用时间：${time}`

2. **扩展时间范围**
   - 增加选择器：7天/14天/30天计划
   - 修改生成逻辑，根据选择的天数调整Prompt和显示

3. **增加社交分享功能**
   - 每张卡片添加“分享”按钮
   - 生成计划总结图（使用html2canvas库）
   - 添加“复制全部”功能

4. **本地存储计划**
   - 保存生成的计划到localStorage
   - 添加“我的历史计划”页面
   - 允许编辑已生成的计划

5. **多模型支持**
   - 在设置中增加更多AI模型选项
   - 根据不同模型调整Prompt策略
   - 添加“测试不同模型效果”功能

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明**

1. **不适合复杂技能学习**
   - 如果你想学编程、乐器等复杂技能，7天微习惯只是“开始”，不是“学会”
   - 应该用：专门的学习平台（如Coursera）或长期学习计划工具

2. **不适合医疗健康建议**
   - 涉及减肥、康复等健康目标时，AI建议可能不专业
   - 应该用：咨询专业医生或营养师

3. **不适合团队协作**
   - 这是个人工具，没有团队进度跟踪、提醒功能
   - 应该用：Trello、Notion等协作工具

4. **不适合深度个性化**
   - AI不知道你的具体作息、身体状况、已有习惯
   - 生成的计划是“通用模板”，需要你手动调整

5. **不适合依赖网络**
   - 必须联网使用（依赖AI API）
   - 应该用：本地运行的应用程序或提前下载计划

**如果用户想做X，应该换什么工具**
- 想做**长期习惯追踪** → 用Habitica、Loop Habit Tracker
- 需要**专业教练指导** → 找真人教练或使用Coach.me
- 想要**科学数据支持** → 用Fabulous、Streaks（基于行为科学研究）
- 需要**离线使用** → 开发本地版本或使用笔记应用

---

**最后提醒**：这个工具的价值在于“降低开始的门槛”。它不保证你成功，但保证你“开始”。最好的使用方式是：生成计划 → 执行 → 根据实际情况调整 → 形成自己的节奏。
