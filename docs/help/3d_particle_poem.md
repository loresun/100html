# Particle Poem 3D · 粒子诗歌云 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你心中有一个模糊的情感或画面——比如“雨后的城市街道”或“童年的夏日午后”。你想把它表达出来，但单纯的文字似乎不够生动。这个网页就是为你准备的：**它将抽象的情感或主题，转化为一首短诗和一组关键词，然后用动态的3D粒子云将这些文字“可视化”出来**。

**适合的使用场景：**
- **创意激发**：当你需要为写作、设计或艺术创作寻找灵感时。
- **情绪表达**：想用一种新颖、视觉化的方式记录或分享某种心境。
- **演示与展示**：在演讲或分享中，用动态的视觉元素来辅助表达一个核心概念。
- **学习与探索**：想了解如何将AI生成的内容与3D图形技术结合。

**不适合的情况：**
- 需要生成长篇、结构严谨的文章或报告。
- 需要精确控制每一个视觉细节（如粒子颜色、形状）。
- 在没有网络或无法访问AI API的环境下使用。

## 【二】使用方式（给第一次接触的人）

1.  **打开页面**：你会看到一个深邃的星空背景，中央漂浮着默认的粒子云和文字。
2.  **输入主题**：在页面左侧的灰色面板中，找到输入框。输入任何你想表达的主题，例如：“孤独的灯塔”、“咖啡的香气”、“春天的第一场雨”。
3.  **点击生成**：点击输入框下方的 **“生成粒子诗歌”** 按钮。
4.  **观察结果**：
    - **左侧面板**：会显示AI为你生成的一首短诗。
    - **3D画布**：粒子云会发生变化，新的关键词（如“灯塔”、“守望”、“潮汐”）会以发光文字的形式在云中漂浮、起伏。
    - **状态提示**：按钮上方的状态栏会告诉你生成进度或结果。
5.  **交互探索**：
    - **旋转视角**：按住鼠标左键拖动，可以旋转整个3D场景。
    - **缩放视角**：使用鼠标滚轮可以拉近或推远视图。
    - **高级设置**：点击右上角的 **“DeepSeek 设置”** 按钮，可以配置你自己的AI API密钥和选择模型。

**容易忽略的细节：**
- **API密钥是必需的**：首次使用时，如果不配置自己的DeepSeek API密钥，页面只会展示**演示模式**（使用固定的默认数据），不会真正调用AI。点击右上角设置进行配置。
- **耐心等待**：点击生成后，需要几秒钟时间等待AI响应和3D场景重建，状态栏会提示进度。
- **动态效果**：生成后，粒子云和关键词会一直缓慢旋转和上下浮动，这是设计的一部分，不是卡顿。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责分明的模块：

**1. 用户交互与配置模块（左侧面板 & 设置弹窗）**
- **职责**：接收用户输入（主题）、展示输出（诗歌）、管理配置（API密钥）。
- **包含**：输入框、生成按钮、诗歌展示框、设置按钮和弹窗。
- **逻辑**：`用户输入主题 -> 点击按钮 -> 触发生成流程 -> 展示诗歌文本`。

**2. AI 内容生成模块（隐藏在代码中的逻辑）**
- **职责**：与DeepSeek API通信，将用户主题转化为结构化的创意数据（诗歌、关键词、颜色等）。
- **核心函数**：`callDeepSeek` 和 `buildPrompt`。
- **逻辑**：`主题 -> 拼接成特定格式的Prompt -> 发送给AI -> 解析返回的JSON数据`。

**3. 3D 视觉渲染模块（占据整个画布）**
- **职责**：根据AI生成的数据，创建并驱动动态的3D粒子场景。
- **核心函数**：`createParticles` 和 `animate`。
- **逻辑**：`解析后的数据 -> 创建对应数量的粒子/设置颜色/生成文字精灵 -> 加入场景并启动动画循环`。

**最值得学习的设计：数据流与职责分离**
整个应用的核心设计思路是 **“数据驱动”**。AI模块产出一份标准的JSON数据包，3D模块则完全根据这份数据包来“绘制”画面。这两个核心模块通过一份约定好的数据结构（包含`poem`, `keywords`, `palette`等字段）进行通信，彼此独立。这意味着：
- 你可以轻易更换AI供应商，只要它能返回相同格式的数据。
- 你也可以彻底重写3D渲染部分，用另一种技术（如2D Canvas、SVG）来表现同一份数据。
- 这种“数据契约”的设计，是构建复杂且可维护应用的关键。

## 【四】Prompt / AI 逻辑是如何被设计的？

**1. Prompt扮演的角色：**
在这里，Prompt是一个**精确的指令生成器**。它解决的是“生成问题”——即要求AI按照一个非常具体的格式和内容要求来创造内容，而不是让AI去“理解”一个开放性问题。

**2. 关键变量与设计：**
- **核心变量**：用户输入的 `{topic}` 被直接嵌入到Prompt中。
- **格式约束**：Prompt明确要求AI **“只返回 JSON”** ，并详细列出了JSON必须包含的字段（`poem`, `keywords`, `palette`, `density`, `drift`, `spark`）及其大致范围（如`density(0.4-1)`）。这是确保后端代码能正确解析的关键。
- **角色设定**：系统提示（`system` content）将AI定义为“视觉艺术与诗歌生成助手”，引导其产出更具美感和想象力的内容。

**3. 如果只改Prompt，不改代码：**
- **改变风格**：将Prompt中的“生成粒子诗歌云”改为“生成赛博朋克风格的标语云”，AI产出的诗歌和关键词风格会大变，但3D云的外观（颜色、密度）可能因未修改`palette`等参数的描述而显得不匹配。
- **增加/减少字段**：如果在Prompt中增加一个`"shape": "circle|spiral"`字段，但代码中没有解析和利用这个字段的逻辑，那么这个新增信息会被忽略。
- **改变格式要求**：如果删除“只返回JSON”的指令，AI可能会返回一段包含解释的文字，导致后端解析失败。

## 【五】如何模仿它，做出你自己的版本？

这是一个安全的、循序渐进的模仿路径：

**第一步：替换“灵魂”（主题与AI）**
这是最安全、见效最快的起点。保持所有3D代码和页面布局完全不变。
1.  **更换使用场景**：把“诗歌”换成“电影标语”、“产品特性”、“人物标签”。例如，做一个“电影角色粒子云”，输入电影名，生成角色标签和经典台词。
2.  **调整Prompt**：修改 `buildPrompt` 函数中的文本。将“诗歌”、“关键词”等词替换为你的新场景需要的输出描述（如“角色三个核心特质”、“一句经典台词”）。**务必保持JSON字段名称和结构暂时不变**。

**第二步：调整“外观”（3D视觉）**
在第一步成功的基础上，开始修改视觉效果。
1.  **改变颜色**：在 `createParticles` 函数中，修改 `palette` 数组的默认颜色，或调整粒子材质（`PointsMaterial`）的初始颜色。
2.  **替换文字精灵**：`createTextSprite` 函数控制关键词的样式。你可以修改这里的字体（`font`）、大小、阴影效果，或者将平面文字改为加载3D字体模型。
3.  **调整动画**：在 `animate` 函数中，微调 `particleGroup.rotation.y`（旋转速度）或 `sprite.position.y`（浮动幅度）的数值，感受变化。

**第三步：重塑“骨架”（页面与交互）**
当你对前两步有信心后，可以改动页面结构。
1.  **增加输入项**：在左侧面板中增加一个下拉菜单，让用户选择“风格”（如“浪漫”、“科幻”、“暗黑”），并将这个值传递给Prompt。
2.  **改变输出布局**：将诗歌展示框移到3D画布的下方，或者改为一个在粒子云旁边弹出的气泡。
3.  **简化或复杂化**：如果你只想做纯视觉展示，可以隐藏左侧面板，让3D云成为绝对主角。反之，你可以增加一个“历史记录”面板，保存之前生成的所有诗歌。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“情绪强度”滑块**：
    - **操作**：在输入框下方添加一个范围在1-10的滑块。
    - **改造**：将这个值传递给Prompt，例如：“… 主题‘${topic}’，情绪强度为${intensity}（1为平和，10为激烈）…”。AI会根据强度值调整诗歌用词和配色建议。
    - **效果**：用户可以通过滑块直观控制生成内容的基调。

2.  **切换视觉风格预设**：
    - **操作**：增加几个按钮，如“星云”、“雪花”、“萤火虫”。
    - **改造**：每个按钮对应一套预定义的粒子参数（`size`, `opacity`, `drift`值）和动画模式。点击后，用这套参数覆盖AI返回的`density`等值，或直接用于`createParticles`函数。
    - **效果**：同一首诗可以匹配不同的视觉氛围。

3.  **接入其他AI模型或本地模型**：
    - **操作**：在设置弹窗的模型下拉列表中，增加选项如“OpenAI GPT-4”、“Claude 3”，或“本地Ollama”。
    - **改造**：修改 `callDeepSeek` 函数，根据选择的模型，切换不同的API端点、请求头和Prompt微调策略。
    - **效果**：对比不同模型在创意写作上的表现差异。

4.  **从“生成”变为“编辑”**：
    - **操作**：生成后，在诗歌旁边显示“编辑”按钮。
    - **改造**：点击后，诗歌文本框变为可编辑状态。用户修改后，点击“重新可视化”，程序将用户修改后的文本拆解成关键词（可用简单算法），并重新生成粒子云。
    - **效果**：赋予用户更大的控制权，实现人机协同创作。

5.  **添加背景音乐与音效**：
    - **操作**：引入Web Audio API。
    - **改造**：根据AI返回的 `palette`（颜色）或 `keywords` 的情绪，从预置的几种环境音（如海浪、雨声、空灵合成音）中选择一种播放。粒子碰撞时可以触发细微的音效。
    - **效果**：打造沉浸式的多感官体验。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合生成精确或事实性内容**：它的核心是**创意和感觉**，而不是准确性。不要用它来生成学术摘要、新闻稿或技术文档，它的输出是诗意且开放的。
2.  **不适合作为稳定的数据可视化工具**：粒子效果虽然美观，但无法精确表达数据间的定量关系（如柱状图、折线图）。如果你想可视化销售数据或用户统计，请使用专业的图表库（如ECharts, D3.js）。
3.  **不适合无网络环境的创作**：其核心功能依赖在线的DeepSeek API。若需离线使用，你需要将其改造为：1) 使用本地大模型（如通过Ollama）；或 2) 完全移除AI部分，变成一个手动输入关键词和参数的可视化编辑器。
4.  **不适合需要复杂交互的3D场景**：它使用的是基础的粒子系统，而非复杂的3D模型。如果你想制作一个可以“点击粒子查看详情”或“在场景中自由行走”的复杂交互应用，你需要学习更完整的3D游戏引擎（如Three.js的更多功能、Babylon.js或Unity）。
