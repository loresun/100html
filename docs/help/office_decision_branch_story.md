# 决策分岔剧情图 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
当你面临一个重要的选择，比如“是否要换工作”、“要不要考研”、“该不该表白”时，这个网页能帮你将抽象的纠结可视化。它通过一个简单的分岔图，让你直观地看到选择A和选择B可能带来的短期与长期结果，并附上AI的建议总结。这就像一位冷静的顾问，帮你把脑海中的“如果……会怎样”画在纸上。

**适合情况：**
- 个人面临二选一的重大决策，需要理清思路。
- 团队讨论方案时，需要快速对比不同路径的潜在影响。
- 写作或游戏设计时，需要构思故事分支。

**不适合情况：**
- 需要精确数据、财务计算或风险评估的决策（如投资）。
- 涉及多个变量、复杂条件或连续决策的连锁反应。
- 需要即时、动态反馈的实时决策场景。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **决策主题**：一个文本框，填写你面临的核心问题（如“是否换工作”）。
2.  **选项A与选项B**：两个文本框，分别填写你的两个具体选择（如“留在原公司”和“跳槽去新公司”）。

**用户通常会做哪几步操作？**
1.  **配置**：首次使用时，点击右上角的齿轮图标，在弹出的设置窗口中输入你的DeepSeek API Key并保存。
2.  **填写**：在左侧面板的三个输入框中，依次填入你的决策主题和两个选项。
3.  **生成**：点击“生成剧情图”按钮。
4.  **查看**：等待几秒后，在右侧面板查看生成的分岔图和AI建议。

**输出结果长什么样？**
- **分岔图**：一个由节点和箭头组成的流程图。起点是你的决策主题，分出两条路指向选项A和B，每条路再分别延伸出“短期结果”和“长期结果”两个节点。
- **文字总结**：在分岔图下方，会有一段AI生成的文字，简要概括两个选项的利弊并给出最终建议。

**有哪些容易忽略的使用细节？**
- **API Key是必须的**：不配置就无法生成任何内容。Key需要你自己从DeepSeek平台获取。
- **选项描述要具体**：输入“选项A：涨薪20%”比“选项A：更好”能获得更精准的分析。
- **生成需要时间**：点击按钮后会有几秒的加载，期间按钮会变灰，请耐心等待。
- **结果非确定性**：AI每次生成的结果可能略有不同，这是正常现象。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

1.  **输入与控制模块（左侧面板）**
    - **职责**：接收用户最核心的决策信息（主题、选项），并触发整个生成流程。
    - **组成**：三个输入框 + 一个生成按钮 + 错误提示区域。
    - **逻辑**：用户填写 → 点击按钮 → 验证输入并收集数据 → 传递给“AI处理模块”。

2.  **AI处理与协调模块（隐藏在代码中）**
    - **职责**：这是页面的“大脑”。它负责将用户的输入组装成AI能理解的指令（Prompt），调用AI API获取分析结果，再将AI返回的文本转换成图表代码。
    - **逻辑**：接收输入数据 → 拼接成特定格式的Prompt → 调用DeepSeek API → 解析AI回复 → 将回复的关键部分嵌入Mermaid图表代码模板。

3.  **输出与展示模块（右侧面板）**
    - **职责**：将AI处理后的结果，以可视化图表（Mermaid图）和文字摘要的形式呈现给用户。
    - **组成**：一个图表渲染容器 + 一个文字显示区域。
    - **逻辑**：接收AI模块生成的Mermaid代码 → 调用Mermaid库渲染成SVG图表 → 同时显示AI的完整文字总结。

**最值得学习的设计：**
**“Prompt即桥梁”的设计模式**。这个网页没有复杂的算法，其核心智慧在于如何设计那个发给AI的指令（Prompt）。它把结构化的用户输入（主题、选项A、选项B）巧妙地填充到一个固定的问题模板中，从而“引导”AI输出格式规整、内容相关的答案。然后，代码再像拼图一样，从AI的答案中提取片段，填入另一个固定的图表代码模板。这种 **“用户输入 → Prompt模板 → AI → 输出模板 → 最终呈现”** 的链路，是构建轻量级AI应用非常高效且可复用的范式。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色：**
在这个页面中，Prompt是一个**高度结构化的指令模板**。它不是一个开放性问题，而是一个规定了AI回答格式和内容的“填空题试卷”。

**它解决的是“生成问题”还是“理解问题”？**
主要解决的是**结构化生成问题**。AI不需要深度理解“换工作”的情感复杂性，它的任务被严格限定为：根据给定的主题和选项，生成**四条简短的结果描述（A短期、A长期、B短期、B长期）和一句总结**。Prompt确保了输出的内容直接可用于下一步的图表生成。

**Prompt中的关键变量：**
- `决策主题`：用户输入的核心问题。
- `选项A`：用户输入的第一个选择。
- `选项B`：用户输入的第二个选择。
- **隐含的格式要求**：`“请为 A/B 各输出一条短期结果与长期结果，每条 16 字以内。并给出一句总结建议。”` 这句话是Prompt的灵魂，它强制AI按行输出，为代码解析提供了便利。

**如果只改Prompt，不改代码，会发生什么？**
变化会非常直接：
- **改变输出内容**：例如，将Prompt中的“短期/长期”改为“风险/机遇”，AI就会生成关于风险和机遇的描述。
- **改变输出格式**：如果Prompt不再要求分行输出，或者增加了新条目（如“所需资源”），而代码还是按原来的行数去解析，图表就会显示错乱或缺失信息。
- **改变AI角色**：将`system`指令中的“你是决策顾问”改为“你是科幻作家”，AI就会以故事创作的口吻来生成分岔结局。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的AI工具：

**第一步：替换核心场景与输入（最安全）**
- **目标**：做一个功能相同但主题不同的工具。
- **操作**：
    1.  修改网页标题和描述（如改为“**故事分支生成器**”）。
    2.  将输入框的提示文字改掉（如“决策主题”改为“故事开头”，“选项A/B”改为“分支情节一/二”）。
    3.  修改生成按钮的文字（如“生成故事线”）。
- **此时，代码逻辑完全不用动，只是换了一层“皮”。**

**第二步：调整Prompt以匹配新场景**
- **目标**：让AI的输出符合你的新主题。
- **操作**：
    1.  在代码中找到 `const prompt = ` 开头的这一行。
    2.  修改引号内的指令。例如，针对故事生成，可以改为：“故事开头：${decision.value}\n分支一：${optionA.value}\n分支二：${optionB.value}\n\n请为每个分支构思一个意外转折和一个最终结局，每句20字以内。最后用一句话点明故事主题。”
- **这一步是关键，它决定了AI“思考”的方向。**

**第三步：改变输出形式**
- **目标**：让展示效果更贴合你的内容。
- **操作**：
    1.  找到 `const mermaidCode = ` 开头的这一行。这是生成图表的模板。
    2.  修改Mermaid语法中的节点标签。例如，将`[短期：...]`和`[长期：...]`改为`[转折：...]`和`[结局：...]`。
    3.  你还可以考虑更换右侧面板的标题（如“分岔图预览”改为“故事脉络图”）。
- **至此，一个全新的工具就诞生了。**

## 【六】3–5 个可直接尝试的改造方向

1.  **增加决策维度**：
    - **操作**：在输入区域增加一个下拉菜单，让用户选择决策类型，如“职业发展”、“情感关系”、“投资理财”。
    - **改造**：根据不同的类型，动态切换不同的`system`指令和Prompt模板。例如，选择“投资理财”时，Prompt可以要求AI分析“潜在回报”和“风险等级”。

2.  **支持多轮分支（嵌套决策）**：
    - **操作**：允许用户点击生成图中的某个“结果”节点，将其作为新的起点，继续添加选项，生成更深层的分支图。
    - **改造**：这需要重构数据结构和交互逻辑。每个节点需要被保存为一个对象，并记录其父节点和子节点。生成新分支时，Prompt需要包含上一级决策的上下文。

3.  **更换可视化引擎或样式**：
    - **操作**：用其他图表库（如ECharts、D3.js）替代Mermaid，或者直接自定义SVG/CSS来绘制分岔图。
    - **改造**：替换掉`renderMermaid`函数。新的函数需要接收AI解析后的数据，并调用新库的API或手动绘制出更美观、更动态的图表（如可交互的、带动画的流程图）。

4.  **本地缓存与历史记录**：
    - **操作**：在页面底部增加一个“历史记录”区域。
    - **改造**：每次成功生成后，将本次的输入（决策、选项）和输出的摘要保存到`localStorage`的一个数组里。在历史记录区域遍历这个数组并展示，点击任一记录可以重新加载当时的输入并渲染图表。

5.  **优化输出与分享**：
    - **操作**：增加“复制图表代码”、“导出为图片”、“生成分享链接”按钮。
    - **改造**：利用Mermaid或html2canvas库将SVG图表转换为PNG图片。生成分享链接时，可以将当前的输入参数编码到URL中，实现“打开即看”的效果。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合做专业决策分析**：它提供的分析基于大语言的通用知识，**不具备专业领域的深度洞察、实时数据或精确计算**。例如，你不能用它来决定“该买哪只股票”或“手术该选哪种方案”。
- **不适合处理复杂逻辑**：它严格限定为“一个起点，两个分支，各两个结果”的简单结构。对于包含多个并行条件、概率事件或循环依赖的复杂系统决策，它无法建模。
- **不适合替代人类判断**：AI的总结是基于模式生成的文字，可能包含偏见或过于笼统。它**只是一个帮助你拓宽思路、可视化可能性的工具，而非权威答案**。最终的决策责任永远在你自己。
- **如果需要上述功能**：你应该转向专业的决策分析软件（如决策树工具）、咨询专业人士，或使用具备更强专业数据接入和复杂逻辑处理能力的AI智能体平台。
