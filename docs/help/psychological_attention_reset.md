# 注意力重启仪式 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下：你正在工作或学习，突然感到思绪混乱、注意力涣散，盯着屏幕却什么都看不进去。这时你需要一个快速、简单的“重启”方式，让自己重新聚焦。

这个网页就是为此设计的“数字仪式”：
- **使用场景**：当你感到分心、拖延或思绪混乱时，花30秒进行呼吸调整，然后获得一个AI生成的、具体的下一步行动建议。
- **适合情况**：需要快速打断分心状态、重新建立专注节奏的场合。比如工作间隙、学习卡壳时。
- **不适合情况**：需要深度心理咨询、长时间专注训练，或者对AI建议有严格准确性要求的场景。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 你需要先配置自己的DeepSeek API Key（点击右上角齿轮图标）
- 然后点击“开始30秒”按钮

**用户通常会做哪几步操作？**
1. 首次使用时，点击右上角齿轮图标 → 输入你的DeepSeek API Key → 保存配置
2. 点击左侧的“开始30秒”按钮，跟随呼吸节奏（看着倒计时）
3. 30秒结束后，点击右侧的“生成下一步”按钮
4. 阅读AI给出的专注指令

**输出结果长什么样？**
- 左侧：一个会脉动的圆形计时器，从00:30倒计时到00:00
- 右侧：一段简短的文字指令，例如：“现在，请关闭所有无关的浏览器标签，只保留当前工作需要的那个。”

**有哪些容易忽略的使用细节？**
- API Key需要自己申请（DeepSeek官网），这是网页能调用AI的前提
- 计时器只是视觉辅助，真正的“仪式感”来自你配合呼吸的30秒专注
- 每次生成的指令都不同，可以多次点击“生成下一步”获取不同建议

## 【三】核心结构拆解（学习重点）

这个页面由三个关键模块组成：

**1. 呼吸计时模块（左侧）**
- **职责**：提供视觉焦点和计时功能，创造“仪式感”
- **逻辑**：点击按钮 → 启动30秒倒计时 → 显示脉动动画
- **设计亮点**：用CSS动画（pulse）模拟呼吸节奏，增强沉浸感

**2. AI指令生成模块（右侧）**
- **职责**：调用AI API，生成个性化专注指令
- **逻辑**：点击按钮 → 发送固定Prompt到AI → 接收并显示回复
- **设计亮点**：将复杂的AI调用封装成简单的“生成”按钮

**3. 配置管理模块（弹窗）**
- **职责**：安全存储用户的API配置
- **逻辑**：输入API Key → 保存到浏览器本地存储 → 后续调用时自动读取
- **设计亮点**：使用localStorage实现“一次配置，长期使用”

**输入 → 处理 → 输出 的逻辑链路：**
```
用户点击“开始30秒” → 计时器启动（视觉反馈）
用户点击“生成下一步” → 发送Prompt到AI API → 接收回复 → 显示指令
```

**最值得学习的设计：**
**“仪式感”的数字化表达**。这个网页没有复杂的交互，而是通过：
- 精心设计的视觉元素（脉动圆环、渐变背景）
- 明确的步骤划分（先呼吸，后获取指令）
- 恰到好处的等待时间（30秒不多不少）

创造了一个完整的“注意力重启”体验。这种**将心理过程转化为可视化交互**的思路，是值得学习的核心。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接用户状态和AI能力的“翻译器”。它告诉AI：“用户刚做完呼吸练习，现在需要一句具体的行动指令。”

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。AI不需要理解用户的复杂情绪，只需要基于“用户完成了30秒呼吸”这个上下文，生成一个合适的下一步建议。

**哪些信息是Prompt中的关键变量？**
当前Prompt是固定的：`“用户完成了 30 秒呼吸，请给出一句下一步专注指令。”`
关键变量是隐含的：
- 用户状态：刚完成呼吸练习
- 指令类型：下一步行动
- 格式要求：一句简短的指令

**如果只改Prompt，不改代码，会发生什么变化？**
- 改成`“用户感到焦虑，请给出一句安慰的话。”` → 网页变成“情绪安抚仪式”
- 改成`“用户需要创意灵感，请提出一个有趣的问题。”` → 网页变成“灵感激发器”
- 改成`“用户刚休息了5分钟，请建议一个简单的伸展动作。”` → 网页变成“健康提醒器”

**Prompt就是网页的“灵魂”**，改变它就能彻底改变网页的用途。

## 【五】如何模仿它，做出你自己的版本？

**安全的下手路径：**

**第一步：保持结构不变，替换使用场景**
- 最安全的起点：只改文字和Prompt
- 例如：改成“晨间启动仪式”，Prompt改为“用户刚醒来，请给出一句开启一天的建议”
- 计时器、按钮、布局全部保留，只是换了“皮肤”

**第二步：调整输入字段或Prompt**
- 增加一个下拉菜单，让用户选择当前状态（如：分心、疲惫、拖延）
- 根据选择动态修改Prompt：`“用户感到[状态]，请给出一句应对建议。”`
- 这是最小的功能扩展，风险很低

**第三步：改变输出形式或展示方式**
- 把文字指令改成“任务卡片”样式
- 或者增加“收藏”功能，让用户保存喜欢的指令
- 这一步开始涉及更多代码修改，但基础框架仍然可用

**关键建议**：先完整运行原版网页，确保你理解每个模块的作用，再开始修改。从改文字开始，逐步深入。

## 【六】3–5 个可直接尝试的改造方向

**1. 增加状态选择器（最简单）**
- 在“生成下一步”按钮上方添加单选按钮：
  - □ 感到分心  □ 缺乏动力  □ 思绪混乱
- 根据选择修改Prompt：`“用户感到[分心]，刚完成呼吸练习，请给出一句专注指令。”`
- **学习点**：如何将用户输入动态插入Prompt

**2. 替换AI服务（中等难度）**
- 保留现有界面，改用其他AI API（如OpenAI、智谱AI）
- 需要修改：API端点、请求格式、错误处理
- 可以做成可配置的：让用户在设置中选择使用哪个AI服务
- **学习点**：不同AI API的接口差异和适配

**3. 增加“指令库”功能（进阶）**
- 每次生成的指令，旁边显示“收藏”按钮
- 新增一个“我的收藏”页面，展示所有收藏的指令
- 使用localStorage或简单的后端存储
- **学习点**：数据持久化和多页面状态管理

**4. 优化呼吸引导体验（交互设计）**
- 计时器增加“吸气/呼气”文字提示
- 或者用图形动画（圆圈缩放）直观展示呼吸节奏
- 甚至可以增加背景音（轻柔的白噪音）
- **学习点**：如何用前端技术增强沉浸式体验

**5. 拆分成“练习”和“回顾”两个页面（架构调整）**
- 页面A：专注练习（当前页面）
- 页面B：历史记录（展示过去生成的指令、使用频率）
- 通过URL参数或localStorage传递数据
- **学习点**：单页应用 vs 多页应用的设计考量

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不适合作为专业的心理健康工具**
   - 这只是简单的注意力调整辅助
   - 如果有严重的注意力障碍或心理困扰，应寻求专业帮助

2. **不适合需要高度个性化建议的场景**
   - AI不了解你的具体工作内容、个人习惯
   - 生成的指令是通用型的，可能不完全适合你的具体情况

3. **不适合离线使用**
   - 依赖网络连接（调用AI API）
   - 依赖外部服务（DeepSeek API的可用性）

4. **不适合需要长期数据追踪的场景**
   - 没有用户账户系统
   - 数据只存储在本地浏览器，换设备就丢失

**如果用户想做X，应该换什么工具：**
- 如果想做**深度专注训练** → 使用Forest、番茄钟等专业时间管理App
- 如果想做**情绪管理** → 使用冥想App（如Headspace、潮汐）
- 如果想做**个性化习惯养成** → 使用Notion、滴答清单等可定制工具

---

**最后提醒**：这个网页的价值不在于技术复杂度，而在于**将一个简单的心理概念（注意力重启）转化为可交互的数字体验**。学习时，请多思考“为什么这样设计”，而不仅仅是“代码怎么写”。
