# 商务邮件写作助手 - 学习与使用指南

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页解决了一个非常具体的日常痛点：**快速、专业地撰写商务邮件**。

*   **使用场景**：想象一下，你需要在下午3点前给一个重要客户发一封合作邀请邮件，既要体现专业性，又要表达诚意。你对着空白文档，反复斟酌措辞，担心语气是否合适，结构是否清晰。这个工具就是你的“商务写作副驾”，帮你快速搭建邮件框架，填充专业内容，让你把精力集中在核心信息的构思上。
*   **适合情况**：
    *   需要撰写正式、规范的商务沟通邮件（如合作、汇报、申请、致谢等）。
    *   不确定针对不同对象（上级、客户、同事）该如何调整语气和措辞。
    *   希望快速生成一个邮件草稿，再进行个性化修改。
    *   想学习或模仿专业商务邮件的写作结构和语言风格。
*   **不适合情况**：
    *   需要撰写高度个性化、充满情感或创意性的个人邮件。
    *   处理涉及法律、财务等需要精确措辞和审核的正式文件。
    *   进行实时、多轮次的对话式沟通。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **邮件类型**：从12种预设模板（如“商务合作”、“工作汇报”）中选择一个。
    *   **收件人身份**：选择收件人是“上级领导”、“客户”还是“同事”等。
    *   **邮件主题/目的**：用一句话概括这封邮件的核心目的（必填）。
    *   **关键信息点**：列出邮件中必须包含的具体信息，比如时间、地点、数据等。
    *   **语气风格**：选择“正式专业”、“友好亲切”等不同口吻。
    *   **附加要求**：可以提出额外需求，如“更简洁一些”或“翻译成英文”。

2.  **用户通常会做哪几步操作？**
    1.  在左侧区域，从上到下依次选择或填写上述输入信息。
    2.  点击底部蓝色的 **“生成邮件”** 按钮。
    3.  等待几秒钟，在右侧的“邮件预览”区域查看AI生成的完整邮件正文。
    4.  如果对结果不满意，可以使用下方的“快捷操作”按钮（如“更简洁”、“重新生成”）进行微调，或复制/导出生成的邮件。

3.  **输出结果长什么样？**
    输出是一封格式完整、措辞得体的中文商务邮件正文。它会包含：
    *   符合身份的称呼（如“尊敬的[收件人]：”）
    *   清晰的开场白
    *   结构分明、重点突出的正文段落
    *   礼貌的结束语
    *   标准的落款（如“此致 敬礼”、你的名字和日期）
    邮件会直接显示在模拟的邮件客户端界面中，视觉效果很直观。

4.  **有哪些容易忽略的使用细节？**
    *   **首次使用需配置**：点击右上角的齿轮图标⚙️，输入你的DeepSeek API Key，否则无法生成邮件。
    *   **“关键信息点”是灵魂**：这里填写得越具体、越有条理（建议分点列出），生成的邮件内容就越准确、越丰富。
    *   **“快捷操作”是迭代工具**：生成第一版邮件后，不要急着重填所有内容，试试“更正式”、“更友好”等按钮，它会在原有基础上快速优化。
    *   **可以查看“思考过程”**：如果选择了“R1 深度”模型，生成后可以展开“深度思考过程”，看看AI是如何一步步构思这封邮件的，这对学习写作逻辑很有帮助。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“配置-生成-输出”** 模块化设计：

1.  **控制面板模块（左侧）**
    *   **职责**：收集用户的所有创作意图和约束条件。它把复杂的写作要求，拆解成一个个简单的选择题和填空题。
    *   **组成**：类型选择卡、收件人身份按钮组、主题输入框、关键信息文本框、语气风格按钮组、附加要求输入框。
    *   **设计亮点**：**将抽象写作要求“表单化”**。它没有让用户直接写Prompt，而是通过精心设计的UI组件引导用户输入，降低了使用门槛，确保了输入信息的结构化。

2.  **AI引擎与逻辑处理模块（代码中不可见，但最关键）**
    *   **职责**：将左侧收集的“表单数据”，转换、拼接成一个AI能理解的完整“指令”（Prompt），然后调用AI API，并处理返回的流式数据。
    *   **输入→处理→输出链路**：
        *   **输入**：用户在各表单字段的选择和输入。
        *   **处理**：`buildSystemPrompt()` 和 `buildUserMessage()` 函数工作，将表单数据填充到预设的Prompt模板中，生成最终的对话消息。
        *   **输出**：调用DeepSeek API，并将返回的文本流实时显示到预览区。

3.  **结果展示与交互模块（右侧）**
    *   **职责**：实时展示AI生成的内容，并提供后续操作入口。
    *   **组成**：邮件预览面板（模拟邮件客户端）、思考过程折叠面板、快捷操作按钮组。
    *   **设计亮点**：**“预览-微调”一体化**。不仅展示结果，还提供了围绕当前结果进行“二次加工”（如改写、翻译）的快捷入口，形成了一个流畅的工作闭环。

**最值得学习的设计**：
**“表单驱动”的Prompt构建模式**。整个页面的精髓在于，它通过友好的UI界面，把非结构化的、需要技巧的Prompt编写工作，变成了结构化的、无需学习成本的信息填写。这使得不懂AI原理的用户也能高效利用大模型能力。这种“界面层封装Prompt复杂性”的思想，是设计AI应用界面的核心。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色**：它是连接**用户意图**和**AI能力**的“翻译官”和“任务书”。在这个页面中，Prompt被拆成了两部分：
    *   **系统提示词**：定义AI的“角色”（商务邮件专家）和“写作规范”（结构、语言、格式等）。它决定了AI输出的“基调和质量”。
    *   **用户消息**：携带本次任务的具体“情报”（邮件类型、收件人、主题等）。它决定了AI输出的“具体内容”。

2.  **解决的是“生成问题”**：它主要解决的是“根据明确的约束条件，生成符合规范的新内容”的问题，而不是“理解复杂模糊的人类指令”的问题。

3.  **Prompt中的关键变量**：这些变量直接来自用户的表单输入：
    *   `{emailType}`（邮件类型）、`{recipient}`（收件人身份）、`{subject}`（邮件主题）、`{keyPoints}`（关键信息）、`{tone}`（语气风格）、`{extra}`（附加要求）。
    这些变量被像填空一样插入到预设的Prompt模板中，形成最终的指令。

4.  **如果只改Prompt，不改代码，会发生什么？**
    你可以彻底改变这个工具的功能性质。例如：
    *   将系统提示词改为“你是一位小红书爆款文案写手”，用户消息模板改为“请写一篇关于{产品}的种草笔记，要求{风格}，突出{卖点}”，那么这个工具就瞬间变成了“小红书文案生成器”。
    *   代码（UI）完全不用动，但工具的核心能力完全被Prompt重新定义了。这体现了 **“Prompt即功能”** 的AI应用设计理念。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，逐步打造自己的AI小工具：

**第一步：保持结构不变，替换使用场景（最安全）**
*   **目标**：先跑通一个属于你自己的最小可行产品。
*   **操作**：
    1.  复制整个HTML文件。
    2.  修改标题，如将“商务邮件写作助手”改为“周报生成助手”。
    3.  修改左侧的“邮件类型”卡片，换成“工作类型”（如“技术开发”、“市场运营”、“产品销售”）。
    4.  修改“收件人身份”选项，换成“汇报对象”（如“直属领导”、“部门总监”、“跨部门同事”）。
    5.  修改其他输入项的标签和提示文字，使其符合“周报”场景（如“关键信息点”改为“本周重点工作与成果”）。
    6.  此时，UI已经变成了一个周报生成器，但功能还是写邮件。

**第二步：调整输入字段或Prompt（核心改造）**
*   **目标**：让功能匹配新的场景。
*   **操作**：
    1.  找到代码中的 `buildSystemPrompt()` 和 `buildUserMessage()` 函数。
    2.  仔细阅读默认的Prompt文本，理解其结构。
    3.  将其中关于“邮件”的描述全部重写为关于“周报”的描述。例如，把“邮件结构清晰，包含恰当的称呼、开场白、正文、结束语和落款”改为“周报结构清晰，包含工作概述、详细成果、遇到的问题、下周计划等部分”。
    4.  在 `buildUserMessage()` 中，调整提示语句式，使其更符合索要周报的语境。
    5.  现在，你的工具已经能生成周报了！

**第三步：改变输出形式或展示方式（体验优化）**
*   **目标**：让结果展示更贴合新场景。
*   **操作**：
    1.  修改右侧“邮件预览”的标题和样式，可以改成“周报预览”。
    2.  调整“快捷操作”按钮，将“更正式”等改为“更数据化”、“更突出重点”等符合周报优化的选项。
    3.  （可选）调整颜色主题，让界面风格更匹配你的工具调性。

**从哪里下手最安全？**
从 **【第一步】** 开始最安全。因为你只修改了静态文字和选项，没有动任何逻辑代码。即使改错了，也很容易对照原版恢复。这一步能让你立刻获得一个外观全新的工具，建立信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“示例参考”输入**：
    *   **操作**：在输入区域增加一个“参考邮件/文本”的文本框。
    *   **效果**：用户可以将一封自己觉得写得很好的邮件贴进去，在Prompt中指示AI“参考以下文本的风格和结构进行创作”。这能实现“模仿特定风格”的个性化生成。

2.  **切换为本地模型或其它API**：
    *   **操作**：修改 `streamChat` 函数中的API地址和请求头。例如，将DeepSeek的端点换成OpenAI的（`https://api.openai.com/v1/chat/completions`），并相应调整 `model` 参数（如`gpt-4o-mini`）。
    *   **效果**：可以对比不同模型（如Claude、GPT、GLM）在相同任务下的输出效果和成本差异。

3.  **拆分为“创建”与“管理”两个页面**：
    *   **操作**：新建一个 `history.html` 页面。在当前页生成邮件后，增加“保存草稿”按钮，将结果（输入参数+输出内容）存入 `localStorage` 或 `IndexedDB`。在历史页面读取并展示这些草稿列表，支持再次编辑或调用。
    *   **效果**：工具从一个一次性生成器，升级为具有简单内容管理功能的写作工作台。

4.  **优化交互：增加“输入联想”或“参数推荐”**：
    *   **操作**：监听“邮件主题”输入框，当用户输入如“项目延期”时，在下方用小字提示：“推荐语气风格：`礼貌谦和`；推荐关键信息点：`延期原因、新的时间节点、补救措施`”。
    *   **效果**：进一步降低用户思考成本，引导用户输入更有效的信息，从而得到质量更高的输出。

5.  **增加“多版本对比”功能**：
    *   **操作**：生成邮件后，将结果暂存。当用户点击“更简洁”或“重新生成”时，将新生成的结果与旧版本并排展示（如左右分栏），让用户可以直观对比差异，选择最满意的一版。
    *   **效果**：将AI的“生成能力”转化为帮助用户决策的“对比能力”，提升结果的可控性和满意度。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合生成具有法律效力的文件**：它生成的邮件是“草稿”和“参考”，其内容的准确性、合规性最终需要由人类专业人士审核。不能直接用于合同、协议、官方声明等法律文书。
2.  **不适合完全替代人类写作与沟通**：商务沟通的精髓在于真情实感和具体情境的把握。AI无法理解你与收件人之间微妙的过往关系、公司内部特定的文化用语。它提供的是“标准件”，而真正打动人心的往往是“定制件”中的个人色彩。
3.  **不适合处理极度模糊或创新的需求**：如果你只有一个模糊的想法（如“写点能让投资人兴奋的东西”），而没有具体的“主题”、“关键信息”，这个工具将难以给出有价值的输出。它擅长在**既定框架内优化**，而非**从零开始创造框架**。
4.  **如果用户想做X，应该换什么工具或方式**：
    *   **想写小说、诗歌等创意文本**：应使用专门针对创意写作优化的工具，或直接使用ChatGPT等通用聊天界面进行多轮、启发式的对话和构思。
    *   **想进行代码编程或数据分析**：应使用GitHub Copilot、Cursor或ChatGPT的代码解释器等专门为开发者设计的工具。
    *   **想深度分析一份长文档**：应使用具备“长上下文上传”和“文档QA”功能的应用，如Kimi Chat、ChatGPT File Upload等，而不是这个格式生成工具。
