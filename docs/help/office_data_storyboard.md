# 数据故事板 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你手头有一份简单的数据表格（比如网站访问量、月度销售额），你想快速了解它的趋势，并得到一些通俗易懂的分析结论。但你不熟悉专业的数据分析工具，或者觉得用Excel做图表、写分析太麻烦。

这个网页就是为你准备的。你只需要把数据粘贴进去，它就能自动生成一张趋势图，并用AI帮你解读数据中的关键信息，比如“最近一周访问量上升了20%”、“周三通常是高峰日，建议提前准备服务器资源”。

**适合场景：**
- 快速分析小规模、结构简单的数据（如周报、月报数据）
- 需要快速获得数据洞察，但不想写复杂分析报告
- 向非技术人员展示数据时，需要一个“一句话总结”

**不适合场景：**
- 处理大规模、复杂的数据集（如百万行数据）
- 需要深度统计建模、预测分析
- 数据清洗、合并等预处理工作

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本输入框，里面预填了示例数据（日期和访问量）
- 你需要把CSV格式的数据粘贴进去（例如从Excel复制出来的表格）

**用户通常会做哪几步操作？**
1.  **准备数据**：在Excel或类似工具中，把你的数据整理成两列（比如“日期”和“数值”），然后复制。
2.  **粘贴数据**：清空或覆盖输入框里的示例数据，粘贴你自己的数据。
3.  **配置API**：点击右上角的齿轮图标，输入你的DeepSeek API Key（这是调用AI功能必需的），然后保存。
4.  **生成故事板**：点击“生成故事板”按钮。

**输出结果长什么样？**
- **左侧**：会立即生成一张折线图，直观展示你数据的变化趋势。
- **右侧**：会出现一段AI生成的文字解读，通常包括趋势描述、可能的异常点，以及一条简单的建议。

**有哪些容易忽略的使用细节？**
- **数据格式必须正确**：第一行必须是标题行（如“日期,销量”），下面每行是具体数据，用逗号分隔。这是CSV的标准格式。
- **API Key是必需的**：不配置API Key，图表能生成，但右侧的AI解读会报错。
- **数据量不宜过大**：这个工具适合几十到几百行的数据，数据太多可能导致响应变慢或API调用失败。

## 【三】核心结构拆解（学习重点）

这个页面由三个清晰的功能模块组成：

1.  **数据输入与图表模块（左侧卡片）**
    - **职责**：接收用户输入的原始数据，进行解析和验证，并负责将数据可视化（绘制图表）。
    - **逻辑链路**：`用户粘贴CSV文本` → `PapaParse库解析为结构化数据` → `提取标签和数值` → `Chart.js库绘制折线图`。

2.  **AI解读模块（右侧卡片）**
    - **职责**：基于生成的数据，构造一个问题（Prompt）发送给AI模型，并将返回的解读结果展示给用户。
    - **逻辑链路**：`从解析后的数据中提取关键字段和数值` → `组装成特定的Prompt文本` → `通过API调用AI模型` → `接收并显示AI的回复`。

3.  **配置管理模块（设置弹窗）**
    - **职责**：管理应用的外部依赖配置（主要是API密钥和模型选择），并利用浏览器的本地存储功能记住用户的设置。
    - **逻辑链路**：`用户打开设置弹窗并输入信息` → `点击保存` → `信息被存入浏览器的localStorage` → `下次打开页面时自动读取`。

**最值得学习的设计：**
**“输入-处理-展示”的清晰分离与异步协作**。整个流程是：用户触发 → 同步处理数据并绘图 → **异步**调用AI → 分别更新界面。这种设计让图表能立刻响应，而需要等待网络的AI解读稍后出现，用户体验更流畅。这是构建现代AI应用的一个经典模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

- **Prompt扮演的角色**：它是连接“原始数据”和“人类可读洞察”的**翻译官**。它告诉AI：“这里有一些数据，请用你的知识，以数据分析师的口吻，帮我总结一下。”
- **解决的是“生成问题”**：它解决的不是理解用户意图（意图已经很明确：分析数据），而是如何根据数据**生成**一段简洁、有洞察力的文本。
- **Prompt中的关键变量**：
    1.  **数据字段名** (`${valueKey}`)：告诉AI你在分析什么（如“访问量”、“销售额”）。
    2.  **具体数值** (`${values.join(', ')}`)：提供分析的原材料。
    3.  **指令** (“总结趋势、异常和 1 条建议，控制在 100 字以内”)：明确限定AI的输出格式、内容和长度。
- **如果只改Prompt，不改代码**：
    - 你可以彻底改变AI输出的风格和内容。例如，把指令改成“用幽默的段子总结数据变化”，那么AI的解读就会变得风趣搞笑。
    - 你可以改变分析维度。例如，增加“与行业平均水平比较”，AI就会尝试在回复中加入对比（尽管它可能需要更多上下文）。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的工具：

**第一步：替换核心场景与数据**
这是最安全、改动最小的起点。保持整个页面结构、图表和AI调用逻辑完全不变。
- **做什么**：把“数据故事板”这个标题和描述，改成你的场景，比如“健身进度追踪器”、“个人收支分析仪”。
- **怎么做**：修改HTML中`<title>`、`<h1>`和`<p>`标签里的文字。同时，把输入框里的示例数据换成你新场景的示例（如“日期,体重\n2024-05-01,65\n2024-05-02,64.5”）。

**第二步：调整输入与Prompt**
开始定制逻辑，让AI为你的新场景服务。
- **做什么**：修改Prompt指令，让它更适合你的新领域。
- **怎么做**：找到`buildStory`函数里构造`prompt`变量的那行代码。把“请总结趋势、异常和 1 条建议...”这部分指令，改成符合你场景的要求。例如，对于健身数据，可以改成“请总结体重变化趋势，分析可能的原因（如饮食、运动），并给出一条鼓励或改进建议。”

**第三步：改变输出形式**
进行更深度的定制，改变信息的呈现方式。
- **做什么**：将折线图换成其他类型的图表，或者在AI解读部分增加更多结构化展示。
- **怎么做**：学习Chart.js文档，将`type: 'line'` 改为 `'bar'`（柱状图）或`'pie'`（饼图），看哪种更适合你的数据。你还可以在AI解读的卡片下方，增加一个“关键指标”区域，用数字卡片突出显示最大值、最小值等。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加数据列选择器**：目前工具自动选择第一列做标签、第二列做数值。可以增加两个下拉菜单，让用户自己选择哪一列作为X轴（标签），哪一列作为Y轴（数值），从而支持多列数据。
2.  **支持多种图表类型**：在“生成故事板”按钮旁边增加一个下拉菜单，让用户可以选择“折线图”、“柱状图”或“饼图”。只需动态修改Chart.js的`type`配置即可。
3.  **更换或增加AI模型**：在设置弹窗中，除了DeepSeek，可以增加OpenAI GPT、Claude等模型的选项。你需要修改`callLLM`函数，根据选择调用不同的API端点和参数。
4.  **优化交互体验**：为“生成故事板”按钮添加加载状态动画（比如一个旋转的图标），让用户明确知道AI正在工作。也可以在AI解读生成后，增加一个“复制解读”按钮，方便用户分享。
5.  **拆分为多步骤向导**：将当前的单页拆解成“上传数据” → “预览图表” → “生成解读”三个步骤页面。这能让流程更清晰，尤其适合更复杂的数据处理场景。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合做精确的、生产级的商业分析**：它使用的AI模型可能会“臆测”或产生不准确的分析，且没有提供置信度或引用来源。对于重要决策，应使用专业的BI工具（如Tableau, Power BI）并结合人工判断。
- **不适合处理敏感或隐私数据**：你的数据会被发送到第三方AI服务商（如DeepSeek）的服务器进行处理。**切勿**粘贴包含个人身份信息、商业秘密或其他敏感数据的内容。
- **不适合自动化或集成到工作流**：这是一个手动操作的网页工具。如果你需要每天自动分析来自数据库的报告，应该学习使用Python（如pandas, matplotlib库）或专门的API来构建自动化脚本。
- **不适合复杂的数据清洗**：如果您的CSV数据格式混乱、有缺失值、或需要复杂的转换（如数据透视），这个工具无法处理。你需要先用Excel、Google Sheets或Python进行数据预处理。
