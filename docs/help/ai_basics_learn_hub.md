# AI 内容创作工坊 - 学习中心帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你正在学习 AI 内容创作，手头有很多教程文档（Markdown 格式），分散在不同的文件夹里。每次想学习时，你都需要：
- 在文件管理器中翻找
- 用不同的软件打开文档
- 手动滚动查看内容
- 无法快速跳转到特定章节

这个网页将这些分散的文档**整合成一个美观、易用的在线学习平台**。它适合：
- **个人学习**：将你的学习笔记整理成系统化课程
- **团队培训**：为团队成员提供统一的学习资料库
- **知识分享**：将技术文档转化为友好的阅读体验

**不适合**：
- 需要实时协作编辑文档（如 Google Docs）
- 需要复杂的搜索功能（如全文检索）
- 需要用户登录和进度跟踪

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 左侧导航栏显示所有可学习的章节
- 每个章节对应一个外部的 Markdown 文件

**用户通常会做哪几步操作？**
1. 打开页面，系统自动加载第一个章节
2. 在左侧导航栏点击想学习的章节标题
3. 阅读中间区域显示的文档内容
4. 使用右侧大纲快速跳转到文档内的特定小节
5. 点击顶部“返回首页”回到主页面

**输出结果长什么样？**
- 中间区域：美观排版的文档，包含标题、段落、列表、代码块（带语法高亮）、引用块等
- 右侧区域：当前文档的章节导航（仅显示 h2 和 h3 标题）
- 左侧区域：所有可用文档的分类列表

**容易忽略的使用细节：**
1. **右侧大纲只在宽屏显示**：在手机或小屏幕上，大纲会隐藏
2. **点击大纲项会平滑滚动**：点击右侧大纲中的标题，页面会自动滚动到对应位置
3. **代码块可复制**：代码区域有语法高亮，方便阅读
4. **URL 不会改变**：切换章节时，浏览器地址栏不会更新，无法直接分享特定章节链接

## 【三】核心结构拆解（学习重点）

这个页面由 **4 个关键模块**组成：

### 1. 导航管理模块（左侧）
- **职责**：展示所有可用文档，按分组分类
- **输入**：从外部 JS 文件加载的文档列表数据
- **处理**：将文档按 `group` 字段分组显示
- **输出**：可点击的章节列表，当前选中项高亮显示

### 2. 内容渲染模块（中间）
- **职责**：获取、解析并显示 Markdown 文档
- **输入**：用户点击的文档路径（`.md` 文件）
- **处理**：
  - 使用 `fetch` 获取 Markdown 原始文本
  - 用 `marked.js` 将 Markdown 转为 HTML
  - 用 `highlight.js` 为代码块添加语法高亮
- **输出**：美观排版的 HTML 内容

### 3. 大纲提取模块（右侧）
- **职责**：自动从文档中提取标题生成导航
- **输入**：Markdown 原始文本
- **处理**：用正则表达式匹配 `##` 和 `###` 标题
- **输出**：层级化的标题列表，点击可跳转

### 4. 状态管理模块（全局）
- **职责**：管理加载状态、错误处理和当前文档
- **输入**：用户操作和网络响应
- **处理**：控制 loading 动画、错误提示显示
- **输出**：协调各模块的显示状态

**最值得学习的设计：**
**“数据与视图分离”** 架构。文档列表（`learnDocs`）来自外部 JS 文件，文档内容来自外部 `.md` 文件。这意味着：
- 你可以轻松添加新文档，只需更新数据文件
- 内容维护和界面开发完全分离
- 适合内容经常更新的学习平台

## 【四】Prompt / AI 逻辑是如何被设计的？

> 注意：这个页面本身**没有使用 AI 或 Prompt**，它是一个静态内容展示平台。但理解这个设计对学习 AI 应用很重要。

**如果这是 AI 应用，Prompt 会扮演什么角色？**
假设我们要改造它，让 AI 为每个章节生成练习题，那么：
- **Prompt 解决的是“生成问题”**：根据文档内容生成相关题目
- **关键变量**：文档标题、文档内容、题目类型、难度级别
- **如果只改 Prompt**：生成的题目质量、类型、数量会变化，但页面布局不变

**当前页面的“类 Prompt”设计：**
文档的 `group` 字段就像是一个简单的“分类指令”，告诉系统如何组织内容。这种**用数据驱动界面**的思路，正是设计 AI 应用时需要掌握的。

## 【五】如何模仿它，做出你自己的版本？

### 安全模仿路径（从易到难）：

**第一步：保持结构不变，替换使用场景**
- 将“AI 内容创作”改为你的主题（如“Python 编程”、“摄影教程”）
- 修改 `learn_data.js` 中的文档列表，指向你的 Markdown 文件
- 调整颜色主题（修改 CSS 中的颜色值）

**第二步：调整数据结构和显示方式**
- 在文档数据中添加新字段（如 `author`、`duration`、`difficulty`）
- 在左侧导航中显示这些额外信息
- 添加按难度或时长筛选的功能

**第三步：改变内容处理逻辑**
- 支持更多文件格式（如 `.txt`、`.html`）
- 添加图片懒加载优化
- 实现搜索功能（用 `localStorage` 做简单搜索）

**从哪里下手最安全？**
从 **`learn_data.js` 文件**开始！这是整个应用的数据源头，修改它：
1. 不会破坏页面功能
2. 能立即看到效果
3. 帮助你理解数据如何驱动界面

## 【六】3–5 个可直接尝试的改造方向

### 1. 增加学习进度跟踪
```javascript
// 在 localStorage 中记录已读章节
localStorage.setItem(`read_${doc.id}`, Date.now());

// 在左侧导航中显示“已读”标记
<a :class="['nav-item', isRead(doc.id) ? 'text-green-600' : '']">
  {{ doc.title }}
  <span v-if="isRead(doc.id)">✓</span>
</a>
```

### 2. 添加笔记功能
- 在每个章节下方添加“添加笔记”文本框
- 将笔记保存到 `localStorage`，键名为 `note_${doc.id}`
- 在页面侧边或底部显示所有笔记摘要

### 3. 实现离线访问
- 使用 Service Worker 缓存文档内容
- 添加“下载所有文档”按钮
- 网络断开时显示离线提示，但仍可阅读已缓存内容

### 4. 增强大纲功能
- 支持更多标题级别（h4, h5）
- 添加大纲折叠/展开功能
- 在大纲中显示当前阅读位置（滚动高亮）

### 5. 添加社交分享
- 为每个章节生成可分享的 URL（使用 `#` 或查询参数）
- 添加“复制链接”按钮
- 集成社交媒体分享按钮（Twitter、微信等）

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性：
1. **不适合大型文档库**：所有文档需要手动维护在 `learn_data.js` 中，超过 50 篇会变得难以管理
2. **没有搜索功能**：无法通过关键词查找内容
3. **没有用户系统**：无法区分不同用户的学习进度
4. **内容只能静态展示**：无法在页面内编辑文档

### 如果用户想做 X，应该换什么工具：

**如果想做多人协作的文档库**：
- 使用 **Notion** 或 **Confluence**
- 或自建 **Wiki 系统**（如 MediaWiki）

**如果想做带视频的学习平台**：
- 使用 **Moodle**、**Canvas** 等 LMS（学习管理系统）
- 或使用 **YouTube 播放列表** + 配套文档

**如果想做智能推荐学习路径**：
- 需要后端服务器记录用户行为
- 使用推荐算法（协同过滤、内容推荐）
- 考虑使用 **AI 学习助手**（如 ChatGPT 插件）
