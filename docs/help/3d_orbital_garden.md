# 轨道花园 · Orbital Garden 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页是一个**情绪与想法的可视化工具**。当你有一些抽象的感受、目标或状态（比如“我想找到更平衡的生活节奏”、“最近感到有些迷茫”）时，它可以将这些文字描述，通过 AI 的理解，转化为一个动态、立体的 3D 轨道花园。每一层轨道、每一个旋转的星球，都代表着 AI 对你输入内容的一种“视觉翻译”。

**适合在什么情况下使用？**
- **个人反思与冥想**：当你需要将内心的想法或情绪外化，获得一个具象的视觉锚点时。
- **创意激发**：设计师、艺术家或任何创意工作者，想为某个主题或概念寻找一种非语言的视觉表现形式。
- **演示与沟通**：在分享一个抽象概念时，提供一个动态、美观的视觉辅助，帮助他人感受其“节奏”和“层次”。

**不适合什么情况？**
- 如果你需要精确的、基于物理定律的科学模拟（如真实太阳系）。
- 如果你需要生成具体的、可编辑的 3D 模型文件。
- 如果你希望 AI 进行复杂的逻辑推理或提供长篇文字解答。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   页面中央偏右下方有一个输入框，你可以在这里输入任何一句话，描述你的心情、目标或一个抽象概念。

2.  **用户通常会做哪几步操作？**
    *   **第一步：配置 API**（首次使用）。点击右上角的“DeepSeek 设置”按钮，在弹出的窗口中填入你的 DeepSeek API Key 并选择模型，然后点击“保存”。
    *   **第二步：输入想法**。在输入框中写下你的话，例如“宁静的午后”或“对未来的期待与不安”。
    *   **第三步：生成花园**。点击“生成轨道花园”按钮。
    *   **第四步：观察与互动**。等待几秒钟，一个根据你输入内容生成的 3D 轨道花园就会出现。你可以用鼠标拖拽旋转视角，滚轮缩放，从不同角度观察。

3.  **输出结果长什么样？**
    *   一个在深邃星空中缓缓旋转的多层轨道系统，每层轨道颜色、半径、旋转速度都不同，上面有发光的“星球”沿轨道运行。
    *   轨道中心可能有一个柔和的光晕。
    *   右下角的面板会显示一段 AI 生成的、对这次生成的“花园”的文字总结。

4.  **有哪些容易忽略的使用细节？**
    *   **鼠标控制**：左键拖拽旋转视角，右键拖拽平移，滚轮缩放。这是与 3D 场景交互的核心。
    *   **API 设置**：如果不配置 API Key，每次生成都只会得到同一个“默认花园”，无法体验 AI 根据输入定制的效果。
    *   **状态提示**：按钮下方的状态文字和右下角的总结框，是了解当前生成状态和 AI 理解结果的关键，不要只看 3D 画面。
    *   **输入框回车**：目前按回车键不会触发生成，必须点击按钮。

## 【三】核心结构拆解（学习重点）

这个页面由三个清晰独立的模块协同工作：

1.  **3D 可视化引擎模块**
    *   **职责**：负责创建和渲染整个星空、轨道、星球的 3D 场景，并处理用户与场景的交互（旋转、缩放）。
    *   **关键组件**：`THREE.Scene`（场景容器）、`THREE.Camera`（摄像机）、`THREE.WebGLRenderer`（渲染器）、`OrbitControls`（鼠标控制）。
    *   **输入**：一组描述花园的 JSON 数据（颜色、半径、速度等）。
    *   **处理**：根据 JSON 数据，用 Three.js 创建对应的 3D 物体（圆环、球体），并将它们添加到场景中。
    *   **输出**：在网页 `<canvas>` 画布上实时渲染出动态的 3D 图像。

2.  **用户交互与配置模块**
    *   **职责**：提供输入界面、保存用户设置、管理生成流程的UI状态（如按钮禁用、加载动画）。
    *   **关键组件**：右下角的控制面板（`.panel`）、右上角的设置按钮和弹窗（`.modal`）。
    *   **输入**：用户的文字输入、API Key 和模型选择。
    *   **处理**：将用户输入组装成 Prompt，触发 AI 调用；将配置保存到浏览器的本地存储（`localStorage`）。
    *   **输出**：更新 UI 状态，并将最终得到的 JSON 数据传递给 3D 引擎模块。

3.  **AI 桥梁模块**
    *   **职责**：连接用户输入和 3D 参数。它不直接生成图像，而是将自然语言“翻译”成机器可读的视觉参数。
    *   **关键组件**：`buildPrompt` 函数和 `callDeepSeek` 函数。
    *   **输入**：用户的一句话。
    *   **处理**：将用户输入嵌入到一个精心设计的 Prompt 中，调用 DeepSeek API，并从 AI 的回复中提取出结构化的 JSON 数据。
    *   **输出**：一个包含 `summary`、`palette`、`radii` 等字段的 JSON 对象。

**最值得学习的设计：**
**“Prompt 作为数据生成器”的范式**。这个网页没有让 AI 去画图或写复杂的 3D 代码，而是让它输出一个极简的、程序完全能预测的 JSON 数据结构。3D 引擎则像一台精密的打印机，忠实地将这个 JSON “蓝图”渲染出来。这种将**不可控的 AI 创意**约束在**完全可控的程序结构**内的思路，是稳定实现“AI+可视化”应用的关键。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt 扮演的角色**：它是一个**“结构化数据生成指令”**。它的核心任务是引导 AI 将一段自由文本，映射到一组预先定义好的、有限的视觉参数上。

2.  **解决的是“理解问题”还是“生成问题”？** 主要是**“理解问题”**。AI 需要理解用户输入语句的情感、节奏、层次感，但它的“生成”任务被严格限定为：按照指定格式（JSON）和字段（如 `palette`、`speeds`）来填充数据。

3.  **Prompt 中的关键变量**：
    *   **用户输入（`${input}`）**：这是唯一的变量，是创意的源头。
    *   **输出格式指令**：“只返回 JSON。” 这句话至关重要，它强制 AI 输出纯净的数据，避免多余解释。
    *   **字段描述**：对每个 JSON 字段（如 `palette(3色)`、`halo(0-1)`）的简短说明，设定了数据的范围和类型。

4.  **如果只改 Prompt，不改代码，会发生什么？**
    *   你可以改变 AI 的“创作风格”。例如，将 Prompt 中的“空间艺术与情绪可视化助手”改为“极简主义建筑可视化引擎”，AI 生成的色彩、轨道数量可能更冷静、规整。
    *   你可以扩展或修改 JSON 字段。例如，在 Prompt 里增加一个 `backgroundMusic` 字段让 AI 推荐一首歌，但如果不修改代码去读取和播放这个字段，那么它只会被显示在 `summaryBox` 里，不会有实际作用。
    *   **核心原则**：Prompt 的修改必须与后端代码（这里指 JavaScript 中处理 JSON 的部分）的期望保持一致，否则会导致解析失败。

## 【五】如何模仿它，做出你自己的版本？

这是一个安全的“三步替换法”，你可以逐步深入：

*   **第一步：替换核心概念与视觉主题（最安全）**
    *   **做什么**：保持所有代码结构不变，只做“文本替换”。
    *   **如何做**：
        1.  修改网页标题和描述（如改为“情绪山脉 · Emotion Mountain”）。
        2.  修改 Prompt 中的描述（如将“轨道花园 JSON”改为“分层山脉 JSON”，将“轨道”、“星球”等词替换为“山脊”、“山峰”）。
        3.  修改 `createGarden` 函数的名字和内部的 3D 物体创建逻辑。例如，把 `TorusGeometry`（圆环）换成 `ConeGeometry`（圆锥体）来制作山，把星球换成树木或云朵的模型。
        4.  调整配色方案（CSS 和默认 JSON 中的颜色）。

*   **第二步：调整输入与输出数据结构**
    *   **做什么**：改变用户输入的方式或 AI 需要生成的参数。
    *   **如何做**：
        1.  增加多个输入框，例如“主情绪”和“次要情绪”。
        2.  修改 Prompt，让 AI 根据多个输入生成数据。
        3.  在 `defaultData` 和 `createGarden` 函数中，增加或删除对应的 JSON 字段（比如增加 `treeDensity` 树木密度参数）。

*   **第三步：改变 AI 模型或输出形式**
    *   **做什么**：更换大脑或改变最终呈现。
    *   **如何做**：
        1.  在设置弹窗中增加其他 AI 模型（如 GPT、Claude）的选项，并修改 `callDeepSeek` 函数中的 API 端点。
        2.  将 3D 输出改为 2D 动态 SVG 或 Canvas 绘画，使用如 p5.js 或 D3.js 库，这可以大大降低学习门槛。

**从哪里下手最安全？**
从 **第一步** 开始。先不要动任何与 API 调用和 JSON 解析相关的代码。集中精力修改 `createGarden` 函数里的 3D 图形和 CSS 样式，先做出一个属于你的、静态的“默认版本”。这能帮你彻底理解“数据如何驱动视觉”。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“情绪强度”滑块**：在输入框旁增加一个范围从 0 到 10 的滑块，代表情绪的强烈程度。将这个值也传入 Prompt（如“情绪强度为 ${intensity}”），并让 `createGarden` 函数利用这个值来调整轨道的数量、星球的旋转速度或光晕的亮度。
2.  **本地化模型替换**：尝试使用本地运行的轻量级 AI 模型（如通过 Ollama 部署的 Llama 3.2）。修改 `callDeepSeek` 函数，指向本地 API 地址（如 `http://localhost:11434/api/generate`），并调整请求格式以匹配新模型。这可以免除 API Key 的依赖和费用。
3.  **多页面故事线**：将单页面应用扩展成一个小型旅程。
    *   **页面1**：输入情绪，生成花园。
    *   **页面2**：展示花园，并允许用户“收藏”或为花园命名。
    *   **页面3**：一个画廊，展示所有收藏的花园，形成你的“情绪宇宙史”。
4.  **优化交互体验**：
    *   **音效**：根据轨道速度生成相应的环境音效（如空灵的哼鸣），速度越快，音调越高。可以使用 Web Audio API。
    *   **点击交互**：允许用户点击某个“星球”，在侧边栏显示 AI 针对这个星球所代表“层次”的更多文字解读（需要扩展 Prompt 让 AI 为每个轨道生成描述）。
    *   **预设模板**：提供几个按钮，如“宁静”、“活力”、“沉思”，点击后自动填充经典 Prompt 并生成，给用户一个起点。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合生成精确的科学可视化**：它的轨道和星球是艺术化的表达，并非遵循物理规律。如果你需要模拟真实的太阳系、星系或引力效应，应使用专门的科学计算库（如 Universe Sandbox 的算法）或天体物理模拟软件。
*   **不适合作为通用的 3D 建模工具**：你无法通过它导出 `.obj` 或 `.gltf` 模型文件，也无法对生成的花园进行顶点级别的精细编辑（如调整星球形状）。这类需求应使用 Blender、Three.js Editor 或专业的参数化建模工具。
*   **不适合处理复杂逻辑或事实查询**：虽然接入了 AI，但它的整个设计闭环是“情绪/概念 → 视觉参数”。如果你问它“如何修复我的自行车？”，它可能会生成一个“由扳手和齿轮组成的混乱轨道花园”，而不会给出实际步骤。对于知识问答，应使用标准的聊天机器人界面。
*   **不适合无网络环境下的 AI 生成**：核心的“理解与翻译”功能依赖云端 AI API。若需离线使用，必须按改造方向2所述，部署本地模型。

希望这份文档能帮助你不仅使用这个工具，更能理解其设计精髓，并最终创造出独一无二的、属于你自己的“想法可视化器”。
