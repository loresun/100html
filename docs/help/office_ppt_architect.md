# PPT 架构与演讲稿生成器 - 帮助与学习指南

## 【一】这个网页解决了什么问题？

**使用场景：**
当你需要准备一个正式的汇报、演讲或路演，但面对空白的PPT文档不知从何下手时，这个工具能帮你快速搭建起一个**逻辑清晰、结构完整**的PPT大纲。它特别适合：
- **职场新人**需要向领导汇报项目进展
- **创业者**准备融资路演材料
- **市场人员**策划产品发布会演讲
- **教师/培训师**设计课程内容框架

**适合情况：**
- 需要快速产出PPT初稿框架
- 希望获得专业的逻辑结构建议
- 需要配套的演讲提示和视觉设计思路
- 准备将大纲导入专业PPT工具（如Gamma、Slidev）

**不适合情况：**
- 需要直接生成可编辑的PPTX文件
- 对视觉设计有高度定制化需求
- 汇报内容涉及高度机密或专业领域知识
- 需要实时协作编辑

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **汇报主题与核心目标**：在左侧大文本框中描述你要汇报的内容
2. **演讲场合**：选择汇报的性质（内部/外部/路演/分享）
3. **幻灯片页数**：选择期望的PPT长度
4. **逻辑框架**：选择喜欢的思维模型（可选）

**用户通常会做哪几步操作？**
1. 在“汇报主题”框中详细描述你的汇报内容
2. 根据实际情况选择“演讲场合”和“页数”
3. （可选）选择一个逻辑框架，或让AI自动匹配
4. 点击“🚀 生成 PPT 架构”按钮
5. 等待10-30秒，右侧会显示完整的PPT架构
6. 可以点击“复制 Markdown”将内容导出到其他工具

**输出结果长什么样？**
右侧会显示一系列“PPT卡片”，每张卡片代表一页幻灯片，包含：
- 醒目的幻灯片标题
- 3-5个核心要点（项目符号列表）
- “视觉建议”：这页PPT应该用什么图表、图片或排版
- “演讲稿提示”：讲这页时应该说什么话

**有哪些容易忽略的使用细节？**
1. **主题描述越详细越好**：不要只写“季度汇报”，要写“第三季度销售数据分析，重点说明华东区增长40%的原因”
2. **先配置API密钥**：第一次使用需要点击右上角设置图标，输入DeepSeek API密钥
3. **可以选择不同模型**：右上角可以切换“快”模型和“强逻辑”模型
4. **复制功能很实用**：生成的Markdown可以直接粘贴到Gamma.app等工具中快速生成真实PPT

## 【三】核心结构拆解（学习重点）

**页面由哪几个关键模块组成？**
1. **配置输入模块**（左侧）
   - 主题输入区：收集用户的核心需求
   - 参数选择区：场合、页数、逻辑框架
   - 生成按钮：触发AI处理

2. **AI处理引擎**（不可见但核心）
   - Prompt构建器：将用户输入转化为AI指令
   - API调用器：与DeepSeek API通信
   - 数据解析器：解析AI返回的JSON

3. **结果展示模块**（右侧）
   - PPT卡片列表：每页幻灯片的可视化预览
   - 思考过程展示：仅在使用R1模型时显示AI的推理
   - 导出功能：复制为Markdown格式

**每个模块承担什么职责？**
- **输入模块**：收集和标准化用户需求
- **AI引擎**：将需求转化为结构化内容
- **展示模块**：将结构化内容可视化呈现

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入主题 → 结合参数构建Prompt → 发送给AI → 
AI返回JSON → 解析JSON → 渲染为PPT卡片 → 用户查看/导出
```

**哪一部分是“这个网页最值得学习的设计”？**
**Prompt的精心设计**是最值得学习的部分。它：
1. 定义了严格的输出格式（JSON数组）
2. 包含了所有用户选择的参数（场合、页数、框架）
3. 给出了具体的内容要求（标题要有吸引力、要有干货）
4. 规定了AI的角色（顶级战略咨询顾问）

这种“结构化Prompt”设计确保了AI输出的一致性，避免了每次生成结果格式不统一的问题。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt是**翻译官**和**项目经理**的结合体：
- 将用户模糊的需求翻译成AI能理解的具体任务
- 管理AI的输出格式和质量标准

**它解决的是“理解问题”还是“生成问题”？**
主要解决**生成问题**。用户已经知道自己要做什么（做PPT），但不知道怎么做。Prompt告诉AI：
- 生成什么（PPT架构）
- 按什么标准生成（专业、逻辑严密）
- 输出成什么格式（JSON）

**哪些信息是 Prompt 中的关键变量？**
1. `activeFramework.value`：逻辑框架选择
2. `context.value`：演讲场合
3. `slideCount.value`：页数要求
4. `topic.value`：用户输入的主题

**如果只改 Prompt，不改代码，会发生什么变化？**
- 改输出格式：比如让AI输出XML而不是JSON
- 改内容风格：比如从“商务风”改为“学术风”
- 改详细程度：要求生成更简略或更详细的内容
- 改角色设定：让AI扮演“幽默的演讲者”而不是“严肃的顾问”

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景**
- 将“PPT生成”改为“文章大纲生成”
- 将“演讲场合”改为“文章类型”（博客/论文/报告）
- 将“逻辑框架”改为“文章结构”（总分总/并列/递进）
- 保持相同的三模块布局：输入 → AI处理 → 输出展示

**第二步：调整输入字段或 Prompt**
- 增加“目标读者”选择框（初学者/专家/管理层）
- 增加“文章长度”选择（短篇/中篇/长篇）
- 修改Prompt中的角色：“你是一位资深编辑，帮助用户规划文章结构”
- 修改输出格式要求：从PPT卡片改为文章章节

**第三步：改变输出形式或展示方式**
- 将卡片式展示改为大纲树状图
- 增加“一键生成草稿”功能（让AI根据大纲写段落）
- 添加“保存模板”功能，让用户复用成功的大纲

**从哪里下手是最安全的？**
从**修改Prompt文本**开始最安全。你可以在不改变任何代码的情况下：
1. 复制整个HTML文件
2. 只修改`systemPrompt`变量的内容
3. 测试不同的Prompt效果
这样即使改错了，也不会破坏页面功能。

## 【六】3–5 个可直接尝试的改造方向

**1. 增加“参考案例”输入**
- 在输入区增加一个文本框：“请参考以下案例的风格”
- 用户可以粘贴一个优秀的PPT链接或描述
- 在Prompt中加入：“请参考用户提供的案例风格进行设计”
- **效果**：让生成结果更符合用户的审美偏好

**2. 换成多模型支持**
- 除了DeepSeek，增加OpenAI、Claude、智谱等API选项
- 在设置中让用户配置多个API密钥
- 生成时让用户选择“用哪个模型”
- **效果**：对比不同模型的输出质量，找到最适合PPT生成的模型

**3. 拆分为“快速版”和“专家版”**
- **快速版**：保持现有简单界面，一键生成
- **专家版**：新页面，增加更多选项：
  - 品牌色系选择
  - 字体偏好
  - 禁用词汇（不想出现的词）
  - 重点强调部分
- **效果**：满足不同用户群体的需求

**4. 增加“实时预览”功能**
- 用户输入主题时，右侧实时显示AI思考过程
- 每输入一段，AI就给出初步建议
- 最终生成时基于这些实时反馈优化
- **效果**：交互更自然，用户感觉AI在“协同创作”

**5. 集成到PPT工具中**
- 开发浏览器插件，在Google Slides或PPT网页版中增加侧边栏
- 用户在当前PPT中选中文字，点击插件生成后续页面建议
- **效果**：从“独立工具”变为“生产力套件的一部分”

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**
1. **不生成实际PPT文件**：它只提供架构和思路，你需要用其他工具（Gamma、Canva、PowerPoint）制作最终PPT
2. **不处理机密信息**：所有内容都会发送到第三方AI API，不要输入公司机密、个人隐私等敏感信息
3. **不替代深度思考**：对于非常重要的汇报（如IPO路演），AI生成的框架只能作为参考，核心逻辑仍需自己把控
4. **不保证100%准确**：AI可能误解你的需求，或给出不合适的建议，需要人工审核和调整

**如果用户想做 X，应该换什么工具：**
- **想做精美视觉设计** → 使用Canva、Gamma.app的AI设计功能
- **需要团队协作编辑** → 使用Google Slides、腾讯文档
- **涉及复杂数据图表** → 使用Excel+PPT的组合，或专业BI工具
- **制作动画丰富的PPT** → 使用Focusky、Prezi等专业工具

---

**最后提醒**：这个工具的价值在于“快速启动”和“提供专业视角”。把它当作你的“虚拟咨询顾问”，而不是“全自动PPT工厂”。最好的使用方式是：AI生成初稿 → 你基于自己的专业知识调整 → 最终形成真正属于你的精彩汇报。
