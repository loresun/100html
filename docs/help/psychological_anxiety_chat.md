# 焦虑解压对话机器人 - 学习指南

你好！这份文档将帮助你理解这个“焦虑解压对话机器人”网页是如何工作的，更重要的是，**你将学会如何制作一个属于自己的版本**。我们不会逐行解释代码，而是聚焦于它的设计思路和可复用的模式。

---

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你或你的朋友在深夜感到焦虑、压力大，想找人聊聊，但又不想打扰别人，或者希望得到一些专业的心理支持。这个网页就像一个随时在线的、温和的倾听者和引导者。它不是一个真正的心理医生，但它能提供即时、非评判性的情感回应，并引导你进行一些简单的情绪调节练习（如呼吸法）。

*   **适合在什么情况下使用？**
    *   感到轻度到中度焦虑、压力，需要倾诉和情绪梳理。
    *   想学习一些基础的认知行为疗法（CBT）技巧来应对负面思维。
    *   在情绪激动时，需要一个引导来帮助自己平静下来（如SOS模式）。
    *   作为日常情绪记录和自我反思的工具。

*   **不适合什么情况？**
    *   **紧急心理危机**：如果用户有严重的自杀、自伤念头或精神疾病发作，网页会建议拨打专业热线，但它**无法**提供真正的危机干预。
    *   **替代专业治疗**：它不能诊断或治疗心理疾病，不能替代心理咨询师或精神科医生。
    *   **深度、复杂的个人问题**：对于需要长期、系统干预的复杂心理创伤，它的帮助有限。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **你的感受**：在页面底部的文本框中，输入任何你想说的话。
    *   **你的选择**：页面顶部的下拉菜单，让你选择对话模式（CBT疗法、纯倾听、紧急SOS）。

2.  **用户通常会做哪几步操作？**
    1.  **首次使用**：点击右上角的设置按钮，填入你的DeepSeek API Key（这是让AI说话的关键）。
    2.  **选择模式**：根据你当下的心情，从顶部选择一个模式。比如，想分析想法选“CBT”，只想被倾听选“纯倾听”，感觉快崩溃了选“SOS”。
    3.  **开始对话**：在下方输入框写下你的焦虑，点击“发送”或按`Enter`键。
    4.  **获得回应**：AI会以你选择的角色（治疗师、倾听者等）回复你。对话会像聊天软件一样滚动。
    5.  **使用附加功能**：可以下载对话记录、清空对话，或在SOS模式下启动“呼吸练习”动画。

3.  **输出结果长什么样？**
    *   **对话流**：你和AI的对话以彩色气泡的形式交替出现，你的在右边（蓝色），AI的在左边（浅蓝色）。
    *   **AI回复内容**：会根据你选择的模式而变化。CBT模式会分析你的思维，倾听模式主要是共情和肯定，SOS模式会给出具体的放松指令。
    *   **附加输出**：可以下载一个格式工整的Markdown文件，包含完整的对话记录、时间和模式信息。

4.  **有哪些容易忽略的使用细节？**
    *   **Shift+Enter换行**：在输入框里，直接按`Enter`是发送，想换行需要按`Shift+Enter`。
    *   **模式切换会清空对话**：切换顶部模式时，会询问你是否清空当前对话，因为不同模式的AI角色设定不同，混在一起会混乱。
    *   **对话自动保存**：即使你关闭浏览器，下次打开时，上次的对话记录还在（除非你手动清空）。
    *   **可以修改AI的“人设”**：在设置中，你可以直接编辑给AI的“系统提示词”，这相当于改变了AI的“大脑”和说话方式，而不需要改代码。

## 【三】核心结构拆解（学习重点）

这个页面由几个清晰的模块组成，像搭积木一样：

1.  **控制面板模块（顶部导航栏）**
    *   **职责**：让用户控制整个对话的“基调”和“引擎”。
    *   **包含**：模式选择器（CBT/倾听/SOS）、AI模型切换器（V3快速/R1深度）、设置入口。
    *   **逻辑**：用户选择模式 → 页面下方的说明卡片和AI的“人设”（系统提示词）随之改变。

2.  **信息展示模块（中部对话区）**
    *   **职责**：清晰地呈现对话历史和当前状态。
    *   **包含**：模式说明卡片、消息气泡列表、AI“正在输入”的动画。
    *   **逻辑**：用户发送消息 → 消息添加到列表并显示 → 触发AI思考（显示打字动画）→ AI回复流式显示并添加到列表。**“流式显示”**（AI回复一个字一个字出现）是这个模块最值得学习的交互设计，它极大地提升了对话的实时感和自然度。

3.  **用户交互模块（底部输入区）**
    *   **职责**：接收用户输入，并提供对话管理功能。
    *   **包含**：文本输入框、发送按钮、下载记录和清空对话的按钮。
    *   **逻辑**：用户输入文本并发送 → 触发`sendMessage`函数。

4.  **功能弹窗模块（呼吸练习、设置）**
    *   **职责**：在不干扰主流程的情况下，提供扩展功能。
    *   **包含**：呼吸练习动画弹窗、API和提示词配置弹窗。
    *   **逻辑**：点击特定按钮（如“呼吸练习”、“设置”）→ 显示对应弹窗。弹窗独立于主对话逻辑。

**最值得学习的设计：**
**“模式-提示词”解耦设计**。网页的核心功能（对话）和核心逻辑（AI如何回应）被清晰地分开了。前端只负责：
*   收集用户输入和模式选择。
*   将对应的“系统提示词”和对话历史一起发给AI API。
*   将AI的回复展示出来。
这意味着，**如果你想改变AI的行为，90%的情况下只需要修改“系统提示词”文本，而完全不用动前端代码**。这种设计让迭代和定制变得极其简单。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt 在这个页面中扮演什么角色？**
    Prompt（系统提示词）在这里扮演了 **“AI角色定义卡”** 和 **“对话脚本大纲”** 的角色。它决定了AI在对话中是“认知行为治疗师”、“温暖倾听者”还是“危机干预专家”。

2.  **它解决的是“理解问题”还是“生成问题”？**
    主要是解决 **“生成问题”** 。它不负责理解用户输入的复杂语义（这部分由基础AI模型完成），而是**指导AI如何基于理解去生成符合特定风格、策略和伦理的回复**。例如，在SOS模式的Prompt中，明确指令AI“优先稳定情绪，再处理深层问题”。

3.  **哪些信息是 Prompt 中的关键变量？**
    *   **角色身份**：如“专业的认知行为治疗（CBT）咨询师”。
    *   **核心策略**：如“苏格拉底式提问”、“情感验证”、“快速干预策略”。
    *   **语言风格**：如“温暖、非评判、鼓励性”、“简短、清晰、具体的指令”。
    *   **禁忌与边界**：如“避免直接否定用户的感受”、“如果用户提到自杀...立即建议拨打危机热线”。
    *   **结构化步骤**：如“1. 倾听与验证 2. 识别认知扭曲...”。

4.  **如果只改 Prompt，不改代码，会发生什么变化？**
    整个对话的体验将彻底改变。例如：
    *   把CBT的Prompt换成法律顾问的Prompt，AI就会开始用法律条款分析你的问题。
    *   在倾听模式的Prompt里加入“每次回复必须包含一个哲学名言”，AI的回复风格就会立刻改变。
    *   修改SOS模式中的紧急热线号码，AI建议的资源就会更新。
    **这证明了前端界面是“壳”，Prompt才是决定应用功能的“魂”。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个安全的路径，一步步创造出全新的应用：

**第一步：保持结构不变，替换使用场景（最安全）**
*   **目标**：先跑通一个属于你自己的主题。
*   **操作**：
    1.  复制整个HTML文件。
    2.  修改标题、颜色主题（修改`<style>`标签中的`.calm-gradient`等颜色值）。
    3.  **最关键**：想一个新的垂直领域（例如：“职业规划导师”、“创意写作伙伴”、“健身饮食教练”）。
    4.  将顶部的三个模式（CBT/倾听/SOS）替换成你新领域下的三种风格（例如：对于“写作伙伴”，可以是“头脑风暴模式”、“语法润色模式”、“灵感激发模式”）。

**第二步：调整输入字段或 Prompt（核心改造）**
*   **目标**：让AI真正为你设定的领域服务。
*   **操作**：
    1.  在设置弹窗中，重命名三个Prompt的标题（如“头脑风暴模式提示词”）。
    2.  **完全重写** `DEFAULT_PROMPTS` 对象里的三个提示词。参考原版的结构（角色、策略、风格、禁忌），为你新的领域撰写。这是创造力的核心。
    3.  （可选）如果新领域需要更多用户输入，可以在输入框上方增加简单的选择器（例如，“文章类型：博客/邮件/小说”），并将这个选择作为变量插入到Prompt中。

**第三步：改变输出形式或展示方式（进阶优化）**
*   **目标**：让体验更贴合你的场景。
*   **操作**：
    1.  修改“呼吸练习”弹窗，将其变为你场景下的工具（如“写作伙伴”场景下，可以改为“随机词汇生成器”或“情节冲突构思器”）。
    2.  调整对话气泡的样式，使其符合新主题（如科技感、文艺感）。
    3.  修改“下载记录”功能，让生成的Markdown文件格式更符合你的需求（例如，为“健身教练”生成一份训练日志总结）。

**从哪里下手最安全？**
**从第二步的“重写Prompt”开始。** 因为这是零代码、零风险的操作，却能立刻看到翻天覆地的效果。先别管界面，专注于用文字描述你希望AI扮演的角色，这是本项目最精髓、最可迁移的部分。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加结构化输入，让Prompt更精准**
    *   **操作**：在输入框上方添加几个“情绪标签”按钮（如😰 焦虑、😠 愤怒、😔 沮丧）。用户可以在发送前点选。在发送消息时，将这个标签作为用户消息的一部分（例如“[情绪标签：焦虑] 我明天要汇报...”）或将其插入到系统Prompt的上下文里。这样AI能更精准地回应用户情绪。

2.  **更换或扩展AI模型后端**
    *   **操作**：在设置弹窗的“AI模型”下拉菜单中，增加其他API选项（如OpenAI的GPT-4o、Claude 3.5）。只需修改`sendMessage`函数中的API端点（`https://api.deepseek.com/v1/chat/completions`）和请求头格式，使其适配新API。这让你可以对比不同模型在你特定场景下的表现。

3.  **将单页应用拆分为引导页和对话页**
    *   **操作**：创建一个新的`index.html`作为引导页，用简单的图文介绍三种模式的区别。用户点击某个模式后，再跳转到当前的对话页面（可命名为`chat.html`），并通过URL参数（如`?mode=cbt`）自动设置初始模式。这提升了产品的专业感和用户引导。

4.  **优化交互体验：增加快捷建议回复**
    *   **操作**：当AI回复后，在它的气泡下方显示2-3个灰色的快捷短语按钮（例如，针对“我感到很焦虑”的回复，可以显示“能举个例子吗？”、“这种感受出现多久了？”）。用户点击按钮，相当于自动输入了该内容并发送。这能降低用户的输入负担，引导对话深入。

5.  **引入简单的“记忆”或总结功能**
    *   **操作**：在侧边栏或对话顶部，增加一个“本次对话要点”的折叠区域。每隔5-10轮对话，或者当用户点击“总结”按钮时，前端将对话历史发送给AI（用一个单独的、简短的总结性Prompt），请求生成一段摘要（例如“用户主要担忧：1... 2... 已讨论的应对策略：...”）并显示出来。这有助于用户回顾和反思。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做专业的医疗或心理诊断工具**
    *   **局限性**：AI的回应基于模式识别和统计概率，不具备人类的临床判断力和责任感。它可能无法识别复杂的心理疾病症状，也可能在极端情况下给出不恰当的建议。
    *   **正确做法**：所有涉及严重身心健康的问题，都必须转向合格的医生、心理咨询师等专业人士。本网页的SOS模式中提示拨打热线，正是明确了这一边界。

*   **不适合处理需要高度保密和安全的敏感信息**
    *   **局限性**：对话记录保存在浏览器的本地存储（LocalStorage）中，相对安全但并非绝对加密。且API调用会将对话内容发送到第三方服务器（如DeepSeek）。
    *   **正确做法**：如果涉及极度个人隐私或商业机密，应使用具备端到端加密的专用安全通讯工具，或部署在自有可控的服务器环境。

*   **不适合进行需要长期状态跟踪和个性化调整的任务**
    *   **局限性**：它的“记忆”仅限于单次浏览器会话内的对话历史，没有跨会话的用户档案、进度跟踪或个性化学习能力。
    *   **正确做法**：需要长期跟踪（如健身计划、学习课程管理）的应用，应该设计后端数据库来存储用户档案和历史数据，并基于此提供个性化的演进式反馈。

**总结**：这个网页是一个出色的**前端交互设计**与**大语言模型提示工程**相结合的范例。它教会我们，一个有用的AI应用不一定需要复杂的后端，其核心往往在于清晰的场景定义、巧妙的Prompt设计以及人性化的交互。现在，拿起你感兴趣的领域，从修改Prompt开始，创造你的第一个AI对话应用吧！
