# 九宫格创意工具 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你面对一个模糊的创意主题（比如“提升线上课程完课率”），需要快速、系统地产生多个具体行动方向时，这个工具能帮你把一个大问题拆解成九个可执行的视角。它特别适合在**头脑风暴初期**、**方案规划会议前**或**个人灵感枯竭时**使用，能帮你跳出线性思维，看到问题的不同侧面。

**适合情况**：
- 需要为某个主题（产品、活动、问题）寻找多个创新切入点
- 希望将抽象想法转化为具体、可操作的行动点
- 需要结构化地整理零散的创意

**不适合情况**：
- 需要深度、专业的行业分析报告
- 已经确定了具体执行方案，只需要细节优化
- 需要实时协作或多人同时编辑

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **选择模式**：决定思考方向（拓展新机会/优化现有方案/突破痛点问题）
2. **主题/产品**：填写你要分析的核心问题或对象
3. **补充信息**：（可选）提供背景、限制条件或已有想法

**用户通常会做哪几步操作？**
1. 在左侧面板选择模式、填写主题
2. 点击“生成九宫格”按钮
3. 等待几秒钟，查看右侧生成的九宫格矩阵
4. 如果满意，可以点击“导出为图片”保存结果

**输出结果长什么样？**
- **核心部分**：3×3的九宫格，每个格子包含：
  - **标题**：一个具体的创意角度（如“游戏化学习路径”）
  - **说明**：该角度的简要解释
  - **行动**：一个可立即尝试的具体建议
- **附加部分**：底部的“策略摘要”，用段落形式总结整体思路

**容易忽略的使用细节：**
1. **API设置**：第一次使用前需要点击右上角“API设置”配置你的AI API密钥
2. **模式选择**：不同的模式会引导AI朝不同方向思考，显著影响输出结果
3. **补充信息**：虽然可选，但填写后能让结果更贴合你的实际情况
4. **导出功能**：生成结果后，可以导出为高清图片用于分享或打印

## 【三】核心结构拆解（学习重点）

**页面由四个关键模块组成：**

1. **控制面板模块**（左侧）
   - **职责**：收集用户输入、触发生成过程
   - 包含：模式选择器、主题输入框、补充信息框、生成按钮
   - **设计亮点**：将复杂的创意需求简化为三个核心输入项

2. **展示模块**（右侧）
   - **职责**：可视化呈现AI生成的结果
   - 包含：九宫格网格（3×3）、策略摘要区域、原始数据展示
   - **设计亮点**：用卡片式布局清晰展示“标题-说明-行动”三层信息

3. **AI引擎模块**（隐藏在代码中）
   - **职责**：将用户输入转化为结构化的创意矩阵
   - 包含：Prompt构建、API调用、JSON解析
   - **设计亮点**：通过严格的JSON格式要求，确保AI输出可被程序化处理

4. **配置模块**（弹出窗口）
   - **职责**：管理API连接设置
   - 包含：模型选择、API密钥输入、配置保存
   - **设计亮点**：支持多个AI服务商，增强了工具的灵活性

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入 → 构建Prompt → 调用AI API → 解析JSON → 渲染九宫格
（模式+主题）   （系统+用户指令）   （DeepSeek/OpenAI） （提取9个项目） （卡片布局+摘要）
```

**最值得学习的设计：**
**“约束性Prompt”设计**——通过给AI明确的输出格式要求（必须返回包含9个项目的JSON），将原本开放、不可控的创意生成，变成了结构化、可预测的数据流。这是将AI从“聊天伙伴”变成“生产工具”的关键转变。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色：**
Prompt是**创意框架的翻译官**。它把用户简单的“模式+主题”输入，翻译成AI能理解的、带有明确格式要求的复杂指令。

**它解决的是“生成问题”还是“理解问题”？**
主要是**生成问题**。AI已经理解“创意分析”这个任务，Prompt的重点是：
1. **约束输出格式**：必须返回JSON，必须有9个项目
2. **提供思考方向**：根据模式选择给出不同的提示词
3. **结构化信息**：要求每个项目包含“标题-说明-行动”三个字段

**Prompt中的关键变量：**
1. `GRID_HINTS[mode]`：根据模式变化的提示语
2. `主题：${this.topic}`：用户输入的核心问题
3. `补充信息：${this.context}`：额外的背景信息
4. **JSON模板**：明确要求输出的数据结构

**如果只改Prompt，不改代码，会发生什么变化？**
- 改`GRID_HINTS` → 改变AI的思考方向（如从“创意”变成“风险评估”）
- 改JSON结构 → 改变输出数据的字段（如增加“预算估算”字段）
- 改系统提示 → 改变AI的角色设定（如从“创意分析师”变成“营销专家”）
- 改温度参数 → 改变输出的创意性和稳定性

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改页面标题和说明文字
- 示例：把“九宫格创意”改成“产品功能脑暴”，把“创意”相关词汇换成“功能”
- 风险：几乎为零，只是文字替换

**第二步：调整输入字段或Prompt**
- 中等改动：增加/减少输入项，修改Prompt提示词
- 示例：增加“目标用户画像”输入框，在Prompt中加入“请从00后用户角度思考”
- 风险：较低，需要测试AI是否能理解新指令

**第三步：改变输出形式或展示方式**
- 较大改动：修改九宫格布局或增加新的展示模块
- 示例：把3×3网格改成4×2的“八大方向”，增加“优先级评分”字段
- 风险：中等，需要同时调整Prompt和前端渲染逻辑

**最安全的下手点：**
从**修改`GRID_HINTS`对象**开始。这是纯文本修改，不需要动代码结构，但能立即看到效果变化。比如把三个模式改成：
- `discover` → “请输出市场调研的九个维度”
- `plan` → “请输出项目计划的九个关键环节”
- `review` → “请输出复盘分析的九个检查点”

## 【六】3–5个可直接尝试的改造方向

**1. 增加“创意风格”选择器**
- **具体操作**：在模式选择下方增加下拉菜单，选项如：“颠覆式创新”、“渐进式改进”、“跨界融合”
- **实现方式**：在Prompt中追加“请以[风格]的风格进行思考”
- **效果**：让创意生成更有针对性，适合不同场景需求

**2. 改为“可编辑九宫格”**
- **具体操作**：生成后允许用户直接点击卡片修改内容
- **实现方式**：将`x-text`改为可编辑元素，添加保存按钮
- **效果**：从“一次性生成”变成“协作编辑工具”，实用性大幅提升

**3. 支持多轮对话优化**
- **具体操作**：在结果下方添加“优化这个方向”、“合并相似项”等按钮
- **实现方式**：将当前结果作为上下文，发送新的优化请求
- **效果**：实现“生成-反馈-优化”的完整工作流

**4. 增加“灵感库”功能**
- **具体操作**：将历史生成结果保存到本地，可随时查看复用
- **实现方式**：使用`localStorage`存储数组，添加历史记录面板
- **效果**：积累个人或团队的创意资产，避免重复劳动

**5. 拆分为“快速版”和“深度版”**
- **具体操作**：增加一个开关，选择简单生成（3×3）或深度分析（带详细论证）
- **实现方式**：准备两套Prompt，深度版要求AI提供更多细节和案例
- **效果**：适应不同深度的需求，从快速脑暴到方案撰写都能覆盖

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不适合做专业市场分析**
   - 这个工具生成的是“创意角度”，不是“市场数据”
   - 如果你需要竞品分析、市场规模、用户调研数据，应该使用专业分析工具或咨询行业报告

2. **不适合替代人类创意会议**
   - AI提供的是发散性思路，缺乏人类的情境理解、经验判断和情感共鸣
   - 重要决策仍需团队讨论，AI结果应作为“讨论素材”而非“最终方案”

3. **不适合高度专业化领域**
   - 对于法律、医疗、金融等需要严格专业知识验证的领域，AI生成的“行动建议”可能存在风险
   - 在这些领域使用时，必须由专业人士审核和修正

4. **不适合实时动态调整**
   - 这是一个“生成-查看”的单向工具，不能根据外部变化（如市场动态）实时调整输出
   - 如果需要动态仪表板，应该使用专门的BI工具

**如果用户想做X，应该换什么工具：**
- 想做**详细方案撰写** → 使用Notion/语雀等文档工具+AI辅助写作
- 想做**团队实时协作** → 使用Miro/Mural等在线白板工具
- 想做**数据驱动决策** → 使用专业数据分析平台（如Tableau、Power BI）
- 想做**项目管理** → 使用Trello、Asana、飞书项目等项目管理工具

---

**最后提醒**：这个工具的价值不在于“替代思考”，而在于“激发思考”。最好的使用方式是：生成九宫格 → 打印出来 → 和团队一起讨论哪些可行、哪些需要调整、哪些能组合成更大的创意。把它当作思考的“跳板”，而不是思考的“终点”。
