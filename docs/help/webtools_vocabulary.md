# 艾宾浩斯单词本 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象你正在学习英语，遇到了很多新单词。你可能会用笔记本记下来，但很快就忘了。这个网页就像一个**智能单词卡片盒**，它不仅能帮你记录单词，还能根据“艾宾浩斯遗忘曲线”自动安排复习时间。当你记不住时，它会让你多复习几次；当你记得牢时，它会延长复习间隔，帮你用最少的时间记住最多的单词。

**适合什么情况：**
- 需要长期记忆外语单词、专业术语、概念定义的学习者
- 希望有系统复习计划，但不想手动安排时间的人
- 想要一个干净、专注的数字化单词本

**不适合什么情况：**
- 只需要临时查词、一次性记忆（用词典App更合适）
- 需要发音、视频等多媒体辅助的学习（这个网页只有文字）
- 完全离线环境（需要网络来使用AI生成功能）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **单词信息**：单词本身、中文释义、例句（可选）
2. **AI生成参数**：主题（如“商务英语”）、难度、数量
3. **复习反馈**：对每个单词选择“忘记”“模糊”“记得”

**用户通常会做哪几步操作？**
1. **添加单词**：点击“添加单词”标签，手动输入；或点击“AI生成”，让AI帮你批量创建
2. **开始复习**：切换到“学习模式”，页面会显示今天需要复习的单词卡片
3. **翻转卡片**：点击卡片查看释义
4. **选择记忆程度**：根据记忆情况点击三个按钮之一
5. **管理词库**：在“单词列表”中搜索、删除单词

**输出结果长什么样？**
- **学习模式**：一张精美的单词卡片，正面是单词，背面是释义和例句
- **单词列表**：按添加时间倒序排列的所有单词，显示复习阶段和下次复习时间
- **AI生成结果**：一组可勾选添加的单词预览列表

**容易忽略的使用细节：**
1. **右上角的设置按钮**：AI功能需要先配置API Key才能使用
2. **导入/导出功能**：可以将词库备份为JSON文件，或从其他来源导入
3. **复习队列**：右上角显示“待复习”数量，点击学习模式才会开始
4. **卡片翻转**：需要先点击卡片看到释义，才能选择记忆程度

## 【三】核心结构拆解（学习重点）

这个网页由**5个核心模块**组成：

### 模块1：导航与状态栏（顶部）
- **职责**：切换功能模式、显示全局状态、提供工具入口
- **包含**：标签导航、待复习计数、设置/导入/导出按钮
- **设计亮点**：用标签清晰划分功能，状态栏始终可见

### 模块2：学习模式（核心）
- **职责**：按计划展示复习卡片、收集记忆反馈
- **输入**：当前需要复习的单词队列
- **处理**：卡片翻转动画、三档记忆评分（忘记/模糊/记得）
- **输出**：更新单词的下次复习时间，推进到下一个单词
- **最值得学习的设计**：**艾宾浩斯算法实现** - 根据评分动态调整复习间隔，并加入随机扰动防止形成固定模式

### 模块3：单词管理（添加/列表）
- **添加子模块**：简单的表单收集单词信息
- **列表子模块**：搜索、排序、删除功能
- **职责**：词库的增删改查
- **数据流**：所有操作实时保存到`localStorage`

### 模块4：AI生成模块
- **职责**：调用AI API批量生成相关单词
- **输入**：主题、难度、数量
- **处理**：构造Prompt → 调用API → 解析JSON响应
- **输出**：可预览和选择的单词列表
- **关键设计**：**结果预览与批量选择** - 生成后先让用户确认，避免盲目添加

### 模块5：数据持久化层
- **职责**：在浏览器本地保存所有数据
- **包含**：单词库、API配置
- **技术点**：使用`localStorage`，监听数据变化自动保存

**逻辑链路：**
```
用户输入单词 → 存入words数组 → 根据nextReview时间筛选
→ 学习模式展示 → 用户评分 → 更新stage和nextReview
→ 循环直到今日复习完成
```

**最值得学习的设计：**
**状态驱动的UI更新** - 整个应用围绕`words`数组和`tab`状态构建，状态变化自动驱动界面更新。这是现代前端框架（如Vue、React）的核心思想，这里用Alpine.js轻量实现。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色：**
它是一个**结构化数据生成器**。用户给出模糊需求（“商务英语、中级、10个”），Prompt将其转化为AI能理解的精确指令，并约束输出格式。

**解决的是“生成问题”还是“理解问题”？**
主要是**生成问题**，但也包含理解：AI需要理解“商务英语中级”应该生成哪些单词，但核心任务是生成结构化的数据。

**Prompt中的关键变量：**
```javascript
`请生成 ${this.ai.count} 个关于"${this.ai.topic}"主题的英语单词，难度为${this.ai.level}。
请严格仅返回一个 JSON 数组，格式如下：
[
    {"term": "单词", "definition": "中文释义", "example": "英文例句"}
]
不要包含 markdown 格式标记，只返回纯 JSON 字符串。`
```
- `count`、`topic`、`level`：用户输入的变量
- **格式约束**：明确要求JSON数组和字段名
- **格式清理指令**：特别强调不要markdown包装

**如果只改Prompt，不改代码，会发生什么？**
1. **改变生成内容**：将“英语单词”改为“日语单词”，就能变成日语学习工具
2. **改变数据结构**：增加`"pronunciation": "发音"`字段，就能支持音标
3. **改变难度控制**：在Prompt中加入“适合小学生学习”，就能调整生成策略
4. **改变主题范围**：从“单词”扩展到“成语”“名言”，就能改变应用性质

## 【五】如何模仿它，做出你自己的版本？

### 安全改造路径（从易到难）：

**第一步：保持结构不变，替换使用场景**
- **目标**：先做出一个能用的版本
- **操作**：
  1. 复制整个HTML文件
  2. 修改标题和文案：将“单词”改为你要记忆的内容，如“历史年代”“编程概念”“客户常见问题”
  3. 修改AI Prompt中的“英语单词”为你的内容类型
  4. 测试基本功能是否正常

**第二步：调整输入字段或Prompt**
- **目标**：让应用更贴合你的需求
- **操作**：
  1. 在“添加单词”表单中，修改`term`和`definition`的标签，如“问题/答案”“概念/解释”
  2. 调整AI生成参数：增加“领域”（技术、文学、医学等）选择
  3. 细化Prompt：描述更具体的生成要求，如“生成10个关于React Hook的面试题”

**第三步：改变输出形式或展示方式**
- **目标**：优化学习体验
- **操作**：
  1. 修改卡片样式：调整颜色、字体大小
  2. 增加学习模式：如“选择题测试”“填空模式”
  3. 添加统计功能：学习进度图表、记忆曲线可视化

**从哪里下手最安全？**
从**文案和Prompt修改**开始！这些改动不会破坏代码逻辑，却能立即改变应用用途。比如改成“面试题记忆卡”，只需修改几处文字和Prompt。

## 【六】3–5个可直接尝试的改造方向

### 1. 增加输入维度，让AI生成更精准
**具体操作：**
- 在AI生成表单中添加“词性筛选”（名词、动词、形容词）
- 添加“使用场景”输入框（如“邮件写作”“技术文档”）
- 修改Prompt为：`生成${count}个关于${topic}的${level}级${词性}单词，主要用于${场景}`

**效果**：生成的单词更贴合具体使用需求。

### 2. 更换或扩展AI模型支持
**具体操作：**
- 在API设置中增加OpenAI、Claude等选项
- 修改`generateWords()`函数，根据选择调用不同API
- 为不同模型微调Prompt（有些模型对格式要求不同）

**效果**：用户可以选择自己拥有的API，或对比不同模型生成效果。

### 3. 拆分学习模式为多个页面/状态
**具体操作：**
- 将“学习模式”拆分为“新词学习”“今日复习”“错题重做”
- 为每种模式设计不同的算法：新词快速过，错题重点练
- 添加“学习目标”设置（如“每天学习20个新词”）

**效果**：学习路径更清晰，针对性更强。

### 4. 优化交互体验
**具体操作：**
- 为卡片添加键盘快捷键（空格翻转，1/2/3对应三个按钮）
- 添加“发音”功能：调用浏览器TTS API朗读单词
- 实现拖拽排序单词列表
- 添加“夜间模式”切换

**效果**：使用更流畅，适合高频使用。

### 5. 增加社交或同步功能
**具体操作：**
- 添加“分享词库”功能，生成可分享链接
- 实现简单的多设备同步（通过导出/导入链接）
- 添加“公共词库”浏览和导入（如“托福高频词”）

**效果**：从个人工具变为可协作的学习平台。

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性：
1. **不适合精确的时间安排**
   - 虽然基于艾宾浩斯曲线，但复习时间只是建议，不是严格科学实验
   - 如果你需要精确到分钟的学习计划，应该用专业的记忆软件

2. **不适合多媒体学习**
   - 没有图片、发音、视频支持
   - 对于需要视觉联想或听力训练的内容，应该用Anki等支持多媒体的工具

3. **不适合大规模协作**
   - 数据存在本地浏览器，没有账号系统
   - 如果需要团队共享词库，应该用Google Sheets或专门的学习平台

4. **不适合作为主要词典**
   - 只有你手动添加的单词
   - 查生词应该用有道、欧路等专业词典

5. **AI生成质量有限**
   - 依赖Prompt设计和模型能力，可能生成不准确的内容
   - 重要术语应该手动验证，不能完全依赖AI

### 如果用户想做X，应该换什么：
- **想做语言学习的全流程**：用Duolingo、多邻国等综合平台
- **需要科学验证的记忆算法**：用Anki（开源、算法经过验证）
- **需要离线优先**：用Anki或本地软件
- **需要与课本同步**：用教材配套的App或学习系统
