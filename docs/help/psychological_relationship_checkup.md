# 亲密关系体检表 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你处于一段亲密关系（如伴侣、夫妻）中，想要客观地了解这段关系的健康状况，但又不想直接去找咨询师时，可以使用这个工具。它就像一个“关系健康自检仪”，通过回答一系列标准问题，为你生成一份包含可视化分析和具体建议的私人报告。

**适合情况：**
- 希望定期（如每季度）评估关系状态，进行“关系保养”。
- 在感到沟通不畅或关系停滞时，想寻找一个客观的切入点来讨论问题。
- 想了解关系中不同维度（如信任、沟通）的强弱分布。

**不适合情况：**
- **紧急或危机情况**：如存在严重冲突、暴力或信任崩塌，应立即寻求专业心理咨询或法律援助。
- **替代专业咨询**：它无法提供持续的、个性化的深度治疗，仅作为自我觉察的辅助工具。
- **决策依据**：不应仅凭此报告做出“分手”或“结婚”等重大人生决定。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   右侧问卷区的 **12个选择题**。每个问题对应亲密关系的一个方面，你需要从“非常好”到“很差”的5个等级中选择最符合你感受的答案。

2.  **用户通常会做哪几步操作？**
    *   **第一步：填写问卷**。依次回答所有12个问题。
    *   **第二步：开始分析**。回答完所有问题后，“开始分析”按钮会亮起。点击它。
    *   **第三步：首次使用需配置**。如果这是你第一次使用，页面会弹出一个“高级设置”窗口，要求你填入 **DeepSeek API Key**（这是调用AI分析能力的“钥匙”，需要你自行在DeepSeek官网申请获取）。
    *   **第四步：查看报告**。稍等片刻，左侧会生成一份包含雷达图、深度分析和改进建议的完整报告。

3.  **输出结果长什么样？**
    *   **雷达图**：一个六边形图表，六个角代表“信任”、“沟通”等六个维度。图形面积越大、越饱满，代表该维度得分越高，关系在该方面越健康。
    *   **深度分析**：一段由AI生成的、基于你答案的文本分析，用Markdown格式呈现，会指出你关系中的优势和潜在风险点。
    *   **改进建议**：另一段文本，提供3-5条具体、可操作的建议，帮助你改善关系中较弱的方面。

4.  **有哪些容易忽略的使用细节？**
    *   **API Key是必须的**：没有它，分析功能无法工作。Key需要妥善保管，不要分享给他人。
    *   **模型选择**：页面右上角有“V3”和“R1”两个按钮，分别代表不同的AI模型（普通对话 vs. 深度推理）。首次使用保持默认的“R1”即可。
    *   **提示词可修改**：在“高级设置”中，你可以看到并修改发给AI的“系统提示词”。这决定了AI以什么角色、什么框架来分析你的答案。除非你清楚自己在做什么，否则建议先使用默认值。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“输入-处理-输出”** 三模块布局，非常适合学习。

*   **模块一：输入模块（右侧问卷区）**
    *   **职责**：收集用户的原始数据。它将抽象的“关系感受”转化为结构化的数字答案（1-5分）。
    *   **关键设计**：`questions` 数组定义了所有问题和其归属的维度。`answers` 数组与之一一对应，存储用户的选择。这种“数据与视图分离”的设计，使得修改问题或增加维度变得非常容易。

*   **模块二：处理模块（隐藏的AI引擎）**
    *   **职责**：作为桥梁，将用户输入（答案）和系统指令（Prompt）打包，发送给外部AI API（DeepSeek），并接收返回的JSON结果。
    *   **逻辑链路**：`用户答案` + `系统Prompt` → `组装成API请求` → `发送给DeepSeek` → `解析返回的JSON` → `更新结果数据`。

*   **模块三：输出模块（左侧报告区）**
    *   **职责**：将AI返回的复杂数据，以人类友好、直观的方式呈现出来。
    *   **它又包含三个子模块**：
        1.  **可视化模块（雷达图）**：将六个维度的分数（0-100）映射为雷达图上的六个点，并用SVG绘制多边形。`getDataPoints` 函数是这里的核心，它完成了数据到图形坐标的转换。
        2.  **分析文本模块**：直接渲染AI返回的Markdown格式文本。
        3.  **建议文本模块**：同上。

**最值得学习的设计：**
**“关注点分离”与“数据驱动视图”**。整个应用的状态（是否在分析、答案是什么、结果是什么）都由几个核心的 `ref` 或 `reactive` 变量（如 `isAnalyzing`, `answers`, `result`）控制。页面的显示（哪个模块可见、按钮是否禁用、雷达图形状）完全由这些数据状态决定。这意味着你修改数据，视图会自动更新，逻辑非常清晰，易于维护和扩展。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色**：它是**AI的分析框架和角色设定**。它告诉AI：“你现在是一名专业的亲密关系咨询师，请按照Gottman方法和六个维度来评估，并以指定的JSON格式输出。”
2.  **解决什么问题**：它同时解决了“理解问题”和“生成问题”。
    *   **理解**：指导AI如何解读那一串1-5分的数字答案，将它们关联到有意义的心理学维度上。
    *   **生成**：约束AI输出的内容（必须包含维度分数、分析、建议）和格式（必须是严格的JSON）。
3.  **Prompt中的关键变量**：
    *   **角色**：`专业亲密关系咨询师`
    *   **方法论**：`Gottman方法`（这是一个著名的关系研究理论）
    *   **评估维度**：`信任`、`沟通`等6个明确定义的维度。
    *   **输出指令**：`输出格式：JSON` 及后面的具体结构。
4.  **如果只改Prompt，不改代码**：
    *   你可以彻底改变这个工具的性质。例如，将Prompt改为“你是一名职业规划师，评估以下六个职场能力维度...”，那么同样的界面就会变成一个“职场竞争力体检表”。
    *   你可以微调分析风格，比如把语言从“温暖、非评判”改为“直接、犀利”。
    *   **注意**：如果修改了JSON结构中的键名（如把 `"dimensions"` 改为 `"scores"`），前端代码将无法正确解析，导致错误。所以修改Prompt时，最好保持输出结构不变，或同步修改前端解析逻辑。

## 【五】如何模仿它，做出你自己的版本？

遵循“先复制骨架，再更换血肉”的路径，从最安全的地方开始：

1.  **第一步：复制并理解基础结构（最安全）**
    *   将整个HTML文件另存为新文件。
    *   不要动任何JavaScript逻辑和Vue代码。
    *   只修改**静态文本**：如页面标题(`<title>`)、导航栏名称、模块标题（“关系评估问卷”、“深度分析”等）、按钮文字。先把整个页面变成你的“主题”。

2.  **第二步：替换核心内容（输入与Prompt）**
    *   **修改 `questions` 数组**：这是你的“数据源”。将12个问题替换为你新主题的问题（例如，“学习习惯评估”、“项目团队健康度”）。
    *   **修改 `dimensions` 数组**：将六个维度的名称改为与你新主题相关的（例如，“专注力”、“记忆力”、“协作力”）。
    *   **重写 `DEFAULT_PROMPT`**：这是灵魂。根据你的新主题，重新定义AI的角色、评估维度和输出要求。**务必保持输出JSON的结构不变**（即仍有 `dimensions`, `analysis`, `suggestions` 这三个键）。

3.  **第三步：定制化外观与输出**
    *   **修改CSS样式**：替换 `love-gradient`、`love-card` 中的颜色代码，改变整体色调以符合新主题（如学习主题用蓝绿色系，职场主题用蓝金色系）。
    *   **考虑输出形式**：目前输出是雷达图+文本。如果你的维度不是6个，或者更适合用柱状图、进度条展示，可以在第三步修改 `getDataPoints` 函数和SVG绘制逻辑。这一步需要一些前端图形知识。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加对比或历史功能**：
    *   **操作**：使用 `localStorage` 不仅保存配置，也保存每次的评估结果（`result`）。在报告页面增加一个“与上次对比”按钮，可以并排显示两次的雷达图，或列出分数变化。
    *   **价值**：让用户能看到关系的动态变化，工具价值倍增。

2.  **丰富输入形式，引入文本描述**：
    *   **操作**：在选择题下方，为每个问题增加一个“补充说明（选填）”的文本框。在构建 `userPrompt` 时，将这些文本描述也附加上去。
    *   **价值**：让AI的分析能结合更具体的情境，建议会更个性化。

3.  **切换或扩展AI模型后端**：
    *   **操作**：在“高级设置”中增加一个API提供商的下拉菜单（如DeepSeek, OpenAI, 智谱AI等）。根据选择，动态修改API请求的URL、Headers和模型参数。
    *   **价值**：让工具不依赖单一服务，用户体验更灵活。

4.  **优化交互与引导**：
    *   **操作**：在用户未填写完问卷就点击分析时，不是简单地禁用按钮，而是将未回答的问题高亮（如边框变红）并滚动到第一个未答问题处。
    *   **操作**：在生成报告后，增加“导出为PDF”或“生成分享链接（匿名）”的按钮。
    *   **价值**：提升工具的易用性和实用性。

5.  **拆分为多步骤向导**：
    *   **操作**：将当前的单页应用，改为多个步骤。例如：步骤1-填写基本信息，步骤2-回答A类问题，步骤3-回答B类问题，步骤4-查看报告。利用Vue的组件系统，用 `v-if` 控制步骤显示。
    *   **价值**：减轻用户面对一长串问题的压力，体验更佳，也便于后续扩展更复杂的问卷逻辑。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做精确的心理诊断工具**：它基于一个通用的问卷和AI的统计模式生成内容，**不能**诊断任何心理疾病或关系障碍（如依恋类型、人格障碍）。这类诊断需要由受过严格训练的专业人士在长期互动中进行。
2.  **不适合处理实时、复杂的对话**：它是一次性的“问卷-报告”模式，无法像聊天机器人那样与你进行多轮对话，深入探讨某个具体事件背后的情绪。
3.  **不适合作为法律或财务建议的依据**：报告中可能涉及“承诺”、“未来规划”，但这与法律上的婚前协议、财产规划等有本质区别。涉及法律和财务的重大决策，请咨询律师和理财顾问。
4.  **如果用户需要**：持续的、深度的情感支持或关系治疗，应该转向**专业的心理咨询平台或线下咨询师**。如果用户需要基于大量数据的科学测评，应该寻找**经过信效度检验的权威心理学量表**（如MBTI、大五人格等需付费认证的测评）。本工具定位在二者之间：一个低门槛、启发性的自我探索起点。
