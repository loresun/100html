# 时薪计算器 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象你是一名自由职业者、兼职工作者，或者正在考虑一份按小时计费的工作。你拿到了一份月薪报价，但想知道“每小时能赚多少钱”，或者反过来，你有一个期望的时薪，想知道“月薪大概是多少”。这个工具就是帮你快速在这两者之间换算的。

**适合情况：**
- 快速评估工作报酬的“性价比”。
- 比较不同薪酬结构（如月薪制 vs 时薪制）的工作机会。
- 自由职业者估算项目报价。

**不适合情况：**
- 计算包含复杂奖金、提成、税金的精确到手收入。
- 进行长期的财务规划或投资分析。
- 需要保存历史记录或生成详细报告的场景。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你会看到两个主要的输入框：
1.  **月薪**：输入你每月税前或税后的收入金额。
2.  **每月工作小时**：输入你平均每月工作的小时数。

**用户通常会做哪几步操作？**
1.  在“月薪”框里输入你的收入数字（例如：8000）。
2.  在“每月工作小时”框里输入你估算的工作时间（例如：160，代表每周40小时，一个月4周）。
3.  点击蓝色的 **“计算结果”** 按钮。

**输出结果长什么样？**
结果会直接显示在按钮下方，是一个清晰的卡片，上面写着类似 **“时薪：50.00 元/小时”** 的信息。

**有哪些容易忽略的使用细节？**
- **单位**：输入框旁边有“元”和“小时”的提示，确保你输入的数字单位正确。
- **数字格式**：直接输入数字即可，不需要输入“元”或“小时”等文字。
- **重置**：如果你想重新计算，直接修改输入框的数字，然后再次点击“计算结果”即可，旧的结果会被自动替换。

## 【三】核心结构拆解（学习重点）

这个页面不是一个单一的计算器，而是一个**多功能工具箱的框架**，时薪计算器只是其中一个工具。理解这个框架是学习的关键。

**关键模块组成：**
1.  **导航栏**：提供返回主页和打开设置的入口。
2.  **工具标题与描述区**：动态显示当前工具的名称和简介。
3.  **工具内容区（核心）**：这是一个“智能容器”，会根据当前加载的工具类型（如 `formula`， `timer`， `list` 等），显示对应的界面和功能。
4.  **设置面板**：用于配置API密钥等高级选项（在本例的时薪计算中可能用不到）。

**输入 → 处理 → 输出 的逻辑链路（以时薪计算器为例）：**
- **输入**：用户在 `tool.values[‘monthlySalary’]` 和 `tool.values[‘monthlyHours’]` 两个输入框中填入数字。
- **处理**：点击按钮触发 `calculate(tool)` 函数。这个函数会从 `tool` 对象中读取定义好的计算公式（例如：`monthlySalary / monthlyHours`），进行计算。
- **输出**：计算结果被赋值给 `tool.result`，页面中 `x-show=”tool.result”` 的部分会显示出来，将数字呈现给用户。

**最值得学习的设计：**
**“配置即界面”的数据驱动模式。** 整个页面的UI不是写死的，而是由一个 `tool` 数据对象控制的。这个对象定义了工具的类型、名称、输入字段、计算公式等。当你想增加一个新工具（比如一个BMI计算器）时，你主要不是去写HTML，而是去定义一个新的 `tool` 配置对象。这种设计让功能扩展变得非常清晰和模块化。

## 【四】Prompt / AI 逻辑是如何被设计的？

> **注意**：在当前提供的时薪计算器代码片段中，**并未直接使用AI或Prompt**。计算是纯数学运算。但是，页面框架预留了AI能力（如设置面板中的DeepSeek API配置），并且代码中包含了 `generator` 和 `text` 等工具类型，它们的设计思路与AI应用高度相关。

**假设在 `generator`（生成器）或 `text`（文本工具）中：**
- **Prompt的角色**：它是向AI模型发出的“指令”或“问题模板”，隐藏在代码逻辑中。例如，一个“冷笑话生成器”工具，其Prompt可能是“请生成一个关于`[用户输入的主题]`的冷笑话”。
- **解决的问题**：主要是“生成问题”。它根据用户的简单输入（如一个关键词），引导AI生成结构化的、符合预期的内容（如一段笑话、一首诗）。
- **关键变量**：用户通过输入框提供的变量（如 `tool.values[‘topic’]`），会被插入到预设的Prompt模板中，形成完整的请求。
- **只改Prompt的后果**：如果你不修改任何HTML或JavaScript代码，只修改工具配置中的Prompt模板，那么工具的行为会彻底改变。例如，把生成笑话的Prompt改成生成菜谱的Prompt，这个工具就从“笑话生成器”变成了“菜谱生成器”，而界面完全不变。

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：替换使用场景，复用“公式计算器”结构**
这是最简单的起点。时薪计算器属于 `type: ‘formula’` 的工具。你可以做一个“BMI计算器”。
1.  在 `tool.fields` 中，将两个输入框的 `label` 分别改为“体重(kg)”和“身高(m)”。
2.  在 `tool.calculate` 函数逻辑中（这部分在引用的 `standalone.js` 里），将计算公式从 `月薪/工时` 改为 `体重 / (身高 * 身高)`。
3.  修改 `tool.name` 和 `tool.desc`。恭喜，你的第一个工具就完成了。

**第二步：调整输入字段或创建新工具类型**
1.  **增加字段**：在 `fields` 数组中增加一个新对象，页面会自动渲染出第三个输入框。例如为BMI计算器增加“年龄”字段（即使计算不用，也可以展示）。
2.  **创建新类型**：如果你想做一个简单的“随机抽签”工具，可以模仿 `generator` 类型。定义 `type: ‘generator’`， 然后写一个函数，从数组中随机选取一个结果赋值给 `tool.result`。

**第三步：改变输出形式**
目前输出是简单的数字和标签。你可以：
1.  在结果显示区域，根据结果值添加颜色提示（例如，BMI结果过高显示红色，正常显示绿色）。这需要修改结果渲染部分的HTML和逻辑。
2.  将单一结果改为多个结果卡片（像记账工具显示总额和笔数那样）。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加本地存储**：让数据在页面刷新后不丢失。
    - **操作**：在 `addListItem`（清单）、`addLedgerEntry`（记账）、`saveNote`（笔记）等函数中，使用 `localStorage.setItem` 保存数据。在页面初始化 (`init`) 时，用 `localStorage.getItem` 读取并恢复数据。
    - **效果**：用户体验大幅提升，工具变得真正实用。

2.  **为“公式计算器”增加公式编辑器**：
    - **操作**：在设置面板或工具内部，增加一个文本框，允许高级用户直接输入JavaScript计算公式字符串（如 `”a * b + c”`），然后用 `eval()` 或 `Function` 构造函数动态执行（注意安全风险，仅供学习演示）。
    - **效果**：工具从一个固定计算器变成一个通用的科学计算器。

3.  **将“番茄钟”与“记账”结合，创造“专注时间薪酬可视化”工具**：
    - **操作**：创建一个新工具类型。用户设置时薪和番茄钟时长。每次完成一个专注周期，自动记录一笔“虚拟收入”到账本，并实时更新“本日专注收入”图表。
    - **效果**：将时间管理工具和财务工具结合，提供新颖的动力反馈。

4.  **优化交互：为所有输入框增加“回车键触发”功能**：
    - **操作**：像清单工具已经做的 (`@keydown.enter.prevent`)，在其他工具的输入框上也添加类似监听事件，让用户输入后按回车键就能直接触发计算，无需点击按钮。
    - **效果**：减少鼠标操作，流程更流畅。

5.  **引入简单的图表库**：
    - **操作**：使用像 `Chart.js` 这样轻量的库。在记账工具的统计部分，将月度消费趋势用折线图展示出来。
    - **效果**：让数据展示更直观，学习如何集成第三方可视化库。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合做复杂、专业的财务计算**：它没有考虑五险一金、个税阶梯、专项扣除等复杂因素。对于严肃的薪资规划，应使用专业的薪资计算器或Excel表格。
- **不适合做需要高精度和稳定性的计时**：网页版的计时器、秒表、番茄钟在浏览器标签页休眠或切换时可能变得不准确。对于严格的计时需求（如运动计时、考试计时），应使用手机原生应用或专业计时软件。
- **不适合作为永久、可靠的数据存储中心**：虽然可以改造加入本地存储，但 `localStorage` 有容量限制（通常约5MB），且用户清除浏览器数据时会丢失。对于重要的项目任务、财务记录，应使用云同步的笔记应用或专业软件。
- **不适合处理敏感信息**：如果集成AI API，请注意不要在Prompt中泄露配置的API密钥。任何需要处理密码、个人隐私信息的场景，都不应直接在前端页面中进行。
