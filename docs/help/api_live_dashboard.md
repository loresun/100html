# 实时数据联动看板 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你是一个需要同时关注多个市场动态的投资者或分析师。你需要在不同的网站或应用之间来回切换：查看天气（可能影响出行或某些行业）、关注加密货币行情、追踪汇率变化。这个过程既繁琐又容易错过关键信息。

这个网页将这些分散的数据源整合到一个简洁的仪表盘中，并创造性地将它们“联动”起来，生成一个综合指数。它适合在以下场景使用：
- **快速概览**：在会议开始前，花30秒了解当前市场与环境的基本面。
- **跨领域关联性观察**：思考天气、加密市场和汇率之间是否存在某种有趣的联动（例如，晴天是否与市场情绪正相关？）。
- **演示或教学**：展示如何将多个免费API数据整合并可视化。

它不适合：
- **深度分析或交易决策**：数据是实时快照，缺乏历史深度分析和专业指标。
- **高频率、高精度监控**：自动刷新间隔为30秒，且使用的是免费API，可能有速率限制，不适合高频交易场景。
- **自定义复杂数据源**：目前数据源和计算逻辑是固定的，无法由用户自由添加或修改。

## 【二】使用方式（给第一次接触的人）

这是一个“开箱即用”的仪表盘，你无需输入任何信息。

**首次打开页面时，你会看到：**
1.  页面顶部会显示“最近更新”时间，以及“组合联动指数”模块。
2.  下方的三个数据卡片（天气、加密行情、汇率）会开始加载，显示“正在更新...”的提示。
3.  几秒钟后，所有数据加载完毕，页面会显示具体数值和简单的趋势图。

**你通常可以做的操作：**
1.  **一键刷新**：点击顶部导航栏的“一键刷新”按钮，手动立即更新所有数据。
2.  **开启/关闭自动刷新**：点击旁边的按钮，可以在“开启自动刷新”（每30秒自动更新）和“暂停”状态之间切换。
3.  **单独刷新某个模块**：在每个数据卡片的右上角，都有一个“刷新”文字按钮，可以只更新该模块的数据。
4.  **查看接口状态**：在右侧“自动刷新设置”卡片中，可以看到三个数据接口的连接状态是“正常”还是“异常”。

**输出结果长什么样？**
- **核心输出**：页面中央的“组合联动指数”会显示一个0-100之间的分数（如“68”），以及“热度高”、“稳态”或“观望”的标签。这个分数由天气舒适度、加密市场趋势和汇率波动共同计算得出。
- **详细数据**：三个卡片分别展示：
    - **天气**：上海的温度、体感温度、风速和湿度。
    - **加密行情**：比特币和以太坊的当前美元价格，以及一个简单的近期价格走势迷你图。
    - **汇率快照**：美元对人民币（USD/CNY）和美元对欧元（USD/EUR）的汇率，以及其走势迷你图。
- **趋势判断**：在指数模块中，还有对“行情热度”（上涨中/回调中/横盘）和“汇率波动”（美元走强/回落/平稳）的文字判断。

**容易忽略的使用细节：**
- **迷你图是历史记录**：价格和汇率下方的折线图，展示的是本次页面打开后，每次刷新时记录的数据点（最多12个），并非长期的日K线图。
- **状态指示**：如果某个API请求失败，对应的“接口状态”会变为“异常”，但页面不会弹出烦人的错误弹窗，只是数据不再更新。你可以通过手动点击“刷新”按钮来重试。
- **图标动态变化**：开启/关闭自动刷新时，按钮上的图标会从“播放”▶️ 变为“暂停”⏸️。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为五个模块，像一个高效运转的数据工厂：

1.  **控制中心（顶部导航栏）**
    - **职责**：提供全局控制与状态概览。它是整个看板的“指挥台”。
    - **包含**：一键刷新按钮、自动刷新开关、最后更新时间。
    - **逻辑**：用户点击按钮 → 触发对应的函数（`refreshAll`, `toggleAutoRefresh`） → 影响所有数据模块。

2.  **综合指数仪表盘（核心联动模块）**
    - **职责**：**融合与解读**。这是本页面的“大脑”，它不直接显示原始数据，而是将三个来源的数据按照一套规则进行计算和综合，输出一个易于理解的分数和趋势标签。
    - **逻辑**：`天气数据` + `加密历史趋势` + `汇率历史趋势` → 通过 `pulseScore`, `marketTrend`, `fxTrend` 等计算属性加工 → 输出分数、标签和颜色。

3.  **数据源模块（三个并列卡片）**
    - **职责**：**获取与展示原始数据**。它们是三个独立的“数据采集工”，分别从不同的API获取数据，并以卡片形式清晰展示。
    - **逻辑**：`点击刷新`或`定时触发` → `fetchWeather`/`fetchCrypto`/`fetchFx` 函数调用对应API → 收到数据后更新页面绑定的变量（`weather`, `crypto`, `fx`） → 页面自动重新渲染显示新数据。

4.  **历史记录与可视化引擎（幕后模块）**
    - **职责**：**记忆与绘图**。每当获取到新的价格或汇率数据，`pushHistory`函数会将其存入一个数组（如`cryptoHistory.btc`）。`sparklinePoints`函数则负责将这些数字转换成SVG折线图的坐标点。这是让静态数据“动起来”的关键。

5.  **监控面板（右侧设置卡片）**
    - **职责**：**系统健康度检查**。显示各个API的连接状态，让用户对数据可靠性心中有数。

**最值得学习的设计：**
**“计算属性（Computed Properties）”的运用**。注意代码中 `get pulseScore()`, `get marketTrend()` 这样的部分。它们不是固定数据，而是根据其他数据（如`weather.temperature`, `cryptoHistory`）实时计算出来的。这种设计使得“综合指数”与底层数据完全联动，任何数据更新都会自动触发指数重新计算和页面更新，无需编写额外的更新逻辑。这是构建响应式、数据驱动界面的核心思想。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，**并没有使用传统意义上的“Prompt”或生成式AI模型**。它解决的是一个 **“数据整合与逻辑判断”** 问题，而非“理解或生成自然语言”问题。

但是，我们可以将 **“计算综合指数的逻辑”** 类比为一个**内置的、硬编码的“决策Prompt”**。

- **这个“逻辑Prompt”的角色**：它是一套预设的规则，负责将输入的原始数据（温度、价格、汇率）“理解”并“翻译”成一个有意义的综合分数和趋势标签。
- **它解决的是“理解问题”**：它试图让机器理解“什么样的数据组合代表市场‘热度高’”。例如，规则是：`天气接近22度得分高` + `比特币上涨加分` + `美元走强减分` = 最终分数。
- **关键变量**：在这个逻辑中，关键变量是 `this.weather.temperature`（天气温度）、`this.marketTrend`（市场趋势方向，-1，0，1）、`this.fxTrend`（汇率趋势方向）。
- **如果只改逻辑，不改代码**：假如你将 `pulseScore` 的计算公式从 `(天气舒适分 + 加密趋势分 + 汇率趋势分)` 改成 `(天气舒适分 * 加密趋势分)`，那么整个综合指数的含义和输出结果将发生**根本性变化**，可能从“市场环境指数”变成“天气驱动型投资指数”，而页面的其他部分（数据获取、展示）完全不变。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的数据仪表盘：

**第一步：替换数据场景（最安全，不碰代码逻辑）**
- **目标**：做一个“个人健康与环境看板”。
- **操作**：
    1.  修改标题和文字：将“API交易平台”改为“健康生活助手”，“实时数据联动看板”改为“健康环境看板”。
    2.  更换数据源：保留页面结构，但替换API。
        - **天气模块**：可以保留，关注本地天气。
        - **加密行情模块** → 改为 **“空气质量指数（AQI）API”**。
        - **汇率快照模块** → 改为 **“当地花粉浓度或紫外线指数API”**。
    3.  修改“综合指数”的名称和说明：改为“健康出行指数”，说明改为“结合天气、空气质量、花粉浓度的出行建议评分”。

**第二步：调整输入与核心逻辑**
- **目标**：让指数计算符合新场景。
- **操作**：
    1.  在JavaScript中，将 `fetchCrypto` 和 `fetchFx` 函数指向新的API地址，并调整数据解析逻辑，将返回的数据赋值给 `crypto` 和 `fx` 变量（你可以重命名这些变量，比如 `aqi`, `pollen`）。
    2.  **关键步骤**：重写 `pulseScore`、`pulseLabel` 等计算属性。例如，健康指数可能是：`天气舒适分 + (100 - AQI) + (100 - 花粉浓度)`。分数越高代表越适合户外活动。

**第三步：改变输出形式**
- **目标**：让展示更贴合主题。
- **操作**：
    1.  修改标签和颜色：将“热度高/稳态/观望”改为“适宜出行/一般/不建议”。
    2.  调整迷你图：如果新数据（如AQI）波动不大，可以考虑将迷你图改为仪表盘或进度条样式。
    3.  优化文案：将所有金融相关术语（如“行情”、“汇率”）替换为健康环境术语。

**从哪里下手最安全？**
从 **修改HTML中的静态文字和样式** 开始，比如标题、说明文字、颜色类名（如将 `bg-cyan-600` 改为 `bg-green-600`）。这不会影响功能，但能立刻让页面变成你的主题。然后，再逐步深入到JavaScript中替换API URL。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加配置化输入**：
    - **操作**：在顶部添加一个城市选择下拉框。将 `fetchWeather` 函数中的经纬度参数（`latitude=31.2304&longitude=121.4737`）改为从下拉框选中的值动态获取。
    - **效果**：用户可以看到不同城市的天气如何影响综合指数。

2.  **切换或增加数据源**：
    - **操作**：将加密行情API从CoinGecko换成其他提供更多币种（如Solana, Dogecoin）的免费API。或者，在汇率模块中增加日元（JPY）、英镑（GBP）等。
    - **效果**：丰富仪表盘的信息维度。

3.  **优化交互体验**：
    - **操作**：为“一键刷新”按钮添加点击反馈。在点击时，让按钮图标短暂旋转（加载动画），并在所有数据加载完成后停止。这可以通过临时添加一个CSS旋转动画类来实现。
    - **效果**：给用户明确的操作反馈，提升使用感受。

4.  **拆分为多页面/增加详情页**：
    - **操作**：将当前页面作为“总览首页”。为每个数据卡片（如加密行情）的标题添加一个链接，点击后跳转到新的“详情页”，在详情页中展示更长时间段的历史K线图（可使用Chart.js等库）。
    - **效果**：满足用户从概览到深度查看的需求，结构更清晰。

5.  **引入真正的AI进行解读**：
    - **操作**：保留现有数据获取逻辑，但将 `pulseScore` 的计算和 `pulseLabel` 的生成，改为调用一个AI大模型的API（如OpenAI GPT-4o Mini）。将天气、行情、汇率数据拼接成一段描述性文字作为Prompt发送，请求模型生成一段简短的“今日市场点评”和1-100的评分。
    - **效果**：指数的生成从“固定规则”升级为“AI解读”，可能发现人类预设规则之外的关联，并生成更自然的评论文本。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合作为严肃的投资工具**：其数据源为免费公开API，可能存在延迟、不准确或中断的情况。指数计算规则过于简单，是演示性质的，不能反映真实的、复杂的市场风险。
- **不适合处理私有或敏感数据**：所有API请求都在用户浏览器中直接发生，如果使用需要API密钥的付费数据源，密钥会暴露给前端，这是极不安全的。**此架构仅适用于调用无需认证或仅限前端使用的免费API。**
- **不适合长期历史数据追踪与分析**：它只保存了最近几次刷新的数据（最多12个点），用于绘制迷你图。关闭页面后，历史记录就会消失。没有数据持久化（如存入数据库）功能。
- **如果想做更专业的分析仪表盘**：你应该考虑使用后端服务器（如Node.js, Python Flask）来安全地管理API密钥、聚合数据、进行复杂计算，然后通过接口提供给前端。并考虑使用专业的数据可视化库（如ECharts, D3.js）来绘制更丰富的图表。
