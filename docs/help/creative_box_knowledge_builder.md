# 知识体系构建器 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
当你想要系统性地学习一个新领域（比如“人工智能”、“数字营销”或“心理学”），但面对海量信息感到无从下手时，这个工具可以帮你。它就像一个“学习规划师”，能根据你的目标、基础和偏好，自动生成一份结构清晰、包含学习路径、模块和评估方法的完整知识体系蓝图。

**适合什么情况？**
- **自学规划：** 你想自学一个新技能或学科，需要一个清晰的路线图。
- **课程设计：** 你是老师或培训师，需要为某个主题设计教学大纲。
- **项目梳理：** 你需要快速理解一个复杂领域的核心框架，以便进行项目规划或研究。
- **知识管理：** 你想将零散的知识点整合成一个有逻辑的体系。

**不适合什么情况？**
- **寻求即时答案：** 它不提供具体问题的答案，而是提供学习的“地图”。
- **深度内容生成：** 它不生成具体的课程内容（如详细的文章或代码），只生成学习框架。
- **无需结构的学习：** 如果你只想随意浏览信息，不需要系统规划，那么这个工具可能过于复杂。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面分为左右两大输入区：
1.  **左侧 - 知识领域：** 定义你要学什么。核心是填写“知识领域”（如“机器学习”）和“具体目标”（如“能独立完成一个预测模型”）。
2.  **右侧 - 体系设计：** 定义你希望怎么学。包括选择体系结构（如“层次递进”）、学习深度、时间框架，并勾选你想要的体系特色（如“实用性”、“前沿性”）。

**用户通常会做哪几步操作？**
1.  **填写核心信息：** 在左侧输入你想学习的领域和你的具体目标。
2.  **调整学习参数：** 在右侧根据你的情况选择合适的学习深度、时间安排等。
3.  **点击生成：** 点击页面中央蓝色的 **“构建知识体系”** 按钮。
4.  **查看与使用结果：** 页面下方会展开一个详细的知识体系报告，你可以阅读、复制或下载它。

**输出结果长什么样？**
生成的结果是一个结构化的报告，通常包含：
- **体系概览：** 标题、描述、统计数据和目标。
- **知识层级：** 分阶段（如入门、进阶、高级）的学习模块，每个模块包含主题、成果和预计时长。
- **关联图谱：** 以可视化节点展示核心概念之间的关系。
- **学习路径：** 为你规划好的、按时间顺序的学习步骤。
- **评估框架：** 告诉你如何检验自己的学习成果。
- **实施指南：** 提供分阶段行动建议和所需资源。

**有哪些容易忽略的使用细节？**
1.  **API设置是第一步：** 页面右上角的“设置”按钮里，需要填入有效的AI API密钥和地址，否则无法生成。这是最容易被卡住的一步。
2.  **“具体目标”要具体：** 不要只写“学会Python”，可以写“能用Python进行数据分析并生成可视化报表”。目标越具体，生成的体系越贴合。
3.  **特色标签可多选：** “体系特色”部分的标签（如“系统性”、“实用性”）可以点击选择多个，这会影响AI生成体系的侧重点。
4.  **结果可交互：** 生成报告后，底部有“复制体系”、“下载架构”等按钮，方便你保存和使用结果。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“输入-处理-输出”** 三层模块化设计：

**1. 输入模块（用户配置层）**
*   **职责：** 收集用户所有的个性化需求。
*   **组成：**
    *   **领域定义卡：** 收集“学什么”（知识领域、目标）和“你是谁”（已有基础、目标层次）。
    *   **体系设计卡：** 收集“怎么学”（结构、深度、时间）和“要什么特色”（应用场景、体系特色）。
*   **逻辑：** 将所有表单选项和输入框的值，整合成一个结构化的数据对象。

**2. 处理模块（AI引擎层）**
*   **职责：** 将用户输入转化为AI能理解的指令（Prompt），并调用AI API获取结构化结果。
*   **核心函数：** `buildKnowledgeSystemPrompt(formData)` 和 `callAI(messages)`。
*   **逻辑链路：**
    *   **输入：** 接收来自输入模块的结构化数据对象。
    *   **处理：**
        1.  **构建Prompt：** 将数据对象“翻译”成一段给AI的详细任务描述，并**严格指定输出格式为JSON**。这是关键！
        2.  **调用API：** 将包含系统指令（“你是知识架构师”）和用户Prompt的消息发送给AI。
    *   **输出：** 收到AI返回的、符合预定JSON格式的知识体系文本。

**3. 输出模块（结果展示层）**
*   **职责：** 将AI返回的JSON数据，渲染成用户易读的、美观的网页内容。
*   **核心函数：** `displayKnowledgeSystem(knowledgeSystem)`。
*   **逻辑链路：**
    *   **输入：** AI返回的JSON字符串。
    *   **处理：** 解析JSON，使用模板字符串（反引号 ` `` `）将数据填充到预设的HTML模板中，生成完整的DOM内容。
    *   **输出：** 将生成的DOM插入到页面指定区域，形成可视化的报告。

**最值得学习的设计：**
**“结构化Prompt + 模板化渲染”** 的管道。它没有让AI自由发挥生成HTML，而是：
1.  要求AI输出**纯数据（JSON）**。
2.  前端代码负责将数据**渲染成界面**。
这样做的好处是：**前后端职责清晰**。AI只负责“思考”内容，前端负责“展示”内容。这使得输出格式完全可控、样式统一，且易于扩展（比如轻松添加“下载为Markdown”功能）。这是构建可靠AI应用的核心模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色：**
在这个页面中，Prompt是连接**用户模糊需求**与**AI结构化输出**的“翻译官”和“蓝图”。它不是一个简单的问题，而是一份详细的**设计任务书**。

**它解决的是“生成问题”：**
Prompt的核心任务是**生成**一个全新的、符合多项约束条件的知识体系框架。它需要综合理解领域、目标、结构、深度等十几个参数，进行创造性设计。

**Prompt中的关键变量：**
所有表单输入都成了Prompt中的变量。最重要的是：
1.  **`data.domain`（知识领域）和 `data.specificGoals`（具体目标）：** 定义了生成内容的主题和方向。
2.  **`data.structureType`（体系结构）和 `data.features`（体系特色）：** 定义了生成内容的“形状”和“风格”。
3.  **预设的JSON结构：** 这是最关键的变量。它强制AI按照一个固定的、包含`systemOverview`、`knowledgeLevels`等键名的格式输出，确保了前端代码能正确解析。

**如果只改Prompt，不改代码，会发生什么？**
1.  **改变内容风格：** 修改开头的系统指令（如“你是一位资深的教育专家”），可以改变AI的口吻和侧重点（如改成“你是一位敏捷教练”）。
2.  **调整详细程度：** 修改JSON结构中的字段，可以要求AI输出更多或更少的信息。例如，可以要求在每个模块下增加“推荐书籍”字段。
3.  **彻底改变应用：** 如果保持JSON结构不变，但把Prompt描述的任务从“设计知识体系”改成“设计健身计划”，那么这个页面就瞬间变成了一个“健身计划生成器”。**这展示了Prompt如何定义应用的本质功能。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”的路径，逐步创建自己的AI工具：

**第一步：替换使用场景，保持核心结构（最安全）**
*   **目标：** 做一个“旅行规划生成器”或“个人健身计划生成器”。
*   **操作：**
    1.  修改网页标题和说明文字。
    2.  **保留所有HTML/CSS布局和JavaScript交互逻辑。**
    3.  只修改输入表单的标签和选项。例如，把“知识领域”输入框改成“旅行目的地”，把“体系结构”下拉框改成“旅行风格”（如“穷游”、“奢华”、“探险”）。
    4.  暂时不修改`displayKnowledgeSystem`函数中的HTML模板。

**第二步：调整Prompt和输出JSON结构**
*   **目标：** 让AI生成符合新场景的内容。
*   **操作：**
    1.  在`buildKnowledgeSystemPrompt`函数中，重写给AI的“任务描述”，让它为你新的场景（如规划旅行）生成内容。
    2.  **关键：** 设计一个新的、适合你场景的JSON结构。例如，对于旅行规划，结构可能是 `{“overview”: {}, “dailyItineraries”: [], “budgetBreakdown”: {}, …}`。
    3.  更新Prompt末尾的JSON示例，换成你设计的新结构。

**第三步：改变输出展示方式**
*   **目标：** 让页面完美展示新内容。
*   **操作：**
    1.  在`displayKnowledgeSystem`函数中，将原有的HTML模板替换成适合你新JSON结构的模板。
    2.  例如，将“知识模块”卡片改成“每日行程”卡片，将“关联图谱”改成“景点地图”预览。
    3.  相应地调整CSS样式，使其符合新内容的视觉需求。

**从哪里下手最安全？**
从**第一步**开始。先只改文字和表单，然后运行。你会发现点击生成后，AI还是会输出旧的知识体系JSON，页面也会错误地渲染。但这验证了你的基础框架是能跑的。然后你再进入第二步，一步步将“知识体系”的管道，替换成你想要的“旅行规划”管道。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让计划更个性化：**
    *   **操作：** 在表单中增加“每日可用学习时间”、“偏好学习形式（视频/书籍/实践）”、“预算”等字段，并将这些信息加入Prompt。
    *   **效果：** AI生成的计划会考虑你的时间投入和学习偏好，推荐更匹配的资源（如“推荐3小时以内的在线课程”）。

2.  **切换或融合多个AI模型/API：**
    *   **操作：** 修改`callAI`函数，或者增加一个模型选择逻辑。例如，用DeepSeek生成体系框架，同时调用一个文生图API（如DALL·E），为每个知识层级生成一张象征性的封面图。
    *   **效果：** 提升结果的可视化程度和吸引力。

3.  **将单次生成改为多步骤对话：**
    *   **操作：** 不要一次性展示所有结果。先让AI生成一个“体系大纲”，然后提供“深化某个模块”、“调整难度”等按钮，点击后基于之前的对话历史继续向AI提问，局部刷新页面内容。
    *   **效果：** 交互更自然，允许用户对生成结果进行微调和迭代。

4.  **优化输出与外部工具集成：**
    *   **操作：**
        *   **增强下载功能：** 除了Markdown，还可以生成PDF、或直接生成可导入Notion、Obsidian等笔记软件的格式。
        *   **添加分享功能：** 生成一个可分享的链接或摘要图。
    *   **效果：** 大大提升生成结果的实用性和流转效率。

5.  **拆解为引导式配置流程：**
    *   **操作：** 将当前页面密集的表单拆成2-3个步骤页面，例如：“第一步：定义目标”、“第二步：选择偏好”、“第三步：生成预览”。使用`localStorage`在页面间传递数据。
    *   **效果：** 对新用户更友好，降低了初次使用的认知负担。

## 【七】这个网页不适合做什么？（边界提醒）

-   **不适合作为实时问答工具：** 它不能回答“卷积神经网络的具体公式是什么？”这类具体知识问题。它的专长是**规划学习路径**，而非**提供知识内容**。
-   **不适合生成可直接执行的学习材料：** 它提供的是模块、主题和资源建议，而不是完整的教材、练习题或代码示例。你需要根据它的框架去寻找或制作具体内容。
-   **不适合替代专业教育咨询：** 对于涉及重要职业规划或学术研究路径的决策，它生成的计划是一个高效的**参考起点**，但不应完全替代与领域专家或导师的深入交流。
-   **不适合极度动态或模糊的领域：** 如果某个领域变化极快（如某些互联网营销热点）或边界极其模糊，AI可能难以构建出一个稳定、共识度高的体系框架，生成结果可能流于表面或很快过时。

**如果你想做X，应该换什么工具？**
-   **如果你想获得具体问题的答案：** 直接使用ChatGPT、DeepSeek Chat等对话AI。
-   **如果你想生成具体的文章、代码或方案：** 使用专注于内容生成的AI工具，并给出更具体的指令（如“写一篇关于Python入门的博客大纲”）。
-   **如果你想管理复杂的项目任务：** 使用Notion、Trello、Asana等专业的项目管理工具，AI可以作为生成初始任务列表的辅助。
