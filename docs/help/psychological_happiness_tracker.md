# 幸福感追踪器 - 学习与模仿指南

## 【一】这个网页解决了什么问题？

**使用场景**：
当你度过了或好或坏的一天，想停下来回顾一下“今天有哪些让我感到幸福的瞬间？”，并希望获得一些专业的、积极的心理学视角来分析这些时刻，从而更了解自己的幸福来源。它就像一个数字化的“幸福日记本”，但不止于记录，还能为你提供分析和建议。

**适合的情况**：
- 个人日常情绪复盘与自我关怀。
- 想了解自己幸福感的来源模式（是来自社交、成就还是独处？）。
- 在感到迷茫或低落时，寻找积极视角和可操作的小建议。
- 作为正念练习或积极心理学学习的辅助工具。

**不适合的情况**：
- 需要即时、专业的心理咨询或危机干预（这不是治疗工具）。
- 进行严格的、量化的心理学研究（其分析基于AI，非标准化测量）。
- 多人协作或团队幸福感追踪（它是为个人设计的单次分析）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **幸福时刻**：从预设的12个选项中，勾选今天让你感到幸福的瞬间（可多选），如“与人深度交流”、“完成一件事”。
2.  **具体描述**：（可选）一个文本框，让你补充细节。
3.  **幸福感评分**：一个1-10分的滑动条，评价今天的整体幸福水平。
4.  **分析维度**：一个下拉菜单，选择你希望AI从哪个角度分析，比如“三好理论”或“行动建议”。

**用户通常会做哪几步操作？**
1.  打开页面，回忆今天。
2.  勾选对应的幸福时刻，调整评分滑块，可能写点描述。
3.  点击“分析幸福感”按钮。
4.  稍等片刻，阅读右侧生成的“幸福分析报告”。

**输出结果长什么样？**
右侧会生成一份格式清晰的报告。顶部会显示你输入的“今日幸福指数”（如`7/10`），下方是AI生成的分析正文。分析会使用标题、列表等Markdown格式，内容温暖、鼓励，并基于你选择的维度（如PERMA模型）进行结构化解读。

**有哪些容易忽略的使用细节？**
1.  **首次使用需配置**：点击页面右上角的齿轮图标，在“高级设置”中填入你自己的DeepSeek API Key，否则无法进行分析。
2.  **模型选择**：右上角有“V3”和“R1”按钮，代表不同的AI模型（普通版和推理增强版），可以切换试试效果。
3.  **分析可复制导出**：生成的报告支持“复制”文本和“导出”为.txt文件，方便保存。
4.  **提示词可自定义**：在“高级设置”里，你可以看到并修改整个分析所依赖的“系统提示词”，这直接决定了AI的分析框架和语气。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

**1. 输入与配置模块（左侧卡片）**
*   **职责**：收集用户数据（幸福时刻、评分、描述）和系统配置（API Key、提示词）。
*   **组成**：多选框、滑块、文本框、下拉菜单、设置面板。
*   **逻辑**：用户在此模块完成所有“告知”操作，这些数据被存储在Vue的响应式变量（`input`, `apiConfig`）中，为后续分析做好准备。

**2. AI 处理与通信模块（不可见，但最关键）**
*   **职责**：作为桥梁，将用户输入打包成AI能理解的请求（Prompt），调用AI API，并处理返回的流式数据。
*   **逻辑链路**：
    *   **输入**：用户点击“分析幸福感”按钮。
    *   **处理**：函数`analyzeHappiness`被触发。它将`apiConfig.systemPrompt`（系统角色设定）和`input`中的数据组合成完整的用户请求（`userPrompt`）。
    *   **通信**：通过`fetch`函数向DeepSeek API发送请求，并开启流式（`stream: true`）接收，实现回答的逐字显示效果。
    *   **输出**：将API返回的文本流实时拼接，最终赋值给`analysis`变量。

**3. 输出与展示模块（右侧卡片）**
*   **职责**：显示状态（生成中/空状态/结果）并优雅地呈现最终的分析报告。
*   **逻辑**：完全依赖`analysis`变量的状态。通过Vue的条件渲染（`v-if`/`v-else`）切换三种视图，并使用`marked`库将AI返回的Markdown文本渲染成美观的HTML。

**最值得学习的设计**：
**“流式响应”与“状态驱动UI”的结合**。页面没有在等待AI完整回复时卡死，而是通过`isGenerating`变量显示友好的加载动画，同时通过流式传输让用户能实时看到文字生成，体验非常流畅。这是现代AI应用提升用户体验的核心设计。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
它是整个应用的“大脑”和“灵魂”。它定义了AI在本次对话中的**身份**（积极心理学专家）、**知识框架**（PERMA模型等理论）和**输出格式**（针对不同分析维度的结构化报告）。没有它，AI只是一个通用的聊天机器人。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**，但也包含了深度的**理解框架**。系统Prompt并没有直接回答用户，而是给了AI一套强大的“分析工具”和“写作模板”。当用户输入具体数据后，AI的任务是**运用这套工具和模板来生成定制化的内容**。

**哪些信息是 Prompt 中的关键变量？**
1.  **AI角色**：`“你是一位积极心理学专家...”`
2.  **理论知识**：PERMA模型、需求层次理论等，这是分析的依据。
3.  **分析框架**：`“根据用户选择的分析维度输出不同内容...”` 这部分是核心逻辑，它告诉AI面对不同的`input.analysis`值，应该选用哪个模板来组织报告。
4.  **输出风格指令**：`“温暖、鼓励、科学，避免说教...”` 这控制了回答的语气。

**如果只改 Prompt，不改代码，会发生什么变化？**
整个应用的分析能力、专业度和输出风格会彻底改变。例如：
*   将角色从“积极心理学专家”改为“人生教练”，分析角度会更偏向行动和规划。
*   在分析框架里增加“情感颗粒度分析”维度，下拉菜单里即使不增加新选项，AI也会尝试用这个新概念来分析。
*   把输出风格改为“严谨、学术、带参考文献”，生成的报告就会像一篇心理学短文。

## 【五】如何模仿它，做出你自己的版本？

这是一个经典的“数据输入 -> AI分析 -> 报告输出”型应用。你可以安全地遵循以下路径进行模仿：

**第一步：替换核心主题与数据输入（最安全）**
保持页面左右布局和所有交互逻辑不变。
*   **改标题**：把“幸福感追踪器”改成你的主题，如“每日创意评估器”、“运动表现分析器”。
*   **改输入项**：将“幸福时刻”的多选框选项，替换为你的主题相关项（如“创意类型”：写作、绘画、编程、音乐...）。相应地修改滑块标签和描述框提示文字。

**第二步：重写系统提示词（赋予新灵魂）**
这是让你的应用拥有专业性的关键。在`DEFAULT_SYSTEM_PROMPT`中：
*   **改角色**：将“积极心理学专家”改为对应领域的专家，如“资深创意教练”、“健身营养师”。
*   **改理论**：替换掉PERMA模型，写入你新领域的基础分析框架。
*   **改分析模板**：根据第一步中新增的“分析维度”下拉选项，为每个选项设计对应的报告输出模板。

**第三步：调整UI与展示细节（个性化外观）**
*   **改配色**：修改`<style>`标签中的`.happiness-gradient`和`.happiness-card`等类的颜色，使其符合新主题（如创意主题可用紫色/蓝色渐变）。
*   **改图标**：替换`lucide`图标，例如把太阳(`sun`)图标换成灯泡(`lightbulb`)或哑铃(`dumbbell`)。
*   **改文案**：将按钮文字“分析幸福感”改为“生成创意报告”等。

完成这三步，一个全新的、属于你的AI分析工具就诞生了。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加历史记录与对比功能**
    *   **操作**：使用`localStorage`不仅保存配置，也保存每次的分析记录（日期、输入、输出）。在页面上增加一个“历史记录”面板，可以查看过往条目，甚至生成简单的趋势图表（如每周平均分数折线图）。
    *   **价值**：让工具从单次分析升级为个人追踪系统，洞察长期变化。

2.  **丰富输入形式，引入情绪板或图片上传**
    *   **操作**：在输入区域增加一个“上传今日图片”的功能。将图片上传到图床后，把图片URL或简单的文字描述（可用其他AI接口生成）也作为上下文提供给分析AI。
    *   **价值**：从纯文本输入扩展到多模态，适合“视觉日记”、“旅行记录”等场景。

3.  **拆解为多步骤向导或增加更多分析维度**
    *   **操作**：将当前的单页输入，改为多个步骤的向导（Step 1: 记录事件； Step 2: 评估情绪； Step 3: 反思原因...）。或者，在现有分析维度基础上，增加更细分的选项，如“从认知行为疗法(CBT)角度分析”。
    *   **价值**：引导用户进行更深度、结构化的反思，提升分析的专业性和针对性。

4.  **优化交互，增加语音输入和音频总结**
    *   **操作**：利用浏览器的`SpeechRecognition` API，在描述框旁增加一个“语音输入”按钮。同时，可以利用语音合成API（如`SpeechSynthesis`），为生成的报告增加一个“朗读给我听”的按钮。
    *   **价值**：极大提升易用性和沉浸感，特别是在移动设备上或用户不想打字时。

5.  **切换或融合多个AI模型/API**
    *   **操作**：在设置中，不止提供DeepSeek模型选择，可以增加OpenAI GPT、Claude等选项。更高级的玩法是，用简单的逻辑将分析任务拆分：用一个模型（如推理强的）做分析，用另一个模型（如文笔好的）做润色。
    *   **价值**：让用户对比不同模型的效果，或通过模型组合获得更优质的结果。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合作为专业的心理诊断或治疗工具**：其分析基于通用心理学理论和AI生成内容，**不能**替代心理咨询师、治疗师的专业评估。如果用户持续情绪低落或有心理健康困扰，应建议其寻求专业帮助。
2.  **不适合进行严格的学术研究或数据统计**：其输入（如幸福时刻选项）是预设的，评分是主观的，AI分析是非确定性的。生成的报告可用于个人启发，但**不能**作为严谨的科学数据。
3.  **不适合需要高度隐私保障的敏感记录**：虽然API Key本地存储，但用户输入的数据会发送给第三方AI服务商。**切勿**用它记录极度私密或敏感的个人信息。
4.  **不适合自动化或批量化处理**：这是一个为**单次、人工、交互式**使用而设计的工具。如果你想自动分析成千上万条用户反馈或日记，需要设计完全不同的后端系统和数据处理流水线。

**如果你想做的是...**
*   **团队情绪管理**：应该寻找专门的团队协作软件或设计一个支持多用户、有权限管理、能匿名提交的后端系统。
*   **基于生物信号的幸福感测量**：需要连接硬件传感器（如心率手环），并学习信号处理与数据分析知识。
*   **生成可打印的精美日记本**：应该专注于PDF生成技术和更复杂的排版设计，而非交互式分析。
