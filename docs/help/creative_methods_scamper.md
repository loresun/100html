# SCAMPER 创意改造工具 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你正在为一个已有的产品、服务或内容寻找新的改进方向，但思路枯竭，或者想跳出常规思维。这个网页就是你的“创意催化剂”。它基于经典的 **SCAMPER 创意方法**（七个改造维度：替代、合并、改造、调整、他用、消除、重组），引导你系统性地思考创新点。

**适合的场景：**
*   **产品经理** 想为现有功能寻找迭代灵感。
*   **创业者** 希望优化自己的商业模式或服务流程。
*   **内容创作者** 想为文章、视频或课程寻找新的表现形式。
*   **团队头脑风暴** 时，需要一个结构化的框架来引导讨论。

**不适合的场景：**
*   你需要一个从零到一的、全新的、颠覆性的创意点子（它更适合在“已有事物”基础上改造）。
*   你需要对创意进行深入的可行性分析或市场调研（它主要提供灵感，而非决策）。
*   你希望完全脱离AI，进行纯手动的、不受任何引导的自由联想。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：点击右上角的 **“API 设置”** 按钮，输入你的AI模型API密钥（例如DeepSeek的密钥）。保存后即可使用。
2.  **输入你的想法**：
    *   **选择模式**：根据你的目标，在下拉框中选择“产品创新”、“服务升级”或“内容重构”。
    *   **对象/方案**：在文本框中清晰地描述你想改造的东西。例如：“我们公司的用户积分系统”、“一个教编程的短视频账号”、“小区里的共享图书角”。
    *   **背景补充（选填）**：可以补充一些限制条件或目标，例如：“目标用户是老年人”、“预算有限”、“希望增加用户互动”。
3.  **生成创意**：点击绿色的 **“生成 SCAMPER”** 按钮。稍等片刻，AI会开始工作。
4.  **查看结果**：
    *   页面右侧会展示一个由7个卡片组成的网格，分别对应SCAMPER的7个步骤（S, C, A, M, P, E, R），每个卡片下会列出2-3条具体的改造建议。
    *   下方会有一个“实施优先级”区域，用Markdown格式给出落地建议。
5.  **保存成果**：如果对结果满意，可以点击“导出为图片”按钮，将整个创意面板保存为一张PNG图片，方便分享或存档。

**容易忽略的细节：**
*   **背景补充很重要**：填写“背景补充”能让AI给出的建议更贴合你的实际场景，避免过于泛泛而谈。
*   **API密钥是必需的**：工具本身不提供AI能力，你需要自己准备并配置API密钥。
*   **结果可以微调**：如果对某一步的建议不满意，你可以手动修改文本框中的“对象/方案”描述，使其更精确，然后重新生成。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

1.  **控制面板模块（左侧）**
    *   **职责**：收集用户输入，触发AI生成任务。
    *   **构成**：模式选择器、核心对象输入框、背景补充框、生成按钮。
    *   **逻辑**：用户在此填写“我想改造什么”和“在什么条件下改造”，点击按钮后，这些信息被组装成一个清晰的指令（Prompt）发送给AI。

2.  **结果展示模块（右侧）**
    *   **职责**：结构化、可视化地呈现AI的思考结果。
    *   **构成**：7个SCAMPER步骤卡片网格、实施优先级摘要区、原始数据回退显示区。
    *   **逻辑**：它期望接收一个结构化的JSON数据，然后将其渲染成美观易读的卡片和文本。如果数据解析失败，则安全地回退到显示原始文本。

3.  **系统配置模块（弹窗）**
    *   **职责**：管理应用与AI模型通信的“钥匙”和“地址”。
    *   **构成**：模型提供商选择、API密钥和模型名称输入框。
    *   **逻辑**：将用户的配置信息保存到浏览器的本地存储（localStorage）中，确保下次打开页面时无需重复输入。

**输入 → 处理 → 输出链路：**
1.  **输入**：用户在控制面板选择模式、填写主题和背景。
2.  **处理**：点击“生成”后，前端代码将输入信息拼接成特定的Prompt，调用用户配置的AI API。
3.  **AI处理**：AI模型根据Prompt进行思考，并**被要求返回一个严格格式的JSON**。
4.  **输出处理**：前端代码尝试解析AI返回的JSON。如果成功，就提取数据并填充到结果展示模块的各个部分；如果失败，则将原始文本显示在“原始数据”区域，保证用户总能看到内容。
5.  **输出**：最终以卡片网格和文本摘要的形式呈现给用户。

**最值得学习的设计：**
**“结构化输出”与“优雅降级”的结合**。这个工具没有让AI自由发挥写一段文章，而是通过精心设计的Prompt，要求AI返回一个预设好结构的JSON数据。这使得前端可以精准地控制展示样式，用户体验极佳。同时，它预见到了AI可能不按格式回答的情况，准备了`result.raw`回退方案，保证了功能的鲁棒性。这是一种非常实用的AI应用设计模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：它是整个工具的“大脑调度员”。它不是一个简单的提问，而是一份详细的**任务说明书**，告诉AI要扮演什么角色、处理什么信息、以及**必须按照什么格式**输出结果。
*   **解决的问题**：它主要解决“**生成问题**”，但是一种“受控的生成”。它引导AI在SCAMPER框架内进行创造性思考，并生成结构化的内容，而不是开放式的论述。
*   **关键变量**：
    1.  **`${this.topic}`（对象/方案）**：这是创意的核心靶子。
    2.  **`${this.context}`（背景补充）**：这是创意的约束条件和背景信息。
    3.  **`${SCAMPER_HINTS[this.mode]}`（模式提示）**：根据用户选择的模式，提供不同的思考角度提示词。
    4.  **输出格式模板**：`{"steps": [{"key": "S", "label": "替代", "ideas": ["建议1", "建议2"]} ... ]}` 这是控制AI输出结构的核心。
*   **如果只改Prompt，不改代码**：
    *   你可以彻底改变这个工具的功能。例如，把SCAMPER改成“5W1H分析法”或“商业模式画布”，只需修改Prompt中的方法和输出格式要求，页面就会变成一个全新的分析工具。
    *   你可以改变创意的风格。例如，在Prompt中加入“请用幽默风趣的语言描述建议”，那么生成的所有点子都会变得很有趣。
    *   你可以调整输出的详细程度。例如，将“每一步输出2-3条”改为“输出5条”，AI就会给出更丰富的选择。

## 【五】如何模仿它，做出你自己的版本？

这是一个低风险的“换壳”创新路径，你可以一步步来：

1.  **第一步：替换核心方法论（最安全）**
    *   **目标**：保留所有代码结构，只改变工具的内在逻辑。
    *   **操作**：将 `SCAMPER_HINTS` 对象中的内容，替换成另一个创意或分析框架，如 **“SWOT分析”**（优势、劣势、机会、威胁）。同时，修改Prompt中的说明和要求的JSON格式，使其对应SWOT的四个象限。
    *   **结果**：你将立刻得到一个“SWOT分析生成器”，而页面布局、配置逻辑、导出功能全部完好。

2.  **第二步：调整输入与输出字段**
    *   **目标**：让工具更贴合新方法论的输入输出需求。
    *   **操作**：例如，做SWOT分析时，你可能需要“内部视角”、“外部视角”两个输入框。你可以复制现有的输入框，修改其标签和绑定的变量名。同时，调整结果展示模块，将7个卡片改为4个，分别对应S、W、O、T。
    *   **结果**：工具的交互界面完全为你自定义的方法论服务。

3.  **第三步：改变视觉风格与展示方式**
    *   **目标**：让你的工具拥有独特的品牌感和用户体验。
    *   **操作**：修改 `tailwindcss` 的配色类名（如将 `bg-emerald-50` 改为 `bg-blue-50`）。你还可以改变布局，比如将网格布局改为时间轴或雷达图（这需要引入新的图表库）。
    *   **结果**：一个从内到外都属于你的专属工具。

**从哪里下手最安全？**
从 **第一步** 开始。只修改 `SCAMPER_HINTS` 和 `generate()` 函数中的 `userPrompt` 字符串。这样，你无需改动任何HTML和样式，就能验证一个新想法是否可行。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“创意风格”选择器**：
    *   **操作**：在输入面板增加一个下拉框，选项如：“务实型”、“天马行空型”、“颠覆型”。将这个选项作为变量加入到发送给AI的Prompt中（例如：“请以[务实型]风格给出建议”）。
    *   **效果**：用户可以根据当前需求（是概念探索还是落地规划）获得不同风格的创意，工具实用性大增。

2.  **引入“历史记录”功能**：
    *   **操作**：每次生成后，将输入的主题和生成的时间戳保存到 `localStorage` 的一个数组里。在页面侧边或底部增加一个区域来展示这个列表，并允许用户点击某条历史记录重新加载当时的结果。
    *   **效果**：方便用户回顾和对比不同方向的创意，避免灵感丢失。

3.  **实现“单步优化”与“投票”功能**：
    *   **操作**：在生成的每个创意点子（`<li>`）后面，添加一个“👍”和“🔄”图标。点击“👍”可以记录用户偏好（数据存本地）；点击“🔄”可以单独针对这一个SCAMPER步骤重新生成建议。
    *   **效果**：交互从“批量生成”变为“可迭代优化”，用户体验更精细，更能产出满意结果。

4.  **更换或扩展AI模型支持**：
    *   **操作**：在API设置的“模型提供方”下拉菜单中，新增“智谱AI”、“月之暗面”等选项。仿照现有的`deepseek`和`custom`配置块，为每个新增的厂商添加对应的API地址、密钥和模型选择框。
    *   **效果**：让用户可以根据成本、速度或效果偏好灵活选择不同的AI引擎。

5.  **生成“创意简报”文档**：
    *   **操作**：在“导出为图片”按钮旁边，增加一个“生成简报”按钮。点击后，将当前的输入、7个步骤的建议和优先级总结，组合成一段结构清晰的Markdown或HTML文本，并提供一个下载为`.md`或`.pdf`文件的功能。
    *   **效果**：产出物不再只是一张图片，而是一份可以直接用于项目讨论或立项的简易文档，工具的价值链得以延伸。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做严谨的可行性评估**：它生成的创意是“可能性”，而非“可行性”。这些点子缺乏数据支撑、成本核算和风险评估。如果你需要这些，应该使用专业的商业计划工具或进行市场调研。
*   **不适合替代深度的人类创意工作**：它是发散思维的助手，而非收敛思维的决策者。最终的创意筛选、深化、情感注入和细节打磨，必须依靠人的智慧和经验。
*   **不适合处理高度专业化或机密信息**：你输入的信息会被发送到第三方AI API。请勿输入未脱敏的商业机密、个人隐私或任何敏感信息。
*   **不适合在没有网络或API配额耗尽时使用**：它的核心能力依赖外部AI服务。如果断网或你的API密钥额度用完，工具将无法工作。它本质上是一个“AI前端界面”，而非离线可用的独立软件。

希望这份文档能帮助你不仅用好这个工具，更能理解其设计精髓，并创造出属于你自己的、更强大的创意助手。
