# 人生小决策评分板 - 学习指南

---

## 【一】这个网页解决了什么问题？

**使用场景：**
当你面临一个“二选一”的人生小决策时，比如“要不要换工作”、“周末去爬山还是看电影”，这个工具可以帮助你。它不会替你决定，而是通过一个结构化的方式，让你思考不同选项在各个维度（如时间、成长、快乐、收益）上的表现，并借助AI的视角，生成一个直观的雷达图对比和一句参考建议，帮你理清思路。

**适合情况：**
- 在两个选项间犹豫不决，需要外部视角参考。
- 希望将模糊的“感觉”转化为可视化的“分数”对比。
- 想快速获得一个基于你自定义权重的分析。

**不适合情况：**
- 需要精确量化分析的重大财务或法律决策。
- 涉及三个以上复杂选项的决策。
- 完全依赖AI做最终决定（它只是提供参考）。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **决策主题**：描述你正在纠结的事情。
    *   **选项A和选项B**：填写你正在对比的两个选择。
    *   **权重滑块**：有四个预设维度（时间成本、成长潜力等），你可以拖动滑块（1-10分）来调整每个维度对你的重要程度。

2.  **用户通常会做哪几步操作？**
    1.  首次使用，先点击右上角的“齿轮”图标，在弹出的设置框中填入你的DeepSeek API Key并保存。
    2.  在左侧面板填写或修改决策主题和两个选项。
    3.  根据你的个人偏好，拖动四个维度的权重滑块。
    4.  点击“**生成对比**”按钮。
    5.  等待几秒钟，查看右侧面板的变化。

3.  **输出结果长什么样？**
    *   **右侧上方**：会出现一个彩色的雷达图。两个选项会形成两个不同颜色的多边形，覆盖面积和形状直观地展示了它们在各个维度上的强弱。
    *   **右侧下方**：会显示一段AI生成的文字建议，通常是对比后的总结或提醒。

4.  **有哪些容易忽略的使用细节？**
    *   **必须配置API Key**：不配置就无法使用AI功能，但图表仍会显示一个默认示例。
    *   **权重是核心**：调整权重会直接影响AI的评分侧重点，这是“个性化”的关键。
    *   **结果非绝对**：AI的建议是基于你提供的有限信息和它的一般知识，请理性参考。
    *   **刷新页面会保留配置**：API Key保存在你的浏览器本地，下次打开还在。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

1.  **输入与控制模块（左侧卡片）**
    *   **职责**：收集用户所有的决策参数。它提供了三个文本输入框和一组可调节的滑块，是用户与工具交互的主界面。
    *   **输入**：用户输入的文字和滑块数值。
    *   **处理**：Vue.js框架实时将这些输入值绑定到内部变量。
    *   **输出**：一组结构化的数据（决策主题、选项A/B、权重数组）。

2.  **可视化与输出模块（右侧卡片）**
    *   **职责**：向用户展示分析结果。它不负责计算，只负责“呈现”。
    *   **输入**：来自AI的评分数据和分析文本。
    *   **处理**：Chart.js库接收数据，绘制雷达图；Vue将文本建议显示在框中。
    *   **输出**：直观的雷达图图像和一段文字建议。

3.  **AI 服务模块（隐藏的逻辑层）**
    *   **职责**：作为“大脑”，处理输入数据并生成评分和建议。它是连接输入和输出的桥梁。
    *   **输入**：由输入模块收集并拼接好的Prompt（指令）字符串。
    *   **处理**：通过`fetch`函数调用DeepSeek API，发送Prompt，等待并解析返回的文本。
    *   **输出**：格式化后的评分数组和文本建议，提供给可视化模块。

**逻辑链路：**
用户输入 → Vue绑定数据 → 点击按钮触发 → 拼接Prompt → 调用AI API → 解析AI回复 → 更新图表和数据 → 页面渲染结果

**最值得学习的设计：**
**“Prompt作为数据管道”**。整个页面的核心逻辑是：将用户的**结构化输入**（选项、权重）转化为一段给AI的**自然语言指令**（Prompt），再将AI返回的**非结构化文本**解析回**结构化数据**（评分数组）用于图表。这个“结构→非结构→结构”的转换设计，是连接前端界面与AI能力的精巧桥梁，非常经典且可复用。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色**：它是发给AI的“工作任务单”。在这个页面里，它负责将零散的用户输入（主题、选项、权重）组织成一个AI能理解的、要求明确的完整任务。

2.  **解决的是“生成问题”**：AI的任务是根据你给的背景和权重，“生成”出两个选项在各个维度上的具体分数，并“生成”一句评价。它不是在理解一个已有答案，而是在创造新的内容。

3.  **Prompt中的关键变量**：
    *   `决策主题`：设定分析背景。
    *   `选项A`和`选项B`：明确分析对象。
    *   `权重`：告诉AI哪个维度更重要，应予以侧重。
    *   **严格的输出格式要求**：`A: 6,7,8,5 B: 5,8,6,7 建议: ...` 这部分是**最关键**的设计。它强制AI以易于程序解析的格式回答，确保了后端代码能稳定地提取出数据。

4.  **如果只改Prompt，不改代码，会发生什么？**
    *   **改变分析维度**：例如在Prompt里加入“风险系数”，AI可能会在建议中提及，但**图表不会改变**，因为代码只预设了四个维度。
    *   **改变AI的角色**：将`你是决策分析师`改为`你是人生导师`，AI回复的语气和风格会变，但基本功能不变。
    *   **破坏格式**：如果删除了对输出格式（如`A: 1,2,3,4`）的严格要求，代码将无法正确解析AI的回复，导致图表出错或无法显示。**这提示我们：设计Prompt时，既要让AI懂，也要让程序好处理。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，像搭积木一样替换掉原有部分：

**第一步：替换核心场景与输入（最安全）**
*   **目标**：先做出一个能跑通的、属于你自己的工具。
*   **操作**：
    1.  修改`决策主题`、`选项A/B`的默认文字和占位符，比如改成“**选择晚餐食谱**”。
    2.  修改`weights`数组中每个对象的`label`，比如换成“**制作难度**、**美味程度**、**健康指数**、**食材成本**”。
    3.  修改页面标题和说明文字。
*   **此时**：你已经有了一个“晚餐选择评分器”，虽然AI还在用“决策分析师”的口吻说话，但核心功能已属于你。

**第二步：调整AI的角色与任务（优化核心）**
*   **目标**：让AI的回复更贴合你的新场景。
*   **操作**：修改`callLLM`函数中`system`角色的内容，例如从`你是决策分析师`改为`你是一位营养师兼美食家`。同时，微调`prompt`变量中的指令文字，使其符合新场景。
*   **此时**：AI给出的建议会更偏向营养和口味，工具的专业性提升了。

**第三步：改变输出与展示形式（增强体验）**
*   **目标**：让结果展示更匹配你的需求。
*   **操作**：
    1.  考虑雷达图是否仍然合适？对于“食谱选择”，或许并列的柱状图更直观。你可以研究Chart.js文档，将`type: 'radar'`改为`type: 'bar'`。
    2.  调整右侧卡片布局，比如将文字建议框的背景色和提示文字也做相应修改。
*   **此时**：你的工具从外观到内核都完成了定制。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加动态评估维度**：
    *   **操作**：在“权重”区域增加一个“+”按钮，允许用户自由添加或删除评估维度（如“社交价值”、“长期影响”）。这需要动态修改`weights`数组和雷达图的`labels`。
    *   **效果**：工具从固定四维分析变为完全自定义的多维分析，适用性大增。

2.  **本地缓存历史决策**：
    *   **操作**：使用`localStorage`不仅存API Key，也把每次的决策主题、选项和结果保存下来。在页面底部或侧边栏增加一个“历史记录”面板，可以查看或重新加载之前的分析。
    *   **效果**：工具有了记忆功能，用户可以回顾自己的决策历程。

3.  **更换或扩展AI模型**：
    *   **操作**：在设置面板中，除了DeepSeek，增加OpenAI GPT、Claude等模型的API Key输入框和模型选择下拉菜单。修改`callLLM`函数，使其能根据选择调用不同的API端点。
    *   **效果**：用户可以对比不同AI模型给出的建议，或在自己熟悉的模型上使用。

4.  **优化交互与反馈**：
    *   **操作**：
        *   为“生成对比”按钮在加载时添加旋转加载图标，禁用状态更明显。
        *   在AI生成建议时，尝试用`\n`换行符将建议分成几个要点，让阅读更轻松。
        *   为每个权重维度添加简短的图标（如时间用时钟图标），提升视觉友好度。
    *   **效果**：显著提升工具的专业感和用户体验。

5.  **拆分为多步骤向导**：
    *   **操作**：将当前单页面的输入，拆分成几个步骤，如“第一步：描述你的难题”、“第二步：填写选项”、“第三步：设置优先级”、“第四步：查看结果”。用上一步/下一步按钮导航。
    *   **效果**：引导性更强，尤其适合复杂的决策，避免用户面对一堆输入框感到困惑。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做精确的量化投资或专业风险评估**：AI的评分基于通用知识和你的简单描述，缺乏深度调研和精确数据支撑，不能用于金融、医疗等需要严谨论证的领域。
2.  **不适合处理有大量复杂约束条件的决策**：例如“在预算、时间、人员等15个限制条件下，从10个方案中选最优”。这类问题需要专业的决策分析软件或运筹学工具。
3.  **不适合作为逃避决策责任的借口**：工具的输出是“参考”，不是“判决”。将决策责任完全推给一个简单网页和AI，是不成熟的表现。它更适合作为激发你思考、整理思路的“催化剂”。
4.  **如果用户需要基于实时数据或专业数据库的决策**：例如“根据当前股市数据选择股票”，应该使用专业的财经分析平台，而不是这个通用工具。
