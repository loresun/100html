# 新人培训/工作交接助手 - 学习指南

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页解决的是 **“如何高效地将知识或工作交接给新人”** 的痛点。

**使用场景举例**：
*   **场景一（培训师/导师）**：你下周要带一个零基础的新人学习“数据分析”，但不知道如何把复杂的知识拆解成他容易消化的步骤。这个工具可以帮你快速生成一份包含学习路径、实践任务和检查点的完整方案。
*   **场景二（即将离职的员工）**：你需要在一周内把手头“客户成功专员”的工作交接给同事。除了口头说明，你还需要一份结构清晰的交接清单，确保不遗漏关键信息、联系人和待办事项。
*   **场景三（团队负责人）**：团队有一份写得很专业但新人看不懂的技术文档。你需要把它“翻译”成新人友好版，增加案例、解释和练习。

**它适合**：
*   需要系统化培训新人的场景。
*   时间紧迫，需要快速产出结构化方案。
*   希望将隐性知识（经验、技巧）显性化、文档化。

**它不适合**：
*   需要实时互动、手把手教学的场景（它生成的是“方案”，不是“实时教学”）。
*   涉及高度机密或敏感信息的交接（所有数据会发送到AI API）。
*   完全替代人际沟通（它辅助你准备，但不能替代你与新人的交流）。

## 【二】使用方式（给第一次接触的人）

1.  **准备工作**：点击右上角“设置”按钮，输入你的 DeepSeek API Key 并选择模型（推荐使用 R1 模型以获得更优的拆解思路）。
2.  **选择模式**：根据你的需求，在左侧选择三种模式之一：
    *   **从零设计**：你有一个培训主题，但不知道如何组织。
    *   **文档转化**：你有一份现成的文档，想让它对新人更友好。
    *   **工作交接**：你需要梳理工作内容，进行系统化交接。
3.  **填写表单**：根据你选择的模式，填写对应的信息。例如，在“从零设计”中，你需要填写“培训主题”、“新人水平”、“学习目标”等。
4.  **调整选项**：展开“高级选项”，勾选你需要的额外内容，如“生成阶梯式学习路径”、“推荐学习资源”等。
5.  **生成方案**：点击绿色的“生成培训方案”按钮。等待片刻（R1模型会有“深度拆解思路”展示），右侧就会生成一份详细的 Markdown 格式方案。
6.  **使用结果**：你可以直接阅读、复制全文，或导出为 `.md` 文件进行后续编辑。

**输出结果长什么样？**
结果是一份结构清晰、可直接使用的 Markdown 文档。以“从零设计”为例，它会包含：学习目标、分周学习计划（含理论、案例、实践）、检查点、资源推荐、导师计划等，就像一个专业的培训课程大纲。

**容易忽略的细节**：
*   **API Key 是必须的**：不配置就无法生成。点击“设置”中的链接可跳转获取。
*   **模式切换会清空表单**：从“从零设计”切换到“文档转化”时，表单内容会重置，注意保存你需要的信息。
*   **善用“高级选项”**：这里可以控制生成内容的丰富程度，比如是否包含“导师带教计划”。
*   **“R1 深度拆解思路”**：如果使用 R1 模型，生成结果前会先展示 AI 的思考过程，这对你理解 AI 如何拆解问题非常有帮助。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“配置-输入-处理-输出”** 模块化设计。

1.  **配置模块（导航栏/设置弹窗）**
    *   **职责**：管理应用的核心设置（API Key、AI 模型）。这是整个应用能运行的“开关”。
    *   **设计亮点**：将配置与主功能分离，并通过本地存储 (`localStorage`) 记忆用户设置，提升体验。

2.  **输入模块（左侧面板）**
    *   **模式选择器**：让用户先定义任务类型，从而动态切换不同的输入表单。这是**引导用户清晰定义问题**的关键设计。
    *   **动态表单区**：根据所选模式，展示最相关、最必要的输入字段。避免了无关信息的干扰。
    *   **高级选项**：以“详情折叠”形式收纳次要选项，保持界面简洁。

3.  **处理逻辑（核心 JavaScript 函数）**
    *   **`buildSystemPrompt()`**：根据所选模式，构建一个详细的、包含角色设定、核心原则和**严格输出格式**的“系统指令”。这是控制 AI 输出质量的**灵魂**。
    *   **`buildUserPrompt()`**：将用户在表单中填写的信息，组织成一段给 AI 的“用户请求”。
    *   **`callDeepSeek()`**：将组装好的“系统指令”和“用户请求”发送给 AI API，并以流式传输的方式接收回复，实现实时显示。

4.  **输出模块（右侧面板）**
    *   **状态管理**：清晰展示“空状态”、“加载中”、“结果展示”三种界面。
    *   **结果渲染**：使用 `marked` 库将 AI 返回的 Markdown 文本渲染成美观的 HTML。
    *   **操作区**：提供“复制”和“导出”功能，让生成的结果能立刻被使用。

**最值得学习的设计**：
**“模式驱动”的动态提示词工程**。整个应用的核心不是复杂的代码，而是针对三种不同场景（培训、转化、交接）精心设计的 **`系统提示词模板`** 。代码的作用是收集用户输入，并将其“填入”对应的模板中，从而向 AI 提出一个**结构清晰、要求明确**的请求。这种将复杂任务分解为“模板+变量”的思路，是构建实用 AI 应用的关键。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt 的角色**：在这个页面中，Prompt（特别是系统提示词）扮演了 **“虚拟专家”和“严格的内容架构师”** 的双重角色。它既定义了 AI 的身份（企业培训师），也规定了回答的格式和必须包含的模块。
*   **解决的问题**：它主要解决 **“生成问题”**——如何根据用户零散的输入，生成一份结构完整、专业可用的方案。同时，通过设定“成人学习特点”、“新人友好”等原则，也部分解决了“理解问题”，即让 AI 理解“什么是好的培训方案”。
*   **关键变量**：Prompt 中的关键变量来自用户表单，例如：`${form.value.topic}`（培训主题）、`${getLevelLabel()}`（学员水平）、`${form.value.objective}`（学习目标）。这些是填充到固定模板中的动态部分。
*   **只改 Prompt 的后果**：如果你只修改 `buildSystemPrompt()` 函数中的文本内容（比如改变输出格式、增加新的原则、更换角色设定），而完全不改动前端代码，那么**生成的方案内容风格、结构和深度将发生根本性变化**。例如，你可以把“企业培训师”改成“敏捷教练”，那么生成的方案就会充满敏捷实践的术语和框架。这证明了 Prompt 是此类应用的“大脑”。

## 【五】如何模仿它，做出你自己的版本？

如果你想创建一个类似工具来解决其他领域的问题，请遵循以下安全路径：

**第一步：保持结构不变，替换使用场景**
*   **目标**：先跑通一个属于你的最小可行产品。
*   **操作**：不要改动任何 Vue 或 Tailwind 代码。只修改文字内容。
    1.  修改网页标题和导航栏名称（如改为“短视频脚本创作助手”）。
    2.  修改左侧的**模式名称和描述**（如“从零设计”改为“产品测评脚本”、“文档转化”改为“口播稿优化”、“工作交接”改为“多平台适配”）。
    3.  修改右侧“生成结果”的标题。

**第二步：调整输入字段和 Prompt**
*   **目标**：让工具适应你的新场景。
*   **操作**：
    1.  在 `form` 对象中，将字段名和默认值改成你需要的（如 `topic` 改为 `productName`, `level` 改为 `videoStyle`）。
    2.  在 HTML 中，修改对应输入框的 `label`、`placeholder` 和选项。
    3.  **最关键的一步**：重写 `buildSystemPrompt()` 函数。为你新的三种模式分别设计：
        *   **角色设定**：AI 是谁？（如“资深短视频编剧”）
        *   **核心原则**：好脚本的标准是什么？（如“黄金3秒开头”、“痛点突出”、“行动号召明确”）
        *   **输出格式**：严格规定脚本必须包含哪些部分（如“标题”、“开场白”、“痛点展示”、“产品介绍”、“结尾号召”）。

**第三步：改变输出形式或展示方式**
*   **目标**：优化体验，使其更专业。
*   **操作**：
    1.  在 `buildSystemPrompt()` 的输出格式部分，使用更符合场景的 Markdown 样式（比如用 `>` 表示画外音，用 `**音效**` 标注音效）。
    2.  可以微调 CSS 中 `.prose` 部分的样式，改变结果呈现的视觉效果。
    3.  考虑在“导出”功能中，将 `.md` 后缀改为 `.txt` 或 `.docx`（这需要更多代码）。

**从哪里下手最安全？**
从 **`buildSystemPrompt()` 函数** 开始修改是最安全、最核心的。因为即使前端界面暂时还是“培训”相关的文字，但只要你的 Prompt 写得好，AI 就能生成你想要的“短视频脚本”内容。你可以先在这里验证你的想法。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“示例库”或“灵感”功能**：
    *   **操作**：在输入区旁边或下方增加一个按钮，点击后可以展示几个该场景下的优秀 Prompt 示例。例如，在“从零设计”模式下，展示“Python入门”、“新媒体运营”等主题的预设模板，用户点击即可一键填充表单。
    *   **价值**：降低用户启动成本，提供创作灵感。

2.  **支持多模型切换与对比**：
    *   **操作**：在设置中，除了 DeepSeek，增加 OpenAI GPT、Claude 等模型的 API 配置选项。生成时，可以让用户选择“用 GPT-4 生成一份，同时用 Claude 生成一份”，并将结果并排展示。
    *   **价值**：让用户对比不同模型的特点，选择最适合当前任务的结果。

3.  **拆解为“方案制定”与“执行跟踪”两个页面**：
    *   **操作**：将当前页面作为“方案制定页”。增加一个“执行跟踪页”，允许用户将生成的方案导入，并将其中的任务（如“本周实践任务”、“交接检查表”）转化为可勾选的待办清单，并记录完成情况。
    *   **价值**：形成“计划-执行”闭环，工具实用性大增。

4.  **优化交互体验**：
    *   **操作**：为“生成”按钮添加防重复点击机制；在加载时，显示一个渐进的进度动画或分步提示（如“正在拆解知识点...”、“正在设计实践任务...”）；成功生成后，用 Toast 提示而非 `alert`。
    *   **价值**：让等待过程更愉悦，提升专业感。

5.  **增加“个性化调优”滑块**：
    *   **操作**：在高级选项中，增加“创意度”、“详细程度”、“正式程度”等滑块，对应调整调用 API 时的 `temperature`、`max_tokens` 等参数。
    *   **价值**：给予用户更精细的控制权，满足不同风格需求。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合生成完全原创、高创新性的内容**：它的强项是基于你的输入进行**结构化、系统化的重组和扩充**。如果你想要一个前所未有的、充满奇思妙想的营销方案，它可能无法满足。
*   **不适合处理实时、动态信息**：它无法接入公司内部的 Wiki、任务系统或通讯录来拉取实时数据。所有信息都需要你手动输入或粘贴。
*   **不适合作为最终交付物**：它生成的是一份高质量的“草案”或“初稿”。其中推荐的具体资源链接、案例的准确性，以及是否符合你公司的特定文化，都需要**人工进行最终的审核、修正和润色**。
*   **如果要做**：对于需要高创新性或整合实时数据的需求，你应该考虑使用更专业的创作工具，或开发能够连接内部系统的定制化应用。本工具的最佳定位是“人类专家的高效辅助脑”。
