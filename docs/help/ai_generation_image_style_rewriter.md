# 图像风格迁移 Prompt 生成器 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
假设你有一张照片或图片，想把它变成“赛博朋克风格”或“水墨画风格”，但不知道如何向 AI 绘画工具（如 Midjourney、Stable Diffusion）描述。这个工具能帮你“翻译”需求：你上传图片、选择风格，它自动生成专业、可用的 AI 绘画提示词（Prompt）。

**适合情况：**
- 你有一张清晰的图片，想快速获得它的“风格化”版本。
- 你不熟悉 AI 绘画的术语和关键词，需要专业提示词。
- 你想探索同一张图片在不同风格下的效果。

**不适合情况：**
- 你想直接生成图片（本工具只生成文字提示词）。
- 你的图片非常模糊、复杂或包含大量文字，AI 可能无法准确识别。
- 你需要对生成结果进行精细、逐像素的控制。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **一张图片**：通过“上传原图”区域上传。
2.  **一个目标风格**：从预设风格（如“插画”、“赛博”）中选择，或手动输入自定义风格。
3.  **（可选）补充描述**：如果 AI 无法识别你的图片，可以在这里用文字描述画面。

**用户通常会做哪几步操作？**
1.  **配置 API**：首次使用时，点击右上角“API 设置”，填入必要的 API Key（如 DeepSeek 和视觉模型的 Key）。
2.  **上传图片**：点击上传区域，选择一张本地图片。
3.  **选择风格**：点击一个预设风格按钮，或在下方输入框输入自定义风格词。
4.  **生成 Prompt**：点击页面中央的“生成风格迁移 Prompt”按钮。
5.  **使用结果**：在右侧结果区域，复制生成的“风格迁移 Prompt”和“可选负面提示词”，粘贴到你的 AI 绘画工具中。

**输出结果长什么样？**
输出分为三块：
1.  **图像描述**：AI 对你上传图片的文字描述（例如：“一只橘猫趴在窗台上，午后阳光柔和，毛发细节清晰”）。
2.  **风格迁移 Prompt**：一段英文关键词组合，可直接用于 Midjourney 或 Stable Diffusion（例如：“a ginger cat lying on a windowsill, soft afternoon sunlight, detailed fur, in a cyberpunk neon style, vibrant colors, digital art, trending on artstation”）。
3.  **可选负面提示词**：一些建议的负面词，用于避免 AI 生成低质量图片（例如：“blurry, low quality, bad anatomy, extra fingers”）。

**有哪些容易忽略的使用细节？**
- **API 设置是必须的**：不配置 API Key，核心功能无法工作。工具本身不提供免费的 AI 服务。
- **视觉模型是可选的**：如果不想配置视觉 API，可以在“补充描述”中手动填写图片内容，工具会以此为基础生成风格 Prompt。
- **自定义风格优先级更高**：如果你既选择了预设风格（如“插画”），又填写了自定义风格（如“柔焦梦幻”），最终会结合两者。
- **结果可以保存**：生成的 Prompt 可以点击“保存模板”，方便以后重复使用。

## 【三】核心结构拆解（学习重点）

这个页面由 **四个核心模块** 组成，像一个流水线工厂：

1.  **输入与配置模块（左侧面板）**
    *   **职责**：收集用户的所有原始材料。包括图片上传、风格选择、文字补充，以及后端的 API 配置。
    *   **逻辑**：用户在此进行所有准备工作。图片被转换为 Base64 编码，风格被确定为文本，API Key 被保存到本地。

2.  **AI 处理引擎（不可见的后台逻辑）**
    *   **职责**：这是网页的“大脑”。它接收输入模块的数据，按顺序调用两个 AI 服务：
        *   **步骤 A（视觉识别）**：将图片和问题“描述这张图”发送给视觉 AI（如 GLM-4V），得到文字描述。
        *   **步骤 B（Prompt 生成）**：将“图片描述”和“目标风格”打包，发送给文本 AI（如 DeepSeek），并指令它“请生成适合 AI 绘画的英文 Prompt”。
    *   **逻辑**：`用户图片 + 风格选择` → `视觉 AI 理解图片` → `文本描述` → `文本 AI 组合描述与风格` → `结构化 Prompt`。

3.  **输出与展示模块（右侧面板）**
    *   **职责**：清晰、分块地展示 AI 处理后的结果。每一块结果（描述、Prompt、负面词）都有独立的复制按钮，方便用户取用。
    *   **逻辑**：接收来自“AI 处理引擎”的 JSON 格式数据，分别填充到三个文本框中，并更新状态提示。

4.  **交互与反馈模块（全局）**
    *   **职责**：管理整个页面的用户体验。包括按钮的加载状态、成功/失败的提示（Toast）、以及设置面板的弹出。
    *   **逻辑**：在用户操作时（如点击生成），禁用按钮并显示“生成中...”；操作完成后，恢复按钮并弹出“成功”提示。

**最值得学习的设计：**
**“AI 服务编排”与“降级处理”**。这个工具没有把 AI 当作一个黑箱，而是将其拆解为两个专业任务（看图说话、写提示词），并串联起来。更巧妙的是，当视觉 AI 不可用时，它允许用户手动输入描述作为“降级方案”，保证了核心功能（生成 Prompt）的可用性。这种设计思路在构建依赖外部服务的应用时非常实用。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt 在这里是 **“翻译官”和“格式化工具”**。它负责将非结构化的用户需求（一张图 + 一个风格词），翻译成 AI 绘画模型能精确理解的、结构化的专业指令。

**它解决的是“理解问题”还是“生成问题”？**
主要是 **“生成问题”**。视觉 AI 的 Prompt（“请用中文描述图片...”）解决的是“理解图片内容”的问题。而核心的 DeepSeek Prompt 解决的是“如何根据已知内容，生成另一段特定格式的文本”的问题。它不关心图片本身，只关心如何组织语言。

**哪些信息是 Prompt 中的关键变量？**
在发给 DeepSeek 的最终 Prompt 中，有两个关键变量被动态插入：
1.  `{description}`：从视觉 AI 或用户输入中获得的图片描述。
2.  `{styleText}`：用户选择的风格标签（如“插画”）或自定义文本。

**如果只改 Prompt，不改代码，会发生什么变化？**
变化会非常直接和巨大：
*   **改变输出格式**：如果把 Prompt 中的“输出 JSON”改成“用逗号分隔的列表”，那么右侧的结果展示就会错乱，因为代码期待解析 JSON。
*   **改变输出内容**：如果把“适合 MJ/SD 使用”改成“适合 DALL-E 使用”，生成的 Prompt 关键词风格会完全不同。
*   **改变 AI 的角色**：如果把“你是专业的图像风格迁移提示词专家”改成“你是一个诗人”，那么生成的结果可能会变成一首关于图片和风格的诗，而不是可用的绘画指令。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的“AI 小助手”：

**第一步：保持结构不变，替换使用场景（最安全）**
*   **目标**：做一个“小红书文案生成器”。
*   **操作**：
    1.  将标题改为“爆款小红书文案生成器”。
    2.  将左侧“选择目标风格”模块，改为“选择文案类型”（如“好物分享”、“旅行攻略”、“美食探店”）。
    3.  将“上传原图”的提示文字改为“上传商品/景点/美食图片”。
    4.  将右侧输出标题改为“生成的小红书文案”。
*   **此时**：页面布局和交互完全一样，只是文字变了。你还没有动核心的 AI 逻辑。

**第二步：调整输入字段或 Prompt**
*   **目标**：让 AI 生成符合小红书风格的文案。
*   **操作**：
    1.  修改发送给视觉 AI 的 Prompt，从“描述图片”改为“请描述这张图片中的商品、场景特点，并指出可能吸引女性的亮点”。
    2.  修改发送给 DeepSeek 的最终 Prompt，将角色设定为“你是资深小红书文案策划”，并要求输出包含“标题”、“正文”和“话题标签”三个部分。
*   **此时**：工具的核心功能变了，它开始为你生成文案。代码结构（上传、调用 API、显示结果）无需改动。

**第三步：改变输出形式或展示方式**
*   **目标**：让文案展示更美观。
*   **操作**：
    1.  将右侧单一的文本框，拆分成三个独立的卡片，分别用于展示“标题”、“正文”和“标签”。
    2.  为“标签”部分添加一个功能：点击每个标签即可复制。
    3.  在文案下方添加一个“模拟小红书封面”的预览区域。
*   **此时**：你的工具在体验上已经独具特色，但底层的数据流转逻辑依然源自最初的模板。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加历史记录与模板库功能**：
    *   **操作**：在页面顶部或侧边栏增加一个“历史记录”标签页。每次生成的 Prompt 都自动保存到这里，并支持搜索、再次编辑、一键应用。这解决了用户需要反复生成相似 Prompt 的痛点。

2.  **集成更多模型或本地模型**：
    *   **操作**：在 API 设置中，增加对 OpenAI GPT-4、Claude 或国内其他大模型（如通义千问、Kimi）的支持。更进阶的尝试是，利用 WebLLM 等技术，在浏览器中直接运行小型开源模型（如 Llama 3.2），实现完全离线的 Prompt 生成，保护隐私。

3.  **拆分或优化流程为多步骤向导**：
    *   **操作**：将当前的一页式设计，改为三步向导：“① 上传图片并描述” -> “② 选择与微调风格” -> “③ 预览与导出 Prompt”。每一步都有更详细的指导和选项（如在风格微调步，可以调整“艺术化程度”、“色彩饱和度”等参数）。这能提升复杂任务的完成度。

4.  **优化交互，增加实时预览**：
    *   **操作**：与一个免费的、支持 API 的文本生图服务（如 Stable Diffusion WebUI 的 API）做简单集成。在用户生成 Prompt 后，增加一个“快速预览”按钮，用这个 Prompt 生成一张低分辨率的小图，让用户直观感受效果，从而决定是否要调整 Prompt。

5.  **增加 Prompt 分析与优化建议**：
    *   **操作**：在生成 Prompt 后，不仅展示结果，还增加一个“分析”板块。用另一段 Prompt 让 AI 分析当前生成的 Prompt 优缺点（例如：“关键词是否足够具体？”“是否缺少光照描述？”），并给出 1-2 条优化建议。这能帮助用户学习如何写出更好的 Prompt。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合直接生成高质量图片**：它只是一个“提示词生成器”。生成图片需要借助 Midjourney、Stable Diffusion 等另一个专门工具。如果你想要“上传图片，直接得到风格化结果”的一站式服务，需要寻找集成了文生图模型的应用。
2.  **不适合进行精确的图像编辑**：如果你想“把图片中人物的衣服换成红色”，或者“去掉背景”，这是“图像编辑”任务。本工具通过生成 Prompt 让 AI“重新绘制”，结果具有随机性，无法保证像素级的精确对应。这类任务应使用 Photoshop 或 AI 修图工具（如 Pixelmator AI、RunwayML）。
3.  **不适合处理法律或版权敏感内容**：工具无法判断你上传的图片是否拥有版权，生成的 Prompt 也可能模仿受版权保护的特定艺术家风格。请负责任地使用，尊重原创版权。
4.  **不适合作为稳定的生产环境工具**：其功能依赖于多个第三方 AI API 的可用性和计费策略。如果某个 API 服务中断或收费变更，功能会受到影响。对于商业或关键用途，建议自行部署可靠的后端服务。
