# 创意风暴 - 灵感碎片重组 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下：你正在为一个新项目、一篇文章或一个营销活动寻找创意，但大脑一片空白。你有一些模糊的想法，却无法将它们组织成有力的表达。这个网页就像一个**创意催化剂**，它帮你把零散的想法“打碎”成一个个富有画面感的短句，并以动态的3D视觉方式呈现，让你在沉浸式体验中捕捉灵感。

**适合使用的情况：**
- 需要为文案、口号、标题寻找灵感
- 头脑风暴时想要可视化想法
- 希望从不同角度拆解一个主题
- 想体验AI创意生成与3D视觉结合的乐趣

**不适合的情况：**
- 需要生成结构严谨的长篇文章或报告
- 需要事实性、数据驱动的分析
- 需要精确的代码或技术文档
- 对3D动画敏感或设备性能较低的用户

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本输入框，你可以输入任何初始想法、关键词或需求描述
- 例如：“为一家主打环保的咖啡店想一句slogan”

**用户通常会做哪几步操作？**
1. **配置API**：首次使用时，点击右上角设置图标，输入你的DeepSeek API Key并保存
2. **输入想法**：在底部文本框中写下你的创意需求
3. **选择模式**：在顶部导航栏选择喜欢的动画效果（如“灵感雨”或“星系漫游”）
4. **开始生成**：按`Ctrl + Enter`或点击“开始重组”按钮
5. **观察与收集**：观看AI生成的短句以3D碎片形式在空间中运动，最终整齐排列

**输出结果长什么样？**
- 屏幕中央会出现一个个发光的文字碎片，每个碎片包含一句AI生成的创意短句
- 碎片会按照你选择的动画模式运动（如下雨般飘落、螺旋上升等）
- 生成结束后，碎片会自动排列成整齐的“阅读布局”
- 左上角会显示AI的“思考过程”（如果使用R1模型）

**有哪些容易忽略的使用细节？**
- **Ctrl + Enter快捷键**：比点击按钮更快地触发生成
- **模型切换**：右上角的“Chat”和“R1”按钮可以切换AI模型，R1会显示推理过程
- **动画切换时机**：生成过程中切换动画会清空当前所有碎片
- **自动整理**：生成结束后等待3秒，碎片会自动整齐排列
- **滚动查看**：当碎片排列后，如果内容较多，可以用鼠标滚轮或触控板缩放/旋转3D视图

## 【三】核心结构拆解（学习重点）

这个页面由四个关键模块协同工作：

**1. 3D可视化引擎模块**
- **职责**：创建和管理三维空间，渲染文字碎片，处理动画逻辑
- **关键组件**：Three.js场景、相机、渲染器、碎片网格（Mesh）
- **输入**：文字内容 → **处理**：生成文字纹理 → **输出**：3D空间中的可视化碎片

**2. AI交互模块**
- **职责**：与DeepSeek API通信，处理流式响应，管理生成状态
- **关键组件**：API调用函数、流式解析器、状态管理（isGenerating）
- **输入**：用户提示词 → **处理**：调用AI并解析流式响应 → **输出**：创意短句和推理内容

**3. 动画状态机模块**
- **职责**：管理四种不同的碎片运动模式，处理模式切换
- **关键组件**：currentAnimation状态、setAnimation函数、每种动画的更新逻辑
- **输入**：动画类型选择 → **处理**：应用对应的物理/运动规则 → **输出**：碎片的不同运动行为

**4. UI控制层模块**
- **职责**：提供用户交互界面，管理配置，显示状态
- **关键组件**：Vue响应式状态、模态框、下拉菜单、输入区域
- **输入**：用户操作 → **处理**：更新状态并触发相应功能 → **输出**：界面反馈和功能调用

**最值得学习的设计：状态驱动的动画系统**
页面没有为每个碎片编写独立的动画脚本，而是通过`currentAnimation.value`这个中心状态，配合碎片`userData`中的元数据，在统一的动画循环中应用不同的运动规则。这种“数据驱动动画”的设计让添加新动画模式变得非常简单。

**逻辑链路：**
```
用户输入 → AI生成短句 → 创建3D文字碎片 → 根据当前动画模式初始化位置/运动参数
         ↓
   动画循环（每帧） → 检查currentAnimation状态 → 应用对应的运动逻辑
         ↓
   生成结束 → 3秒后切换到“assembly”模式 → 碎片平滑移动到阅读布局
```

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是“创意导演”，它定义了AI输出的风格和格式。这里的系统Prompt明确要求AI：“生成一系列简短有力、富有画面感的文案片段。请不要输出长篇大论，而是输出一句句的'金句'或'灵感碎片'。”

**它解决的是“理解问题”还是“生成问题”？**
主要是“生成问题”中的**格式控制问题**。用户提供的是“要生成什么”（内容方向），而Prompt解决的是“以什么形式生成”（短句、碎片化、有画面感）。

**哪些信息是Prompt中的关键变量？**
1. **角色定义**：“创意文案生成器” - 设定AI的身份
2. **输出格式指令**：“一系列简短有力、富有画面感的文案片段”
3. **负面约束**：“不要输出长篇大论”
4. **具体示例**：“一句句的'金句'或'灵感碎片'”（给AI具体的格式参考）

**如果只改Prompt，不改代码，会发生什么变化？**
- 改为“生成五个问题” → 碎片会变成疑问句
- 改为“用古诗词风格” → 碎片会变得文雅古典
- 改为“生成技术术语解释” → 碎片会变得专业严谨
- 改为“生成emoji表情组合” → 可能会输出乱码（因为3D纹理只支持文字）

**关键设计点**：Prompt与3D展示是解耦的。AI只需要输出纯文本短句，3D系统负责将其可视化。这意味着你可以完全改变Prompt的内容类型，而无需修改任何Three.js代码。

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径（从易到难）：**

**第一步：替换内容领域（最安全）**
- 保持所有代码结构不变
- 修改系统Prompt，例如：
  - 从“创意文案”改为“科学知识点”
  - 从“金句”改为“历史事件要点”
  - 从“灵感碎片”改为“编程技巧提示”
- 测试：输入“Python列表操作”，看是否生成相关知识点碎片

**第二步：调整视觉风格**
- 修改CSS中的颜色变量（`:root`中的`--primary-color`和`--bg-color`）
- 替换图标：使用不同的Lucide图标名称
- 调整碎片的发光效果：修改`createTextTexture`函数中的`ctx.shadowColor`
- 测试：改为蓝色主题，看看视觉效果如何

**第三步：简化或修改动画模式**
- 先保留一种动画模式（如“falling”），删除其他三种
- 调整该模式的参数：修改下落速度、旋转速度
- 或者添加简单的水平飘动：在`animate`函数中添加新的运动逻辑
- 测试：让碎片只做水平往复运动

**第四步：改变输入/输出形式**
- 输入：从单行文本框改为多个标签输入（如“主题词”+“风格”+“数量”）
- 输出：除了3D展示，在侧边栏添加“导出为文本”功能
- 测试：添加一个按钮，点击后将所有碎片文字复制到剪贴板

**从哪里下手最安全？**
从**修改Prompt和颜色**开始。这不需要理解Three.js或Vue的复杂逻辑，却能立即改变页面的核心功能和视觉风格。

## 【六】3–5个可直接尝试的改造方向

**1. 增加输入维度，让生成更精准**
- **具体操作**：在输入框上方添加三个下拉菜单：
  - “风格”：幽默/严肃/诗意/科技
  - “长度”：短句/中句/长句
  - “数量”：生成3/5/10个碎片
- **修改位置**：在`startGenerate`函数中，将这些参数拼接到用户输入中
- **效果**：用户对输出有更精细的控制

**2. 添加碎片交互功能**
- **具体操作**：为每个3D碎片添加点击事件
  - 点击碎片：放大显示、朗读文字、标记为“喜欢”
  - 拖拽碎片：重新排列位置
  - 双击碎片：编辑文字内容（同步更新AI？）
- **修改位置**：在`addFragment`函数中为mesh添加事件监听
- **效果**：从“被动观看”变为“主动整理灵感”

**3. 更换AI模型或添加多模型支持**
- **具体操作**：
  - 在设置中添加OpenAI、Claude等API配置项
  - 修改模型选择器为下拉菜单，支持多个供应商
  - 在`callDeepSeek`函数中根据选择调用不同API
- **修改位置**：扩展`apiConfig`和`callDeepSeek`函数
- **效果**：对比不同AI的创意生成风格

**4. 添加“灵感板”保存和分享功能**
- **具体操作**：
  - 添加“保存当前视图”按钮，将3D场景截图+文字保存为图片
  - 添加“保存为项目”功能，将当前所有碎片状态保存到localStorage
  - 生成分享链接，包含编码后的配置和内容
- **修改位置**：新增函数处理截图和序列化
- **效果**：让创意成果可以保留和分享

**5. 优化移动端体验**
- **具体操作**：
  - 检测设备类型，移动端默认使用更简单的动画（减少性能消耗）
  - 将底部输入区域改为手势呼出（避免虚拟键盘遮挡）
  - 为触屏优化碎片交互（拖拽、捏合缩放）
- **修改位置**：添加设备检测和响应式交互逻辑
- **效果**：让创意生成随时随地进行

## 【七】这个网页不适合做什么？（边界提醒）

**1. 不适合生成需要精确结构的内容**
- **局限性**：碎片化输出天生不适合生成有逻辑顺序、章节结构的内容
- **替代方案**：如果需要文章大纲、报告结构，应使用专门的大纲生成工具，或要求AI输出Markdown格式的结构化内容

**2. 不适合事实核查或数据验证**
- **局限性**：AI可能生成听起来很棒但事实错误的“创意”表述
- **替代方案**：对于需要准确性的内容（如产品规格、历史日期），应使用搜索引擎或专业数据库验证

**3. 不适合实时协作或团队使用**
- **局限性**：当前版本是单用户、单会话的本地工具
- **替代方案**：如果需要团队头脑风暴，应考虑使用支持多人实时编辑的协作白板工具，或将此工具的输出导出到协作平台

**4. 不适合生成代码或技术解决方案**
- **局限性**：Prompt设计为创意文案，3D展示也不适合显示代码结构
- **替代方案**：使用专门的代码生成工具（如GitHub Copilot）或在IDE中直接使用AI辅助编程

**5. 不适合作为最终成品交付工具**
- **局限性**：输出的是“灵感碎片”，需要人工筛选、组合、润色才能成为最终文案
- **正确使用方式**：将此工具视为“创意矿工”，它帮你挖掘金矿，但你需要冶炼和锻造才能得到珠宝

**最后提醒**：这个网页最核心的价值在于**将AI的线性文本输出转化为空间化的视觉体验**，这种转化本身就能激发新的联想。当你模仿或改造时，请思考：在你的使用场景中，什么样的“空间隐喻”最能帮助用户理解和创造？是“星空中的知识点”？是“流水线上的生产步骤”？还是“地图上的故事节点”？找到那个隐喻，你就找到了属于自己的创意风暴。
