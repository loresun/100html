### 【一】这个网页解决了什么问题？

想象一下，你对自己的职业发展感到迷茫，不确定下一步该怎么走。你可能会在网上搜索“如何成为高级前端工程师”，但得到的答案千篇一律，并不符合你的个人情况。这个网页就是来解决这个问题的。

*   **使用场景**：当你处于职业转型期、晋升瓶颈期，或者刚进入职场需要明确发展方向时，可以使用它。它像一个“AI职业规划师”，根据你**独一无二**的背景（技能、经验、兴趣、目标），为你生成一份结构化的、可执行的成长路线图。
*   **不适合什么情况**：它不适合用来获取即时、具体的行业薪资数据，也不适合处理复杂的心理或人际关系问题（如职场冲突）。它提供的是一份基于通用知识的“战略蓝图”，而非精确的“战术手册”。

### 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **职业领域**：从8个预设按钮中选择一个（如“技术开发”）。
    *   **个人信息**：填写你当前的职位、工作年限、学历、核心技能和兴趣。
    *   **目标设定**：描述你理想的职位、希望在多久内达成、最看重什么（如薪资或技能），以及期望的薪资范围。

2.  **用户通常会做哪几步操作？**
    1.  **选择领域**：点击一个职业领域按钮（如“技术开发”），它会高亮显示。
    2.  **填写表单**：在左侧的三个白色卡片区域，依次填写你的现状和目标。
    3.  **生成规划**：点击最下方的 **“生成职业路径”** 蓝色大按钮。
    4.  **查看结果**：等待几秒后，右侧会显示详细的“职业发展时间线”。
    5.  **深入分析**：可以继续点击 **“技能差距分析”**、**“设定里程碑”** 等按钮，获得更细化的建议。

3.  **输出结果长什么样？**
    输出不是一段冗长的文字，而是结构清晰的视觉化模块：
    *   **时间线**：像一条纵向的时间轴，分阶段（如“第一阶段：6个月”）展示你应该达到什么职位、掌握什么技能、获得什么成就。
    *   **技能分析**：用进度条直观对比你“当前技能水平”和“目标技能水平”的差距。
    *   **里程碑**：像一张张任务卡片，列出了具体的、可检查的阶段性目标及其行动项。
    *   **行动建议**：提供立即可以开始的行动、月度目标以及成功小贴士。

4.  **有哪些容易忽略的使用细节？**
    *   **API设置**：页面顶部有一个隐藏的“API配置”面板（通过“API设置”按钮打开）。如果你有自己的DeepSeek或其他兼容OpenAI的API密钥，可以在这里配置，否则可能使用默认设置（可能无法工作）。
    *   **字段关联性**：你填写的“核心技能”和“兴趣方向”越详细，AI生成的建议就越贴合你。
    *   **按钮顺序**：建议先点“生成职业路径”，再点“技能差距分析”和“设定里程碑”，因为后两者的分析会基于已生成的路径进行。

### 【三】核心结构拆解（学习重点）

这个页面采用了经典的 **“输入-处理-输出”** 三明治结构，并且左右分栏，逻辑非常清晰。

*   **模块1：输入面板（左侧）**
    *   **职责**：收集用户所有原始信息。它又细分为三个子模块：
        1.  **领域选择器**：快速确定大方向。
        2.  **个人信息表单**：收集客观现状（是什么）。
        3.  **目标设定表单**：收集主观愿望（要什么）。
    *   **设计亮点**：将输入分类，并用不同的图标和视觉样式区分，让用户填写时思路清晰，不易遗漏。

*   **模块2：控制中心（左侧底部）**
    *   **职责**：触发不同的AI处理任务。它是连接“输入”和“输出”的**调度器**。每个按钮对应一个特定的Prompt（提示词）和一种结果展示方式。

*   **模块3：输出展示区（右侧）**
    *   **职责**：以友好的方式呈现AI的分析结果。它包含多个“抽屉式”的结果面板（时间线、技能分析等），默认隐藏，根据用户点击的按钮来显示对应的面板。
    *   **设计亮点**：结果不是纯文本，而是被精心设计成**数据可视化卡片**（进度条、时间线、彩色标签、任务列表），极大提升了可读性和专业性。

*   **逻辑链路**：
    1.  **输入**：用户在左侧填写信息。
    2.  **触发**：用户点击控制中心的某个按钮（如“生成职业路径”）。
    3.  **处理**：前端JS函数收集所有输入，拼接成一个结构化的**Prompt**，通过API发送给AI模型。
    4.  **AI响应**：AI返回**严格格式化**的JSON数据。
    5.  **输出**：前端JS解析JSON，调用对应的展示函数（如`displayCareerPath`），将数据填充到预先设计好的HTML模板中，并显示对应的右侧面板。

*   **最值得学习的设计**：
    **“Prompt作为函数调用”** 的设计思想。在这个网页里，每个功能按钮（生成路径、分析技能）背后都是一个精心编写的Prompt函数（如`buildCareerPathPrompt`）。这些Prompt规定了AI思考的框架和输出的格式（JSON）。这相当于你为AI设计好了“工作流程”，它只需要在你设定的框架内填充内容。这是构建可靠AI应用的关键。

### 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：Prompt在这里扮演着**“指令蓝图”**和**“数据格式约束”**的双重角色。它告诉AI：“请以职业顾问的身份，根据以下用户信息，并严格按照我指定的JSON格式，生成一份规划。”
*   **解决的问题**：它主要解决的是**“生成问题”**——根据已知信息（用户输入）生成未知的方案（职业规划）。但它也隐含地解决了“理解问题”，因为它指导AI如何理解“职业规划”这个抽象概念（将其分解为时间线、技能分析等部分）。
*   **关键变量**：Prompt中的关键变量就是所有用户输入的信息，它们被`${userInfo.xxx}`这样的模板语法动态插入到固定的Prompt文本中。例如，`${userInfo.careerField}`、`${userInfo.coreSkills}`。
*   **如果只改Prompt**：代码逻辑和页面布局完全不变，但应用的功能会发生**根本性变化**。例如，你把所有Prompt里“职业规划”相关的描述换成“健身计划”，把“技能”换成“运动项目”，那么这就从一个职业规划器变成了一个健身计划生成器。这证明了**Prompt是AI应用的灵魂**。

### 【五】如何模仿它，做出你自己的版本？

这是一个低风险、循序渐进的模仿路径：

1.  **第一步：替换场景，保留骨架（最安全）**
    *   **做什么**：不要动任何JS代码和CSS样式。只修改文字内容。
    *   **如何做**：
        *   把标题“职业发展路径规划器”改成你的主题，如“**个人学习路径规划器**”。
        *   把左侧“职业领域”的8个按钮，改成8个**学习领域**（如“Python编程”、“数字营销”、“吉他入门”）。
        *   把“个人信息”和“目标设定”表单里的标签和选项，全部换成学习相关的词汇（如“当前水平”、“目标水平”、“每日可用时间”、“学习偏好”）。
    *   **效果**：你立刻得到了一个外观一模一样，但主题全新的应用框架。

2.  **第二步：调整Prompt，改变核心逻辑**
    *   **做什么**：修改JS代码中的那几个`build...Prompt`函数。
    *   **如何做**：根据你的新主题，重写Prompt的指令部分。例如，在`buildCareerPathPrompt`里，把“作为专业的职业规划顾问...”改成“作为资深的学习规划师...”，并把JSON结构里的字段名改成学习相关的（如`phases` -> `learning_stages`, `required_skills` -> `key_concepts`）。
    *   **效果**：AI现在开始为你生成学习计划，而不是职业计划了。

3.  **第三步：微调输出展示**
    *   **做什么**：修改那几个`display...`函数中的HTML模板。
    *   **如何做**：让展示的文字和UI组件更贴合你的新主题。例如，在`displaySkillAnalysis`里，把“技能提升规划”的标题改成“知识点掌握规划”。
    *   **效果**：最终呈现给用户的界面语言完全契合你的新应用。

### 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让规划更精准**：
    *   **可操作**：在“个人信息”里增加一个“**所在城市**”下拉菜单。然后修改Prompt，加入“请考虑${city}的就业市场/学习资源特点”这一句。这样生成的建议会更具地域针对性。

2.  **切换或扩展AI模型后端**：
    *   **可操作**：在API配置面板的“模型选择”下拉框中，增加其他选项，如`gpt-4o`、`claude-3-haiku`。在JS的`callAPI`函数中，根据选择使用不同的API端点。这让你可以对比不同模型的效果。

3.  **将单页应用拆解为多步骤向导**：
    *   **可操作**：把现在左侧所有的输入表单隐藏起来，改为一个分步向导。
        *   第一步：选择领域。
        *   第二步：填写现状。
        *   第三步：设定目标。
        *   第四步：预览并生成。
    *   **好处**：用户体验更流畅，尤其适合在手机端使用。

4.  **优化交互体验**：
    *   **可操作**：为生成的里程碑卡片增加**交互功能**。例如，在每个里程碑卡片上添加一个“标记为完成”的复选框。当用户勾选时，卡片样式变为“已完成”状态（代码中已有`.completed`样式），并将进度保存到浏览器的`localStorage`中。这样应用就有了简单的进度跟踪功能。

5.  **结果可视化升级**：
    *   **可操作**：引入一个简单的图表库（如Chart.js）。在“技能分析”部分，不仅用进度条，还可以增加一个**雷达图**，一次性展示多个技能的当前水平与目标水平的对比，视觉效果更震撼。

### 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精确的决策**：它生成的路径是基于通用知识和模式，**并非百分百准确的预言**。你不能把它当作是否应该跳槽、是否应该接受某个offer的唯一决策依据。
*   **不适合替代深度咨询**：对于复杂的职业心理障碍、人际关系处理、极其小众或快速变化的职业赛道，它无法替代人类职业咨询师一对一的深度沟通和辅导。
*   **不适合生成可直接执行的“待办清单”**：它给出的“行动建议”仍然是方向性的。比如它建议你“学习React框架”，但不会为你生成今天下午2点-4点看哪个具体视频教程的日历事件。
*   **如果你需要做上述事情**：你应该将它的输出作为**思考的起点和讨论的提纲**，然后结合更专业的行业报告、招聘网站的具体职位要求、以及向业内前辈请教，来制定最终的个人计划。对于深度问题，寻求专业咨询师帮助。对于具体任务管理，使用Todoist、Notion等专业工具。
