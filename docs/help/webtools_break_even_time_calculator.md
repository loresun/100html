# Webtools 工具箱 - 帮助文档

## 【一】这个网页解决了什么问题？

这个网页是一个**个人效率工具箱**，它解决了日常工作和生活中需要快速使用各种小型工具，但又不想安装多个App或在不同网站间切换的麻烦。

**适合的使用场景：**
- **快速计算**：比如估算投资回本周期、单位换算。
- **时间管理**：需要专注工作（番茄钟）、倒计时或记录耗时。
- **简单记录**：临时记账、列待办清单、写简短笔记。
- **内容生成**：需要一些随机内容或简单文本处理。

**不适合的情况：**
- 需要复杂数据处理或专业分析（如Excel图表）。
- 需要长期、大量、结构化的数据存储（如完整账本、项目管理系统）。
- 需要团队协作或分享功能。

本质上，它是一个**轻量级、即开即用、功能聚合**的桌面小工具集合。

## 【二】使用方式（给第一次接触的人）

1.  **打开页面**：你会看到一个整洁的白色面板，顶部有工具名称和描述。
2.  **理解当前工具**：页面中央区域会根据你选择的工具，显示不同的输入框和按钮。例如，如果是“回本周期估算”，你会看到“投资金额”、“月收入”等输入框。
3.  **进行操作**：
    *   **对于计算器类**：在对应的输入框填写数字，点击“计算结果”按钮。
    *   **对于计时器类**：设置时间，点击“开始”、“暂停”、“重置”。
    *   **对于清单/记账类**：输入内容，点击“添加”或“记录一笔”。
    *   **对于笔记类**：直接输入，内容会自动保存。
4.  **查看结果**：结果会直接显示在输入区域下方，通常在一个有边框的卡片里，清晰明了。
5.  **切换工具**：点击左上角的“返回 Webtools”，可以回到工具箱主页面选择其他工具。

**容易忽略的细节：**
*   **设置按钮**：页面右上角的齿轮图标是 **API 配置**，只有部分工具（如AI生成类）需要用到，普通计算工具无需设置。
*   **自动保存**：笔记工具和清单工具在你输入时可能会**自动保存**到浏览器本地，关闭页面再打开，内容还在。
*   **键盘快捷键**：在清单工具中，输入后按 **回车键** 可以直接添加项目。

## 【三】核心结构拆解（学习重点）

这个页面的设计非常模块化，是学习的典范。

**关键模块与职责：**

1.  **导航栏模块**：位于顶部。负责提供返回入口和全局设置入口。它不参与具体工具逻辑。
2.  **工具容器模块**：页面中央的白色卡片区域。它是**动态的舞台**，根据当前加载的工具类型，渲染出完全不同的界面。
3.  **工具逻辑模块**：这是核心。页面通过一个 `tool` 对象来管理当前工具的所有状态。这个对象包含了：
    *   `type`：工具类型（如 `‘formula’`, `‘timer’`, `‘list’`），用于决定显示哪个UI模板。
    *   `fields/values`：对于输入型工具，定义和存储输入字段及值。
    *   `result`：存储计算结果。
    *   各种状态：如计时器的剩余时间、清单的条目列表等。
4.  **UI 模板模块**：在HTML中，有一系列用 `x-show` 控制的区块（如公式计算器、计时器、清单等）。每个模板只负责**展示**和**绑定**对应 `tool` 类型的数据，真正的**计算逻辑**和**状态管理**在背后的JavaScript函数里（如 `calculate()`, `startTimer()`）。

**输入 → 处理 → 输出 的逻辑链路：**
1.  **输入**：用户在模板的输入框（绑定到 `tool.values` 或 `tool.input`）中输入数据。
2.  **触发**：用户点击按钮（如“计算结果”），调用一个处理函数（如 `calculate(tool)`）。
3.  **处理**：该函数读取 `tool` 对象中的输入值，执行特定逻辑（数学计算、时间递减、数组操作等）。
4.  **输出**：处理函数将结果写回 `tool` 对象的某个属性（如 `tool.result`）。
5.  **渲染**：UI 模板监听到 `tool.result` 变化，自动更新显示结果区域。

**最值得学习的设计：**
**“数据驱动视图”和“配置化”思想。** 整个页面围绕一个中心化的 `tool` 数据对象运转。通过改变 `tool.type` 和对应的数据，就能切换完全不同的功能界面。这意味着，**添加一个新工具，主要工作是定义好这个工具的数据结构和对应的处理函数，然后复制修改一个UI模板即可**，页面主体框架几乎不用动。这种模式使得功能扩展非常清晰和容易。

## 【四】Prompt / AI 逻辑是如何被设计的？

> 注：在当前提供的代码中，AI功能并未在UI中直接体现，但预留了API配置界面。以下分析基于此类工具常见的模式。

1.  **Prompt 的角色**：在生成类或文本处理类工具中，Prompt 是**隐藏在后台的指令**。它告诉AI模型“扮演什么角色”以及“按照什么格式和规则生成内容”。
2.  **解决的问题**：主要是**生成问题**。例如，用户输入几个关键词，Prompt 指导AI生成一段符合要求的文案、诗歌或代码。
3.  **关键变量**：Prompt 中通常会包含用户输入的内容作为变量。例如：
    *   `{{topic}}`：用户输入的主题。
    *   `{{tone}}`：用户选择的语气。
    *   `{{length}}`：用户要求的长度。
    这些变量会在代码中被替换成真实值，然后发送给AI API。
4.  **只改 Prompt 的影响**：如果不改动代码，只修改后台的 Prompt 文本，会**彻底改变AI的“行为”和输出质量**。例如，从“生成广告文案”的Prompt改成“生成技术报告摘要”的Prompt，那么同一个输入框和按钮，就会产生完全不同类型的文本。这是调整AI应用最快速有效的方式。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地从模仿过渡到创新：

**第一步：替换内容，理解结构（最安全）**
1.  复制整个HTML文件。
2.  找到 `tool` 对象初始化的地方（在引用的 `standalone.js` 中，你需要查看或模拟它）。创建一个你自己的工具定义，例如一个 `type: ‘formula’` 的“BMI计算器”。
3.  修改 `tool.fields`，将“投资金额”换成“身高(m)”，将“月收入”换成“体重(kg)”。
4.  修改 `calculate` 函数中的计算公式，改成 `BMI = 体重 / (身高 * 身高)`。
5.  此时，你就得到了一个全新的BMI计算器，而页面布局、交互方式完全没变。

**第二步：调整交互和展示**
1.  在第一步的基础上，你觉得结果只显示一个数字太单调。
2.  你可以修改结果展示的模板，根据BMI值的范围（偏瘦、正常、超重），用不同的颜色显示结果文字。
3.  这一步你学会了如何根据数据动态改变样式。

**第三步：创造新的工具类型**
1.  你已经熟悉了“公式计算”和“清单”两种类型。
2.  现在你想做一个“抽签决定器”。你可以定义一个新的 `type: ‘lottery’`。
3.  在HTML中复制一份类似`‘list’`的模板，修改它，变成输入选项、点击按钮随机选择一个。
4.  在JS中编写对应的 `runLottery(tool)` 函数，实现随机逻辑。
5.  恭喜，你为这个工具箱添加了一个全新的工具类别。

## 【六】3–5 个可直接尝试的改造方向

1.  **为现有工具增加“历史记录”功能**：
    *   **操作**：在计算器、转换器等工具的结果区域下方，添加一个“保存本次结果”按钮。点击后将本次输入和结果组成一个对象，存入 `localStorage` 的一个数组中，并在页面下方以列表形式展示出来。
    *   **学习点**：数据持久化、数组操作、动态列表渲染。

2.  **将“清单工具”升级为“项目管理看板”**：
    *   **操作**：允许用户为清单项添加标签（如“进行中”、“已完成”、“阻塞”）。通过拖拽（可引入简单拖拽库）或点击，让项目在不同标签的列之间移动。
    *   **学习点**：状态管理、更复杂的UI交互、第三方库集成。

3.  **集成一个真正的AI小工具**：
    *   **操作**：利用设置面板中预留的API配置，创建一个 `type: ‘ai_chat’` 的工具。界面可以是一个简单的对话窗口。编写Prompt，让AI扮演一个“周报助手”，用户输入本周工作要点，AI自动生成周报草稿。
    *   **学习点**：调用外部API、异步编程、Prompt工程实践。

4.  **增加“工具收藏”和“自定义排序”功能**：
    *   **操作**：在工具箱主页面，为每个工具卡片添加一个“星标”按钮。被收藏的工具可以出现在一个单独的“常用”页面，或是在主列表置顶。排序数据保存在 `localStorage`。
    *   **学习点**：全局状态管理、用户偏好设置。

5.  **优化移动端体验**：
    *   **操作**：检查现有布局在手机上的显示。将一些多列布局（如记账工具的表单）在移动端改为单列垂直排列。为按钮增加触摸反馈（如点击时轻微变色）。
    *   **学习点**：响应式设计、移动端交互优化。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做严肃的财务管理和数据分析**：
    *   **局限性**：记账工具数据仅存在本地浏览器，容易丢失，且没有分类报表、趋势分析等功能。
    *   **替代方案**：如果需要，应使用专业的记账软件（如挖财、MoneyWiz）或电子表格。

2.  **不适合处理复杂、长篇的文档编辑**：
    *   **局限性**：笔记工具只是一个简单的文本框，没有格式（加粗、列表）、图片插入、文件夹管理等功能。
    *   **替代方案**：使用专业的笔记应用，如 Notion、Obsidian、语雀等。

3.  **不适合需要云端同步和多人协作的场景**：
    *   **局限性**：所有数据都存在本地，无法在不同设备间同步，也无法与他人共享清单或共同编辑。
    *   **替代方案**：寻找具有协作功能的在线工具，如腾讯文档、Google Sheets、Trello等。

4.  **不适合作为高精度、专业领域的计算工具**：
    *   **局限性**：其计算器功能较为基础，没有考虑复杂的税率、复利模型、工程计算等。
    *   **替代方案**：使用专业的计算器App、数学软件（如Mathematica）或行业专用软件。

**总结**：请将这个工具箱视为你的 **“数字瑞士军刀”** —— 轻便、快捷，用于处理临时性、轻量级的任务。对于更重大、更长期的工作，请选择更专业的“动力工具”。
