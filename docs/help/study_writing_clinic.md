# 写作诊所 - 学习指南

## 【一】这个网页解决了什么问题？

想象一下，你刚刚写完一篇文章、邮件或报告，不确定自己的表达是否清晰，结构是否合理。你希望有人能快速帮你看看，给出专业的修改建议，但又不想麻烦别人或付费请编辑。

**写作诊所**就是为你准备的“AI写作教练”。它能在几秒钟内：
- 分析你写作的结构逻辑
- 指出语言表达上的问题
- 提供优化后的改写示例

**适合场景：**
- 学生检查作业、论文
- 职场人士优化邮件、报告
- 内容创作者润色文章
- 非母语者学习中文表达

**不适合场景：**
- 需要深度文学创作指导（如小说情节设计）
- 需要专业领域审核（如法律文件、医学论文）
- 需要实时对话讨论
- 需要保密性极高的内容（AI会看到你的文本）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本框：粘贴或输入你想检查的写作内容
- 两个模型选择按钮：V3（标准版）和 O1（推理增强版）
- 一个API设置入口：配置你的AI密钥

**操作步骤：**
1. **粘贴内容**：将你的写作内容复制到左侧的文本框中
2. **选择模型**（可选）：点击V3或O1按钮切换AI模型
3. **点击“生成反馈”**：等待几秒钟分析
4. **查看右侧报告**：获得结构、语言、改写三方面的建议

**输出结果长什么样？**
右侧会显示一个清晰的诊断报告，分为三部分：
1. **结构反馈**：段落式的分析，指出整体结构问题
2. **语言优化**：列表形式的具体建议，每条都很简短
3. **改写示例**：展示优化后的版本，让你看到“可以怎么写”

**容易忽略的细节：**
- **API设置**：第一次使用需要点击右上角“API设置”，输入你的DeepSeek API密钥
- **模型区别**：V3响应快，适合日常检查；O1思考更深，适合复杂文本
- **内容长度**：过长的文本可能需要更长时间分析
- **JSON格式**：AI返回的是特定格式的数据，如果格式错误会显示失败

## 【三】核心结构拆解（学习重点）

这个页面由**四个核心模块**组成：

### 模块1：输入控制区（左侧）
- **职责**：接收用户输入的文本，触发分析流程
- **包含**：文本输入框 + 分析按钮 + 错误提示
- **逻辑**：用户输入 → 点击按钮 → 发送到AI → 接收结果

### 模块2：报告展示区（右侧）
- **职责**：结构化展示AI的分析结果
- **包含**：三个固定栏目（结构、语言、改写）
- **逻辑**：接收AI返回的JSON数据 → 分别填充到对应位置

### 模块3：配置管理模块
- **职责**：管理用户设置（API密钥、模型选择）
- **包含**：设置弹窗 + 本地存储功能
- **逻辑**：用户配置 → 保存到浏览器 → 后续调用时读取

### 模块4：AI通信层（隐藏但关键）
- **职责**：与DeepSeek API通信，处理请求和响应
- **包含**：在`study-shared.js`中定义的通用函数
- **逻辑**：格式化请求 → 调用API → 解析响应 → 返回数据

**最值得学习的设计：**
**“约定式数据交换”** - 页面与AI之间通过一个固定的JSON格式通信：
```json
{
  "structure": "...",
  "languageTips": ["...", "..."],
  "rewrite": "..."
}
```
这种设计让前端代码非常简单：只需要按字段名显示内容，不需要复杂的解析逻辑。如果你想做一个类似的AI工具，这是最值得模仿的模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色：**
在这个页面中，Prompt是**指令说明书**。它告诉AI：
1. 你要扮演什么角色（写作教练）
2. 你要做什么任务（诊断写作）
3. 你要以什么格式返回结果（特定的JSON结构）

**解决的是“理解问题”还是“生成问题”？**
主要是**理解问题**。AI需要理解用户的写作内容，然后按照要求的结构进行分析和反馈。虽然也有“改写示例”这种生成任务，但核心是理解原文并给出诊断。

**Prompt中的关键变量：**
1. **系统指令**：`"你是写作教练，提供结构反馈与语言优化建议。"`
2. **输出格式**：`返回 JSON：{"structure":"...","languageTips":[...],"rewrite":"..."}`
3. **用户内容**：`内容：\n${this.draft}`（这是唯一的变量部分）

**如果只改Prompt，不改代码：**
- 改系统指令：比如改成`"你是严厉的语文老师"`，AI的语气会变得严厉
- 改输出格式：比如增加`"score": "评分"`字段，页面不会显示（因为代码没改）
- 改任务描述：比如改成`"请找出错别字和语法错误"`，AI会专注于找错误

**重要提示**：Prompt和代码中的字段名必须匹配。如果Prompt返回的JSON字段名变了，页面就无法正确显示。

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 复制整个HTML结构
- 把“写作诊所”改成你的场景，比如“代码审查器”、“简历优化器”
- 修改页面标题和描述文字
- **此时先不要动JavaScript逻辑**

**第二步：调整输入字段和Prompt**
- 修改输入框的提示文字
- 重写Prompt中的系统指令和任务描述
- 保持JSON格式不变，但可以修改字段名的显示文字
- 比如代码审查：`{"issues": "问题列表", "suggestions": ["建议1", "建议2"], "fixedCode": "修复后的代码"}`

**第三步：改变输出形式或展示方式**
- 修改右侧报告区的标题和布局
- 如果字段变了，更新JavaScript中的变量名
- 可以增加新的展示元素，比如评分星级、进度条

**从哪里下手最安全？**
从**修改文字和Prompt**开始。这是零风险的：
1. 改页面上的所有中文文字
2. 改Prompt中的系统指令
3. 运行测试，确保还能正常工作
4. 然后逐步调整布局和功能

## 【六】3–5个可直接尝试的改造方向

### 1. 增加写作类型选择
**具体操作：**
- 在输入框上方添加下拉菜单：`<select>`标签
- 选项：议论文、邮件、报告、故事、诗歌等
- 根据选择修改Prompt：`"请以[类型]的标准分析以下内容..."`
- **效果**：让AI的反馈更有针对性

### 2. 添加反馈深度调节
**具体操作：**
- 增加滑块或单选按钮：简单反馈 / 详细反馈
- 修改temperature参数：简单时用0.3（更确定），详细时用0.8（更有创意）
- 或者在Prompt中说明：`"请提供[深度]级别的反馈"`
- **效果**：满足不同场景的需求

### 3. 实现多轮对话
**具体操作：**
- 将`review()`函数改为维护对话历史数组
- 每次点击“继续提问”时，将之前的对话和新的问题一起发送
- 在页面下方显示对话记录
- **效果**：可以针对AI的反馈进一步追问

### 4. 增加本地示例库
**具体操作：**
- 在页面底部添加“示例”区域
- 预置几个写作示例和对应的AI反馈
- 点击示例时自动填充输入框并触发分析
- **效果**：帮助用户理解工具能做什么，提供学习参考

### 5. 优化响应展示
**具体操作：**
- 在语言建议前添加图标：✅ 表示好，⚠️ 表示需要注意
- 让改写示例可以“一键替换”原文
- 添加“导出报告”按钮，生成PDF或Markdown
- **效果**：提升实用性和用户体验

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性说明：

1. **不是专业编辑服务**
   - AI可能错过深层的逻辑漏洞
   - 无法理解特定领域的专业知识
   - 如果写作涉及专业领域（法律、医学、学术），仍需人工审核

2. **不适合创意写作指导**
   - 无法评估故事的“感染力”或“文学价值”
   - 对于诗歌、小说等创意作品，反馈可能过于机械
   - **替代方案**：使用专门的创意写作AI工具，或加入写作社群获取真人反馈

3. **不能保证完全准确**
   - AI有时会“幻觉”（生成看似合理但错误的信息）
   - 语言建议可能不符合个人风格偏好
   - **正确态度**：把AI反馈当作“参考意见”而非“标准答案”

4. **不适合处理敏感信息**
   - 文本会发送到第三方API
   - 不要输入密码、个人信息、商业机密
   - **安全做法**：对敏感内容进行脱敏处理，或使用本地AI模型

5. **无法替代学习过程**
   - 工具能指出问题，但不能教你“为什么”
   - 长期依赖可能导致写作能力停滞
   - **健康用法**：用工具发现问题，然后通过学习和练习真正提高

**最后提醒**：这个网页是一个很好的学习起点，展示了如何将AI能力封装成简单可用的工具。当你掌握了它的设计模式后，可以创造出无数类似的“AI小助手”，解决各种特定场景的问题。
