# 深度用户画像与痛点挖掘机 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你有一个产品（或服务）的想法，但不确定“谁会买它”以及“他们为什么需要它”时，这个工具能帮你快速、深入地描绘出几类潜在用户的完整画像。它特别适合产品经理、市场运营、创业者或内容创作者，在产品早期构思、营销文案策划或用户调研阶段，快速获得用户洞察。

*   **适合什么情况？**
    *   **产品创意阶段**：你有一个模糊的产品概念，想看看它可能吸引哪些人。
    *   **营销策划前**：你需要为广告、推文或销售页面找到能打动不同人群的“痛点”和“爽点”。
    *   **团队脑暴**：作为讨论的起点，激发团队对目标用户更具体的想象。
*   **不适合什么情况？**
    *   **替代真实用户调研**：它生成的是基于AI推理的“假设画像”，不能替代真实的用户访谈、问卷或数据分析。
    *   **精确的市场细分**：它无法提供基于大数据（如地域、收入、消费行为）的精准人群划分。
    *   **已有明确用户数据**：如果你已经通过问卷或访谈收集了大量用户反馈，直接分析那些数据会更可靠。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **产品/服务名称**：你的产品叫什么？（必填）
    *   **核心卖点/功能**：它最主要的功能或好处是什么？
    *   **大致目标人群**：你心里大概觉得谁会用它？（可选）

2.  **用户通常会做哪几步操作？**
    1.  在左侧面板依次填写上述三个信息。
    2.  点击页面顶部的模型切换按钮，选择 **“Reasoner (R1)”**（推荐，思考更深）。
    3.  点击蓝色的 **“🚀 开始深度挖掘”** 按钮。
    4.  等待片刻（R1模型思考时间可能较长），右侧会生成3-4个用户画像卡片。
    5.  浏览结果，可以点击 **“复制全部”** 或 **“导出 Markdown”** 保存分析报告。

3.  **输出结果长什么样？**
    右侧会以卡片网格的形式展示生成的用户画像。每张卡片包含：
    *   **画像名称**（如“焦虑的颈椎自救者”）
    *   **基础信息**（年龄、职业）
    *   **典型场景**：一段第一人称描述，描绘用户遇到问题的具体时刻。
    *   **核心痛点与焦虑**：3个深层的心理或生活困扰。
    *   **爽点与期望**：3个使用产品后希望获得的心理满足。
    *   **文案切入角度**：一句针对该画像的营销文案策略。

4.  **有哪些容易忽略的使用细节？**
    *   **首次使用需配置API**：点击右上角 **“API 设置”**，填入你的DeepSeek API Key（需自行申请），Key会保存在你的浏览器本地。
    *   **模型选择**：默认的“Reasoner (R1)”模型推理更深，但速度慢；“Chat (V3)”模型更快，但分析可能较浅。根据你对深度和速度的需求选择。
    *   **“目标人群”字段是提示**：填写它可以帮助AI缩小范围，但不填AI也会基于产品名称和卖点自行推断。
    *   **结果可能不稳定**：AI每次生成的结果会有差异，如果对某次结果不满意，可以调整输入信息或重新生成。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“输入-处理-输出”** 左右分栏结构，由以下几个关键模块组成：

1.  **控制与配置模块（顶部导航栏）**
    *   **职责**：提供全局控制（模型切换）和系统配置（API设置入口）。
    *   **设计亮点**：将模型选择这种高级选项放在显眼但非核心操作区，不影响主流程。

2.  **输入采集模块（左侧面板）**
    *   **职责**：以表单形式收集用户提供的产品信息。这是整个应用的“燃料”。
    *   **设计亮点**：表单设计简洁，必填项明确，并提供了友好的占位符提示。底部有状态栏，实时反馈API连接状态。

3.  **AI处理引擎（核心逻辑，不可见）**
    *   **职责**：将用户输入拼接成一个结构化的 **Prompt（指令）**，调用DeepSeek API，并处理返回的JSON数据。
    *   **逻辑链路**：`用户输入` → `拼接为Prompt` → `调用API` → `解析并清洗JSON` → `格式化数据`。
    *   **最值得学习的设计**：**对AI输出格式的强约束**。通过精心设计的Prompt和API的`response_format: { type: 'json_object' }`参数，强制AI返回结构化的JSON数据，极大简化了前端数据处理难度。同时，代码中还包含了对返回JSON的“容错处理”（如清理Markdown标记、尝试修复引号），提升了健壮性。

4.  **结果展示模块（右侧主区域）**
    *   **职责**：将AI返回的结构化数据，以美观、易读的卡片形式可视化呈现。
    *   **设计亮点**：
        *   **空状态/加载状态设计**：在无结果和生成中提供了友好的图形和文案提示，提升体验。
        *   **信息分层与视觉编码**：使用不同的图标、颜色和标题样式（如红色代表痛点，绿色代表爽点），让用户快速抓取每类信息的重点。
        *   **可操作的结果**：提供“复制”和“导出”功能，让分析结果能立刻用于其他工作。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色**：它是连接“用户输入”和“AI能力”的**翻译器**和**任务指挥官**。它告诉AI：“请以某种特定角色，按照某个特定格式，完成某个特定任务。”
2.  **解决什么问题**：它主要解决 **“生成问题”**。即，根据有限的产品信息，生成丰富、具体、符合商业分析逻辑的用户画像内容。
3.  **Prompt中的关键变量**：
    *   **角色设定**：`“顶级市场策略专家和心理学家”` – 赋予AI专业的分析视角。
    *   **任务要求**：强调`“深度”、“具体”、“差异化”`，并特别要求`“挖掘内心深处的焦虑、恐惧”`和`“模拟具体时刻”`，这是获得高质量画像的关键。
    *   **结构化输出格式**：详细定义了JSON中每个字段（`name`, `age`, `scenario`, `painPoints`等）的含义和示例。这是保证前端能顺利解析数据的**基石**。
    *   **用户输入变量**：`${input.productName}`, `${input.sellingPoints}` 等，将网页表单内容动态插入Prompt。
4.  **如果只改Prompt，不改代码，会发生什么？**
    *   **改变分析维度**：例如，在Prompt中要求增加“购买阻力”或“社交媒体使用习惯”字段，AI就会在JSON中生成这些新内容，但前端页面不会显示它们（因为代码没改）。
    *   **改变分析风格**：例如，将角色从“市场专家”改为“小说家”，AI生成的画像描述会更具故事性和文学色彩。
    *   **改变输出结构**：如果大幅修改JSON结构（如更改字段名），前端代码将无法正确解析，导致页面出错或显示异常。**因此，Prompt中关于输出格式的约定必须与前端解析代码严格匹配。**

## 【五】如何模仿它，做出你自己的版本？

如果你想做一个类似的分析工具，但主题不同（例如“短视频脚本灵感生成器”、“健身计划生成器”），可以遵循以下安全路径：

1.  **第一步：保持结构不变，替换使用场景**
    *   **做什么**：完全保留现有的页面布局、样式和交互逻辑（左右分栏、表单、卡片展示）。
    *   **改什么**：
        *   修改网页标题和说明文字（如改为“短视频脚本痛点挖掘机”）。
        *   修改左侧输入表单的标签和占位符（如将“产品名称”改为“视频主题”， “核心卖点”改为“想传达的核心信息”）。
    *   **效果**：你得到了一个外观和交互完全一样，但主题不同的新工具框架。

2.  **第二步：调整输入字段与核心Prompt**
    *   **做什么**：这是**最核心的一步**。你需要重新设计AI要完成的任务。
    *   **改什么**：
        *   **深入修改Prompt**：重新编写 `generatePersonas` 函数中的 `prompt` 变量。明确你的新角色（如“资深短视频编剧”）、新任务（如“生成3个能引发共鸣的短视频脚本创意”）、以及**全新的、结构化的输出格式**（例如，输出包含 `scriptTitle`, `targetPlatform`, `coreEmotion`, `sceneBreakdown` 等字段的JSON）。
    *   **效果**：AI开始为你新的主题服务，并按照你定义的格式生成内容。

3.  **第三步：改变输出形式或展示方式**
    *   **做什么**：让前端页面能够展示你新Prompt生成的新数据结构。
    *   **改什么**：
        *   修改结果展示区的模板（HTML部分）。将 `v-for="(persona, index) in personas"` 循环中的内容，替换为展示你新JSON字段的HTML元素（如显示 `scriptTitle`, `sceneBreakdown`）。
        *   相应地调整“复制全部”和“导出”函数，以处理新的数据结构。
    *   **效果**：一个功能完整、主题全新的AI工具就诞生了。

**从哪里下手最安全？** 从 **第一步** 开始。先只改文字和标签，确保页面能正常运行。然后进入 **第二步**，精心设计你的Prompt和输出格式，并用浏览器控制台测试API返回的数据是否合规。最后做 **第三步**，调整前端展示。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，使画像更精准**
    *   **操作**：在左侧表单增加“价格区间”、“主要竞品”等字段。将这些信息加入Prompt中，AI生成的画像会对价格敏感度、选择理由有更具体的描述。
    *   **价值**：输入信息越丰富，AI的推理基础越扎实，产出越具参考性。

2.  **切换或增加模型/API提供商**
    *   **操作**：在顶部导航栏增加一个下拉菜单，除了DeepSeek，允许选择OpenAI的GPT-4o、Claude 3.5等。在 `generatePersonas` 函数中根据选择调用不同的API端点。
    *   **价值**：不同模型的分析风格和侧重点不同，为用户提供对比选择，也能作为模型效果的测试平台。

3.  **将单次分析变为多步骤对话**
    *   **操作**：生成画像后，在每个卡片下方增加一个“追问”按钮。点击后，可以针对这个特定画像向AI提问（如“请为这个用户设计一个典型的一天日程”）。这需要将页面结构改为聊天式，并维护对话历史。
    *   **价值**：实现交互式深度挖掘，用户可以根据初步结果进行聚焦探索。

4.  **优化交互与体验**
    *   **操作**：
        *   **历史记录**：将每次的分析结果（输入和输出）保存在浏览器的 `localStorage` 中，在左侧增加一个历史记录面板，方便回溯和对比。
        *   **手动编辑**：允许用户对生成的画像卡片进行微调（点击编辑修改文字），让AI生成的结果成为可打磨的草稿。
    *   **价值**：工具从“一次性使用”变为“可积累、可迭代”的工作伴侣，实用性大增。

5.  **拆解为引导式多页面流程**
    *   **操作**：将当前的单页应用拆成几个步骤页：① 输入产品信息 → ② 选择分析维度（如侧重心理、侧重消费行为）→ ③ 查看并优化结果。每一步都更专注。
    *   **价值**：降低初次使用者的认知负担，通过流程引导用户提供更有效的信息，也便于在未来扩展更复杂的功能。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做真实的用户验证**：这些画像是AI基于模式和概率“想象”出来的，可能遗漏真实世界中重要的用户群体，或者其痛点并不真实存在。**它提供的是“假设”，而非“事实”**。
*   **不适合做数据驱动的精细决策**：它无法提供“25-30岁女性用户占比35%”这类量化数据。如果你需要决定生产规模、定价策略或渠道投放，必须依赖市场报告、电商平台数据或A/B测试等量化工具。
*   **不适合生成可直接使用的最终文案**：它提供的“文案切入角度”是策略和方向，通常比较笼统或模板化。优秀的营销文案需要结合品牌调性、具体媒介和创意打磨，不能直接照搬AI的初稿。
*   **如果用户想做X，应该换什么工具？**
    *   **想做定量市场调研**：使用问卷工具（如腾讯问卷、问卷星）或用户行为分析平台（如Google Analytics, Mixpanel）。
    *   **想获得真实的用户反馈**：进行用户访谈（可线下或通过视频会议），或使用可用性测试工具（如UserTesting）。
    *   **想生成可直接发布的营销素材**：可以将本工具生成的“切入点”作为Brief（需求简报），输入到更专业的AI文案工具（如ChatGPT、Notion AI）中进行扩写和润色。
