# 数据微信号实验室 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你有一串数字（比如每天的销售额、用户活跃度、温度变化等），你想知道这些数字背后隐藏着什么规律。这些规律可能很微弱，不容易一眼看出来。这个网页就像一个“数字侦探”，帮你分析这些数据序列，找出其中可能存在的微弱趋势，并给出实用的建议。

**适合的使用场景：**
- 你有一组连续的数据点，想快速了解整体趋势
- 你需要对数据变化进行初步解读，但不想使用复杂的统计软件
- 你想获得一些基于数据的行动建议灵感
- 适合分析10-30个数据点的简单序列

**不适合的情况：**
- 需要精确的统计分析（如P值、置信区间）
- 处理大量数据（超过100个点）
- 需要实时数据更新或自动化分析
- 涉及敏感或机密数据（数据会发送到外部AI服务）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本框，里面默认有一串用逗号分隔的数字（如：12,14,13,18...）
- 你可以直接修改这些数字，或者清空后输入自己的数据

**用户通常会做哪几步操作？**
1. **准备数据**：将你的数据整理成逗号分隔的形式（例如：`10,12,15,14,18`）
2. **粘贴或输入**：把数据粘贴到左侧的文本框中
3. **点击分析**：按下“分析信号”按钮
4. **查看结果**：左侧会显示数据折线图，右侧会显示AI的解读和建议

**输出结果长什么样？**
- **左侧**：一个简洁的折线图，直观展示你输入的数据走势
- **右侧**：一段文字分析，通常包括：
  - 对整体趋势的判断（上升、下降、波动等）
  - 对“微弱信号”的识别（如“第4-6个点有轻微上升趋势”）
  - 2-3条具体的行动建议

**容易忽略的使用细节：**
1. **必须先配置API**：第一次使用时，需要点击右上角的设置按钮，输入你的DeepSeek API密钥
2. **数据格式要正确**：数字之间用逗号分隔，不要有空格以外的其他字符
3. **等待时间**：点击分析后需要等待几秒钟，按钮会变灰，不要重复点击
4. **数据隐私**：你的数据会被发送到AI服务进行处理，不要输入敏感信息

## 【三】核心结构拆解（学习重点）

这个页面由三个主要模块组成：

**1. 数据输入与可视化模块（左侧卡片）**
- **职责**：接收用户输入、验证数据格式、绘制图表
- **输入**：用户输入的逗号分隔数字
- **处理**：将字符串分割为数字数组，用Chart.js绘制折线图
- **输出**：一个交互式折线图

**2. AI解读模块（右侧卡片）**
- **职责**：调用AI服务、显示分析结果
- **输入**：从左侧模块获取的数字数组
- **处理**：构建Prompt、调用DeepSeek API、接收AI回复
- **输出**：格式化的文字分析和建议

**3. 配置管理模块（设置弹窗）**
- **职责**：管理API密钥和模型选择、保存用户配置
- **输入**：用户输入的API密钥和模型选择
- **处理**：将配置保存到浏览器的localStorage
- **输出**：持久化的配置信息

**逻辑链路：**
```
用户输入数据 → 分割为数字数组 → 同时进行：
    1. 绘制折线图（前端完成）
    2. 构建Prompt → 调用AI API → 接收回复 → 显示分析
```

**最值得学习的设计：**
**“最小可行产品”的架构思路**。整个页面只做一件事（分析数据趋势），但做得完整：
- 有美观的可视化（Chart.js）
- 有智能分析（AI集成）
- 有配置管理（localStorage）
- 有错误处理
- 所有功能在一个页面内完成，没有复杂的路由

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接“原始数据”和“有用分析”的翻译器。它告诉AI：“这是一串数字，请用数据策略师的视角，找出微弱趋势并给出建议。”

**它解决的是“理解问题”还是“生成问题”？**
主要是“生成问题”。AI已经具备数据分析能力，Prompt的作用是：
1. **限定角色**：“你是数据策略师”——让AI用专业视角回答
2. **明确任务**：“指出微弱趋势，给出2条建议”——具体可执行
3. **提供上下文**：“数据序列：[数字]”——给AI需要分析的材料

**Prompt中的关键变量：**
```javascript
`数据序列：${values.join(', ')}\n请指出是否存在微弱趋势，并给出 2 条建议。`
```
- `values.join(', ')`：这是唯一的变量，即用户输入的数字
- 其他部分都是固定的指令模板

**如果只改Prompt，不改代码，会发生什么变化？**
- 改角色：`“你是金融分析师”` → AI会用投资视角分析
- 改任务：`“预测下一个值”` → AI会尝试预测
- 改格式：`“用表格形式列出”` → AI会输出表格
- 改风格：`“用通俗易懂的语言解释”` → 回答会更简单

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改标题和描述
- 例如：改为“情绪日记分析器”、“运动数据追踪器”
- 代码只需修改HTML中的文字部分

**第二步：调整输入字段或Prompt**
- 改输入框提示：`placeholder="输入数据，逗号分隔"` → `placeholder="输入每天的心情分数，1-10分"`
- 改Prompt：`“数据序列：${values}...给出2条建议”` → `“心情分数序列：${values}...分析情绪波动原因”`
- 这是最核心的个性化步骤

**第三步：改变输出形式或展示方式**
- 改图表颜色：`borderColor: '#334155'` → 换成其他颜色
- 改AI回复区域样式：`bg-slate-50` → 其他背景色
- 可以增加“复制结果”按钮等小功能

**从哪里下手最安全？**
从**修改Prompt**开始最安全。因为：
1. 不需要改JavaScript逻辑
2. 立即能看到效果变化
3. 不会破坏现有功能
4. 可以快速测试不同场景

## 【六】3–5个可直接尝试的改造方向

**1. 增加数据上下文输入**
```html
<!-- 在文本输入框下方添加 -->
<div class="mt-3">
    <label class="block text-sm text-slate-600 mb-1">数据说明（可选）</label>
    <input v-model="dataContext" placeholder="例如：这是过去10天的销售额" class="w-full border rounded-lg px-3 py-2">
</div>
```
然后在Prompt中加入这个上下文：`“这是${dataContext}，数据序列：${values}...”`

**2. 切换不同的AI服务**
- 将DeepSeek API换成OpenAI、Claude或智谱AI
- 只需修改`callLLM`函数中的API端点、headers和请求格式
- 可以做成下拉选择，让用户自己选用哪个AI

**3. 拆分为“分析”和“建议”两个步骤**
- 第一步：只分析趋势（快速）
- 第二步：基于趋势生成详细建议（需要时再点）
- 这样可以减少单次API调用时间，提升体验

**4. 增加数据预处理选项**
```html
<select v-model="preprocessType" class="border rounded-lg px-3 py-2">
    <option value="raw">原始数据</option>
    <option value="diff">差值分析</option>
    <option value="moving_avg">移动平均</option>
</select>
```
在发送给AI前，先对数据进行简单处理

**5. 保存历史记录**
- 每次分析后，将“数据+结果”保存到localStorage
- 添加一个“历史记录”侧边栏
- 用户可以回顾之前的分析

## 【七】这个网页不适合做什么？（边界提醒）

**1. 不适合做精确的统计分析**
- 不能计算标准差、相关系数等统计指标
- 不能进行假设检验或回归分析
- **替代方案**：使用Excel、Python的pandas、或专业统计软件

**2. 不适合处理实时或流数据**
- 每次都需要手动输入/粘贴
- 没有定时自动更新的功能
- **替代方案**：搭建后端服务，连接数据库，设置定时任务

**3. 不适合分析复杂多维数据**
- 只能处理一维数据序列
- 不能分析多个变量之间的关系
- **替代方案**：使用Tableau、Power BI等多维分析工具

**4. 不适合生产环境或团队协作**
- 配置保存在个人浏览器中
- 没有用户管理系统
- 没有版本控制
- **替代方案**：开发完整的Web应用，包含后端和数据库

**5. 不适合处理敏感数据**
- 数据会发送到第三方AI服务
- 没有加密传输（虽然HTTPS是加密的，但数据内容AI服务商可见）
- **替代方案**：使用本地AI模型（如Ollama）或确保数据已脱敏
