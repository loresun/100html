# 竞品内容抓取与策略对比器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
假设你是一个内容创作者、新媒体运营或产品经理，正在研究竞争对手的内容策略。你手动收集了对方在社交媒体（如小红书、抖音）上发布的几十条内容，包括标题、点赞数、评论数和摘要。面对这些零散的信息，你很难快速看出规律：哪些主题最受欢迎？他们用了哪些吸引人的“钩子”（开头技巧）？情绪基调是什么？这个网页就是帮你从一堆数据中，自动提炼出清晰的策略地图。

**适合情况：**
- 你需要快速分析一个账号或一个赛道的内容模式。
- 你手头有结构化的文本数据（标题+摘要+互动数据）。
- 你想获得可操作的内容创作建议，而不是单纯的数据统计。

**不适合情况：**
- 你需要分析图片、视频本身的内容（本工具只处理文本摘要）。
- 你需要实时监控竞品动态（这是爬虫和监控工具的工作）。
- 你的数据量极大（成千上万条），更适合用专业的数据分析工具。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **竞品名称**：你正在研究的对象，比如“健身博主小A”。
2.  **竞品内容列表**：核心输入区。你需要按照提示的格式，一行一条地粘贴竞品内容。格式是：`标题 | 点赞数 | 评论数 | 内容摘要`。
3.  **分析目标**：你这次分析的具体目的，比如“找出爆款标题的共性”。
4.  **主要平台**：内容来源的平台，如“小红书”。

**用户通常会做哪几步操作？**
1.  **准备数据**：从目标竞品的主页，手动复制或整理出至少6条以上的内容，整理成要求的格式。
2.  **填写表单**：将整理好的数据粘贴到“竞品内容列表”文本框中，并填写其他可选信息。
3.  **首次设置**：点击“生成内容策略地图”按钮，如果首次使用，会弹出设置窗口，要求你输入DeepSeek的API Key。
4.  **获取分析**：点击按钮后等待几秒到几十秒，右侧面板就会生成分析结果。
5.  **查看与复制**：浏览生成的主题聚类、策略矩阵和机会提示，可以使用“复制摘要”按钮保存关键结论。

**输出结果长什么样？**
结果分为三个清晰的部分：
- **主题聚类**：将你输入的内容自动归纳成几个核心主题（如“减脂食谱”、“居家训练”），每个主题会标注其热度、常用的钩子类型（如“悬念式”、“利益点明式”）和情绪类型（如“励志”、“轻松”）。
- **内容策略矩阵**：将内容划分为不同的策略区块（如“高互动生活分享”、“知识干货型”），评估其表现，并给出具体的“建议钩子”。
- **机会区间提示**：以列表形式给出几条具体的行动建议，比如“可以尝试结合‘痛点场景+专业背书’的钩子”。

**有哪些容易忽略的使用细节？**
- **格式中的竖线 `|`**：在粘贴内容时，必须用英文的竖线 `|` 分隔标题、点赞、评论和摘要，这是AI正确解析数据的关键。
- **互动数据不是必须的**：如果某些内容没有点赞或评论数据，可以留空或写“0”，但格式中的 `|` 分隔符不能少。
- **API Key保存**：输入的API Key会保存在你当前浏览器的本地，换浏览器或清除数据后需要重新设置。
- **模型选择**：顶部可以选择“DeepSeek Chat”或“DeepSeek Reasoner”，后者思考更深但可能更慢，初次使用默认即可。

## 【三】核心结构拆解（学习重点）

这个页面可以看作一个 **“文本分析流水线”** ，由三个核心模块组成：

1.  **输入与配置模块（左侧面板）**
    - **职责**：收集用户的所有原始输入（竞品数据、分析目标）和系统配置（API密钥、模型选择）。
    - **关键设计**：使用一个多行文本框作为核心数据入口，通过格式提示引导用户输入结构化数据。配置信息通过一个弹窗（Modal）管理，保持界面简洁。

2.  **AI处理引擎（不可见，但最关键）**
    - **职责**：这是整个应用的大脑。它接收左侧模块整理好的文本，调用DeepSeek API，按照预设的“分析专家”角色和严格的输出格式要求进行思考和分析。
    - **逻辑链路**：`用户输入文本` -> `拼接成特定格式的Prompt` -> `发送给AI API` -> `接收并解析AI返回的JSON数据`。

3.  **结果展示模块（右侧面板）**
    - **职责**：将AI返回的、结构化的JSON数据，以清晰、可视化的方式渲染出来，分为“主题聚类”、“策略矩阵”、“机会区间”三个维度。
    - **关键设计**：使用卡片（Card）式布局展示每个聚类和策略项，用标签（Tag）和徽章（Badge）直观显示“热度”、“钩子类型”等属性，信息密度高且易读。

**最值得学习的设计：**
**“结构化输入引导结构化输出”的闭环设计。** 整个应用的精髓在于：
- 前端通过一个简单的文本框和格式示例，引导用户输入**半结构化**数据。
- 后端（AI Prompt）则明确要求AI输出**完全结构化**的JSON数据。
- 前端再根据这个固定的JSON结构，渲染出美观的界面。
这种设计将复杂的自然语言分析任务，变成了一个稳定、可预测的数据处理流程，极大地降低了开发和使用难度。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt在这里扮演了 **“分析框架”和“输出规范”** 的双重角色。它不仅仅是一个问题，而是为AI定义了一个完整的分析任务、角色身份和必须遵守的答卷格式。

**它解决的是“理解问题”还是“生成问题”？**
主要是 **“生成问题”** ，但生成的前提是深度理解。AI需要先理解用户输入的一堆零散内容，然后根据Prompt的指导，进行归纳、分类、评估，最后生成全新的、结构化的策略分析报告。

**哪些信息是 Prompt 中的关键变量？**
Prompt由两部分组成，其中用户输入的内容是关键变量：
- **System Prompt（系统指令）**：固定不变，定义了AI的**角色**（新媒体策略分析专家）和**输出格式**（一个包含`theme_clusters`、`strategy_matrix`、`opportunity_zones`的JSON对象）。
- **User Prompt（用户指令）**：是动态的，包含了所有用户输入的变量：`竞品名称`、`主要平台`、`分析目标`，以及最核心的`竞品内容列表`。

**如果只改 Prompt，不改代码，会发生什么变化？**
你可以彻底改变这个工具的分析方向和输出内容。例如：
- 将System Prompt中的“新媒体策略分析专家”改为“短视频脚本分析师”，并修改JSON格式要求输出“脚本结构”、“节奏建议”等字段，这个工具就变成了“脚本分析器”。
- 在User Prompt中加入“目标受众：Z世代”，AI的分析侧重点就会向年轻人的偏好倾斜。
- **注意**：如果你改变了System Prompt中定义的JSON结构（比如新增或删减字段），前端的展示代码会因为找不到对应字段而报错或显示不全。所以改Prompt时，通常需要同步调整前端展示逻辑。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“三步替换法”，安全地创建一个属于你的分析工具：

**第一步：替换核心场景与输入（最安全）**
保持整体布局和代码结构完全不变。只修改以下内容：
- **标题和描述**：将“竞品内容分析”改为你的场景，如“用户反馈分析”、“新闻热点归类”。
- **输入字段的标签和提示文案**：将“竞品名称”改为“产品名称”，“竞品内容列表”改为“用户反馈列表”，并更新文本框内的示例格式。

**第二步：重写Prompt以匹配新场景**
这是核心的一步。在`runAnalysis`函数中，找到`systemPrompt`和`userPrompt`。
- 在`systemPrompt`中，修改AI的角色和任务描述。例如，从“新媒体策略分析专家”改为“用户洞察分析师”。
- **关键**：根据新任务，重新设计`systemPrompt`中要求AI返回的**JSON格式**。比如，输出字段可以改为`“主要诉求”`、`“情感倾向”`、`“功能建议”`等。

**第三步：调整结果展示面板**
根据第二步中设计的新JSON格式，修改右侧结果展示的模板（即HTML中`v-if="result"`后面的部分）。将显示“主题聚类”的代码块，改为渲染你新定义的字段，如“诉求分类”。

按照这个路径，你可以在不触碰复杂的JS逻辑（如API调用、数据流）的情况下，快速得到一个全新的工具。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加数据输入维度**：
    - **操作**：在输入区增加“发布时间”、“视频时长”或“话题标签”等字段，并在示例格式中体现（如`标题 | 点赞 | 评论 | 标签 | 摘要`）。
    - **效果**：让AI的分析维度更丰富，例如可以分析“哪种标签组合流量更高”或“最佳发布时间段”。

2.  **本地缓存与历史记录**：
    - **操作**：使用浏览器的`localStorage`，在用户点击分析后，不仅保存结果，还把当次的输入内容一起保存。在页面侧边或底部增加一个“历史分析”下拉列表。
    - **效果**：用户可以方便地回顾和对比多次分析结果，提升工具实用性。

3.  **切换或融合多个AI模型**：
    - **操作**：在API设置中，增加对OpenAI GPT、Claude或国产大模型（如通义千问）的支持。甚至可以设计一个流程，用A模型做聚类，用B模型做策略生成。
    - **效果**：对比不同模型的分析效果，或利用不同模型的专长，获得更优结果。

4.  **优化交互：分步引导与实时验证**：
    - **操作**：将当前的一次性输入，改为分步引导。第一步只让用户粘贴数据，并提供一个“格式检查”按钮，用简单的JS规则验证格式是否正确（如检查每行是否包含3个`|`），给出即时反馈。
    - **效果**：大幅降低用户因格式错误导致分析失败的概率，体验更友好。

5.  **输出形式多样化**：
    - **操作**：在结果区域增加选项卡或按钮，允许用户将结果以“思维导图”、“SWOT分析图”或“简单的PPT大纲”等不同形式查看或导出。
    - **效果**：满足用户不同场景下的汇报或脑暴需求，工具价值更高。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合做精确的数据统计与可视化**：它给出的“热度高/中/低”是AI的定性判断，而非精确的数学计算。如果你需要生成点赞数的趋势图、评论率的精确对比，应该使用Excel、Tableau或专门的数据分析库（如ECharts）。
- **不适合处理非文本的原始内容**：它无法“看懂”你输入的图片或视频链接。它的分析完全基于你提供的**文字摘要**。如果你想让AI直接分析视频字幕或图片描述，需要先通过其他工具（如语音转文字、图像识别API）提取文本，再将文本输入本工具。
- **不适合作为全自动的竞品监控系统**：这是一个**手动分析工具**。你需要自己收集数据并粘贴进来。它不能自动去小红书、抖音抓取竞品的最新内容。实现自动化监控需要复杂的爬虫、反爬和定时任务系统，与本工具的设计目标不同。
- **不适合进行深度财务或风险预测**：它的分析局限于内容策略层面，给出的“机会”是基于文本模式的推理。对于涉及市场风险、投资回报等需要严谨数据和专业模型的决策，请寻求更专业的商业分析工具或咨询。
