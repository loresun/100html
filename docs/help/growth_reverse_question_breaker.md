# 逆向问题拆解器 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，当你面对一个难题时，思维常常会陷入固定的模式。比如“如何提高工作效率？”这个问题，你可能会反复思考时间管理、工具使用等常规方法。这个网页的作用就是帮你“换个角度看问题”。

**使用场景举例：**
- 当你对某个问题感到“卡住”时，想寻找新的思考角度
- 在头脑风暴中需要激发创意，打破常规思维
- 作为个人反思工具，挑战自己的固有假设
- 在团队讨论中引入不同的视角

**适合的情况：**
- 需要创意突破的开放式问题
- 个人或团队的思维热身
- 想要验证问题本身是否问对了

**不适合的情况：**
- 需要具体执行步骤的实操问题
- 有标准答案的技术性问题
- 紧急需要解决方案的危机处理

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 页面中央有一个输入框，默认显示“如何让我的工作更高效？”
- 你需要在这里输入任何你想重新思考的问题

**用户通常会做哪几步操作？**
1. **配置API**：首次使用时，点击右上角的齿轮图标，输入你的DeepSeek API Key
2. **输入问题**：在输入框中写下你的困惑或挑战
3. **点击生成**：按下“生成逆向问题”按钮
4. **查看结果**：等待几秒钟，页面下方会显示5个逆向提问

**输出结果长什么样？**
- 结果以卡片形式展示，每张卡片标有“反向视角 1”、“反向视角 2”等
- 每个逆向问题都是对原问题的“翻转”，例如原问题是“如何提高销量？”，逆向问题可能是“如何让销量下降得更快？”
- 每个问题都很简短，不超过20个字

**容易忽略的使用细节：**
1. **API配置是必须的**：不配置API Key，点击生成会提示错误
2. **问题要具体**：过于宽泛的问题（如“人生意义？”）可能得不到有用的逆向提问
3. **可以修改默认问题**：直接覆盖输入框中的文字即可
4. **结果可以反复生成**：同一个问题每次可能得到不同的逆向视角

## 【三】核心结构拆解（学习重点）

这个页面由四个关键模块组成：

**1. 用户输入模块**
- **位置**：页面中央的输入框和按钮
- **职责**：收集用户的问题，触发逆向提问生成
- **输入**：用户输入的任何文本问题
- **输出**：传递给AI处理的问题字符串

**2. AI处理模块**
- **位置**：隐藏在代码中的`callLLM`函数
- **职责**：将用户问题包装成Prompt，调用DeepSeek API
- **输入**：格式化后的Prompt
- **输出**：AI返回的文本结果

**3. 结果展示模块**
- **位置**：输入框下方的卡片区域
- **职责**：将AI返回的文本解析并美观地展示
- **输入**：AI返回的原始文本
- **输出**：格式化的5个逆向问题卡片

**4. 配置管理模块**
- **位置**：点击齿轮图标弹出的设置窗口
- **职责**：管理API Key和模型选择，保存到本地
- **输入**：用户输入的API配置
- **输出**：保存到浏览器本地存储的配置数据

**逻辑链路：**
```
用户输入问题 → 点击生成按钮 → 检查API配置 → 构建Prompt → 调用AI API → 
解析AI回复 → 清理格式 → 显示为卡片
```

**最值得学习的设计：**
- **“一键式”交互**：整个复杂过程被简化为“输入→点击→查看”
- **本地存储配置**：API Key只需输入一次，下次访问自动加载
- **渐进式反馈**：加载状态、错误提示都很清晰
- **视觉层次分明**：输入区、按钮、结果区有明显的视觉区分

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色：**
Prompt是连接用户问题和AI能力的“翻译官”。它告诉AI：“用户给了我这个原始问题，请你用逆向思维的方式重新提问。”

**解决的是“理解问题”还是“生成问题”？**
主要是“生成问题”。AI不是解释用户的问题，而是基于用户问题**创造新的问题**。

**Prompt中的关键变量：**
```javascript
`问题：${question.value}\n\n请输出 5 条逆向提问，每条不超过 20 字，直接列表输出。`
```
- **`${question.value}`**：这是唯一的变量，即用户输入的问题
- **“5条”**：控制输出数量
- **“不超过20字”**：控制输出长度
- **“直接列表输出”**：控制输出格式，便于后续解析

**如果只改Prompt，不改代码，会发生什么变化？**
1. 改“5条”为“3条”→结果卡片减少到3个
2. 改“逆向提问”为“类比提问”→AI会给出类比式问题
3. 改“不超过20字”为“详细阐述”→结果会变成长段落
4. 改“直接列表输出”为“用JSON格式输出”→代码解析会出错（因为代码是按行解析的）

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景（最安全）**
- 修改标题和描述，比如改成“创意类比生成器”
- 修改Prompt中的“逆向提问”为“创意类比”
- 保持所有代码结构不变，只改文字和Prompt

**第二步：调整输入字段或Prompt**
- 增加一个下拉菜单，让用户选择“逆向程度”：轻度翻转/彻底反转
- 在Prompt中加入这个选择：`请根据${degree}程度生成逆向提问`
- 这需要修改HTML（增加下拉框）和JS（读取下拉框值）

**第三步：改变输出形式或展示方式**
- 将卡片式展示改为思维导图式
- 或者增加“收藏”功能，让用户可以保存喜欢的逆向问题
- 这需要较大的前端改动，但核心AI调用逻辑可以保留

**从哪里下手最安全？**
从**修改Prompt文本**开始。这是零风险、立即见效的改动。比如把“逆向提问”改成“三个完全不同的角度”，就能立刻改变整个工具的功能。

## 【六】3–5个可直接尝试的改造方向

**1. 增加问题类型选择**
- **操作**：在输入框上方增加单选按钮：“逆向提问”/“类比提问”/“极端提问”
- **效果**：用户可以选择不同的思维工具
- **代码改动**：增加HTML单选组，在Prompt中根据选择调整指令

**2. 替换为其他AI模型**
- **操作**：在设置中增加OpenAI、Claude等选项
- **效果**：可以对比不同模型的创意能力
- **代码改动**：修改`callLLM`函数，根据选择调用不同API端点

**3. 增加结果交互功能**
- **操作**：在每个结果卡片上增加“展开分析”按钮
- **效果**：点击后，用这个逆向问题再次询问AI，得到详细分析
- **代码改动**：给卡片增加点击事件，用逆向问题作为新Prompt调用AI

**4. 拆分为引导式多页面**
- **操作**：第一页输入问题，第二页选择思维模式，第三页查看结果
- **效果**：更适合复杂的思维工具组合
- **代码改动**：用Vue的条件渲染显示不同页面，或直接拆成多个HTML文件

**5. 优化为团队协作工具**
- **操作**：增加“分享结果”功能，生成可分享的链接
- **效果**：团队可以共同讨论逆向问题
- **代码改动**：将结果编码到URL参数中，或连接后端保存会话

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不提供解决方案**：它只生成新问题，不回答这些问题
2. **依赖AI创意**：如果AI当天“没创意”，结果可能不理想
3. **无法深度分析**：每个问题只有20字，无法展开复杂思考
4. **没有记忆功能**：每次都是独立会话，无法基于历史优化

**如果用户想做X，应该换什么工具：**

**如果你想得到具体解决方案：**
- 应该使用“问题解决助手”类工具，直接问“如何做X”
- 或者使用这个工具生成的逆向问题，再去问其他AI“如何解决这个逆向问题”

**如果你需要系统性的思维框架：**
- 应该学习专门的思维模型（如SWOT、第一性原理）
- 或者使用更专业的思维导图软件

**如果你要处理高度专业的技术问题：**
- 应该咨询领域专家或使用专业工具
- 逆向思维可能产生不切实际或危险的建议

**如果你需要长期跟踪思维进展：**
- 应该使用笔记软件或项目管理工具
- 这个工具更适合单次、即时的思维激发

---

**最后提醒**：这个工具的价值不在于“正确答案”，而在于“打破惯性”。最好的使用方式是：生成逆向问题 → 挑选最有启发的1-2个 → 深入思考这些新问题 → 再回到原问题，你会发现视角已经不同了。

现在，试着输入你的第一个问题吧。从“如何让这个工具对我更有用？”开始也不错。
