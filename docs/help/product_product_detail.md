# 产品详情页文案生成器 - 学习与使用指南

---

## 【一】这个网页解决了什么问题？

**使用场景：**
当你需要为一个新产品（例如智能按摩椅、护肤品、小家电）撰写电商平台（如淘宝、京东）的详情页文案时，传统方式需要你绞尽脑汁构思卖点、场景和话术，耗时耗力。这个工具就像一个“AI文案副驾驶”，你只需输入产品的基本信息，它就能在几十秒内为你生成一套结构完整、风格多样的详情页文案草稿。

**适合什么情况？**
- **电商运营/内容创作者**：需要快速为多个产品上架准备文案。
- **初创团队/个人卖家**：没有专业文案预算，需要快速产出基础内容。
- **营销人员**：需要为同一产品构思不同风格的文案进行A/B测试。
- **学习者**：想了解电商详情页的标准结构和文案技巧。

**不适合什么情况？**
- **需要高度原创、有深刻品牌故事**的奢侈品或艺术品文案。
- **涉及复杂技术参数、法律声明**的工业品或医疗器械。
- **需要即时对话、反复沟通**的深度定制化文案服务。

## 【二】使用方式（给第一次接触的人）

**1. 页面输入是什么？**
你需要填写一个表单，主要包括：
- **产品名称**（必填）：你的产品叫什么。
- **核心卖点**（必填）：用分行的短句列出产品最吸引人的地方。
- **目标人群**：产品卖给谁。
- **价格区间与定位**：卖多少钱，是性价比还是高端货。
- **文案风格**：选择一种文案的“语气”，比如高端品质或情感共鸣。
- **生成模块**：选择需要AI帮你写哪几个部分（如痛点、亮点、场景等）。

**2. 用户通常会做哪几步操作？**
1.  **填写信息**：在左侧面板依次填入产品信息。
2.  **选择风格与模块**：点击选择你想要的文案风格和需要生成的模块。
3.  **一键生成**：点击底部橙色的“✨ 一键生成文案”按钮。
4.  **查看与使用结果**：在右侧面板查看生成的文案，可以展开、折叠、复制单个模块或全部内容。

**3. 输出结果长什么样？**
生成的结果不是一大段文字，而是被分成了几个**独立的卡片模块**，例如：
- **痛点引入**：提供3个不同角度的开头文案。
- **产品亮点**：一段详细展开核心卖点的文字。
- **使用场景**：列出3-5个具体的使用场景描述。
- **信任背书**：关于资质、好评的文案。
- **促单话术**：3句引导用户下单的话。

每个模块都可以独立展开查看、复制，甚至**单独重新生成**。

**4. 有哪些容易忽略的使用细节？**
- **API Key设置**：第一次使用前，需点击右上角齿轮图标，输入你的DeepSeek API Key。
- **模块选择**：可以只勾选“痛点引入”和“促单话术”来快速生成广告语，不一定每次都全选。
- **重新生成**：对某个模块不满意？点击模块右上角的刷新图标，可以单独让AI重写这个部分。
- **导出格式**：“导出文档”按钮会将所有内容保存为一个格式清晰的Markdown文件。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个大模块，像一个高效的内容生产线：

**1. 输入配置模块（左侧面板）**
- **职责**：收集用户需求。把零散的产品信息（是什么、卖给谁、怎么卖）结构化地收集起来。
- **关键设计**：将抽象的需求（如“文案风格”）转化为可视化的选择卡片（👑高端品质、💰性价比），极大降低了用户的理解和操作成本。

**2. AI处理引擎（核心逻辑，不可见）**
- **职责**：将输入的信息“翻译”成给AI的指令（Prompt），并调用AI API获取结果。
- **逻辑链路**：
  `用户输入` → `拼接成结构化Prompt` → `发送给DeepSeek API` → `解析返回的JSON` → `将数据分发给各个展示模块`。
- **最值得学习的设计**：**“模块化生成”策略**。它没有让AI生成一整篇大文章，而是要求AI按指定模块（痛点、亮点等）分别生成内容，并以JSON格式返回。这样做的好处是：
  - 结构清晰，易于后续处理和使用。
  - 允许用户对不满意的部分进行“局部重写”，无需全部推倒重来。
  - 降低了AI一次生成过长文本的出错概率。

**3. 输出展示与管理模块（右侧面板）**
- **职责**：优雅地展示AI生成的内容，并提供便捷的内容管理功能（复制、导出、重写）。
- **关键设计**：**交互式结果卡片**。每个结果模块都是一个独立的UI组件，拥有自己的状态（展开/折叠）、操作按钮（复制、重写）和内容展示逻辑（区分单一段落和多个版本）。这让生成结果不再是“只读的”，而是“可交互、可再编辑”的资产。

## 【四】Prompt / AI 逻辑是如何被设计的？

**1. Prompt扮演的角色**
在这个工具里，Prompt是**产品经理**和**AI指令员**的结合体。它负责把用户在前端表单里的零散选择，转化成一个AI能精确理解的、结构化的创作任务书。

**2. 解决的是“理解问题”还是“生成问题”？**
主要解决**“理解问题”**。它通过极其详细的上下文（产品信息、风格、模块要求、输出格式），框定了AI的思考范围和输出形式，确保AI生成的内容**不跑题、格式统一、符合商业用途**。真正的“创造性生成”工作仍由AI模型完成。

**3. Prompt中的关键变量**
- **产品信息变量**：`${this.input.productName}`, `${this.input.coreFeatures}` 等，这些是内容的基石。
- **风格与模块变量**：`${this.getStyleName()}`, `${this.getSelectedModuleNames()}`，这些决定了内容的“调性”和“结构”。
- **格式指令**：`请返回 JSON 格式：{...}`，这是**最关键**的部分，它强制AI以程序可解析的格式输出，是实现模块化展示和操作的技术前提。

**4. 如果只改Prompt，不改代码，会发生什么？**
- **改变内容风格**：在Prompt中强调“用网络流行语”或“模仿李佳琦的口吻”，生成的文案风格会立刻改变。
- **增加/减少模块**：在“输出格式”部分增加一个`"faq": ["问题1", "答案1"]`，AI就会多生成一个FAQ模块，但前端页面不会显示它，因为代码没有为这个新模块准备展示位置。
- **调整内容深度**：将“300-500字”改为“用50字概括”，生成的内容会变得非常简练。

**这正说明了Prompt是控制AI行为的“软开关”，而前端代码是呈现结果的“硬载体”。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，逐步打造自己的AI工具：

**第一步：保持结构不变，替换使用场景（最安全）**
- **目标**：做一个“小红书爆款笔记生成器”或“短视频口播脚本生成器”。
- **操作**：
  1.  修改网页标题和说明文字。
  2.  **保留左侧输入面板、右侧输出面板、底部按钮的三段式布局**。
  3.  将输入字段改为你的场景所需，例如：“产品/主题”、“关键词”、“笔记风格”（干货分享、好物推荐、避坑指南）、“平台”（小红书、抖音）。
  4.  此时先不修改代码逻辑，只改文字。

**第二步：调整输入字段与核心Prompt**
- **目标**：让AI生成你想要的内容。
- **操作**：
  1.  在HTML中找到输入字段的`x-model`（如`input.productName`），根据第一步的设计，修改变量名和提示文字。
  2.  找到`generateContent`函数中的`userPrompt`变量。这是核心！根据你的新字段，重新编写给AI的“任务书”。**务必保留要求AI返回JSON格式的指令**。
  3.  例如，对于小红书笔记，Prompt可以改为：“请生成一篇小红书笔记，包含标题、正文（带emoji和标签）、和3个评论话题。以JSON格式返回：`{“title”: “...”, “content”: “...”, “topics”: [...]}`”

**第三步：改变输出形式或展示方式**
- **目标**：让生成的结果更符合你的需求。
- **操作**：
  1.  找到`result`对象和展示结果的模板部分（`<template x-for="(module, key, index) in result">`）。
  2.  根据你新Prompt中定义的JSON键名（如`title`, `content`），修改展示模板，用`module.title`、`module.content`来显示内容。
  3.  可以调整样式，比如为“标题”加大字号，为“正文”增加小红书笔记常见的背景边框。

**从哪里下手最安全？**
从**修改静态文字和Prompt**开始。这不会破坏程序运行逻辑。当你理解了数据（`input`和`result`）是如何在Prompt和页面之间流动的之后，再去调整UI结构和交互逻辑。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“竞品分析”输入框，生成对比文案**
    - **操作**：在输入面板增加一个“竞品弱点”文本框。在Prompt中加入指令：“针对竞品[用户输入的弱点]，突出我方产品[对应卖点]的优势，生成对比性话术。” 在输出模块中新增一个“优势对比”卡片。

2.  **切换为多模态AI，生成文案配图建议**
    - **操作**：将API调用从DeepSeek Chat换成支持图像识别的模型（如GPT-4V或国内混元）。修改Prompt：“根据以上产品描述，生成3条详细的配图建议（描述画面构图、元素、色调）。” 输出结果中增加一个“配图建议”列表。

3.  **拆分为“快速生成”与“深度编辑”双页面**
    - **操作**：将当前页面作为“快速生成”页。点击“导出”后，跳转到一个新页面，该页面将导出的Markdown内容加载到一个可编辑的富文本编辑器（如TinyMCE）中，允许用户进行精细化修改和排版。

4.  **优化交互：增加“历史记录”与“模板保存”**
    - **操作**：
      - 使用`localStorage`保存每次成功的生成记录（时间、产品名、关键参数）。
      - 在页面顶部增加一个下拉菜单，可以快速加载历史记录。
      - 增加“保存为模板”按钮，将当前输入框的配置（风格、选择的模块等）保存下来，以后卖类似产品时一键套用。

5.  **增强实用性：接入翻译API，一键生成多语言文案**
    - **操作**：在输出面板的“复制全部”按钮旁，增加一个“翻译成英文”按钮。点击后，将生成的文案内容通过一个简单的翻译API（如百度翻译开放API）进行翻译，并在新标签页或弹窗中展示结果。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合生成法律、医疗、金融等领域的合规文本**
    - **局限性**：AI不了解最新的法律法规和行业监管细则，生成的内容可能存在合规风险。
    - **正确做法**：此类文本应由专业法务或持牌人士撰写，AI工具仅可作为灵感参考。

2.  **不适合替代与真实用户的调研和沟通**
    - **局限性**：AI的“目标人群”描述是基于模式推断，而非真实用户反馈。用它生成的“痛点”可能不是市场真正的痛点。
    - **正确做法**：将AI生成的文案作为初稿，务必通过用户访谈、A/B测试等方式进行验证和优化。

3.  **不适合处理极度依赖实时信息的文案**
    - **局限性**：AI的知识有截止日期，无法知晓今天发生的热点事件或最新的促销政策。
    - **正确做法**：对于结合热点的营销文案，应人工撰写或强烈引导AI（在Prompt中提供具体热点信息）。

4.  **不适合作为100%的最终发布内容**
    - **局限性**：AI可能生成重复、啰嗦或带有轻微“机器感”的文字，缺乏真正顶尖文案的灵感和人情味。
    - **正确做法**：**永远将AI视为你的“初级撰稿员”**。它的价值在于提供高质量草稿和多样思路，而最终的打磨、定调和注入品牌灵魂，必须由人来完成。
