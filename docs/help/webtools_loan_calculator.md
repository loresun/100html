# 房贷计算器 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景：**
当你计划买房，需要向银行贷款时，这个工具能帮你快速了解未来的还款压力。比如，你想知道“贷款100万、30年、利率3.55%，每月要还多少钱？总共要付多少利息？”它能在几秒钟内给你清晰的答案，并用图表直观展示本金和利息的比例。

**适合情况：**
- 个人购房前的初步财务规划
- 比较不同贷款方案（如等额本息 vs 等额本金）
- 理解长期贷款的利息成本构成

**不适合情况：**
- 精确的银行最终审批结果（实际利率可能有浮动）
- 包含税费、保险等综合购房成本计算
- 商业贷款或复杂的分段利率计算

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **贷款金额**：输入你想借的钱，单位是“万元”
2. **贷款期限**：选择还款年限（5-30年）
3. **年利率**：输入百分比，或点击“公积金”“商贷”快速设置
4. **还款方式**：选择“等额本息”或“等额本金”

**用户通常会做哪几步操作？**
1. 在左侧输入区填写/选择你的贷款条件
2. 点击蓝色的“开始计算”按钮
3. 查看右侧的还款摘要（每月还款额、总利息等）
4. 展开“查看还款计划表”了解每月详细构成
5. 调整参数，重新计算比较不同方案

**输出结果长什么样？**
- **顶部摘要卡片**：显示关键数字（每月还款、总利息、还款总额）
- **中间饼图**：用蓝色和橙色直观展示“本金 vs 利息”的比例
- **底部详细表格**：列出每一期的还款明细（本金、利息、剩余本金）

**容易忽略的使用细节：**
1. “贷款金额”单位是**万元**，输入100代表100万
2. “等额本金”方式下，每月还款额会**逐月递减**（摘要处有提示）
3. 表格可以滚动查看，表头在滚动时会固定在上方
4. 利率输入框旁的“公积金”“商贷”按钮是预设值，点击可直接应用

## 【三】核心结构拆解（学习重点）

这个页面由**三个核心模块**组成：

**1. 输入控制模块（左侧）**
- **职责**：收集用户的所有贷款参数
- **设计亮点**：使用`x-model`双向绑定，用户输入立即同步到数据层；预设按钮提供快捷操作

**2. 计算引擎模块（JavaScript函数）**
- **职责**：根据输入参数执行数学计算
- **核心算法**：
  - **等额本息**：每月还款额固定，前期利息多、本金少
  - **等额本金**：每月还固定本金，利息逐月减少，月供递减
- **输出**：生成完整的还款计划表和汇总数据

**3. 可视化展示模块（右侧）**
- **职责**：以多种形式呈现计算结果
- **三层展示**：
  - 摘要卡片（关键指标）
  - 饼状图（本金利息比例）
  - 详细表格（逐月明细）

**输入 → 处理 → 输出 链路：**
```
用户输入 → Alpine.js数据绑定 → calculate()函数计算 → 更新results/schedule → 重新渲染UI/图表
```

**最值得学习的设计：**
**分层的信息展示策略**——从“摘要”到“图表”再到“明细”，由浅入深，满足不同深度的信息需求。用户可以先看关键数字，有兴趣再深入了解细节。

## 【四】Prompt / AI 逻辑是如何被设计的？

> 注：这个页面**没有使用AI或Prompt**，它是一个纯计算工具。但我们可以从这个角度思考：如果我们要为它添加AI功能，Prompt会如何设计？

**假设的AI应用场景：**
如果添加“AI贷款顾问”功能，Prompt可能这样设计：

```
你是一位专业的房贷顾问。请根据以下贷款条件：
- 贷款金额：{amount}万元
- 贷款期限：{years}年
- 年利率：{rate}%
- 还款方式：{type}

请提供：
1. 简要分析这种方案的优缺点
2. 与另一种还款方式的对比建议
3. 如果利率上涨0.5%，每月会增加多少还款？
4. 给出1-2条财务规划建议
```

**Prompt中的关键变量：**
- `{amount}`、`{years}`、`{rate}`、`{type}`（从页面输入获取）
- 分析框架（优缺点、对比、风险提示、建议）

**如果只改Prompt，不改代码：**
- 可以改变AI回复的风格（如从“专业顾问”改为“朋友式建议”）
- 可以调整分析的重点（如更关注利息节省 vs 更关注前期压力）
- 可以增加或减少建议的维度

## 【五】如何模仿它，做出你自己的版本？

**安全改造路径：**

**第一步：替换使用场景（保持结构不变）**
- 将“房贷”改为“车贷计算器”
- 修改标题、标签文字
- 调整预设值（车贷通常1-5年，利率更高）

**第二步：调整输入字段**
- 增加“首付比例”输入
- 增加“保险费用”字段
- 将“万元”改为“元”或“千元”

**第三步：改变计算逻辑**
- 修改`calculate()`函数中的公式
- 例如车贷可能是简单利息计算
- 调整还款计划表的字段

**第四步：定制化展示**
- 更换颜色主题（将蓝色系改为绿色系）
- 修改图表类型（如用柱状图展示每月还款变化）
- 增加不同的输出视图（如“三年总成本”卡片）

**从哪里下手最安全？**
从**修改文字和预设值**开始，这是零风险的操作。然后尝试**增加一个简单的输入字段**，最后再触碰核心的计算逻辑。

## 【六】3–5 个可直接尝试的改造方向

**1. 增加“提前还款”模拟功能**
- 添加“第X个月提前还款XX万元”的输入
- 重新计算后续的还款计划
- 显示“节省的利息”作为新的摘要卡片

**2. 添加“多方案对比”模式**
- 允许保存当前方案（如“方案A”）
- 调整参数后作为“方案B”
- 并排显示两个方案的摘要和图表
- 高亮显示哪个方案总利息更少

**3. 集成实时利率API**
- 调用公开的LPR（贷款市场报价利率）API
- 自动获取最新基准利率
- 增加“基于最新LPR”的快速设置按钮
- 显示“与上月相比”的变化提示

**4. 优化移动端体验**
- 在手机上将布局改为垂直排列
- 输入区在顶部，结果在下方
- 表格改为卡片式逐月展示，支持滑动
- 增加“分享计算结果”功能

**5. 添加“还款能力评估”**
- 增加“家庭月收入”输入
- 计算“月供占比”（月供/月收入）
- 根据常见标准（如不超过50%）给出风险提示
- 建议“你能承受的最高贷款金额”

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **非精确的财务工具**：计算结果仅供参考，实际银行审批会有差异
2. **忽略附加成本**：不计算房产税、保险费、物业费等购房相关费用
3. **固定利率假设**：假设整个贷款期间利率不变，现实中可能调整
4. **单一货币计算**：只支持人民币，不考虑汇率变化

**如果用户想做以下事情，应该换工具：**
- **精确的贷款申请**：直接使用银行官方计算器或咨询客户经理
- **综合购房成本计算**：使用专业的房产APP或Excel模板
- **投资回报分析**：需要结合租金收益、房价增长等复杂模型
- **跨国/多币种贷款比较**：需要专门的国际房贷计算工具
