# 小红书多图轮播生成器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你写了一篇关于“如何高效学习”的长文，想在社交媒体（如小红书）上发布。但平台通常限制单张图片的文字量，长篇内容需要拆分成多张图片（轮播图）才能完整展示。手动用设计软件（如PS）一张张制作，费时费力，且风格难以统一。

这个工具就是为你准备的。它让你**专注于内容创作**，只需输入Markdown格式的文本，就能自动将其拆分成多张风格统一、设计精美的图片，并一键批量导出。你无需任何设计技能，就能快速生成一套可以直接发布的“小红书风格”轮播图。

**适合情况：**
*   将长篇文章、教程、清单、复盘总结等内容快速转化为社交媒体图片。
*   需要批量生成风格统一的视觉内容。
*   追求效率，希望减少在排版设计上的重复劳动。

**不适合情况：**
*   需要高度定制化、复杂图形设计（如手绘插图、复杂合成）。
*   需要生成动态或交互式内容（如GIF、视频）。
*   内容本身是纯数据图表，需要精确的图表工具。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **核心内容**：一个大的文本框，用于输入你的文章内容。
2.  **全局设置**：
    *   **设计风格**：选择“极简白”、“极客黑”等预设模板。
    *   **顶部/底部文字**：设置每张图片顶部（如你的账号名）和底部（如引导语）的固定文字。

**用户通常会做哪几步操作？**
1.  **输入内容**：在左侧编辑区的大文本框中，写下你想展示的全部内容。可以用 `#` 表示大标题，`##` 表示小标题，`-` 表示列表，`---`（三个减号）来手动分割不同的卡片页面。
2.  **点击“填入示例”**：如果不确定格式，可以点击这个链接，它会填入一份示例内容，你可以直接看到效果。
3.  **实时预览**：输入内容后，右侧会立即显示拆分后的所有卡片预览图，并自动编号。
4.  **调整风格**：在“全局设置”中选择喜欢的视觉风格，预览图会同步变化。
5.  **微调文案**：修改顶部和底部的固定文字。
6.  **导出下载**：点击右上角“下载所有图片”按钮，工具会自动将每一张预览图生成为高清PNG图片，并依次下载到你的电脑。

**输出结果长什么样？**
你会得到一系列（例如5张）尺寸为450x600像素的PNG图片。每张图片包含：
*   顶部：你设置的账号信息 + 当前页码（如“2/5”）。
*   中部：你输入的内容，经过精美排版（标题加粗、列表清晰）。
*   底部：你设置的引导语。
*   整体风格：与你选择的主题一致（如黑色背景、粉色标题等）。

**有哪些容易忽略的使用细节？**
*   **分割符是关键**：默认用 `---`（前后需换行）来分割卡片。如果你没写 `---`，工具会尝试寻找 `## ` 标题来分割，但用 `---` 控制更精确。
*   **第一张是封面**：工具会自动将分割后的第一段内容视为“封面”，其排版（居中、大字体）与其他内容页不同。
*   **导出需要时间**：点击“下载所有图片”后，按钮会显示“生成中...”，浏览器会依次弹出多个保存对话框，请勿关闭页面，直到全部完成。
*   **支持Markdown**：在内容中输入 `**加粗**`、`- 列表项` 等Markdown语法，预览时会自动渲染为加粗文字和列表点。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

**1. 输入与配置模块（左侧编辑区）**
*   **职责**：接收用户的所有原始输入和配置指令。
*   **包含**：内容文本框、风格选择按钮、顶部/底部文字输入框。
*   **逻辑**：用户在这里进行所有“创作”和“设定”。这里的任何更改，都会立刻成为后续流程的“数据源”。

**2. 内容处理与状态管理模块（Vue 应用核心）**
*   **职责**：作为大脑，处理输入数据，管理整个应用的状态。
*   **关键函数**：
    *   `parsedCards`：这是**最核心的逻辑**。它读取 `inputText`，根据 `---` 或 `##` 规则将其拆分成一个数组，数组的每一项就对应一张卡片的内容。
    *   `currentTheme`, `headerText` 等：管理全局样式和文案状态。
*   **逻辑**：`输入文本` -> `分割函数(parsedCards)` -> `卡片数据数组`。这个数组是连接输入和预览的桥梁。

**3. 渲染与输出模块（右侧预览区及导出功能）**
*   **职责**：将处理好的数据，可视化为图片，并提供导出能力。
*   **包含**：
    *   **预览区**：循环遍历 `parsedCards` 数组，为每一项数据动态生成一个HTML卡片。应用当前选择的 `themeClass` 和 `headerText` 等样式。
    *   **导出功能** (`exportAll`函数)：其核心是“克隆-截图-下载”循环。它遍历每张卡片的DOM节点，克隆一份，使用 `html2canvas` 库将其转换为图片数据，并触发浏览器下载。
*   **逻辑**：`卡片数据` + `样式状态` -> `Vue动态渲染DOM` -> `html2canvas转换为图片` -> `下载`。

**最值得学习的设计：**
**“数据驱动视图”与“关注点分离”**。整个应用围绕 `parsedCards` 这个核心数据数组运转。输入模块修改它，渲染模块消费它。这种设计使得功能模块之间耦合度很低，例如，要增加一种新的分割规则，你几乎只需要修改 `parsedCards` 函数，而无需改动渲染和导出逻辑。这是构建可维护、可扩展前端应用的关键思想。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个工具中，**没有使用传统的AI或Prompt**。它解决的是一个**确定性的格式化与渲染问题**，而非需要理解或生成自然语言的问题。

但是，我们可以将用户的**输入文本**和**分割规则**类比为一个“设计指令”或“格式化Prompt”：
*   **“Prompt”角色**：用户输入的Markdown文本以及其中嵌入的 `---` 分割符，共同构成了一个指令，告诉程序：“请将这段文本按此规则切分，并套用指定的版式。”
*   **解决什么问题**：它解决的是“**结构化问题**”。程序不需要理解“2026年”是什么意思，它只需要识别 `#`、`---` 这些符号，并执行预设的排版动作。
*   **关键变量**：分割符 (`---` 或 `##`)、Markdown语法符号 (`#`, `-`, `**`)。
*   **如果只改规则，不改代码**：如果未来小红书流行用 `***` 分割，你只需要修改 `parsedCards` 函数中的正则表达式分割规则。输入模块、渲染模块、导出模块都无需改动，整个工具的行为就会改变。这体现了核心逻辑集中管理的好处。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的内容生成工具：

**第一步：替换场景与视觉风格（最安全）**
*   **目标**：做一个“知识卡片生成器”或“金句海报生成器”。
*   **操作**：
    1.  修改 `title` 和导航栏中的标题文字。
    2.  在 `themes` 数组中，替换或增加新的主题对象，修改 `class` 名称，并在 `<style>` 标签中定义对应的 `.theme-yourstyle` CSS类，改变背景、字体、颜色。
    3.  将“顶部文字”和“底部文字”的标签改为更符合你场景的文案（如“话题：#哲学思考”、“出处：《沉思录》”）。

**第二步：调整输入与内容处理规则**
*   **目标**：适应不同的内容结构。
*   **操作**：
    1.  如果你生成的是“每日待办清单”，输入可能不需要分割。你可以简化 `parsedCards` 函数，让它总是将整个输入文本作为数组的唯一元素。
    2.  如果你想支持从网络API获取内容，可以增加一个“导入URL”按钮，在 `addSample` 函数旁边添加一个新函数 `fetchContent`，用 `fetch` API获取数据并赋值给 `inputText`。

**第三步：改变输出形式与交互**
*   **目标**：提供更丰富的输出选项。
*   **操作**：
    1.  在导出按钮旁增加一个“导出为PDF”按钮。这需要引入像 `jspdf` 这样的库，将多张图片合并到一个PDF文件中。
    2.  在每张预览卡片上增加“单独下载”按钮，让用户可以只导出某一张。

**从哪里下手最安全？**
从 **第一步** 开始。只修改静态文本、颜色、样式。这不会破坏程序的核心逻辑，你能立即看到视觉变化，建立信心。然后尝试修改 `addSample` 函数中的示例内容，理解数据是如何流动的。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加图片上传与背景融合功能**：
    *   **操作**：在全局设置区增加一个“上传背景图”的按钮。将上传的图片作为 `background-image` 应用到 `.xhs-card` 的CSS中。记得调整文字颜色以确保可读性。
    *   **价值**：让内容更具视觉冲击力和独特性。

2.  **引入简单的AI润色或摘要功能**：
    *   **操作**：在内容文本框上方增加一个“AI优化”按钮。点击后，调用一个免费的AI API（如DeepSeek、Moonshot），将当前文本发送过去，Prompt可以是“请将这段文字改写得更加口语化，适合小红书平台”，然后将返回的结果填回文本框。
    *   **价值**：提升内容本身的质量，工具从“排版助手”升级为“创作助手”。

3.  **将单页应用拆分为“创建-管理-导出”多页面**：
    *   **操作**：利用Vue Router或简单的页面跳转。首页是内容创建和预览。增加一个“我的项目”页面，使用 `localStorage` 来保存每次生成的内容和配置，允许用户再次编辑或导出。
    *   **价值**：管理更复杂的工作流，适合需要多次修改和版本管理的用户。

4.  **优化交互体验**：
    *   **操作**：
        a. **拖拽排序**：在预览区，允许用户通过拖拽来调整卡片的顺序。这需要监听拖拽事件并更新 `parsedCards` 数组的顺序。
        b. **实时字数统计**：在内容文本框下方显示总字数和当前卡片字数。
        c. **导出进度条**：在导出时，显示一个进度条模态框，明确告知用户“正在生成第3/5张...”，提升等待体验。
    *   **价值**：让工具更加专业、易用、人性化。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做高精度平面设计**：它的排版是固定的模板。如果你需要像素级精确控制文字位置、使用特殊字体（非网络字体）、创建复杂图形布局，应使用 **Figma、Canva 或 Adobe Illustrator** 等专业设计软件。
*   **不适合处理实时协作**：这是一个纯前端工具，所有数据都在当前浏览器页面中。多人无法同时编辑同一份内容。如需协作，应构建后端服务或使用 **Google Docs、语雀** 等在线文档工具写好内容后，再粘贴过来。
*   **不适合生成大量动态内容**：它生成的是静态图片。如果你需要内容中的数字、图表能根据数据实时更新，或者制作带动画的演示文稿，应使用 **PPT、Keynote 或基于SVG/Canvas的图表库**。
*   **不适合作为最终发布平台**：它只是一个“内容生产工具”。生产出的图片，你需要手动上传到小红书或其他平台。它不具备发布、调度、数据分析等功能。

**记住这个工具的核心定位：它是一个将“文本内容”快速包装成“视觉格式”的转换器。** 明确这个边界，你就能在它的能力范围内最大化其价值，并在需要时选择合适的替代工具。
