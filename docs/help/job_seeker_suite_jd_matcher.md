# JD 拆解与匹配度评分器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你看到一份心仪的招聘信息（JD），不确定自己的背景是否匹配，或者想知道如何优化简历时，这个工具能帮你快速分析。它就像一个“求职顾问”，帮你解读岗位要求，对比你的经历，并给出具体的改进建议。

**适合情况：**
- 求职者准备投递简历前，想评估自己的竞争力。
- 想了解某个岗位的核心要求，以便针对性准备。
- 需要一份结构化的分析报告，用于指导简历修改或面试准备。

**不适合情况：**
- 需要精确的、法律或财务相关的职业资格认证评估。
- 代替真实的面试模拟或专业的职业规划咨询。
- 分析极其模糊或非结构化的岗位描述（效果会打折扣）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面左侧有四个输入框：
1.  **目标岗位**：填写你申请的职位名称，如“前端开发工程师”。
2.  **岗位描述 (JD)**：粘贴完整的招聘要求文本。
3.  **个人背景摘要**：简要描述你的工作经历、技能、项目亮点。
4.  **优先关注维度**：（可选）填写你特别看重的点，如“团队氛围”、“技术成长”。

**用户通常会做哪几步操作？**
1.  **首次使用**：点击右上角齿轮图标，在弹出的设置窗口中填入你的 DeepSeek API Key（需要自行申请），然后保存。
2.  **填写信息**：将招聘信息和你的个人背景分别粘贴到对应的输入框中。
3.  **生成分析**：点击绿色的“生成匹配分析”按钮。
4.  **查看结果**：等待几秒后，右侧会显示详细的分析报告。
5.  **使用结果**：你可以“复制”报告内容，或“导出”为 TXT/JSON 文件保存。

**输出结果长什么样？**
结果是一份用 Markdown 格式呈现的结构化报告，通常包含：
-   岗位关键能力结构
-   JD 关键词清单
-   匹配度评分（0-100分）及依据
-   你的能力差距清单和短期提升建议
-   是否建议投递及简历调整重点
如果使用了“R1”推理模型，报告前还会有一个可展开的“深度思考过程”部分，展示 AI 的分析思路。

**有哪些容易忽略的使用细节？**
-   **API Key 是必须的**：不填写就无法使用，这是调用 AI 服务的“钥匙”。
-   **模型切换**：顶部有“V3”和“R1”两个按钮。“V3”响应快，“R1”会展示思考过程，分析可能更深入，但稍慢。
-   **自定义提示词**：在设置里，你可以追加要求，比如“请用更严厉的标准评估”，这会让 AI 的输出风格发生变化。
-   **数据保存**：你填写的 API Key 和自定义提示词会自动保存在浏览器本地，下次打开还在。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

**1. 输入配置模块（左侧面板）**
-   **职责**：收集所有分析所需的基础信息。它像一个“信息采集器”。
-   **构成**：四个表单字段（`jobTitle`, `jobDescription`, `profile`, `focus`）和两个操作按钮（生成、清空）。
-   **逻辑**：用户填写 → 数据被绑定到 `form` 对象 → 点击“生成”时，`form` 数据被送入下一个处理环节。

**2. AI 处理与通信模块（看不见的后台）**
-   **职责**：这是网页的“大脑”。它负责将输入信息打包成 AI 能理解的请求（Prompt），调用外部 AI API，并处理返回的数据流。
-   **关键函数**：`buildPrompt()` 组装指令，`streamChat()` 负责与 DeepSeek API 通信并实时接收数据。
-   **逻辑链路**：`表单数据` + `自定义提示` → `buildPrompt()` 组装 → `streamChat()` 发送请求 → 接收 AI 流式响应 → 实时更新界面。

**3. 结果展示与导出模块（右侧面板）**
-   **职责**：美观、结构化地呈现 AI 生成的内容，并提供实用的后续操作。
-   **构成**：结果标题区、操作按钮区（复制、导出）、内容显示区（支持 Markdown 渲染）。
-   **逻辑**：接收来自 `streamChat()` 的实时数据 → 更新 `result` 和 `reasoning` 变量 → 界面自动重新渲染显示内容。

**最值得学习的设计：**
-   **“流式响应”处理**：代码没有等待 AI 全部生成完再显示，而是一边接收数据一边更新页面（`onChunk` 回调）。这让用户感觉响应更快，体验更好。这是现代 AI 应用的关键交互设计。
-   **清晰的职责分离**：输入、处理、输出三个模块界限分明，数据通过明确的变量（`form`, `result`）流动。这种结构让代码易于理解和修改。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 扮演的角色：**
Prompt 在这里是给 AI 的“详细工作指令单”。它决定了 AI 如何理解你的输入，以及以何种格式和深度输出分析报告。

**解决的是“生成问题”：**
这个工具的核心是让 AI **生成**一份全新的、结构化的分析报告，而不是简单地理解或分类已有信息。

**Prompt 中的关键变量：**
1.  **结构化指令**：`输出结构：1)... 2)...` 这部分强制 AI 按固定框架输出，保证了结果的一致性和可用性。
2.  **用户输入变量**：`岗位名称：${this.form.jobTitle}`，这些是插入到固定指令中的动态内容，是每次分析的核心。
3.  **追加要求**：`额外要求：${this.promptConfig.custom}`，这是留给高级用户微调 AI 行为的入口。

**如果只改 Prompt，不改代码，会发生什么？**
-   **改变输出内容**：例如，把“输出结构”改成包含“面试可能问题预测”，报告就会多出这个部分。
-   **改变分析风格**：例如，在开头加上“你是一名苛刻的资深技术面试官”，AI 生成的评价可能会更严格、更技术化。
-   **改变输出语言**：将指令中的“使用中文”改为“使用英文”，整个报告就会变成英文。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个功能类似但主题不同的工具：

**第一步：保持结构不变，替换使用场景（最安全）**
-   **目标**：先做出一个能跑起来的“新外壳”。
-   **操作**：
    1.  复制整个 HTML 文件。
    2.  修改标题和页面中的文字，例如将“JD 匹配度评分器”改为“XX 评测器”。
    3.  修改左侧输入框的标签和提示文字。例如，改成“产品描述”、“用户反馈”、“评测维度”。
    4.  此时先不要动核心的 JavaScript 逻辑和 Prompt。

**第二步：调整输入字段或 Prompt**
-   **目标**：让工具处理你的新数据。
-   **操作**：
    1.  在 `form` 对象中，增加或删减属性，以匹配你第一步改好的输入框。
    2.  修改 `buildPrompt()` 函数。这是核心！根据你的新场景，重写给 AI 的指令。例如，新指令可以是：“你是一名产品经理，请根据用户反馈分析产品优缺点...输出结构：1) 优点总结 2) 痛点清单 3) 改进优先级建议...”
    3.  确保 Prompt 中引用的变量名（如 `${this.form.xxx}`）与 `form` 对象中的属性名一致。

**第三步：改变输出形式或展示方式**
-   **目标**：让结果展示更符合你的需求。
-   **操作**：
    1.  观察 `result` 变量是如何被渲染的（通过 `x-html="marked.parse(result)"`）。如果你的新 Prompt 输出格式变了，这里通常不需要修改。
    2.  你可以修改结果区域的标题、说明文字和导出文件的默认名称（`jd_match_report.txt`）。
    3.  （进阶）如果你需要图表，可以在此区域引入图表库，并将 `result` 解析成数据来绘图。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加历史记录功能**
    -   **操作**：在 `localStorage` 中新增一个数组，每次生成完成后，将 `form` 和 `result` 打包成一个记录对象存进去。在页面侧边栏或底部增加一个“历史记录”面板，点击可以快速载入之前的分析。
    -   **价值**：方便用户对比多次投递或跟踪自己的提升。

2.  **支持多轮对话与追问**
    -   **操作**：修改 `streamChat` 函数，不再每次清空 `messages`，而是将用户每次的“追问”（如一个输入框输入“请详细解释第三点”）作为新的 `user` message 追加到历史消息中，再发送给 AI。
    -   **价值**：让分析工具变成交互式顾问，用户可以针对报告中的某一点深入提问。

3.  **更换或增加 AI 模型/API**
    -   **操作**：在设置面板中增加一个“API 提供商”下拉选择框（如 DeepSeek, OpenAI, 智谱AI）。修改 `streamChat` 函数中的请求 URL (`fetch` 地址) 和请求头 (`headers`)，根据用户选择动态拼接。不同 API 的请求格式略有不同，需要查阅对应文档。
    -   **价值**：给用户更多选择，或作为备用方案（当某个 API 不可用时）。

4.  **优化输入体验——JD 解析助手**
    -   **操作**：在“岗位描述”文本框下方增加一个“一键解析”按钮。点击后，调用另一个 AI 接口（或一个简单的文本处理函数），自动从用户粘贴的长篇 JD 中提取出“职位名称”、“核心要求”、“加分项”等，并自动填充到对应的输入框中。
    -   **价值**：简化用户操作，提升工具智能化程度。

5.  **增加可视化评分组件**
    -   **操作**：在结果区域，使用正则表达式或简单解析，从 AI 生成的文本中提取出“匹配度评分（XX）”这个数字。然后，用一个圆形进度条或雷达图（可引入轻量图表库如 `chart.js`）将这个分数可视化地展示出来。
    -   **价值**：让核心结论一目了然，报告更具专业感和冲击力。

## 【七】这个网页不适合做什么？（边界提醒）

-   **不适合做最终的录用决策**：这个工具的分析基于 AI 对文本的理解，它无法核实你经历的真实性，也无法评估面试中的临场表现等复杂因素。它只是一个**辅助分析工具**，不能代替人的综合判断。
-   **不适合分析高度专业化或监管严格的领域**：例如，对于医生、律师、飞行员等有严格法定资质要求的职业，AI 可能无法准确理解行业内的特定术语、标准和法规，其分析可能遗漏关键点，甚至产生误导。
-   **不适合处理完全非结构化的信息**：如果岗位描述只是一句话（如“招一个能干的人”），或者你的个人背景描述极其混乱、缺乏关键信息，工具的分析质量会急剧下降，给出的建议可能没有实际价值。
-   **如果你需要的是…**：
    -   **真实的模拟面试**：应该使用专门的面试练习平台或找人进行模拟。
    -   **深度的职业路径规划**：建议咨询专业的职业规划师。
    -   **简历排版设计**：应该使用 Canva、LaTeX 或专业的简历设计服务。

**总结：** 这个网页是一个出色的“信息处理器”和“内容生成器”模板。你学会了如何将用户输入、AI 能力和结果展示串联起来。现在，你可以用它作为起点，去构建解决其他领域问题的智能工具了。
