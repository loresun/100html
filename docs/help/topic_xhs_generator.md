# 小红书爆款选题专家 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：你是一名小红书博主、内容创作者或营销人员，需要持续产出吸引人的笔记内容。你有一个大概的主题方向（比如“秋季穿搭”），但不知道从哪个具体角度切入才能成为爆款。你不想一个个手动想标题、封面和正文，希望有一个“创意助手”帮你批量生成高质量的选题和文案草稿。

**适合情况**：
*   需要快速为某个主题（如产品、生活方式、知识分享）策划多个内容方向。
*   希望内容风格符合小红书平台调性（视觉化、情绪化、干货感）。
*   需要将选题可视化，模拟成手机笔记卡片，方便预览和筛选。

**不适合情况**：
*   需要生成完全原创、未经AI辅助的深度长文。
*   需要直接发布未经修改的文案（AI生成内容需人工审核和润色）。
*   创作领域高度专业化或需要严格事实核查（如法律、医疗）。

## 【二】使用方式（给第一次接触的人）

1.  **准备工作**：首次使用需点击右上角“API 设置”，填入你的 DeepSeek API Key（需自行申请）。
2.  **输入核心信息**：
    *   **创作主题**：你想写的大方向，如“露营装备推荐”。
    *   **目标人群**：你的笔记想给谁看，如“都市白领，周末放松”。
    *   **参考资料**：（可选）可以粘贴一些灵感来源或关键词。
    *   **生成数量**：想一次得到几个选题点子（4/6/8个）。
    *   **风格**：选择笔记的整体语气，如“干货教程”或“情感共鸣”。
3.  **核心操作**：点击 **“✨ 生成爆款选题”** 按钮。稍等片刻，右侧会以卡片网格的形式展示生成的选题。
4.  **查看与细化**：
    *   点击任意卡片，会弹出**编辑抽屉**，你可以微调标题、封面大字和切入角度。
    *   在编辑抽屉内，可以点击 **“生成正文”** 为该选题生成完整的小红书风格文案。
    *   也可以在所有选题生成后，点击左侧底部的 **“批量生成正文”** 一次性为所有选题生成文案。
5.  **输出结果**：
    *   **视觉化**：每个选题被包装成一个3:4比例的“小红书笔记卡片”，有模拟的封面和标题。
    *   **文案**：生成的小红书正文，包含emoji、短段落、互动引导和话题标签。
    *   **可导出**：支持复制单篇文案、下载为文本文件，或一键导出全部文案。

**容易忽略的细节**：
*   **模型切换**：顶部导航可以切换“Chat”和“Reasoner (R1)”模型，后者可能逻辑性更强，但生成速度可能稍慢。
*   **封面大字**：这是显示在卡片封面最显眼位置的短句，需要足够吸睛，可以在编辑器中单独修改。
*   **流式生成**：生成正文时，文字是逐字出现的（流式输出），体验更好，需要等待它完成。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“输入-处理-展示”** 左右分栏结构。

*   **模块1：控制面板（左侧）**
    *   **职责**：收集用户所有创作意图（主题、人群、风格等），并触发AI生成任务。它是整个应用的“大脑”和起点。
    *   **逻辑**：将表单中的输入项，组合成一个结构化的 **Prompt（提示词）**，调用AI API。生成选题后，此处还提供“批量生成”的入口。

*   **模块2：选题画廊（右侧主区域）**
    *   **职责**：**可视化展示**AI生成的成果。将抽象的“选题”对象，渲染成用户熟悉的“小红书笔记卡片”样式，提升筛选和管理的体验。
    *   **逻辑**：接收来自API的JSON数据，遍历并生成卡片。每个卡片都是后续“生成正文”操作的入口。

*   **模块3：卡片编辑器（滑动抽屉）**
    *   **职责**：提供**细粒度编辑**和**深度生成**功能。用户可以对AI生成的选题进行微调，并在此触发针对单个选题的正文生成。
    *   **逻辑**：它是一个“弹出式”工作台，绑定到当前选中的`activeCard`数据。在此处的修改会实时同步到主画廊的卡片上。

*   **模块4：API配置与状态管理（全局）**
    *   **职责**：管理应用依赖的AI服务（DeepSeek）密钥，并显示当前任务状态（如“生成中”）。
    *   **逻辑**：将API Key存储在浏览器的本地存储（LocalStorage）中，实现一次配置，多次使用。

**最值得学习的设计**：
**“两级生成”工作流**。页面没有试图让AI一步到位生成完美文案，而是拆解为：
1.  **创意发散级（生成选题）**：用一次AI调用，批量产出多个**内容方向**（标题、角度）。这成本低，效率高，便于用户快速选择。
2.  **内容深化级（生成正文）**：在用户选定具体方向后，再针对单个选题调用AI，生成**详细内容**。这保证了内容质量，且可按需生成，节省资源。
这种设计模仿了人类创作过程：先头脑风暴，再具体写作，体验非常自然。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：它是连接用户意图和AI能力的**翻译器**和**任务说明书**。在这个页面中，它严格规定了AI输出的格式和内容要点。
*   **解决的问题**：它同时解决“理解问题”和“生成问题”。
    *   **理解**：告诉AI“你是谁”（小红书专家）、“你要做什么”（策划选题）。
    *   **生成**：规定输出的**具体结构**（JSON数组，包含`title`, `cover_title`等字段）和**风格要求**（吸引人、带emoji）。
*   **关键变量**：Prompt中嵌入了所有用户输入：`${input.topic}`, `${input.audience}`, `${input.vibe}`, `${input.count}`。它们是Prompt的“活参数”。
*   **只改Prompt的影响**：如果只修改Prompt而不改代码，你可以彻底改变这个工具的功能。例如：
    *   将“小红书选题”改为“短视频脚本创意”，它就成了短视频脚本生成器。
    *   修改JSON结构中的字段（如增加`hashtag`字段），AI就会在新字段中输出内容，但前端页面不会显示它（因为代码没改）。
    *   强化风格要求，如“用鲁迅的文风”，生成的选题标题会变得诙谐犀利。

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径**：

1.  **第一步：替换“皮肤”与场景（不改逻辑）**
    *   **目标**：先做出一个能跑起来的、属于你自己的工具。
    *   **操作**：
        *   修改`<title>`和顶部导航的“XHS Maker”为你工具的名字。
        *   将左侧输入表单的标签全部替换。例如，将“创作主题”改为“产品名称”，“目标人群”改为“产品卖点”，“风格”改为“文案调性”。
        *   将页面中所有“小红书”、“笔记”、“爆款”等文字替换成你的领域词汇，如“电商详情页”、“卖点文案”。
        *   **此时，工具的逻辑（生成选题->生成详情）完全没变，只是换了个说法。**

2.  **第二步：调整Prompt（改变AI生成的内容）**
    *   **目标**：让AI生成你想要的东西。
    *   **操作**：
        *   找到`generateTopics`函数中的`prompt`变量。
        *   重写这段提示词。明确告诉AI你的新角色（如“你是电商文案专家”）和新任务（如“生成产品卖点标题”）。
        *   修改示例JSON格式中的字段名，使其符合你的需求（例如，`cover_title` 可能对你没用，可以改成 `slogan`）。
        *   同样，修改`generateSingleContent`函数中的Prompt，定义你想要的“正文”长什么样（如“生成一段200字的商品描述”）。

3.  **第三步：改变输出展示方式（优化体验）**
    *   **目标**：让展示形式更贴合你的内容。
    *   **操作**：
        *   修改右侧卡片的样式。例如，如果不是3:4的图片比例，可以调整`.aspect-3-4`的CSS。
        *   修改卡片上显示的信息。在模板中，将`{{ card.title }}`改为`{{ card.slogan }}`（对应你第二步改的字段）。
        *   可以调整编辑抽屉里的表单，增加或删除编辑项。

**从哪里下手最安全？** 从**第一步**开始。先改文字和标签，确保工具能正常运行。这是零风险且能立刻获得成就感的一步。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“负面提示”输入框**：
    *   **操作**：在输入区域增加一个“避免内容”或“不喜欢的风格”文本框，并将其变量（如`input.negative`）加入到生成选题和正文的Prompt中。例如：“避免使用‘绝绝子’等网络流行语”。
    *   **效果**：让生成的内容更精准，更符合个人或品牌调性。

2.  **接入多模型API，实现“风格对比”**：
    *   **操作**：在API设置中增加OpenAI GPT、Claude等模型的Key配置。在生成正文时，提供按钮如“用GPT-4生成”、“用Claude生成”，并将结果并排展示在编辑抽屉中。
    *   **效果**：用户可以直观对比不同AI的文案风格，选择最满意的一版。

3.  **拆解为“团队协作”流程**：
    *   **操作**：将单页应用拆成两个页面。**页面A（策划）**：仅保留生成和展示选题卡片的功能，增加“分享链接”按钮。**页面B（创作）**：通过链接打开，只显示一个卡片编辑器，专注于该选题的文案撰写和修改，并增加“提交审核”状态。
    *   **效果**：模拟真实内容团队的工作流，策划和写作分离。

4.  **增加“灵感库”和历史保存**：
    *   **操作**：利用`localStorage`或简单的后端，将每次生成的选题卡片数组保存下来。在首页增加一个“历史灵感”面板，可以查看、复用或合并过去的选题。
    *   **效果**：避免灵感流失，建立个人的内容创意库。

5.  **优化交互：增加卡片“点赞”与“排序”**：
    *   **操作**：为每个卡片增加一个“👍”按钮，点击后记录点赞数。在画廊顶部增加排序筛选器，如“按热度排序”、“仅显示未生成正文的”。
    *   **效果**：帮助用户在众多选题中快速聚焦到最有潜力的方向上，交互更人性化。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做最终发布工具**：它生成的是**草稿**和**灵感**。所有AI生成的内容都必须经过人工的审核、事实核对、个性化润色和情感注入，才能发布。直接发布AI文案可能导致内容同质化、缺乏真情实感，甚至出现事实错误。
*   **不适合完全替代深度思考**：对于需要严密逻辑、独特观点或高度专业性的内容（如行业分析、学术科普、个人故事），这个工具只能提供角度参考和结构启发，核心思想仍需创作者自己构建。
*   **不适合无目的的内容生成**：如果输入的主题过于空泛（如“写点东西”），生成的结果也会质量低下。它的效果严重依赖于你输入的**质量**。它是一个“放大器”，而不是“无中生有”的机器。
*   **如果需要更复杂的排版或视频脚本**：它目前输出纯文本和简单封面模拟。如果需要生成带复杂排版的图文，或需要分镜头的视频脚本，你需要在此工具生成文案的基础上，使用专业的排版工具（如Canva）或视频脚本模板进行二次加工。
