# FIRE 计算器 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你正在规划自己的财务未来，想知道“我到底需要存够多少钱，才能不再为钱工作？”这个网页就是为你设计的。它基于 **FIRE（财务独立，提前退休）** 理念，帮你将模糊的财务目标转化为清晰的数字和可视化的时间线。你可以在制定年度储蓄计划、评估投资策略、或者单纯想了解自己离财务自由还有多远时使用它。

**适合情况：**
- 对个人财务规划有初步概念，想进行长期模拟。
- 需要一个快速、直观的工具来测试不同储蓄率或投资回报率对退休年龄的影响。
- 希望将抽象的“财务自由”概念，变成一个具体的、可追踪的数字目标。

**不适合情况：**
- 需要精确的、考虑通胀、税收、突发大额支出等复杂因素的财务规划（应使用专业财务软件或咨询顾问）。
- 进行短期（如1年内）的预算或现金流管理。
- 作为唯一的投资决策依据（它不提供具体的投资建议）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面左侧有6个输入项，它们是你财务模型的“参数”：
1.  **当前年龄**：你现在的岁数。
2.  **预期年支出**：你希望退休后，每年需要多少钱来生活（单位：万元）。
3.  **当前存款**：你已经攒下的本金（单位：万元）。
4.  **每年储蓄**：你计划每年能存下并投入的钱（单位：万元）。
5.  **投资回报率**：你预计投资组合的年化收益率（通过滑块调整）。
6.  **安全提现率**：退休后，你计划每年从本金中提取多少比例来花销，而不耗尽本金（经典值是4%）。

**用户通常会做哪几步操作？**
1.  **填写基本信息**：先填入你的年龄、当前存款和预计的年支出。
2.  **调整关键变量**：滑动“投资回报率”和“每年储蓄”滑块，观察右侧图表和结果如何剧烈变化。这是探索不同财务策略的核心。
3.  **解读结果**：查看“FIRE目标金额”、“还需奋斗年数”和资产成长曲线图，理解你的财务路径。
4.  **反复试验**：尝试“如果我把储蓄提高到XX万”或“如果投资回报只有X%”等场景，找到现实与理想的平衡点。

**输出结果长什么样？**
-   **一个核心数字**：左上角显示你的“FIRE目标金额”（例如“¥250.00万”）。
-   **两个关键指标**：右侧卡片显示“还需奋斗”的年数以及当前存款相对于目标的“进度”百分比。
-   **一张动态图表**：最直观的部分，用两条曲线展示你的资产随时间如何增长（橙色实线），以及目标线在哪里（绿色虚线）。两条线的交汇点，就是你预计的退休时间。

**有哪些容易忽略的使用细节？**
-   **单位是“万元”**：输入“10”代表十万元，而不是十元。
-   **滑块与数字联动**：调整“投资回报率”或“安全提现率”滑块时，旁边的数字会实时变化。
-   **数据自动保存**：刷新页面后，你上次输入的数据还会保留（存储在浏览器本地）。
-   **图表可交互**：将鼠标悬停在图表曲线上，可以看到具体某一年龄的资产数值。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

**1. 输入控制模块（左侧面板）**
-   **职责**：收集用户所有的财务假设和现状数据。
-   **设计亮点**：使用了“数字输入框”和“范围滑块”的组合。对于精确值（如年龄、存款）用输入框；对于需要探索的变量（如回报率）用滑块，鼓励用户互动和试错。

**2. 计算与状态管理模块（JavaScript `fireApp` 对象）**
-   **职责**：这是页面的大脑。它监听所有输入的变化，执行核心财务计算，并管理应用的整体状态（数据）。
-   **核心逻辑链路**：
    -   **输入**：用户修改任何输入字段 → 触发 `calculate()` 函数。
    -   **处理**：
        1.  根据 `年支出` 和 `提现率` 计算终极目标 `fireNumber`。
        2.  根据 `当前存款`、`年储蓄`、`回报率` 模拟未来几十年的资产复利增长。
        3.  在模拟过程中，找到资产超过目标的年份，即为 `yearsToFire`。
    -   **输出**：计算出目标金额、所需年数、进度百分比，以及用于绘制图表的逐年数据数组。

**3. 可视化与展示模块（右侧面板）**
-   **职责**：将计算结果以最直观、易懂的方式呈现给用户。
-   **组成**：
    -   **指标卡片**：突出显示最关键的两个结果（年数、进度）。
    -   **图表区**：使用 Chart.js 库将枯燥的数字序列转化为一眼可懂的成长曲线与目标线对比图。
    -   **说明区**：用简短的文字解释FIRE核心概念，降低理解门槛。

**最值得学习的设计：**
**“输入 → 实时计算 → 可视化反馈”的闭环体验。** 任何参数的调整都能在1秒内反映在图表和数字上，这种即时反馈让探索变得高效且有趣。它通过 **`x-model` 双向数据绑定** 和 **`$watch` 监听器** 优雅地实现了这一效果，是交互式工具类网页的典范。

## 【四】Prompt / AI 逻辑是如何被设计的？

> **请注意**：当前版本的代码**并未使用AI或Prompt**。它是一个纯粹基于确定性和财务公式的计算器。
>
> 但我们可以借此机会思考：**如果**要加入AI，可以如何设计？这能帮助你理解AI在工具类应用中的角色。

**假设我们要加入一个“AI财务建议”功能：**
-   **Prompt扮演的角色**：将用户的财务数据（输入模块的数据）转换成一个问题，提交给AI大语言模型（如GPT-4），请求其生成个性化的储蓄或投资建议。
-   **解决什么问题**：它解决的是“生成问题”——基于通用财务原则和用户的具体情况，**生成**一段定制化的、易于理解的文本建议，而不仅仅是冷冰冰的数字。
-   **Prompt中的关键变量**：用户的`当前年龄`、`目标退休年龄`（由`yearsToFire`推算）、`当前储蓄率`、`缺口大小`等都会被嵌入到Prompt中。例如：“请以专业理财顾问的口吻，为一位{currentAge}岁，计划{targetAge}岁退休，目前储蓄率为{rate}的用户，提供3条缩小财务缺口的可行建议。”
-   **如果只改Prompt**：你可以彻底改变AI输出的风格和内容重点。比如，把Prompt从“提供建议”改成“分析主要风险”，那么AI的输出就会从行动方案转向风险警示，而页面计算功能完全不变。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的计算器：

**第一步：保持结构不变，替换使用场景（最安全）**
-   **目标**：做一个“学习进度计算器”。
-   **操作**：复制整个HTML和JS结构。将“当前存款”改成“已学知识点”，“每年储蓄”改成“每日学习量”，“投资回报率”改成“学习吸收效率”，“FIRE目标金额”改成“课程总目标”。计算逻辑改为模拟知识积累过程。这是**换皮**，能让你熟悉所有模块如何连接。

**第二步：调整输入字段与核心计算逻辑**
-   **目标**：做一个“项目存钱罐计算器”，为某个目标（如旅行、买设备）存钱。
-   **操作**：
    1.  增加一个“目标总额”输入框，**取代**原来由“年支出/提现率”计算出的`fireNumber`。
    2.  简化输入：可以去掉“安全提现率”滑块。
    3.  修改JS中的`calculate()`函数，让其基于“当前存款”、“每月储蓄”和“时间”来推算何时能达到“目标总额”。**这是核心逻辑的定制**。

**第三步：改变输出形式或展示方式**
-   **目标**：让结果展示更生动。
-   **操作**：
    1.  将进度条改成一个小游戏化的视觉元素，比如一个随着进度填充的存钱罐图标。
    2.  在图表中增加一个“里程碑”标记，比如在达到目标的50%、80%时在曲线上标注出来。
    3.  用更鼓舞人心的文案替换原有的说明文字。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“通货膨胀率”输入**：
    -   **操作**：在输入面板增加一个滑块，让用户设定预期的年通胀率（如2%）。在`calculate()`函数中，让“目标金额”（`fireNumber`）和“年支出”随着模拟年份的增长而按通胀率增加。这会使模型更贴近现实。

2.  **引入“阶段性目标”或“人生大事”节点**：
    -   **操作**：增加一个“添加事件”按钮，允许用户在图表的特定年龄点标注“买房”、“子女教育”等事件，并预估其大额支出。在资产模拟计算中，在这些年份扣除相应金额，让曲线出现下跌，规划更全面。

3.  **切换可视化图表类型**：
    -   **操作**：在图表上方增加一个按钮组（如“曲线图/柱状图/面积图”）。修改`updateChart()`函数，根据用户选择，使用Chart.js的不同`type`（如`'bar'`）重新渲染图表。这能学习如何动态切换数据视图。

4.  **增加数据导出与分享功能**：
    -   **操作**：
        -   **导出**：增加一个“导出数据”按钮，将计算出的逐年资产数据转换为CSV格式字符串，并触发浏览器下载。
        -   **分享**：增加一个“生成分享图”按钮，使用`html2canvas`库将当前结果面板（特别是图表）截图，并生成一张可保存或分享的图片。

5.  **优化移动端体验**：
    -   **操作**：目前布局在手机上可能拥挤。使用更激进的响应式设计，例如在手机上将左右布局改为上下堆叠（`grid-cols-1`），调整图表高度，确保所有交互元素在触屏上易于操作。

## 【七】这个网页不适合做什么？（边界提醒）

-   **不适合作为精确的退休规划工具**：它忽略了**通货膨胀**、**收入增长**、**税率变化**、**社保养老金**、**突发医疗支出**等关键现实因素。计算结果是一个高度简化的理论模型。
-   **不适合预测短期市场波动**：“投资回报率”是一个假设的固定值，而现实市场波动巨大。切勿将计算结果等同于未来必然发生的收益。
-   **不适合替代专业咨询**：对于复杂的债务管理、税务优化、遗产规划或具体的投资产品选择，必须寻求持牌财务规划师或投资顾问的帮助。
-   **如果用户想做的是“实时股票分析”或“基金筛选”**：应该转向专门的金融数据平台（如东方财富、雪球）或量化分析工具，而不是这个基于长期假设的计算器。

**总结**：这个FIRE计算器是一个优秀的**教学原型**和**思维实验工具**。它成功地将一个复杂的财务概念，通过清晰的模块划分、实时的计算反馈和直观的可视化，变成了每个人都能上手探索的交互式体验。你的学习重点应是理解其“数据驱动UI”的架构，并在此基础上进行大胆的改造和创新。
