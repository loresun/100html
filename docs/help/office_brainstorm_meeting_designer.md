# 头脑风暴会议设计工具 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页解决的是 **“如何高效地设计和组织一场头脑风暴会议”** 的难题。

**使用场景**：
想象一下，你是一个产品经理、团队负责人或活动组织者。下周要开一个创意会，讨论“如何提升用户活跃度”。你希望会议不是漫无目的的闲聊，而是有结构、有产出、能让每个人都参与进来。但你不知道具体流程该怎么安排，用哪种方法，时间怎么分配，需要准备什么物料。这个工具就是你的“虚拟会议引导师”，帮你快速生成一份专业、可执行的会议设计方案。

**适合情况**：
- 需要快速为团队会议、工作坊、创意讨论会制定议程。
- 对头脑风暴方法不熟悉，希望获得结构化指导。
- 希望会议有明确的产出（如创意清单、行动计划），而不仅仅是讨论。

**不适合情况**：
- 需要即时、动态的团队协作（如实时白板）。
- 会议主题涉及高度机密或敏感信息（因为需要调用外部AI API）。
- 已经拥有非常成熟的会议流程模板，无需额外设计。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你需要填写一个表单，主要包括：
1.  **会议主题/问题**：你想讨论的核心议题。
2.  **会议时长**：从60到180分钟不等。
3.  **参与人数**：小型、中型或大型团队。
4.  **会议目标**：你希望这次会议具体达成什么。
5.  **参与者背景**：参会者的角色（如设计师、工程师）。
6.  **背景信息/限制条件**：任何需要提前知道的约束（如预算、时间）。

**用户通常会做哪几步操作？**
1.  **配置**：首次使用时，点击右上角“设置”，填入你的 DeepSeek API Key 并选择模型（推荐 R1）。
2.  **选择方法**：在左侧“选择头脑风暴方法”区域，点击一个你感兴趣的方法卡片（如“经典头脑风暴”、“SCAMPER法”）。
3.  **填写信息**：在“会议信息”表单中，逐一填写上述输入项。
4.  **勾选选项**：在“高级选项”中，按需勾选是否需要“破冰环节”、“投票机制”等。
5.  **生成设计**：点击底部橙色的“生成会议设计”按钮。
6.  **查看与使用**：在右侧“会议设计方案”区域等待并查看AI生成的完整方案，可以“复制”或“导出”为Markdown文件。

**输出结果长什么样？**
输出是一份详细的 **Markdown格式会议方案**，通常包含：
-   **会议概览**：目标、参与者、成功指标。
-   **详细议程**：分阶段（如破冰、发散、收敛、决策）的流程、时间、负责人、具体操作步骤。
-   **工具清单**：需要准备的白板、便利贴、在线工具等。
-   **主持人指南**：注意事项、引导话术、常见陷阱。
-   **行动计划**：（如果勾选）会后跟进步骤。

**有哪些容易忽略的使用细节？**
1.  **API Key是必须的**：不填API Key无法生成。点击“设置”填入，工具会帮你保存在浏览器本地。
2.  **“会议主题”和“会议目标”是必填项**：这是AI理解任务的核心，不填的话生成按钮是灰色的。
3.  **高级选项很有用**：特别是“设计投票决策机制”和“生成后续行动计划”，能极大提升会议产出质量。
4.  **可以展开“R1深度设计思路”**：如果使用R1模型，这里会展示AI的思考过程，是学习如何设计会议的好材料。
5.  **结果可以导出**：生成的方案可以一键导出为 `.md` 文件，方便分享和放入你的会议文档。

## 【三】核心结构拆解（学习重点）

这个页面清晰地分为 **输入、处理、输出** 三大模块。

**1. 输入配置模块**
*   **职责**：收集用户的所有意图和约束条件。
*   **组成**：
    *   **方法选择器**：让用户选择创意激发框架（如SCAMPER法），这决定了后续流程设计的核心逻辑。
    *   **信息表单**：收集会议的具体参数（主题、时长、人数等）。
    *   **高级选项**：让用户定制化需求（如是否需要破冰游戏）。
    *   **API设置面板**：管理调用AI引擎的钥匙（API Key）和选择“思考深度”（模型）。

**2. 逻辑处理模块（核心）**
*   **职责**：将用户的输入，转化为AI能理解的指令，并调用AI服务。
*   **流程**：
    *   **输入**：用户点击“生成”按钮。
    *   **处理**：
        1.  **组装Prompt**：前端代码将用户选择的方法、填写的表单内容，动态拼接成两份文本：
            *   `系统提示词 (System Prompt)`：定义AI的角色（专业引导师）、会议设计原则、所选方法的详细说明，以及**严格的输出格式模板**。
            *   `用户提示词 (User Prompt)`：简明扼要地复述用户的具体需求。
        2.  **调用API**：将组装好的Prompt发送给DeepSeek AI的接口。
        3.  **流式接收**：边接收AI返回的文字，边显示在页面上，体验更流畅。
    *   **输出**：原始的AI生成文本。

**3. 结果展示与交付模块**
*   **职责**：将AI生成的原始文本，美观地呈现给用户，并提供后续操作。
*   **组成**：
    *   **Markdown渲染器**：将AI返回的Markdown文本（带`#`标题、`-`列表）转换成美观的HTML格式。
    *   **思考过程展示**：如果使用R1模型，单独展示AI的“内心独白”，增加透明度和信任感。
    *   **动作按钮**：“复制”和“导出”功能，让方案能轻松融入用户的实际工作流。

**最值得学习的设计**
**“结构化Prompt工程”** 是本页面的精髓。它没有简单地把用户输入扔给AI，而是：
1.  **赋予角色**：让AI扮演“专业引导师”，锁定其回答的专业范围和语气。
2.  **提供知识**：在System Prompt中内置了不同头脑风暴方法的原理和流程，相当于给了AI一个“工具箱”。
3.  **规定格式**：通过一个极其详细的Markdown模板，严格规定了AI输出的结构和内容。这确保了每次生成的结果都**结构一致、内容完整、可直接使用**，而不是随机的、需要用户二次整理的段落。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色**
在这个页面中，Prompt是连接 **“用户模糊需求”** 和 **“AI具体创作”** 的 **“精密设计蓝图”**。它不是一个简单的问题，而是一份包含角色、背景知识、任务要求和成品规格的完整设计文档。

**它解决的是“生成问题”**
它主要解决“如何根据一组参数，生成一份结构化的文档”的问题。系统Prompt中大量的会议方法论知识和格式模板，是在“引导”AI进行内容生成，确保生成的内容既专业又符合规范。

**Prompt中的关键变量**
1.  **方法变量**：`${method.name}` 和 `getMethodDescription(selectedMethod.value)`。这是整个Prompt的“剧本”选择，决定了会议的核心流程。
2.  **表单变量**：如`${form.value.topic}`, `${form.value.duration}`等。这些是“剧本”的具体参数，用于填充到固定格式中。
3.  **条件变量**：通过`${form.value.includeIcebreaker ? ... : ''}`这种判断，动态地在Prompt中添加或移除“破冰环节”、“行动计划”等模块。

**如果只改Prompt，不改代码，会发生什么？**
整个应用的行为会发生根本性改变，因为AI的“工作说明书”变了。例如：
-   如果你在System Prompt中把AI的角色从“引导师”改成“敏捷教练”，生成的方案会充满“冲刺”、“站会”、“用户故事”等敏捷术语。
-   如果你修改输出格式模板，比如要求AI输出一个Excel表格的文本描述，那么右侧的结果就会以表格规划的形式呈现。
-   如果你在Prompt中增加一条规则：“所有建议必须符合成本低于1000元”，那么AI生成的所有方案都会考虑预算限制。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个类似工具：

**第一步：保持结构不变，替换使用场景（最安全）**
-   **目标**：做一个“周会日程生成器”或“项目复盘报告生成器”。
-   **操作**：
    1.  复制整个HTML文件。
    2.  修改标题和文案，如将“头脑风暴会议设计工具”改为“高效周会规划工具”。
    3.  将左侧的“头脑风暴方法”替换成“会议类型”（如：进度同步会、问题解决会、决策评审会）。
    4.  修改表单输入项，保留“时长”、“参与人”，将“会议主题”改为“本周核心议题”，将“会议目标”改为“希望达成的决议”，去掉“参与者背景”，增加“上周待办完成情况”。

**第二步：调整输入字段或Prompt**
-   **目标**：让你的工具更贴合新场景。
-   **操作**：
    1.  在`buildSystemPrompt`函数中，重写角色定义和原则。例如，角色改为“高效团队协作专家”，原则改为“明确议程、责任到人、会议纪要”。
    2.  重写输出格式模板，模仿现有Markdown结构，但内容改为周会所需的“上周总结”、“本周计划”、“风险与阻塞”、“决议”等部分。
    3.  修改`buildUserPrompt`函数，使其汇总你新表单里的字段。

**第三步：改变输出形式或展示方式**
-   **目标**：优化体验。
-   **操作**：
    1.  除了Markdown，可以尝试让AI生成一个简单的JSON数据，然后你用前端代码把这个JSON渲染成更直观的时间线或看板。
    2.  在结果区域增加一个“一键生成会议邀请邮件”按钮，将方案的核心内容自动填入邮件模板。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“知识库”输入，让方案更精准**：
    -   **操作**：在表单中增加一个“上传背景资料（可选）”的文本框或文件上传区域。用户可以将产品文档、用户反馈链接贴进去。在组装Prompt时，将这些信息以“以下是相关背景资料：”的形式追加到用户Prompt中。这样AI生成的方案会更贴合项目实际。

2.  **切换或增加AI模型，获得不同风格的方案**：
    -   **操作**：在API设置中，除了DeepSeek，增加对OpenAI GPT-4o、Claude 3.5 Sonnet或国内通义千问等模型的支持。不同模型的“性格”和知识侧重点不同，可以给用户提供选择，比如“GPT-4：更富创意”、“Claude：逻辑更严谨”。

3.  **将单次生成拆解为“多轮对话设计”**：
    -   **操作**：不要一次性生成全部方案。第一步，只让AI生成“会议议程框架”。第二步，用户可以对不满意的阶段（如“发散环节”）进行高亮，点击“优化此环节”，工具则针对这个环节发起新一轮更细致的AI对话，生成3个不同的细化方案供用户选择。这样交互性更强，用户控制度更高。

4.  **优化交互，提供“实时预览”和“模板库”**：
    -   **操作**：
        -   **实时预览**：在用户填写表单时，右侧不是空白的，而是显示一个根据已填内容实时变化的“方案骨架预览图”（仅显示结构标题），让用户有即时反馈。
        -   **模板库**：在“选择方法”旁边增加一个“从模板开始”按钮，点击后弹出几个经典场景（如“App新功能创意会”、“年度规划务虚会”）的预设模板，一键填充表单的大部分内容，用户只需微调。

5.  **增加“协作”功能**：
    -   **操作**：为生成的每份方案生成一个唯一的链接。用户可以将此链接分享给团队成员。团队成员打开后，可以在方案的每个部分（如“破冰游戏建议”）添加评论或点赞，共同完善这份会议设计。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合作为实时协作平台**：它只是一个**设计工具**，用于会前规划。它不能替代腾讯会议、Zoom、Miro、飞书文档等**实时沟通和协作工具**。会议中的实际讨论、画图、投票仍需在这些平台上进行。
2.  **不适合生成极度专业化、依赖深度领域知识的内容**：例如，你要设计一个“量子计算算法研讨会”或“新药临床试验方案讨论会”。虽然AI可能给出一个通用流程，但其中最关键的专业内容深度和准确性无法保证，仍需领域专家主导设计。
3.  **不适合在无网络或API失效时使用**：它的核心能力依赖云端AI服务。如果没网，或者你的API额度用完，工具将无法生成任何内容。它不是一个离线的模板库。
4.  **不适合完全替代人类的思考和判断**：AI生成的方案是一个优秀的起点和参考，但最终是否适用，还需要主持人根据团队文化、具体情境进行审核和调整。不能盲目执行AI给出的所有建议。

**如果你想做的是...**
-   **实时团队脑暴和画图**：请使用 **Miro、FigJam、腾讯文档白板**。
-   **管理复杂的项目计划和任务**：请使用 **Jira、Asana、飞书项目**。
-   **进行严肃的战略规划或财务建模**：请使用专业的 **咨询方法论、SWOT分析模板、Excel模型**，并结合专家讨论。

希望这份文档能帮助你不仅用好这个工具，更能理解其设计思想，创造出属于你自己的、解决特定问题的AI应用。
