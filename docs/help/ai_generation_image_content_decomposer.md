# 视觉素材拆解器 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你看到一张优秀的设计图（比如海报、社交媒体封面、电商主图），想学习它的版式、配色和结构，但不知道如何系统地分析时，这个工具能帮你。它就像一个“设计侦探”，把一张复杂的视觉图片，拆解成一份清晰的“复刻说明书”。

**适合什么情况？**
- 设计初学者想学习优秀作品的布局思路
- 需要快速分析竞品海报的设计结构
- 想复现某个喜欢的界面但不知从何下手
- 需要一份结构化的设计分析作为参考

**不适合什么情况？**
- 需要精确的颜色拾取（应该用取色器工具）
- 需要识别图片中的具体文字内容（应该用OCR工具）
- 需要生成可编辑的设计文件（应该用Figma/PS等设计软件）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. 一张图片（支持拖拽或点击上传）
2. 一个深度调节滑块（从1到5）

**用户通常会做哪几步操作？**
1. **上传图片**：把你想分析的图片拖到虚线框里，或者点击框内选择文件
2. **调整深度**：用滑块选择分析的详细程度（数字越大分析越细）
3. **点击拆解**：按下“开始拆解”按钮，等待分析完成

**输出结果长什么样？**
分析完成后，右侧会显示三部分内容：
- **版式结构摘要**：用文字描述图片的整体布局
- **可复刻结构清单**：列出具体的栅格比例、间距、字体层级等
- **配色建议**：提取图片中的主要颜色

**容易忽略的使用细节：**
- 上传后可以点击“移除图片”重新选择
- 深度滑块有5个档位，档位越高输出的建议越具体
- 当前版本使用的是“模拟数据”，不是真实的AI分析结果
- 分析过程大约需要1秒钟（模拟延迟）

## 【三】核心结构拆解（学习重点）

这个页面由三个主要模块组成：

### 模块1：输入控制区（左侧）
- **图片上传模块**：负责接收用户图片，提供预览和错误提示
- **深度调节模块**：让用户控制分析的详细程度
- **触发按钮**：连接输入和输出的“开关”

**职责**：收集用户的所有输入，验证数据有效性，为分析做准备。

### 模块2：结果展示区（右侧）
- **状态提示**：显示“请上传图片”或“正在分析”等状态
- **结构化结果**：将分析结果分成三个清晰的板块展示
- **建议提示**：提供使用技巧和后续改进方向

**职责**：清晰、有条理地呈现分析结果，让用户一目了然。

### 模块3：逻辑处理层（JavaScript部分）
- **状态管理**：跟踪图片、分析状态、深度设置等所有变量
- **事件处理**：响应用户的拖拽、点击、滑块变化等操作
- **模拟分析**：根据深度设置生成对应的模拟数据

**输入 → 处理 → 输出 的逻辑链路：**
```
用户上传图片 + 设置深度
    ↓
点击“开始拆解”按钮
    ↓
触发 startAnalysis() 函数
    ↓
调用 buildMockResult(depth) 生成模拟数据
    ↓
将结果渲染到右侧展示区
```

**最值得学习的设计：**
**“深度调节”与“结果粒度”的联动设计**。滑块不仅改变一个数字，还直接影响：
1. 摘要内容的多少
2. 结构清单的类别
3. 建议的详细程度

这种设计让工具既适合快速浏览，也适合深度学习，用户体验很灵活。

## 【四】Prompt / AI 逻辑是如何被设计的？

**当前状态说明**：这个版本使用的是“模拟数据”，没有真正的AI调用。但它的结构已经为接入AI做好了准备。

**如果接入AI，Prompt会扮演什么角色？**
Prompt会成为“分析指令”，告诉AI：
1. 要分析什么（这张图片）
2. 分析到什么程度（根据深度值）
3. 输出什么格式（结构化的三个部分）

**它解决的是“理解问题”还是“生成问题”？**
主要是“理解问题”——让AI理解图片的视觉结构，而不是生成新图片。

**Prompt中的关键变量会是：**
1. `{image}`：用户上传的图片
2. `{depth}`：分析深度（1-5）
3. `{output_format}`：要求返回JSON格式，包含summary、structure、palette三个字段

**如果只改Prompt，不改代码，会发生什么？**
- 可以让AI关注不同的设计元素（比如只分析配色，或只分析字体）
- 可以改变输出的详细程度和侧重点
- 可以要求用不同的语言描述
- 但界面展示方式不会改变

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 把“视觉素材拆解”改成你的场景，比如“菜谱分析器”、“旅行照片规划器”
- 只修改文字：标题、说明、按钮文字、结果标题
- **不要动任何代码结构**，先让页面“看起来”是你的工具

**第二步：调整输入字段**
- 如果不需要深度调节，可以隐藏或替换滑块
- 可以增加其他输入，比如“分析重点选择”（配色/布局/文字）
- 修改 `buildMockResult()` 函数中的模拟数据，让它符合你的场景

**第三步：改变输出形式**
- 修改右侧的三个结果板块，让它们展示你的内容
- 可以增加或减少展示板块
- 可以改变展示样式（比如把颜色块改成图标）

**从哪里下手最安全？**
从 **修改文字和模拟数据** 开始。找到代码中的：
1. HTML中的标题、说明文字
2. `buildMockResult()` 函数中的数组内容
3. 颜色值

先改这些，页面就能变成“你的版本”，而且不会出错。

## 【六】3–5个可直接尝试的改造方向

### 1. 增加“分析重点”选择
**具体操作**：
- 在深度滑块下方增加几个复选框：
  - [ ] 重点分析配色
  - [ ] 重点分析版式  
  - [ ] 重点分析字体
- 修改 `buildMockResult()`，根据勾选情况返回不同的数据

**效果**：让用户能定制分析方向，更符合个性化需求。

### 2. 接入真实的AI API
**具体操作**：
1. 注册一个免费的AI服务（如OpenAI、Google Gemini）
2. 替换 `startAnalysis()` 中的 `setTimeout` 部分
3. 调用AI的视觉识别API，把图片和深度设置传给AI
4. 将AI返回的结果赋值给 `this.result`

**效果**：从“模拟工具”变成“真实AI工具”，分析结果更准确。

### 3. 增加“历史记录”功能
**具体操作**：
1. 在页面底部增加一个区域
2. 每次分析后，把结果摘要保存到 `localStorage`
3. 显示最近3次的分析记录，点击可以重新查看

**效果**：方便用户对比多次分析结果，提升工具实用性。

### 4. 优化为“分步引导”界面
**具体操作**：
1. 把当前的单页拆成三个步骤：
   - 步骤1：上传图片
   - 步骤2：设置选项（深度、重点）
   - 步骤3：查看结果
2. 用“上一步/下一步”按钮导航

**效果**：对新用户更友好，操作路径更清晰。

### 5. 增加“导出报告”功能
**具体操作**：
1. 在结果区域增加“导出PDF”按钮
2. 点击后，将当前结果生成格式化的PDF文档
3. 可以使用 `jsPDF` 等库实现

**效果**：让用户能把分析结果保存下来，方便后续参考。

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性说明：
1. **不是精确的设计工具**
   - 颜色提取是模拟的，不是从图片真实取色
   - 尺寸测量是估算的，不是像素级精确
   - **如果你需要精确数据**：应该使用Figma、Photoshop等专业设计软件

2. **不是内容识别工具**
   - 不会识别图片中的具体文字内容
   - 不会理解图片的语义含义
   - **如果你需要识别文字**：应该使用OCR工具（如Google Lens）

3. **不是生成式工具**
   - 不会根据分析生成新的设计稿
   - 不会提供代码实现
   - **如果你需要生成代码**：应该使用Figma to Code类工具

4. **不适合复杂设计分析**
   - 对于非常复杂、非标准的布局，分析效果有限
   - 对于动态、交互式的设计无法分析
   - **如果你需要分析完整产品**：应该进行人工走查和用户测试

**记住**：这个工具的最佳定位是“学习辅助”和“灵感参考”，而不是“生产工具”。它帮你理解“这个设计为什么好看”，而不是帮你“做出一个一样好看的设计”。
