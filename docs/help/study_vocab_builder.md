# 词汇构建器 - 学习帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你正在准备一场语言考试（如雅思、JLPT），或者需要快速掌握某个专业领域（如商务英语、医学英语）的词汇。传统方法是手动查找单词、编写例句，这个过程既耗时又难以保证质量。

这个网页就是你的**个人词汇生成助手**。它能在几秒钟内，根据你指定的主题、数量和风格，生成一套结构化的词汇学习卡片，包含释义、例句和记忆提示。

**适合场景：**
- 备考特定语言考试，需要针对性词汇
- 学习新行业术语，希望快速建立词汇库
- 教师为学生准备课堂词汇材料
- 语言学习者想围绕兴趣主题（如“旅行”、“美食”）扩展词汇

**不适合场景：**
- 需要深入语法讲解或长篇课文分析
- 需要真人互动对话练习
- 需要查询特定单词的详细词源或历史用法
- 需要生成大量（超过20个）词汇的批量处理

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **主题/考试/行业**：你想学习的词汇领域，如“商务英语”、“JLPT N2”
2. **词汇数量**：想生成多少个单词/短语（5-20个）
3. **输出风格**：选择“实用”、“考试”或“场景化”三种风格之一

**用户通常会做哪几步操作？**
1. 首次使用时，点击右上角“API设置”，输入你的DeepSeek API密钥并保存
2. 在左侧面板填写主题、选择数量（如10个）和风格（如“场景化”）
3. 点击“生成词汇包”按钮
4. 等待几秒钟，右侧就会显示生成的词汇清单

**输出结果长什么样？**
每个词汇条目会以卡片形式展示，包含：
- **单词/短语**（如“negotiation”）
- **场景标签**（如“商务”）
- **简明释义**（如“谈判，协商”）
- **例句**（如“The negotiation lasted for three hours.”）
- **记忆提示**（如“联想：negoti-（协商）+ -ation（名词后缀）”）

**有哪些容易忽略的使用细节？**
- 右上角的“V3”和“O1”按钮可以切换AI模型（V3响应快，O1思考更深）
- 词汇数量建议从10个开始尝试，太多可能导致生成时间变长
- 如果生成失败，检查API密钥是否正确，或尝试切换模型
- 生成的词汇卡片可以直接复制到你的笔记软件中使用

## 【三】核心结构拆解（学习重点）

这个页面由三个主要模块组成：

**1. 控制面板模块（左侧）**
- **职责**：收集用户需求，触发生成动作
- **包含**：主题输入框、数量选择器、风格下拉菜单、生成按钮
- **逻辑**：用户填写 → 点击生成 → 发送请求 → 接收数据 → 更新显示

**2. 展示面板模块（右侧）**
- **职责**：清晰展示生成的词汇内容
- **包含**：词汇卡片容器，每张卡片有固定字段（单词、释义、例句等）
- **逻辑**：接收数据数组 → 循环渲染 → 格式化显示

**3. 配置模块（弹窗）**
- **职责**：管理API连接设置
- **包含**：API密钥输入、模型选择、保存按钮
- **逻辑**：用户配置 → 本地存储 → 后续调用使用

**输入 → 处理 → 输出链路：**
```
用户输入（主题+数量+风格）
    ↓
拼接成Prompt文本
    ↓
通过API发送给AI模型
    ↓
AI返回JSON格式数据
    ↓
解析JSON，提取vocab数组
    ↓
渲染到右侧卡片区域
```

**最值得学习的设计：**
**“配置与使用分离”**的设计思路。API配置被封装在独立的弹窗和共享脚本中，主页面只关注核心功能。这使得：
- 代码更清晰，维护更容易
- 用户可以安全地保存密钥，无需每次输入
- 未来扩展其他AI服务时，只需修改配置部分

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色：**
Prompt在这里是**精确的需求说明书**。它告诉AI：“我需要什么格式、什么内容、如何返回”。

**解决的是“生成问题”：**
AI需要根据模糊的用户需求（如“商务英语词汇”）生成具体、结构化、可用的学习内容。

**Prompt中的关键变量：**
1. `“${this.topic}”` - 用户输入的主题
2. `共 ${this.count} 个词条` - 用户指定的数量
3. `风格：${this.style}` - 用户选择的风格
4. **最重要的**：JSON结构模板，明确要求返回特定字段

**如果只改Prompt，不改代码：**
- 改主题描述：从“商务英语”改为“医学英语”，内容领域完全改变
- 改风格描述：从“场景化”改为“考试重点”，生成内容会更偏向考点
- 改JSON结构：增加“同义词”字段，AI会返回包含同义词的数据，但页面无法显示（因为前端没对应渲染）
- 改系统指令：从“语言学习教练”改为“词汇记忆专家”，AI的角色和语气会变化

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最安全！不改代码，只改文字和Prompt
- 例如：做成“成语学习器”，把“主题”改为“成语主题”（如寓言类）
- 修改Prompt中的描述即可，页面布局完全不变

**第二步：调整输入字段或Prompt**
- 增加一个“难度级别”下拉菜单（初级/中级/高级）
- 在Prompt中加入这个新变量：`难度：${difficulty}`
- 在JavaScript中增加对应的数据绑定

**第三步：改变输出形式或展示方式**
- 把卡片式改为表格式
- 增加“发音”按钮，点击可播放单词读音
- 添加“收藏”功能，让用户标记重要词汇

**从哪里下手最安全？**
从**修改主题和Prompt描述**开始。这是零风险改动，不会破坏页面功能。比如先做一个“编程术语学习器”，测试成功后再考虑增加功能。

## 【六】3–5个可直接尝试的改造方向

**1. 增加“母语”选择功能**
- **操作**：在控制面板增加“翻译为”下拉菜单（英语、日语、韩语等）
- **修改**：Prompt中加入“请提供${language}释义”
- **效果**：帮助不同母语的学习者使用

**2. 添加“导出”功能**
- **操作**：在展示面板顶部增加“导出为Anki卡片”按钮
- **修改**：将vocab数组转换为Anki支持的CSV格式并下载
- **效果**：一键导入到记忆软件，提升学习效率

**3. 实现“渐进生成”模式**
- **操作**：将“词汇数量”改为“每日5词”，每次生成后本地保存进度
- **修改**：使用localStorage记录已学词汇，下次生成时排除已学
- **效果**：变成每日词汇学习工具，避免重复

**4. 增加“语音朗读”功能**
- **操作**：每张卡片旁添加喇叭图标
- **修改**：调用浏览器Web Speech API或第三方语音服务
- **效果**：点击即可听到单词发音，强化记忆

**5. 改为“多轮对话”模式**
- **操作**：点击词汇卡片后，可追问“请给更多例句”或“易混淆词对比”
- **修改**：为每个词汇存储对话历史，实现上下文交互
- **效果**：从一次性生成变为交互式学习助手

## 【七】这个网页不适合做什么？（边界提醒）

**1. 不适合做精确的学术研究**
- **局限**：AI生成的释义和例句可能不够学术严谨
- **替代方案**：使用专业词典API（如牛津、韦氏）获取权威解释

**2. 不适合生成超长内容**
- **局限**：一次最多20个词汇，且无分页/滚动加载
- **替代方案**：需要大量词汇时，应使用数据库驱动的词汇库

**3. 不适合实时对话练习**
- **局限**：这是单向生成工具，无法进行对话互动
- **替代方案**：使用ChatGPT对话界面或专门的语言陪练APP

**4. 不适合深度语法分析**
- **局限**：只提供词汇层面的信息，不分析句子结构
- **替代方案**：使用语法检查工具或请教语言教师

**5. 不适合离线使用**
- **局限**：完全依赖API连接，无网络时无法工作
- **替代方案**：开发时可考虑添加本地词汇库作为后备方案
