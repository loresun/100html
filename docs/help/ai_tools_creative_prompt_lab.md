# 创意提示语实验台 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你正在准备一个创意项目——可能是写一篇小说、画一幅画，或者设计一个视频脚本。你心里有个大概的主题，但总觉得思路不够开阔，想不出足够多、足够有创意的具体方向。这个网页就是你的“创意火花发生器”。

**适合的使用场景：**
- 当你有一个模糊的创作主题（如“城市夜生活”），但需要具体的、可执行的创意提示来激发灵感。
- 当你希望从多个特定维度（如“反差”、“情绪”）来探索一个主题，而不是漫无目的地发散。
- 在头脑风暴的初期，快速生成一批高质量的创意种子，供后续筛选和深化。

**不适合的情况：**
- 你需要一个完整、可直接使用的成品（如一篇完整的文章或一张画好的图）。它只提供“提示语”，不负责执行。
- 你的主题非常专业或技术性极强，需要领域专家进行深度分析。
- 你希望进行长时间的、结构化的创意工作坊，这个工具更适合快速启动。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：页面右上角有一个齿轮图标（⚙️），点击它。在弹出的窗口中，输入你的 **DeepSeek API Key**（你需要自行在 DeepSeek 官网注册获取），然后点击“保存配置”。这是让网页能工作的第一步。

2.  **输入你的想法**：
    *   **创作主题**：在页面中央最大的输入框里，写下你的核心想法，比如“未来城市”、“孤独的宇航员”或“夏日回忆”。
    *   **维度标签**：页面已经预置了几个标签（如“反差”、“情绪”）。你可以直接使用它们，它们代表了提示语生成的不同角度。

3.  **生成提示语**：点击蓝色的 **“生成提示语”** 按钮。稍等片刻（你会看到一个旋转的加载图标），页面下方的蓝色区域就会显示出 AI 为你生成的 5 条创意提示语。

4.  **查看结果**：输出结果通常是 5 条独立的、格式清晰的文本提示。每一条都可能是一个故事开头、一个画面描述或一个创作方向。例如：“一个在霓虹灯下寻找失物的侦探，背景是潮湿的雨夜和模糊的倒影。”

**容易忽略的细节：**
*   **API Key 是私密的**：务必保管好你的 API Key，不要分享给他人。这个 Key 只保存在你浏览器的本地存储中，不会上传到其他服务器。
*   **标签是固定的**：当前版本的标签是预设的，无法在页面上直接添加或删除。但你可以通过修改代码来改变它们（见下文）。
*   **模型选择**：在设置中，你可以选择不同的 AI 模型（如 DeepSeek Chat 或 Reasoner），它们生成的结果风格和逻辑性可能略有不同。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个模块，像一个创意生产线：

1.  **控制面板模块**（页面顶部蓝色卡片内）：
    *   **职责**：接收用户的原始创意输入。
    *   **组成**：一个主题输入框、一组固定的维度标签、一个生成按钮。
    *   **逻辑**：用户在这里“投料”（主题+标签），然后按下“启动”按钮。

2.  **结果展示模块**（控制面板下方）：
    *   **职责**：清晰、美观地呈现 AI 的生成结果。
    *   **组成**：一个带有背景色的矩形区域，内部显示多行文本。
    *   **逻辑**：它是生产线的“输出口”，将非结构化的 AI 回复以整洁的格式展示出来。

3.  **AI 引擎模块**（隐藏在代码中的 `callLLM` 函数）：
    *   **职责**：作为“翻译官”和“调度员”，将用户的输入打包成 AI 能理解的格式（Prompt），并调用外部 API 获取结果。
    *   **逻辑**：`用户输入` → `组装成特定格式的Prompt` → `发送给DeepSeek API` → `接收并返回AI的回复`。这是整个应用最核心的“大脑”连接部分。

4.  **配置管理模块**（点击齿轮弹出的设置窗口）：
    *   **职责**：管理应用运行所需的外部密钥和参数，并提供持久化存储。
    *   **逻辑**：用户输入 API Key → 点击保存 → 信息被加密存储在浏览器本地 → 每次打开页面自动读取。这实现了“一次配置，多次使用”。

**最值得学习的设计：**
**“输入-组装-调用-展示”的清晰管道**。整个应用没有复杂的逻辑，它完美地演示了如何将用户在前端的简单操作，通过一个精心设计的 Prompt，转化为 AI 的有价值输出，并友好地展示回来。这种 **“最小可行产品(MVP)思维”** 和 **“关注核心链路”** 的设计，是构建 AI 应用时最应该首先掌握的。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，**Prompt 是连接人类模糊意图与 AI 具体能力的“翻译指令”**。

1.  **扮演的角色**：Prompt 在这里解决的是一个 **“理解与生成问题”**。它需要让 AI 理解两件事：用户的**任务**（生成创意提示语）和任务的**约束**（基于特定主题和维度，输出5条）。

2.  **关键变量**：
    *   **`${topic.value}`**：用户输入的主题，是创意的核心。
    *   **`${tags.value.join('、')}`**：预设的维度标签，是引导 AI 思考方向的关键。它们被直接拼接进 Prompt，告诉 AI “请从这些角度思考”。
    *   **系统指令**：`你是创意提示词设计师，输出 5 条提示语。` 这设定了 AI 的角色和基础任务。

3.  **Prompt 的变化效应**：
    如果只修改 Prompt，不改代码，整个应用的行为和产出将发生根本性变化。例如：
    *   将系统指令改为 `你是一个严厉的文学评论家`，输出可能会变成对主题的批判性分析，而非创意提示。
    *   将用户 Prompt 改为 `请将主题“${topic.value}”写成一个三行俳句`，输出就会从5条提示语变成一首诗。
    *   在 Prompt 中加入 `每条提示语不超过10个字`，输出的长度和密度就会改变。

**核心启示**：在这个应用中，**代码搭建了舞台和流程，而 Prompt 才是导演和剧本**。调整 Prompt 是成本最低、效果最直接的改造方式。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个“安全”的路径，一步步创造出属于你的 AI 小工具：

**第一步：替换“外壳”（最安全）**
保持所有代码逻辑完全不变，只修改文字和视觉元素。
1.  修改 `<title>` 和 `<h1>` 中的标题，例如改为“短视频脚本灵感生成器”。
2.  修改说明文字 `<p class="text-slate-500">`。
3.  替换预置的 `tags` 数组，比如改成 `['搞笑', '反转', '温情', '卡点']`。
4.  修改输入框的 `placeholder`，比如“请输入视频核心内容”。
5.  修改系统指令中的角色，比如 `你是短视频编导，输出 5 个脚本创意。`
至此，你已经得到了一个功能相同但领域全新的应用。

**第二步：调整“输入管道”**
在第一步的基础上，增加或改变输入方式。
1.  **增加下拉框**：让用户从“文章类型”、“绘画风格”、“音乐流派”等列表中选择，而不仅仅是输入主题。
2.  **让标签可编辑**：将固定的 `tags` 数组改为允许用户自由添加、删除的标签输入功能。
这一步开始涉及 Vue 数据绑定的修改，但结构依然清晰。

**第三步：重塑“输出形式”**
改变结果的展示方式，使其更符合你的新场景。
1.  如果生成的是“脚本”，可以将结果区域改为多个卡片，分别显示“标题”、“场景”、“对话”。
2.  如果生成的是“营销文案”，可以增加一个“复制单条”按钮。
3.  使用更丰富的 HTML 元素（如列表、表格）来结构化展示 AI 的回复。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格参考”输入**：在主题输入框下增加一个文本区域，让用户粘贴一段他们喜欢的文字风格（如某位作家的段落），并将此内容加入 Prompt，例如：“请模仿以下文字的写作风格：${styleText}”。这能极大地控制生成结果的语感和调性。

2.  **实现“历史记录”功能**：在页面侧边或底部增加一个区域，使用 `localStorage` 将每次生成的主题和结果（或前几条）保存下来。用户可以回顾、重用或对比之前的灵感。这是提升工具实用性的关键一步。

3.  **拆分为“引导式”多步页面**：将单页应用拆解。**第一页**：选择创作类型（写诗/写文案/想点子）。**第二页**：根据类型，动态显示不同的输入项（如写诗需输入“韵律”，想点子需输入“目标人群”）。**第三页**：展示结果。这能处理更复杂的输入逻辑。

4.  **优化交互体验**：
    *   **一键复制**：为每一条生成的提示语添加一个“复制”图标，点击后直接复制该条内容到剪贴板。
    *   **点赞/收藏**：在每条结果旁添加“👍”按钮，将用户最喜欢的提示语单独保存。
    *   **重新生成单条**：对某一条不满意的结果，可以单独针对它进行重新生成。

5.  **切换或融合多个 AI 模型**：在设置中增加更多模型选项（如 OpenAI 的 GPT， Anthropic 的 Claude），甚至设计一个“对比生成”功能，让用户可以用同一个 Prompt 同时调用两个模型，并排查看结果，体会不同模型的特色。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合生成精确、无误的专业内容**：它是一个“灵感实验台”，而非“事实核查器”或“专业编辑器”。对于法律文书、医疗建议、精确代码等容错率低的内容，绝不可依赖其直接产出。

2.  **不适合进行深度、复杂的多轮对话**：它的设计是“单次请求-响应”模式。如果你需要与 AI 就一个创意进行多轮深入的探讨、修改和迭代，应该使用 ChatGPT、Claude 等聊天界面本身，而不是这个工具。

3.  **不适合处理高度结构化或格式化的输出**：虽然可以修改 Prompt 来让 AI 输出 JSON 或 Markdown 表格，但本页面的结果展示区域只是一个简单的文本块。如果需要复杂的数据结构，你需要大幅修改前端代码来解析和渲染。

4.  **不适合作为唯一的创意来源**：它的作用是“激发”和“拓展”，而不是“替代”。最优秀的创意依然来源于你对生活的观察、深度的思考以及专业的技能。请将它视为一副好用的“脑力助跑器”，而非“自动创作机”。
