# 构图提示词生成器 - 学习与使用指南

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景**：当你需要为AI绘画（如Midjourney、Stable Diffusion）或摄影创作构思画面构图时，却不知道如何用专业、准确的“提示词”来描述想要的画面效果。比如，你想画一张“静谧的森林小屋”，但不知道如何描述它的镜头角度、光线氛围和空间层次。

- **适合**：AI绘画新手、摄影爱好者、内容创作者、需要快速获得构图灵感的任何人。
- **不适合**：需要生成完整图像（它只生成文字提示）、需要处理已有图片、需要极其精确的物理参数（如焦距、光圈值）。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **场景类型**：选择你的画面主体（人物、产品、风景、室内）。
    *   **镜头风格**：选择你想要的镜头感觉（广角、长焦、俯拍、仰拍）。
    *   **参考情绪/主题**：用几个词描述你想要的氛围（如“电影感、孤独、未来科技”）。

2.  **用户通常会做哪几步操作？**
    1.  首次打开，点击右上角“API设置”，填入你的DeepSeek API Key。
    2.  在左侧面板，依次选择“场景类型”和“镜头风格”。
    3.  在“参考情绪/主题”框中，输入你的想法。可以点击“构图词库”按钮，从分类词库中一键添加专业词汇（如“三分法构图”、“前景遮挡”）。
    4.  点击蓝色的“生成构图提示词”按钮。
    5.  等待几秒，右侧会显示生成结果。

3.  **输出结果长什么样？**
    结果会以三个深色卡片的形式展示：
    *   **构图提示词**：可直接复制到AI绘画工具中的提示词。
    *   **镜头语言描述**：解释了为什么这样构图，以及机位、景别等。
    *   **光线/景深建议**：关于打光、阴影和虚实焦点的建议。
    每个部分都有独立的“复制”按钮，上方还有“复制全部”和多种格式下载按钮。

4.  **有哪些容易忽略的使用细节？**
    *   **API Key是必须的**：不配置就无法生成。它保存在你的浏览器本地，下次打开无需重复输入。
    *   **“构图词库”是灵感来源**：如果你不知道写什么，打开词库看看，点击关键词会自动添加到输入框。
    *   **可以切换模型**：顶部有“V3”（通用）和“R1”（推理）两个按钮，对于复杂描述，R1可能给出更细致的分析。
    *   **情绪描述是关键**：这里输入的内容越具体、越有画面感，生成的结果就越精准。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个模块：

1.  **控制面板模块（左侧）**
    *   **职责**：收集用户的所有创作意图。它通过**按钮选择**（场景、镜头）和**文本框输入**（情绪）来获取结构化与非结构化的需求。
    *   **设计亮点**：将专业的选择（如镜头风格）做成了直观的按钮，降低了用户的理解门槛。“构图词库”是一个**可扩展的灵感池**，有效解决了用户“词穷”的问题。

2.  **AI处理引擎模块（核心逻辑）**
    *   **职责**：将用户的输入，打包成一个给AI（DeepSeek）的“问题”（即Prompt），并处理AI返回的答案。
    *   **逻辑链路**：
        *   **输入**：用户选择的 `场景类型`、`镜头风格`、`情绪主题`。
        *   **处理**：将这些变量填入一个预设好的“问题模板”（User Prompt）中，连同“角色设定”（System Prompt）一起发送给AI API。
        *   **输出**：接收AI返回的文本，从中提取出格式化的JSON数据（包含三个字段）。

3.  **结果展示模块（右侧）**
    *   **职责**：清晰、美观地呈现AI生成的结构化内容，并提供便捷的后续操作（复制、下载）。
    *   **设计亮点**：**结果卡片化**，每个部分独立且重点突出。提供了**多种输出格式**（复制、TXT、Markdown、CSV），满足了不同场景下的使用需求（如直接使用、存档、导入其他工具）。

4.  **辅助功能模块（弹窗）**
    *   **职责**：处理配置（API设置）和提供额外帮助（构图词库）。
    *   **设计亮点**：将非核心但必要的功能（如API设置）以**模态弹窗**形式隐藏，保持了主界面的简洁。

**最值得学习的设计**：
**“结构化输入 + 模板化Prompt + 结构化输出”的完整闭环**。它没有让用户自由发挥写Prompt，而是通过界面引导用户输入关键信息，再由程序自动组装成高质量的Prompt，最后将AI返回的非结构化文本解析成清晰的结构。这大大提升了工具的易用性和输出质量。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色**：它是连接用户意图和AI能力的“翻译官”和“任务书”。System Prompt定义了AI的**角色**（专业摄影构图顾问），User Prompt则给出了具体的**任务指令**和**输出格式要求**。
2.  **解决什么问题**：主要解决“**生成问题**”。它要求AI基于给定的条件（场景、镜头、情绪），创造性地生成一套专业的构图描述方案。
3.  **关键变量**：User Prompt中的 `场景类型`、`镜头风格`、`参考情绪/主题` 这三个部分，是每次生成时唯一变化的内容，它们直接决定了AI的思考方向。
4.  **如果只改Prompt**：代码不变，只修改System或User Prompt，会彻底改变这个工具的行为。例如：
    *   把System Prompt改成“你是一位国画大师”，它生成的就会是国画构图建议。
    *   在User Prompt中增加“请用英文输出”，结果就会变成英文。
    *   修改输出JSON的字段，比如增加一个“色彩建议”字段，那么右侧展示的结果也会需要相应调整（这步就需要改代码了）。

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

1.  **第一步：替换领域，保持骨架**
    *   **目标**：做一个“短视频脚本创意生成器”。
    *   **操作**：保持HTML/CSS/Vue的页面结构完全不变。
    *   **修改**：
        *   将“场景类型”改为“视频类型”（如“产品测评”、“知识科普”、“Vlog”）。
        *   将“镜头风格”改为“叙事风格”（如“快节奏剪辑”、“一镜到底”、“访谈式”）。
        *   将“参考情绪/主题”改为“核心创意/关键词”。
        *   将“构图词库”改为“脚本元素库”（如“开场悬念”、“痛点提问”、“金句总结”）。
        *   修改页面标题和所有文字提示。

2.  **第二步：调整Prompt与输出**
    *   **操作**：修改JavaScript中的 `systemPrompt` 和 `userPrompt` 变量。
    *   **修改**：
        *   `systemPrompt`：改为“你是一位资深短视频编导，擅长生成吸引人的短视频脚本创意。”
        *   `userPrompt`：调整输出JSON的字段，例如：`scriptHook`（开场钩子）、`sceneFlow`（场景流程）、`copywritingTips`（文案建议）。
    *   此时，点击生成，AI返回的内容就已经变了，但页面展示的还是旧字段。

3.  **第三步：改变输出展示**
    *   **操作**：修改右侧结果展示部分的HTML和JS中对应的字段名。
    *   **修改**：
        *   在HTML中，将“构图提示词”、“镜头语言描述”等标题和绑定变量（`{{result.xxx}}`）换成你自己的新字段（如`{{result.scriptHook}}`）。
        *   在JS的 `downloadTxt`、`downloadMarkdown` 等函数中，更新拼接文本时使用的字段名。
    *   **至此，一个属于你的新工具就诞生了。**

**最安全的起点**：从**第一步**开始。先只改文字和选项，不碰代码逻辑，你能立刻看到一个外观全新的工具，这能给你带来巨大的信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让提示更精准**
    *   **操作**：在控制面板增加一个“画幅比例”选择（如16:9、1:1、9:16）或“时代背景”选择（现代、复古、赛博朋克、古风）。
    *   **效果**：将这些新变量加入到User Prompt中，AI生成的建议会更具针对性。

2.  **更换或扩展AI模型后端**
    *   **操作**：在API设置弹窗中，增加一个模型选择下拉框（如DeepSeek、GPT-4o、Claude等）。修改 `callDeepSeek` 函数，使其能根据选择动态改变请求的URL和参数。
    *   **效果**：用户可以对比不同模型的效果，或在自己有多个API密钥时灵活选择。

3.  **增加“历史记录”功能**
    *   **操作**：使用 `localStorage` 将每次的输入和输出结果保存为一个数组。在页面底部或侧边栏增加一个“历史”按钮，点击后可以查看、复用或删除之前的记录。
    *   **效果**：方便用户回溯和迭代自己的创意，工具实用性大大提升。

4.  **优化交互体验**
    *   **操作**：为“生成”按钮增加一个快捷键（如`Ctrl/Cmd + Enter`）。在结果区域，为每个卡片添加“重新生成此部分”的按钮，只修改对应部分的Prompt并调用AI。
    *   **效果**：提升操作效率，允许用户对不满意的部分进行微调，而无需全部重来。

5.  **拆分为“快速模式”与“专家模式”**
    *   **操作**：默认是现在的快速模式。增加一个开关，切换到专家模式后，展开更多高级选项，如“构图权重”、“排除元素”、“参考艺术家风格”等输入框。
    *   **效果**：兼顾了新手的易用性和高阶用户的深度定制需求。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合直接生成图片**：它是一个“提示词”生成器，不是AI绘画模型本身。你需要将生成的文字复制到Midjourney、DALL-E等工具中才能出图。
2.  **不适合进行精确的摄影技术规划**：它给出的“光线/景深建议”是艺术性和方向性的（如“侧逆光营造轮廓”），而非精确的技术参数（如“f/2.8， 1/200s， ISO 100”）。如需后者，应使用专业的摄影规划软件或查阅器材手册。
3.  **不适合作为唯一的创作判断**：AI生成的建议是基于常见模式和数据的组合，可能缺乏真正的突破性创意。它最适合用于**启发灵感**和**补充专业知识**，而不应完全替代创作者本人的思考和决策。
4.  **不适合处理高度定制化的商业需求**：对于品牌视觉规范极其严格、需要与具体产品细节深度结合的商业项目，此工具生成的通用建议可能不够用，仍需专业设计师进行原创构思。

**总结**：这个网页是一个出色的 **“创意催化剂”** 和 **“专业术语翻译器”** 。它降低了专业构图知识的应用门槛，将模糊的感觉转化为可执行的指令。通过理解它的结构并动手模仿，你完全可以打造出适用于写作、编程、营销等任何领域的“专属创意助手”。
