# 平行宇宙模拟器 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景**：
你有没有想过“如果当初我做了另一个选择，现在会怎样？”这个网页就是为你这种“如果”的念头而生的。它不是一个算命工具，而是一个**思维实验沙盘**。当你站在人生的十字路口，对过去的选择感到一丝遗憾，或者对未来感到迷茫时，它可以帮你展开想象，理性地推演另一种人生的可能性，从而更好地理解自己、接纳当下。

*   **适合**：进行自我反思、减轻选择焦虑、激发创意写作灵感、作为心理咨询或教练对话的辅助工具。
*   **不适合**：预测未来、做出重大人生决策、寻求绝对正确的答案。它生成的是基于你提供信息的**可能性叙事**，而非事实。

## 【二】使用方式（给第一次接触的人）

1.  **准备**：点击右上角的齿轮图标，在“高级设置”中填入你的 DeepSeek API Key（需要自行申请）。
2.  **输入你的“如果”**：
    *   **人生岔路口**：描述那个让你纠结或后悔的关键选择点。例如：“如果当年我接受了那份外派工作”。
    *   **当时的年龄/时间**：让场景更具体。例如：“28岁那年”。
    *   **实际选择及现状**：描述你真实的选择和现在的生活状态。这是AI进行对比推演的重要基础。
    *   **模拟深度**：选择你想要的叙事风格（乐观、现实或多元）。
3.  **启动模拟**：点击“启动模拟”按钮，等待AI为你构建平行宇宙的故事。
4.  **查看与保存结果**：结果会以富有格式的文本形式呈现。你可以“复制”内容，或“导出”为文本文件保存。

**容易忽略的细节**：
*   **API Key是必须的**：没有它，功能无法使用。这是调用AI模型的“钥匙”。
*   **“实际选择”很重要**：描述得越具体，AI生成的对比和洞察就越有深度。
*   **右上角的“V3”和“R1”**：这是切换不同AI模型的按钮（标准版和推理增强版），可以尝试不同模型的效果。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个模块：

1.  **控制面板模块（左侧）**
    *   **职责**：收集用户输入的核心参数（决策点、时间、现状、模拟深度），并触发模拟任务。
    *   **逻辑**：用户填写表单 → 点击按钮 → 验证API Key → 将表单数据打包成“用户提问” → 发送给AI。

2.  **展示面板模块（右侧）**
    *   **职责**：显示状态（等待、生成中、结果）并呈现最终的AI生成内容。
    *   **逻辑**：初始为空/提示 → 生成时显示加载动画 → 接收AI返回的文本流并实时渲染 → 最终提供复制和导出功能。

3.  **配置模块（弹窗）**
    *   **职责**：管理应用的核心配置（API Key和系统提示词），并持久化保存。
    *   **逻辑**：用户打开设置 → 修改配置 → 保存至浏览器本地存储 → 后续模拟调用时使用。

**输入 → 处理 → 输出链路**：
用户输入（决策+现状） + 配置（API Key+Prompt） → 前端拼接成完整的请求 → 调用DeepSeek API → API 返回文本流 → 前端实时渲染为Markdown格式 → 最终呈现为结构化的平行宇宙叙事。

**最值得学习的设计**：
*   **“系统提示词”与“用户输入”的分离**：将AI的“角色设定”和“任务规则”（`DEFAULT_SYSTEM_PROMPT`）与用户的具体问题分开。这使得核心的AI行为逻辑可以通过修改提示词来调整，而无需改动前端代码，极大地提升了可维护性和灵活性。
*   **流式输出（Streaming）体验**：不是等待AI全部生成完再一次性显示，而是一个字一个字地“流”出来，这让等待过程变得可感知，体验更流畅。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：它是整个应用**灵魂的编程**。它定义了AI在这个场景中扮演的角色（叙事心理学家）、必须遵循的原则（基于现实、辩证视角）以及输出的固定结构（分标题、分维度）。
*   **解决什么问题**：它主要解决“**生成问题**”——如何根据零散的用户输入，生成一篇结构严谨、富有洞察且风格统一的叙事文章。它同时也解决了“理解问题”，因为它告诉AI该如何理解“平行宇宙模拟”这个任务。
*   **关键变量**：
    1.  **用户输入变量**：`${input.decision}`, `${input.age}`, `${input.actualPath}`, `${input.depth}`。这些被动态插入到最终发给AI的请求中。
    2.  **深度模式变量**：Prompt内部根据`${input.depth}`的值，规定了不同的输出结构（乐观、现实、多元宇宙）。
*   **只改Prompt会怎样**：如果你只修改`DEFAULT_SYSTEM_PROMPT`（比如把AI角色改成“科幻小说家”，把输出结构改成剧本格式），那么整个应用生成的内容风格、结构和深度都会彻底改变，而页面外观和操作流程完全不变。这展示了Prompt作为“软逻辑”的强大威力。

## 【五】如何模仿它，做出你自己的版本？

这是一个低风险、分步走的模仿路径：

1.  **第一步：替换场景，保持骨架**
    *   **目标**：先做出一个能跑通的新应用。
    *   **操作**：保留所有Vue、Tailwind CSS和API调用的代码。只修改以下内容：
        *   标题和文案（如改为“**商业决策模拟器**”）。
        *   左侧输入表单的标签和占位符（如“人生岔路口”改为“关键商业决策”，“实际选择”改为“已执行策略”）。
        *   `DEFAULT_SYSTEM_PROMPT`，将其重写为针对新场景的指令（如扮演“商业战略分析师”，输出SWOT分析和推演）。

2.  **第二步：调整输入与输出**
    *   **目标**：让应用更贴合你的需求。
    *   **操作**：
        *   增加或删除几个输入字段（例如增加“行业背景”、“资源约束”）。
        *   修改右侧结果区域的展示样式，比如增加一个时间线图表的位置（可以先留空）。
        *   微调API调用参数，比如温度（`temperature`）来控制AI的创造性。

3.  **第三步：改变外观与交互**
    *   **目标**：打造独特的品牌和体验。
    *   **操作**：
        *   修改 `universe-gradient` 等CSS类，更换全新的配色方案和视觉主题。
        *   将单列结果展示，改为可切换查看不同推演方案的卡片组。
        *   添加历史记录功能，将每次模拟的结果保存在侧边栏。

**最安全的起点**：毫无疑问是**第一步**。你不需要理解复杂的流式请求代码，只需进行文本替换，就能快速得到一个属于你的、功能完整的AI工具原型。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“人格底色”输入**：在表单中添加一个下拉菜单，让用户选择“当时的我更像：冒险家/保守者/理想主义者…”。将这个变量加入Prompt，让AI在推演时考虑主人公的性格因素，使故事更个性化。
2.  **切换AI模型与服务**：将DeepSeek API替换为OpenAI的GPT-4o、Anthropic的Claude或国内的通义千问、文心一言等。只需修改代码中的API端点（`fetch` URL）和请求头格式。这可以对比不同模型在创造性叙事上的差异。
3.  **从单次模拟到对话迭代**：不要在一次模拟后就结束。允许用户针对AI生成的结果，进一步追问：“在宇宙A里，我中年时遇到了什么危机？”，实现多轮对话，深入探索某个分支。
4.  **可视化时间线**：在结果区域，不仅展示文字，尝试用简单的HTML/CSS绘制一个横向时间线，将AI叙事中的关键事件（如“30岁升职”、“35岁创业”）提取出来（可通过让AI用特定格式输出，如JSON），并标记在时间线上，让推演结果一目了然。
5.  **预制“经典人生岔路”模板**：为不知道从何下手的用户提供几个模板按钮，如“高考志愿选择”、“一线与二线城市抉择”、“创业还是留守”，点击后自动填充表单的示例内容，降低使用门槛。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做重大决策依据**：它生成的内容是基于概率和模式联想的美好或合理的“故事”，**不是预言**。切勿将模拟结果作为辞职、投资或结束关系等重大人生决定的直接依据。
*   **不适合替代专业心理咨询**：虽然它能提供反思视角，但对于深度的心理创伤、焦虑症或抑郁症，它无法替代专业医生的诊断和治疗。
*   **不适合需要精确数据或逻辑验证的场景**：比如模拟投资项目回报、法律案件推演、医疗诊断等。这些需要严谨数据、专业知识和严格逻辑链的场景，应使用相应的专业工具或咨询专家。
*   **如果用户想做**：一个基于真实数据的决策分析工具，那么应该转向学习数据分析（如Python的Pandas）、可视化库（如ECharts）或专业的商业模拟软件。
