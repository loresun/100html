# “WHAT IF” 历史推演器 - 学习与改造指南

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你在和朋友讨论历史，突然冒出一个想法：“如果秦始皇没有统一六国，现在的中国会是什么样？” 或者你在写小说、构思游戏世界观，需要一个逻辑自洽的“平行历史”设定。这个网页就是为你准备的。它让你能快速、系统地将一个天马行空的“如果”想法，扩展成一篇结构完整、细节丰富的平行世界历史报告。

**适合什么情况？**
- **头脑风暴与创意激发：** 为写作、游戏设计、视频内容提供灵感。
- **趣味学习与讨论：** 以一种有趣的方式理解历史事件的关联性和重要性。
- **快速生成结构化内容：** 需要一个有条理、有深度的“假设性”分析报告。

**不适合什么情况？**
- **严肃的学术研究：** 它的输出是基于AI模型的创意生成，并非严谨的历史考证。
- **需要精确数据或事实核对：** 它生成的是“可能性”而非“事实”。
- **实时对话或复杂交互：** 它是一次性的问答模式，不支持多轮追问或深度辩论。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    - 页面中央有一个大文本框，这是你的“历史假设”输入框。你需要在这里写下你的“如果...”问题。

2.  **用户通常会做哪几步操作？**
    - **第一步：提出假设。** 在文本框中输入你的想法，例如“如果蒸汽机在宋朝被发明...”。
    - **第二步：点击生成。** 点击下方蓝色的“开始推演”按钮。
    - **第三步：等待与阅读。** 页面会显示加载动画，几秒到几十秒后，一篇完整的平行历史报告就会出现在下方。
    - **（可选）使用示例：** 如果没想法，可以直接点击文本框下方的示例标签（如“如果郑和的船队...”），它会自动填入并开始推演。
    - **（可选）保存结果：** 生成报告后，可以使用右上角的“复制”或“下载”按钮保存内容。

3.  **输出结果长什么样？**
    - 输出是一篇格式清晰的Markdown文章，通常包含：
        - **一个吸引人的标题**（如“平行宇宙档案: ‘如果蒸汽机在宋朝被发明...’”）
        - **分章节的详细论述**，包括引言、转折点、连锁效应、今日世界和结语。
        - 内容会使用**加粗、标题、列表**等格式，阅读体验很好。

4.  **有哪些容易忽略的使用细节？**
    - **右上角的齿轮按钮：** 点击可以打开设置面板，配置你自己的AI API（如OpenAI、Claude等），否则会使用默认的DeepSeek API（可能需要你自己的API Key）。
    - **示例标签是快捷入口：** 不仅展示例子，点击它就会自动填入并开始生成，非常方便。
    - **加载状态：** 点击“开始推演”后，按钮会变灰并显示“正在推演...”，此时请耐心等待，不要重复点击。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个模块，像一个高效的生产线：

1.  **输入与触发模块**
    - **组成：** 文本框 (`#what-if-input`) + 示例标签 + “开始推演”按钮 (`#generate-btn`)。
    - **职责：** 收集用户最核心的创意种子（历史假设），并提供快捷输入方式。它的任务就是“启动”整个流程。
    - **逻辑：** 用户输入/点击示例 → 点击按钮 → 触发 `generateHistory()` 函数。

2.  **控制与配置模块**
    - **组成：** 右上角齿轮按钮 + 滑出的设置面板 (`#settings-panel`)。
    - **职责：** 管理网页的“后台引擎”。它允许高级用户更换AI服务提供商（API URL）、使用自己的密钥（API Key）和选择不同模型。
    - **逻辑：** 用户配置 → 保存到浏览器本地存储 (`localStorage`) → 生成时调用这些配置。

3.  **处理与通信模块（核心引擎）**
    - **组成：** `generateHistory()` 函数中的 **Prompt构建** 和 **API调用** 部分。
    - **职责：** 这是网页的“大脑”。它把用户的简单输入，包装成一个结构清晰、指令明确的请求（Prompt），然后发送给远端的AI模型，并取回结果。
    - **逻辑链路：**
        用户输入 → 拼接成详细Prompt → 通过`fetch`发送HTTP请求到AI API → 接收JSON格式的响应 → 提取AI返回的文本内容。

4.  **输出与展示模块**
    - **组成：** 加载动画 (`#loader`) + 结果容器 (`#result-container`) + 复制/下载按钮。
    - **职责：** 友好地告知用户“正在工作”，然后优雅地呈现AI生成的内容，并提供实用的结果处理工具。
    - **逻辑：** 开始生成时显示加载动画 → 收到结果后隐藏动画 → 将Markdown文本转换为HTML并渲染 → 提供复制和下载功能。

**最值得学习的设计：**
**“Prompt工程”与“用户界面”的无缝结合。** 这个网页没有复杂的算法，它的魔力在于：用一个精心设计的Prompt模板，将用户的一句话，转化为对AI的明确指令。同时，界面（示例、加载状态、格式化输出）全程服务于这个核心交互，让技术细节对用户完全透明，体验非常流畅。这是AI应用设计的典范。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt扮演的角色：**
    - 它是**指令手册**和**角色设定**。它告诉AI：“现在你不是普通的助手，你是一位来自平行宇宙的历史学家，请按照以下严格的结构和语气来回答问题。”

2.  **解决的是“生成问题”还是“理解问题”？**
    - 主要解决**“生成问题”**。用户的输入（如“如果罗马帝国从未衰落”）本身是模糊的、开放的。Prompt的任务是引导AI生成一篇**结构严谨、内容充实、风格统一**的长篇分析报告，而不是帮助AI理解“罗马帝国”是什么（这被认为是AI已具备的知识）。

3.  **Prompt中的关键变量：**
    - **`${query}`：** 这是唯一由用户输入决定的变量，被直接嵌入到Prompt的固定结构中。整个Prompt都是围绕这个变量展开的。
    - **系统指令 (`role: 'system'`)：** `“你是一位来自平行宇宙的顶尖历史学家。”` 这设定了AI回答的基调和身份。
    - **结构指令：** 从“引言”到“结语”的五段式结构，强制AI进行系统化、深度的思考，而不是随意闲聊。
    - **格式指令：** `“请使用Markdown格式进行撰写”`，这确保了返回的内容能被网页完美地格式化展示。

4.  **如果只改Prompt，不改代码，会发生什么？**
    - **改变输出领域：** 把“历史学家”改成“经济学家”，把历史事件改成经济政策，它就能生成经济分析报告。
    - **改变输出风格：** 把“严谨的报告”改成“幽默的博客文章”或“儿童故事”，AI生成的口吻会完全不同。
    - **改变输出结构：** 增加或减少分析维度（如“对环境的影响”、“对流行文化的影响”），报告的重点就会转移。
    - **简单来说，Prompt是网页的“灵魂”。** 修改Prompt，就等于彻底改变了这个工具的应用场景，而代码（身体）几乎不用动。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，一步步创造出属于你的AI小工具：

**第一步：替换核心场景与Prompt（最安全、变化最大）**
- **目标：** 做一个“科幻小说创意生成器”。
- **操作：**
    1.  修改网页标题和说明文字，如改为“科幻点子孵化器”。
    2.  修改输入框提示语，如“请输入一个科幻核心设定...”。
    3.  **最关键的一步：** 修改 `generateHistory` 函数中的 `prompt` 变量。把历史学家的角色换成“科幻小说大师”，把五段式历史报告结构换成“世界观背景、关键科技、社会冲突、主要角色、故事梗概”等。
    4.  同时，更新示例标签为科幻相关的内容，如“如果人类发现意识可以数字化上传...”。

**第二步：调整输入字段（增加复杂性）**
- **目标：** 让生成内容更精准。
- **操作：**
    1.  在现有文本框上方或下方，增加新的输入框。例如，增加一个“选择时代背景”的下拉菜单（古代/近代/未来），或一个“期望的文章长度”单选框（简短/中等/详细）。
    2.  在构建Prompt时，将这些新的输入值也作为变量插入到Prompt模板中。例如：`**时代背景：** ${era}\n**核心设定：** ${query}`。

**第三步：改变输出形式或交互（提升体验）**
- **目标：** 让结果展示更酷或更实用。
- **操作：**
    1.  **改变展示：** 不只用一种格式。可以增加一个“切换视图”按钮，让用户在“文章模式”和“要点列表模式”之间切换。
    2.  **增加交互：** 在生成的结果中，为某些关键词（如生成的国家名、科技名）添加“深挖”按钮，点击后可以基于此关键词发起一次新的、更细化的生成请求。
    3.  **美化输出：** 使用更丰富的CSS，为不同的章节添加不同的背景色、图标或边框。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格化”输入控件：**
    - **操作：** 在设置面板或主界面增加一个“叙事风格”下拉菜单，选项包括“学术报告”、“新闻快讯”、“小说旁白”、“知乎体回答”。
    - **实现：** 将这个选项值加入到Prompt中，例如：“请以`${style}`的风格撰写以下内容...”。
    - **效果：** 同一个历史假设，可以产出完全不同口味的文章，工具灵活性大增。

2.  **更换或扩展后端AI模型：**
    - **操作：** 在设置面板的“模型选择”下拉框中，增加更多选项，如 `gpt-4o`、`claude-3-sonnet`，并对应修改API URL。
    - **实现：** 需要用户填入对应平台的API Key和URL。可以为每个模型预设好URL（如OpenAI的是`https://api.openai.com/v1/chat/completions`）。
    - **效果：** 用户可以对比不同AI模型在创意和历史推演上的表现差异。

3.  **将单次生成拆分为“对话式”探索：**
    - **操作：** 隐藏现有的结果区域，改为一个聊天界面。用户输入假设后，AI以历史学家的身份回复。用户可以在AI的回复基础上继续追问，例如：“你刚才提到的东方帝国，它的具体政治制度是怎样的？”
    - **实现：** 需要重构代码，将每次的对话历史（`messages`数组）保存下来，并在每次发送时附加上去。
    - **效果：** 从生成一篇静态报告，变为进行一次动态的历史访谈，深度和趣味性更强。

4.  **优化体验：保存历史记录与收藏夹：**
    - **操作：** 在页面左侧或新增一个页面，列出用户所有过往的推演记录（保存到`localStorage`）。每条记录可以重命名、重新生成、删除或标记为收藏。
    - **实现：** 每次成功生成后，将`query`和`lastResultMarkdown`以及时间戳作为一个对象存入数组，再保存到`localStorage`。
    - **效果：** 打造一个属于用户个人的“平行宇宙档案馆”，价值感瞬间提升。

5.  **增加可视化元素：**
    - **操作：** 在AI生成报告后，额外发起一个请求，让AI从报告中提取关键的时间点、事件和实体，并生成一个简化的JSON数据。然后用前端图表库（如Mermaid.js）绘制一个“平行历史时间线”图。
    - **实现：** 这需要设计第二个更复杂的Prompt，专门用于信息提取和结构化。然后根据返回的JSON数据渲染图表。
    - **效果：** 从纯文字报告升级为“图文并茂”的分析，更直观，传播性也更好。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合做事实核查或获取准确知识：** AI可能会在推演中混合真实历史与虚构细节，甚至出现“幻觉”（编造看似合理但不存在的事实）。**切勿**将其输出作为学术引用或事实依据。
- **不适合处理高度敏感或伦理议题：** 对于涉及现实世界重大灾难、特定族群等敏感话题的“假设”，AI的生成可能缺乏必要的谨慎和伦理考量，容易产生不当内容。这类创意探索需要更严格的约束和人工审核。
- **不适合需要高精度控制输出的场景：** 虽然Prompt提供了结构，但AI生成的具体内容、举例、措辞每次都可能有所不同。如果你需要一字不差的固定文案，应该使用模板填充或直接撰写，而非AI生成。
- **如果用户想做以上事情，应该：**
    - 查询权威历史数据库、学术论文或百科全书。
    - 进行深入的伦理框架设计，并在人类监督下使用AI。
    - 使用内容管理系统（CMS）或文档模板来生成标准化内容。
