# 学习路径规划器 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你决定要学习一项新技能（比如编程、设计、数据分析），但面对海量的课程、书籍和资源，不知道从哪里开始，也不知道如何安排学习顺序。这个网页就是你的“私人学习规划师”。

**适合的使用场景：**
- 当你想要系统性地学习一个新领域，但缺乏规划经验时
- 当你需要一份结构化的学习计划，来保持学习动力和方向时
- 当你希望根据个人情况（时间、预算、基础）定制学习方案时
- 当你需要了解某个技能领域的职业发展路径时

**不适合的情况：**
- 需要即时解答具体技术问题（更适合搜索引擎或问答社区）
- 已经拥有非常成熟的个人学习体系
- 学习目标非常模糊或过于宏大（如“改变世界”）
- 需要实时互动教学或手把手指导

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你需要填写两个主要部分的信息：
1. **学习目标**：你的具体目标、当前水平、目标水平、已有技能
2. **学习设置**：你计划投入的时间、每周学习时长、学习偏好、预算等

**用户通常会做哪几步操作？**
1. 在左上角“学习目标”卡片中，填写你的核心目标（如“成为全栈开发工程师”）
2. 选择你的技能领域、当前水平和目标水平
3. 在右下角“学习设置”卡片中，设定你的时间安排和学习偏好
4. 点击页面中央的“生成学习路径”按钮
5. 等待AI生成结果，查看详细的学习计划

**输出结果长什么样？**
生成的结果是一个结构化的学习路径，包含：
- 路径概览（总时长、难度、成功率）
- 多个学习阶段（每个阶段有具体模块、资源、里程碑）
- 实践项目建议
- 职业发展路径
- 专家建议和下一步行动

**有哪些容易忽略的使用细节？**
1. **学习方式标签**：默认只选中了“在线课程”和“书籍阅读”，记得点击其他标签（如“视频教程”、“实战练习”）来丰富学习方式
2. **已有技能**：填写你已经掌握的技能，AI会据此调整起点，避免重复学习
3. **学习挑战**：描述你的困难（如“时间碎片化”、“数学基础弱”），AI会给出针对性建议
4. **设置面板**：首次使用前，需要点击右上角齿轮图标，配置你的API密钥

## 【三】核心结构拆解（学习重点）

这个页面由四个关键模块组成：

**1. 用户输入模块（两个卡片）**
- **职责**：收集用户的所有个性化参数
- **设计亮点**：将输入分为“目标”和“设置”两类，逻辑清晰。标签式选择让交互更友好。

**2. AI处理引擎（隐藏在按钮后）**
- **职责**：将用户输入转化为结构化的Prompt，调用AI API，解析返回结果
- **关键函数**：`buildLearningPathPrompt()` 和 `callAI()`
- **设计亮点**：Prompt模板将散乱的用户输入组织成AI易于理解的格式，并指定了严格的JSON输出格式

**3. 结果展示模块（动态生成）**
- **职责**：将AI返回的JSON数据渲染成美观易读的界面
- **关键函数**：`displayLearningPath()`
- **设计亮点**：采用“阶段-模块-资源”的层级展示，符合学习认知规律

**4. 工具辅助模块（底部按钮）**
- **职责**：提供结果导出、复制、进度跟踪等实用功能
- **设计亮点**：一键下载为Markdown文件，便于后续编辑和分享

**输入 → 处理 → 输出 的逻辑链路：**
```
用户填写表单 → 点击生成按钮 → 表单数据被收集 → 构建Prompt → 调用AI API
→ AI返回JSON格式的学习路径 → 解析JSON → 动态生成HTML界面 → 用户查看结果
```

**最值得学习的设计：**
**结构化Prompt设计**。页面没有让AI自由发挥，而是通过精心设计的Prompt模板，要求AI按照特定JSON格式返回数据。这确保了：
- 输出结果结构统一，便于后续处理
- 避免了AI“跑题”或格式混乱
- 前端展示代码可以稳定地解析和渲染

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接“用户需求”和“AI能力”的桥梁。它告诉AI：“用户提供了这些信息，请按照这个格式，生成一个学习路径。”

**它解决的是“理解问题”还是“生成问题”？**
主要是“生成问题”，但也包含了“理解问题”。Prompt需要：
1. **理解**：将用户的选择（如“programming”）转换为人类可读的描述（“编程开发”）
2. **生成**：按照指定的JSON结构，生成完整的学习路径内容

**哪些信息是Prompt中的关键变量？**
所有表单字段都会进入Prompt，但最重要的是：
- `data.goal`（学习目标）- 决定了路径的核心方向
- `data.currentLevel` 和 `data.targetLevel`（水平差距）- 决定了路径的深度和长度
- `data.learningTime` 和 `data.weeklyHours`（时间约束）- 决定了路径的节奏和强度

**如果只改Prompt，不改代码，会发生什么变化？**
1. **改变输出结构**：比如要求AI增加“每周学习计划表”字段
2. **改变内容风格**：比如要求AI用更幽默或更严谨的语言
3. **改变详细程度**：比如要求AI提供更简略或更详细的建议
4. **改变侧重点**：比如更强调项目实践或更强调理论学习

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景（最安全）**
- 将“学习路径”改为“健身计划”、“旅行攻略”、“读书清单”
- 只修改界面文字和选项内容，不修改代码逻辑
- 例如：将“技能领域”改为“运动类型”，“学习时长”改为“训练周期”

**第二步：调整输入字段或Prompt**
- 增加或减少几个输入字段（如增加“饮食偏好”、“可用器材”）
- 修改Prompt模板中的描述和JSON结构
- 保持前端展示逻辑基本不变

**第三步：改变输出形式或展示方式**
- 将学习路径改为时间轴、甘特图或日历视图
- 增加交互功能，如点击模块查看详情、拖拽调整顺序
- 这需要修改`displayLearningPath()`函数和CSS样式

**从哪里下手最安全？**
从**修改Prompt模板**（`buildLearningPathPrompt()`函数）开始。这是纯文本修改，不会影响页面运行。你可以：
1. 先修改提示词中的中文描述
2. 然后调整JSON结构中的字段名
3. 最后再考虑修改前端展示代码

## 【六】3–5个可直接尝试的改造方向

**1. 增加“学习资源平台”偏好**
- **现状**：只选择了学习方式（在线课程、书籍等）
- **改造**：增加“平台偏好”选择，如“Coursera优先”、“B站优先”、“英文资源优先”
- **方法**：在表单中添加多选框，将选择值传入Prompt

**2. 支持多模型对比**
- **现状**：一次只能用一个AI模型生成
- **改造**：同时调用多个AI模型（如DeepSeek、豆包、GPT），并排展示不同版本
- **方法**：修改`callAI()`函数支持并发请求，在界面上用标签页展示

**3. 拆分为“规划”和“执行”两个页面**
- **现状**：所有功能在一个页面
- **改造**：页面1生成路径，页面2跟踪进度（记录学习时间、完成模块）
- **方法**：将进度跟踪功能独立出来，使用localStorage保存进度数据

**4. 增加“社区案例”参考**
- **现状**：完全依赖AI生成
- **改造**：增加一个“查看类似案例”按钮，展示其他用户的真实学习路径
- **方法**：构建一个简单的后端，存储匿名学习路径案例

**5. 优化为“渐进式生成”**
- **现状**：一次性生成完整路径，等待时间较长
- **改造**：先生成大纲，再让用户选择重点展开的模块
- **方法**：修改Prompt，让AI先输出概要，再根据用户选择生成细节

## 【七】这个网页不适合做什么？（边界提醒）

**1. 不适合作为实时学习工具**
- **局限性**：生成的路径是静态计划，不会根据你的学习进度动态调整
- **替代方案**：使用专门的学习管理应用（如Notion模板、Todoist）来跟踪每日任务

**2. 不适合解决具体学习问题**
- **局限性**：无法回答“这个代码错误怎么解决”、“这个概念怎么理解”
- **替代方案**：使用AI编程助手（如Cursor、Copilot）或问答社区（Stack Overflow）

**3. 不适合需要认证或学位的场景**
- **局限性**：生成的路径仅供参考，不保证被教育机构或雇主认可
- **替代方案**：直接查询正规教育机构的课程大纲和认证要求

**4. 不适合完全零基础的决策**
- **局限性**：如果你对某个领域毫无概念，可能无法做出合理的参数选择
- **替代方案**：先通过百科、科普视频了解领域概貌，再使用本工具

**5. 不适合替代真人指导**
- **局限性**：AI无法理解你的情感状态、学习动力、个人特殊情况
- **替代方案**：对于重要技能投资，建议结合真人导师或职业顾问的建议

---

**记住**：这个工具的价值在于“提供结构化的起点”，而不是“替代整个学习过程”。把它看作你的学习地图绘制师，但走路的人还是你自己。
