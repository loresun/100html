# 隐喻制造机 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你正在准备一场重要的演讲、创作一首诗，或者想用一个新颖的比喻来解释一个复杂的概念。你脑海中浮现出两个看似毫无关联的事物，比如“梦想”和“螺丝钉”，你想知道它们之间能碰撞出怎样的思想火花。这个网页就是你的“创意催化剂”。

**适合的使用场景：**
- **创意写作**：为诗歌、散文、小说寻找独特的比喻
- **演讲与表达**：为演讲内容增加深刻、令人印象深刻的隐喻
- **思维训练**：锻炼发现事物之间深层联系的能力
- **教学辅助**：用生动的比喻解释抽象概念
- **灵感获取**：在创意枯竭时获得新的视角

**不适合的情况：**
- 需要严谨、无歧义的科学或技术定义
- 需要快速查找事实信息的场景
- 需要多人协作、实时编辑的创作环境

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **两个名词输入框**：分别输入你想连接的两个概念（如“时间”和“河流”）
2. **隐喻风格选择**（可选）：从“诗意优美”、“哲学深刻”等风格中选择
3. **情感色调选择**（可选）：设定隐喻的情感基调，如“忧郁”、“希望”等

**用户通常会做哪几步操作？**
1. 在左侧输入第一个词，右侧输入第二个词
2. （可选）从页面提供的“有趣的组合”中点击一个预设组合
3. （可选）选择你想要的隐喻风格和情感色调
4. 点击“制造隐喻”按钮
5. 等待几秒钟，查看AI生成的创意结果

**输出结果长什么样？**
结果会以卡片形式展示，从上到下包括：
- 一个醒目的、带背景动画的“隐喻句子”（如：“时间是一条无声的河流，我们既是航行者也是河床。”）
- 详细的隐喻分析，包括深层连接、象征解读、情感共鸣和生活应用
- 生成时间和使用的AI模型信息
- 复制、分享、下载结果的按钮

**有哪些容易忽略的使用细节？**
1. **预设组合是很好的起点**：如果你不知道输入什么，先试试页面提供的组合
2. **风格和色调可以组合使用**：比如“诗意优美”+“忧郁”会产生特定的效果
3. **可以按Ctrl+Enter快速提交**：在输入框聚焦时，按这个组合键可以直接生成
4. **结果可以保存**：每个结果卡片都有下载按钮，可以保存为文本文件
5. **模型可以随时切换**：页面右上角可以快速切换不同的AI模型

## 【三】核心结构拆解（学习重点）

这个页面由**四个关键模块**组成，每个模块职责清晰：

### 1. 配置管理模块
- **职责**：管理AI模型、API地址和密钥的设置
- **位置**：设置面板（点击齿轮图标打开）和右上角模型选择器
- **设计亮点**：将技术配置与创意界面分离，用户不需要懂API也能使用

### 2. 输入与引导模块
- **职责**：收集用户创意意图，并提供引导
- **包含**：两个输入框、风格/色调选择器、预设组合按钮
- **设计亮点**：预设组合降低了使用门槛，风格选择让输出更可控

### 3. AI交互与处理模块
- **职责**：将用户输入转化为AI能理解的指令，调用AI生成内容
- **关键函数**：`createMetaphorPrompt()` 和 `callAI()`
- **设计亮点**：Prompt设计结构化，确保AI输出符合预期格式

### 4. 结果展示与交互模块
- **职责**：美观地展示AI生成内容，并提供实用功能
- **包含**：结果卡片、隐喻高亮显示、操作按钮（复制/分享/下载）
- **设计亮点**：自动提取隐喻句子并高亮显示，增强视觉冲击力

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入两个词 + 可选参数
    ↓
createMetaphorPrompt() 构建结构化Prompt
    ↓
callAI() 调用AI接口
    ↓
displayResults() 解析并美化展示
    ↓
用户获得带格式的创意结果
```

**最值得学习的设计：**
**结构化Prompt设计**是核心。它没有简单地说“写一个比喻”，而是明确要求了五个方面（隐喻句子、深层连接、象征解读、情感共鸣、生活应用），这确保了AI输出既有创意又有深度，且格式统一，便于后续展示处理。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接用户意图和AI能力的“翻译官”和“质量控制器”。它把用户简单的“两个词”输入，转化为AI能理解的、有明确要求的创作任务。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**，但也解决了部分理解问题。它告诉AI：
1. **角色**：你是隐喻大师
2. **任务**：连接这两个概念
3. **要求**：输出必须包含五个特定部分
4. **质量**：要有原创性、深度、顿悟感

**哪些信息是Prompt中的关键变量？**
1. **两个核心名词**：用户输入的两个词
2. **风格要求**：如“诗意优美的”
3. **情感色调**：如“带有忧郁的情感”
4. **结构化输出要求**：五个必须包含的部分

**如果只改Prompt，不改代码，会发生什么变化？**
- 改**风格描述**：AI会改变语言风格（如从诗意改为幽默）
- 改**输出结构**：如果去掉“生活应用”要求，AI就不会生成这部分
- 改**质量要求**：如果把“深刻的洞察力”改为“简单的比喻”，输出会变浅显
- 改**角色设定**：如果把“诗人哲学家”改为“科幻作家”，隐喻会有科幻色彩

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 将“隐喻制造”改为其他创意任务，如：
  - “广告语生成器”（输入：产品+目标人群）
  - “角色背景生成器”（输入：职业+性格特质）
  - “产品概念生成器”（输入：技术+应用场景）
- 只修改页面标题、描述和预设示例，其他代码完全不动

**第二步：调整输入字段和Prompt**
- 根据新场景，修改输入框的提示文字（placeholder）
- 调整`createMetaphorPrompt()`函数中的Prompt模板
- 保持五个部分的结构，但改变具体内容要求
- 示例（广告语生成器）：
  ```javascript
  function createAdPrompt(product, audience) {
    return `作为资深广告创意总监，请为"${product}"针对"${audience}"创作广告语。
    要求：
    1. 核心广告语（10-15字）
    2. 产品卖点分析
    3. 目标人群心理洞察
    4. 情感共鸣点
    5. 应用场景建议`;
  }
  ```

**第三步：改变输出形式或展示方式**
- 修改`displayResults()`函数中的HTML模板
- 改变结果卡片的视觉样式（颜色、布局）
- 增加新的交互功能，如“收藏”、“评分”

**从哪里下手最安全？**
从**修改预设示例**开始 → 然后**修改Prompt模板** → 最后**调整界面文字和样式**。这样每一步都能看到效果，风险最小。

## 【六】3–5个可直接尝试的改造方向

### 1. 增加输入维度，让创意更精准
- **增加“使用场景”输入框**：比如“用于演讲开场”、“用于诗歌创作”
- **增加“目标受众”选择**：如“面向年轻人”、“面向专业人士”
- **增加“长度控制”滑块**：控制生成内容的详细程度
- **改造难度**：低，只需在HTML中添加字段，在Prompt中引用

### 2. 扩展为“创意工作坊”多页面应用
- **页面1：灵感收集**：用户输入多个关键词，AI生成多个组合建议
- **页面2：隐喻制造**：当前页面功能
- **页面3：创意完善**：对生成的隐喻进行修改、扩展、组合
- **页面4：作品库**：保存和分类所有生成的结果
- **改造难度**：中，需要学习页面路由和状态管理

### 3. 增加社交和协作功能
- **“灵感接力”模式**：A用户生成隐喻，B用户基于此生成新隐喻
- **投票功能**：用户可以对生成的隐喻进行“有创意/没创意”投票
- **收藏和分享**：建立用户账户，收藏喜欢的隐喻，分享到社交媒体
- **改造难度**：中高，需要后端支持和用户系统

### 4. 优化为专业写作工具
- **增加“导出格式”选项**：可直接导出为Markdown、Word或PPT格式
- **增加“风格模仿”功能**：模仿特定作家或诗人的风格
- **增加“修改建议”功能**：AI对用户自己写的隐喻提出改进建议
- **改造难度**：中，主要在Prompt和输出处理上增强

### 5. 实现本地化和小型化
- **更换为本地AI模型**：使用可在浏览器中运行的小型模型（如通过WebLLM）
- **离线使用**：将页面打包为桌面应用（使用Electron或Tauri）
- **隐私保护**：所有处理在本地完成，无需上传数据
- **改造难度**：高，需要学习本地AI模型部署

## 【七】这个网页不适合做什么？（边界提醒）

### 明确的局限性：
1. **不适合生成事实性内容**
   - 如果你问“爱情和旧冰箱的科学原理”，AI会创作隐喻而不是科学解释
   - **应该使用**：百科全书、学术数据库或专业问答工具

2. **不适合需要精确控制输出的场景**
   - AI生成具有随机性，同样的输入可能产生不同输出
   - **应该使用**：模板化的内容生成工具或手动创作

3. **不适合需要逻辑论证的严肃写作**
   - 隐喻是修辞手法，不是逻辑论证
   - **应该使用**：论文写作工具、逻辑思维导图

4. **不适合需要即时、高频使用的生产环境**
   - 依赖外部API，有网络延迟和调用限制
   - **应该使用**：本地安装的专业写作软件

5. **不适合需要版权完全清晰的商业用途**
   - AI生成内容的版权归属尚不明确
   - **应该使用**：雇佣专业文案或使用有明确版权协议的服务

### 最重要的提醒：
这个工具是**创意启发器**，不是**内容生产流水线**。它最好的使用方式是：用AI的创意激发你的创意，而不是完全依赖AI的产出。最珍贵的永远是你自己的思考和再创造。
