# 爆款标题实验室 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景**：
当你写了一篇文章、一个视频脚本，或者有一个产品想法，但不知道如何起一个吸引人的标题时，这个工具能帮你快速生成多个“爆款潜力”的标题选项。它特别适合：
- 自媒体创作者需要为文章/视频起标题
- 营销人员需要为广告文案设计吸引点击的标题
- 内容编辑需要为同一内容准备多个标题变体进行A/B测试

**不适合的情况**：
- 需要完全原创、不能有任何AI痕迹的正式出版物标题
- 需要深度理解专业领域术语的学术论文标题
- 需要实时与用户对话、反复修改的协作场景

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **核心输入框**：你的原始标题或文章大意（必填）
2. **可选输入框**：目标受众描述（如“宝妈”、“大学生”）

**用户通常会做哪几步操作？**
1. 在左侧面板输入你的内容（比如“教你如何做红烧肉”）
2. （可选）填写目标受众
3. 点击“开始实验”按钮
4. 等待10-30秒，查看右侧生成的标题列表
5. 点击单个标题旁边的复制按钮，或使用“复制全部”批量复制

**输出结果长什么样？**
- 右侧会显示10-20个标题卡片
- 每个卡片包含：标题文字、分类标签（如“悬念式”）、AI预测点击率得分（0-100分）、得分环形图
- 得分≥90的标题会有“爆款预定”红色角标
- 如果使用“Reasoner”模型，还能展开查看AI的思考过程

**容易忽略的使用细节**：
1. **API设置**：第一次使用需要点击右上角“API设置”输入DeepSeek API Key
2. **模型切换**：右上角可以切换“Chat”和“Reasoner”模型，后者会显示思考过程但可能稍慢
3. **得分解读**：环形图颜色代表得分等级（红>橙>黄>灰）
4. **思考过程**：生成后记得展开“AI深度思考过程”看看AI是如何分析的

## 【三】核心结构拆解（学习重点）

**页面由四个关键模块组成：**

1. **控制面板（左侧）**
   - 职责：接收用户输入、触发生成、显示状态
   - 包含：输入区、按钮、状态提示
   - 逻辑：用户输入 → 点击按钮 → 发送请求 → 显示加载状态

2. **结果展示区（右侧）**
   - 职责：展示生成结果、提供交互操作
   - 包含：标题卡片网格、复制功能、得分可视化
   - 逻辑：接收数据 → 渲染卡片 → 用户交互（复制/查看）

3. **API配置模态框**
   - 职责：管理API密钥（本地存储）
   - 逻辑：点击设置 → 输入密钥 → 保存到localStorage

4. **导航与模型选择**
   - 职责：提供模型切换、返回主页入口
   - 逻辑：用户选择 → 更新模型变量 → 影响后续API调用

**输入 → 处理 → 输出 的逻辑链路**：
```
用户输入内容
    ↓
拼接成Prompt（系统指令 + 用户内容）
    ↓
调用DeepSeek API（流式接收）
    ↓
解析返回的JSON数据
    ↓
清洗数据、按得分排序
    ↓
渲染为可视化卡片
    ↓
用户复制使用
```

**最值得学习的设计**：
- **“实验室”隐喻的一致性**：从图标（烧瓶、显微镜）到文案（实验、样本、报告），整个界面营造了“科学实验”的氛围，让枯燥的标题生成变得有趣
- **得分可视化**：用环形进度条直观展示抽象的数字得分，颜色编码提供快速认知
- **渐进式反馈**：加载时的骨架屏、生成成功时的彩色纸屑效果，让等待过程不枯燥

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是“标题生成专家”的岗位说明书，它定义了：
- AI的角色身份（10年经验的新媒体专家）
- 任务目标（生成爆款标题）
- 创作维度（8种标题类型）
- 输出格式（严格的JSON结构）

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**，但也包含了理解：
- 理解部分：需要理解用户输入的内容主题
- 生成部分：基于理解，按照8种策略创造性地产出标题

**Prompt中的关键变量**：
1. **角色定义**：“10年经验的新媒体爆款标题专家”
2. **创作维度**：8种具体的标题策略（这是核心）
3. **输出格式**：严格的JSON结构，包含category、title、score、reasoning四个字段
4. **评分标准**：“AI预测点击率得分”的概念设定

**如果只改Prompt，不改代码，会发生什么变化？**
- 改角色定义 → AI的语气和风格会变（如改成“学术论文标题专家”）
- 改创作维度 → 生成的标题类型会变（如增加“疑问式”、“命令式”）
- 改输出格式 → 代码可能无法正确解析，页面会报错
- 改评分标准 → 得分的含义会变（如改成“吸引力指数”）

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改文字和Prompt
- 例如：改成“广告文案生成器”
- 修改：页面标题、说明文字、图标
- 修改Prompt中的角色和任务：“你是一位资深广告文案策划...”

**第二步：调整输入字段和Prompt**
- 增加/减少输入字段
- 例如：增加“产品特点”、“品牌调性”输入框
- 修改Prompt：在用户输入部分加入这些新字段
- 修改输出格式：增加“适用平台”字段

**第三步：改变输出形式或展示方式**
- 修改卡片布局：如改成列表式、瀑布流
- 增加交互：如“点赞”、“收藏”功能
- 修改可视化：如用柱状图代替环形图

**从哪里下手最安全？**
从**文字和Prompt**开始最安全，因为：
1. 不改动HTML/CSS结构，页面不会崩
2. 不改动JavaScript逻辑，功能正常
3. 只需改几处文本，就能看到明显变化

## 【六】3–5个可直接尝试的改造方向

**1. 增加标题风格预设**
- 在输入区增加单选按钮：“小红书风格”、“知乎风格”、“微博风格”
- 在Prompt中加入：“请生成符合[风格]平台调性的标题”
- 代码改动：增加单选按钮组件，将选择值传入Prompt

**2. 增加批量处理功能**
- 允许用户上传CSV文件，一次处理多个内容
- 生成结果可以按原内容分组展示
- 代码改动：增加文件上传组件，循环调用API

**3. 替换为本地模型**
- 使用Ollama + 本地小模型（如Qwen2.5-7B）
- 修改API调用地址为本地（http://localhost:11434）
- 优点：完全免费、隐私安全
- 代码改动：修改`callDeepSeek`函数中的API地址和参数

**4. 增加“标题优化”模式**
- 用户输入一个现有标题，AI给出优化建议和多个优化版本
- 在Prompt中增加：“分析以下标题的优缺点，并提供5个优化版本”
- 界面增加模式切换：“生成新标题” / “优化现有标题”

**5. 增加A/B测试记录**
- 用户可以将喜欢的标题加入“测试列表”
- 记录每个标题的实际点击率（手动输入）
- 用图表展示AI预测得分 vs 实际表现
- 帮助AI“学习”用户的偏好

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明：**

1. **不适合生成完全原创的文学性标题**
   - AI基于模式生成，可能缺乏真正的文学创意
   - 如果需要诗集标题、小说标题，建议找人类编辑

2. **不适合需要深度领域知识的标题**
   - 如医学论文、法律文件、专业研究报告
   - AI可能不理解专业术语的准确含义和重要性

3. **不适合实时协作编辑**
   - 这是一个“一次生成，批量选择”的工具
   - 如果需要边聊边改、反复调整，应该用ChatGPT对话界面

4. **不适合需要100%准确率的关键场景**
   - AI的“预测点击率”只是模拟，不是真实数据
   - 重要的商业广告标题，应该结合真实A/B测试

**如果用户想做X，应该换什么工具：**
- 想生成诗歌/文学标题 → 使用专门的文学创作AI工具
- 需要专业领域标题 → 使用该领域的专业工具或咨询专家
- 需要实时对话修改 → 直接使用ChatGPT/Claude对话
- 需要真实数据验证 → 使用Google Optimize等A/B测试平台
