# 人生 K 线图 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你想要用一种新颖、有趣的方式回顾自己的人生历程，或者对未来进行一种“半开玩笑半认真”的展望时，这个工具就派上用场了。它把金融市场的“K线图”概念套用在人生上，将抽象的情绪起伏、人生际遇转化为可视化的图表，并配上幽默犀利的“股评式”点评。

*   **适合什么情况？**
    *   **年终复盘：** 回顾过去一年或几年的高低起伏，用一种轻松的方式总结。
    *   **朋友间娱乐：** 和朋友一起输入信息，比比谁的“人生K线”更精彩。
    *   **创意写作/头脑风暴：** 为虚构角色设计人生轨迹，寻找灵感。
    *   **自我反思：** 通过量化“开心指数”，直观地看到哪些事件对自己影响最大。

*   **不适合什么情况？**
    *   **严肃的心理评估或人生规划：** 它的分析基于AI的想象和模式化处理，不具备科学性和专业性。
    *   **需要精确预测未来：** 这只是一个基于有限信息的创意游戏，不能当真。
    *   **处理极度敏感或创伤性事件：** AI的点评可能不够体贴，不适合用于严肃的心理疗愈场景。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    *   **模式选择：** 页面左侧有两个模式：“运势推演”（预测未来）和“人生复盘”（回顾过去）。
    *   **“运势推演”模式：** 需要填写你的出生日期、当前职业/状态，并选择你的“风险偏好”（稳健型、大起大落、大器晚成）。
    *   **“人生复盘”模式：** 只需要在一个文本框里，按行写下你人生中的关键事件（例如：“18岁：考上大学”、“25岁：第一次升职”）。

2.  **用户通常会做哪几步操作？**
    1.  首次打开，需要点击右上角的设置按钮（齿轮图标），填入你的 DeepSeek API Key 并保存。
    2.  在左侧面板选择你想要的模式（“运势推演”或“人生复盘”）。
    3.  根据所选模式，填写对应的信息。
    4.  点击绿色的“生成 K 线趋势”按钮。
    5.  稍等片刻，右侧的图表区域就会生成你的人生K线图，左下方还会出现一段AI的“分析师点评”。

3.  **输出结果长什么样？**
    *   **主图表：** 一个类似股票软件的K线图，横轴是年龄（0-80岁），纵轴是“开心指数”。**红色K线**表示该年份“收盘”（年终状态）比“开盘”（年初状态）好，是“上涨年”；**绿色K线**则相反。
    *   **鼠标悬停：** 把鼠标放在任何一根K线上，会弹出提示框，显示该年龄的开心指数和可能的关键事件。
    *   **文字点评：** 图表下方会有一段AI生成的、风格类似股票分析师的简短幽默点评。

4.  **有哪些容易忽略的使用细节？**
    *   **必须配置API Key：** 不填API Key直接点生成会弹窗提示，这是整个功能运行的基础。
    *   **数据缩放：** 生成的图表支持鼠标滚轮缩放和拖拽，可以仔细查看特定年龄段。
    *   **事件格式：** 在“人生复盘”模式中，事件按行分隔，建议使用“年龄：事件描述”的格式，AI理解得更好。
    *   **模式切换会清空数据：** 切换“运势推演”和“人生复盘”时，另一个模式的输入内容会被清空。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

1.  **控制面板模块（左侧）**
    *   **职责：** 接收用户输入，选择模式，触发生成指令，并展示AI返回的文本点评。
    *   **构成：** 模式切换标签、动态表单（根据模式显示不同输入框）、生成按钮、AI点评展示区。
    *   **逻辑：** 用户在此交互 → 数据被收集到Vue的变量中 → 点击按钮触发 `generateChart` 函数。

2.  **数据可视化模块（右侧图表区）**
    *   **职责：** 以专业金融图表的形式，直观展示人生数据的起伏。
    *   **构成：** ECharts图表实例、浮动水印、空状态提示。
    *   **逻辑：** 接收来自AI处理后的结构化数据 → 通过ECharts的 `setOption` 方法渲染为K线图 → 提供丰富的交互（提示、缩放）。

3.  **AI 引擎模块（不可见，但最关键）**
    *   **职责：** 理解用户的自然语言输入，并按照严格的规则，将其转化为结构化的、可量化的数据。
    *   **构成：** 封装在 `generateChart` 函数中的 `systemPrompt`（系统指令）和 API 调用。
    *   **逻辑：** 将用户输入和模式包装成一个详细的指令（Prompt） → 调用 DeepSeek API → 解析返回的JSON数据 → 将数据分别提供给“控制面板”（点评）和“数据可视化模块”（图表数据）。

**最值得学习的设计：**
**“Prompt 作为数据转换器”的设计。** 这是本项目的灵魂。它没有尝试用复杂的代码算法去“计算”人生走势，而是把“如何理解人生事件并转化为数据”这个最复杂的任务，通过一段精心设计的提示词（Prompt），交给了大语言模型（AI）来完成。前端只负责友好的输入和惊艳的展示，中间的“黑盒”处理既智能又灵活。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt 扮演的角色：**
    它是一个**“数据格式化与生成指令”**。它告诉AI：“嘿，我现在有一些关于人生的杂乱信息，请你按照我定的‘K线数据’这套规则，把它们重新组织并生成出来。”

2.  **解决的是“理解问题”还是“生成问题”？**
    两者皆是，但更偏向**“生成问题”**。它的核心任务是**生成**一套符合金融数据格式的、虚构的人生K线数据。当然，这个生成过程需要先**理解**用户输入的事件或背景。

3.  **Prompt 中的关键变量：**
    *   **模式判断 (`isPredict`):** 告诉AI当前是预测还是复盘，这决定了AI发挥的基调。
    *   **用户原始输入:** `birthDate`, `currentStatus`, `risk` 或 `lifeEvents`。这些是AI创作的素材。
    *   **严格的输出格式规定:** 要求AI返回一个特定的JSON结构，包含 `comment`（点评）和 `data`（数据数组）。这是确保前端能正确解析的关键。
    *   **数据规则:** 如“分数范围0-100”、“50为基准”、“红涨绿跌”等，这些规则让生成的数据具有一致性和可读性。

4.  **如果只改 Prompt，不改代码，会发生什么？**
    整个应用的行为和产出将发生根本性变化。例如：
    *   把“开心指数”改成“财富指数”或“健康指数”，整个图表的含义就变了。
    *   修改输出JSON的格式，前端图表就无法正确解析，导致显示错误。
    *   改变点评的风格要求（比如从“幽默犀利”改成“温柔治愈”），AI返回的文字氛围会完全不同。
    *   你可以通过修改Prompt，轻松地将这个“人生K线”改造成“项目进度K线”、“恋情发展K线”等等。

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

1.  **第一步：替换“主题”，保持骨架**
    *   **目标：** 先做出一个能跑通的、属于你自己的版本。
    *   **操作：** 不要动任何代码结构。只做两件事：
        *   **改标题和文字：** 把“人生K线图”改成“**游戏角色战力K线图**”。把“出生日期”改成“**角色创建日期**”，“当前状态”改成“**当前版本强度**”，“风险偏好”改成“**角色成长曲线**”（稳健、爆发、后期）。
        *   **改Prompt：** 在 `systemPrompt` 变量里，把所有关于“人生”、“年龄”、“开心指数”的描述，换成“游戏角色”、“版本号”、“战力指数”。输出格式（JSON）完全保留。
    *   **结果：** 你将立刻得到一个能为游戏角色生成战力起伏图的应用。

2.  **第二步：调整输入与输出字段**
    *   **目标：** 让应用更贴合你的新主题。
    *   **操作：**
        *   **输入：** 根据新主题，增加或修改左侧面板的输入框。例如，为“游戏角色”增加“职业”、“装备等级”等字段。你需要修改Vue中的 `data` 和模板中的表单。
        *   **输出：** 修改图表提示框（`tooltip.formatter`）里的文字，把“岁”改成“版本”，把“开心指数”改成“战力评分”。
    *   **结果：** 应用的专业度和定制感大幅提升。

3.  **第三步：改变视觉风格**
    *   **目标：** 拥有独特的品牌外观。
    *   **操作：**
        *   修改 `tailwindcss` 的配色。将 `bg-[#131722]`（深蓝黑）、`red-600`、`green-500` 等颜色变量，换成你主题的颜色（如科技蓝、魔法紫）。
        *   更换字体、图标库。
        *   修改水印文字和图标。
    *   **结果：** 一个从功能到外观都完全属于你的新应用。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“数据持久化”与分享功能**
    *   **操作：** 使用 `localStorage` 或 `IndexedDB` 保存用户生成过的历史K线图。为每个生成结果生成一个唯一的ID或截图，并创建一个“分享链接”按钮，将数据编码到URL中，方便分享给朋友查看。
    *   **价值：** 从一次性工具变成可积累、可传播的玩具。

2.  **引入更多AI模型或本地模型**
    *   **操作：** 在设置面板中，增加更多API选项（如OpenAI GPT、Claude、智谱GLM）。甚至可以尝试集成 `Ollama`，让用户选择运行在自己电脑上的本地模型，彻底消除API成本。
    *   **价值：** 提高可用性，满足不同用户偏好，或提供离线使用能力。

3.  **拆分“复盘”与“预测”，深化功能**
    *   **操作：** 将“人生复盘”模式扩展成一个独立页面。允许用户上传时间线图片、为每个事件手动打分（拖动滑块），AI仅作为补充描述生成器。将“运势推演”模式与一些简单的命理或星座知识库（本地数据）结合，减少对API的完全依赖。
    *   **价值：** 功能更专精，用户体验更深入，减少对网络和API的依赖。

4.  **优化交互体验**
    *   **操作：** 生成过程中，在按钮上显示加载进度或阶段提示。生成后，允许用户点击某根K线，在侧边栏展开该年份的“详细分析报告”（可再次调用AI生成）。增加键盘快捷键（如按`空格键`重新生成）。
    *   **价值：** 让应用感觉更流畅、更强大、更专业。

5.  **从“单人生”到“对比人生”**
    *   **操作：** 设计一个“双图表对比”模式。让用户输入两套信息（如“我的现实人生” vs “我梦想的人生”；“我的K线” vs “平均K线”），并排或叠加显示两个K线图，AI生成对比点评。
    *   **价值：** 创造新的玩法和洞察点，社交性和趣味性更强。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做严肃决策依据：** 切勿根据这个工具的“预测”来做出教育、职业、财务或情感上的重大人生决定。它只是一个创意娱乐工具。
*   **不适合进行精准的心理状态追踪：** 情绪的量化极其复杂和个人化，这个工具简单的0-100分模型是对真实情况的极大简化，不能替代日记、心理咨询或专业的情绪评估工具。
*   **不适合处理大规模、精确的历史数据：** 如果你想分析公司真实的股价、加密货币波动，或者基于大量真实统计数据生成图表，应该使用专业的金融数据分析软件（如TradingView, Python的 `pandas` + `matplotlib` 库）。
*   **不适合作为AI Prompt工程的唯一学习案例：** 这个项目的Prompt设计相对直接。要学习更复杂、稳定的Prompt工程（如思维链、ReAct模式等），需要寻找更专业的教程和项目。

**总结：** 这个网页是一个绝佳的“**创意原型**”范例。它巧妙地结合了成熟的图表库、现代前端框架和AI的能力，快速构建出一个有趣、有传播力的概念。你的学习重点应该是掌握这种 **“前端（交互+可视化） + AI（智能处理） = 创意应用”** 的搭建模式，并学会如何通过修改Prompt来快速迭代创意。
