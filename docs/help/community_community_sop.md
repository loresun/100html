# 社群SOP话术生成器 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
想象你是一个社群运营者（比如母婴群、读书会、电商客户群的管理员），每天需要在群里发布不同内容来活跃气氛、推广产品、或者引导用户下单。你常常为“今天该发什么话术？”、“早上和晚上的语气怎么调整？”、“同一个活动能不能多几个版本让用户不觉得重复？”这些问题头疼。

这个工具就是你的“AI运营助理”。它帮你：
- **批量生成**：一次性为早、中、晚不同时段，生成多个版本的话术，让你有充足的选择。
- **场景化定制**：针对“拉新”、“激活”、“转化”、“促单”、“售后”等不同运营目标，生成针对性话术。
- **结构化输入**：你只需要描述清楚你的社群是做什么的、卖给谁，AI就能结合你的业务背景来创作。

**适合什么情况？**
- 你需要为微信群、QQ群等私域社群准备日常运营内容。
- 你希望快速获得不同风格、不同时段的话术进行A/B测试。
- 你没有专业的文案团队，或者想为现有文案提供更多灵感。

**不适合什么情况？**
- 需要生成非常长、结构复杂的文章（如公众号推文、活动策划案）。
- 需要完全原创、无任何模板痕迹的创意文案（AI生成的内容仍有一定模式）。
- 对话实时性要求极高的场景（如与用户的实时一对一聊天）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **社群/产品信息（必填）**：在左侧第一个大文本框里，告诉AI你的社群是做什么的。例如：“我们是一个健身打卡社群，主要卖蛋白粉和运动装备，成员以20-30岁上班族为主。”
2.  **运营场景（必选）**：在五个卡片中选择一个当前的目标，比如想让大家更活跃，就选“社群激活”。
3.  **发送时段（至少选一个）**：选择你打算在什么时间发消息，可以多选。AI会根据“早上积极”、“中午轻松”、“晚上温暖”的设定调整语气。
4.  **每时段生成版本数（可选）**：用滑块选择，比如选“3”，那么每个你选中的时段，AI都会生成3个不同角度的话术。
5.  **额外要求（可选）**：可以在这里提出更具体的指令，比如“多加点表情符号”、“语气要幽默一点”。

**用户通常会做哪几步操作？**
1.  **填写与选择**：完成上述所有输入和选择。
2.  **点击生成**：点击底部紫色的“生成社群话术”按钮。
3.  **查看结果**：在右侧区域，结果会按“时段”分组展示。每个时段下有你指定数量的“版本”卡片。
4.  **使用结果**：你可以直接“复制”某条话术到剪贴板，粘贴到群里使用；也可以“重新生成”某个不满意的版本；或者“导出全部”话术到一个文本文件备用。

**输出结果长什么样？**
输出是一段段可以直接复制粘贴到微信群里的文字。例如（针对“母婴社群-早上-激活场景”）：
> “各位宝妈早上好呀！☀️ 美好的一天从我们的育儿交流开始～ 今天想和大家聊聊宝宝添加辅食后，便便颜色变化正常吗？【有经验的宝妈快来支招！】评论区分享你的观察，我们一起学习成长！💕”

**有哪些容易忽略的使用细节？**
- **API设置**：第一次使用前，需要点击右上角的“设置”按钮，填入你自己的DeepSeek API Key，否则无法生成。
- **模型选择**：右上角可以选择“DeepSeek V3”或“DeepSeek R1”。R1模型会展示“深度思考过程”，让你看到AI的推理逻辑，但生成速度可能稍慢。
- **重新生成**：对某个版本不满意，可以点击该卡片右上角的“刷新”按钮单独重新生成，无需全部重来。
- **导出功能**：导出的文本文件会包含所有话术、你的输入信息以及生成时间，方便存档和管理。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“配置面板 + 结果展示”** 左右分栏结构，逻辑清晰，非常适合学习。

**关键模块与职责：**
1.  **控制面板模块（左侧）**
    - **职责**：收集用户的所有“创作指令”。它把复杂的文案创作需求，拆解成“产品背景”、“运营目标”、“发送时间”、“数量与风格”这几个结构化选项。
    - **设计亮点**：将抽象的“写一段话”需求，变成了表单填空和按钮选择，极大降低了用户的使用门槛和思考负担。

2.  **结果展示模块（右侧）**
    - **职责**：清晰、分组地呈现AI的创作成果，并提供便捷的“复制”、“重试”、“导出”等操作。
    - **设计亮点**：按“时段”分组，符合运营人员的实际工作流（需要按排期准备内容）。每个“版本”独立成卡，方便对比和选择。

3.  **AI通信模块（脚本中 `generateSingle` 函数）**
    - **职责**：将左侧收集的“用户指令”和内置的“场景知识”，组装成AI能理解的“提示词（Prompt）”，调用API，并处理返回的流式数据。
    - **设计亮点**：实现了“流式响应”，生成过程中文字会逐个显示，体验更好。同时兼容了显示“思考过程”（R1模型）的功能。

**输入 → 处理 → 输出 逻辑链路：**
1.  **输入**：用户在左侧表单填写信息并点击“生成”。
2.  **处理**：
    - 前端将表单数据 + 选中的场景/时段内置提示语，拼接成完整的 **系统提示词** 和 **用户提示词**。
    - 通过 `fetch` 请求将提示词发送给 DeepSeek API。
    - 接收AI返回的“数据流”，实时更新到对应的结果卡片上。
3.  **输出**：将AI返回的文本，按“时段-版本”的结构，渲染在右侧的卡片中。

**最值得学习的设计：**
**“场景化模板 + 结构化变量”的提示词工程。** 它没有让用户直接去写复杂的Prompt，而是把优秀的Prompt模板（藏在`scenes`和`timePeriods`数组的`prompt`字段里）提前写好。用户只需要提供“变量”（如产品信息），系统就能自动组合出高质量的完整Prompt。这是将AI能力产品化、傻瓜化的关键思路。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt是隐藏在背后的“**灵魂指令**”。它决定了AI以什么身份、什么风格、基于什么信息来生成内容。在这个工具里，Prompt不是一个框，而是由 **系统提示词** 和 **动态组装用户提示词** 两部分精密配合的。

**它解决的是“理解问题”还是“生成问题”？**
两者都有，但更侧重于 **“理解问题”**。
- **系统提示词**：解决“身份与框架”问题。它告诉AI：“你现在是一个10年经验的社群运营专家，你要写的话术要自然、要有引导性、要符合微信群习惯...”。这设定了生成的**质量标准和风格框架**。
- **用户提示词**：解决“具体任务”问题。它把用户输入的“产品信息”、“选择的场景和时段”、“额外要求”像拼积木一样拼起来，告诉AI这次具体的任务是什么。

**哪些信息是 Prompt 中的关键变量？**
1.  **产品信息 (`productInfo`)**：这是最核心的变量，决定了话术的“内容血肉”。AI会基于这些信息来具体发挥。
2.  **场景提示 (`scene.prompt`)**：如“【拉新裂变场景】生成邀请好友入群的话术...”，这决定了话术的**核心目标和策略**。
3.  **时段提示 (`period.prompt`)**：如“早上好类型的问候...”，这决定了话术的**语气和情感基调**。
4.  **版本索引 (`versionIndex`)**：提示词中会包含“这是第X个版本，请提供不同角度”，这是实现**批量生成多样化内容**的关键技巧。

**如果只改 Prompt，不改代码，会发生什么变化？**
效果会发生**立竿见影**的变化：
- **修改 `scenes` 数组中的 `prompt` 字段**：会彻底改变该场景下生成话术的侧重点和风格。比如把“售后关怀”的提示词从“提升忠诚度”改成“紧急处理客诉”，生成的话术会从“温情关怀”变成“专业道歉与解决方案”。
- **修改 `timePeriods` 数组中的 `prompt` 字段**：会改变不同时段的语气。比如把晚间的“情感共鸣”改成“重磅促销”，晚间话术会从走心变得更具商业性。
- **修改 `customSystemPrompt` （自定义系统提示词）**：会改变AI的底层“人设”和所有话术的通用标准。比如加入“严禁使用感叹号”，那么所有生成的话术风格都会变得沉稳。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“模仿路径”，从最安全的地方开始改动：

**第一步：保持结构不变，替换使用场景（最安全）**
- **目标**：做一个“小红书笔记标题生成器”。
- **操作**：
    1.  将 `scenes` 数组中的内容替换。例如：
        - `id: 'acquisition'` -> `id: 'viral'`, `name: '爆款标题'`, `desc: '高互动高流量'`, `prompt: '【爆款标题】生成能引发好奇心和点击欲的小红书笔记标题。善用数字、痛点提问、身份标签...'`
        - `id: 'activation'` -> `id: 'tutorial'`, `name: '教程干货'`, `desc: '步骤清晰实用'`...
    2.  将 `timePeriods` 替换为不同的 **内容类型** 或 **平台**。例如：
        - `id: 'morning'` -> `id: 'fashion'`, `name: '穿搭'`, `prompt: '针对穿搭类笔记的标题风格...'`
        - `id: 'afternoon'` -> `id: 'food'`, `name: '美食'`...
    3.  将页面标题、文案中的“社群”、“话术”等词全局替换为“小红书”、“标题”。
- **效果**：你立即得到了一个结构完整、UI美观的新工具，功能完全变成了生成小红书标题。

**第二步：调整输入字段或 Prompt**
- **目标**：让工具更贴合“标题生成”的需求。
- **操作**：
    1.  修改左侧“社群/产品信息”的标签和提示文本，改为“笔记核心内容描述”。
    2.  在 `scenes` 和新的“内容类型”的 `prompt` 字段里，详细描述优秀标题的公式和技巧。
    3.  “额外要求”可以改为“关键词”（让用户填入希望包含的热词）。
- **效果**：工具的输入和输出更专业化，Prompt更精准，生成质量更高。

**第三步：改变输出形式或展示方式**
- **目标**：优化结果展示。
- **操作**：
    1.  右侧结果卡片可以增加一个“模拟小红书封面”的预览区域（用CSS简单模拟）。
    2.  可以增加“点赞数预测”、“爆款指数”等模拟标签（用简单的随机数或规则计算）。
    3.  导出功能可以调整为导出为更适合标题库的CSV格式。
- **效果**：工具的交互体验和实用性进一步提升。

**从哪里下手最安全？**
从 **第一步** 下手最安全。因为你只修改了数据（`scenes`, `timePeriods` 数组和文字），没有动任何核心逻辑（Vue代码、API调用函数、HTML结构）。即使改错了，也很容易对照原版恢复。这是学习“套用模板”的最佳起点。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“角色设定”输入**：
    - **操作**：在左侧面板增加一个下拉框或输入框，让用户选择或自定义发言者身份，如“亲切的群主”、“专业的营养师”、“幽默的班长”。
    - **效果**：将此变量插入到系统提示词中（例如“你将以[身份]的口吻发言”），话术的个人化风格会更强。

2.  **切换为其他模型或本地模型**：
    - **操作**：修改 `generateSingle` 函数中的API请求地址和参数。例如，将 `https://api.deepseek.com/v1/chat/completions` 换成 OpenAI、通义千问或智谱AI的接口。如果你在本地部署了Ollama，可以换成 `http://localhost:11434/api/chat`。
    - **效果**：可以对比不同模型在该场景下的生成效果，或在不依赖外部API的情况下使用。

3.  **拆分为“配置页”和“执行页”**：
    - **操作**：将当前页面拆成两个。A页面负责填写所有配置（产品信息、场景等），点击“保存方案”后将配置存入 `localStorage` 或生成一个链接。B页面是一个简洁的“生成工作台”，读取配置并专注于话术的生成、刷新和导出。
    - **效果**：适合需要管理多个不同社群方案的专业用户，工作流更清晰。

4.  **优化交互：增加“话术评分”与“收藏”功能**：
    - **操作**：在每个话术卡片上增加“点赞/点踩”按钮。用户评分后，将“高评分的话术内容+当时的生成配置（Prompt）”记录下来，存入 `localStorage`。
    - **效果**：形成用户个人的“优质话术库”，并且可以反向学习哪些配置（Prompt组合）更容易产出优质内容，实现数据驱动优化。

5.  **增加“多轮对话”优化功能**：
    - **操作**：在每个话术卡片下增加一个“优化”按钮。点击后弹出小文本框，用户可以输入“再短一点”、“加入一个抽奖活动”等指令，工具将此指令作为新的用户消息，与之前的历史记录一起再次调用AI，实现话术的迭代优化。
    - **效果**：从“一次性生成”升级为“可协作编辑”，AI更像一个随时待命的文案助手。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合生成法律、医疗等专业领域的严谨文本**：AI生成的话术缺乏严格的合规性审查，不能替代专业法律文书或医疗建议。
- **不适合完全替代人类创意和情感连接**：对于需要深度品牌调性、高度情感共鸣或处理复杂客诉的场合，AI话术可能显得模板化或不够真诚，仍需人工润色和判断。
- **不适合作为全自动群发机器人**：本工具只负责“内容生成”。如果想让AI自动定时发送到微信群，你需要将其与微信群控工具或机器人API（如企业微信机器人、钉钉机器人）结合，并自行处理消息发送的频率、合规性等风险。
- **如果用户想做X，应该换什么工具或方式？**
    - **想做长篇内容（公众号文章、报告）**：应使用专门的AI写作工具（如Notion AI、秘塔写作猫），它们有更优的长文本处理和结构规划能力。
    - **想做实时智能客服**：应使用接入大模型的对话机器人平台（如Dify、FastGPT），它们具备对话记忆、知识库检索和流程编排能力。
    - **想做视觉内容（海报、配图）**：应转向AI绘画工具（如Midjourney、Stable Diffusion）或Canva等设计平台的AI功能。
