# 小红书图书推荐文案工具 - 学习指南

## 【一】这个网页解决了什么问题？

想象你刚读完一本好书，想在小红书上分享，却不知道怎么写才能吸引人。你可能会纠结：标题怎么写才抓眼球？正文结构怎么安排？用什么话术才能让读者产生购买冲动？

这个网页就是你的“小红书文案助手”。它专门解决**“如何将一本书包装成受欢迎的小红书笔记”**这个问题。它适合：
- **图书博主/编辑**：需要快速为不同书籍生成多种风格的推荐文案。
- **普通读者**：想分享读书心得，但缺乏文案写作经验。
- **营销人员**：需要批量测试不同文案风格对特定人群的吸引力。

**不适合**：
- 需要生成完整书评或深度分析文章。
- 需要直接发布到小红书平台（它只生成文案，不负责发布）。
- 书籍内容非常专业或小众，需要特定领域知识来撰写。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你需要填写5个关键信息：
1.  **书名**：你想推荐的那本书的名字。
2.  **核心亮点**：这本书最吸引人的2-3个特点（如“可执行清单”、“图文并茂”）。
3.  **目标读者**：这本书最适合谁看（如“学生党”、“新手妈妈”）。
4.  **笔记风格**：你希望文案呈现的感觉（如“真实体验”、“干货清单”）。
5.  **场景/用途**：在什么情况下读这本书（如“自我提升”、“睡前阅读”）。

**用户通常会做哪几步操作？**
1.  **配置（首次使用）**：点击右上角的齿轮图标，在弹出的窗口中输入你的DeepSeek API Key并保存。
2.  **填写信息**：在左侧“小红书信息”区域，依次填写上述5个输入框。
3.  **生成提示**：点击蓝色的“生成小红书文案”按钮。
4.  **查看结果**：右侧面板会立即显示三部分内容。

**输出结果长什么样？**
点击按钮后，右侧会生成：
1.  **AI 提示词**：一个完整的、结构化的文本指令。这是你**可以复制并直接粘贴到AI聊天框（如ChatGPT、DeepSeek）里**的“魔法咒语”。AI会根据这个指令生成最终文案。
2.  **笔记结构**：一个简短的列表，告诉你一篇合格的小红书图书笔记通常包含哪几个部分（如开场、中段、结尾）。
3.  **交付物建议**：另一个列表，说明最终你会从AI那里得到哪些具体的文案素材（如标题池、正文模板）。

**有哪些容易忽略的使用细节？**
- **这不是一个“一键生成”工具**：它本身不调用AI。它的核心产出是那个“AI提示词”。你需要**手动复制这个提示词，然后去你常用的AI平台（网页或App）粘贴并运行**，才能得到最终文案。
- **API Key是全局的**：你配置的DeepSeek Key会被保存在浏览器里，同一个网站下的其他工具可能也会用到它。
- **输入越具体，提示词越好**：在“核心亮点”和“目标读者”框里多写几个关键词，生成的提示词会更精准，最终AI产出的文案质量也更高。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个模块：

**1. 信息输入与配置模块（左侧面板 + 右上角）**
- **职责**：收集用户关于书籍和文案风格的所有想法，并管理访问AI所需的“钥匙”（API Key）。
- **包含**：5个输入框、生成按钮、设置按钮和API状态指示器。
- **逻辑**：用户填写信息 → 点击生成 → 触发后续模块。

**2. 提示词与框架生成模块（右侧面板）**
- **职责**：将用户零散的想法，**组装成一个专业、结构化的AI指令（Prompt）**，并同时给出内容框架作为参考。
- **包含**：`promptOutput` (显示生成的提示词)、`structureList`和`deliverableList`。
- **逻辑**：接收左侧输入 → 按照固定模板拼接成完整Prompt → 在页面上显示出来。

**3. 模态框（弹窗）模块**
- **职责**：提供一个不跳转页面的、聚焦的交互区域，用于处理敏感信息（API Key）的输入和保存。
- **逻辑**：点击设置按钮打开 → 输入并保存Key → 关闭弹窗并更新状态。

**最值得学习的设计：Prompt模板引擎**
这个网页的核心不是一个AI调用器，而是一个 **“Prompt生成器”** 。它最巧妙的地方在于：
- **输入**：5个简单的文本框。
- **处理**：一个隐藏在`generateBtn`点击事件里的字符串模板。它把用户输入像填空一样，嵌入到一个预先设计好的、符合小红书平台调性的专业Prompt框架里。
- **输出**：一个可直接使用的、高质量的AI指令。
这种设计将“构思Prompt”这个有门槛的任务，简化成了“填写表单”，极大降低了用户使用AI的门槛。这是**人机交互设计**和**提示工程（Prompt Engineering）** 的完美结合点，非常值得学习。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是**连接用户意图与AI能力的桥梁**。在这个工具里，Prompt是**最终产品**。页面本身不生产文案，它生产的是能生产文案的“说明书”（即Prompt）。

**它解决的是“理解问题”还是“生成问题”？**
它同时解决了两个问题：
1.  **理解问题**：它通过预设的模板，**帮助AI理解“小红书图书推荐笔记”这个特定任务需要什么格式、什么风格、包含哪些要素**。没有这个Prompt，AI可能只会写出一篇普通的书评。
2.  **生成问题**：它给AI提供了明确的**生成清单**（“输出要求”里的5点），让AI的创作不跑偏，确保产出物直接可用。

**哪些信息是Prompt中的关键变量？**
Prompt模板中的 `{title}`, `{highlights}`, `{audience}`, `{style}`, `{scene}` 这5个占位符是关键变量。它们来自用户的输入，是让每次生成的Prompt具有独特性和针对性的核心。

**如果只改Prompt，不改代码，会发生什么变化？**
这是本工具最强大的特性之一。你只需修改JavaScript代码中 `promptOutput.textContent = ` 后面那一长串字符串模板，就能彻底改变工具的用途。例如：
- 把“小红书图书推荐达人”改成“抖音电子产品测评博主”，它就变成了一个**数码测评脚本生成器**。
- 把“标题候选5个”改成“视频分镜脚本5个”，输出形式就变了。
- 增加一条输出要求“提供3个争议性话题点”，AI产出的内容策略就会改变。
**代码结构完全不用动，你只是换了一套“灵魂指令”。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的Prompt生成工具：

**第一步：保持结构不变，替换使用场景（最安全）**
1.  复制整个HTML文件。
2.  修改`<title>`和`<h1>`里的文字，比如改成“抖音短视频脚本生成器”。
3.  修改左侧输入框的`<label>`和`placeholder`。把“书名”改成“产品名”，“核心亮点”改成“产品卖点”，“目标读者”改成“目标观众”等。
4.  **最关键的一步**：修改`generateBtn`点击事件里的那个**Prompt模板字符串**。参照原文案的结构，为你新的场景重写一套指令。例如，给AI的角色、输出要求全部换成短视频脚本相关的。

**第二步：调整输入字段或Prompt**
1.  根据新场景的需求，**增加或减少输入框**。比如做旅行攻略生成器，可能需要“目的地”、“旅行天数”、“预算”等字段。只需在HTML里复制一个输入框的代码块并修改，然后在JS里添加对应的变量获取即可。
2.  进一步优化Prompt模板，让指令更精准。可以上网搜索“如何写好XX领域的AI提示词”，把最佳实践融入你的模板。

**第三步：改变输出形式或展示方式**
1.  目前输出是只读的文本。你可以让结果更易用：比如在生成的Prompt旁边加一个“一键复制”按钮。
2.  更进一步，你可以**真正集成AI API**（利用已保存的Key），让页面在生成Prompt后，自动调用AI并**直接把最终文案显示在页面上**，实现真正的“一键生成”。这需要学习简单的异步JavaScript调用（fetch或axios）。

**从哪里下手最安全？**
从**第一步**开始最安全。因为你只修改了文字内容，没有改动任何功能逻辑。你能立即得到一个外观不同、用途不同的新工具，并且它能正常工作。这能给你最大的信心和成就感。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“负面描述”或“避坑点”输入**：好的推荐不仅要夸，有时指出“不适合谁”或“有什么缺点”反而更真实。可以增加一个“注意事项”文本框，并将其融入Prompt，让AI生成的文案更立体。
2.  **集成真正的AI调用，实现“端到端”生成**：
    - 在`generateBtn`的点击事件里，添加调用DeepSeek API的代码（使用已保存的`apiKey`）。
    - 将生成的Prompt作为API请求的`messages`参数发送。
    - 将API返回的AI回复，渲染在一个新的结果展示区域（比如在右侧面板下新增一个`<div>`）。
    - 这样改造后，工具就从“Prompt生成器”升级为“文案全自动生成器”了。
3.  **增加“文案风格”单选或下拉菜单**：除了自由输入的“笔记风格”，可以提供几个固定选项（如“活泼可爱”、“冷静专业”、“热血励志”），这些选项值可以作为更精确的关键词插入到Prompt中，让风格控制更稳定。
4.  **拆解为“新手模式”和“专家模式”**：
    - **新手模式**：保持现有简单的5个输入框。
    - **专家模式**：点击一个开关后，展开更多高级选项，如“指定模仿的博主”、“要求避免使用的词汇”、“设定文案字数”等。这可以让工具同时满足小白用户和高级用户的需求。
5.  **优化交互：添加示例和保存功能**：
    - 在每个输入框旁边加一个“示例”小按钮，点击后自动填入优质示例，帮助用户理解该怎么填。
    - 增加“保存本次配置”功能，将用户填写的信息组合保存到本地，下次可以快速加载，方便对同一本书进行不同风格的文案测试。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合直接进行多轮对话或深度定制**：它生成的Prompt是“一次性”的指令。如果你需要根据AI的第一版回复提出修改意见（如“把标题写得更夸张一点”），你需要**手动进行第二轮对话**，这个工具无法帮你完成后续的交互优化。
- **不适合生成高度创意或艺术性内容**：它的模板偏向于实用、结构化的商业文案（种草文）。如果你想写一首关于这本书的诗，或者一个富有文学性的读后感，这个工具生成的Prompt可能限制而非激发AI的创意。
- **不适合处理复杂逻辑或数据计算**：它只是一个信息收集和文本拼接工具。如果你的场景需要先计算（如根据预算推荐旅行路线），你需要另一个工具或手动完成计算，再将结果作为输入填进来。
- **如果需要“真正的一键发布”**：这个工具链止步于文案生成。如果你需要将生成的文案直接同步发布到小红书、知乎等平台，你需要寻找或开发集成了相应平台发布API的专业工具。
