# Webtools 工具箱 - 学习指南

## 【一】这个网页解决了什么问题？

这个网页是一个**个人工具箱**，它解决了日常工作和学习中需要频繁切换不同工具的问题。想象一下，你正在学习或工作，突然需要计算一笔存款的利息，然后又想记录一个待办事项，接着需要专注25分钟，最后还想快速换算一下单位。如果每个功能都要打开一个独立的网站或App，会非常麻烦。

**适合的使用场景：**
- **个人学习与工作**：当你需要快速使用一些简单工具，但又不想安装多个软件或打开多个网页时。
- **轻度、临时性需求**：比如快速计算、临时记录、短时间计时等。
- **希望所有工具在一个地方**：喜欢整洁、讨厌杂乱标签页的用户。

**不适合的情况：**
- **专业、复杂计算**：如需要复杂公式、图表分析或大量数据处理的金融、工程计算。
- **团队协作**：所有数据都保存在本地浏览器，无法与他人共享或同步。
- **长期、重要的数据管理**：因为数据可能因清除浏览器缓存而丢失，不适合作为唯一的账本或笔记系统。

## 【二】使用方式（给第一次接触的人）

1.  **打开页面**：你会看到一个标题为“简单利息计算器”的页面，但实际上它包含多种工具。
2.  **理解页面结构**：
    *   顶部有“返回 Webtools”的导航和设置按钮。
    *   中间最大的区域就是当前正在使用的工具。
3.  **基本操作步骤**：
    *   **选择工具**：虽然当前页面显示“利息计算器”，但根据代码结构，这个页面可能是一个“工具箱”的入口之一。通常，你会从一个工具列表页面进入某个具体工具（如利息计算器）。
    *   **输入数据**：在工具对应的输入框（如“本金”、“年利率”、“时间”）里填写数字。
    *   **触发计算**：点击“计算结果”按钮。
    *   **查看结果**：结果会显示在按钮下方，清晰地区分了标签和数值。
4.  **输出结果长什么样？**
    *   结果通常在一个有灰色边框的卡片中展示。
    *   上方是小字标签（如“利息”、“本息合计”），下方是放大加粗的数值，非常直观。
5.  **容易忽略的使用细节：**
    *   **设置功能**：点击右上角的齿轮图标可以配置API（如DeepSeek），这说明某些工具（可能是“文本工具”或“生成器”）背后接入了AI能力。
    *   **自动保存**：注意“笔记工具”的代码中有一个 `@input.debounce.400ms` 的属性。这意味着你在笔记中输入内容时，系统会在你停止输入400毫秒后自动保存，无需手动点击保存按钮。
    *   **本地存储**：你的所有记录（待办、记账条目、笔记）都保存在你的浏览器本地。换一台电脑或清除浏览器数据，这些记录就会消失。

## 【三】核心结构拆解（学习重点）

这个页面的设计非常模块化，是学习的典范：

1.  **导航模块**：
    *   **职责**：提供返回主页的入口和全局设置入口。
    *   **设计亮点**：使用模糊背景(`backdrop-blur`)和固定定位(`sticky`)，保证在任何工具页面都能便捷操作。

2.  **工具容器模块**：
    *   **职责**：作为所有工具的“画布”，根据当前工具的类型(`tool.type`)动态切换显示不同的UI界面。
    *   **逻辑链路**：`x-data` 中加载了一个工具对象 → `x-show` 根据 `tool.type` 决定显示哪个工具面板 → 用户在面板中输入 → 点击按钮调用对应的函数(`calculate`, `startTimer`等) → 函数更新 `tool.result` 等数据 → 页面自动刷新显示结果。

3.  **工具类型模块（共10种）**：
    这是最核心的部分。页面没有为每个工具写一个独立的HTML文件，而是用一套模板系统来渲染。
    *   **公式计算器 (`formula`)**：通过 `tool.fields` 数组动态生成输入框，计算逻辑写在JS函数里。
    *   **计时器/番茄钟/秒表 (`timer`, `pomodoro`, `stopwatch`)**：共用“开始/暂停/重置”的交互模式，核心是使用 `setInterval` 更新剩余或已用时间。
    *   **清单/记账/笔记 (`list`, `ledger`, `note`)**：核心是“增删改查”本地数据，并用 `x-for` 指令循环渲染列表。
    *   **生成器/文本工具/转换器 (`generator`, `text`, `converter`)**：可能调用AI API或本地函数进行处理，将输入转换为输出。

**最值得学习的设计：**
**“配置驱动UI”** 的思想。尤其是“公式计算器”部分，它的界面（有几个输入框、叫什么标签、单位是什么）完全由一个 `tool.fields` 数组定义。这意味着，如果你想新增一个“复利计算器”，你几乎不需要修改HTML，只需要在JavaScript中定义一个新的 `tool` 对象，包含对应的 `fields` 和 `calculate` 函数即可。这极大地提高了代码的可维护性和可扩展性。

## 【四】Prompt / AI 逻辑是如何被设计的？

从代码中的设置面板可以看出，这个工具箱为某些工具预留了AI能力（如DeepSeek API）。

1.  **Prompt扮演的角色**：在这个页面中，Prompt（提示词）是**隐式存在**的。它可能被用在“文本工具”或“生成器”中。例如，在“文本工具”中，用户输入一段文字，点击“处理文本”，背后的JS函数可能会将用户输入的文字与一段预设的Prompt组合，然后发送给AI API，最后将AI的回复展示为输出。
2.  **解决什么问题**：它主要解决“生成问题”和“转换问题”。比如，根据几个关键词（输入字段）生成一段文案、总结长文本、翻译语言或转换文本风格。
3.  **关键变量**：Prompt中的关键变量通常就是用户在输入框中填写的内容。例如，在一个“周报生成器”工具里，Prompt可能是：“请根据以下工作内容生成一份专业的周报：{{用户输入的内容}}”。这里的 `{{用户输入的内容}}` 就是关键变量。
4.  **只改Prompt的影响**：如果不改动任何代码，只修改JS中内置的Prompt文本，那么AI工具的行为会发生根本性变化。例如，把“总结以下文本”的Prompt改成“用幽默的口吻改写以下文本”，那么同一个“文本工具”就会从“总结”功能变成“幽默改写”功能。这展示了**通过配置而非代码来改变功能**的强大之处。

## 【五】如何模仿它，做出你自己的版本？

这是一个绝佳的模板，你可以按以下安全路径创建自己的工具箱：

**第一步：复制结构，替换“灵魂”**
1.  将整个HTML、CSS、JS框架保存下来。
2.  找到定义所有工具的JavaScript文件（代码中引用的 `standalone.js` 或类似文件）。这是页面的“灵魂”。
3.  在这个JS文件中，找到工具列表，从你**最理解、最常用**的一个工具开始模仿。比如，你觉得“计数器”最简单，就先研究它。

**第二步：创建你的第一个工具**
1.  **确定类型**：你的新工具最像现有的哪一类？是输入数字计算的`formula`，还是记录项目的`list`？
2.  **修改配置**：在JS中复制一个类似工具的配置对象。例如，做“BMI计算器”，就复制`formula`工具的配置。
3.  **更改配置项**：
    *   修改 `name` 和 `desc`（名称和描述）。
    *   修改 `fields`（输入字段），把“本金、利率”换成“身高(m)、体重(kg)”。
    *   修改 `calculate` 函数里的公式，把利息计算改成 `体重 / (身高 * 身高)`。

**第三步：调整外观与交互**
1.  如果结果展示不满意，可以去HTML里找到对应工具类型的输出模板（如 `formula` 的 `tool.result` 显示部分），微调它的样式。
2.  给你的新工具添加一个图标，并在主页的列表里加上它。

**从哪里下手最安全？**
从 **`formula`（公式型）** 或 **`counter`（计数器型）** 工具开始最安全。它们逻辑简单，不涉及复杂的定时器或列表循环，只需要修改配置数据和简单的计算函数，就能立刻看到效果，获得成就感。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加一个“汇率转换器”**：
    *   **操作**：在JS中新增一个 `type: 'converter'` 的工具。
    *   **关键点**：`tool.options` 里填充各国货币（USD, CNY, EUR...）。`runConverter` 函数需要调用一个免费的汇率API（如exchangerate-api.com）来获取实时汇率进行换算。

2.  **为“记账工具”增加图表**：
    *   **操作**：在记账工具的显示区域下方，新增一个 `<canvas>` 画布。
    *   **关键点**：使用轻量级的图表库（如Chart.js），当 `tool.entries` 数据变化时，按分类(`category`)汇总金额，绘制一个饼图或柱状图，让消费一目了然。

3.  **将“番茄钟”与“任务清单”结合**：
    *   **操作**：修改“番茄钟”的界面，在开始前可以从一个下拉菜单中选择本次专注对应哪个“清单工具”中的任务。
    *   **关键点**：专注结束后，自动在该任务上打勾或添加一条完成记录。这创造了工具间的联动，实用性大增。

4.  **实现“数据备份与恢复”**：
    *   **操作**：在设置面板中增加两个按钮：“导出数据”和“导入数据”。
    *   **关键点**：将所有 `localStorage` 中的数据打包成一个JSON文件让用户下载。导入时读取用户上传的文件并恢复数据。这解决了本地存储的最大痛点。

5.  **改造“生成器”，接入更多AI玩法**：
    *   **操作**：复制“生成器”的代码，创建多个实例。
    *   **关键点**：配置不同的Prompt，创建“小红书标题生成器”、“代码注释生成器”、“邮件润色助手”等。通过修改Prompt，一个工具模板就能衍生出无数个AI小应用。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做精确、复杂的科学或工程计算**：如矩阵运算、微分方程求解、电路仿真等。这些需要专业软件（如MATLAB, SPICE）。
2.  **不适合处理敏感或大量数据**：所有数据存储在浏览器本地，没有加密，容易通过简单检查被查看。且浏览器存储有容量限制，不适合存储大量文本或记录。
3.  **不适合需要永久保存和跨设备同步的核心数据**：例如你的个人日记、财务总账、客户关系管理。这些应该使用专业的、有服务器备份的云服务（如Notion, Google Sheets, 专业财务软件）。
4.  **不适合需要高强度、长时间交互的任务**：它的界面是为轻量、快速使用而设计的。如果需要像Excel那样持续操作大量单元格，或像Photoshop那样进行复杂编辑，这个工具箱会显得非常吃力。

**总结**：这个网页是一个出色的**个人生产力工具原型**。它教会我们如何用清晰的结构、模块化的思维和配置化的数据来构建一组小功能。你的学习重点不应是某个具体的利息计算公式，而是它如何用一套统一的规则，优雅地管理了十种不同的交互模式。从这里出发，你可以打造出任何你想要的轻量级工具。
