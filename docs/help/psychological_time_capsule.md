# 人生时间胶囊 - 帮助与学习指南

## 【一】这个网页解决了什么问题？

**使用场景：**
当你站在人生的某个节点，对未来感到迷茫、期待或焦虑时，这个工具能帮你把此刻的想法、状态和期望“封装”起来，通过AI的视角，生成一封写给未来自己的信。它像一位温柔的生活导师，帮你梳理思绪，用更结构化和富有情感的方式记录成长轨迹。

**适合情况：**
- 生日、新年、毕业等人生节点，想要进行自我反思和展望
- 设定重要目标（如职业转型、学习计划）后，想给自己一份鼓励和提醒
- 感到压力或迷茫，需要梳理现状并看到未来的可能性
- 想用一种有仪式感的方式记录当下的心境

**不适合情况：**
- 需要即时、专业的心理咨询（应寻求专业帮助）
- 需要具体的行动计划或项目管理工具
- 需要与他人协作或分享的目标设定

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面左侧有五个输入区域：
1. **时间维度**：选择这封信是写给1个月、1年、5年还是10年后的自己
2. **当前状态**：描述你现在的生活、心情、正在做的事
3. **未来期望**：写下你希望未来的自己达成的目标或成为的样子
4. **想说的话**：直接对未来的自己说些鼓励、提醒或嘱咐的话
5. **成就检验**（可选）：设置一个具体的里程碑，比如“如果学会了编程，就...”

**用户通常会做哪几步操作？**
1. 先点击右上角的设置按钮（齿轮图标），输入你的DeepSeek API Key（需要先注册获取）
2. 选择你喜欢的模型：V3（快速）或R1（会展示思考过程）
3. 填写左侧的所有或大部分信息，特别是“当前状态”和“未来期望”
4. 点击“生成时间胶囊”按钮
5. 等待片刻，右侧会显示生成的信件
6. 可以复制内容或下载为文本文件保存

**输出结果长什么样？**
生成的信件是一封结构完整、语言优美的Markdown格式信件，通常包含：
- 写信日期和预计打开日期
- 对你当前状态的温柔描述
- 对未来目标的展望
- 鼓励的话语
- 如果设置了里程碑，还会有检验建议

如果使用R1模型，还会有一个“深度思考过程”区域，可以看到AI是如何一步步构思这封信的。

**容易忽略的使用细节：**
1. **必须先配置API Key**：第一次使用必须点设置按钮输入Key，否则无法生成
2. **R1模型会显示思考过程**：如果你好奇AI是怎么“想”的，可以切换到R1模型
3. **成就检验是可选的**：不填也可以生成完整的信
4. **内容会自动保存**：刷新页面不会丢失已填写的内容（Vue的数据绑定特性）
5. **可以导出和复制**：生成后记得使用右上角的复制或下载按钮保存成果

## 【三】核心结构拆解（学习重点）

这个页面由四个主要模块组成，每个模块职责清晰：

**1. 配置管理模块**
- **职责**：管理API密钥、模型选择、系统提示词
- **位置**：右上角设置按钮打开的弹窗
- **关键设计**：使用`localStorage`保存配置，下次打开无需重复输入

**2. 输入收集模块**
- **职责**：收集用户的所有输入信息
- **位置**：左侧的白色卡片区域
- **关键设计**：使用Vue的`v-model`实现双向数据绑定，输入即时同步到数据对象

**3. AI处理模块**
- **职责**：调用DeepSeek API，处理流式响应
- **位置**：代码中的`generate()`函数
- **关键设计**：支持流式输出（显示生成过程），能同时处理普通回复和思考过程

**4. 结果展示模块**
- **职责**：展示生成的信件和思考过程
- **位置**：右侧的白色卡片区域
- **关键设计**：使用`marked`库将Markdown实时渲染为美观的HTML

**输入 → 处理 → 输出 的逻辑链路：**
```
用户填写表单 → 点击生成按钮 → 检查API配置 → 拼接系统提示词和用户输入 → 
调用DeepSeek API → 流式接收数据 → 分离思考内容和正式内容 → 
Markdown渲染 → 展示结果
```

**最值得学习的设计：**
**流式响应处理**是核心亮点。代码不是等待AI完全生成后再显示，而是一边接收一边显示，让用户看到“正在生成”的过程。特别是对R1模型，它能同时处理`reasoning_content`（思考过程）和`content`（正式回复），这种双通道数据处理很值得学习。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是“灵魂指令”。它告诉AI：“你现在不是普通的聊天机器人，而是一位温柔的生活导师，专门帮人写时间胶囊信。”

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。系统提示词（`systemPrompt`）定义了：
- AI的角色定位（生活导师）
- 信件必须包含的结构（6个部分）
- 语气要求（温暖、鼓励）
- 不同时间维度的处理方式

用户输入（`userPrompt`）则提供了具体内容，让AI基于这些信息进行创作。

**哪些信息是Prompt中的关键变量？**
1. **时间维度映射**：`timeframeMap`把“1month”转换成“1个月后”的中文描述
2. **当前日期**：自动获取并格式化
3. **用户填写的所有内容**：直接拼接到用户Prompt中
4. **模型类型**：决定是否启用深度思考模式

**如果只改Prompt，不改代码，会发生什么变化？**
- 改**系统提示词**：会彻底改变AI的“人格”和信件风格。比如改成“严厉的教练”，信件就会变得直接、严格。
- 改**用户Prompt模板**：会改变信息的组织方式，比如增加“最担心的三件事”这样的新部分。
- 改**温度参数**（`temperature: 0.8`）：调低会更稳定保守，调高会更创意随机。

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：替换使用场景，保持技术框架**
- 最安全：把“时间胶囊”改成“旅行计划生成器”、“读书笔记助手”、“健身计划书”
- 保持：Vue框架、Tailwind CSS样式、API调用逻辑
- 修改：页面标题、图标、输入字段的标签和提示文字

**第二步：调整输入字段和Prompt**
- 分析你的新场景需要收集什么信息
- 在`formData`中增加或减少字段
- 重写`systemPrompt`，定义新场景下的AI角色和输出要求
- 调整`userPrompt`的拼接逻辑

**第三步：改变输出形式和交互**
- 如果不需要思考过程，可以隐藏相关UI
- 可以增加“分享到社交媒体”按钮
- 可以改成PDF导出而不是纯文本
- 可以增加“再次编辑”功能，让用户基于AI生成的内容进行修改

**从哪里下手最安全？**
从**修改文字内容**开始：先不改代码结构，只改所有显示的文字（标题、标签、提示词）。确保新场景能跑通，再考虑增加/删除字段。

## 【六】3–5个可直接尝试的改造方向

**1. 增加情感标签和情绪分析**
- **操作**：在输入区增加“当前情绪”选择器（下拉菜单：兴奋、平静、焦虑、期待...）
- **效果**：AI可以根据情绪调整信件语气，焦虑时更多安慰，兴奋时更多鼓励
- **技术点**：在`userPrompt`中加入情绪标签，在`systemPrompt`中定义不同情绪的处理方式

**2. 改为多模型支持，增加对比功能**
- **操作**：在设置中增加OpenAI GPT、Claude等模型选项
- **效果**：可以用不同模型生成同一主题的信件，对比风格差异
- **技术点**：需要处理不同API的调用格式，可以抽象一个统一的AI服务层

**3. 增加“时间胶囊库”和定时提醒**
- **操作**：使用IndexedDB或后端存储生成的信件，设置定时邮件提醒
- **效果**：真正实现“时间胶囊”功能，到时间自动发送给自己
- **技术点**：需要后端支持或使用第三方邮件服务（如SendGrid）

**4. 可视化时间线展示**
- **操作**：把多次生成的信件按时间轴排列展示
- **效果**：可以看到自己的成长轨迹和心态变化
- **技术点**：需要本地存储历史记录，用SVG或Canvas绘制时间线

**5. 增加语音朗读和语音输入**
- **操作**：集成Web Speech API
- **效果**：可以听AI读信，也可以用语音描述当前状态
- **技术点**：`speechSynthesis`用于朗读，`SpeechRecognition`用于语音输入

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不是专业的心理评估工具**
   - 虽然能提供情感支持，但不能替代心理咨询师
   - 如果持续情绪低落或有心理困扰，应寻求专业帮助

2. **不是项目管理或目标追踪工具**
   - 它生成的是“鼓励信”，不是“行动计划”
   - 如果需要具体的任务分解、进度跟踪，应该用Notion、Trello等工具

3. **不能保证隐私绝对安全**
   - 虽然API Key本地存储，但生成内容会发送到DeepSeek服务器
   - 不要输入高度敏感的个人信息（如具体住址、身份证号等）

4. **不是多人协作工具**
   - 设计为个人使用，没有分享、协作功能
   - 如果想和家人一起写时间胶囊，需要自己改造

5. **依赖网络和第三方服务**
   - 必须联网，必须有DeepSeek账号和API额度
   - 如果DeepSeek服务不可用，整个工具失效

**如果用户想做X，应该换什么方式：**
- **想做详细的人生规划** → 使用OKR工具或专业的人生规划咨询
- **需要即时情感支持** → 联系朋友、家人或专业心理咨询热线
- **想与朋友互相鼓励** → 使用共享文档或专门的双人目标设定App
- **需要严格的进度监督** → 使用习惯追踪类App（如Habitica、Streaks）

---

**最后提醒**：这个工具的价值不在于技术的复杂性，而在于它创造了一个“自我对话”的仪式感空间。当你模仿它时，思考的核心应该是：“我想为用户创造什么样的对话体验？”技术只是实现这个体验的手段。
