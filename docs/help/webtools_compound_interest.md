# 复利计算器 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你计划进行长期储蓄或投资时，想知道“如果每月/每年固定投入一笔钱，在特定收益率下，多年后我能积累多少财富？”这个计算器能直观展示复利增长的威力，帮助你制定财务目标。

**适合情况**：
- 规划教育基金、养老金等长期储蓄
- 评估不同投资策略（如定投）的长期效果
- 向他人解释“为什么越早开始投资越好”

**不适合情况**：
- 短期（少于1年）的财务计算
- 需要精确考虑税收、通胀、手续费等复杂因素的投资分析
- 高风险投资或波动性极大的资产（如个股）的精确预测

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- **初始本金**：你一开始就投入的钱
- **每年/月追加**：你定期额外投入的金额，可选择“每月”或“每年”
- **年化收益率**：预期的年平均回报率（百分比）
- **投资年限**：你计划投资的年数

**用户通常会做哪几步操作？**
1. 在左侧输入区填写或调整四个数值
2. 观察右侧“期末总资产”等关键数字的变化
3. 查看图表，了解资产增长趋势
4. 浏览下方表格，查看每年的详细数据

**输出结果长什么样？**
- **大数字展示**：最终总金额、总投入本金、总利息收益
- **增长曲线图**：两条线分别显示“总资产”增长和“本金投入”累积
- **年度明细表**：每年期初金额、当年投入、当年收益、期末余额

**容易忽略的使用细节**
- 滑块和输入框是联动的：拖动滑块或直接输入数字效果相同
- “每月”和“每年”切换会显著影响最终结果（复利频率不同）
- 图表中的Y轴单位：当数值过大时，会自动转换为“w”（万）为单位
- 表格可以滚动查看，表头在滚动时会保持固定

## 【三】核心结构拆解（学习重点）

**页面由四个关键模块组成：**

1. **输入控制模块**（左侧）
   - **职责**：收集用户的所有参数设置
   - **设计亮点**：每个输入项都有清晰的标签、货币符号、滑块辅助，提供良好的触控和键盘输入体验

2. **结果摘要模块**（右上）
   - **职责**：用醒目的方式展示最重要的计算结果
   - **设计亮点**：大字体突出最终金额，用对比色区分“投入”和“收益”

3. **可视化图表模块**（右中）
   - **职责**：将数字增长转化为直观的曲线图
   - **设计亮点**：两条线对比显示，工具提示显示具体金额，Y轴自动优化显示

4. **数据明细模块**（右下）
   - **职责**：提供逐年的详细数据供深度分析
   - **设计亮点**：表格可滚动，悬停高亮，数据对齐清晰

**输入 → 处理 → 输出 的逻辑链路：**
```
用户调整参数 → Alpine.js 监听变化 → 触发 calculate() 函数
    ↓
calculate() 进行复利计算 → 生成每年的数据数组
    ↓
同时更新：结果摘要 + 图表数据 + 表格数据
    ↓
页面实时刷新所有显示区域
```

**最值得学习的设计**：
- **响应式数据绑定**：使用 Alpine.js 的 `x-model` 和 `$watch`，实现“数据变化 → 自动重新计算 → 自动更新所有显示区域”的无缝联动
- **计算与展示分离**：`calculate()` 函数只负责生成数据，`updateChart()` 和模板负责展示，结构清晰

## 【四】Prompt / AI 逻辑是如何被设计的？

> 注意：这个页面**没有使用 AI 或 Prompt**，它是一个纯计算工具。但理解这一点很重要——不是所有工具都需要 AI。

**如果这是一个 AI 应用，可能会如何设计？**
- **Prompt 角色**：将用户输入转化为对金融模型的查询
- **解决什么问题**：可能是“生成投资建议”而非“计算数字”
- **关键变量**：风险承受能力、投资目标、市场条件等
- **只改 Prompt 的效果**：会改变 AI 回复的风格和内容深度，但计算逻辑不变

**本页面的替代设计思路**：
如果加入 AI，可以添加一个“智能建议”模块，Prompt 可能是：
```
“用户有 {本金} 元初始资金，计划每月投资 {追加金额} 元，期望 {年限} 年后达到 {目标金额}。根据历史数据，给出实现该目标的收益率建议和投资策略。”
```

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 将“复利计算”改为其他需要逐步计算的场景，如：
  - **学习进度计算器**：初始水平、每日学习时间、进步速度、目标年限
  - **健身计划计算器**：初始体重、每周运动量、卡路里赤字、目标时间
  - **业务增长预测**：初始用户、月增长率、运营成本、盈利目标

**第二步：调整输入字段和计算逻辑**
- 修改 `interestApp()` 中的变量名：
  ```javascript
  // 原版
  principal: 10000,
  contribution: 1000,
  rate: 5,
  
  // 健身版
  initialWeight: 70,
  weeklyExercise: 5, // 小时
  calorieDeficit: 500, // 每日卡路里缺口
  ```
- 重写 `calculate()` 函数中的计算公式

**第三步：改变输出形式**
- 修改图表标签和颜色主题
- 调整表格的列名和数据格式
- 改变大数字的展示方式和单位

**最安全的下手点**：先只改 **CSS 颜色和文字**，确保页面能运行，再逐步修改计算逻辑。

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明：**

1. **不是精确的财务规划工具**
   - 假设收益率恒定不变 → 实际投资有波动
   - 未考虑税收、手续费、管理费 → 实际收益会减少
   - 如果要做真实财务规划，应使用专业软件或咨询理财顾问

2. **不能预测市场或推荐具体产品**
   - 只是一个数学计算器，没有市场分析能力
   - 如果想知道“现在该买什么基金”，需要：
     - 使用投资平台的分析工具
     - 阅读财经资讯
     - 咨询持牌投资顾问

3. **不适合短期或复杂现金流计算**
   - 只能处理“定期等额投入”这一种模式
   - 如果需要计算“前3年每月1000，后2年每月2000”这类不规则投入：
     - 使用Excel的FV函数
     - 使用专业的现金流计算器

**记住**：这个工具最好的用途是**理解复利概念**和**建立长期投资意识**，而不是做出具体的投资决策。它的价值在于“让人看到可能性”，而不是“给出精确答案”。
