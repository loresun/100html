## 🇨🇳 国内平台

### 1. DeepSeek（已集成 ⭐⭐⭐）
```
官网：https://platform.deepseek.com/
控制台：https://platform.deepseek.com/api-console/deepseek-chat
```
**获取步骤**：
1. 注册/登录账号
2. 点击右上角「API Keys」
3. 点击「Create New API Key」
4. 复制并保存 Key（只显示一次）

**定价**：$0.14-2.2 / 百万 tokens（极具性价比）

---

### 2. 火山引擎（字节跳动）⭐⭐
```
官网：https://www.volcengine.com/
控制台：https://console.volcengine.com/
```
**获取步骤**：
1. 访问火山引擎官网，注册账号
2. 完成企业/个人实名认证
3. 进入「控制台」→「访问凭证」
4. 创建 Access Key 和 Secret Key
5. 在「模型推理」中开通豆包模型服务

**主流模型**：
- 豆包 Pro / Turbo
- 扣子（Coze）
- 语音合成

---

### 3. 阿里云（通义千问）⭐⭐
```
官网：https://www.aliyun.com/
控制台：https://dash.console.aliyun.com/
```
**获取步骤**：
1. 登录阿里云账号
2. 搜索「模型服务灵积」并开通
3. 进入「API-KEY 管理」页面
4. 点击「创建新的 API Key」
5. 复制保存

**定价**：通义千问 Plus 12元/百万 tokens

---

### 4. 百度智能云（文心一言）⭐⭐
```
官网：https://cloud.baidu.com/
控制台：https://console.bce.baidu.com/
```
**获取步骤**：
1. 登录百度智能云
2. 开通「千帆大模型平台」
3. 进入「应用接入」创建应用
4. 获取 API Key 和 Secret Key

**主流模型**：

## ⚠️ 注意事项

1. **API Key 安全**
   - 不要将 Key 提交到 GitHub
   - 使用环境变量或本地配置文件
   - 定期轮换 Key

2. **费用控制**
   - 设置使用限额（大部分平台支持）
   - 关注账单和用量
   - 优先使用免费 tier 测试

3. **访问问题**
   - 部分国外平台需要科学上网
   - 国内平台通常更稳定
   - 考虑使用代理或聚合平台
