# LLM 交互原理实验室

> **复杂度等级**: ⭐⭐⭐⭐⭐ 专家 | **适用人群**: AI 开发者、产品经理、技术爱好者

## 功能介绍

LLM 交互原理实验室是一个交互式学习平台，通过 12 个精心设计的实验，帮助你深入理解大语言模型的工作原理和最佳实践。

### 核心能力

- 🔬 **12 个交互式实验** - 从基础到高级，渐进式学习
- 🌊 **流式输出体验** - 理解 SSE 技术和实时响应
- 🎛️ **参数可视化调节** - 直观感受 temperature、top_p 等参数影响
- 🧠 **思维链演示** - 体验 R1 深度推理与 CoT 技术

## 实验列表

### 实验 1：流式输出 vs 非流式输出

学习 HTTP 请求中的流式传输机制，对比两种输出方式的用户体验差异。

### 实验 2：温度控制 (Temperature)

通过滑块调节 temperature 参数，观察输出从严谨到创意的变化。

### 实验 3：系统提示词组装

理解 system/user/assistant 三种角色的作用，学习多轮对话的消息结构。

### 实验 4：JSON 结构化输出

学习如何让 AI 按指定格式输出 JSON，以及 json_schema 参数的使用。

### 实验 5：记忆与上下文

理解 AI 的"记忆"本质——完整的会话历史如何影响后续响应。

### 实验 6：RAG 知识注入

演示如何通过 Prompt 注入外部知识，让 AI 能够回答超出训练数据的问题。

### 实验 7：思维链 (Chain of Thought)

体验 R1 推理模型的深度思考过程，理解 reasoning_content 的产生。

### 实验 8：Token 计数与成本估算

学习 Token 的概念，理解 API 调用的成本计算方式。

### 实验 9：Top-P 采样

对比 temperature 和 top_p 两种采样策略的不同效果。

### 实验 10：停止序列 (Stop Sequences)

学习如何控制 AI 在特定位置停止输出。

### 实验 11：多 Agent 协作

演示多个 AI 角色如何协作完成复杂任务。

### 实验 12：函数调用 (Function Calling)

了解 AI 如何与外部工具集成，实现动态能力扩展。

## 常见问题

### Q: 需要编程基础吗？

A: 不需要。实验设计了可视化界面，纯小白也能理解。但如果有编程基础，收获会更大。

### Q: R1 推理模型为什么这么慢？

A: R1 是深度推理模型，会进行多轮自我思考，因此响应时间较长，但质量通常更高。

### Q: 这些实验代码可以直接用吗？

A: 可以。每个实验都提供了标准的 JavaScript 代码示例，可直接在您的项目中使用。
