# 习惯设计师 - AI创意生成器 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你下定决心要养成一个新习惯，比如每天早起、坚持阅读或定期锻炼。但没过几天，就因为计划不切实际、动力不足或忘记执行而放弃了。这个网页就是你的“个人习惯养成教练”。

**使用场景**：
- 当你想要开始一个新习惯，但不知道如何科学地设计执行计划时
- 当你之前尝试养成习惯但屡次失败，需要个性化解决方案时
- 当你希望基于自己的作息、性格和可用时间，获得量身定制的习惯方案时
- 当你需要一个结构化的追踪工具来监督自己21天的习惯养成过程时

**适合情况**：
- 个人习惯养成（健康、学习、工作、生活）
- 需要结构化指导和科学方法支持
- 愿意花几分钟描述自己的情况，获得个性化建议

**不适合情况**：
- 需要即时、简单的习惯提醒（用手机闹钟或待办事项App更合适）
- 需要团队协作或社交监督的习惯养成
- 涉及专业医疗或心理治疗的行为改变

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **核心目标**：你想要养成的习惯（如“每天阅读30分钟”）
2. **个人背景**：你的生活方式、日常作息、空闲时间
3. **过往经历**：之前尝试过但失败的习惯及遇到的困难
4. **偏好选择**：动机类型、可用时间、个性特征、期望难度

**用户通常会做哪几步操作？**
1. 在“想要养成的习惯”框中输入具体目标
2. 简要描述自己的生活方式和过往挑战（可选但建议填写）
3. 从下拉菜单中选择主要动机和每天可用时间
4. 点击符合自己个性的按钮（如“晨型人”、“独立型”）
5. 选择期望的挑战难度（简单/适中/高强度）
6. 点击“设计专属习惯系统”按钮
7. 等待AI生成方案（约10-30秒）
8. 查看生成的详细计划，并使用下方的21天追踪器

**输出结果长什么样？**
- 一个美观的卡片，包含：
  - 习惯分析与个性化调整建议
  - 分阶段（21天+）的实施计划
  - 具体的触发器设计（环境/时间提示）
  - 奖励系统和追踪方法
  - 科学原理说明
- 一个21天的可视化追踪器（点击日期标记完成）
- 操作按钮：开始追踪、复制、分享、下载

**容易忽略的使用细节**：
1. **个性特征可以多选**：你不是只能选一个，可以同时选择“晨型人”和“结构化”
2. **Ctrl+Enter快捷键**：在填写表单时，按Ctrl+Enter（Mac上是Cmd+Enter）可以直接提交
3. **模型选择在顶部**：右上角可以快速切换不同的AI模型，不同模型可能给出不同风格的方案
4. **设置中的API密钥**：如果使用自己的API密钥，需要在设置面板中填写（留空则使用默认）
5. **追踪器的进度计算**：点击日期方块标记完成，系统会自动计算完成百分比

## 【三】核心结构拆解（学习重点）

这个页面由**四个核心模块**组成，每个模块职责清晰：

### 模块1：用户信息收集表单
- **职责**：获取生成个性化方案所需的所有输入
- **设计亮点**：
  - 分左右两栏，逻辑分组（左侧：目标与现状；右侧：偏好与特征）
  - 使用按钮式选择代替复杂的表单，降低输入门槛
  - 渐变背景和玻璃态效果提升视觉吸引力

### 模块2：AI处理引擎
- **职责**：将用户输入转化为AI能理解的指令，调用API获取结果
- **关键函数**：`createHabitPrompt()` 和 `callAI()`
- **逻辑链路**：
  用户输入 → 组装成结构化Prompt → 添加系统指令 → 调用DeepSeek API → 返回纯文本结果

### 模块3：结果展示卡片
- **职责**：美观地呈现AI生成的内容，并提供实用工具
- **设计亮点**：
  - 使用卡片式设计，信息层次清晰
  - 顶部操作栏提供“追踪、复制、分享、下载”四大功能
  - 内容区域使用`whitespace-pre-wrap`保留AI返回的格式
  - 底部显示生成时间和模型信息，增加透明度

### 模块4：交互式习惯追踪器
- **职责**：让用户能够执行并追踪生成的计划
- **设计亮点**：
  - 21天网格可视化，点击即可标记完成
  - 自动计算和显示进度百分比
  - 完成全部21天时有庆祝提示

**最值得学习的设计**：
**Prompt的模块化构造**（在`createHabitPrompt`函数中）。它没有简单拼接用户输入，而是按照“习惯教练”的思维框架，将零散信息组织成专业咨询的结构。这种“将用户输入翻译成专业领域语言”的思路，是AI应用设计的核心。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是“翻译官”和“框架师”。它将用户零散的个人信息，翻译成习惯养成教练能理解的“专业案例描述”，并为AI的思考提供了清晰的回答框架。

**它解决的是“理解问题”还是“生成问题”？**
两者都有，但更偏向**生成问题**。它不仅要让AI理解用户情况，更重要的是**引导AI按照特定结构生成内容**。系统指令中已经定义了AI的角色（行为心理学专家），Prompt则进一步规定了回答必须包含的6个部分。

**Prompt中的关键变量**：
1. **用户输入变量**：`${habitGoal}`、`${lifestyle}`、`${motivation}`等
2. **结构指令**：用“## 1. 习惯分析与定制”这样的标题强制分块
3. **质量要求**：“请确保方案具体可操作，符合用户的个人情况和约束条件”

**如果只改Prompt，不改代码，会发生什么变化？**
- 改**系统指令**：改变AI的“人设”，如改成“健身教练”或“时间管理专家”
- 改**结构标题**：改变生成方案的组成部分，如增加“常见问题解答”或“应急方案”
- 改**质量要求**：如要求“用更口语化的语言”或“每个部分不超过200字”
- 改**变量组合**：如将“个性特征”更详细地描述给AI，会得到更精准的方案

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径**：

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改文字和主题
- 例如：把“习惯养成”改成“旅行规划”
  - “想要养成的习惯” → “想要规划的旅行”
  - “生活方式” → “旅行偏好”
  - “个性特征” → “旅行风格”（如“冒险型”、“舒适型”）
- 此时只需修改HTML中的文字和标签，JavaScript逻辑完全不用动

**第二步：调整输入字段和Prompt**
- 修改表单字段：
  - 增加/删除一些选择项
  - 例如增加“预算范围”、“旅行人数”字段
- 修改`createHabitPrompt`函数：
  - 将习惯设计的框架改成旅行规划的框架
  - 如“## 1. 目的地分析与推荐”、“## 2. 每日行程安排”
- 此时需要同时修改HTML和JavaScript，但保持函数结构不变

**第三步：改变输出形式或展示方式**
- 修改结果展示：
  - 如果生成的是行程，可以用时间轴而不是纯文本
  - 增加地图嵌入或图片展示区域
- 修改追踪器：
  - 21天习惯追踪 → 旅行倒计时或行李准备清单
- 这一步需要较强的CSS和JavaScript能力

**从哪里下手最安全？**
从**只修改文字和视觉样式**开始。不改任何JavaScript，只是把页面变成“学习计划生成器”、“健身方案生成器”等。这样你能先理解整个数据流动，再逐步深入逻辑修改。

## 【六】3–5个可直接尝试的改造方向

### 1. 增加“习惯类型”预定义模板
- **具体操作**：在表单顶部增加按钮，如“健康习惯”、“学习习惯”、“工作效率”
- **效果**：点击后自动填充部分字段（如动机、推荐时间），降低用户输入负担
- **代码位置**：在`generateHabitPlan()`前添加模板选择逻辑

### 2. 实现多模型对比功能
- **具体操作**：修改生成按钮，一次调用2-3个不同模型（或不同Prompt）
- **效果**：并排展示DeepSeek、豆包等不同AI的生成方案，用户可对比选择
- **代码位置**：修改`callAI()`函数支持并发请求，修改`displayResults()`支持多卡片

### 3. 添加“方案微调”交互
- **具体操作**：在结果卡片中添加“太简单了”、“时间不够”等反馈按钮
- **效果**：点击后基于原方案和反馈，调用AI进行微调，生成修正版
- **代码位置**：在结果卡片按钮旁添加反馈按钮，新建`refinePlan()`函数

### 4. 引入社交分享和公开案例库
- **具体操作**：将匿名方案保存到云端，首页增加“查看他人成功方案”区域
- **效果**：用户可浏览其他人的习惯方案获取灵感，形成社区效应
- **技术选择**：可用Supabase或Firebase作为简单后端

### 5. 增加“科学原理”可视化
- **具体操作**：在结果中识别关键词（如“习惯回路”、“多巴胺”），添加简单图表或动画解释
- **效果**：不仅告诉用户怎么做，还用可视化解释为什么这样做有效
- **实现方式**：用Chart.js或纯CSS动画，在特定关键词旁添加可展开的图示

## 【七】这个网页不适合做什么？（边界提醒）

### 明确的局限性：
1. **不是专业医疗或心理治疗工具**
   - 如果习惯涉及戒除成瘾（吸烟、酗酒）或严重心理问题，请寻求专业帮助
   - AI生成的方案不能替代医生或心理咨询师的诊断和治疗

2. **无法处理实时动态调整**
   - 方案是一次性生成的静态计划
   - 无法根据你每天的实际执行情况动态调整（如你连续三天失败，它不会自动重新规划）

3. **缺乏长期数据追踪和分析**
   - 21天追踪器只在当前浏览器会话中有效
   - 没有历史记录、趋势分析或深度洞察功能

4. **不适合团队或家庭习惯养成**
   - 设计完全针对个人
   - 如果需要家庭共同养成习惯或团队挑战，需要协作功能

### 如果用户想做X，应该换什么工具：
- **想做“实时习惯追踪与提醒”**：用Habitica、Streaks等专业习惯追踪App
- **想做“基于大量数据的习惯分析”**：用Exist.io或年度复盘模板+Excel
- **想做“与朋友互相监督”**：用Focusmate或专门的 accountability group
- **想做“复杂行为改变治疗”**：咨询心理医生或行为治疗师
