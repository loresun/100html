# 学习休息计时工具 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你正在学习或工作，需要管理自己的时间，但又不想安装多个App。这个网页就像一个**个人效率工具箱**，把常用的时间管理、记录和计算工具都放在一个页面里。

**适合的场景：**
- 学生需要番茄钟来管理学习节奏
- 自由职业者需要计时器来追踪工作时间
- 日常需要快速记账、记笔记或列清单
- 需要简单计算或单位换算时

**不适合的情况：**
- 需要复杂数据分析或专业记账功能
- 需要团队协作或数据共享
- 需要离线使用（数据可能丢失）
- 需要精确到秒的长时间计时（页面刷新会重置）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 根据你选择的工具类型，输入框会变化：
  - 计时器：输入分钟数
  - 番茄钟：输入“专注分钟”和“休息分钟”
  - 清单：输入待办事项
  - 记账：输入金额、分类、备注

**基本操作步骤：**
1. 页面加载后，你会看到一个工具界面（默认可能是计时器）
2. 在输入框中填写或选择需要的数值
3. 点击对应的操作按钮（开始、添加、计算等）
4. 查看下方显示的结果或状态

**输出结果长什么样？**
- 计时器：显示剩余时间的数字时钟
- 清单：显示带复选框的项目列表
- 计算结果：在输入框下方以卡片形式显示

**容易忽略的细节：**
- 页面右上角的⚙️按钮可以配置AI API（如果需要AI功能）
- 有些工具（如笔记）会自动保存，有些需要手动点击按钮
- 计时器在页面刷新后会重置，数据不会永久保存
- 清单和记账工具的数据只在当前浏览器会话中有效

## 【三】核心结构拆解（学习重点）

这个页面采用了**“一个框架，多种工具”**的设计思路：

**关键模块：**
1. **导航栏** - 返回按钮和设置入口
2. **工具容器** - 显示当前选中的工具
3. **工具切换逻辑** - 通过`tool.type`控制显示哪个工具界面
4. **数据管理** - 每个工具都有自己的数据模型

**职责分工：**
- `tool.type`是“指挥官”，决定显示哪个工具界面
- 每个工具区块（`x-show="tool.type === 'xxx'"`）是“执行者”，负责自己的UI和逻辑
- Alpine.js的`x-data`是“大脑”，管理所有状态和数据

**输入→处理→输出链路：**
```
用户输入 → 更新tool对象中的数据 → 触发对应函数 → 更新tool.result → 界面自动刷新显示
```

**最值得学习的设计：**
**条件渲染模式** - 用同一个HTML结构，通过`tool.type`切换显示不同的工具界面。这比写10个独立页面要高效得多，维护也更容易。

## 【四】Prompt / AI 逻辑是如何被设计的？

> 注：当前代码中AI功能未在界面直接体现，但通过设置面板可以看到预留了API配置。这里分析其设计思路。

**Prompt在这个页面中的角色：**
如果启用AI功能，Prompt可能用于：
- 根据输入生成建议（如学习计划）
- 分析记账数据给出消费建议
- 为笔记工具提供内容优化

**解决的是“理解问题”还是“生成问题”？**
主要是**生成问题** - 根据用户输入的结构化数据，生成有意义的建议或分析。

**关键变量（如果实现AI功能）：**
- 用户输入的具体数值（学习时间、消费金额等）
- 工具类型上下文（让AI知道在什么场景下）
- 历史数据模式（如果有存储）

**如果只改Prompt，不改代码：**
- 可以改变AI回应的风格和深度
- 可以调整建议的详细程度
- 可以切换AI的“角色”（如从“学习教练”变成“财务顾问”）

## 【五】如何模仿它，做出你自己的版本？

**安全上手路径：**

**第一步：保持结构不变，替换使用场景**
- 先不要动HTML结构
- 修改`tool`对象的初始数据，比如把“番茄钟”改成“烹饪计时器”
- 只改文字标签和描述，确保功能还能运行

**第二步：调整输入字段或逻辑**
- 选择一个工具类型（如`timer`），增加或减少输入字段
- 修改对应的计算函数（在`standalone.js`中）
- 测试修改后的功能是否正常

**第三步：改变输出形式或展示方式**
- 修改结果展示的HTML结构
- 添加CSS样式让显示更符合你的需求
- 可以增加图表、进度条等可视化元素

**从哪里下手最安全？**
从**计数器（counter）** 工具开始修改最简单，因为它逻辑最单纯，只有“+1”和“清零”两个操作。

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不是专业时间管理工具**
   - 缺少详细的数据报告和分析
   - 无法生成周/月视图的时间分布
   - 替代方案：使用Toggl、RescueTime等专业工具

2. **不是协作工具**
   - 所有数据仅限个人使用
   - 无法分享或同步给他人
   - 替代方案：使用Notion、腾讯文档等协作平台

3. **不是离线优先应用**
   - 关闭页面后，未保存的数据会丢失
   - 无法在无网络环境下可靠使用
   - 替代方案：开发PWA（渐进式Web应用）或使用Electron打包

4. **不是专业财务工具**
   - 记账功能极其基础，无分类统计、预算管理
   - 无法导入银行流水或生成报表
   - 替代方案：使用挖财、MoneyWiz等专业记账软件

**记住：** 这个网页的核心价值是**快速、轻量、集中**，适合解决即时的小需求，而不是替代专业软件。
