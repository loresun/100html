# 心情声景合成 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

想象一下，你此刻心情复杂，难以言表，但脑海中却浮现出某种声音或旋律。这个网页就像一个**情绪翻译器**，它让你用一个简单的滑块（1-10分）来表达心情，然后：
1.  **即时生成**一段与心情匹配的简短音效（一个和弦）。
2.  **调用AI**，为你此刻的心情生成一句富有意境的“声音氛围”描述。

**适合的场景：**
- **情绪探索与表达**：当你感到某种情绪，想用一种非语言（声音+文字）的方式去感受和定义它时。
- **创意启发**：作为写作、音乐创作或冥想前的热身，快速获得一个“声音锚点”。
- **轻量级互动演示**：向他人展示如何将用户输入、声音合成和AI生成结合在一个简单的界面中。

**不适合的场景：**
- **专业音乐制作**：它生成的只是一个单音和弦，并非复杂的音乐片段或完整作品。
- **精准的心理评估**：它不提供专业的情绪分析或建议，只是一个艺术化的表达工具。
- **长时间的声音播放**：声音是短暂的，不适合作为背景白噪音或持续的环境音。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：点击页面右上角的齿轮图标（⚙️），在弹出的窗口中输入你的 **DeepSeek API Key** 并选择模型，然后点击“保存配置”。（这是让AI描述功能生效的关键一步）。
2.  **核心操作**：
    *   **调整心情**：拖动主区域左侧卡片中的滑块，从“1”（低落）到“10”（高涨），选择一个代表你当前心情的数值。
    *   **生成体验**：点击滑块下方的 **“播放声景”** 按钮。你会立刻听到一个与心情数值对应的和弦音，同时右侧卡片中会显示一句由AI生成的、描述该心情对应声景的优美句子。
    *   **停止声音**：如果声音还在播放（虽然很短），可以点击 **“停止”** 按钮来中断。

**输出结果什么样？**
- **听觉上**：一个清脆的电子合成器音色发出的和弦，心情值越高，音调也越高。
- **视觉上**：右侧“AI描述”区域会显示如“心情指数：7/10。如林间晨曦，鸟鸣清脆，溪水潺潺，带着一丝暖意与生机。”这样的句子。

**容易忽略的细节：**
- **API Key是必须的**：如果不配置API Key，滑块和播放按钮虽然能用，但右侧永远只会显示“等待生成”。
- **声音需要用户交互触发**：大多数浏览器要求必须由用户点击（如“播放声景”按钮）后，才能首次播放网页声音。这是浏览器的安全策略。
- **心情数值影响音高**：仔细听，心情值1-2、3-4、5-6……对应的音高是不同的，它被映射到了一组预设的音符上。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

1.  **用户交互与输入模块（左侧卡片）**
    *   **职责**：捕获用户的核心输入——心情指数。
    *   **组成**：一个滑块（`<input type="range">`）和两个控制按钮（播放/停止）。
    *   **逻辑**：用户拖动滑块 → `mood` 数值变量更新 → 这个数值被后续的播放和AI调用函数读取。

2.  **AI生成与展示模块（右侧卡片）**
    *   **职责**：根据心情指数，请求AI生成描述性文字并展示。
    *   **组成**：一个标题和一个用于显示多行文本的容器（`<div>`）。
    *   **逻辑**：播放按钮被点击 → 函数将 `mood` 值填入预设的Prompt模板 → 调用AI API → 将返回的文字结果赋值给 `description` 变量 → 界面自动更新显示。

3.  **音频合成与控制模块（背后逻辑）**
    *   **职责**：根据心情指数，生成并播放对应的声音。
    *   **组成**：隐藏在JavaScript中的Tone.js合成器对象。
    *   **逻辑**：播放按钮被点击 → 根据 `mood` 值计算出一个对应的音符 → 通过Tone.js触发合成器播放该音符。

**输入 → 处理 → 输出链路：**
**用户拖动滑块（输入）** → `mood=7`
↓
**用户点击“播放声景”** → 1) 用 `mood=7` 计算播放“B4”音符；2) 用 `mood=7` 构造Prompt：“心情指数：7/10...” → 分别发送给 **Tone.js（声音合成）** 和 **DeepSeek API（文本生成）**
↓
**同步输出**：耳朵听到“B4”音高 + 眼睛看到“如林间晨曦...”的描述。

**最值得学习的设计：**
**“单一输入，双重输出”的同步触发机制。** 整个应用以一个滑块输入为核心，通过一个“播放”动作，同时触发声音和文本两种不同形式的输出。这种设计让体验非常紧凑和直观，是构建轻量级、趣味性AI交互原型的经典模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

- **Prompt扮演的角色**：它是连接“冰冷数字”（心情指数）和“生动描述”的**翻译官**。它告诉AI：“请把1-10的这个数字，转化成一个声音场景的文学化描述。”
- **解决的问题类型**：它主要解决**生成问题**。AI的任务不是分析心情是否健康，而是根据数字的提示，创作出一句符合语境的描述。
- **Prompt中的关键变量**：只有一个：`${mood.value}`，即用户选择的心情数值。整个Prompt是固定的模板，只有这个数字会变化。
- **如果只改Prompt，不改代码**：
    *   改变AI的“身份”（`system`角色）：例如从“声音设计师”改为“诗人”，生成的描述风格会从专业转向文艺。
    *   改变用户的指令（`user`内容）：例如将“用一句话描述适合的声景氛围”改为“用三个关键词概括”，那么输出就会从句子变成几个词。
    *   这直接证明了Prompt是控制AI输出内容和风格的“方向盘”。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于自己的变体：

1.  **第一步：替换核心主题与输入（最安全）**
    *   **保持**：双卡片布局、一个滑块、一个触发按钮、一个显示区域的结构。
    *   **改变**：将“心情指数”改为其他可量化的概念，例如“**能量值**”、“**专注度**”、“**故事紧张感（1-10）**”。
    *   **此时**：你的应用已经变成了一个“能量声景合成器”或“故事氛围生成器”。

2.  **第二步：调整Prompt和输出映射**
    *   **改变Prompt**：将AI的`system`角色和`user`指令改为与新主题匹配。例如，对于“故事紧张感”，Prompt可以是：“你是一个悬疑小说家，根据紧张感指数（${value}/10），用一句话描述对应的环境氛围。”
    *   **改变声音映射**：在代码的`playSound`函数里，修改`notes`数组，让不同的输入值对应更符合主题的音符或音效（比如紧张感低用长音，高用短促刺耳音）。

3.  **第三步：改变输出展示形式**
    *   **视觉**：你可以让AI生成的不是一句话，而是一小段故事开头，或者一张用文字描述的“场景速写”。相应地，调整右侧显示区域的样式。
    *   **听觉**：不再只是播放一个音符，可以尝试使用Tone.js播放一段简单的循环节奏，或者加载不同的短音效文件。将滑块数值映射到音量、播放速度等参数上。

**从哪里下手最安全？** 从**第一步**开始。先不要动任何JavaScript代码，只修改HTML和Vue模板中的文字（如标题、标签）和CSS颜色。这样你能立刻看到一个外观不同但功能完好的新应用，建立信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加多元输入**：除了心情滑块，可以增加第二个滑块控制“氛围类型”（如“自然/都市/科幻”）。将这个新变量也加入到Prompt中（例如“都市环境，心情指数：5”），并让声音映射也受其影响（切换不同的音色或音阶）。
2.  **更换或扩展输出媒介**：
    *   **视觉化**：使用`<canvas>`或Three.js，根据心情数值实时生成一个简单的动态图形（如粒子波动幅度、颜色变化）。
    *   **多句描述**：修改API调用参数，让AI一次性生成3-5句不同侧面的描述，以列表形式轮播展示。
3.  **优化交互体验**：
    *   **实时预览**：将“播放声景”改为“生成声景”，并让声音和AI描述在用户**松开滑块**时自动触发，实现更流畅的实时反馈。
    *   **历史记录**：添加一个数组记录每次生成的心情值和描述，在页面下方展示出来，形成用户的“心情日记”。
4.  **模块化与配置化**：
    *   **可配置Prompt**：在设置弹窗中增加一个文本框，让高级用户可以自定义发送给AI的Prompt模板，使工具更灵活。
    *   **切换声音引擎**：在设置中提供几种不同的基础音色（如钢琴、合成器、环境音）供用户选择。
5.  **接入更多模型或本地模型**：将API设置部分扩展，除了DeepSeek，还可以选择接入OpenAI GPT、Claude或智谱GLM。对于进阶学习者，可以尝试集成Ollama，调用本地运行的大模型。

## 【七】这个网页不适合做什么？（边界提醒）

- **不适合作为专业的音乐创作或声音治疗工具**：其声音生成部分极其简单，音色单一，缺乏对音量、时长、和声进行等专业参数的控制，无法产出可用于作品或疗愈的复杂音频。
- **不适合进行严肃的情绪分析与心理辅导**：它仅对1-10的数字进行简单的文学化联想，没有科学的情绪模型、分析逻辑或安全护栏。如果用户需要情绪支持，应寻求专业的心理咨询服务或使用经过临床验证的数字疗法应用。
- **不适合处理复杂、多条件的创意生成**：它的输入维度单一（一个数字），Prompt固定。如果你需要基于一段详细文案、一张图片或多个复杂参数来生成内容，这个简单的结构无法胜任，需要设计更复杂的输入表单和Prompt工程逻辑。
