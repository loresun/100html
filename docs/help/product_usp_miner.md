# 产品卖点提炼器 (USP Miner) 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你正在为一款新产品（比如一款智能水杯）设计营销方案。你大概知道它有什么功能，也知道市面上有类似的产品。但你很难说清楚：**“我的产品到底有什么独一无二的价值？为什么用户要选我而不是别人？”**

这个网页就是你的“营销军师”。它通过分析你的产品、竞争对手和目标用户，帮你快速提炼出产品的**核心卖点（USP）**、一句**抓人的广告语**，以及**对比竞品的优势**。

*   **适合场景**：
    *   初创团队为新产品构思市场定位。
    *   营销人员为现有产品寻找新的宣传角度。
    *   个人创业者或自由职业者，需要快速梳理自己的服务优势。
*   **不适合场景**：
    *   需要基于大量市场数据（如销量、用户画像）进行深度分析。
    *   需要生成完整的营销方案或长文案。
    *   产品本身没有明确的功能或目标用户。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：打开页面后，点击右上角的“设置”按钮，输入你的 DeepSeek API Key 并保存。这是让 AI 为你工作的“钥匙”。
2.  **填写信息**：在左侧面板的三个输入框中，分别填写：
    *   **我的产品**：产品名称、核心功能、适用场景等。
    *   **竞品信息**：主要竞争对手是谁？他们主打什么？你觉得他们有什么缺点？
    *   **目标用户**：你的产品主要卖给谁？（例如：“25-35岁的都市白领”）
3.  **开始分析**：填写“我的产品”后，点击蓝色的 **“挖掘差异化卖点”** 按钮。
4.  **查看结果**：等待几秒钟，右侧区域会生成一份结构清晰的卖点报告，包括：
    *   **一句醒目的核心 Slogan**（蓝色大横幅）。
    *   **竞品弱点与我方优势的对比**（左右分栏）。
    *   **三个具体的核心卖点卡片**，每个都包含标题、解释和销售话术示例。

**容易忽略的细节**：
*   **“竞品信息”不是必填**，但填写后分析会更精准，能突出“差异化”。
*   **“目标用户”越具体越好**，AI 会根据用户特征来调整卖点话术。
*   分析结果每次都会不同，可以微调输入内容，多次点击按钮，获得不同角度的灵感。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个模块，像一条流水线：

1.  **信息输入模块（左侧面板）**
    *   **职责**：收集用户提供的原始、零散的产品信息。
    *   **设计亮点**：将复杂的市场分析简化为三个最核心的输入项（产品、竞品、用户），降低了使用门槛。

2.  **AI 处理引擎（隐藏的逻辑层）**
    *   **职责**：将用户输入打包成一个结构化的 **Prompt（指令）**，发送给 AI 模型（DeepSeek），并接收、解析返回的 JSON 数据。
    *   **逻辑链路**：`用户输入` → `拼接成 Prompt` → `调用 API` → `解析 JSON` → `生成结构化数据`。
    *   **最值得学习的设计**：**“指令即接口”**。开发者没有编写复杂的分析逻辑，而是设计了一个清晰的指令模板（Prompt），让 AI 扮演“营销策略师”的角色，并严格按照指定的 JSON 格式返回结果。这极大地简化了后端代码。

3.  **结果展示模块（右侧面板）**
    *   **职责**：将 AI 返回的结构化数据，以视觉化、易读的方式呈现出来。
    *   **设计亮点**：
        *   **信息分层**：从最抓眼球的 Slogan，到对比分析，再到具体卖点，层层递进。
        *   **卡片化设计**：每个卖点独立成卡，信息集中，便于阅读和后续使用。
        *   **视觉对比**：用红/绿色区分“竞品弱点”和“我方优势”，一目了然。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt 的角色**：它是整个应用**真正的“大脑”和“说明书”**。代码只负责搬运数据和展示，而思考和分析的工作全部由 Prompt 指导 AI 完成。
*   **解决的问题**：它主要解决 **“生成问题”** 。它基于用户提供的碎片信息，生成全新的、结构化的营销文案和分析结论。
*   **关键变量**：Prompt 中嵌入了三个关键变量：`${input.product}`, `${input.competitor}`, `${input.target}`。它们是 AI 进行分析的原始材料。
*   **只改 Prompt 的后果**：如果你只修改 Prompt 中的指令（例如，把“营销策略师”改成“资深销售”，或者要求返回5个卖点），那么**整个页面的输出内容和风格都会随之改变，而页面布局和代码逻辑完全不变**。这体现了 Prompt 驱动的应用其核心优势：快速迭代和调整功能。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你自己的 AI 小工具：

1.  **第一步：替换场景，保持骨架**
    *   **目标**：先做出一个能跑通的、属于你自己的版本。
    *   **操作**：把“产品卖点提炼”换成另一个场景，比如 **“旅行行程规划器”**、**“健身计划生成器”** 或 **“短视频脚本灵感”**。保持左侧输入框、中间按钮、右侧结果展示的三段式布局不变。只需修改标题、输入框的提示文字和按钮文字。

2.  **第二步：重新设计 Prompt**
    *   **目标**：让你的应用在新场景下产生正确的思考。
    *   **操作**：根据你的新场景，重写 `analyzeUSP` 函数中的 `prompt` 变量。明确告诉 AI 你要它扮演什么角色（例如：“你是一个资深旅行规划师”），以及你希望它返回什么样的结构化数据（可以先用中文描述，再转换成 JSON 格式）。

3.  **第三步：调整结果展示界面**
    *   **目标**：让输出结果完美匹配新场景。
    *   **操作**：根据你新设计的 Prompt 返回的 JSON 数据结构，修改右侧结果展示的 HTML 模板。比如，“旅行行程规划器”的展示模块可能变成“每日行程卡片”、“必去景点列表”、“美食推荐”等。

**从哪里下手最安全？** 从 **第一步** 开始。先不改代码逻辑，只改文字和概念，确保整个流程（输入-点击-输出）能走通，这会给你巨大的信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“语气”或“风格”选择**：
    *   **操作**：在输入区增加一个下拉菜单，让用户选择“文案风格”，如“专业严谨”、“活泼有趣”、“激情澎湃”。将这个选项作为变量加入到 Prompt 中（例如：“请用${tone}的风格来撰写…”）。
    *   **效果**：让输出结果更贴合不同的宣传渠道（如官网、社交媒体）。

2.  **支持多模型切换与对比**：
    *   **操作**：在设置弹窗中，除了 API Key，增加一个“模型选择”下拉框（如：gpt-4o, claude-3.5-sonnet）。点击分析后，可以同时或依次调用不同模型，并将结果并列展示，让用户对比哪个模型的创意更好。
    *   **效果**：提升工具的灵活性和专业性。

3.  **将结果拆分为多个视图标签页**：
    *   **操作**：在结果区域顶部增加标签页，如“核心卖点”、“详细文案”、“常见问答（Q&A）”。每次分析后，让 AI 不仅生成卖点，再额外生成一段产品描述文案和3个用户可能问的问题及答案，分别放在不同标签页下。
    *   **效果**：从一个分析工具扩展为一个轻量的内容生成工作站。

4.  **增加“历史记录”与“灵感库”功能**：
    *   **操作**：使用 `localStorage` 将每次的输入和结果保存下来。在页面侧边或底部增加一个区域，展示历史记录。用户可以查看、复用或对比之前的分析结果。
    *   **效果**：让工具不再是“一次性”的，而成为积累创意的个人知识库。

5.  **优化交互体验**：
    *   **操作**：为结果卡片增加“复制话术”的小按钮，点击后自动将对应话术复制到剪贴板。或者在分析时，让按钮显示进度动画，并允许用户中途取消。
    *   **效果**：提升工具的实用性和操作流畅度。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精确的市场调研**：它的分析基于你提供的、可能主观的竞品信息和产品描述，而非真实的用户行为数据或市场报告。结论是“创意灵感”和“分析角度”，不能替代专业的市场调研。
*   **不适合生成可直接投放的最终素材**：生成的 Slogan 和话术是很好的起点和灵感，但通常需要人类进行二次润色、调整，以确保符合品牌调性、法律法规和具体投放渠道的要求。
*   **如果用户需要基于财务报表或用户画像数据做决策**：应该使用专业的商业智能（BI）工具或数据分析平台，而不是这个基于文本推理的创意工具。
*   **如果用户需要与现有客户管理系统（CRM）联动**：这个工具是独立且静态的。需要深度集成的工作，应考虑开发更复杂的系统或使用自动化平台（如 Zapier/Make）来连接。
