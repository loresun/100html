# 微信公众号封面图库 - AI封面生成 帮助文档

---

## 【一】这个网页解决了什么问题？

**使用场景：**
想象你是一名公众号运营者，每周都要发布多篇文章。每次写完后，最头疼的就是找一张合适的封面图——要么图片版权有问题，要么风格不搭，要么尺寸不对。这个网页就是你的“封面设计师”，你只需要告诉它文章标题和主题，它就能在几秒钟内为你生成3张符合微信公众号标准尺寸（2.35:1）的封面图。

**适合什么情况？**
- 需要快速为公众号文章配图
- 没有设计基础，但希望封面看起来专业
- 想一次性获得多个风格选择
- 需要符合微信官方封面尺寸

**不适合什么情况？**
- 需要高度定制化的品牌设计（如企业VI严格规范）
- 需要真人模特或特定产品照片
- 对图片细节有极其精确的要求（如特定logo位置）
- 需要生成非2.35:1比例的其他尺寸图片

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **文章标题**：输入你的文章标题（必填）
2. **文章主题**：从下拉菜单中选择最接近的主题（如科技、职场、生活等）
3. **封面风格**：选择你喜欢的视觉风格（如简约现代、科技感等）

**用户通常会做哪几步操作？**
1. 在左侧“文章信息”区域填写标题、选择主题和风格
2. （可选）点击“快捷生成”中的预设模板，快速应用推荐的主题和风格组合
3. 点击底部绿色的“生成3个封面备选”按钮
4. 等待10-30秒，右侧会显示3张生成的封面图
5. 选择喜欢的封面，点击“下载”保存到电脑

**输出结果长什么样？**
- 3张900×383像素的图片（符合微信公众号封面标准）
- 每张图片都基于你的标题、主题和风格生成
- 3张图在配色方案上会有差异（如暖色调、冷色调、中性色调）
- 图片下方显示尺寸信息和操作按钮

**容易忽略的使用细节：**
1. **首次使用需要配置API**：第一次点击“生成”时，会自动弹出设置窗口，需要输入火山引擎的API Key
2. **快捷生成是预设组合**：点击“年终总结”等按钮，会自动设置主题和风格，但**不会自动生成图片**，仍需点击生成按钮
3. **下载全部是分批下载**：点击“下载全部”时，3张图片会间隔0.5秒依次下载，避免浏览器阻塞
4. **重新生成会替换全部**：点击某张图的“重新生成”按钮，会重新生成全部3张图，不是只替换那一张

## 【三】核心结构拆解（学习重点）

**页面由哪几个关键模块组成？**

1. **配置管理模块**（顶部导航栏右侧）
   - 职责：显示当前使用的AI模型，提供设置入口
   - 特点：设置保存在浏览器本地，下次打开无需重复配置

2. **输入控制模块**（左侧面板）
   - 子模块1：文章信息输入（标题输入框+两个下拉菜单）
   - 子模块2：快捷生成预设（三个预设按钮）
   - 职责：收集用户需求，提供快速选择路径

3. **生成控制模块**（左侧底部按钮）
   - 职责：触发生成过程，显示生成状态

4. **输出展示模块**（右侧主区域）
   - 子模块1：空状态提示（未生成时显示）
   - 子模块2：加载状态（生成中显示骨架屏）
   - 子模块3：结果展示（3张图片+操作按钮）
   - 职责：展示生成结果，提供下载和重生成功能

5. **设置弹窗模块**（覆盖层）
   - 职责：配置API参数和模型选项

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入（标题+主题+风格）
    ↓
拼接成Prompt（包含所有参数）
    ↓
调用火山引擎图像生成API（连续调用3次，每次微调配色描述）
    ↓
API返回图片URL
    ↓
前端展示3张图片 + 提供下载功能
```

**最值得学习的设计：**
**“快捷生成预设”与“完整输入”的双路径设计**。这个设计非常巧妙：
- 对于新手：可以直接点击“年终总结”等预设，快速获得经过验证的主题+风格组合
- 对于有明确需求者：可以手动选择每个参数，获得更精准的控制
- 预设只设置参数，不自动生成，保持了用户最终的控制权

这种设计平衡了“易用性”和“灵活性”，是很多工具类应用可以借鉴的模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接“用户需求”和“AI能力”的翻译官。它把用户选择的几个简单参数（标题、主题、风格）转换成了AI能理解的详细作画指令。

**它解决的是“理解问题”还是“生成问题”？**
主要是“理解问题”。用户说“我要一个科技感的封面”，AI不知道具体是什么样子。Prompt通过添加“Clean, professional, eye-catching, suitable for WeChat article cover”等描述，告诉AI：要干净、专业、吸睛、适合微信文章。

**哪些信息是Prompt中的关键变量？**
1. **标题**：直接引用用户输入，确保图片内容相关
2. **主题**：作为关键词告诉AI图片的大方向
3. **风格**：定义视觉语言（如简约现代）
4. **配色方案**：通过`color scheme 1/2/3`让同一主题生成3种不同配色的变体
5. **尺寸要求**：明确指定2.35:1比例和具体像素

**如果只改Prompt，不改代码，会发生什么变化？**
假设你把Prompt中的“suitable for WeChat article cover”改成“suitable for LinkedIn post cover”：
- 生成的图片风格会偏向LinkedIn平台常见的商务、专业风格
- 可能减少活泼元素，增加正式感
- 但页面功能完全不变，还是生成3张、还是可以下载

这就是Prompt的魔力：**不改一行代码，就能改变AI的“创作方向”**。

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景（最安全）**
- 目标：做一个“小红书封面生成器”
- 操作：
  1. 修改页面标题和描述
  2. 把“文章主题”下拉菜单改成小红书常见分类（美妆、穿搭、探店等）
  3. 把“封面风格”改成小红书风格（ins风、日系、韩系等）
  4. 修改Prompt中的“WeChat”为“Xiaohongshu”，尺寸改为3:4（小红书封面比例）
  5. 快捷生成预设改为“探店打卡”、“OOTD穿搭”、“好物分享”等

**第二步：调整输入字段或Prompt**
- 目标：增加更多控制维度
- 操作：
  1. 增加“色调偏好”选择（暖色/冷色/黑白）
  2. 增加“包含元素”多选（人物/文字/图标/背景）
  3. 在Prompt中对应添加这些新参数
  4. 例如：`Tone preference: ${tonePreference}, Include elements: ${elements.join(', ')}`

**第三步：改变输出形式或展示方式**
- 目标：提供更多样化的输出
- 操作：
  1. 让用户选择生成数量（3张/6张/9张）
  2. 增加“横版/竖版”切换
  3. 在结果区域增加“点赞/收藏”交互
  4. 添加“生成历史”功能，保存之前生成的图片

**从哪里下手最安全？**
从**修改下拉菜单的选项**开始。这是零风险操作：
- 不会破坏现有功能
- 立即看到界面变化
- 可以测试新分类是否合理
- 例如：先把“科技互联网”改成“数码科技”，感受一下修改的流程

## 【六】3–5个可直接尝试的改造方向

**1. 增加“负面提示词”输入框**
- **具体操作**：在文章信息区域增加一个“不希望出现的元素”输入框
- **Prompt修改**：在API调用时添加`negative_prompt`参数
- **效果**：用户可以排除不想要的元素（如“不要人物”、“不要文字”），提高生成精准度

**2. 替换为本地运行的AI模型**
- **具体操作**：
  - 使用Stable Diffusion WebUI的API
  - 修改`callImageAPI`函数中的URL为本地地址（如`http://localhost:7860`）
  - 调整请求参数格式匹配SD WebUI
- **效果**：完全免费使用，无需API Key，但需要本地有显卡

**3. 拆分成“快速模式”和“高级模式”**
- **具体操作**：
  - 快速模式：保持现有简单输入
  - 高级模式：增加更多参数（主色调、构图方式、艺术风格参考）
  - 通过一个切换按钮控制显示哪个模式
- **效果**：兼顾小白用户和专业用户的需求

**4. 增加“封面模板库”功能**
- **具体操作**：
  - 在结果区域增加“保存为模板”按钮
  - 新建一个“我的模板”页面，展示保存的模板
  - 点击模板可以快速应用相同的参数组合
- **效果**：积累自己的设计资产，提高重复工作效率

**5. 优化交互：实时预览Prompt**
- **具体操作**：
  - 在输入区域下方增加一个“预览Prompt”折叠区域
  - 用户修改任何输入时，实时显示将要发送给AI的完整Prompt
  - 允许用户直接编辑这个Prompt
- **效果**：帮助用户理解AI“看到”的是什么，学习Prompt编写技巧

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明：**

1. **不适合生成品牌严格规范的图片**
   - 如果公司有严格的VI规范（特定logo位置、标准色值、固定字体），这个工具无法精确控制
   - **替代方案**：使用Figma或Canva的模板，手动调整

2. **不适合需要特定人物或产品的图片**
   - 无法生成指定真人（如CEO）或特定产品（如最新手机型号）的图片
   - AI生成的人物是虚构的，产品可能不准确
   - **替代方案**：使用专业摄影或3D渲染

3. **不适合法律/医疗等敏感领域**
   - 生成的图片可能包含不准确或误导性信息
   - AI不理解专业领域的合规要求
   - **替代方案**：使用经过审核的图库或聘请专业设计师

4. **不适合需要多次迭代修改的设计**
   - 每次生成都是全新的，无法在上一张基础上“微调”
   - “重新生成”是完全重来，不是迭代优化
   - **替代方案**：使用Midjourney等支持“Vary”功能的工具

5. **不适合没有网络连接的环境**
   - 完全依赖云端API，无法离线使用
   - **替代方案**：使用本地部署的Stable Diffusion

**核心建议：**
把这个工具看作你的“创意助手”而不是“设计总监”。它擅长快速提供灵感、生成备选方案、解决“从0到1”的问题。但对于“从1到100”的精细打磨，还需要结合专业设计工具和人的判断力。
