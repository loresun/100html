# 知识付费课程策划工具 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你想要创建一门在线课程（比如在知识星球、小鹅通、得到等平台），但不知道如何系统化地设计课程结构、提炼卖点、撰写招生文案时，这个工具能帮你快速生成一份完整的课程策划草案。

**适合情况**：
- 个人知识IP（专家、讲师、博主）想将自己的经验转化为付费课程
- 教育机构需要为新课程快速产出大纲和宣传素材
- 内容创作者想验证某个课程主题的市场潜力
- 需要灵感启发，打破“不知道从何开始”的困境

**不适合情况**：
- 需要深度市场调研和竞品分析（这只是一个创意生成工具）
- 已经拥有成熟的课程体系，只需要微调（AI可能给出过于通用的建议）
- 对课程内容的专业性和准确性要求极高（如医学、法律等严肃领域，必须由专家审核）
- 需要直接生成视频脚本、PPT或教学材料（本工具只产出“策划案”）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **课程主题**：你想教的课程核心是什么？（必填）
2.  **目标人群 & 痛点**：这门课是给谁上的？他们有什么具体困难？
3.  **课程亮点/特色**：你的课程有什么与众不同之处？（可选）

**用户通常会做哪几步操作？**
1.  **配置**：首次使用，点击右上角“设置”，填入你的 DeepSeek API Key。
2.  **填写**：在左侧面板依次填写三个输入框。
3.  **生成**：点击“生成课程大纲”按钮。
4.  **使用结果**：在右侧查看生成的完整方案，可以复制文案或导出整个方案。

**输出结果长什么样？**
生成的结果会以三个清晰的模块展示在右侧：
1.  **课程概览**：包含一个吸引人的主标题、副标题和几个标签（如#实战、#小白友好）。
2.  **课程大纲**：以章节（模块）为单位，列出每个章节下的具体课时，并说明每节课能给学员带来什么好处。
3.  **宣发文案**：一段可以直接用于朋友圈或课程详情页的推广文案，通常包含痛点描述、解决方案、课程亮点和行动号召。

**有哪些容易忽略的使用细节？**
- **API Key 是必须的**：不填写就无法生成，工具本身不提供AI能力。
- **模型切换**：右上角可以在“V3”（通用对话）和“R1”（推理增强）模型间切换，R1可能对结构化思考更有帮助。
- **填写越具体，结果越精准**：在“目标人群”框里详细描述学员画像和痛点，比只写“小白”效果好得多。
- **导出功能**：生成的整个方案可以点击右下角“导出方案”保存为JSON文件，方便后续编辑或导入其他工具。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“配置-输入-处理-输出”** 单页应用结构。

**关键模块与职责：**
1.  **配置管理模块（右上角/弹窗）**：
    - **职责**：管理用户身份（API Key）和AI模型选择。
    - **逻辑**：将配置信息保存到浏览器的本地存储（localStorage），下次打开页面自动读取。

2.  **输入面板模块（页面左侧）**：
    - **职责**：收集用户关于课程的核心想法。
    - **逻辑**：三个输入框分别对应策划案的“是什么”（主题）、“给谁”（受众）和“凭什么”（亮点）。

3.  **AI处理引擎（隐藏，在代码中）**：
    - **职责**：将用户的输入组合成一个精心设计的“提示词”（Prompt），调用AI API，并解析返回的JSON数据。
    - **逻辑**：`输入数据` + `固定Prompt模板` → `API请求` → `解析JSON` → `转换为前端可用的数据对象`。

4.  **结果展示模块（页面右侧）**：
    - **职责**：将AI返回的结构化数据，以美观、易读的方式分块呈现。
    - **逻辑**：分别渲染“概览区”、“大纲区”和“文案区”，每个区域对应数据对象的不同属性。

**输入 → 处理 → 输出 的逻辑链路：**
```
用户填写表单 -> 点击生成 -> 前端组合Prompt -> 调用DeepSeek API
-> AI返回JSON -> 前端解析并更新`result`变量 -> Vue自动重新渲染右侧展示区
```

**最值得学习的设计：**
**“结构化输出”与“展示层解耦”**。这个工具最巧妙的地方在于，它通过Prompt严格约束AI返回一个预设好字段的JSON对象。前端代码只需要相信这个结构存在（如 `result.modules[0].lessons`），然后据此渲染UI。这意味着，**如果你想改变AI生成的内容范畴，只需要修改Prompt；如果你想改变页面的外观，只需要修改HTML/CSS，两者互不干扰**。这是一种非常清晰、可维护的前端+AI集成模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt 是连接“人类模糊想法”和“机器结构化输出”的**翻译官和指挥官**。它不是一个简单的问题，而是一份详细的“工作说明书”。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**，但也包含了**理解问题**的引导。Prompt通过明确的指令（“请设计一份详细的课程策划案”）、提供的上下文（用户输入的主题、人群、亮点）和严格的输出格式要求（JSON结构），引导AI理解任务边界并生成符合期望的内容。

**哪些信息是 Prompt 中的关键变量？**
Prompt 中有三个由用户输入决定的**关键变量**：
1.  `“${input.topic}”`：课程主题，是生成内容的核心锚点。
2.  `“${input.audience}”`：目标人群，决定了课程内容和文案的针对性。
3.  `“${input.highlights}”`：特色亮点，影响课程的独特卖点和文案的亮点部分。

**如果只改 Prompt，不改代码，会发生什么变化？**
- **改变内容范畴**：例如，在JSON结构中增加一个 `"priceStrategy"`（定价策略）字段，AI就会在返回的数据中生成这块新内容，但页面不会显示它，因为前端没有为这个新字段编写渲染代码。
- **改变风格或深度**：例如，将“设计一份详细的课程策划案”改为“用轻松幽默的口吻设计一份课程策划案”，AI生成的所有标题和文案风格都会随之改变。
- **改变结构**：例如，要求 `modules` 数组里每个对象增加一个 `"duration"`（课时时长）字段，AI会照办，但同样需要前端配合渲染。

**核心启示**：Prompt 定义了AI输出的“数据契约”，前端代码则负责可视化这份“契约”。修改Prompt是改变AI“思考什么”和“输出什么”的最直接方式。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全路径”，逐步替换，最终得到一个属于你的AI工具：

**第一步：替换核心场景与输入（最安全，不碰逻辑）**
- **目标**：做一个“活动策划生成器”。
- **操作**：
    1.  将页面标题、按钮文字中的“课程”全部改为“活动”。
    2.  将左侧输入框的标签和提示语修改：
        - “课程主题” -> “活动主题”（如：公司年会）
        - “目标人群 & 痛点” -> “参与人员 & 需求”（如：全体员工；希望放松、增强凝聚力）
        - “课程亮点/特色” -> “活动预算/特殊要求”（如：人均500元，需要有颁奖环节）
    3.  此时点击生成，AI会基于旧Prompt生成课程内容，虽然不匹配，但页面能正常运行。

**第二步：重写Prompt，匹配新场景（关键一步）**
- **目标**：让AI为你新的“活动策划”场景生成正确内容。
- **操作**：找到代码中的 `prompt` 变量字符串，将其重写。例如：
    ```javascript
    const prompt = `请为“${input.topic}”活动设计一份策划案。
    参与人员与需求：${input.audience}
    预算与要求：${input.highlights}
    请返回 JSON 格式：
    {
      "title": "活动主题名称",
      "subtitle": "活动口号或目标",
      "tags": ["标签1", "标签2"],
      "schedule": [
        { "time": "时间段", "activity": "活动内容", "purpose": "该环节目的" }
      ],
      "promotionCopy": "一段用于内部通知或宣传的活动预告文案"
    }`;
    ```
- **注意**：此时AI返回的数据结构变了，但前端还在按旧的`result.modules`渲染，页面会出错或空白。别急，这是预期现象。

**第三步：调整前端展示层，匹配新数据结构**
- **目标**：让页面正确显示活动策划案。
- **操作**：修改右侧结果展示的HTML模板。将渲染“课程大纲”的部分，改为渲染“活动流程”（`result.schedule`）。例如：
    ```html
    <!-- 将原来的modules循环改为schedule循环 -->
    <div v-for="(item, idx) in result.schedule" :key="idx">
        <h4>{{ item.time }}</h4>
        <p>{{ item.activity }} - {{ item.purpose }}</p>
    </div>
    ```
- **至此，你已经完成了一个新工具的核心闭环！**

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让策划更精准**：
    - **操作**：在输入面板增加一个下拉选择框 `课程难度`，选项为：`["零基础", "入门", "进阶", "高阶"]`。
    - **修改点**：将这个新变量（如 `input.difficulty`）加入到Prompt中，并提示AI根据难度调整大纲深度和文案语气。
    - **效果**：AI会为“零基础”课程生成更基础、鼓励性强的文案，为“高阶”课程生成更专业、干货密集的内容。

2.  **切换或扩展AI模型后端**：
    - **操作**：在设置弹窗中，将模型选择从DeepSeek V3/R1，增加一个选项，如 `gpt-4o-mini`。
    - **修改点**：修改 `apiConfig` 对象和下拉选项，并在 `generatePlan` 函数中，根据选择的值，动态改变API请求的URL和请求头（例如，从 `https://api.deepseek.com` 改为 `https://api.openai.com`）。
    - **效果**：用户可以对比不同AI模型生成的策划案风格和质量差异。

3.  **将单次生成改为多轮对话/迭代优化**：
    - **操作**：在生成的结果区域，每个模块（如大纲、文案）旁边增加一个“优化此部分”的小按钮。
    - **修改点**：点击按钮时，不是重新生成整个策划，而是将当前这部分内容（如 `result.copywriting`）和一条新指令（如“请让这段文案更口语化一些”）发送给AI，并只更新这部分内容。
    - **效果**：用户体验从“一次性的灵感获取”升级为“可交互的创作助手”。

4.  **优化交互与视觉反馈**：
    - **操作**：为“生成”按钮添加分阶段状态。例如，点击后显示“思考中...”、“正在撰写大纲...”、“正在打磨文案...”，虽然实际是单次API调用，但分步提示能提升等待体验。
    - **修改点**：利用Vue的响应式特性，在 `isGenerating` 为 `true` 时，动态改变按钮文字。甚至可以模拟一个简单的进度条动画。
    - **效果**：让用户感知到AI正在为其“工作”，减少等待时的焦虑感。

5.  **拆分为多页面应用，管理多个策划案**：
    - **操作**：新增一个“方案库”页面（`library.html`）。
    - **修改点**：在当前生成页面，将“导出方案”改为“保存至方案库”，将 `result` 数据保存到 `localStorage` 或 `IndexedDB` 中，并跳转到方案库页面列表展示。方案库页面可以查看、删除、重新编辑历史方案。
    - **效果**：工具从一个“一次性生成器”升级为一个“轻量级的课程策划CRM”。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合作为最终交付物**：它生成的是**草案和灵感**，不是可以直接上架的完美课程。所有内容都必须由真人（你）进行审核、调整、补充和本地化，注入你真正的专业知识和个人风格。
2.  **不适合处理高度创意或情感化内容**：对于需要极强原创性、艺术感或情感共鸣的课程（如诗歌创作、心灵疗愈），AI可能只能提供框架性建议，无法替代人类导师的深度洞察和感染力。
3.  **不适合进行复杂决策**：比如“这个课程定价199元还是299元更好？”，AI可以基于网络信息给出建议，但无法替代真实的市场测试、成本核算和用户调研。
4.  **如果用户想做这些，应该换什么工具？**
    - **想做精细的竞品分析**：应使用专业的数据分析工具（如蝉妈妈、新榜）或手动进行深度调研。
    - **想直接制作课程视频/音频**：应使用视频剪辑软件（如剪映、Premiere）、录音设备或专业的内容制作团队。
    - **想搭建完整的课程售卖平台**：应使用小鹅通、知识星球、Teachable等专业的SaaS平台。
    - **想管理学员、安排直播、布置作业**：应使用上述平台或专门的在线教育系统（如ClassIn、Zoom）。

**记住**：这个网页是一个出色的“创意加速器”和“结构化思考的启动器”，但它不是全能的。将它与你的专业判断、其他专业工具结合使用，才能发挥最大价值。
