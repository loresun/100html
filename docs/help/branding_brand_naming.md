# 品牌起名大师 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你需要为一个新项目、新产品或新公司起名字时，可能会感到无从下手。名字既要好听易记，又要体现品牌特色，还要避免与现有品牌冲突。这个工具就像一个随时在线的品牌顾问，你只需要告诉它“做什么行业”和“有什么特色”，它就能在几秒钟内为你生成10个完整的命名方案，包括名字、口号和起名逻辑。

**适合情况：**
- 创业者需要为新项目起名
- 营销人员需要为新产品线命名
- 设计师为客户提供命名建议
- 学生需要为课程项目起个响亮的名字

**不适合情况：**
- 需要法律层面的商标查重（这只是创意生成）
- 需要多语言命名（目前主要针对中文场景）
- 需要基于大量市场数据的分析

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **所属行业**：你的业务领域，比如“精品咖啡”、“宠物美容”
2. **品牌理念/核心卖点**：你的独特之处，比如“强调自然环保”、“针对Z世代年轻人”

**操作步骤：**
1. 在左侧输入框中填写你的行业（必填）
2. 在下方文本框中描述你的品牌特色（选填，但建议填写）
3. 点击“生成10个创意命名”按钮
4. 等待几秒钟，右侧会显示结果

**输出结果长什么样？**
每个命名方案都是一个卡片，包含：
- **品牌名**：大字显示的核心名称
- **品牌口号**：简短有力的宣传语
- **起名逻辑简述**：解释这个名字为什么适合你

**容易忽略的细节：**
1. **行业是必填的**：如果不填行业直接点击生成，按钮会禁用
2. **需要先配置API Key**：首次使用需要在首页配置DeepSeek的API密钥
3. **结果可以反复生成**：调整输入内容后，可以再次点击生成新的方案
4. **错误信息在顶部**：如果生成失败，错误详情会显示在结果区域上方

## 【三】核心结构拆解（学习重点）

**页面由三个关键模块组成：**

1. **输入模块（左侧）**
   - **职责**：收集用户需求，触发生成动作
   - **包含**：行业输入框、理念文本框、生成按钮
   - **设计亮点**：简洁的卡片式设计，清晰的视觉层次

2. **输出模块（右侧）**
   - **职责**：展示AI生成的结果，处理加载和错误状态
   - **包含**：结果卡片网格、加载动画、错误提示
   - **设计亮点**：卡片悬停效果、优雅的占位符设计

3. **状态管理模块（背后）**
   - **职责**：管理用户输入、API调用、结果存储
   - **包含**：Vue响应式数据、API配置、本地存储
   - **设计亮点**：统一的错误处理、流畅的状态切换

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入 → Vue响应式数据 → 构建Prompt → 调用API → 解析JSON → 渲染卡片
```

**最值得学习的设计：**
**状态管理的完整性**。这个页面完美处理了所有用户可能遇到的状态：
- 初始空状态（引导用户输入）
- 加载状态（骨架屏动画）
- 成功状态（美观的卡片展示）
- 错误状态（详细的错误日志）

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接用户需求和AI能力的“翻译官”。它把简单的行业和理念描述，转换成一个专业的品牌命名任务指令。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。AI已经理解“品牌命名”这个任务，Prompt的作用是告诉AI：“请用这个行业和这个理念，生成10个具体的名字”。

**Prompt中的关键变量：**
1. `行业：${industry.value}` - 决定了名字的领域相关性
2. `理念：${concept.value}` - 决定了名字的风格和调性
3. **输出格式要求** - 强制AI返回标准JSON，方便前端直接使用

**如果只改Prompt，不改代码，会发生什么变化？**
- 改**角色描述**：从“品牌咨询顾问”改成“文学大师”，名字会更文艺
- 改**数量要求**：从“10个”改成“5个”，结果会更精简
- 改**格式要求**：去掉JSON格式，页面就无法正常解析结果
- 改**质量要求**：增加“要国际化”、“要谐音梗”等要求，结果风格会变化

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 把“品牌命名”改成“文章标题生成”
- 输入框改成：“文章主题”和“目标读者”
- 输出卡片改成：标题 + 摘要 + 适合平台

**第二步：调整输入字段或Prompt**
- 增加“风格选择”下拉菜单：正式、幽默、文艺
- 修改Prompt中的角色：“你是一个自媒体运营专家”
- 调整输出格式要求：返回标题数组即可

**第三步：改变输出形式或展示方式**
- 把卡片网格改成列表形式
- 增加“复制标题”按钮
- 添加“收藏喜欢”的功能

**从哪里下手最安全？**
从**修改Prompt和文案**开始。这是零风险、见效快的改动。先确保AI能返回你想要的内容格式，再考虑界面调整。

## 【六】3–5个可直接尝试的改造方向

1. **增加筛选和排序功能**
   - 在结果上方添加“按字母排序”、“按字数筛选”按钮
   - 让用户可以标记“喜欢”的名字，并单独查看收藏夹
   - **技术实现**：在`results.value`数组上使用`.filter()`和`.sort()`

2. **支持多模型切换**
   - 在输入区域添加模型选择下拉框：DeepSeek、GPT-4、Claude等
   - 根据选择调用不同的API端点
   - **技术实现**：扩展`apiConfig.value`，增加`endpoint`和`model`字段

3. **添加命名解析和评分**
   - 对生成的每个名字进行“易读性”、“记忆度”、“相关性”评分
   - 点击名字可以展开详细分析：字数、音节、寓意等
   - **技术实现**：二次调用AI进行分析，或使用本地算法计算

4. **优化为多步骤向导**
   - 第一步：选择行业类别（预设选项+自定义）
   - 第二步：选择品牌调性（年轻化、高端、亲民等）
   - 第三步：输入关键词或理念
   - **技术实现**：使用Vue组件切换显示不同步骤

5. **增加社交分享功能**
   - 每个卡片添加“分享到Twitter”、“复制链接”按钮
   - 生成专属的结果页面URL，方便分享给团队成员
   - **技术实现**：使用URL参数存储输入，生成短链接

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不是商标法律顾问**：生成的名字可能已被注册，需要另行查重
2. **不是多语言专家**：主要针对中文命名，其他语言效果不确定
3. **不是市场调研工具**：不考虑竞品分析、市场接受度等实际因素
4. **不是设计系统**：只提供名字和口号，不包含Logo、VI等视觉设计

**如果你需要做以下事情，请换工具：**
- **商标注册查询** → 使用官方商标查询网站或专业律师
- **多语言品牌命名** → 寻找本地化的命名专家或工具
- **完整的品牌设计** → 使用Figma、Canva等设计工具，或雇佣设计师
- **基于数据的决策** → 使用市场调研工具分析名字的搜索量、社交声量

---

**最后提醒**：这个工具的最佳使用方式是**激发灵感**，而不是**直接决策**。把AI生成的10个名字作为起点，结合你的直觉和团队讨论，才能找到最适合的那个名字。
