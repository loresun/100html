# Excel 智能伴侣 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页解决的是**日常办公中，面对Excel时“知道要做什么，但不知道怎么写公式”或“有一堆杂乱文本，不知道怎么快速整理成表格”**的痛点。

**适合的使用场景：**
*   **公式生成模式：** 当你需要计算某个东西，但记不住复杂的Excel函数（如VLOOKUP、IF嵌套、日期处理、文本提取），或者不确定哪种公式组合最合适时。例如：“怎么把A列里的手机号中间四位变成星号？”或“如何根据销售额自动计算提成等级？”
*   **数据清洗模式：** 当你从聊天记录、邮件、文档里复制出一堆非结构化的文本，需要快速整理成有表头、行列分明的表格时。例如：“张三 销售部 13800138000\n李四 技术部 13912345678”变成规范的表格。

**不适合的情况：**
*   **处理大型或敏感数据集：** 所有数据都会发送到AI服务商，不适合包含个人隐私、商业机密或数据量过大的情况。
*   **需要离线使用：** 必须联网并配置有效的API密钥。
*   **执行复杂的数据分析或图表制作：** 它只负责生成公式或整理数据，不执行计算或生成可视化图表。

## 【二】使用方式（给第一次接触的人）

1.  **准备工作：** 首次使用，点击右上角的齿轮图标（⚙️），在弹出的设置窗口中输入你的DeepSeek API密钥并保存。
2.  **选择模式：** 页面左上角有两个大按钮：“公式生成”和“数据清洗”。根据你的需求点击一个。
3.  **输入你的问题或数据：**
    *   **公式生成：** 在左侧大文本框中，用大白话描述你的计算需求。例如：“如果A列成绩大于等于60，就在B列显示‘及格’，否则显示‘不及格’”。
    *   **数据清洗：** 在左侧大文本框中，直接粘贴你那堆乱七八糟的文本。例如：“张三 13800138000 销售部\n李四 (技术部) 13912345678”。
4.  **获取结果：** 点击下方绿色的“生成公式”或“开始清洗数据”按钮。稍等片刻，AI就会在右侧区域给出结果。
5.  **使用结果：**
    *   **公式：** 你会看到推荐的Excel公式、解释，以及一个“复制”按钮，点击后可以直接粘贴到Excel单元格中。
    *   **清洗后的表格：** 你会看到一个预览表格，点击右上角的“复制为Excel格式”按钮，然后打开Excel，直接按 `Ctrl+V` 粘贴，数据就会自动填入单元格。

**容易忽略的细节：**
*   **模型选择：** 在导航栏可以切换“DeepSeek V3（快）”和“DeepSeek R1（强逻辑）”。处理复杂逻辑问题时，选择R1可能效果更好。
*   **思考过程：** 在公式生成模式下，如果AI模型支持，你可能会看到一小段“思考过程”，这有助于你理解AI是如何推导出公式的。
*   **数据格式：** 清洗数据时，粘贴的文本越有规律（比如都用空格、横线、括号分隔），AI识别和整理的准确率越高。

## 【三】核心结构拆解（学习重点）

这个页面是一个清晰的“**输入-处理-输出**”单页应用，由以下几个关键模块组成：

1.  **模式选择与导航模块（顶部）**
    *   **职责：** 让用户在“公式生成”和“数据清洗”两个核心功能间切换，并提供设置入口。
    *   **设计亮点：** 使用卡片式按钮和视觉高亮（颜色、边框）清晰指示当前模式，避免用户混淆。

2.  **用户输入模块（左侧）**
    *   **职责：** 收集用户最原始的需求或数据。包含一个模式动态变化的提示标签、一个大文本输入框和一个触发按钮。
    *   **设计亮点：** 输入框的占位符文本（`placeholder`）会根据所选模式动态变化，给出非常具体、可模仿的示例，极大降低了用户的学习成本。

3.  **AI处理与通信模块（逻辑核心，不可见）**
    *   **职责：** 这是页面的大脑。它根据当前模式，组装不同的“指令”（System Prompt）和用户输入，调用DeepSeek的API，并处理返回的JSON数据。
    *   **逻辑链路：** `用户点击按钮` → `检查API密钥` → `根据模式组装特定Prompt` → `发送请求到AI API` → `解析AI返回的JSON` → `将数据分发给结果展示模块`。

4.  **结果展示模块（右侧）**
    *   **职责：** 以最适合的方式呈现AI的处理结果。
    *   **公式模式：** 采用“代码块 + 解释说明”的两段式布局，突出核心公式，并用通俗语言解释。
    *   **清洗模式：** 直接渲染成一个HTML表格，模拟Excel的视觉样式，并提供“一键复制为Excel格式”的功能。
    *   **设计亮点：** **结果展示与输入模式强绑定**，且提供了直接可用的操作（复制公式、复制表格）。空状态和加载中的设计也提升了体验。

**最值得学习的设计：**
**“基于模式的动态系统”**。整个页面的提示文本、按钮标签、结果展示UI、乃至背后发送给AI的指令，都围绕 `mode` 这个核心变量进行切换。这种设计让单一页面承载了多个相关功能，结构清晰且扩展性强。如果你想增加一个“数据透视表建议”模式，只需要新增一个模式选项，并为其配套输入、输出和Prompt即可。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，**Prompt（系统指令）是连接用户意图与AI能力的“翻译官”和“约束器”**。

1.  **扮演的角色：** 它告诉AI“你现在要扮演什么角色”（Excel专家/数据清洗专家），以及“你必须以什么格式回答”（严格的JSON）。它解决的是**“生成问题”**——即如何让AI生成我们想要的、结构化的输出。
2.  **关键变量：** Prompt中最关键的部分是：
    *   **角色定义：** `你是一个Excel专家` / `你是一个数据清洗专家`。
    *   **任务描述：** 清晰说明需要AI做什么（分析、提取、整理）。
    *   **输出格式约束：** **`只返回 JSON`**，并明确给出JSON的具体结构（如 `{“code”: “…”, “explanation”: “…”}`）。这是确保前端能稳定解析结果的关键。
3.  **只改Prompt的影响：** 如果只修改Prompt而不改代码，你可以彻底改变这个工具的功能，但前提是输出格式保持不变。例如：
    *   把“Excel专家”改成“SQL专家”，把“生成Excel公式”改成“生成SQL查询语句”，它就能变成一个SQL助手。
    *   在数据清洗的Prompt里增加“识别并分类情感为正/负/中性”，它就能在整理表格的同时多输出一列情感分析。
    *   但如果新的功能需要不同的输出格式（比如需要返回图表配置），那么前端代码就无法正确解析，必须同步修改。

## 【五】如何模仿它，做出你自己的版本？

如果你想创建一个类似风格的AI工具，请遵循以下安全路径：

**第一步：替换核心场景，保持骨架不变**
*   **目标：** 先让一个最小版本跑起来。
*   **操作：** 不要改动任何Vue.js和Tailwind CSS的代码结构。只修改以下内容：
    1.  把标题“Excel智能伴侣”改成你的工具名（如“PPT文案助手”）。
    2.  把两种模式的名字改成你的新功能（如“生成大纲”和“优化文案”）。
    3.  修改输入框的占位符示例，换成你新场景的例子。
    4.  修改结果展示区域的标题和空状态提示语。

**第二步：调整AI指令（Prompt）和输入**
*   **目标：** 让AI为你新的场景工作。
*   **操作：**
    1.  在代码中找到 `systemPrompt` 的赋值部分（有两个 `if (isCleaning) {...}` 分支）。
    2.  根据你的新功能，重写这里的角色描述、任务说明和**最重要的JSON输出格式**。例如，对于“PPT文案助手”，输出格式可能是 `{“title”: “…”, “bullet_points”: [“点1”, “点2”]}`。
    3.  确保你的新Prompt要求AI `只返回 JSON`。

**第三步：改变结果的展示方式**
*   **目标：** 让前端漂亮地展示AI为你生成的新内容。
*   **操作：**
    1.  在 `data` 部分（`ref` 变量），将 `formulaResult` 和 `cleaningResult` 改名为符合你场景的变量名。
    2.  在模板（HTML部分）中，找到 `<!-- 模式 A: 公式生成结果 -->` 和 `<!-- 模式 B: 数据清洗结果 -->` 这两个区块。
    3.  根据你新设计的JSON格式，重新设计这里的HTML。比如，如果输出是标题和要点，就用 `<h3>` 和 `<ul><li>` 列表来展示。
    4.  更新“复制”按钮的功能，让它复制你新格式的内容。

完成这三步，你就拥有了一个属于你自己的、功能完整的AI工具雏形。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“示例库”或“历史记录”功能：**
    *   **操作：** 在输入框下方或侧边增加一个区域。用户可以点击“常用示例”快速填充输入框。或者，将每次的查询和结果（不含敏感数据）保存在 `localStorage` 中，方便回顾。
    *   **价值：** 极大提升工具的实用性和粘性。

2.  **支持更多AI模型/提供商（如OpenAI、智谱AI）：**
    *   **操作：** 在设置弹窗中，增加一个“服务商”下拉选择框（DeepSeek/OpenAI等）。根据选择，动态改变API请求的URL (`fetch` 的地址) 和密钥字段的名称。`systemPrompt` 可以通用或微调。
    *   **价值：** 让用户可以根据成本、速度、效果选择最适合的模型。

3.  **为公式生成增加“上下文”输入：**
    *   **操作：** 在公式生成模式下，增加一个可选的“数据样例”输入框。用户可以粘贴几行模拟数据（如“A1: 张三， B1: 85”），让AI在生成公式时更有依据。
    *   **价值：** 提高公式的准确性和针对性，尤其对于复杂的数据引用。

4.  **优化数据清洗的交互流程：**
    *   **操作：** 清洗结果展示后，允许用户**在线编辑**表头名称或某个单元格的值。编辑后，“复制”按钮同步更新要复制的内容。
    *   **价值：** 实现“清洗-微调-导出”的闭环，无需在Excel中二次修改。

5.  **拆分为专注的独立页面：**
    *   **操作：** 将当前的单页应用拆成两个独立的HTML文件：`excel-formula.html` 和 `data-clean.html`。每个页面只专注于一个功能，可以设计更深入的专属特性（如公式模式增加函数库查询）。
    *   **价值：** 结构更简单，便于分享和针对性地优化，也利于通过首页进行导航。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合处理真实、敏感的Excel文件：** 它无法上传和解析 `.xlsx` 文件。你只能通过文字描述需求。如果你需要分析文件本身的内容，应该使用微软Office内置的“Ideas”功能、Python的pandas库，或专门的文件处理AI工具。
2.  **不适合作为生产环境的自动化数据清洗管道：** 它的清洗依赖AI的每次识别，对于成千上万条记录，速度慢、成本高且可能不稳定。对于规律性强的批量清洗，应使用Excel的“分列”、“查找替换”功能，或编写Python脚本。
3.  **不适合生成复杂宏或插件代码：** 虽然可以生成简单VBA，但对于需要与Excel对象模型深度交互、带有用户窗体（UserForm）的复杂插件，它的能力有限。这类需求应寻求专业的VBA编程资料或开发者。
4.  **不能保证100%正确：** AI可能误解你的需求或生成有误的公式。**始终在Excel中测试生成的公式，尤其是用于重要数据之前。** 这个工具是强大的“助手”和“学习伙伴”，而非绝对可靠的“自动化引擎”。
