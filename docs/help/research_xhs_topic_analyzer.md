# 选题拆解分析大师 - 帮助文档

---

## 【一】这个网页解决了什么问题？

**使用场景**：
假设你是一名内容创作者、营销人员或自媒体运营者，你发现小红书上某些笔记特别火爆，点赞收藏量很高。你想知道它们为什么能火，但靠自己一篇篇分析太费时间。同时，你也想借鉴这些爆款的“套路”，快速为自己的产品或主题创作出风格相似、同样吸引人的新文案。

这个工具就是你的“爆款分析助手”。它帮你：
1.  **批量分析**：一次性丢进去多篇爆款文案，自动提炼出它们的共同“爆款公式”（比如用了什么热词、什么情绪、开头怎么吸引人）。
2.  **智能创作**：基于你分析出的“公式”，再结合你的新产品资料或想法，快速生成一篇符合爆款风格的新文案。

**适合什么情况？**
- 你想快速了解某个领域（如美妆、家居、职场）在小红书上的内容流行趋势。
- 你需要批量分析竞品或优秀案例的文案结构。
- 你希望获得创作灵感，快速产出符合平台调性的初稿。

**不适合什么情况？**
- 你需要对单篇文案进行极其精细的语法、修辞分析。
- 你需要生成完全原创、不借鉴任何现有风格的全新内容。
- 你需要分析视频、图片等非文本内容。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **待分析的小红书内容**：一个大的文本框，用于粘贴你收集到的多篇小红书爆款笔记全文。
2.  **新文案参考资料**：另一个文本框，用于输入你想推广的产品信息、卖点，或者你的新想法、新主题。

**用户通常会做哪几步操作？**
1.  **配置**：首次使用，点击右上角“设置”，填入你的 DeepSeek API Key 并保存。
2.  **分析**：将多篇小红书爆款文案粘贴到第一个文本框，点击蓝色的 **“开始拆解分析”** 按钮。
3.  **查看分析**：稍等片刻，页面右侧会自动切换到“拆解分析结果”标签页，以卡片形式展示分析出的关键词、情绪、钩子和痛点。
4.  **创作**：（可选）在第二个文本框输入你的产品资料或新想法，点击红色的 **“撰写新文案”** 按钮。
5.  **获取结果**：页面右侧切换到“生成的新文案”标签页，查看 AI 为你生成的完整小红书笔记。你可以复制或导出它。

**输出结果长什么样？**
- **分析结果**：像仪表盘一样，分为四个彩色卡片：
    - **搜索热词**：一堆蓝色的标签，如“早C晚A”、“通勤穿搭”。
    - **核心情绪**：一堆黄色的标签，如“焦虑”、“治愈”、“爽感”。
    - **爆款钩子**：红色背景的列表，展示分析出的吸引人的开头句式。
    - **用户痛点**：紫色背景的列表，展示分析出的用户常见问题。
- **生成文案**：一个整洁的文本区域，展示生成的小红书笔记，标题带Emoji，段落清晰，结尾有互动引导和话题标签。

**有哪些容易忽略的使用细节？**
1.  **API配置是必须的**：不配置 API Key，所有按钮都无法真正工作。
2.  **分析是生成的基础**：虽然“撰写新文案”按钮在没有分析结果时也能点（只要有参考资料），但结合分析结果生成的文案会更贴近爆款风格。
3.  **参考资料可选但重要**：第二个文本框不填，AI 会完全基于分析出的风格自由发挥，可能不贴合你的具体产品。
4.  **流式生成**：生成文案时，文字是一个字一个字“流”出来的，体验更好，需要等待它写完。
5.  **导出功能**：分析结果可以导出为 CSV 文件，生成文案可以导出为 TXT 文件或直接复制。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“输入-处理-输出”** 左右分栏布局，模块化程度很高。

**关键模块与职责：**

1.  **配置管理模块**（右上角设置）：
    - **职责**：管理 API 密钥和模型选择等外部依赖配置，并持久化保存到浏览器本地。
    - **设计亮点**：通过一个全局状态 (`apiConfig`) 控制整个应用的“就绪”状态，并在按钮上给予视觉提示（如“API Ready”）。

2.  **输入控制区**（左侧面板）：
    - **职责**：承载用户的所有输入操作。明确分为两个阶段：
        - **阶段一输入**：“待分析内容”文本框 + “开始拆解分析”按钮。
        - **阶段二输入**：“参考资料”文本框 + “撰写新文案”按钮。
    - **设计亮点**：通过按钮的禁用状态 (`:disabled`) 清晰地引导了操作流程（先分析，后生成体验更佳），并将两个阶段用视觉分割线隔开。

3.  **结果展示区**（右侧面板）：
    - **职责**：通过 Tab 页切换，分别展示“分析结果”和“生成文案”。
    - **分析结果子模块**：采用 **“指标卡片”** 设计。每个卡片（关键词、情绪、钩子、痛点）负责展示一类分析结论，使用不同颜色区分，信息呈现非常直观。
    - **生成结果子模块**：采用 **“文档预览”** 设计。专注于展示长文本，并提供了复制、导出等实用操作。

4.  **AI 逻辑处理层**（脚本中的 `analyzeContent` 和 `generateNewCopy` 函数）：
    - **职责**：这是**最核心的模块**。它不负责显示，只负责“组装问题”和“解析答案”。
    - **工作流程**：
        1.  **收集输入**：从左侧的 `input` 对象中获取用户粘贴的文本。
        2.  **组装 Prompt**：根据不同的任务（分析/生成），将用户输入与预定义的指令模板拼接，构成一个完整的、给 AI 的“问题”。
        3.  **调用 API**：将组装好的 Prompt 发送给 DeepSeek API。
        4.  **解析响应**：对于分析任务，将 AI 返回的 JSON 字符串解析成对象；对于生成任务，接收流式文本并实时展示。
        5.  **更新状态**：将解析后的结果赋值给 `analysisResult` 或 `generatedCopy`，触发页面重新渲染。

**输入 → 处理 → 输出 的逻辑链路：**
```
用户粘贴爆款文案 -> `input.sourceContents`
    ↓
点击“分析” -> `analyzeContent()` 函数运行
    ↓
函数内部组装“分析型Prompt” -> 调用DeepSeek API
    ↓
API返回JSON字符串 -> 解析为JS对象 -> 存入 `analysisResult`
    ↓
Vue检测到 `analysisResult` 变化 -> 自动重新渲染右侧“分析结果”Tab页 -> 用户看到四个指标卡片
```

**最值得学习的设计：**
**“任务分离与状态驱动”**。整个应用被清晰地拆分为两个主要任务（分析、生成），每个任务有独立的输入、按钮、处理函数和输出展示区域（通过Tab切换）。应用的状态（`analysisResult`, `generatedCopy`, `isAnalyzing` 等）是唯一的真相来源，UI 只是这些状态的反映。这种设计使得逻辑清晰，易于维护和扩展。例如，你想增加一个“分析历史”功能，只需要新增一个状态和展示它的模块即可。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 扮演的角色：**
在这个页面中，Prompt 是连接**用户原始输入**和**AI结构化输出**的 **“翻译官”和“指令官”**。它把用户随意粘贴的文字，转换成 AI 能精确理解并按要求格式回答的问题。

**它解决的是“理解问题”还是“生成问题”？**
两者都解决了，但侧重点不同：
- **在分析任务中**：Prompt 主要解决 **“理解与结构化”** 问题。它指示 AI 去“阅读并分析”，然后必须按照一个**严格的 JSON 格式**返回结果，这强制 AI 的输出是程序可解析的数据。
- **在生成任务中**：Prompt 主要解决 **“风格模仿与内容生成”** 问题。它指示 AI 扮演“小红书爆款文案专家”，并给出了具体的文案要求（标题带Emoji、段落短小等），引导 AI 生成特定风格和格式的文本。

**Prompt 中的关键变量：**
1.  **用户动态内容**：`${input.sourceContents}` 和 `${input.referenceMaterials}`。这是 Prompt 中最核心的变量，决定了每次 AI 处理的具体对象。
2.  **分析上下文**：在生成文案的 Prompt 中，`${analysisContext}` 变量将上一步的分析结果（关键词、钩子等）作为新的指令注入，让 AI 的创作有据可依。
3.  **固定指令模板**：如“以严格的 JSON 格式返回”、“直接返回 JSON，不要 Markdown 代码块”、“标题要极其吸引人，带 Emoji”等。这些是保证输出质量与格式稳定的关键。

**如果只改 Prompt，不改代码，会发生什么变化？**
变化会非常直接和巨大：
- **改变分析维度**：如果你把分析 Prompt 里的 `keywords`（关键词）改成 `rhetorical_devices`（修辞手法），那么 AI 就会分析文案用了什么修辞，右侧卡片展示的内容也会完全改变（当然，卡片标题需要代码配合修改）。
- **改变生成风格**：如果你把生成 Prompt 里的“小红书爆款文案专家”改成“知乎深度回答风格”，并要求“逻辑严谨，引经据典”，那么生成出来的文案就会从短平快的小红书体，变成深度的知乎体。
- **改变输出格式**：如果你要求分析结果以 Markdown 表格形式返回，那么现有的 JSON 解析代码就会报错。

**结论**：Prompt 是控制 AI 行为的“开关”和“模具”。在这个应用中，代码负责搭建流程和界面，而 Prompt 则决定了在这个流程中 AI 具体“想什么”和“说什么”。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个“换肤-换核-升级”的路径，安全地创建你自己的 AI 工具：

**第一步：保持结构不变，替换使用场景（最安全）**
- **目标**：做一个功能一模一样，但主题不同的工具。
- **操作**：
    1.  修改 `title` 和顶部导航栏的标题（如改为“知乎高赞回答分析器”）。
    2.  修改左侧两个输入框的提示文字（如“待分析的知乎高赞回答”、“新回答的参考资料或问题”）。
    3.  修改两个按钮的文字（如“开始分析回答套路”、“生成新回答”）。
    4.  修改右侧 Tab 和卡片的标题（如将“爆款钩子”改为“高赞开头”，“用户痛点”改为“核心议题”）。
- **此时**：你的新工具已经诞生了，它分析的是知乎回答，生成的是知乎体文案，但底层代码和逻辑完全没动。

**第二步：调整输入字段或 Prompt（改变核心功能）**
- **目标**：让工具解决更具体或略有不同的问题。
- **操作**：
    1.  **增删输入框**：在左侧面板增加一个“选择文案类型”的下拉菜单（如：评测、教程、清单），并将这个选择加入到 Prompt 变量中。
    2.  **修改分析维度**：打开代码，找到 `analyzeContent` 函数里的 Prompt 模板。修改其中要求 AI 分析的 JSON 字段。例如，增加一个 `target_audience`（目标受众）字段。
    3.  **修改生成要求**：找到 `generateNewCopy` 函数里的 Prompt 模板。细化或改变对生成内容的要求。例如，要求生成“包含3个产品优缺点的对比表格”。
- **此时**：你的工具开始有了独特的分析视角和生成偏好。

**第三步：改变输出形式或展示方式（优化体验）**
- **目标**：让结果展示更符合你的内容特点。
- **操作**：
    1.  **调整分析结果布局**：如果你新增了分析维度，在右侧的“分析结果”区域，仿照现有卡片的样式，增加一个新的卡片来展示它。
    2.  **改变文案展示样式**：如果你生成的是带表格的文案，可以修改 `renderMarkdown` 后的样式，让表格有更好的边框和背景。
    3.  **增加新功能**：例如，在生成的文案下方增加“重新生成”、“改写某一段”的按钮。
- **此时**：你的工具从内到外都成为了一个独特的作品。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格选择器”**：
    - **操作**：在左侧“参考资料”上方，增加一个下拉框，选项包括“活泼口语风”、“专业测评风”、“治愈温暖风”等。
    - **改造点**：将这个选项作为变量加入到生成文案的 Prompt 中（例如：“请使用 ${selectedStyle} 风格进行撰写”）。
    - **效果**：用户可以在生成前就控制文案的整体语调，工具灵活性大增。

2.  **接入多模型API，实现“模型对比”**：
    - **操作**：在设置弹窗中，除了 DeepSeek，增加 OpenAI GPT、Claude 等模型的 API Key 输入框和模型选择。
    - **改造点**：修改 `callDeepSeek` 函数为 `callAI`，内部根据用户选择，构造不同的请求 URL 和头部信息。
    - **进阶**：在生成文案时，允许用户同时调用两个模型，并将结果并排展示进行对比。

3.  **拆解为“分析库”与“创作台”两个页面**：
    - **操作**：将当前单页面拆成两个 HTML 文件。
    - **页面一（分析库）**：专注于分析。用户可以保存多组分析结果，形成自己的“爆款套路库”。
    - **页面二（创作台）**：专注于生成。可以从“分析库”中选择一个套路，再结合参考资料进行创作。
    - **效果**：流程更专业，适合需要长期积累和复用分析结果的用户。

4.  **优化交互，增加“示例填充”与“历史记录”**：
    - **操作**：
        - 在每个输入框旁边增加一个“加载示例”按钮，点击后会自动填充一段示例文本，帮助新用户快速理解工具用法。
        - 在页面底部或侧边栏，增加一个“历史记录”区域，使用 `localStorage` 保存最近几次的分析结果和生成文案，方便回溯和复用。
    - **效果**：极大提升用户体验，让工具更友好、更实用。

5.  **增加“文案评分”或“优化建议”功能**：
    - **操作**：在生成文案的展示区域，增加一个“AI评分”按钮。
    - **改造点**：点击后，将当前生成的文案和最初的分析结果（关键词、情绪等）再次发送给 AI，让 AI 从“是否匹配爆款特征”、“是否有吸引力”等维度进行评分，并给出1-3条具体的优化建议。
    - **效果**：从“生成”工具升级为“生成+优化”教练，闭环体验更完整。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做精确的事实核查或数据验证**：
    - **局限性**：AI 分析的是文本中的“模式”、“情绪”和“表述”，它无法验证文案中提到的产品功效、数据是否真实准确。
    - **正确做法**：如果需要验证事实，应使用专业的搜索引擎、学术数据库或事实核查工具。

2.  **不适合生成需要高度专业领域知识的内容**：
    - **局限性**：对于法律、医疗、金融等强监管、高专业门槛的内容，AI 基于模式生成的文案可能存在风险、不准确或不合规。
    - **正确做法**：此类内容应由领域专家主导创作，AI 仅作为辅助工具提供灵感或检查语病。

3.  **不适合完全替代人类的创意和策略思考**：
    - **局限性**：这个工具擅长“模仿风格”和“快速成稿”，但它无法理解你品牌的长远战略、无法产生真正划时代的创意概念。
    - **正确做法**：将工具定位为“高级助手”和“灵感加速器”。最终的策略方向、品牌调性把控和核心创意，仍需人类来主导。

4.  **不适合处理非文本的深度分析**：
    - **局限性**：它只分析粘贴进去的文字。对于爆款笔记中图片的构图、色彩、信息量，视频的节奏、BGM，它无法处理。
    - **正确做法**：如果需要分析多媒体内容，应寻找专门的图像/视频分析工具，或结合人工研判。

**总结**：这是一个强大的 **“文本模式分析与风格化生成”** 工具。请将它用在它擅长的领域——快速解构流行文本模式和辅助内容生产。对于超出其边界的工作，请寻求更专业的工具或方法。
