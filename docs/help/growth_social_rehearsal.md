# 社交情景彩排 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下：你明天要和老板谈加薪，或者需要向朋友提出一个敏感话题，但不知道如何开口。你可能会在脑海中反复排练，却不确定自己的表达是否得体、有效。

这个网页就是你的“社交演练场”。它让你在真实对话发生前，**安全地模拟各种社交场景**。你输入一个具体情境（如“向同事提出协作请求”），选择想要的语气，AI就会生成一个包含6轮对话的彩排剧本。你可以看到“你”会说什么，以及“对方”可能的回应。

**适合使用的情况：**
- 准备重要谈话（工作汇报、客户沟通、家庭讨论）
- 练习不熟悉的社交场合（面试、约会、社交活动）
- 探索不同表达方式的效果
- 缓解社交焦虑，提前“预演”

**不适合的情况：**
- 需要实时互动的真实对话
- 涉及高度专业或技术性内容的讨论
- 需要法律或心理咨询的严肃问题
- 替代真实的人际沟通练习

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **场景描述**：一个文本框，让你描述想要演练的社交情境
2. **语气选择**：下拉菜单，提供“礼貌稳重”、“轻松幽默”、“坚定直接”三种风格

**用户通常会做哪几步操作？**
1. **首次使用**：点击右上角的齿轮图标，输入你的DeepSeek API Key并保存
2. **输入场景**：在左侧输入框中描述你的情境，比如“拒绝朋友的借钱请求”
3. **选择语气**：根据你想要的效果选择一种对话风格
4. **生成对话**：点击“生成对话”按钮，等待几秒钟
5. **查看结果**：右侧会显示生成的6轮对话，交替显示“你”和“对方”的发言

**输出结果长什么样？**
右侧会显示一个对话气泡列表：
- “你”的发言显示在右侧，绿色背景
- “对方”的发言显示在左侧，灰色背景
- 每轮对话都有角色标签和具体内容
- 例如：
  ```
  你：你好，最近工作怎么样？
  对方：还不错，项目进展挺顺利的。
  ```

**有哪些容易忽略的使用细节？**
1. **API配置是必须的**：第一次使用前一定要先设置API Key，否则无法生成对话
2. **场景描述要具体**：“向老板汇报进度”比“工作对话”效果更好
3. **可以修改默认场景**：输入框默认有文字，但你可以完全替换它
4. **错误提示在左侧**：如果生成失败，错误信息会显示在生成按钮下方
5. **对话格式固定**：AI会严格按照“角色：内容”的格式生成，确保能被正确解析

## 【三】核心结构拆解（学习重点）

这个页面由三个主要模块组成：

**1. 配置与输入模块（左侧卡片）**
- **职责**：收集用户需求和系统配置
- **包含**：场景输入框、语气选择器、生成按钮、API设置面板
- **关键设计**：将用户输入（场景+语气）打包成Prompt，触发AI调用

**2. 展示与输出模块（右侧卡片）**
- **职责**：可视化呈现AI生成的对话
- **包含**：对话气泡容器，区分“你”和“对方”的样式
- **关键设计**：通过颜色和位置区分对话双方，增强可读性

**3. 数据处理与通信模块（幕后逻辑）**
- **职责**：连接前端与AI服务，处理数据格式
- **包含**：API调用函数、Prompt构建、响应解析、本地存储
- **关键设计**：将自然语言对话解析为结构化数据对象

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入场景和语气 → 构建Prompt → 调用DeepSeek API → 
接收AI回复 → 解析文本为结构化数据 → 渲染为对话气泡
```

**最值得学习的设计：**
**Prompt的精心设计**是整个应用的核心。它用极简的指令（“场景：X\n语气：Y\n请输出6轮对话，格式：你：...\n对方：...”）就让AI理解了复杂任务。这种“用最少的话说清要求”的Prompt设计思路，是构建AI应用的关键技能。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接用户意图与AI能力的“翻译官”。它把用户简单的“场景+语气”输入，翻译成AI能理解的具体任务指令。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。AI已经理解了“对话生成”这个基本任务，Prompt的作用是：
1. **限定范围**：指定是“6轮对话”
2. **提供上下文**：给出具体场景和语气要求
3. **规范格式**：要求“你：...\n对方：...”的格式，便于后续解析

**哪些信息是Prompt中的关键变量？**
1. **场景描述**：`${scenario.value}` - 这是对话的主题和背景
2. **语气风格**：`${tone.value}` - 决定对话的情感色彩和用词
3. **格式指令**：“请输出6轮对话，格式：你：...\n对方：...” - 确保输出可解析

**如果只改Prompt，不改代码，会发生什么变化？**
- 改场景描述 → 对话内容变化（主题不同）
- 改语气选项 → 对话风格变化（用词、态度不同）
- 改轮数要求 → 对话长度变化（如改成8轮）
- 改格式要求 → 可能需要调整解析逻辑（如果格式不匹配）

## 【五】如何模仿它，做出你自己的版本？

**安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改标题和描述
- 例如：改成“面试模拟器”、“客户服务演练”、“亲子沟通练习”
- 保持所有代码结构不变，只改文字和提示语

**第二步：调整输入字段或Prompt**
- 增加输入项：如“对方性格”、“对话难度”
- 修改Prompt模板：调整指令，让AI生成不同风格的对话
- 例如：增加“请包含一个常见的误解和澄清过程”

**第三步：改变输出形式或展示方式**
- 修改对话气泡样式：改变颜色、布局、动画
- 增加交互功能：如“重说这一句”、“评价这个回应”
- 改变展示逻辑：如分步骤显示，而不是一次性全部展示

**最安全的下手点：**
从**只修改HTML中的文字内容**开始。把“社交情景彩排”改成你的应用名称，把示例场景改成你的领域相关例子。这样不会破坏任何功能，却能立即获得一个“看起来不同”的版本。

## 【六】3–5个可直接尝试的改造方向

**1. 增加角色和关系设定**
- 增加输入框：“对方是谁？（同事/朋友/家人）”
- 增加下拉菜单：“你们的关系（亲密/一般/陌生）”
- 修改Prompt：“场景：${场景}\n对方身份：${身份}\n关系：${关系}\n语气：${语气}”

**2. 加入对话评价和建议**
- 生成对话后，让AI额外生成一段“沟通建议”
- 例如：“这段对话中，你的表达在第三轮可能过于直接，建议...”
- 在对话下方添加一个“教练点评”区域

**3. 实现多轮迭代和修改**
- 允许用户点击某句对话进行修改
- 修改后，重新生成后续对话
- 增加“我不喜欢这个回应，换一个”按钮

**4. 更换AI模型或增加模型选择**
- 除了DeepSeek，增加OpenAI、Claude等选项
- 让用户可以选择不同模型体验差异
- 增加“哪个模型生成得更好？”的对比功能

**5. 增加情景库和快速选择**
- 预设一些常见场景：“要求加薪”、“拒绝邀请”、“道歉”
- 用户可以直接点击选择，不用每次手动输入
- 增加“保存我的场景”功能，建立个人情景库

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不是真实的人际互动**
   - AI的回应基于模式识别，不是真实人类的情感反应
   - 对方在现实中可能不会按剧本回应
   - **如果需要真实反馈**：应该找真人角色扮演或专业教练

2. **不处理深度情感或心理问题**
   - 对于涉及创伤、焦虑症、人际关系冲突的严重问题
   - AI无法提供专业的心理支持或干预
   - **如果有心理困扰**：请寻求专业心理咨询师帮助

3. **不适用于高度专业化场景**
   - 法律谈判、医疗诊断、技术评审等需要专业知识的对话
   - AI可能生成看似合理但不专业或不准确的建议
   - **专业场景准备**：应咨询领域专家或使用专业培训材料

4. **不能替代实践和反思**
   - 工具提供的是“预演”，不是“掌握”
   - 真正的沟通能力需要在真实互动中发展和调整
   - **最佳使用方式**：作为准备工具，而非能力替代品

记住：这个工具最适合作为**沟通前的热身和思路拓展**，而不是沟通能力的唯一来源。把它当作你的“私人排练室”，而不是“万能沟通导师”。
