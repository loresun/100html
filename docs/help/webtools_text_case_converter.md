# 文本大小写转换工具 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你需要快速调整一段文本的书写格式时，这个工具能帮你一键完成。比如：
- 程序员需要将变量名从“user_name”改成“userName”（camelCase）
- 写作者想把标题从全大写改成首字母大写（Title Case）
- 设计师需要为CSS类名生成“kebab-case”格式
- 学生想把整段英文改成句子格式（Sentence case）

**适合情况**：
- 处理英文文本的大小写和格式转换
- 需要快速预览不同格式的效果
- 需要复制转换结果到其他应用

**不适合情况**：
- 处理中文文本（工具主要针对英文设计）
- 需要复杂的文本编辑功能（如查找替换、批量处理）
- 需要保留原始文本的特殊格式（如HTML标签、Markdown语法）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个大的文本框，你可以在里面粘贴或输入任何英文文本

**用户通常会做哪几步操作？**
1. 在左侧“Input”区域输入或粘贴你的文本
2. 在右侧的按钮网格中选择想要的转换格式
3. 查看右侧“Result”区域的转换结果
4. 点击“Copy”按钮复制结果到剪贴板

**输出结果长什么样？**
- 转换后的文本会显示在右侧的灰色文本框中
- 格式会根据你选择的按钮而变化
- 例如：选择“UPPERCASE”会把“hello”变成“HELLO”

**有哪些容易忽略的使用细节？**
1. **实时转换**：输入文本后，只要选择过一次转换格式，后续修改输入会自动重新转换
2. **清除功能**：输入框右上角的“Clear”按钮可以一键清空所有文本
3. **复制反馈**：点击“Copy”后会出现“Copied”提示，2秒后消失
4. **按钮状态**：当前选中的转换模式按钮会变成紫色，其他按钮是白色

## 【三】核心结构拆解（学习重点）

这个页面由**三个核心模块**组成：

**1. 输入模块（左侧）**
- **职责**：接收用户输入的原始文本
- **特点**：使用`textarea`元素，支持多行文本，有清空功能
- **数据流**：用户输入 → 存储到`input`变量 → 触发转换

**2. 控制模块（右上）**
- **职责**：提供10种不同的转换模式选择
- **设计**：网格布局的按钮，每个按钮展示该模式的示例
- **交互**：点击按钮 → 调用`convert()`函数 → 更新`mode`状态

**3. 输出模块（右下）**
- **职责**：显示转换结果并提供复制功能
- **特点**：只读文本框，有复制按钮和成功反馈
- **数据流**：`output`变量 → 显示在textarea → 可复制到剪贴板

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入文本 → 存储在input变量 → 用户选择转换模式 → 
调用convert(type)函数 → 根据type执行对应算法 → 
结果存储在output变量 → 自动显示在输出区域
```

**最值得学习的设计：**
- **状态驱动UI**：使用Alpine.js的`x-data`管理所有状态（input、output、mode）
- **响应式更新**：通过`$watch`监听input变化，自动重新转换
- **清晰的职责分离**：输入、控制、输出三个区域完全独立，便于维护和扩展

## 【四】Prompt / AI 逻辑是如何被设计的？

**注意**：这个网页**没有使用AI或Prompt**，它完全基于JavaScript的字符串处理函数实现转换逻辑。

**替代理解：转换逻辑的设计**
- **角色**：每种转换模式对应一个特定的字符串处理算法
- **解决的问题**：如何将文本从一种格式转换为另一种格式
- **关键变量**：转换类型（type）和输入文本（str）

**如果只改算法，不改界面，会发生什么变化？**
1. 修改`convert()`函数中的某个case逻辑 → 该模式的转换规则改变
2. 例如：修改'title' case的算法 → 标题格式的生成方式变化
3. 修改'sentence' case的正则表达式 → 句子识别的规则变化

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 复制整个HTML结构
- 修改标题和说明文字
- 例如：改成“文本编码转换器”、“文本替换工具”

- 修改`convert()`函数中的算法
- 例如：实现“文本反转”、“单词计数”、“行号添加”
- 保持相同的函数结构和调用方式

**第三步：改变输出形式或展示方式**
- 修改输出区域的显示方式
- 例如：改成表格显示、添加统计信息、支持多种输出格式
- 保持复制功能不变

**最安全的下手点**：从修改`convert()`函数开始，先实现一个简单的转换功能（如文本反转），确保整个流程能跑通。

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **仅限英文文本**：算法主要针对英文字母设计，处理中文会得到奇怪的结果
2. **简单转换**：只能做格式转换，不能做内容修改（如翻译、摘要）
3. **无批量处理**：一次只能处理一段文本，不适合大量文件
4. **无版本控制**：没有保存历史版本的功能

**如果用户想做以下事情，应该换工具：**
- **处理中文文本**：使用专门的中文排版工具
- **复杂文本编辑**：使用专业的文本编辑器（如VS Code、Sublime Text）
- **批量文件处理**：使用命令行工具（如sed、awk）或编写脚本
- **智能文本处理**：使用AI工具（如ChatGPT）进行翻译、改写等

**记住**：这个工具的核心价值是**快速、简单、专注**。它不做所有事情，但把自己能做的事情做得很好。
