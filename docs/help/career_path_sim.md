# 职业路径模拟器 - 学习与改造指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你对自己的职业发展感到迷茫，或者想探索从当前岗位到理想岗位的可能路径时，这个工具能快速为你提供多种发展思路。比如，你是一名“内容运营”，想知道如何成为“增长负责人”，这个工具会给你3条不同的发展建议。

**适合情况**：
- 职业转型初期的探索阶段
- 需要快速获得多种发展思路
- 个人职业规划的头脑风暴

**不适合情况**：
- 需要详细的、个性化的职业咨询
- 涉及具体公司内部晋升路径
- 需要认证的职业评估或心理测评

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 两个文本框：一个填写“当前身份”，一个填写“目标岗位”

**用户通常会做哪几步操作？**
1. 点击右上角的设置按钮，输入你的DeepSeek API Key（第一次使用时必须）
2. 在“当前身份”框中填写你现在的职位或角色
3. 在“目标岗位”框中填写你想达到的目标职位
4. 点击“生成路径”按钮
5. 等待几秒钟，查看AI生成的3条路径

**输出结果长什么样？**
- 页面下方会显示3个卡片，每个卡片代表一条发展路径
- 每条路径用一句话描述，例如：“路径1：从内容运营转向用户运营，积累数据分析能力后申请增长岗位”

**有哪些容易忽略的使用细节？**
1. **必须配置API Key**：第一次使用时，如果不配置API Key，点击生成会报错
2. **输入要具体**：“当前身份”和“目标岗位”越具体，生成的路径越有参考价值
3. **可以修改模型**：设置中可以选择不同的AI模型，会影响回答的风格和质量
4. **路径数量固定**：无论输入什么，都只生成3条路径

## 【三】核心结构拆解（学习重点）

这个页面由4个关键模块组成：

**1. 用户输入模块**
- **位置**：页面中央的两个输入框
- **职责**：收集用户的起点和目标信息
- **特点**：使用Vue的双向绑定，实时同步数据

**2. AI处理模块**
- **位置**：隐藏在后台的JavaScript函数
- **职责**：将用户输入转化为AI能理解的Prompt，调用API，处理返回结果
- **关键函数**：`callLLM()` 和 `generate()`

**3. 结果显示模块**
- **位置**：输入区域下方的卡片区域
- **职责**：清晰展示AI生成的3条路径
- **设计亮点**：使用左侧蓝色边框和浅灰色背景区分每条路径

**4. 配置管理模块**
- **位置**：点击设置按钮弹出的浮层
- **职责**：管理API Key和模型选择，并保存到本地存储
- **价值**：让用户无需每次输入API Key

**输入 → 处理 → 输出 的逻辑链路**：
```
用户输入 → 拼接成Prompt → 调用AI API → 解析返回文本 → 分割成3条路径 → 显示在卡片中
```

**最值得学习的设计**：
- **配置的持久化存储**：使用`localStorage`保存API配置，用户只需设置一次
- **简洁的Prompt设计**：用最少的文字让AI理解任务并输出结构化结果
- **错误处理机制**：当API调用失败或未配置时，有明确的错误提示

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色**：
Prompt是连接用户意图和AI能力的“翻译官”。它告诉AI：“用户给了两个信息，请基于这些信息完成特定任务。”

**解决的是“理解问题”还是“生成问题”？**
主要是“生成问题”。AI已经理解了“职业发展顾问”的角色（通过system message），Prompt需要的是让它基于具体输入生成具体内容。

**Prompt中的关键变量**：
```javascript
`当前：${start.value}\n目标：${target.value}\n请给出 3 条路径，每条一句话。`
```
- `start.value`：用户的当前身份
- `target.value`：用户的目标岗位
- “3条路径，每条一句话”：这是对输出格式的明确要求

**如果只改Prompt，不改代码，会发生什么变化？**
- 改输出数量：`请给出 5 条路径` → 会生成5条，但页面只显示前3条（因为代码固定取3条）
- 改输出格式：`每条用两句话描述` → AI会输出更详细的内容
- 改任务性质：`请分析这个转型的难点` → 会得到分析性内容，但页面可能显示不正常

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径**：

**第一步：保持结构不变，替换使用场景**
- 最安全！只改文字，不改代码
- 例如改成“学习路径规划器”：
  - 标题：学习路径模拟器
  - 输入1：当前水平（如“Python初学者”）
  - 输入2：目标能力（如“能开发Web应用”）
  - Prompt：`当前：${start.value}\n目标：${target.value}\n请给出 3 条学习路径，每条一句话。`

**第二步：调整输入字段或Prompt**
- 增加一个输入框：比如“可用时间（月）”
- 修改Prompt：`在${time.value}个月内，从${start.value}到${target.value}，请给出3条路径`
- 注意：需要先在Vue的setup()中添加对应的ref变量

**第三步：改变输出形式或展示方式**
- 把卡片改成时间轴样式
- 或者每条路径显示为多个步骤的列表
- 这一步需要修改HTML结构和CSS样式

**从哪里下手最安全？**
从**第一步**开始最安全。先完全理解现有代码，然后只改文字内容和Prompt，确保功能正常。之后再考虑增加功能。

## 【六】3–5个可直接尝试的改造方向

**1. 增加路径详细度控制**
- 在输入区域增加一个下拉菜单：“路径详细度：简洁/详细”
- 修改Prompt：根据选择决定输出格式
- 代码修改：增加一个`detailLevel`变量，在Prompt中体现

**2. 支持多模型切换**
- 当前只支持DeepSeek，可以增加OpenAI、Claude等
- 在设置中增加模型提供商选择
- 修改`callLLM`函数，根据选择调用不同的API端点

**3. 添加路径收藏功能**
- 每条路径卡片旁增加“收藏”按钮
- 点击后保存到`localStorage`的另一个键中
- 新增一个“我的收藏”页面查看保存的路径

**4. 改进结果展示**
- 每条路径显示预计时间、难度等级、关键技能
- 使用图标或进度条可视化不同维度
- 让用户可以对路径进行排序（按时间、难度等）

**5. 增加示例库**
- 在输入框下方显示“常见示例”按钮
- 点击后自动填充经典转型案例（如“设计师→产品经理”）
- 帮助用户理解如何填写更有价值

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明**：

1. **不是专业的职业咨询工具**
   - AI生成的路径基于通用知识，不考虑个人具体情况（性格、价值观、家庭等）
   - **如果需要**：应寻求专业职业咨询师或使用专业的职业测评工具

2. **无法提供具体行动计划**
   - 每条路径只有一句话，缺乏具体的步骤、时间节点、资源推荐
   - **如果需要**：可以基于某条路径，使用项目管理工具或学习平台制定详细计划

3. **不考虑市场实时变化**
   - AI的知识有截止日期，无法反映最新的招聘趋势或新兴岗位
   - **如果需要**：应结合招聘网站数据、行业报告进行验证

4. **没有个性化交互**
   - 无法追问、无法根据用户反馈调整建议
   - **如果需要**：应使用对话式AI工具或咨询真人顾问

5. **不处理复杂职业场景**
   - 如跨行业转型、创业路径、自由职业规划等复杂情况效果有限
   - **如果需要**：应寻找专门针对这些场景的工具或咨询服务

**记住**：这个工具最适合的是“灵感激发”和“思路拓展”，而不是“决策依据”。把它当作一个聪明的头脑风暴伙伴，而不是终极的职业导师。
