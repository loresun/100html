# 反直觉思考者 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你面对一个“理所当然”的观点，想跳出常规思维、寻找不同视角时，这个工具能帮你快速获得多个反直觉的批判性论证。比如：
- 在团队头脑风暴中，需要挑战“我们一直这样做”的惯性思维
- 写议论文时，想找到新颖的论点来反驳主流观点
- 个人决策前，希望看到被忽略的风险或反面证据
- 学习批判性思维，想看看专家会如何“抬杠”

**适合：**
- 需要思维激荡的创意工作者
- 学习辩论和逻辑思考的学生
- 希望避免“群体思维”的团队讨论引导者

**不适合：**
- 寻求绝对正确答案的查询（如数学计算）
- 需要情感支持或安慰的场景
- 对已有明确科学共识的事实进行“为反而反”

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 一个文本框：输入你想挑战的普遍观点（如“失败是成功之母”）
- 三个示例标签：点击可直接使用预设观点

**操作步骤：**
1. **输入观点**：在文本框中写下你想挑战的观点，或直接点击示例
2. **点击生成**：按下“挑战该观点”按钮
3. **等待思考**：页面会显示加载动画，AI正在构建反驳论证
4. **查看结果**：获得3-5个不同角度的反驳视角，每个都有标题和详细解释

**输出结果长什么样？**
```
对“失败是成功之母”的反思

视角一：幸存者偏差的陷阱
[详细解释：我们只看到那些失败后成功的案例...]

视角二：心理成本的诅咒  
[详细解释：反复失败可能导致习得性无助...]

视角三：资源错配的风险
[详细解释：在错误的方向上坚持失败...]
```

**容易忽略的细节：**
- 右上角的齿轮图标可打开设置面板，配置自己的API密钥
- 生成结果后，右上角有“复制”和“下载”按钮
- 点击示例标签会**自动开始生成**，不用再按按钮

## 【三】核心结构拆解（学习重点）

**四个关键模块：**

1. **输入模块**（顶部白色区域）
   - **职责**：接收用户观点，提供快捷示例
   - **设计亮点**：示例标签不仅是展示，点击后直接触发生成，减少操作步骤

2. **处理引擎**（隐藏的逻辑层）
   - **职责**：将用户观点包装成Prompt，调用AI API，解析返回结果
   - **关键流程**：用户观点 → 构建Prompt → API调用 → 解析格式 → 结构化数据

3. **展示模块**（结果区域）
   - **职责**：以卡片形式展示每个反驳视角，提供复制/下载功能
   - **设计亮点**：每个论证独立成卡，视觉上清晰分隔不同角度

4. **配置模块**（侧滑面板）
   - **职责**：管理API连接设置，支持自定义模型和密钥
   - **设计亮点**：与全局配置同步，一次设置可在多个工具中使用

**输入→处理→输出链路：**
```
用户输入“勤能补拙”
    ↓
Prompt构建（加入系统指令和格式要求）
    ↓
调用DeepSeek API
    ↓
解析返回的文本（按“**视角X**”分割）
    ↓
渲染为视觉卡片 + 生成Markdown备用
```

**最值得学习的设计：**
**格式化的Prompt与解析的配合**。网页不是简单显示AI的原始回复，而是通过严格的Prompt要求AI按特定格式输出，再用JavaScript解析这个格式，最终渲染成结构化的界面。这种“约束生成→解析→美化”的三段式设计，让AI输出变得可控、美观。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色：**
- **约束生成方向**：告诉AI“你是一位批判性思维专家和杠精”
- **规定输出格式**：要求必须按“**视角一：[标题]**”的格式输出
- **提供思考框架**：暗示从“幸存者偏差”“机会成本”等角度思考

**解决的是“生成问题”：**
这个Prompt主要解决“如何让AI生成结构化的反驳论证”，而不是“理解用户观点是什么”。用户观点只是Prompt中的一个变量。

**关键变量：**
1. `{viewpoint}`：用户输入的观点，被直接嵌入Prompt
2. **角色设定**：“顶级批判性思维专家和‘杠精’”
3. **数量要求**：“3-5个完全不同角度的反驳论证”
4. **格式模板**：明确的标题和解释分隔符

**如果只改Prompt，不改代码：**
- 改角色设定（如“你是一位哲学家”）→ 论证的理论深度会变化
- 改角度数量（如“生成7个角度”）→ 输出会更全面但可能重复
- 改格式要求（如用数字列表）→ 网页可能无法正确解析，显示混乱
- 改思考方向（如“从经济学角度反驳”）→ 所有论证都会偏向经济学视角

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：替换使用场景（保持结构不变）**
- 把“反驳观点”改成其他场景，如：
  - **产品创意生成器**：输入用户痛点 → 生成产品方案
  - **辩论论点助手**：输入辩题 → 生成正反方论点
  - **学习计划生成**：输入学习主题 → 生成学习路径
- 只需修改：页面标题、输入框提示语、示例标签

**第二步：调整Prompt核心**
- 修改系统指令中的“角色设定”
- 调整输出格式要求（但保持“标题+内容”的基本结构）
- 改变生成的数量或角度类型

**第三步：改变展示方式**
- 修改结果卡片的样式（颜色、布局）
- 增加新的操作按钮（如“分享到Twitter”）
- 改变下载格式（如PDF、图片）

**从哪里下手最安全？**
从**修改示例标签和页面文案**开始。这是零风险修改，不会影响功能。比如改成“输入一个业务问题，生成创新解决方案”，示例标签换成“用户留存率低”“获客成本高”等。

## 【六】3–5个可直接尝试的改造方向

1. **增加输入维度**
   - 加一个下拉菜单：“反驳强度”（温和/中等/激进）
   - 加一个复选框：“包含实际案例”
   - 加一个文本框：“特定领域”（如心理学、经济学、科技）

2. **扩展输出形式**
   - 增加“一键生成辩论稿”功能，把多个视角串联成文章
   - 增加可视化图表：用雷达图展示不同反驳角度的“颠覆性强度”
   - 增加“保存到收藏夹”功能，建立个人论点库

3. **优化交互体验**
   - 增加“历史记录”面板，查看之前的生成结果
   - 为每个论证卡片增加“点赞/踩”按钮，让AI学习你的偏好
   - 增加“深入展开”按钮，点击后让AI为该视角生成更多细节

4. **拆分为多页面**
   - **页面1**：观点输入和基础反驳
   - **页面2**：“深度反驳模式”：针对其中一个视角，生成更多子论点
   - **页面3**：“正反平衡”：在反驳后，再生成支持原观点的论证

5. **更换或扩展AI能力**
   - 集成多个AI模型：让Claude、GPT-4、DeepSeek同时生成，对比结果
   - 增加“人类专家模式”：接入真实辩论数据库或哲学论文摘要
   - 本地模型支持：用Ollama在本地运行小模型，保护隐私

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不是事实核查工具**：它擅长逻辑反驳，但不验证观点的事实基础。如果输入“地球是平的”，它会从逻辑角度反驳，但不会提供科学证据。
2. **缺乏深度对话**：每次生成都是独立的，无法基于之前的反驳进行多轮深入讨论。
3. **可能过度批判**：对于需要建设性建议的场景（如心理咨询），这种“杠精”模式可能有害。

**如果你需要做这些，请换工具：**
- **需要事实验证** → 使用Perplexity.ai或传统搜索引擎
- **需要情感支持** → 使用专门的情感陪伴AI（如Replika）
- **需要多轮深入讨论** → 使用ChatGPT的对话模式
- **需要生成实际方案** → 使用“如何做”类的AI工具（如针对“如何提高效率”给出步骤）

**记住**：这个工具是“思维破壁器”，不是“真理判定器”。用它打开思路，而不是关闭对话。
