# 短视频分镜脚本生成器 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你有一个视频创意（比如一篇教程文章、一个生活片段想法、或一个有趣的故事梗概），但不知道如何把它变成可拍摄的、专业的短视频分镜脚本时，这个工具能帮你快速完成转化。

**适合情况**：
- 短视频创作者需要将文字内容（文章、想法）可视化
- 新手导演或编导需要标准化的分镜模板
- 团队协作时，需要快速生成可讨论的拍摄方案
- 内容创作者想尝试不同视频风格（口播、剧情、Vlog）

**不适合情况**：
- 需要高度创意、艺术性极强的电影长片分镜
- 已经拥有完整剧本，只需要微调细节
- 需要实时协作编辑（如Google Docs）
- 对画面构图、灯光有极其专业要求的情况

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **创意/主题**：一句话概括你的视频主题（如“如何制作一杯完美的拿铁”）
2. **参考文案/详细信息**：粘贴你的文章内容、详细步骤或粗略想法
3. **脚本类型选择**：口播讲解类、剧情/段子类、Vlog/生活类

**用户通常会做哪几步操作？**
1. 在左侧输入区填写主题和详细内容
2. 根据视频风格选择对应的脚本类型
3. 点击“生成分镜脚本”按钮
4. 等待AI生成结果（右侧会实时显示）
5. 查看生成的表格，可复制Markdown或导出Excel

**输出结果长什么样？**
- 一个完整的Markdown表格，包含：
  - 镜号（序号）
  - 景别（近景、特写等）
  - 画面描述
  - 运镜方式
  - 台词/旁白
  - 备注/音效
- 如果使用“Reasoner”模型，还会显示AI的思考过程

**容易忽略的使用细节：**
1. **API配置**：第一次使用前，需要点击右上角“API设置”输入DeepSeek API Key
2. **提示词配置**：可以自定义每种脚本类型的生成规则
3. **模型切换**：右上角可切换“Chat”和“Reasoner”模型，后者会显示思考过程
4. **内容不能为空**：详细内容区域必须填写，否则无法生成

## 【三】核心结构拆解（学习重点）

**页面由四个关键模块组成：**

1. **配置与状态模块**（顶部导航栏）
   - 职责：模型切换、API设置、提示词配置入口
   - 设计亮点：将技术配置与创作界面分离，保持主界面简洁

2. **输入与控制模块**（左侧面板）
   - 职责：收集用户创意、选择脚本类型、触发生成
   - 包含：主题输入框、内容文本框、类型选择卡、生成按钮
   - 输入逻辑：用户填写 → 选择类型 → 点击生成 → 发送给AI

3. **输出与展示模块**（右侧主区域）
   - 职责：实时显示生成结果、提供导出功能
   - 包含：Markdown渲染区、思考过程折叠面板、导出按钮
   - 输出逻辑：AI流式返回 → 实时渲染Markdown → 用户操作（复制/导出）

4. **模态窗口模块**（设置弹窗）
   - 职责：处理配置信息，不干扰主流程
   - 包含：API配置窗、提示词编辑窗

**最值得学习的设计：**
- **流式响应体验**：AI生成时，内容逐字显示，让用户感知进度
- **配置与使用分离**：将复杂的API、提示词设置放在弹窗，主界面保持专注
- **类型化提示词系统**：每种脚本类型有独立的提示词，可自定义修改
- **思考过程可视化**：使用“Reasoner”模型时，展示AI的推理链，增加透明度

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色：**
Prompt是“翻译官”和“格式规范员”。它把用户的粗糙想法，按照特定视频类型的专业要求，翻译成标准化的分镜脚本。

**解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。AI已经能理解用户输入的内容，Prompt的作用是：
1. 约束输出格式（必须是Markdown表格）
2. 定义专业标准（景别、运镜等影视术语）
3. 设定风格基调（口播要口语化、Vlog要有氛围感）

**Prompt中的关键变量：**
1. **角色定义**：“你是一个专业的短视频脚本编剧...”
2. **任务描述**：“请将用户输入的内容转化为...”
3. **具体要求**：结构、语言、节奏等
4. **格式强制**：“输出格式必须为 Markdown 表格，包含以下列：”
5. **列定义**：镜号、景别、画面描述、运镜、台词、备注

**如果只改Prompt，不改代码，会发生什么变化？**
- 改变脚本风格：把口播改成纪录片风格
- 调整专业深度：增加或减少技术细节
- 修改输出格式：从表格改成列表或JSON
- 切换应用领域：从视频脚本改成播客大纲或漫画分镜

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最安全：只改文字和图标
  - 把“短视频分镜”改成“播客节目大纲”
  - 把“口播/剧情/Vlog”改成“访谈/故事/新闻”
  - 替换所有相关文案和图标
- 代码几乎不用改，只是文字替换

**第二步：调整输入字段和Prompt**
- 中等难度：改输入和AI逻辑
  - 增加“目标受众”输入框
  - 增加“视频时长”选择器
  - 修改DEFAULT_PROMPTS中的提示词
  - 添加新的脚本类型
- 需要理解Vue的数据绑定和prompt结构

**第三步：改变输出形式或展示方式**
- 进阶改造：改展示逻辑
  - 把表格改成时间轴可视化
  - 增加“一键生成拍摄清单”功能
  - 添加“分享链接”功能
  - 集成图片生成API，为每个分镜生成参考图
- 需要前端和API集成知识

**从哪里下手最安全？**
从**修改DEFAULT_PROMPTS**开始。这是纯文本修改，不会破坏代码结构，却能完全改变应用的功能。比如改成“小红书文案生成器”、“周报自动生成器”等。

## 【六】3–5个可直接尝试的改造方向

1. **增加输入维度，让脚本更精准**
   - 添加“视频时长”选择（15秒、60秒、3分钟）
   - 增加“目标平台”选择（抖音、B站、YouTube）
   - 添加“情绪基调”选择（欢乐、严肃、治愈）
   - **操作**：在左侧面板添加新的下拉菜单，将选择值拼接到prompt中

2. **扩展输出格式，满足不同需求**
   - 增加“导出为拍摄清单”功能（纯文本清单）
   - 增加“导出为团队协作格式”（Notion、飞书文档）
   - 添加“一键生成台词提词器”功能
   - **操作**：在导出按钮旁增加格式选择，修改exportToExcel函数

3. **集成多模型API，提升质量**
   - 除了DeepSeek，增加OpenAI GPT、Claude、智谱AI选项
   - 实现“模型对比”功能：同时用两个模型生成，对比结果
   - **操作**：在API设置中增加模型选择，修改callDeepSeek函数

4. **拆分为多页面，适应复杂流程**
   - 页面1：创意输入与脚本生成（当前页面）
   - 页面2：脚本编辑与调整（可拖拽调整顺序）
   - 页面3：团队评审与批注（添加评论功能）
   - **操作**：使用Vue Router创建多页面应用

5. **优化交互体验，降低使用门槛**
   - 添加“示例库”：点击示例直接填充输入框
   - 实现“历史记录”：保存最近生成的脚本
   - 添加“语音输入”功能：直接说话生成脚本
   - **操作**：在左侧面板添加示例按钮，使用localStorage保存历史

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不适合专业影视制作**
   - 无法处理复杂镜头语言（长镜头、蒙太奇）
   - 不考虑实际拍摄条件（场地、灯光、演员调度）
   - **替代方案**：使用专业分镜软件（Storyboard Pro、ShotPro）

2. **不适合实时协作**
   - 没有多用户同时编辑功能
   - 没有版本控制和修改记录
   - **替代方案**：使用Notion、飞书文档或专业协作工具

3. **不适合高度定制化需求**
   - Prompt修改有一定门槛
   - 无法深度调整AI的“创作风格”
   - **替代方案**：直接使用ChatGPT等工具，进行多轮对话调整

4. **不适合无网络环境**
   - 完全依赖API调用
   - 没有离线生成能力
   - **替代方案**：使用本地部署的大模型（Ollama + 本地模型）

5. **不适合法律/医疗等专业领域**
   - 生成的文案可能不准确或不专业
   - 没有事实核查机制
   - **替代方案**：咨询领域专家，或使用专业领域训练过的AI工具
