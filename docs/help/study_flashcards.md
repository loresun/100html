# 记忆闪卡实验室 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你正在学习一个新主题（比如英语短语动词、历史事件、编程概念），需要制作一套记忆卡片来帮助自己复习。传统方法需要你手动构思卡片的正反面内容，既耗时又可能不够系统。

这个网页就像一个**智能记忆卡片生成器**。你只需要输入一个学习主题或几个关键词，它就能自动为你生成一套结构化的记忆卡片。你还可以随时手动添加自己想到的卡片，并对所有卡片进行分类标记，进行翻转练习。

**适合的场景：**
*   **快速启动学习：** 面对一个新知识点，想快速建立一套复习材料。
*   **补充学习材料：** 在已有笔记基础上，希望AI帮你生成一些补充性的、不同角度的记忆点。
*   **碎片化复习：** 利用生成的卡片进行短时、高效的记忆练习。

**不适合的场景：**
*   **需要深度、长篇内容的学习：** 它生成的是零散的“知识点卡片”，不适合用来理解复杂的逻辑链条或阅读长篇文章。
*   **需要100%准确性的专业内容：** AI生成的内容可能存在偏差，对于法律、医学等要求绝对精确的领域，请务必人工核对。
*   **完全替代系统学习：** 它更适合作为复习和记忆的辅助工具，而不是初次学习的主要途径。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置：** 点击右上角的“API 设置”，输入你的 DeepSeek API Key 并选择模型（V3或O1），然后点击“保存配置”。这是让网页能调用AI生成卡片的关键一步。
2.  **生成卡片：**
    *   在左侧“学习主题或词汇列表”框中，输入你想学习的内容，例如“机器学习常用算法”或“10个法语基础单词”。
    *   在“生成数量”中选择你想要的卡片张数（5-20张）。
    *   点击“生成闪卡”按钮。稍等片刻，右侧区域就会自动出现一套卡片。
3.  **使用卡片：**
    *   **翻转：** 点击任何一张卡片的文字区域，它会从“正面”（问题/提示）翻转到“背面”（答案/解释）。
    *   **标记状态：** 每张卡片下方有三个按钮：“熟悉”、“待练”、“难记”。根据你的记忆情况点击，卡片上方的标签会相应变化，方便你后续筛选复习。
    *   **随机排序：** 点击右上角的“随机排序”按钮，可以打乱所有卡片的顺序，避免记忆定式。
4.  **手动添加：** 如果你有AI没有覆盖到的知识点，可以在左侧下方的“手动添加”区域，分别输入“正面内容”和“背面内容”，然后点击“加入卡片”，它会被添加到卡片列表的最前面。

**输出结果长什么样？**
右侧会以网格形式展示所有卡片。每张卡片是一个白色圆角矩形，默认显示“正面”内容。点击后，内容会替换为“背面”内容，模拟了实体闪卡的翻转效果。卡片上方会根据你的标记显示彩色标签（绿色“熟悉”、黄色“待练”、红色“难记”）。

**容易忽略的细节：**
*   **API Key 是必需的：** 不设置API Key，“生成闪卡”功能将无法工作。
*   **主题描述越具体越好：** 输入“古希腊哲学三大思想家”比输入“哲学”能生成更精准的卡片。
*   **手动添加的卡片会置顶：** 新加入的手动卡片会出现在列表最上方，方便你立即看到。
*   **标记状态不会自动保存：** 刷新页面后，所有的卡片状态（包括标记和顺序）都会重置。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块，它们协同工作：

1.  **控制与配置模块（左侧面板 & 顶部栏）**
    *   **职责：** 接收用户输入，控制整个应用的行为。
    *   **包含：**
        *   **主题输入区：** 接收核心指令（学什么）。
        *   **参数控制区：** 控制生成规模（生成多少）。
        *   **手动输入区：** 提供人工补充的入口。
        *   **全局配置区（顶部）：** 切换AI模型和设置API。
    *   **逻辑：** 用户在这里设定目标 → 点击“生成”按钮 → 触发后续流程。

2.  **AI处理模块（不可见，在代码中）**
    *   **职责：** 作为“大脑”，将用户的自然语言指令转化为结构化的数据。
    *   **逻辑：** 它接收来自控制模块的`主题`和`数量`，结合预设的**Prompt（指令模板）**，构造一个完整的请求发送给AI API。然后，它解析AI返回的JSON数据，转换成页面能理解的卡片对象数组。

3.  **展示与交互模块（右侧面板）**
    *   **职责：** 可视化呈现数据，并提供丰富的交互手段。
    *   **包含：**
        *   **卡片网格：** 展示所有卡片。
        *   **卡片单元：** 每个单元具备**翻转**（点击切换正反面）、**状态标记**（三个按钮）、**状态显示**（标签）的功能。
        *   **控制栏：** 提供“随机排序”等批量操作。
    *   **逻辑：** 接收来自AI处理模块或手动添加的卡片数据 → 渲染为可视化卡片 → 响应用户的翻转、标记等交互操作 → 更新卡片自身的状态数据。

**最值得学习的设计：**
**“数据状态与视图的绑定”**。这是本页面的精髓。注意，每张卡片在数据中都是一个包含 `front`（正面）、`back`（背面）、`show`（是否显示背面）、`tag`（标记）的对象。页面视图（HTML）通过 `x-text`、`x-show` 等指令直接绑定到这些数据上。当用户点击按钮时，只是修改了底层数据（例如 `card.show = !card.show`），而视图会自动、即时地更新以反映数据变化。这种设计让复杂的交互逻辑变得异常清晰和易于维护。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色：** 它是连接“用户模糊意图”和“AI结构化输出”的**翻译官**和**格式化工具**。它告诉AI不仅要理解主题，还要以非常特定的格式（JSON）来回应。
*   **解决什么问题：** 它主要解决的是“**生成问题**”。用户输入“学什么”，Prompt负责将其转化为“**如何生成一套符合规范的记忆卡片**”的具体任务。
*   **关键变量：**
    1.  `“${this.seed}”`：用户输入的学习主题，是生成内容的**核心依据**。
    2.  `“${this.count}”`：用户指定的生成数量，控制输出规模。
    3.  **系统指令 (`role: 'system'`)**: “你是记忆卡片设计师...” 这设定了AI的**角色和风格**，使其输出更符合教育辅助的语境。
    4.  **输出格式指令**: “格式为 JSON：...” 这是**最关键**的部分，它强制AI以程序能直接解析的格式输出，确保了前端代码能稳定可靠地处理结果。
*   **如果只改Prompt，不改代码：**
    *   **改变内容风格：** 将系统指令改为“你是严厉的历史老师”，生成的卡片语气可能会更严肃、带有考问性质。
    *   **改变卡片结构：** 在JSON格式中增加 `"hint"`（提示）或 `"example"`（例句）字段，AI会尝试填充这些新字段，但页面不会显示它们（因为代码没改）。
    *   **改变生成逻辑：** 将Prompt改为“生成...并按照难度排序”，AI可能会在JSON中调整顺序或添加难度字段。**这充分体现了Prompt作为“软逻辑”的控制力。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的AI工具：

**第一步：替换核心场景与数据（最安全）**
*   **目标：** 先做一个能跑通的“换皮”版本。
*   **操作：**
    1.  复制整个HTML文件。
    2.  修改标题、标语（如将“记忆闪卡实验室”改为“面试问题生成器”）。
    3.  修改左侧输入框的提示文字（如“学习主题”改为“职位名称”）。
    4.  修改Prompt中的描述（如“请根据主题‘${this.seed}’生成 ${this.count} 张学习闪卡”改为“请根据‘${this.seed}’这个职位，生成 ${this.count} 个常见的面试问题”）。
    4.  修改JSON字段名（如将 `"front"/"back"` 改为 `"question"/"answer"`），并同步修改代码中用到这些字段名的地方（主要在`generateCards`和`addManual`函数中）。

**第二步：调整输入与输出形式**
*   **目标：** 让工具更贴合你的新需求。
*   **操作：**
    1.  **增加输入项：** 在左侧面板添加新的输入框，例如“难度级别”（初级/高级），并将这个值加入到Prompt变量中。
    2.  **改变展示方式：** 修改右侧卡片的布局或交互。例如，将“翻转”交互改为“点击显示答案”，并始终将问题显示在顶部。

**第三步：重构核心逻辑与交互**
*   **目标：** 实现本质上的功能创新。
*   **操作：**
    1.  重新设计数据模型。例如，为卡片增加 `category`（分类）属性。
    2.  增加新的交互模块，如一个“筛选器”，让用户可以只显示某个分类或某个标记的卡片。
    3.  将状态保存到浏览器的本地存储（LocalStorage），这样刷新页面后数据不会丢失。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“复习模式”与进度追踪：**
    *   **操作：** 增加一个“开始复习”按钮，点击后进入全屏或专注模式，一次只显示一张卡片。记录每张卡片被标记为“熟悉”的次数，并设计一个简单的算法（如连续3次“熟悉”则视为掌握），将其移出当前复习队列。
    *   **价值：** 从静态卡片集升级为动态学习系统。

2.  **引入多轮对话与卡片优化：**
    *   **操作：** 为每张卡片添加一个“优化”或“解释更多”按钮。点击后，将这张卡片的内容发送给AI，并Prompt：“请为以下知识对提供更生动的例子或记忆口诀：”，然后将返回的内容更新到卡片的`back`字段或新增的`detail`字段中。
    *   **价值：** 让AI不仅是生成者，还是每张卡片的个性化辅导老师。

3.  **更换输出为表格或思维导图：**
    *   **操作：** 保留相同的生成逻辑，但修改Prompt，要求AI输出Markdown表格或思维导图语法（如Mermaid）格式的数据。然后在右侧，使用对应的渲染库（如`marked`、`mermaid`）来渲染结果，而不是渲染成卡片。
    *   **价值：** 同一套输入和AI逻辑，可以衍生出完全不同的可视化成果，适合不同学习风格的用户。

4.  **实现卡片导入/导出与分享：**
    *   **操作：** 增加两个按钮：“导出卡片组”和“导入卡片组”。导出功能将`this.cards`数组转换为JSON文件并下载。导入功能允许用户上传JSON文件，并将数据加载到`this.cards`中。
    *   **价值：** 打破了单次使用的限制，允许知识库的积累、备份和共享。

5.  **集成文本到语音（TTS）功能：**
    *   **操作：** 利用浏览器的`SpeechSynthesis` API。在每张卡片上添加一个“朗读”图标按钮，点击后自动朗读`front`或`back`的内容。
    *   **价值：** 满足听觉学习者的需求，提供多感官学习体验，特别适合语言学习场景。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合作为唯一的学习资料源：** AI生成的内容需要批判性接受。它可能遗漏重点、产生事实性错误或存在偏见。**务必将其与你信任的教材、课程结合使用。**
*   **不适合处理高度动态或实时性信息：** 例如，“生成今天加密货币市场的前5个新闻摘要”。因为它的知识可能不是最新的，且没有接入实时数据的能力。
*   **不适合进行复杂的逻辑推理或计算：** 虽然可以问“解释牛顿定律”，但不要期望它能替代专业的模拟软件或计算工具来解决具体的物理问题。
*   **不适合需要深度个性化互动的场景：** 例如，模拟一场心理咨询对话或进行复杂的职业规划。这类任务需要更长期、连贯、具有深度共情的交互，而本工具是一次性的、任务导向的生成。
*   **如果用户想做以上事情：** 应该寻找专门的**学习平台**、**实时数据API工具**、**专业软件**或寻求**真人专家**的帮助。本工具的最佳定位是“**学习过程中的高效生产与复习助手**”。
