# 屏幕时间管理工具 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你发现自己频繁刷手机、难以专注时，这个工具能帮你暂时“戒断”数字设备。比如：
- 需要专心学习或工作，但总忍不住看手机
- 想培养阅读、冥想等线下习惯
- 希望减少睡前屏幕时间，改善睡眠质量

**适合情况**：
- 短时间（15-60分钟）的专注需求
- 个人自我监督，不需要外部强制
- 想要可视化看到自己的专注成果

**不适合情况**：
- 需要长时间（数小时）的深度工作（它没有长时间提醒机制）
- 多人协作或需要他人监督的场景
- 对手机有强制物理隔离需求的情况

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 选择一个专注时长：15、30、45或60分钟

**用户通常会做哪几步操作？**
1. 进入页面，看到累计专注时间和历史记录
2. 在四个时间按钮中选择一个（默认30分钟）
3. 点击“开始专注”按钮
4. 进入全屏专注界面，看着倒计时和随机名言
5. 坚持到时间结束，或中途点击“放弃挑战”

**输出结果长什么样？**
- 成功完成后：弹出庆祝弹窗，显示“挑战成功！”
- 历史记录更新：新增一条记录（日期+时长）
- 累计时间增加：顶部统计数字会更新

**容易忽略的使用细节：**
- 所有数据都保存在你的浏览器本地（localStorage），清空浏览器数据会丢失记录
- 倒计时界面是全屏覆盖的，但可以随时放弃
- 名言是随机显示的，每次开始都可能不同
- 页面尝试使用“唤醒锁”防止手机息屏（需要浏览器支持）

## 【三】核心结构拆解（学习重点）

**页面由三个关键模块组成：**

1. **数据统计模块**（顶部绿色卡片）
   - **职责**：展示用户的历史成就（累计时间、挑战次数）
   - **数据流**：从本地存储读取 → 计算总和 → 格式化显示

2. **控制中心模块**（白色设置区域）
   - **职责**：让用户设置专注时长并启动挑战
   - **数据流**：用户选择时长 → 存储到变量 → 点击开始触发倒计时

3. **专注体验模块**（全屏绿色界面）
   - **职责**：提供沉浸式倒计时体验，防止用户中途退出
   - **数据流**：启动定时器 → 每秒更新显示 → 结束时保存数据

**输入 → 处理 → 输出 的逻辑链路：**
```
用户选择时长 → 点击开始 → 进入全屏界面 → 定时器倒计时
    ↓
倒计时结束 → 保存记录到本地 → 显示成功弹窗 → 更新统计数据
```

**最值得学习的设计：**
- **状态切换的流畅性**：使用 Alpine.js 的 `x-show` 和 `x-transition` 在“设置界面”和“专注界面”之间无缝切换
- **离线数据持久化**：完全依赖 `localStorage`，无需后端服务器
- **渐进增强**：尝试使用 `wakeLock` API（如果浏览器支持），但不强求

## 【四】Prompt / AI 逻辑是如何被设计的？

**注意**：这个页面**没有使用 AI 或 Prompt**，它完全是一个本地计时工具。但我们可以从中学到：

**如果我们要为它添加 AI 功能，Prompt 可以扮演什么角色？**
1. **生成个性化名言**：代替固定的名言数组，用 AI 根据用户时长、时间、心情生成鼓励语句
2. **分析专注模式**：根据历史数据，用 AI 建议最佳专注时长
3. **生成专注报告**：每周/每月用 AI 总结用户的专注习惯

**哪些信息会成为 Prompt 中的关键变量？**
- 用户选择的专注时长
- 当前时间（早晨/下午/晚上）
- 用户的历史成功率
- 本次是第几次尝试

**如果只改 Prompt，不改代码，会发生什么变化？**
- 用户体验会更个性化，但核心功能（计时）不变
- 名言会更贴合用户情境，增加坚持动力
- 可能需要调用外部 API，增加网络依赖

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 把“屏幕时间管理”改成“喝水提醒器”、“番茄钟”、“运动计时器”
- 修改颜色主题（把绿色改成蓝色、橙色等）
- 替换图标和文案（把叶子图标改成水杯、番茄、跑步图标）

**第二步：调整输入字段或逻辑**
- 增加更多时长选项（5分钟、90分钟等）
- 添加“自定义时长”输入框
- 增加“休息时间”设置（像真正的番茄钟那样）

**第三步：改变输出形式或展示方式**
- 把历史记录改成图表形式
- 添加成就系统（连续7天挑战成功等）
- 增加分享功能（分享到社交媒体）

**从哪里下手最安全？**
从 **修改文案和颜色** 开始，然后 **调整时长选项**，最后再考虑 **添加新功能**。这样每一步都能看到明显变化，且不容易出错。

## 【六】3–5 个可直接尝试的改造方向

1. **增加“自定义时长”输入框**
   - 在四个固定按钮下方添加一个数字输入框
   - 允许用户输入5-120分钟之间的任意值
   - 修改 `selectedDuration` 的绑定逻辑

2. **添加“专注类型”选择**
   - 让用户选择本次专注的目的：学习、工作、阅读、冥想
   - 根据不同类型显示不同的背景和名言
   - 在历史记录中记录类型，方便后续分析

3. **实现真正的番茄工作法**
   - 专注25分钟 → 休息5分钟 → 循环
   - 添加休息倒计时界面
   - 记录完成的番茄数量

4. **增加音效和通知**
   - 开始时播放轻柔的提示音
   - 结束时播放完成音效
   - 使用浏览器通知API（如果用户允许）

5. **添加每周报告功能**
   - 每周一显示上周的专注统计
   - 计算平均专注时长、最佳专注时段
   - 给出简单的改进建议

## 【七】这个网页不适合做什么？（边界提醒）

**明确局限性：**

1. **不是强制锁机工具**
   - 用户可以随时点击“放弃”或直接关闭网页
   - 如果需要强制隔离，应该使用专门的锁机App或物理工具

2. **没有社交或竞争功能**
   - 纯个人使用，无法和朋友一起挑战
   - 如果需要“专注自习室”效果，需要添加房间和用户系统

3. **数据仅限本地**
   - 换设备或清空浏览器后，所有记录消失
   - 如果需要多设备同步，需要添加账号系统和云端存储

4. **没有深度分析**
   - 只能看到总时间和最近记录
   - 如果需要习惯分析、趋势图表，需要更复杂的数据处理

**如果用户想做 X，应该换什么工具：**
- 想彻底锁住手机：用 Forest、番茄Todo等专业App
- 想多人一起专注：用专注吧、腾讯会议等协作工具
- 想深度分析习惯：用时间块、aTimeLogger等统计工具
- 想跨设备同步：需要开发带后端服务器的版本

**最后提醒**：这个网页的精髓在于 **极简主义** 和 **单一职责**。它只做好一件事：帮你暂时放下手机。在学习时，先理解这个核心，再考虑扩展。
