# Prompt 资产管理器 - 帮助文档

--------------------------------
## 【一】这个网页解决了什么问题？

想象一下，你是一个经常使用 AI 工具（如 ChatGPT、Claude）的创作者、营销人员或产品经理。你积累了很多精心设计的“提示词”（Prompt），比如“品牌分析模板”、“客服回复指南”、“产品文案生成器”。这些提示词散落在各个聊天记录、文档里，难以查找、管理和迭代。

这个网页就是一个**个人或团队的提示词知识库**。它帮你：
- **集中管理**：把所有提示词像文件一样整理在一个地方。
- **分类筛选**：按用途（如“营销”、“产品”）、状态（如“草稿”、“已发布”）快速找到需要的提示词。
- **版本控制**：每次修改都保留历史版本，可以随时回滚到旧版。
- **协作评审**：记录同事的评审意见，方便团队讨论优化。
- **AI 辅助创作**：直接调用 AI 来帮你生成或优化新的提示词。

**适合场景**：
- 个人：管理自己常用的、不断优化的提示词模板。
- 小团队：共享和评审团队内部的提示词资产，确保质量一致。
- 学习阶段：通过保存和对比不同版本的提示词，理解如何写出更好的提示。

**不适合场景**：
- 需要复杂权限管理（如公司级多部门协作）。
- 直接运行提示词并获取 AI 回复（它只管“词”本身，不管“对话”）。
- 管理非文本类资产（如图片、代码文件）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- **左侧列表**：显示你已有的所有提示词资产。
- **右侧编辑区**：当你选中或新建一个资产时，可以在这里填写或修改它的详细信息。
- **顶部工具栏**：提供搜索、筛选、导入/导出、以及打开“AI 生成助手”面板的按钮。

**用户通常会做哪几步操作？**
1.  **浏览与查找**：进入页面后，左侧会列出所有提示词。你可以通过顶部的搜索框，或左侧的“分类”、“状态”筛选器快速找到目标。
2.  **查看详情**：点击任意一个资产卡片，右侧会显示其完整信息，包括标题、描述、状态、分类和具体的提示词内容。
3.  **编辑与保存**：在右侧编辑区修改内容后，点击“保存更新”。系统会自动为你保留一个历史版本。
4.  **使用 AI 助手**：点击顶部“AI 生成助手”按钮，在下方面板中，你可以：
    - **生成**：描述你的需求（如“写一个小红书爆款标题生成器”），让 AI 直接生成提示词。
    - **改写**：基于当前编辑的提示词，让 AI 按照你的指令（如“让它更幽默”）进行优化。
    - **比较**：将 AI 生成的多个结果进行并排对比，选择最好的一个。
5.  **复制使用**：在任何地方看到满意的提示词，点击旁边的“复制”图标，即可粘贴到 ChatGPT 等工具中使用。

**输出结果长什么样？**
- 核心输出是**结构化的提示词数据**，保存在你的浏览器本地。
- 你可以将整个库**导出为 CSV 文件**备份或分享。
- AI 助手生成的结果会显示在面板中，你可以选择“插入”到编辑区，或“保存为新资产”。

**有哪些容易忽略的使用细节？**
- **数据存储在本地**：所有数据都保存在你电脑的浏览器本地存储中。换一台电脑或清空浏览器数据会丢失！务必定期使用“导出 CSV”或“一键备份”功能。
- **星标功能**：点击资产卡片右上角的星星，可以将其标记为“星标”，方便在“星标筛选”中快速找到最重要的资产。
- **版本回滚**：每次保存都会生成一个历史版本。在“版本回滚”区域，可以查看并回滚到任意旧版本。
- **评审备注**：在“评审备注区”可以记录他人或自己对该提示词的修改意见，适合团队协作场景。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为四个主要模块，各司其职：

**1. 导航与全局控制模块（顶部）**
- **职责**：提供全局操作入口和搜索功能。
- **包含**：标题、搜索框、“AI生成助手”开关、导入/导出/备份按钮、“新建资产”按钮。
- **逻辑**：用户在这里发起最高层级的操作（如新建、搜索），状态变化会驱动其他模块更新。

**2. 资产列表与筛选模块（左侧边栏）**
- **职责**：以卡片形式展示所有资产，并提供多维度的筛选和排序。
- **包含**：筛选器（星标、分类、状态、排序）、资产卡片列表。
- **逻辑**：
    - **输入**：用户设置的筛选条件 + 全部资产数据。
    - **处理**：根据条件实时过滤和排序资产列表。
    - **输出**：更新后的资产卡片列表。点击卡片会触发“资产详情模块”更新。

**3. 资产详情与编辑模块（右侧主区域）**
- **职责**：查看和编辑单个资产的完整信息，管理其版本和评审记录。
- **包含**：资产表单（标题、状态、分类、内容等）、“版本回滚”面板、“评审备注区”面板。
- **逻辑**：
    - **输入**：从列表模块接收选中的资产ID，或“新建”指令。
    - **处理**：根据ID加载资产数据到表单中，或准备空表单。保存时，将旧数据存入“版本”数组，用新数据更新资产。
    - **输出**：更新后的资产数据，持久化到本地存储。

**4. AI 辅助工坊模块（可折叠面板）**
- **职责**：集成 DeepSeek API，提供生成和优化提示词的能力。
- **包含**：API 密钥设置、模型选择、需求输入框、生成/改写按钮、结果列表与对比器。
- **逻辑**：
    - **输入**：用户的需求描述或改写指令 + 当前编辑的提示词内容。
    - **处理**：构造特定的 Prompt 调用 AI API，获取生成的文本。
    - **输出**：将 AI 返回的结果作为新的“资产”或“AI结果”保存，并展示给用户选择使用。

**最值得学习的设计：**
**“状态驱动的数据流与本地持久化”**。整个应用的核心数据（`assets` 数组）存储在 Vue 的 `data` 中。任何操作（增删改查、筛选）都只是修改这个数据状态。Vue 的响应式系统会自动将状态变化同步到 UI 显示。同时，每次数据变更后，都会调用 `persist()` 方法将整个状态保存到 `localStorage`。这种设计使得应用逻辑清晰，且具备了“离线可用”和“状态持久化”的能力，是构建此类轻量级工具应用的经典模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，Prompt 扮演着 **“元工具”** 的角色。它不直接解决外部问题，而是用来**生成或优化解决其他问题的工具（即新的 Prompt）**。

1.  **解决的是“生成问题”**：AI 助手模块的核心是让 AI 帮你“写 Prompt”。它解决的是“我不知道怎么描述这个任务”或“我的 Prompt 不够好”的问题。
2.  **Prompt 中的关键变量**：
    - **用户意图 (`ai.idea`)**：这是最关键的变量，例如“生成一份适合电商客服的投诉处理 Prompt”。它定义了要创造什么。
    - **上下文 (`form.content`)**：在“改写”功能中，当前的提示词内容作为上下文输入，让 AI 知道要在什么基础上修改。
    - **改写指令 (`ai.rewriteInstruction`)**：指导 AI 如何改写，例如“改写为更适合初级客服人员使用的版本”。
    - **模型与参数 (`ai.model`, `ai.temperature`)**：控制 AI 的创造性和风格。
3.  **如果只改 Prompt，不改代码，会发生什么？**
    代码中调用 AI API 时，会动态构造一个“系统提示词”（System Prompt），其核心是要求 AI 扮演一个“提示词工程师”。如果你修改这个内置的 Prompt（在 `generateWithAI` 方法里），比如从“你是一个提示词专家”改成“你是一个擅长写幽默文案的提示词专家”，那么 AI 生成的所有新提示词都会带有更强的幽默风格倾向。这是成本最低的改造方式。

## 【五】如何模仿它，做出你自己的版本？

如果你想做一个“个人食谱管理器”、“项目灵感库”或“代码片段收藏夹”，可以遵循以下安全路径：

**第一步：保持结构不变，替换核心概念**
- **目标**：先让一个最小版本跑起来。
- **操作**：
    1.  将代码中所有的“Prompt”、“资产”字眼替换成你的概念，如“食谱”、“菜谱”。
    2.  修改 `form` 对象中的字段。例如，将 `content` 改为 `ingredients`（食材）和 `steps`（步骤），`category` 改为 `cuisine`（菜系）。
    3.  修改 `statusOptions`，将“草稿、评审中”等改为“待尝试、已验证、家庭最爱”。
- **效果**：你将得到一个能管理“食谱”的库，功能完全一样。

**第二步：调整 AI 助手的功能（可选）**
- 如果你的新应用不需要 AI，可以直接隐藏或移除整个 `AI 生成助手` 面板。
- 如果需要 AI，则修改 `generateWithAI` 方法中的系统 Prompt。例如，让 AI 根据现有食材生成新菜谱，或优化烹饪步骤。

**第三步：改变展示与交互形式**
- 这是个性化最强的部分。例如，对于食谱，你可能想在列表卡片上展示图片。
- **操作**：在资产数据对象中增加 `imageUrl` 字段，然后在列表和详情模块的模板中，使用 `<img>` 标签来展示。
- **注意**：先从修改 Vue 模板 (`<div id="app">` 内的 HTML) 开始，这是最直观且安全的。

**从哪里下手最安全？**
从 **`data` 中的 `form` 对象和 `statusOptions` 数组** 开始修改。这定义了你的“资产”长什么样。然后去模板里找到对应的显示和输入位置进行修改。这样你能立刻看到界面变化，而不会破坏核心逻辑。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“标签”系统，替代或补充“分类”**
    - **操作**：在 `form` 对象中增加 `tags: []` 数组字段。在编辑界面，将输入分类的单行文本框，改为一个可以输入多个标签的组件（输入后按回车生成标签）。在筛选区，增加按标签筛选的功能。
    - **价值**：一个提示词可以属于“营销”和“文案”多个标签，检索更灵活。

2.  **更换或增加 AI 模型提供商**
    - **操作**：在 AI 面板的模型选择下拉框中，增加 OpenAI (GPT)、Claude 或国内其他大模型的选项。修改 `generateWithAI` 方法中的 API 调用地址和参数格式。
    - **价值**：利用不同模型的特长，比如用 GPT-4 生成更复杂的逻辑，用 Claude 生成更人性化的文案。

3.  **拆分为“库浏览”与“编辑预览”双页面模式**
    - **操作**：将当前单页面应用拆解。首页只保留左侧列表和顶部搜索，点击资产后跳转到一个新的 `edit.html?id=XXX` 页面进行编辑和查看详情。
    - **价值**：更符合传统认知，URL 可分享，并且可以利用浏览器前进/后退导航。

4.  **优化交互：增加批量操作与快捷操作**
    - **操作**：在列表卡片前增加复选框，在顶部增加“批量删除”、“批量修改分类”按钮。为常用操作（如复制内容）增加键盘快捷键（如 Ctrl+C）。
    - **价值**：提升管理大量资产时的效率。

5.  **增加“使用统计”与“效果反馈”**
    - **操作**：为每个资产增加 `usageCount`（使用次数）字段和 `rating`（评分）字段。每次点击“一键复制”时增加计数。在详情页增加一个简单的五星评分组件。
    - **价值**：帮你识别哪些是最常用、最好用的提示词，让知识库越用越智能。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合作为在线协作工具**：它的数据存储在每个人的浏览器本地，没有服务器同步。如果团队需要实时共同编辑，应该使用像 Notion、飞书文档或自建带有后端数据库的 Web 应用。
2.  **不适合直接执行和测试 Prompt**：它不能直接连接 AI 并显示对话结果。如果你需要边写边测试 Prompt 的效果，应该使用 ChatGPT Playground、Claude Console 或 Poe 等专门平台。本工具更适合管理“最终确定版”或“待测试”的 Prompt 模板。
3.  **不适合管理超大规模（数千条）资产**：所有数据一次性加载到内存，并用 Vue 实时过滤排序。当资产数量极大时，页面性能会下降。此时需要后端进行分页、索引和搜索。
4.  **不适合需要严格数据安全性的场景**：`localStorage` 中的数据相对容易被用户或浏览器插件访问。如果管理的提示词是公司核心机密，此工具不适合。

**总结**：这是一个**极佳的个人生产力工具和前端学习项目**。它清晰地展示了如何用现代 Web 技术（Vue 3、组合式 API、Tailwind CSS）构建一个功能完整、体验良好的单页面应用。通过拆解和模仿它，你可以掌握一类应用的核心构建思路，并将其灵活运用于你自己的创意中。
