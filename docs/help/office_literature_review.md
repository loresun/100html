# AI 文献综述生成器 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你是一名研究生或科研人员，刚刚下载了一篇几十页的英文论文。你需要快速理解它的核心内容，并为自己的研究撰写文献综述部分。传统方法需要你逐字阅读、做笔记、归纳总结，这个过程可能需要数小时甚至数天。

这个网页就是你的“学术速读助手”。它能在几分钟内：
- 为你提炼论文的核心框架
- 生成结构化的综述报告
- 提供批判性思考角度

**适合场景：**
- 快速了解陌生领域论文的核心贡献
- 为文献综述收集素材和观点
- 在组会前快速准备论文汇报
- 对比多篇论文的研究方法

**不适合场景：**
- 需要深度理解复杂数学推导或实验细节
- 法律、医学等对准确性要求极高的专业文献
- 作为最终学术成果的直接引用（仍需人工校验）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 论文全文文本（支持直接粘贴或上传.txt/.md文件）

**典型操作步骤：**
1. **准备论文**：找到你想分析的论文，复制全文内容
2. **粘贴/上传**：将内容粘贴到左侧大文本框，或点击“上传 .txt/.md”按钮
3. **配置API**：首次使用需点击右上角设置图标，输入DeepSeek API Key
4. **选择模型**：在右上角选择“DeepSeek V3”（快速）或“DeepSeek R1”（深度思考）
5. **点击生成**：点击“生成结构化综述”按钮
6. **查看结果**：右侧区域会逐步显示生成的综述

**输出结果长什么样？**
生成的综述会以“学术论文”的格式呈现，包含：
- 标题和摘要
- 研究背景与问题
- 方法论描述
- 主要结论（可能包含数据）
- 批判性分析（优点与不足）
- 总结评价

**容易忽略的细节：**
1. **文件格式**：只支持纯文本(.txt)和Markdown(.md)，不支持PDF、Word
2. **API配置**：第一次使用时必须配置API Key，否则无法生成
3. **模型选择**：R1模型会显示“思考过程”，但生成速度较慢
4. **内容长度**：过长的论文可能被截断（取决于API限制）
5. **复制功能**：生成后可以点击右上角“复制”按钮保存结果

## 【三】核心结构拆解（学习重点）

这个页面采用了经典的“输入-处理-输出”三明治结构：

### 模块1：导航与控制面板（顶部）
- **职责**：提供全局控制与状态显示
- 包含：返回链接、模型选择器、设置入口
- **关键设计**：将技术配置（API Key、模型）与核心功能分离，保持界面简洁

### 模块2：输入区（左侧）
- **职责**：接收用户提供的原始论文内容
- 包含：文本输入框、文件上传按钮、生成按钮
- **输入处理流程**：
  1. 用户粘贴文本 → 直接存入变量
  2. 用户上传文件 → 读取文件内容 → 存入变量
  3. 点击生成 → 检查API配置 → 发送请求

### 模块3：输出区（右侧）
- **职责**：展示AI生成的综述结果
- 包含：思考过程显示区、综述内容区、复制功能
- **输出展示流程**：
  1. 流式接收AI响应 → 实时显示
  2. 区分“思考过程”（R1模型）和“最终答案”
  3. 将Markdown转换为美观的HTML格式

### 模块4：设置弹窗（浮动层）
- **职责**：管理API配置
- 设计理念：按需出现，不干扰主流程

**最值得学习的设计：**
**流式响应与状态分离**。页面在等待AI响应时：
- 显示加载动画
- 实时显示“思考过程”（如果使用R1模型）
- 逐步渲染最终结果
- 保持界面可交互（如可复制已生成内容）

这种设计让用户感知到“进度”，而不是面对一个空白的等待界面。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt的角色：**
在这个页面中，Prompt扮演“学术导师”的角色。它告诉AI：
1. 你的身份是什么（学术研究专家）
2. 你要完成什么任务（撰写文献综述）
3. 输出的格式要求（7个固定部分，Markdown格式）

**解决的是“理解问题”还是“生成问题”？**
主要是**结构化生成问题**。AI已经能“理解”论文内容，但需要被引导：
- 关注哪些重点（方法论、结论、创新点）
- 以什么顺序呈现
- 采用什么语气（学术、客观、批判性）

**Prompt中的关键变量：**
1. **角色指令**：“你是一个学术研究专家”
2. **任务描述**：“阅读用户提供的论文文本，撰写...文献综述”
3. **结构约束**：明确的7个部分标题
4. **格式要求**：“使用 Markdown 格式输出”

**如果只改Prompt，不改代码：**
- 改为“你是一个投资分析师” → 输出会侧重商业价值而非学术价值
- 增加“用中文输出” → 所有内容变为中文
- 修改结构为“摘要、方法、结果、讨论” → 输出格式完全改变
- 增加“不超过500字” → 内容会大幅精简

**提示**：Prompt是控制AI行为的“遥控器”，调整它比改代码更安全、更快速。

## 【五】如何模仿它，做出你自己的版本？

### 安全模仿路径（从易到难）：

**第一步：保持结构不变，替换使用场景**
- 目标：创建一个“新闻摘要生成器”
- 修改：
  1. 改标题：“文献综述生成器” → “新闻摘要器”
  2. 改提示语：“上传论文” → “粘贴新闻文章”
  3. 改Prompt：将“学术研究专家”改为“新闻编辑”，输出结构改为“标题、核心事件、各方观点、影响分析”

**第二步：调整输入字段或Prompt**
- 目标：增加用户控制
- 修改：
  1. 在输入区增加“摘要长度”选择框（短/中/长）
  2. 在Prompt中加入变量：`请生成${length}版本的摘要`
  3. 增加“语言风格”选择（正式/通俗/幽默）

**第三步：改变输出形式或展示方式**
- 目标：优化阅读体验
- 修改：
  1. 将右侧区域改为“要点卡片”式布局
  2. 增加“导出为PDF”功能
  3. 添加“高亮关键句”功能

**从哪里下手最安全？**
从**修改Prompt和文字**开始。这是零风险、即时见效的改动。例如，先把所有“论文”改为“文章”，所有“综述”改为“摘要”，看看效果如何。

- **效果**：在平板、手机上也能顺畅使用

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性说明：

1. **不是精准的文献分析工具**
   - **问题**：AI可能误解专业术语、忽略重要细节
   - **边界**：生成的综述需要人工校验，不能直接作为学术引用
   - **替代方案**：使用EndNote、Zotero等专业文献管理软件进行精确管理

2. **不适合处理非文本内容**
   - **问题**：无法解析论文中的图表、公式、图像
   - **边界**：如果论文核心贡献在图表中，本工具会丢失关键信息
   - **替代方案**：人工阅读+图表分析，或使用支持多模态的AI工具

3. **不是实时翻译工具**
   - **问题**：虽然能处理英文论文，但翻译质量不稳定
   - **边界**：需要精准翻译时（如法律条款），不应依赖此工具
   - **替代方案**：使用DeepL、Google翻译等专业翻译工具

4. **无法替代深度阅读**
   - **问题**：只能提供“概览”，无法传授领域专业知识
   - **边界**：要真正掌握一篇论文，仍需投入时间精读
   - **正确用法**：作为“第一遍快速阅读”的辅助，而非“唯一阅读”

5. **依赖外部API，有成本限制**
   - **问题**：需要API Key，长论文可能消耗大量token
   - **边界**：不适合批量处理数百篇论文
   - **替代方案**：对于大规模文献分析，考虑本地部署的开源模型

### 最后提醒：
这个工具的最佳定位是“学术研究的起点”，而不是“终点”。它帮你快速筛选、初步理解，但真正的学术工作——批判性思考、创新性连接、严谨性验证——仍然需要你亲自完成。

**记住**：AI是你研究路上的“导航仪”，但方向盘始终在你手中。
