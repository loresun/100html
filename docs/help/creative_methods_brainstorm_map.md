# 头脑风暴 · 思维导图工具 - 学习与改造指南

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你正面临一个需要创意或需要拆解的复杂任务。比如：
*   **产品经理** 在想：“如何设计一个让用户更愿意分享内容的功能？”
*   **学生** 在思考：“如何高效地准备一场重要的演讲？”
*   **创业者** 在琢磨：“我的新产品有哪些潜在的市场推广渠道？”

你脑子里可能有很多零散的想法，但缺乏一个清晰的结构将它们组织起来，也担心自己思考得不够全面。这个网页就像一个**数字化的“白板伙伴”**，它在你输入一个核心主题后，利用 AI 快速帮你**发散思维、梳理逻辑、并提炼出可执行的行动点**，最终以一张清晰的思维导图形式呈现。

**它适合在以下情况使用：**
*   **创意启动阶段**：需要快速产生大量新点子时。
*   **问题拆解**：面对复杂问题，需要理清头绪和不同解决维度时。
*   **方案优化**：对已有计划进行查漏补缺，寻找改进空间时。
*   **个人或小组的快速脑暴**：作为讨论的起点和框架。

**它不适合以下情况：**
*   **需要深度、严谨的行业分析报告**（它提供的是启发性的框架，而非详实的数据）。
*   **处理高度专业化或需要实时数据的问题**（如法律条文分析、股票预测）。
*   **作为最终交付物**（它生成的导图更适合作为你自己进一步深化和创作的蓝图）。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：点击右上角“API 设置”按钮，填入你的 AI 模型 API Key（例如 DeepSeek 的 Key）。保存后即可使用。
2.  **输入你的想法**：
    *   **选择模式**：根据你的目的，选择“探索新点子”、“优化已有方案”或“解决具体问题”。
    *   **填写主题**：在“主题/问题”框中，用一句话描述你的核心议题。
    *   **补充信息（可选）**：在“已有信息”框中，可以写下任何背景、限制条件或已知想法。
3.  **生成导图**：点击“生成思维导图”按钮，等待几秒钟。
4.  **查看与使用结果**：
    *   页面右侧会生成一张思维导图，**中心**是你的主题，周围是几个**分支**（每个分支包含几个要点）。
    *   下方会有一个 **“行动摘要”** ，用更连贯的文字总结关键步骤。
    *   如果对结果满意，可以点击“导出为图片”保存下来。

**容易忽略的细节：**
*   **模式选择很重要**：它决定了 AI 思考的侧重点，选对了模式，结果会更贴合你的需求。
*   **“已有信息”是强力催化剂**：哪怕只写一两句关键限制（如“预算有限”、“目标用户是青少年”），都能让 AI 生成更具体、更可行的点子。
*   **结果可以多次生成**：对同一个主题，改变模式或补充信息，多次点击生成，可以获得不同角度的导图，激发更多灵感。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个职责明确的模块：

1.  **控制面板模块（左侧）**
    *   **职责**：接收用户的所有输入和指令。它是整个应用的“调度中心”。
    *   **包含**：模式选择器、主题输入框、上下文输入框、生成按钮。
    *   **逻辑**：用户在此配置任务 → 点击按钮 → 触发 `generate` 函数。

2.  **渲染展示模块（右侧）**
    *   **职责**：将 AI 返回的结构化数据，以美观、易读的视觉形式呈现出来。
    *   **包含**：中心主题标签、分支卡片（标题+要点列表）、行动摘要区域。
    *   **逻辑**：接收 `result` 数据对象 → 通过 Alpine.js 的模板循环 (`x-for`) 动态生成 HTML → 使用 Tailwind CSS 进行样式渲染。

3.  **AI 引擎模块（不可见，在代码中）**
    *   **职责**：作为“大脑”，处理用户输入，调用外部 AI API，并返回结构化思考结果。
    *   **核心函数**：`callModel` 和 `generate`。
    *   **逻辑链路**：
        **输入**（模式+主题+上下文）→ **处理**（拼接成特定的 Prompt 发送给 AI）→ **输出**（解析 AI 返回的 JSON，更新 `result` 对象）。

**最值得学习的设计：**
**“结构化 Prompt + 标准化 JSON 输出”的管道设计。** 它没有让 AI 自由发挥生成一段文字，而是通过精心设计的 Prompt，要求 AI 严格按照指定的 JSON 格式输出。这使得前端代码可以稳定地预测和解析结果，实现了**灵活的 AI 思维与确定性的程序处理之间的完美衔接**。这是构建可靠 AI 应用的关键模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt 的角色**：它是给 AI 的“工作说明书”和“输出格式模板”。它告诉 AI 要扮演什么角色、基于什么信息、完成什么任务、以及**必须用什么格式**来交付结果。
*   **解决的问题**：它同时解决了“理解问题”和“生成问题”。
    *   **理解**：通过 `systemPrompt` 设定 AI 角色（创意导师），通过 `userPrompt` 传递用户的具体需求、模式和背景信息。
    *   **生成**：通过 `userPrompt` 中严格的 JSON 格式描述，约束 AI 的生成内容，确保其输出能被程序方便地使用。
*   **关键变量**：
    *   `主题`：用户输入的核心问题。
    *   `补充信息`：用户提供的上下文，是让结果更具针对性的关键。
    *   `需求`：根据“模式”选择动态映射的提示语（`MODE_HINTS`），引导 AI 的思考方向。
*   **如果只改 Prompt**：整个应用的外观和交互完全不变，但 AI 生成的内容会发生本质变化。
    *   例如，把 Prompt 中的“创意导师”改成“风险评估专家”，把输出格式改成 `{“风险点”: [], “应对策略”: []}`，那么这个工具就从“头脑风暴”变成了“风险分析”工具。这展示了 **Prompt 是定义 AI 应用功能的“灵魂”**。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个安全的路径，逐步打造你的专属工具：

1.  **第一步：复制骨架，替换场景**
    *   将整个 HTML 文件复制一份，重命名。
    *   修改标题、页面描述，将“头脑风暴”这个概念替换成你的目标场景，例如“**个人周报生成器**”、“**旅行规划助手**”或“**辩论观点梳理**”。**此时不要动核心代码和 Prompt。**

2.  **第二步：调整输入字段**
    *   在左侧控制面板，修改或增加输入框。例如，对于“旅行规划”，你可以将“模式”下拉框换成“旅行类型”（如“背包客”、“家庭游”、“奢华度假”），并增加“出行天数”、“预算范围”等输入字段。
    *   在 JavaScript 的 `brainstormApp()` 函数里，为这些新字段创建对应的数据变量（如 `travelType`, `days`, `budget`）。

3.  **第三步：重写核心 Prompt**
    *   这是最关键的一步。根据你的新场景和新输入字段，重新设计 `systemPrompt` 和 `userPrompt`。
    *   重点设计输出的 JSON 结构。例如，旅行规划的输出可能是 `{"destination": "城市名", "itinerary": [{"day": 1, "morning": "...", "afternoon": "..."}], "budgetBreakdown": {...}}`。
    *   在 `generate` 函数中，用你的新变量替换旧的 `topic`, `context`, `MODE_HINTS[this.mode]`。

4.  **第四步：改造输出渲染**
    *   根据你新设计的 JSON 输出结构，修改右侧渲染模块的 HTML 模板。
    *   使用 Alpine.js 的 `x-for` 循环来遍历你的新数据结构（如 `itinerary`），并将内容展示在页面上。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“灵感种子”功能**：在输入区增加一个按钮，点击后随机显示一个创意挑战或问题模板（如“如何用一句话让这个产品听起来很有趣？”），并将其自动填入主题框，帮助用户克服“开头难”。
2.  **实现“分支编辑”**：让生成的思维导图不再是只读的。为每个分支和要点添加一个“编辑”图标，点击后可以就地修改文本内容，修改后甚至可以有一个“基于此重新生成”的按钮，让 AI 在你修改的基础上继续发散。
3.  **切换 AI 模型风格**：在 API 设置中，除了切换模型提供商，可以增加一个“思考风格”选项，如“天马行空”、“逻辑严谨”、“务实高效”。这可以通过在 `systemPrompt` 中附加不同的描述来实现（例如，“你是一个逻辑极其严谨的架构师”）。
4.  **增加历史记录**：使用 `localStorage` 保存用户最近生成的 5-10 个思维导图主题和结果摘要。在页面底部或侧边栏增加一个“历史记录”面板，方便用户回顾和再次编辑。
5.  **优化导出功能**：除了导出图片，可以增加“导出为 Markdown 大纲”或“导出为项目任务列表”的功能。这只需要编写一个函数，将 `result` 对象转换成纯文本或特定格式的字符串，然后提供下载。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精确的决策分析**：它提供的思路是启发性和框架性的，并未经过严格的验证或数据支撑。**不要**完全依赖它来做出重大的商业或投资决策。
*   **不适合替代专业的创作工具**：它生成的思维导图在美观度和定制化上无法与 XMind、MindNode 等专业软件相比。它的核心价值在于 **“快速启动”和“结构化灵感”**，而非“精美制图”。
*   **不适合处理需要保密的信息**：你输入的主题和上下文信息会被发送到第三方 AI 服务商（如 DeepSeek、OpenAI）的服务器。**切勿**输入任何敏感、机密或个人隐私数据。
*   **如果用户需要的是**：基于大量数据的分析报告、代码编写、精确的翻译或事实性问答，那么应该转向专门的 AI 对话工具（如 ChatGPT 本身）、数据分析平台或搜索引擎。本工具的核心定位始终是 **“创造性思维的结构化辅助”**。
