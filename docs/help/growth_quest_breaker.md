# 任务冒险拆解器 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页解决了一个普遍存在的“启动困难”问题：当你面对一个庞大、复杂或枯燥的目标时（比如“学会一门新技能”、“完成一个大项目”），常常会因为不知从何下手、缺乏动力而感到焦虑和拖延。

**使用场景举例：**
- **学生**：面对“完成毕业论文”这个艰巨任务，感到无从下手，需要清晰的步骤和动力。
- **职场人**：想“启动一个副业项目”，但日常工作繁忙，需要将目标拆解成下班后可以执行的小块。
- **自我提升者**：计划“健身减肥”或“学习吉他”，但三分钟热度后容易放弃，需要一种持续激励的方式。

**它适合在什么情况下使用？**
- 当你有一个明确但感觉“庞大”的目标时。
- 当你需要将抽象目标转化为具体、可执行的步骤时。
- 当你缺乏动力，希望用一种有趣、游戏化的方式看待任务时。
- 当你需要为个人项目或学习计划做初步规划时。

**它不适合什么情况？**
- **紧急任务**：需要立刻执行的、时间以小时计的任务。
- **团队协作项目**：它生成的是个人视角的“冒险”，不涉及任务分配和团队沟通。
- **高度专业化或已有成熟流程的任务**（如公司的标准操作流程）。
- **情感或创意类目标**（如“变得更快乐”、“写一首诗”），虽然可以尝试，但效果可能不如结构化目标好。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **核心任务**：一个文本框让你写下任务名称（如“学会Python编程”），一个多行文本框让你描述详情、当前状况和困难。
2.  **游戏化设置**：几个下拉菜单和按钮，让你选择“角色职业”、“难度偏好”、“目标周期”，并决定是否包含“Boss关卡”和“阶段奖励”。

**用户通常会做哪几步操作？**
1.  **描述任务**：在左侧输入区写下你想完成的目标。如果没灵感，可以点击下方的“快速示例”按钮（如“学吉他”、“减肥健身”）自动填充。
2.  **定制冒险**：在“游戏化设置”区域，像创建游戏角色一样选择你的风格。比如，选“法师”代表你喜欢策略规划，选“困难”模式代表你想要高挑战。
3.  **开启冒险**：点击页面中央大大的 **“🚀 开启冒险！”** 按钮。
4.  **查看结果**：等待几秒钟，右侧区域就会生成一份详细的“游戏化任务清单”。

**输出结果长什么样？**
生成的结果是一份**结构清晰的Markdown文档**，在网页上会以漂亮的格式渲染出来，通常包含：
- **冒险概览**：总周期、终极目标、等级提升。
- **冒险地图**：将大任务拆分成多个“章节”，每个章节下是具体的“怪物”（子任务），配有难度星级、经验值和预计时间。
- **Boss战**：（如果勾选）将关键里程碑设计成需要攻略的Boss。
- **装备推荐**：完成任务所需的知识、工具和注意事项。
- **奖励设计**：（如果勾选）完成不同阶段后给自己的小奖励建议。
- **冒险锦囊**：实用的小贴士和避坑指南。

**有哪些容易忽略的使用细节？**
1.  **API密钥**：第一次使用或点击生成按钮时，会弹窗要求输入DeepSeek API密钥。你需要先去[DeepSeek平台](https://platform.deepseek.com/api_keys)注册并获取一个Key（通常是`sk-`开头的一串字符），粘贴进去并保存。
2.  **模型选择**：页面右上角或设置中可以选择“⚡ V3”（快速）或“🧠 R1”（深度推理）。R1模型会多一个“AI思考过程”的折叠区域，生成方案可能更精细，但速度稍慢。
3.  **描述越详细越好**：在“详细描述”里多写你当前的状况、拥有的资源、遇到的具体困难，AI能据此给出更贴切的建议。
4.  **导出功能**：生成结果后，右上角有“复制”和“导出”按钮。**“导出”会将结果保存为`.md`格式的Markdown文件**，方便你导入到Notion、Obsidian等笔记软件中持续跟踪。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块，像一个流水线工厂：

**1. 输入与配置模块（左侧面板）**
*   **职责**：收集用户原始意图和个性化偏好。它是整个应用的“原料采集区”。
*   **组成**：
    *   **任务描述区**：获取核心目标（`taskName`, `taskDesc`）。
    *   **游戏化设置区**：将用户偏好转化为AI能理解的参数（`playerClass`, `difficulty`等）。这里的每个选择都会影响后续AI生成内容的语气和结构。
    *   **行动按钮**：触发整个流程的“开关”（`generateQuest`函数）。

**2. AI处理引擎（核心逻辑，不可见）**
*   **职责**：这是网页的“大脑”。它不直接显示在页面上，但负责最重要的转换工作。
*   **工作流程**：
    1.  **组装Prompt**：将左侧模块收集的所有数据，按照固定格式，拼接成一段给AI的“指令”（包含`systemPrompt`和`userPrompt`）。
    2.  **调用API**：将组装好的Prompt发送给DeepSeek的AI模型。
    3.  **流式处理响应**：一边接收AI返回的文字，一边实时显示在页面上，提升用户体验。

**3. 输出与展示模块（右侧面板）**
*   **职责**：将AI生成的原始文本，转化为美观、易读的格式呈现给用户。它是“产品包装区”。
*   **组成**：
    *   **状态展示器**：显示“空状态”、“加载中”、“错误”等不同情况下的界面。
    *   **Markdown渲染器**：利用`marked`库，将AI返回的Markdown文本（带`#`标题、`-`列表等）转换成带样式的HTML。
    *   **交互工具**：提供“复制”、“导出”等实用功能，让结果能被带走和使用。

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入任务 → 选择游戏化参数 → 点击生成 → 前端组装Prompt → 调用AI API → 流式接收结果 → Markdown渲染 → 美观展示 → 用户复制/导出
```

**哪一部分是“这个网页最值得学习的设计”？**
**Prompt的模块化设计**是整个网页的灵魂。它没有把复杂的逻辑写在代码里，而是通过精心设计的`systemPrompt`（系统指令）来“教”AI如何工作。`systemPrompt`里定义了游戏化的**设计原则**（如怪物化、关卡制）和**输出格式**（Markdown模板）。当用户点击生成时，程序只是把用户输入（`userPrompt`）和这个模板结合起来发给AI。这意味着，**如果你想改变整个游戏化的风格或结构，大部分时候只需要修改`systemPrompt`这个字符串，而不需要改动复杂的JavaScript代码**。这是一种非常高效、清晰的“AI应用”架构思想。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt在这里扮演着**产品经理 + 内容总监**的角色。它不直接产生代码逻辑，而是**定义了一套内容生产的规则和模板**，指挥AI按照特定的风格、结构和原则来生成内容。

**它解决的是“理解问题”还是“生成问题”？**
主要解决的是**“结构化生成”问题**。AI本身理解“学吉他”是什么意思，但它不知道你需要一个“游戏化任务清单”。Prompt通过详细的指令（设计原则、输出格式），将AI的通用知识**约束和引导**到一个非常具体、有用的输出形式上。

**哪些信息是 Prompt 中的关键变量？**
Prompt由两部分组成，关键变量都体现在`userPrompt`中：
1.  **`systemPrompt`（固定模板）**：包含不变的规则和格式要求。
2.  **`userPrompt`（动态填充）**：包含所有来自表单的变量：
    *   `任务名称`和`任务描述`：AI生成内容的核心依据。
    *   `我的角色`：根据`playerClass`映射成的描述文本（如“战士型玩家…”），影响AI的建议风格。
    *   `难度偏好`和`目标周期`：让AI调整任务拆解的粒度和时间估算。
    *   `额外设置`（Boss/奖励）：控制最终输出是否包含`### 🐉 Boss 战`和`## 🎁 奖励设计`这两个章节。

**如果只改 Prompt，不改代码，会发生什么变化？**
变化会非常直接和巨大，因为输出内容完全由Prompt驱动：
*   **改变风格**：把`systemPrompt`里的“游戏化专家”改成“军事化指挥官”，把“怪物”、“经验值”改成“敌军据点”、“战功”，整个输出的比喻体系就全变了。
*   **调整结构**：在`systemPrompt`的输出格式里增加一个“## 📈 进度追踪表”章节，AI生成的结果里就会多出这个部分。
*   **细化要求**：在`systemPrompt`的设计原则里加入“**每个子任务必须包含一个5字以内的行动动词**”，AI生成的子任务就会变得更可执行（如“搜索10个教程”、“练习C和弦”）。
*   **更换领域**：保持结构不变，但把`systemPrompt`里的“游戏化学习”背景换成“敏捷项目管理”，它就能生成类似“用户故事地图”的产物。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“模仿路径”，从最安全、最简单的改动开始：

**第一步：替换“皮肤”和场景（最安全）**
*   **目标**：在不改动核心逻辑的情况下，做一个新主题的应用。
*   **操作**：
    1.  修改`<title>`和页面中的标题文字，例如改成“**学习路径规划师**”。
    2.  修改所有游戏化术语：将“怪物”改为“知识点”，“经验值”改为“技能点”，“Boss”改为“阶段测评”，“冒险”改为“学习旅程”。
    3.  调整配色方案（修改`:root`中的CSS变量），比如从紫色奇幻风改为绿色清新风。
*   **效果**：你会立刻得到一个“学习路径规划”工具，而所有代码和Prompt逻辑都无需变动。

**第二步：调整输入字段和Prompt（核心改造）**
*   **目标**：让工具适应更具体的需求。
*   **操作**：
    1.  在表单中增加新字段。例如，增加一个“**已有基础**”下拉菜单（选项：零基础、有基础、熟练）。
    2.  在`fillExample`函数中为示例数据增加这个字段。
    3.  在`userPrompt`的组装部分，将这个新字段的值也拼接进去，告诉AI。
    4.  微调`systemPrompt`，在**设计原则**里加一句：“请根据用户的‘已有基础’调整起点难度和推荐资源”。
*   **效果**：你的工具现在能根据用户的基础提供更个性化的计划。

**第三步：改变输出形式或交互（进阶玩法）**
*   **目标**：让结果不仅仅是文本，而是可以交互的。
*   **操作**：
    1.  不再直接用`marked.parse()`渲染整个结果。
    2.  写一个函数来解析AI返回的Markdown（尤其是表格部分），将每个“子任务”解析成一个JavaScript对象。
    3.  用`v-for`循环将这些对象渲染成可勾选的待办事项列表`<input type="checkbox">`。
    4.  添加一个“进度统计”功能，勾选任务时自动计算获得的“总经验值”。
*   **效果**：你的工具从一个“计划生成器”变成了一个“可交互的任务追踪器”，实用性大增。

**从哪里下手是最安全的？**
从**第一步**开始是最安全的，因为它只涉及HTML文本和CSS样式的修改，完全不会影响JavaScript逻辑和AI交互。你能立即看到视觉变化，建立信心。之后再进行第二步的Prompt调整，因为Prompt修改的风险也很低，大不了改回来。最后再挑战第三步的交互逻辑修改。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让计划更精准**
    *   **操作**：在表单中添加“每日可用时间（小时）”和“最希望提升的3个能力”多选框。
    *   **修改Prompt**：在`userPrompt`中告诉AI这些信息，并在`systemPrompt`中要求AI根据“每日可用时间”来分配每日任务量，并根据“希望提升的能力”侧重推荐相关资源。
    *   **效果**：从通用计划升级为高度个性化的定制方案。

2.  **切换或扩展AI模型后端**
    *   **操作**：在`apiConfig`和设置弹窗中增加对OpenAI（GPT）、Claude或国内大模型（如通义千问、智谱）的支持。
    *   **关键修改**：修改`generateQuest`函数中的`fetch`请求URL和`headers`，根据用户选择的模型适配不同的API格式。
    *   **效果**：用户可以选择自己拥有密钥的、或效果更喜欢的模型，工具适用性更广。

3.  **将单页应用拆解为多步骤向导**
    *   **操作**：将当前页面拆成两个页面（或同一个页面内用`v-if`切换的多个步骤）。
    *   **步骤一**：仅收集核心任务和目标。
    *   **步骤二**：展示AI生成的初步大纲，让用户调整优先级或合并/拆分任务。
    *   **步骤三**：基于调整后的大纲，再让AI生成最终详细计划。
    *   **效果**：引入“人工审核”环节，让生成的结果更可控、更符合用户预期。

4.  **优化体验：增加历史记录和方案保存**
    *   **操作**：使用`localStorage`在用户本地浏览器保存每次生成的任务名称、时间和关键参数。
    *   **在首页**：增加一个“历史冒险”侧边栏，点击可以快速载入过去的方案。
    *   **关键修改**：在生成成功后，将`formData`和`result`组合成一个对象，存入一个数组并保存。
    *   **效果**：工具从一个一次性生成器，变成了一个可积累、可回顾的个人目标库。

5.  **深化游戏化：引入可视化进度和成就系统**
    *   **操作**：结合改造方向3（可交互列表），当用户勾选任务时，不仅计算经验，还更新一个可视化进度条（如`<div class="exp-bar">`的宽度）。
    *   **进阶**：预设一些“成就”（如“连续3天登录”、“一次性完成一个章节”），当检测到用户行为符合时，弹出勋章动画。
    *   **效果**：极大增强用户的参与感和坚持动力，让工具不仅仅是计划，更是陪伴。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做精确的项目管理**：它生成的是**激励性、启发性的行动清单**，而非精确到工时、依赖关系和责任人的**项目甘特图**。如果你需要管理团队项目，应使用Jira、Trello、飞书项目等专业工具。
2.  **不适合替代专业领域建议**：对于“备考法律职业资格证”、“治疗某种疾病”等需要严格专业知识的领域，它生成的“冒险计划”只能作为**学习动力和初步框架的补充**，绝不能替代官方教材、课程或医生的专业方案。
3.  **不适合处理模糊或探索性目标**：它的强项是将**相对明确的目标**结构化。如果你的目标是“找到人生方向”、“探索我对什么感兴趣”，这种工具可能会让你强行聚焦在一个可能错误的方向上。此时，更适合使用思维导图、自由写作或与导师交流。
4.  **不能保证生成质量**：输出质量严重依赖于你**输入描述的清晰度**和**AI模型当前的能力**。如果描述含糊，可能会得到空洞的建议。你需要具备一定的判断力，对AI生成的结果进行筛选、调整和补充，它是一位“创意助理”，而非“终极权威”。

**总结**：将这个工具视为你的**“目标启动催化剂”**和**“动力增强外挂”**。用它来打破最初的迷茫和惰性，获得一个充满趣味的行动框架。一旦启动后，你可以将其中的任务导入更专业的工具进行精细管理，或根据实际进展灵活调整。它的核心价值在于 **“让开始变得有趣”**。
