# 高情商沟通助手 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景：**
当你遇到一个棘手的沟通场景，不知道如何回应才得体时，这个工具能帮你。比如：
- 老板让你周末加班，但你已有安排
- 朋友找你借钱，你不想借
- 同事推卸责任给你，你想拒绝
- 暧昧对象说了让你不舒服的话，你想表达但怕伤感情

**适合情况：**
- 需要快速获得“得体”回复建议的紧急场景
- 沟通经验不足，想学习高情商表达方式
- 需要从多个角度（委婉/直接/幽默）思考如何回应

**不适合情况：**
- 需要实时对话的聊天场景
- 涉及法律、医疗等专业领域的严肃咨询
- 需要深度心理分析或长期关系建议

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **对方是谁？** - 从6个预设身份中选择（老板、客户、同事等）
2. **对方说了什么？** - 文本框，输入对方的具体话语或情况描述
3. **你的真实意图** - 输入框，用大白话说明你真正想表达的意思

**操作步骤：**
1. 点击选择“对方身份”（默认是“老板/上级”）
2. 在“对方说了什么”框中描述场景
3. 在“你的真实意图”中写下内心真实想法
4. 点击“✨ 帮我生成高情商回复”按钮
5. 首次使用需在弹窗中输入DeepSeek API Key

**输出结果长什么样？**
右侧会显示3种不同风格的回复方案，例如：
- **委婉得体型** - 具体话术 + 简短解析
- **不卑不亢型** - 具体话术 + 简短解析  
- **幽默化解型** - 具体话术 + 简短解析

如果选择“DeepSeek R1”模型，还会显示AI的“心理分析过程”。

**容易忽略的细节：**
- 必须先配置API Key才能使用
- “真实意图”要写大白话，不要写“我想拒绝”而要写“我不想加班，因为...”
- 可以点击每条回复右上角的“复制”按钮直接使用
- 模型切换在右上角，R1模型思考更深但更慢

## 【三】核心结构拆解（学习重点）

**页面由4个关键模块组成：**

1. **场景配置模块（左侧）**
   - **职责**：收集用户输入的所有信息
   - **包含**：身份选择器、场景描述框、意图输入框
   - **设计亮点**：将复杂沟通拆解为3个简单问题，降低用户思考负担

2. **AI处理引擎（后台逻辑）**
   - **职责**：将用户输入组装成Prompt，调用AI API，解析返回结果
   - **关键函数**：`generateReply()` 处理整个流程
   - **设计亮点**：严格定义输出格式（JSON数组），确保前端能稳定解析

3. **结果展示模块（右侧）**
   - **职责**：清晰展示AI生成的多种方案
   - **包含**：风格标签、具体话术、解析说明、复制功能
   - **设计亮点**：用不同颜色标签区分风格，hover显示复制按钮

4. **配置管理模块（弹窗）**
   - **职责**：管理API Key和模型选择
   - **设计亮点**：配置自动保存到localStorage，下次打开无需重复输入

**输入 → 处理 → 输出 链路：**
```
用户输入（身份+场景+意图）
    ↓
组装成结构化Prompt
    ↓
调用DeepSeek API
    ↓
解析AI返回的JSON
    ↓
前端渲染为3种风格卡片
```

**最值得学习的设计：**
**“问题拆解”思维** - 将复杂的“高情商回复”需求拆解为三个可操作的输入项，让AI能精准理解场景。这种“结构化提问”比让用户写一大段描述更有效。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色：**
Prompt在这里是“沟通专家”的**角色定义**和**任务指令**，它告诉AI：
1. 你是什么专家（高情商沟通专家）
2. 你需要什么信息（三个结构化输入）
3. 你要输出什么（3种风格的JSON数组）
4. 必须遵守的原则（得体、达意、分寸）

**解决的是“生成问题”：**
这个Prompt主要解决**内容生成问题**——基于给定场景，生成合适的回复话术。它不需要理解复杂的心理学理论，只需要应用沟通技巧。

**Prompt中的关键变量：**
1. `对方身份` - 决定语气和分寸
2. `对方说的话` - 具体场景内容
3. `我的真实意图` - 回复必须达成的核心目标

**如果只改Prompt，不改代码：**
- 改`输出格式要求` → 前端可能无法正确解析
- 改`回复原则` → 生成的风格会变化（如更激进或更保守）
- 改`风格数量` → 如果还是返回JSON数组，前端能自适应显示

**安全提示**：这个Prompt要求AI返回严格JSON格式，这是确保前后端配合的关键设计。

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从易到难）：**

**第一步：保持结构不变，替换使用场景**
- 最安全的起点
- 将“高情商沟通”改为其他场景，如：
  - **学习建议生成器**：输入“科目、薄弱点、目标”→输出学习计划
  - **旅行规划助手**：输入“地点、天数、偏好”→输出行程安排
- 只需修改：页面标题、输入框标签、Prompt中的角色描述

**第二步：调整输入字段**
- 增加/减少输入项
- 例如增加“紧急程度”下拉框、“关系亲密度”滑块
- 在Prompt中对应增加这些变量

**第三步：改变输出形式**
- 当前是3种风格平铺展示
- 可改为：选项卡切换、对比表格、流程图
- 或增加“我最喜欢这个”的投票功能

**从哪里下手最安全？**
从**修改Prompt文本**开始，这是零代码风险的操作。比如先把“高情商沟通专家”改为“学习规划师”，看看AI会生成什么。

## 【六】3–5个可直接尝试的改造方向

1. **增加“语气强度”滑块**
   - 在输入区增加一个滑块：从“非常委婉”到“非常直接”
   - 将滑块值传入Prompt：“请生成偏向[直接/委婉]风格的回复”
   - **效果**：让用户控制回复的强硬程度

2. **支持多轮对话优化**
   - 保存每次生成的回复
   - 增加“这个不行，再生成3个”按钮
   - 将不满意的回复作为负面示例传给AI：“不要像这样说...”
   - **效果**：实现迭代优化，更贴近用户需求

3. **更换为本地模型/免费API**
   - 使用Ollama + 本地Qwen模型
   - 或换用Groq、OpenRouter等提供免费额度的服务
   - 修改`fetch`请求的URL和headers即可
   - **效果**：降低使用门槛，无需API Key

4. **增加“实战演练”模式**
   - 右侧不直接显示回复，而是显示“对方可能怎么回应”
   - 用户需要输入自己的回复，AI给出评分和建议
   - **效果**：从“给答案”变成“练能力”

5. **输出多样化展示**
   - 当前是纯文本卡片
   - 可增加：语音朗读按钮、一键分享到微信、保存为图片
   - 或按“风险程度”排序（高风险/中风险/低风险回复）
   - **效果**：提升实用性和传播性

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不适用于实时对话**
   - 这是“离线参谋”，不是“实时翻译”
   - 如果需要边聊边得建议，应该用聊天机器人插件

2. **无法处理复杂关系动态**
   - 基于单次交互给出建议
   - 如果涉及长期恩怨、权力博弈，需要人类咨询师

3. **文化差异处理有限**
   - Prompt基于中文沟通习惯
   - 对于跨文化沟通（如对外国人），可能需要调整原则

4. **不替代真实沟通能力**
   - 工具给出的是“话术模板”
   - 真实沟通还需要语气、表情、时机等，这些无法通过文本学习

**如果用户想做X，应该换什么：**
- 想分析对话中的情绪变化 → 用情感分析工具（如Sentiment Analysis API）
- 需要法律文书或正式邮件 → 用专业文书生成工具
- 想练习沟通实战 → 用角色扮演AI聊天机器人
- 需要深度心理建议 → 咨询专业心理咨询师

**最后提醒**：这个网页的核心价值在于“结构化提问”的设计思维。学会这种思维，你可以为任何需要AI辅助决策的场景搭建类似工具。从模仿开始，从修改Prompt起步，你很快就能做出属于自己的AI小应用。
