# 钩子套路库 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你是一名内容创作者（比如做短视频、写公众号、发小红书笔记）。你每天都要想新的标题、开场白，好让读者在3秒内被吸引住。时间久了，脑子里的“好点子”会用完，或者你发现某个“悬念式”标题在小红书效果特别好，但下次想用时却记不清具体怎么写了。

这个网页就是一个**个人化的“灵感弹药库”**。它帮你：
- **收集**：把你在网上看到、自己想到的各种“抓人”的标题套路（钩子）记录下来。
- **整理**：给每个套路打上类型、情绪、平台等标签，方便以后查找。
- **激发**：在你没灵感时，随机给你推荐一个套路，或者把几个套路组合起来，生成新的创意。

**适合场景**：
- 日常积累和整理看到的好标题、好开场白。
- 创作前快速寻找灵感，打破思维定式。
- 分析不同平台（抖音、小红书等）上流行的内容风格。

**不适合场景**：
- 需要直接生成完整文章或脚本（它只提供“钩子”或标题灵感）。
- 需要复杂的团队协作和版本管理（它是单机版工具）。
- 需要对内容效果进行数据分析（它没有数据追踪功能）。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
页面左侧有一个“录入钩子”的卡片，里面有五个输入框：
1.  **标题**：你看到的或想到的那个吸引人的句子本身。
2.  **钩子类型**：这个标题用了什么技巧（如：悬念、反转、提问）。
3.  **情绪标签**：这个标题想激发读者什么情绪（如：好奇、惊喜、焦虑）。
4.  **适用平台**：这个标题在哪个平台效果好（如：抖音、小红书）。
5.  **自定义分类**：你自己定义的分类（如：美妆、职场、育儿）。

**用户通常会做哪几步操作？**
1.  **积累阶段**：看到一个爆款标题，就打开这个页面，把信息填到左侧表单，点击“保存到库”。你的“弹药”就存进去了。
2.  **创作阶段**：
    - **找灵感**：在右上角点击“随机推荐”，它会从库里随机挑一个钩子给你。
    - **找更多**：在中间的搜索框输入关键词（如“好奇”），或从下拉框选择分类（如“短视频”），来筛选你积累的所有钩子。
    - **玩组合**：点击右上角“一键组合”，它会自动将库里的钩子元素（标题、情绪、类型等）打乱重组，生成5个新的标题公式，给你更多创意角度。

**输出结果长什么样？**
- **库列表**：中间区域会以卡片形式展示所有钩子，每个卡片上都有标题和对应的彩色标签。
- **随机推荐**：左下角区域会单独展示随机选出的一个钩子详情。
- **一键组合**：右下角区域会展示5条由模板生成的、可供参考的新标题。

**有哪些容易忽略的使用细节？**
1.  **分类需要手动添加**：在“自定义分类”输入后，必须点击旁边的“添加”按钮，这个分类才会生效，并出现在筛选下拉框里。直接保存钩子时，如果分类是新的，会自动添加。
2.  **导入/导出功能**：所有数据都存在你电脑的内存里，刷新页面会丢失。**务必使用右下角的“导出JSON”功能备份你的库**。下次使用时，用“导入JSON”恢复。
3.  **搜索是全局的**：在搜索框输入关键词，会同时匹配标题、类型、情绪、平台、分类所有字段。

## 【三】核心结构拆解（学习重点）

这个页面可以看作一个**个人数据库管理工具**，由四个核心模块组成：

1.  **数据录入模块（左侧卡片）**
    - **职责**：提供表单，让用户输入一条新“钩子”的所有属性（标题、类型等），并提交保存到核心数据库。同时管理“分类”这个全局标签列表。
    - **输入**：用户填写的表单数据。
    - **处理**：检查必填项 → 生成一个带唯一ID的数据对象 → 添加到数据库数组开头 → 更新分类列表 → 清空表单。
    - **输出**：一条新的数据记录，并实时显示在“钩子条目”区域。

2.  **数据存储与检索模块（中间上部及中部卡片）**
    - **职责**：
        - **存储**：在内存中维护一个`entries`数组，这就是你的数据库。
        - **检索**：提供搜索框和分类下拉框，让用户过滤数据。
    - **输入**：用户输入的关键词和选择的分类。
    - **处理**：每当过滤条件变化，一个叫做`filteredEntries`的计算属性会自动运行，遍历整个数据库，找出所有匹配条件的条目。
    - **输出**：一个过滤后的数组，直接驱动“钩子条目”区域的显示。

3.  **数据展示与操作模块（中间下部卡片）**
    - **职责**：以美观的卡片网格展示过滤后的数据条目。提供每条数据的删除功能，以及整个数据库的导入/导出功能。
    - **关键设计**：**数据驱动视图**。开发者没有手动去创建或删除HTML卡片，而是定义了一个数据数组(`entries`)和一个过滤逻辑。页面上的卡片列表(`<template x-for="entry in filteredEntries">`)会自动根据数组的变化而更新。这是现代前端框架（如Vue、React）的核心思想，这里用Alpine.js轻量实现，是**最值得学习的地方**。

4.  **灵感生成模块（下方两个卡片）**
    - **职责**：提供两种创意工具。
    - **随机推荐**：从`entries`数组中随机选取一条数据展示。
    - **一键组合**：定义了几个文本模板（如`【{emotion}】{title}｜{hookType}`），然后随机选取条目，将其属性（`{emotion}`, `{title}`等）填充到随机模板中，生成新的标题建议。
    - **设计亮点**：将**数据（钩子条目）** 与 **模板（组合规则）** 分离。只需修改或增加模板，就能创造出完全不同的组合效果，而无需改动核心数据逻辑。

**逻辑链路总结**：
`用户输入` -> `表单验证并生成数据对象` -> `存入中央数组(entries)` -> `触发计算属性(filteredEntries)更新` -> `视图自动重新渲染` -> `用户看到新条目`。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，**“一键组合”功能本质上是一个内置的、简化版的Prompt应用**。

- **Prompt扮演的角色**：这里没有调用外部AI，而是用**硬编码的文本模板**模拟了AI提示词（Prompt）的功能。每个模板（如`【{emotion}】{title}｜{hookType}`）就是一个固定的“指令格式”。
- **解决什么问题**：它解决的是“**生成问题**”。它的任务不是理解自然语言，而是按照预设的规则，将已有的数据（钩子属性）进行排列组合，生成符合特定格式的新内容。
- **关键变量**：Prompt中的关键变量是那些用花括号`{}`包裹的部分：`{title}`, `{hookType}`, `{emotion}`, `{platform}`。这些变量会在运行时被替换成真实数据。
- **如果只改Prompt（模板），不改代码**：你会发现“一键组合”生成的句子格式完全变了。例如，如果你把模板改成`听说{platform}上都在用这个{hookType}：{title}`，那么生成的结果就会是更口语化、更像推荐语的标题。这展示了**Prompt（模板）如何直接控制输出内容的风格和结构**。

## 【五】如何模仿它，做出你自己的版本？

这是一个经典的“**CRUD（增删改查）管理面板**”模式，应用范围极广。你可以按以下安全路径模仿：

**第一步：保持结构不变，替换使用场景**
这是最安全的一步。不要改动任何代码逻辑，只做文字替换。
- **目标**：做一个“个人金句库”、“项目灵感库”或“电影收藏库”。
- **操作**：
    1.  修改网页标题（`<title>`标签内）。
    2.  修改页面主标题（`<span class="font-bold ...">钩子套路库</span>`）。
    3.  修改左侧表单的标签和提示文字（如把“标题”改成“金句”，“钩子类型”改成“出处”，“情绪标签”改成“主题”）。
    4.  修改默认的示例数据（`entries`数组里的那两个对象）。

**第二步：调整输入字段或数据模型**
现在你需要改动数据结构和表单。
- **目标**：让你的库记录更多或不同的信息。
- **操作**：
    1.  在`form`对象和`entries`数组的示例对象中，增加或减少属性（例如增加一个`author`作者字段）。
    2.  在HTML中，复制一个`<div>`输入框区块，修改其`label`和`x-model`绑定（绑定到新增的属性，如`form.author`）。
    3.  在“一键组合”的模板中，就可以使用新的变量`{author}`了。

**第三步：改变输出形式或展示方式**
调整数据如何被呈现。
- **目标**：让展示更符合你的需求。
- **操作**：
    1.  修改“钩子条目”卡片的布局，比如只显示核心信息，点击后再展开详情。
    2.  改变“一键组合”生成的模板，让它更贴合你的新场景（比如为“金句库”生成带出处的引用格式）。
    3.  可以增加一个“详情”按钮，点击后弹窗显示该条目的更多信息或你的私人笔记。

**从哪里下手最安全？**
从 **第一步的文字替换** 和 **第五步的修改模板** 开始。这两处几乎不会破坏原有功能，能让你立刻看到变化，建立信心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“效果评分”与“排序”**
    - **操作**：在数据模型中为每个条目增加一个`rating`（1-5星）字段。在表单中添加一个五星评分组件。在检索区域增加“按评分排序”的下拉框。在`filteredEntries`计算属性中，不仅过滤，还根据选择进行排序。
    - **价值**：从“收集”升级到“甄选”，帮你快速找到质量最高的灵感。

2.  **接入真实AI API，实现“智能拓展”**
    - **操作**：保留现有所有功能。增加一个按钮“AI拓展”，当选中某个钩子条目时，调用OpenAI或文心一言等大语言模型的API。Prompt可以设计为：“这是一个{hookType}类型的标题，旨在引发{emotion}情绪，用于{platform}平台。标题是：{title}。请基于这个标题，再生成3个不同角度的类似标题。”
    - **价值**：将工具从“记忆库”变为“创意引擎”，获得人类想不到的变体。

3.  **拆分为“库管理”与“灵感工坊”两个页面**
    - **操作**：创建`index.html`（当前页面）和`workshop.html`。当前页面专注于数据的增删改查。在新页面中，只保留“随机推荐”、“一键组合”和“AI拓展”功能，并设计得更像创作台（更大的输入区、更多生成选项）。两个页面通过URL参数或`localStorage`共享`entries`数据。
    - **价值**：职责分离，让创作环境更专注，减少干扰。

4.  **优化交互：添加撤销删除与收藏夹**
    - **操作**：删除条目时，不是直接移除，而是先移入一个“临时删除区”，并提示“撤销”。5秒后无操作再真正删除。为每个条目增加一个“收藏”按钮，点击后将其加入一个独立的`favorites`数组，并可以单独查看。
    - **价值**：防止误操作，并允许用户建立精华子集，提升使用体验。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合作为多人协作工具**：所有数据仅存在于当前浏览器标签页的内存中。如果两个人同时打开，他们看到的是完全独立的数据。**如果需要共享库，应该使用Google Sheets、Airtable或搭建一个带有后端数据库的Web应用。**
2.  **不适合深度内容创作**：它只解决“开头吸引人”的问题，不涉及内容结构、论据展开、文笔润色等。**如果需要写完整文章或脚本，应该使用Notion、Obsidian或专门的写作软件。**
3.  **不适合进行数据分析和趋势预测**：它只能记录和检索，无法告诉你“哪种情绪标签在抖音上点击率更高”。**如果需要分析内容表现，应该将数据导出，并导入到Excel、Tableau或专门的数据分析平台进行处理。**
4.  **不适合存储大量多媒体信息**：它设计用于存储文本和标签。**如果需要管理图片、视频素材及其对应的标题，应该使用Eagle、Billfish等数字资产管理工具。**

**总结**：把这个网页看作你的**私人创意火花记录本**和**思维锻炼器**。它的强大在于简单、直接、可定制。用它来积累“原料”和激发“瞬间灵感”，然后将这些火花带到更专业的工具中去完成最终作品。
