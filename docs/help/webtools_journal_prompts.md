# 日记灵感助手 - 帮助与学习文档

## 【一】这个网页解决了什么问题？

**使用场景**：当你想要写日记，但面对空白页面不知从何下笔时，这个工具能为你提供具体的写作灵感。它就像一个写作教练，每次给你一个不同的话题提示，帮助你聚焦思考，克服“不知道写什么”的障碍。

**适合情况**：
- 想要养成写日记习惯但缺乏动力的人
- 需要写作灵感或话题启发
- 希望记录生活但不知如何组织内容
- 想要进行简单的自我反思练习

**不适合情况**：
- 需要长篇大论的深度写作
- 需要专业的写作工具（如格式调整、导出功能）
- 需要与他人协作或分享日记
- 需要加密或高度隐私保护

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 页面会自动显示一个“今日灵感”（写作提示）
- 你只需要在下方的大文本框中输入文字

**用户通常会做哪几步操作？**
1. 打开页面，阅读自动显示的写作提示
2. 如果不喜欢当前提示，点击“换一个”按钮更换
3. 在下方文本框中开始写作
4. 写完后点击“保存日记”按钮
5. 点击右上角的历史图标可以查看过往日记

**输出结果长什么样？**
- 保存的日记会显示在历史记录中
- 每篇日记包含：保存时间、使用的提示、日记内容
- 日记按时间倒序排列（最新的在最上面）

**容易忽略的使用细节**
1. **自动保存**：日记保存在浏览器本地，不会上传到服务器
2. **字数统计**：写作时右上角会实时显示字数
3. **历史记录切换**：点击右上角时钟图标可在写作区和历史记录间切换
4. **删除功能**：鼠标悬停在历史日记上才会显示删除按钮

## 【三】核心结构拆解（学习重点）

**页面由四个关键模块组成：**

1. **提示模块（Prompt Card）**
   - **职责**：展示随机的写作提示，提供更换功能
   - **特点**：视觉突出，有动画效果，是页面的“启动器”

2. **写作模块（Writing Area）**
   - **职责**：提供写作空间，显示日期和字数，处理保存操作
   - **特点**：模拟纸张纹理，专注于写作体验

3. **历史模块（History List）**
   - **职责**：展示所有保存的日记，提供删除功能
   - **特点**：按时间排序，悬停显示操作按钮

4. **状态管理模块（JavaScript逻辑）**
   - **职责**：管理所有数据（当前提示、日记内容、历史记录）
   - **特点**：使用浏览器本地存储持久化数据

**输入 → 处理 → 输出 的逻辑链路：**
```
用户打开页面 → 随机显示提示 → 用户写作 → 点击保存
    ↓
数据验证 → 生成时间戳 → 保存到数组 → 存储到本地
    ↓
切换到历史视图 → 重新渲染列表
```

**最值得学习的设计：**
- **状态切换的优雅处理**：写作区和历史记录区使用同一个空间，通过`x-show`切换，保持界面简洁
- **本地存储的完整实现**：从保存、读取到删除，展示了完整的前端数据持久化方案
- **用户体验细节**：字数统计、纸张纹理、悬停效果等小设计提升了整体质感

## 【四】Prompt / AI 逻辑是如何被设计的？

**提示在这个页面中扮演的角色：**
- 这里是**静态提示**，不是AI生成的
- 提示是预先定义好的问题数组，随机展示
- 它解决的是“**启动问题**”——给用户一个具体的起点

**提示中的关键变量：**
- 提示内容本身（10个预设问题）
- 随机选择逻辑（确保不重复显示相同提示）

**如果只改提示，不改代码：**
1. 修改`prompts`数组的内容：改变写作话题的方向
2. 增加/减少数组长度：改变提示的多样性
3. 修改提示的语言风格：从反思性变为创造性等

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 将“日记灵感”改为其他主题，如“每日感恩”、“读书笔记”、“健身记录”
- 修改提示数组的内容，匹配新主题
- 调整颜色和图标（如将暖色调改为冷色调）

**第二步：调整输入字段**
- 增加更多输入类型：如评分（1-5星）、标签选择、情绪选择
- 将单行文本框改为多字段表单
- 添加图片上传功能（需要调整数据存储方式）

**第三步：改变输出形式**
- 将列表视图改为日历视图
- 添加统计功能（如每周写作频率）
- 增加导出功能（导出为PDF或文本文件）

**最安全的下手点**：从修改`prompts`数组开始，这是零风险且立即见效的改动。

## 【六】3–5个可直接尝试的改造方向

1. **增加提示分类**
   - 将提示分为“反思类”、“创意类”、“感恩类”等
   - 添加分类选择按钮，让用户选择今天想写的类型
   - 修改`spinPrompt()`函数支持按分类筛选

2. **添加AI生成提示**
   - 集成OpenAI API，根据用户历史或心情生成个性化提示
   - 保留原有提示作为备选，当API不可用时使用
   - 需要：API密钥、简单的后端或使用客户端SDK

3. **改进历史记录视图**
   - 添加搜索功能（按日期、关键词搜索）
   - 增加编辑已保存日记的功能
   - 添加“收藏”功能，标记特别有意义的日记

4. **增强写作体验**
   - 添加写作计时器（如“专注写作10分钟”）
   - 实现自动保存草稿（每30秒保存一次）
   - 添加简单的文本格式（粗体、列表）

5. **数据可视化**
   - 添加简单的统计图表（每月写作天数、字数趋势）
   - 显示“连续写作天数”成就
   - 生成年度回顾报告

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不适合长期、大量的日记存储**：本地存储有容量限制（通常5-10MB），日记过多可能导致数据丢失
2. **不适合多设备同步**：数据只保存在当前设备的浏览器中，换设备或清除缓存会丢失所有数据
3. **不适合敏感隐私内容**：没有加密，懂技术的人可以查看本地存储数据
4. **不适合协作或分享**：没有分享、导出或多人协作功能

**如果用户想做X，应该换什么工具：**
- **想要云端同步**：使用Notion、Google Docs或专门的日记应用（如Day One）
- **需要高度隐私**：使用端到端加密的应用或离线笔记软件
- **想要丰富的格式**：使用Markdown编辑器或富文本编辑器
- **需要AI辅助写作**：使用ChatGPT、Claude等AI对话工具直接交互
