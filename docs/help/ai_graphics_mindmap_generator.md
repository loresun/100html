# 思维导图生成器 - 帮助与学习文档

--------------------------------

## 【一】这个网页解决了什么问题？

**使用场景：**
当你面对一段冗长的文字（如一篇博客、一份会议记录、一章节教科书内容或一个项目计划）时，想要快速理清其核心脉络和逻辑结构，但手动梳理费时费力。这个工具就像一个“思维助手”，它能帮你自动消化这些文字，并生成一张可视化的思维导图，让你一眼看清内容的骨架和重点。

*   **适合在什么情况下使用？**
    *   **学习与复习：** 快速将教材章节或课堂笔记转化为知识图谱。
    *   **内容梳理：** 分析文章、报告或演讲稿的结构和论点。
    *   **会议整理：** 将杂乱的会议纪要提炼成清晰的任务和要点。
    *   **头脑风暴后整理：** 将零散的想法初步归类和组织。
    *   **快速制作演示大纲：** 为演讲或汇报生成一个结构草稿。

*   **不适合什么情况？**
    *   **需要高度精确的逻辑或专业分类时：** AI的理解可能不够精准，需要人工复核和调整。
    *   **处理极度机密或敏感信息时：** 内容会发送到外部AI API，存在隐私风险。
    *   **作为最终成品直接交付：** 它更适合作为“初稿”或“草稿”，帮助你启动思考，通常需要后续的编辑和美化。
    *   **输入内容极短或无实质信息时：** 例如只输入一个标题，AI难以生成有意义的层级结构。

## 【二】使用方式（给第一次接触的人）

1.  **准备输入：** 在左侧面板的“文字内容”框中，粘贴或输入你想要分析的文本。例如，可以是一段关于“如何学习编程”的文章。
2.  **（可选）设定中心主题：** 如果你希望思维导图围绕一个特定主题展开（如“Python学习路径”），可以在“中心主题”框中填写。不填的话，AI会从你输入的文字中自动提取一个。
3.  **（可选）调整层级深度：** 通过滑块选择你想要的详细程度。2层会很简洁（只有主干），5层则会非常详细（包含很多细分枝叶）。
4.  **生成：** 点击“✨ 生成思维导图”按钮。页面会进入加载状态，AI开始工作。
5.  **查看与使用结果：**
    *   右侧会动态渲染出一幅可交互的思维导图，你可以点击节点展开/折叠。
    *   如果使用了“DeepSeek Reasoner”模型，可以展开“AI深度思考过程”查看AI是如何一步步分析你的文本的。
    *   你可以使用上方的按钮**导出图片**、**复制Markdown文本**或**下载Markdown文件**。
    *   点击“编辑”按钮，可以直接修改生成的Markdown文本，然后点击“更新导图”实时看到修改后的效果。

**输出结果长什么样？**
*   **视觉上：** 一幅树状图，中心是主题，向外辐射出各级分支和关键词。
*   **实质上：** 一份结构化的Markdown文档，用 `#`、`##`、`###` 等符号表示层级。

**容易忽略的使用细节：**
*   **首次使用需配置：** 点击顶部导航栏的“设置”按钮，填入你的DeepSeek API Key，否则无法生成。
*   **可以自定义AI的“思考方式”：** 点击“提示词”按钮，你可以修改给AI的指令（System Prompt和User Prompt），从而改变它分析和输出的风格。
*   **直接编辑是强大的功能：** 生成的结果不满意？不用重新生成，直接在编辑框里修改Markdown文本，然后“更新导图”即可，这是迭代优化的捷径。
*   **模型选择：** 在顶部可以选择“DeepSeek Chat”或“DeepSeek Reasoner”。后者会展示思考过程，可能更严谨，但速度可能稍慢。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的前后端分离式设计，我们可以把它看作一个**输入-处理-展示**的流水线工厂。

**关键模块与职责：**

1.  **用户输入模块（左侧面板）：**
    *   **职责：** 收集用户提供的原材料（文本）和加工要求（主题、深度）。
    *   **组成：** 文本框、输入框、滑块、生成按钮。
    *   **输出：** 一个结构化的数据对象，包含 `content`, `centerTopic`, `depth`。

2.  **AI处理引擎（隐藏的后台逻辑）：**
    *   **职责：** 将用户输入和预设指令（Prompt）打包，发送给DeepSeek AI API，并接收AI返回的Markdown格式文本。
    *   **关键设计：** **Prompt工程**。它不是一个简单的请求，而是精心设计的“任务说明书”，告诉AI“你要扮演什么角色”、“具体要做什么”、“输出格式是什么”。这是整个应用的大脑。

3.  **状态管理中枢（Vue响应式数据）：**
    *   **职责：** 协调整个页面的状态流转。例如，管理 `isGenerating`（是否在生成）、`viewState`（当前显示空状态/加载中/结果）、`result`（AI返回的数据）。
    *   **重要性：** 它确保了用户界面能平滑地根据后台任务进度进行切换，不会出现按钮点了没反应或页面卡死的情况。

4.  **结果展示与交互模块（右侧面板）：**
    *   **职责：**
        *   **渲染器：** 使用 `markmap` 库将AI返回的Markdown文本转换成绚丽的、可交互的思维导图。
        *   **编辑器：** 提供Markdown文本编辑框，允许用户直接修改。
        *   **输出器：** 提供导出图片、复制文本、下载文件等功能。
    *   **设计亮点：** **“编辑-预览”一体化**。用户可以在原始文本（Markdown）和最终可视化效果（思维导图）之间无缝切换和即时同步，这极大地提升了工具的可用性和灵活性。

**逻辑链路：**
`用户输入文本` → `Vue收集数据` → `拼接Prompt并调用AI API` → `接收AI返回的Markdown` → `Vue更新状态，切换视图` → `markmap库渲染可视化导图` → `用户查看、编辑或导出`。

**最值得学习的设计：**
**“以Prompt为核心驱动，以Markdown为中间桥梁”的架构。**
1.  **解耦：** AI只负责生成标准的Markdown文本，前端负责将其渲染成图。两者通过Markdown这个通用格式连接，职责清晰。
2.  **灵活性：** 因为中间层是Markdown，所以用户可以轻松编辑，也可以换用其他支持Markdown的渲染库，甚至将结果用于其他支持Markdown的工具。
3.  **可调试性：** 所有AI的“思考成果”都以文本形式呈现，无论是最终的Markdown还是推理过程，都易于人类阅读、理解和调整。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt扮演的角色：** 它是**AI的“岗位职责说明书”和“工作流程指南”**。它定义了AI在这个特定任务中应该扮演的角色（思维导图生成专家），规定了输入输出的格式（Markdown层级），并约束了它的行为（只输出导图，不要额外解释）。

*   **解决的是“理解问题”还是“生成问题”？** 两者兼有，但更侧重于**“格式化生成”**。它首先要让AI“理解”用户输入的内容，提取关键信息，但更关键的一步是强制AI按照**特定的、机器可读的格式（Markdown标题层级）** 来组织这些信息并输出。这解决了AI输出结果随机、难以被程序直接利用的问题。

*   **Prompt中的关键变量：**
    *   `{content}`: 用户输入的核心文本，是AI分析的对象。
    *   `{centerTopic}`: 用户指定的中心主题，为AI的分析提供了焦点和方向。
    *   `{depth}`: 用户要求的层级深度，直接控制了AI输出结构的复杂程度。

*   **如果只改Prompt，不改代码，会发生什么变化？**
    AI的行为和输出风格会彻底改变。例如：
    *   把System Prompt里的“专业思维导图生成助手”改成“一个喜欢用幽默比喻的老师”，生成的导图用词可能会变得活泼有趣。
    *   在User Prompt里增加要求：“为每个末级节点添加一个表情符号”，那么生成的Markdown里就会包含😊、🚀等符号。
    *   改变输出格式要求，比如“请用JSON格式输出”，那么AI就会返回JSON，但前端的`markmap`库就无法渲染了（因为代码没改，它仍然期待Markdown）。这说明了Prompt和代码（解析逻辑）需要匹配。

## 【五】如何模仿它，做出你自己的版本？

**模仿路径（从最安全、改动最小的地方开始）：**

1.  **第一步：替换“皮肤”和使用场景（零风险）**
    *   **做什么：** 保持所有代码逻辑完全不变。
    *   **改哪里：**
        *   修改网页标题和导航栏文字，比如改成“**读书笔记提炼器**”。
        *   修改左侧输入框的提示文字，如“粘贴你想要提炼的书籍章节内容...”。
        *   修改默认的 `centerTopic` 提示，如“本书核心主题（可选）”。
        *   修改按钮文字和提示框内的说明，使其符合新场景。
    *   **效果：** 你立刻得到了一个外观不同但功能一模一样的工具，可以用来分析书籍内容。

2.  **第二步：调整Prompt，改变AI的“专业领域”（低风险）**
    *   **做什么：** 进入“提示词”设置，修改System和User Prompt。
    *   **改哪里：**
        *   假设你想做“**会议行动项提取器**”。将System Prompt改为：“你是一个高效的项目经理助理，擅长从会议记录中提取清晰的任务、负责人和截止日期。”
        *   将User Prompt模板改为：“请分析以下会议纪要，提取出所有行动项，并按‘任务描述 - 负责人 - 截止时间’的格式，用列表呈现。内容：{content}”
    *   **注意：** 此时输出可能不再是树状思维导图，而是列表。你需要同步进行第三步。

3.  **第三步：改变输出展示方式（中等风险）**
    *   **做什么：** 根据新Prompt的输出格式，更换右侧的渲染模块。
    *   **改哪里：**
        *   如果新AI输出是任务列表，你可以移除 `markmap` 库的引用和渲染代码。
        *   在结果展示区，将渲染思维导图的 `div` 替换为一个简单的用于显示富文本或列表的 `div`，并使用 `v-html` 或其它方式展示AI返回的内容。
        *   相应地，导出功能可能从“下载图片”变为“导出为PDF”或“复制任务列表”。
    *   **核心：** **保持“输入-调用AI-接收结果-展示结果”这个主流程不变**，只更换最后一个环节的“展示”部件。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让导图更精准：**
    *   **操作：** 在左侧面板增加一个下拉选择框，让用户选择文本的“类型”，如“科技文章”、“法律条文”、“小说情节”、“学术论文”。
    *   **实现：** 将这个新变量（如 `{docType}`）加入到User Prompt模板中。例如：“这是一篇{doctype}，请根据该类型文本的典型结构进行分析...”。
    *   **效果：** AI会根据不同的文体特征来调整分析的重点和结构。

2.  **更换或增加AI模型/API：**
    *   **操作：** 在顶部模型选择下拉框中，增加新的选项，如“OpenAI GPT-4o”、“Claude 3.5 Sonnet”。
    *   **实现：** 在 `generate` 函数中，根据选择的值，修改API请求的URL、Headers和Body结构。可能需要为不同模型设计略微不同的Prompt。
    *   **效果：** 用户可以选择不同特点的AI，比如追求性价比、追求最强推理或追求特定长文本能力。

3.  **实现“历史记录”或“项目”功能：**
    *   **操作：** 将页面拆分为两个：一个“项目列表页”和一个“编辑生成页”。
    *   **实现：** 使用浏览器的 `localStorage` 或 `IndexedDB` 保存每次生成的输入、输出和元数据（时间、模型）。在列表页展示所有历史记录，点击可进入编辑页查看或修改。
    *   **效果：** 工具从一个单次使用的工具，变成了一个可积累、可管理的知识库。

4.  **优化交互体验：**
    *   **操作：** 为思维导图节点增加“右键菜单”。
    *   **实现：** 监听 `#mindmap` SVG 内元素的右键点击事件，弹出自定义菜单，提供“折叠子节点”、“高亮此分支”、“删除此节点（同步修改Markdown）”等功能。
    *   **效果：** 大幅增强用户对生成导图的直接操控能力，使其更接近一个轻量级的思维导图编辑器。

5.  **增加“模板”功能：**
    *   **操作：** 在生成按钮旁增加一个“使用模板”按钮。
    *   **实现：** 预设几种Prompt模板（如“SWOT分析”、“5W1H分析”、“人物关系梳理”），用户选择后，会自动修改System和User Prompt，并可能预填一些输入字段。
    *   **效果：** 降低了高级用户的使用门槛，让工具能应对更具体的结构化分析任务。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做精确的图表绘制：** 它生成的是逻辑结构图，不是流程图、时序图或架构图。虽然通过深度定制Prompt可能勉强实现，但远不如使用Mermaid、Draw.io等专业图表工具。
*   **不适合处理实时或流式数据：** 它是一个基于静态文本的批处理工具。你不能用它来连接数据库、监控日志并实时生成变化的导图。
*   **不适合作为最终交付的文档或设计稿：** 生成的思维导图在美观度和定制化上比较有限。如果需要向客户或团队提交正式材料，建议将AI生成的Markdown导入到XMind、MindNode等专业软件中进行深度美化。
*   **不适合进行严格的逻辑验证或事实核查：** AI可能会误解原文，遗漏重要信息，或创造出原文中不存在的联系。生成的导图必须由使用者基于自身知识进行批判性审阅和修正。
*   **如果用户想做...**：如果需要创建包含复杂图标、图片、附件、公式的思维导图，应该直接使用**专业的桌面或在线思维导图软件**（如XMind, MindMeister），本工具更适合快速构思和梳理初稿。
