# 热点追踪与选题推荐 - 学习指南

## 【一】这个网页解决了什么问题？

想象一下，你是一个新媒体运营、内容创作者或小品牌主。每天你需要为公众号、小红书等平台想选题，既要结合自己的品牌，又要“蹭”上热点，让内容有更多人看。手动找热点、想角度很费时间，而且容易想不出好点子。

这个网页就是你的“选题助手”。你只需要告诉它你的品牌是做什么的、想在哪些平台发内容，再输入几个最近的热搜词，它就能用AI帮你生成一系列结合了热点和品牌特色的具体选题建议，包括标题、切入角度和内容大纲。

**适合使用的情况：**
- 日常内容创作缺乏灵感时
- 突发事件或热点出现后，需要快速反应时
- 为特定营销节点（如节日、促销）策划内容时
- 运营多个平台，需要统一策划方向时

**不适合使用的情况：**
- 需要深度行业报告或数据分析（它提供的是创意方向，不是数据）
- 已经确定了具体内容，只需要文案撰写（它是“想点子”的工具）
- 完全原创、不依赖热点的内容策划

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **品牌/行业信息**：你的品牌名称（如“元气森林”）、所属行业（如“饮料”）
2.  **目标平台**：你计划发布内容的平台（小红书、抖音等，可多选）
3.  **热点关键词**：近期你关注的热点，每行一个（如“五一调休”、“AI歌手”）

**用户通常会做哪几步操作？**
1.  首次打开页面，点击右上角“配置”按钮，输入你的DeepSeek API Key并保存。
2.  在左侧表单中，填写你的品牌信息、选择平台、输入热点关键词。
3.  点击底部蓝色的 **“生成选题建议”** 按钮。
4.  等待几秒到几十秒，右侧区域会逐步显示出AI生成的选题列表。

**输出结果长什么样？**
结果会以清晰的Markdown格式展示，例如：
```
## 选题建议

### 选题1：【五一宅家】用我们的咖啡，自制网红“便利店调饮”
- **热点关联**：结合五一假期“宅家”热点和便利店调饮风潮
- **切入角度**：教用户用品牌咖啡复刻网红饮品，主打“在家也能享受咖啡馆体验”
- **内容大纲**：1. 介绍风潮 2. 材料准备（突出品牌产品）3. 步骤教程 4. 成品展示与标签
- **传播潜力**：⭐⭐⭐⭐☆
```
每个选题都包含了标题、与热点的关联、具体怎么“蹭”热点、内容可以怎么写，以及预估的传播效果。

**有哪些容易忽略的使用细节？**
- **API配置是第一步**：不配置API Key，点击生成会直接弹出配置窗口，无法使用核心功能。
- **关键词输入有技巧**：输入越具体、越新鲜的热点词（如“某某明星塌房”），生成的选题关联性越强。可以输入多个关键词，AI会尝试综合。
- **结果不是一次性的**：你可以修改关键词或平台，多次点击生成，获取不同方向的灵感。
- **平台选择影响角度**：选择“小红书”和选择“抖音”，AI生成的选题形式和语言风格会有所不同。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

**1. 配置与状态管理模块**
*   **职责**：管理应用的全局设置（如API密钥）和运行状态（如是否正在生成）。
*   **位置**：右上角的“配置”按钮和弹出的模态框；以及整个应用底层的JavaScript数据对象（`trendingApp()`）。
*   **逻辑**：用户输入API Key → 保存到浏览器本地存储 → 每次请求AI时读取使用。这是一个典型的“设置持久化”设计。

**2. 用户输入模块**
*   **职责**：收集所有生成选题所需的背景信息。
*   **位置**：页面左侧的两个白色卡片（“品牌/行业信息”和“热点关键词”）。
*   **逻辑**：用户填写表单 → 数据被实时绑定到JavaScript变量（通过`x-model`）→ 为下一步的Prompt组装做好准备。

**3. AI处理与结果展示模块**
*   **职责**：向AI发送请求，并流式接收、展示结果。
*   **位置**：页面右侧的大面积卡片区域，以及`generateTopics()`函数。
*   **逻辑**：点击按钮 → 组装Prompt → 调用DeepSeek API → **流式（Stream）** 接收AI回复 → 实时将Markdown文本渲染为HTML并显示。

**输入 → 处理 → 输出 的逻辑链路：**
```
用户填写表单 (输入)
      ↓
点击“生成”按钮
      ↓
函数检查配置并组装Prompt (处理)
      ↓
调用DeepSeek API (发送Prompt)
      ↓
流式接收AI返回的Markdown文本 (处理)
      ↓
使用`marked.js`实时渲染为美观的HTML (输出)
```

**最值得学习的设计：**
**“Prompt即界面”的封装思想**。整个页面的表单，本质上是在为一个大Prompt收集变量。AI并不直接“理解”表单，而是开发者设计了一个结构化的Prompt模板，将表单变量（品牌、热点词）填充进去，从而引导AI生成格式统一、内容相关的输出。这种将复杂交互简化为一个精心设计的Prompt请求的模式，是AI应用设计的核心。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt是连接“用户输入”和“AI能力”的**翻译官**和**指令手册**。它把零散的表单信息，组织成一段AI能理解的、带有明确角色和任务要求的背景描述。

**它解决的是“理解问题”还是“生成问题”？**
主要解决**生成问题**。它的核心任务是：根据给定的背景（品牌、热点），**生成**符合要求的、新颖的、结构化的内容（选题）。它也在一定程度上解决了“理解问题”，因为它定义了何为“好的选题”（如需要结合热点、给出角度等）。

**哪些信息是 Prompt 中的关键变量？**
1.  **角色设定**：`你是一个专业的新媒体运营专家。` —— 这决定了AI回应的口吻和专业领域。
2.  **背景变量**：`${this.brandName}`, `${this.industry}`, `${this.platforms.join('、')}`, `${this.hotKeywords}` —— 这些来自表单，是每次请求的核心变量。
3.  **任务指令**：`请生成选题时：1. 结合热点... 2. 给出具体标题...` —— 这是对生成内容的**质量要求和约束条件**。
4.  **格式规范**：`输出格式（Markdown）：## 选题建议...` —— 这强制AI按照我们想要的、便于页面渲染的结构来回答。

**如果只改 Prompt，不改代码，会发生什么变化？**
整个应用的行为和产出会发生根本性改变。例如：
- 将角色从“新媒体运营专家”改为“资深投资人”，它生成的就会是“热点事件投资机会分析”。
- 修改任务指令中的“生成5-10个选题”为“生成一个详细的视频脚本”，输出就会变成脚本。
- 调整格式规范，输出的排版结构会完全不同。
**这说明：在AI应用中，Prompt是业务的灵魂，前端界面只是收集灵魂所需养分的容器。**

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的AI工具：

**第一步：保持结构不变，替换使用场景（最安全）**
这是最简单的起步方式。不要改动任何代码结构（三个模块布局、流式请求逻辑），只替换文字和Prompt。
*   **做什么**：把“热点追踪”换成“周报生成器”。将左侧表单的标签改为“本周工作事项”、“下周计划”、“遇到的挑战”。将Prompt中的角色改为“项目经理”，任务改为“请根据以下信息生成一份结构清晰、重点突出的工作周报”。
*   **为什么安全**：你只是在修改静态文本和字符串，没有动任何交互逻辑和数据处理代码，出错风险极低。

**第二步：调整输入字段或 Prompt**
在第一步成功的基础上，根据新场景的需要，增加、删除或修改输入字段。
*   **做什么**：在“周报生成器”里，增加一个“汇报对象”下拉菜单（直属领导、部门总监）。同时，修改Prompt，加入“请根据不同的汇报对象，调整周报的详略程度和语气”。
*   **关键**：确保表单中新增的字段（如`reportTo`）在Prompt模板中被正确引用（`${this.reportTo}`）。

**第三步：改变输出形式或展示方式**
当你的应用能稳定运行后，可以优化结果展示。
*   **做什么**：你觉得Markdown列表不够直观，想为每个生成的周报建议添加一个“一键复制”按钮。或者，你想把结果用更丰富的卡片样式展示。
*   **如何做**：这需要修改结果展示区域的HTML和CSS，并可能添加新的JavaScript函数（如复制到剪贴板）。此时应专注于UI/UX的改进，不影响核心的“输入-组装Prompt-请求AI”链路。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格调性”选择输入**：
    *   **操作**：在表单中添加一个下拉菜单，选项如“专业严谨”、“轻松搞笑”、“温暖治愈”、“科技感”。
    *   **修改点**：在Prompt的“任务指令”部分加入一条：“请使用【用户选择的风格】的文案风格来撰写选题。”
    *   **效果**：让AI生成的内容更符合品牌人格或平台调性。

2.  **接入多模型API，实现“专家会诊”**：
    *   **操作**：在配置模态框中，增加一个“备用模型”选项（如GLM、GPT），并修改`generateTopics`函数。
    *   **修改点**：函数中不再只调用DeepSeek，而是同时或依次调用两个不同的模型API，将它们的返回结果并排展示或进行对比。
    *   **效果**：用户可以获得来自不同AI的创意角度，激发更多灵感。

3.  **拆分为“两步引导”式页面**：
    *   **操作**：创建两个页面（或用标签页/步骤条在单页面内实现）。第一步只收集品牌信息并生成“品牌画像”；第二步基于这个画像和实时输入的热点，生成选题。
    *   **修改点**：将数据存储从纯前端变量改为更持久的方式（如URL参数、IndexedDB），以便在页面间传递。为第一步设计一个分析品牌调性的Prompt。
    *   **效果**：流程更清晰，品牌信息可复用，用户体验更专业。

4.  **增加“灵感库”和历史记录功能**：
    *   **操作**：在页面底部或侧边栏新增一个区域。
    *   **修改点**：每次成功生成选题后，将本次的输入参数（品牌、关键词）和输出结果的核心标题，以一个可点击的卡片形式保存到`localStorage`中。点击历史卡片，可以重新加载当时的输入和结果。
    *   **效果**：避免灵感丢失，方便回溯和对比不同时间的策划思路。

5.  **优化交互：提供热点关键词的“推荐”或“一键导入”**：
    *   **操作**：在“热点关键词”文本框上方增加一个“获取今日热搜”按钮。
    *   **修改点**：点击该按钮，调用一个免费的公开热搜API（如微博、百度热榜的RSS或简易API），将返回的热词列表自动填充到文本框中。
    *   **效果**：极大降低用户获取热点信息的门槛，让工具更“自动化”。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合进行事实核查或生成精确数据**：AI可能“一本正经地胡说八道”。它生成的“传播潜力：⭐⭐⭐⭐⭐”是基于模式的猜测，并非真实数据分析结果。**切勿**直接将其用于需要绝对准确性的场景，如法律文书、医疗建议、财务数据生成。

2.  **不适合替代人类的最终判断和创意**：它是一个“灵感加速器”，而不是“自动创作机”。它提供的选题角度可能流于表面、同质化，或与品牌真实情况有偏差。运营者必须对其结果进行筛选、评估和二次加工。

3.  **不适合处理极度敏感或私密信息**：虽然API调用是端到端加密，但你的品牌信息、热点关键词和生成的选题内容会发送给AI服务提供商（DeepSeek）。**切勿**输入未公开的商业机密、个人隐私信息或任何你不希望第三方可能接触到的内容。

4.  **不适合作为稳定的生产环境工具**：这是一个纯前端的演示项目。API Key暴露在浏览器中，存在安全风险；没有错误重试、速率限制、使用量统计等生产级功能。如果你想团队使用或长期使用，需要开发后端服务来代理API调用、管理密钥和用户。

**如果你想做的是**：一个能自动发布内容到平台、能分析真实传播数据、或能进行深度竞品分析的系统，那么这个网页只是一个起点。你需要将其与后端服务、数据库、真正的数据分析工具以及各平台的官方API相结合，构建一个更复杂的系统。
