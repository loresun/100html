# 微信公众号排版助手 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你写了一篇文章（可能是草稿、笔记或从其他地方复制的内容），想在微信公众号发布时，它看起来更专业、更美观。你不想花大量时间手动调整字体、颜色、间距，或者你不太懂 HTML/CSS，但又希望文章有统一的视觉风格。

- **适合**：内容创作者、自媒体运营、需要快速美化文章的非技术人员。
- **不适合**：需要像素级精确控制设计、使用复杂交互组件（如视频播放器、投票插件）的场景。

## 【二】使用方式（给第一次接触的人）

1.  **页面输入是什么？**
    - **原始文案**：把你写好的文章粘贴到左侧的大文本框里。
    - **排版风格**：在下方选择一种你喜欢的视觉风格（如“清新”、“商务”）。
    - **排版增强**：勾选你想要的额外效果，比如“智能引用框”、“关键词高亮”。
    - **自定义指令**：可以告诉 AI 你的特殊要求，比如“让标题更吸引人”。

2.  **用户通常会做哪几步操作？**
    1.  粘贴文章内容。
    2.  选择一个喜欢的风格。
    3.  （可选）勾选一些增强选项。
    4.  点击 **“AI 智能排版”** 按钮。
    5.  在右侧的手机预览图中查看效果。
    6.  如果满意，点击 **“复制到公众号”**。

3.  **输出结果长什么样？**
    - 右侧会模拟一个手机屏幕，展示你的文章应用了所选风格后的样子。标题、段落、引用块、列表等都会变得美观、统一。
    - 最终复制到剪贴板的是**带有内联样式的 HTML 代码**，可以直接粘贴到微信公众号后台的编辑器中，样式会保留。

4.  **有哪些容易忽略的使用细节？**
    - **快速排版**：如果只是想把 Markdown 格式（比如用 `#` 表示标题、`**`表示加粗）快速转成 HTML，可以点“快速排版”，它不调用 AI，速度更快。
    - **字数统计**：预览区顶部会显示文章字数。
    - **导出功能**：除了复制，还可以“导出”为一个完整的 HTML 文件备用。
    - **API 配置**：第一次使用“AI 智能排版”前，需要点击右上角“设置”，填入你的 DeepSeek API Key。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个模块：

1.  **控制面板模块（左侧）**
    - **职责**：接收用户的所有输入和配置。它是整个应用的“大脑”，负责收集原始内容、风格偏好和增强指令。
    - **包含**：内容输入框、风格选择按钮组、增强选项复选框、自定义指令输入框、操作按钮。
    - **逻辑**：用户在这里进行的所有选择，都会被存储在 Vue 的响应式数据（`input`, `options`, `selectedStyle`）中，为后续处理做好准备。

2.  **预览渲染模块（右侧）**
    - **职责**：实时展示排版效果。它是“所见即所得”的窗口。
    - **包含**：模拟手机外壳、文章内容渲染区域、操作按钮（复制、导出）。
    - **逻辑**：它监听左侧数据的变化。当 `formattedHtml`（AI 处理结果）或 `quickPreview`（Markdown 直接转换结果）更新时，它会立即将 HTML 内容渲染到 `div` 中，并应用对应的 CSS 样式类（如 `style-fresh`）。

3.  **AI 服务模块（幕后）**
    - **职责**：作为“智能美工”，理解用户需求并生成代码。
    - **包含**：`buildPrompt` 函数（组装指令）、`callDeepSeek` 函数（调用 API）。
    - **逻辑**：这是一个 **“输入配置 → 构建 Prompt → 调用 API → 处理返回”** 的管道。它将分散的用户配置（风格、选项、自定义指令）整合成一段清晰的、给 AI 的“工作说明书”（Prompt）。

**最值得学习的设计**：
- **“配置即 Prompt”的映射思想**：页面上的每一个选择（风格、复选框）都不是孤立的，它们最终都被巧妙地编织进一段给 AI 的文本指令中。这使得复杂的排版需求可以通过简单的 UI 交互来配置，而无需编写复杂的代码逻辑。
- **实时预览与数据绑定**：利用 Vue 的响应式系统，左侧的任何改动都能即时在右侧看到反馈（至少是基础 Markdown 渲染的反馈），提供了流畅的用户体验。

## 【四】Prompt / AI 逻辑是如何被设计的？

1.  **Prompt 的角色**：扮演“**设计需求文档**”和“**技术规范说明书**”的双重角色。它告诉 AI：① 你要处理什么内容；② 你想要什么风格效果；③ 必须遵守哪些技术限制（如微信公众号的 CSS 限制）。

2.  **解决的问题**：主要是“**生成问题**”。AI 的任务不是理解文章的深层含义，而是根据明确的视觉和格式规则，将输入文本重新“包装”成符合要求的 HTML 代码。

3.  **关键变量**：
    - **`styleDesc`**：根据用户选择的风格 ID，映射成一段详细的文字描述（如“绿色主题，标题高亮底色”）。
    - **`optionsList`**：将用户勾选的布尔值选项（`autoQuote: true`）转化为具体的任务描述（“为重要观点添加引用框”）。
    - **`input.customPrompt`**：用户自由发挥的补充要求。
    - **技术约束**：如“输出纯 HTML”、“使用内联 CSS”、“不支持外部 CSS”等，这些是保证生成结果可用的关键。

4.  **只改 Prompt 的后果**：如果你只修改 `buildPrompt` 函数里的文本，而不改前端代码，你可以：
    - **改变设计风格**：即使 UI 上还叫“清新风格”，但实际生成的可能变成“复古风格”。
    - **增加或减少排版功能**：比如在 Prompt 里要求 AI 自动生成文章摘要并放在开头，即使页面上没有这个选项。
    - **更换目标平台**：把 Prompt 里的“微信公众号”改成“知乎专栏”或“小红书”，AI 就会生成适应另一套规则的排版。**但前提是，右侧预览的 CSS 样式可能不匹配**。

## 【五】如何模仿它，做出你自己的版本？

**模仿路径**（从最安全、改动最小开始）：

1.  **第一步：替换“皮肤”与场景**
    - **最安全**：保持所有代码结构、Vue 逻辑、API 调用方式完全不变。
    - **做什么**：
        - 修改 `styles` 数组里的 `name`（名称）和 `icon`（图标）。
        - 修改 CSS 中 `.style-xxx` 类的具体样式（颜色、边框、背景），打造一套全新的视觉主题。
        - 把页面标题、描述从“公众号排版”改成其他场景，如“**邮件模板美化器**”、“**个人博客文章格式化工具**”。
    - **效果**：你得到了一个功能一模一样，但外观和适用场景不同的新工具。

2.  **第二步：调整输入与 Prompt**
    - **中等风险**：开始修改核心逻辑的“配方”。
    - **做什么**：
        - 在左侧控制面板**增加或减少**一些复选框或输入框（例如，增加一个“目标读者：程序员/设计师/学生”的下拉菜单）。
        - 在 `buildPrompt` 函数中，将新增的配置变量融入到给 AI 的指令中。
        - 微调 Prompt 的措辞，让 AI 更符合新场景的需求（例如，邮件模板更注重简洁和正式）。
    - **效果**：你的工具开始具备独特的、差异化的排版逻辑。

3.  **第三步：改变输出与交互形式**
    - **较高风险**：改动数据呈现和用户操作流。
    - **做什么**：
        - 改变右侧预览的布局，比如从模拟手机变成模拟桌面网页或 A4 纸。
        - 增加新的输出方式，比如“一键复制为 Markdown”、“生成分享图”。
        - 将“单次排版”改为“多步骤向导”式的交互。
    - **效果**：工具的完整性和用户体验得到大幅提升，更贴近你的专属需求。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“内容类型”预设**：
    - **操作**：在“排版风格”下增加一个下拉菜单，选项如“产品发布”、“活动通知”、“教程指南”、“个人随笔”。
    - **原理**：将不同的内容类型映射到 Prompt 中，让 AI 不仅调整样式，还能调整内容结构（如教程自动添加步骤编号，活动通知突出时间地点）。

2.  **本地模型替换云端 API**：
    - **操作**：在设置中增加一个“使用本地 Ollama”的选项。修改 `callDeepSeek` 函数，当选择本地时，向 `http://localhost:11434/api/generate` 发送请求（使用 `llama3.2` 等模型）。
    - **原理**：降低使用门槛和成本，保护隐私。学习如何与本地 AI 服务交互。

3.  **拆分为“编辑”与“历史”页面**：
    - **操作**：将当前页面作为主编辑页。增加一个“历史记录”页面，使用 `localStorage` 保存每次排版的结果（标题、时间、内容摘要），并可以点击重新加载编辑。
    - **原理**：学习单页面应用(SPA)的简单路由管理和数据持久化。

4.  **优化交互：添加“部分重排”功能**：
    - **操作**：在预览区域，允许用户用鼠标选中一段话，然后出现一个浮动按钮“优化此段”，点击后仅将选中内容发送给 AI 进行重写或润色。
    - **原理**：提升工具精细度，学习如何获取选区内容并与现有 AI 流程结合。

5.  **增加“样式自定义器”**：
    - **操作**：在“设置”弹窗旁增加一个“高级样式”按钮，弹出一个面板，允许用户通过颜色选择器、滑块等，实时调整当前风格的主色、圆角、阴影等，并即时在预览中反映。
    - **原理**：将静态的 CSS 样式类变为动态可配置的变量，学习 CSS 变量和更复杂的动态样式绑定。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做专业的平面设计**：它生成的是**基于文本的、结构化的内容排版**，不是海报、传单或复杂的图文混排设计。如果需要制作包含大量自定义位置图片、艺术字的海报，应使用 Figma、Canva 或专业设计软件。
2.  **不适合处理极其复杂的文档**：对于包含大量表格、数学公式、代码片段（需要语法高亮）、复杂图表的内容，它的支持有限。AI 可能无法完美处理，专门的文档工具（如 Typora、Notion）或代码编辑器是更好的选择。
3.  **不适合需要严格品牌规范的公司**：如果公司对字体、字号、色号、间距有像素级精确的规范手册，本工具自动生成的结果可能无法 100% 符合。这种情况下，应基于品牌规范手动开发定制模板。
4.  **不是内容创作 AI**：它的核心是“排版”和“格式化”，而不是“写作”。虽然自定义指令可以要求 AI 润色，但对于从零生成高质量长文，专门的写作 AI 工具会更合适。

---
**总结**：这个网页是一个优秀的“**AI 赋能传统工作流**”的范例。它抓住了“微信公众号排版麻烦”这个痛点，用清晰的 UI 收集用户意图，再用精心设计的 Prompt 驱动 AI 完成技术实现。你的学习重点应是理解这种 **“用户友好界面”与“AI 指令工程”之间的桥梁作用**，并尝试将其应用到其他领域。
