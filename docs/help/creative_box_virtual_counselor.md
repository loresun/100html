# 虚拟心理咨询室 - 学习指南

## 【一】这个网页解决了什么问题？

这个网页是一个**轻量级的AI心理支持工具**，它主要解决以下场景中的需求：

**适合的使用场景：**
- 当你感到情绪波动，需要有人倾听和回应，但暂时不方便或不想找真人倾诉时
- 当你想要整理自己的情绪，通过“说出来”的方式理清思路时
- 当你需要一些基础的心理健康知识和放松技巧时
- 作为日常情绪记录和觉察的工具

**不适合的情况：**
- **紧急心理危机**：如有自伤、自杀念头，应立即联系专业危机干预热线
- **严重心理疾病**：如重度抑郁、焦虑症等需要专业诊断和治疗的情况
- **深度心理治疗**：需要长期、系统的治疗关系
- **法律或医疗建议**：AI无法提供专业法律或医疗意见

本质上，这是一个**情绪陪伴和初步支持工具**，而不是专业治疗的替代品。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **心情选择**：6种基本情绪（开心、难过、焦虑等）+ 强度滑块
2. **文字输入框**：在中间聊天区域，可以输入任何你想说的话
3. **快速回复按钮**：三个预设的常见开场白

**用户通常会做哪几步操作？**
1. **第一步：选择当前心情**
   - 点击左侧的心情图标（如😊开心）
   - 拖动下方的强度滑块（1-10分）

2. **第二步：开始对话**
   - 在中间输入框打字，或点击快速回复按钮
   - 按回车或点击发送按钮

3. **第三步：查看反馈和建议**
   - 右侧会显示情感分析和专业建议
   - 可以点击心理健康资源查看具体技巧

4. **第四步：使用辅助功能**
   - 点击“开始呼吸练习”进行放松
   - 右上角齿轮可以配置API（高级用户）

**输出结果长什么样？**
- **对话回复**：AI以心理咨询师的口吻回应，温暖、理解
- **情感分析**：右侧显示当前情绪状态和洞察
- **专业建议**：针对对话内容给出具体建议
- **监控图表**：左侧显示情绪稳定性、压力水平等指标

**容易忽略的使用细节：**
1. **心情选择影响回复**：AI会知道你当前的心情状态
2. **快速回复是捷径**：点击就能直接发送，不用打字
3. **呼吸练习有计时**：按照4-7-8呼吸法的节奏引导
4. **资源库是静态内容**：点击右侧卡片查看具体技巧
5. **可以导出记录**：右下角可以导出整个对话为JSON文件

## 【三】核心结构拆解（学习重点）

这个页面采用了**三栏式布局**，每个区域有明确分工：

### **模块1：左侧面板 - 状态输入与监控**
- **心情选择区**：6个情绪按钮 + 强度滑块
  - 职责：收集用户当前情绪状态
  - 设计亮点：视觉反馈（选中状态）、实时更新右侧分析
  
- **呼吸练习区**：动画圆球 + 引导文本
  - 职责：提供即时放松工具
  - 设计亮点：交互式计时器、状态切换（开始/停止）
  
- **情感监控区**：三个进度条图表
  - 职责：可视化情绪指标
  - 设计亮点：根据心情动态计算数值、颜色编码（绿/黄/红）

### **模块2：中间面板 - 对话交互**
- **聊天显示区**：消息气泡容器
  - 职责：显示对话历史
  - 设计亮点：自动滚动、用户/AI消息样式区分
  
- **输入与快速回复区**：输入框 + 三个快捷按钮
  - 职责：接收用户输入
  - 设计亮点：回车发送、快速入口降低使用门槛
  
- **打字指示器**：三个跳动的圆点
  - 职责：提供等待反馈
  - 设计亮点：简单的CSS动画创造“正在思考”的错觉

### **模块3：右侧面板 - 分析与资源**
- **情感分析区**：当前状态卡片 + 洞察卡片
  - 职责：解析和展示情绪信息
  - 设计亮点：基于关键词的简单分析、渐进式显示
  
- **专业建议区**：建议卡片
  - 职责：提供针对性建议
  - 设计亮点：根据对话内容匹配建议、时间戳
  
- **资源库区**：三个可点击的资源卡片
  - 职责：提供心理健康知识
  - 设计亮点：模态框展示详细内容、分类清晰
  
- **会话管理区**：导出和清空按钮
  - 职责：数据管理
  - 设计亮点：JSON格式导出、确认提示防止误操作

### **隐藏模块：API配置面板**
- 职责：允许用户自定义AI后端
- 设计亮点：本地存储保存配置、优雅的显示/隐藏切换

### **输入 → 处理 → 输出 的逻辑链路：**
```
用户选择心情 + 输入文字
    ↓
[前端] 构建包含心情信息的Prompt
    ↓
[API调用] 发送到AI模型
    ↓
[AI] 生成心理咨询风格的回复
    ↓
[前端] 显示回复 + 更新分析面板
    ↓
[前端] 基于关键词生成建议
```

### **最值得学习的设计：**
**“状态感知的对话系统”** - 页面巧妙地将用户选择的心情状态融入Prompt，让AI的回复更具针对性。这种“前端状态 + AI上下文”的结合方式，是很多AI应用的核心模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演的角色：**
Prompt是**AI的“角色设定和对话指南”**，它告诉AI：“你现在是一位心理咨询师，请用这样的方式回应。”

**它解决的是“生成问题”还是“理解问题”？**
主要是**生成问题** - 指导AI如何生成合适的回复。但通过包含用户心情信息，也部分解决了**理解问题** - 让AI更理解用户的处境。

**Prompt中的关键变量：**
1. **系统角色**：“你是专业的心理咨询师...”
2. **职责清单**：5条具体职责（情感支持、分析、建议等）
3. **回应原则**：6条指导原则（温暖语气、验证感受等）
4. **格式限制**：“用中文，200字以内”
5. **动态信息**：用户当前心情和强度（如果已选择）

**如果只改Prompt，不改代码，会发生什么变化？**
- 改**角色**：如改成“生活教练”、“学习伙伴” - AI的回复风格会完全改变
- 改**原则**：如去掉“避免诊断” - AI可能给出医疗建议（有风险）
- 改**格式**：如改成“每次回复3个要点” - 输出结构会变化
- 改**语言**：如改成英文 - AI会用英文回复

**Prompt设计的巧妙之处：**
1. **边界清晰**：明确说“避免诊断或治疗建议”，降低风险
2. **语气指导**：强调“温暖、理解”，而不是冷冰冰的回复
3. **实用限制**：“200字以内”防止AI啰嗦
4. **专业定位**：强调“专业心理咨询师”而非普通聊天

## 【五】如何模仿它，做出你自己的版本？

### **安全起步的模仿路径：**

**第一步：保持结构不变，替换使用场景（最安全）**
- 目标：做一个“AI学习伙伴”或“健身教练”
- 操作：
  1. 修改标题和描述
  2. 左侧：把心情换成“学习状态”（专注、分心、困惑等）或“身体感受”（精力充沛、疲劳、酸痛等）
  3. 右侧：把心理健康资源换成“学习技巧”或“健身知识”
  4. 不改代码逻辑，只改文字内容

**第二步：调整输入字段和Prompt**
- 目标：让AI更适合新场景
- 操作：
  1. 修改Prompt中的角色描述（如“你是一位耐心的学习导师”）
  2. 调整快速回复按钮的文字
  3. 修改情感分析的关键词（如把“焦虑”换成“学习难点”）
  4. 测试对话效果，微调Prompt

**第三步：改变输出形式或展示方式**
- 目标：优化用户体验
- 操作：
  1. 右侧面板改成“学习进度追踪”或“健身计划”
  2. 增加新的可视化图表
  3. 修改资源模态框的内容
  4. 调整颜色主题匹配新场景

**从哪里下手最安全？**
从**文字替换**开始 → 然后改**Prompt** → 最后改**交互和样式**。

## 【六】3–5个可直接尝试的改造方向

### **1. 增加更多输入维度**
- **具体操作**：
  - 在心情选择下方增加“触发事件”选择（工作、家庭、健康、社交等）
  - 增加“持续时间”滑块（情绪持续了多久）
  - 增加“身体反应”多选（失眠、食欲变化、头痛等）
- **效果**：让AI更全面理解用户处境

### **2. 增强情感分析能力**
- **具体操作**：
  - 用更复杂的关键词匹配或简单的情感分析API
  - 增加“情绪变化趋势”图表（基于对话历史）
  - 添加“建议有效性”反馈按钮（有用/没用）
- **效果**：提供更精准的分析和建议

### **3. 个性化资源推荐**
- **具体操作**：
  - 根据对话内容动态推荐资源（而不是固定三个）
  - 增加外部资源链接（专业文章、视频、本地服务机构）
  - 添加“收藏”功能，让用户保存有用的建议
- **效果**：资源更有针对性，提高实用性

### **4. 多模型/API支持**
- **具体操作**：
  - 在API配置中增加更多模型选项
  - 添加“风格切换”（如：更温暖/更直接/更简洁）
  - 实现简单的A/B测试，让用户选择喜欢的回复风格
- **效果**：适应不同用户的偏好

### **5. 移动端优化和离线功能**
- **具体操作**：
  - 使用响应式设计优化小屏幕体验
  - 添加PWA支持，可安装到手机桌面
  - 实现基础的离线对话（使用本地小型模型或预设回复）
- **效果**：随时随地可用，减少网络依赖

## 【七】这个网页不适合做什么？（边界提醒）

### **明确的局限性：**
1. **不是危机干预工具**
   - 如果用户表达自伤、自杀念头，页面无法提供即时救援
   - **应该**：明确提示紧急联系方式，或接入危机干预转接

2. **不是诊断工具**
   - 基于关键词的简单分析不能替代专业评估
   - **应该**：始终强调“如需诊断请咨询专业医生”

3. **缺乏深度记忆和连续性**
   - 每次对话相对独立，缺乏长期治疗关系
   - **应该**：明确说明这是单次或短期支持

4. **文化和个人差异处理有限**
   - Prompt基于通用心理学原则，可能不适用所有文化或个人
   - **应该**：增加文化敏感性说明

5. **无法处理复杂现实问题**
   - 如法律纠纷、家庭暴力、严重经济问题等
   - **应该**：提供相应专业机构的转介信息

### **如果用户想做X，应该换什么工具？**
- **想做正式心理咨询** → 寻找持证心理咨询师
- **需要医疗诊断** → 预约精神科医生
- **处于紧急危机** → 拨打心理危机热线
- **需要长期支持** → 加入支持团体或定期咨询
- **处理具体现实问题** → 寻找相应领域的专业人士
