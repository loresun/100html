# 营销文案策略机 - 帮助文档

## 【一】这个网页解决了什么问题？

想象一下，你是一位图书编辑、营销人员或内容创作者，手头有一本新书即将上市。你需要为这本书策划一套完整的营销文案，包括在不同平台（如小红书、抖音、电商页面）上使用的宣传语、核心卖点提炼和传播模板。手动构思这些内容不仅耗时，还容易遗漏关键信息或风格不统一。

这个网页就是你的“营销文案策略机”。它通过一个结构化的表单，引导你输入图书的核心信息，然后为你生成一套**系统化、可执行的营销文案框架和提示词**。它特别适合在以下场景使用：
*   **新品上市前**：快速搭建营销内容体系。
*   **头脑风暴时**：为营销团队提供结构化的讨论起点。
*   **跨渠道内容规划**：确保不同平台的话术风格统一且各有侧重。

**不适合**需要直接生成最终文案成品、进行深度数据分析或处理复杂多媒体内容的场景。它提供的是“策略框架”和“生成指令”，而非最终的、可直接发布的文案。

## 【二】使用方式（给第一次接触的人）

1.  **配置API（首次使用）**：点击页面右上角的齿轮图标（⚙️），在弹出的窗口中输入你的DeepSeek API Key，然后点击“保存”。（这一步是为了后续可能的AI调用做准备，当前版本仅生成提示词，不实际调用API）。
2.  **填写营销信息**：在左侧的“营销信息”区域，依次填写：
    *   **书名**：你的图书名称。
    *   **核心卖点**：这本书最吸引人的几个特点。
    *   **目标读者**：这本书主要写给谁看。
    *   **核心渠道**：你计划在哪些平台推广（如小红书、抖音）。
    *   **文案风格**：你希望文案呈现出的语气（如温柔鼓励、理性专业）。
3.  **生成策略**：填写完毕后，点击蓝色的“**生成营销文案**”按钮。
4.  **查看结果**：点击后，右侧面板会立即更新：
    *   **AI 提示词**：显示一个结构完整、包含了所有你输入信息的AI指令（Prompt）。你可以直接复制这个提示词，粘贴到任何AI聊天工具（如ChatGPT、DeepSeek）中，让它为你生成具体的文案内容。
    *   **渠道文案结构**：列出了撰写渠道文案时建议遵循的通用结构（开场钩子、价值陈述、行动号召）。
    *   **交付物建议**：提醒你最终应该产出哪些具体的营销物料。

**容易忽略的细节**：
*   即使不配置API Key，你也可以正常使用“生成提示词”的核心功能。
*   所有输入框都有示例文本，照着格式填写思路会更清晰。
*   生成的“AI提示词”是整个页面的核心产出，它是你与AI协作的“工作说明书”。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个模块：

1.  **信息输入与配置模块（左侧）**
    *   **职责**：收集用户关于图书营销的所有关键信息，并提供系统配置入口。
    *   **组成**：包含5个文本输入字段（书名、卖点等）、一个生成按钮，以及右上角的全局API配置入口。
    *   **逻辑**：用户在此模块完成信息填充和必要设置。

2.  **策略与指令输出模块（右侧）**
    *   **职责**：将左侧输入的信息，加工、组织成结构化的策略框架和可执行的AI指令。
    *   **组成**：包含三个子面板——“AI提示词”、“渠道文案结构”、“交付物建议”。
    *   **逻辑**：点击生成按钮后，此模块接收左侧的输入数据，按照预设的模板进行格式化，并展示出来。

3.  **全局配置模块（弹窗）**
    *   **职责**：管理应用级别的设置（目前主要是API密钥），并实现跨工具的配置共享。
    *   **逻辑**：通过`localStorage`将API Key保存为全局配置，方便同一域名下的其他工具读取。

**核心逻辑链路**：
**用户输入**（书名、卖点等） → **点击生成按钮** → **前端脚本处理**（将输入数据拼接进预设的Prompt模板） → **输出展示**（结构化提示词、文案框架、物料清单）。

**最值得学习的设计**：
**“提示词工程的前端化”**。这个页面没有直接调用AI，而是将构建一个高质量Prompt的过程做成了一个**可视化、引导式的表单**。它把原本需要用户在脑中构思或手动编写的复杂指令，拆解成几个简单的填空题，极大地降低了使用门槛，并保证了生成指令的结构化和完整性。这是将AI能力“平民化”和“流程化”的优秀范例。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：在这个页面中，Prompt是**核心的、待生成的“产品”**。它是一份详尽的“工作任务书”，用户可以将它直接交付给AI执行。
*   **解决的问题**：它主要解决的是“**生成问题**”。这个Prompt明确指令AI扮演“出版营销策划师”的角色，并按照一个非常具体的结构（核心主张、卖点提炼、渠道话术等）来生成内容。它确保了AI输出的内容不是随意的，而是符合营销专业框架的。
*   **关键变量**：Prompt模板中的 `{title}`, `{sellingPoints}`, `{audience}`, `{channels}`, `{tone}` 就是关键变量。它们直接来自用户的输入，是Prompt动态化的部分。
*   **只改Prompt的后果**：如果你只修改代码中`promptOutput.textContent`后面的那段模板字符串，而不改动任何其他代码，那么：
    *   页面的外观和操作流程完全不变。
    *   但最终生成的“AI提示词”的内容结构、角色设定、输出要求会全部改变。
    *   例如，你可以把模板从“出版营销”改成“APP功能宣传”，那么它就会变成一个“APP宣传文案策略机”。

## 【五】如何模仿它，做出你自己的版本？

如果你想创建一个类似但用途不同的工具，请遵循以下安全的模仿路径：

1.  **第一步：替换使用场景与字段（最安全）**
    *   保持HTML结构和CSS样式基本不变。
    *   修改`<title>`和页面中的大标题，例如改为“**短视频脚本创意机**”。
    *   将左侧输入模块的标签和占位符替换成新场景所需的信息。例如：
        *   “书名” → “视频主题”
        *   “核心卖点” → “产品/服务亮点”
        *   “目标读者” → “目标观众画像”
        *   “核心渠道” → “发布平台（抖音/B站/视频号）”
        *   “文案风格” → “视频风格（搞笑/科普/治愈）”

2.  **第二步：重写核心Prompt模板**
    *   在JavaScript代码中找到`promptOutput.textContent = `...` 这一行。
    *   根据你的新场景，完全重写这段Prompt模板。明确AI的角色、任务和输出格式。例如，角色可以改为“资深短视频编导”，输出要求可以改为“1. 黄金3秒开场白 2. 核心内容分段 3. 结尾互动话术”。

3.  **第三步：调整右侧的策略建议**
    *   修改“渠道文案结构”和“交付物建议”两个列表的内容，使其符合新场景的专业知识。例如，“渠道文案结构”可以改为“短视频脚本结构”，“交付物建议”可以列出“分镜脚本”、“口播文案”、“话题标签”等。

完成这三步，你就拥有了一个全新的、属于你的策略生成工具。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让策略更精准**：
    *   在表单中增加“**竞品分析**”文本框，让用户输入主要竞品的卖点。
    *   增加“**营销预算/资源**”单选按钮（如“高预算多渠道”、“小成本精准投放”），让生成的Prompt能考虑到执行层面的限制。

2.  **从“生成指令”升级到“生成内容”**：
    *   利用已配置的DeepSeek API Key，改造`generateBtn`的点击事件。
    *   点击后，不再仅仅显示Prompt，而是将构造好的Prompt直接通过API发送给DeepSeek模型。
    *   在页面下方新增一个“**AI生成结果**”区域，以流式或一次性输出的方式，展示模型根据你的Prompt生成的实际文案内容。

3.  **拆解流程，实现多步骤向导**：
    *   将当前的单页拆成两个页面：`1_input.html` 和 `2_output.html`。
    *   在输入页面收集信息，点击生成后，将数据通过URL参数或`localStorage`传递到输出页面。
    *   在输出页面，不仅可以展示Prompt，还可以设计多个标签页，分别展示“核心主张”、“渠道话术”、“传播模板”等AI生成的具体内容，使结果更清晰。

4.  **优化交互与体验**：
    *   为“生成营销文案”按钮添加加载状态（loading spinner），特别是在未来接入真实API时，给用户明确的反馈。
    *   为生成的“AI提示词”添加一个“一键复制”按钮，提升操作效率。
    *   增加“历史记录”功能，将用户每次生成的信息和对应的Prompt保存在`localStorage`中，方便回顾和复用。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合直接产出最终稿件**：它产出的是“策略”和“指令”，不是打磨好的、可直接发布的文案。AI根据这些指令生成的内容，通常需要人工进行二次润色、调整和本地化。
*   **不适合进行深度市场分析**：它无法替代市场调研工具或数据分析平台。它的策略基于你输入的主观信息，而非客观的市场数据。
*   **不适合生成视觉或多媒体内容**：它专注于文本策略。如果你需要设计海报、视频脚本分镜或音频素材，应使用专门的视觉设计工具或更专业的AI视频生成工具。
*   **不适合处理高度定制化、复杂的B2B或技术产品营销**：对于技术参数极多、客户决策链复杂的场景，这种通用模板可能过于简单，需要更专业的咨询和定制化方案。

**简单来说**：这是一个强大的“**头脑风暴助手**”和“**内容规划蓝图生成器**”，但它不是全自动的营销内容生产线。它的价值在于提升你与AI协作的效率和专业性起点，而不是取代你的专业判断和创意工作。
