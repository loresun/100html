# Prompt 优化工坊 - 帮助文档

---

## 【一】这个网页解决了什么问题？

想象一下，你正在使用 ChatGPT、Claude 或 DeepSeek 等 AI 工具，但总觉得它给出的回答不够精准、不够专业，或者总是偏离你的本意。问题可能不在于 AI 模型本身，而在于你给它的“指令”——也就是 Prompt。

这个网页就是一个 **“Prompt 医生”** 兼 **“Prompt 教练”**。它专门解决“如何向 AI 清晰、高效地表达需求”这个痛点。

*   **适合的场景**：
    *   当你有一个模糊的想法，但不知道如何组织成 AI 能理解的指令时。
    *   当你觉得自己的 Prompt 效果不佳，想让它更专业、更有效时。
    *   当你需要针对不同场景（如写营销文案、生成代码、分析数据）快速获得高质量的 Prompt 模板时。
    *   当你希望了解自己 Prompt 的优缺点，并学习如何改进时。

*   **不适合的场景**：
    *   如果你需要 AI 直接处理文件、分析图片或进行实时对话，这个工具不提供这些功能。
    *   如果你已经是非常资深的 Prompt 工程师，对 Prompt 结构有深刻理解，这个工具可能过于基础。
    *   它不直接生成文章、代码或分析报告，它的核心产品是 **“更好的指令”**。

## 【二】使用方式（给第一次接触的人）

1.  **输入是什么？**
    *   **核心输入**：把你想要优化的、原始的 Prompt 粘贴到“原始 Prompt”大文本框里。比如：“帮我写一篇介绍 Python 的文章”。
    *   **辅助输入**：你可以选择这个 Prompt 的“使用场景”（如营销文案、代码生成），选择想要生成的“优化版本”（如简洁版、详细版），指定“目标模型”（如 GPT、Claude），还可以添加“额外要求”（如“输出需要中英双语”）。

2.  **通常的操作步骤**：
    1.  打开页面，在左侧面板的“原始 Prompt”框里粘贴你的指令。
    2.  （可选）根据你的需求，点选下方的“使用场景”、“优化版本”等选项。
    3.  点击中央紫色的 **“一键优化 Prompt”** 按钮。
    4.  等待约 15-30 秒，AI 会进行分析和优化。
    5.  在右侧结果区，查看 AI 对你的 Prompt 的“诊断报告”和生成的多个“优化版本”。

3.  **输出结果长什么样？**
    *   **诊断报告**：像一个体检单，列出你原始 Prompt 可能存在的问题（如“指令模糊”、“缺乏上下文”），并给出一个百分制评分和详细分析。
    *   **优化版本**：根据你的选择，生成多个不同风格的优化后 Prompt。每个版本都像一张精美的卡片，包含优化后的完整指令、评分和优化要点说明。

4.  **容易忽略的使用细节**：
    *   **首次使用需配置**：点击右上角“设置”按钮，填入你的 DeepSeek API Key，否则无法使用优化功能。
    *   **模板库是捷径**：如果你不知道从何写起，可以切换到“模板库”标签页，直接使用或参考内置的优质 Prompt 模板。
    *   **一键复制**：每个优化版本右上角都有复制按钮，点击即可将优化后的 Prompt 复制到剪贴板，直接拿去用。
    *   **保存自己的模板**：在模板库底部可以“添加自定义模板”，把你常用的、好用的 Prompt 保存下来，方便下次直接调用。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个大模块，像一个高效的工作流水线：

1.  **控制中心（左侧面板）**
    *   **职责**：收集用户的所有输入和配置。它有两个模式：“优化 Prompt”模式负责收集待优化的指令和参数；“模板库”模式负责展示和选择预制模板。
    *   **设计亮点**：使用了**标签页（Tab）** 来切换两种核心功能，保持了界面整洁。输入项通过清晰的标签、图标和友好的提示语引导用户，降低了使用门槛。

2.  **处理引擎（隐藏的逻辑层）**
    *   **职责**：这是页面的“大脑”。当用户点击“一键优化”后，它会将左侧收集的所有信息（原始 Prompt、场景、版本选择等）打包，按照预定格式组织成一个新的、更复杂的 Prompt（称为“元Prompt”），然后调用 DeepSeek 的 API。
    *   **逻辑链路**：`用户输入 -> 组装“元Prompt” -> 调用AI API -> 解析AI返回的JSON -> 生成结果数据`。最关键的一步是 **“组装元Prompt”**，它决定了 AI 会以什么角色、什么格式来执行优化任务。

3.  **展示车间（右侧面板）**
    *   **职责**：将处理引擎得到的结果，以直观、美观的方式呈现给用户。它负责展示诊断报告的详情、各个优化版本的卡片，并提供复制、导出等操作按钮。
    *   **设计亮点**：采用了**卡片化设计**和**渐进动画**。每个优化版本都是一个独立的卡片，信息层次分明（标题、内容、优化要点）。动画让结果的出现不突兀，提升了体验。

**最值得学习的设计**：
**“诊断+多版本优化”的一体化流程**。它不是简单地把你的 Prompt 扔给 AI 说“改一下”，而是先让 AI 扮演“医生”进行诊断（发现问题、打分），再让 AI 扮演“教练”生成多个有针对性的改进方案。这种“先分析后解决”的结构，极大地提升了结果的可信度和学习价值。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，Prompt 是**绝对的核心驱动力**。页面本身不进行复杂的逻辑判断，它的主要工作是 **“为用户和 DeepSeek AI 之间搭建一座高效沟通的桥梁”**。

1.  **扮演的角色**：Prompt 在这里解决的是 **“理解问题”** 和 **“生成问题”** 的结合。它首先要让 AI 理解“什么是一个好的 Prompt 优化任务”（通过系统 Prompt），然后引导 AI 根据用户的具体输入，生成结构化的优化结果。

2.  **关键变量**：在发送给 DeepSeek 的“元Prompt”中，以下几个信息是变量，由用户输入决定：
    *   `{原始Prompt}`：用户要优化的核心内容。
    *   `{使用场景}`：帮助 AI 从特定角度思考优化方向。
    *   `{目标模型}`：让 AI 的优化建议更具针对性（不同模型的特性略有不同）。
    *   `{需要生成的版本}`：告诉 AI 要输出几种特定类型的优化结果。
    *   `{额外要求}`：用户的个性化指令。

3.  **只改 Prompt 会怎样？**
    如果你只修改代码中的 `systemPrompt` 和 `userPrompt` 字符串（而不改页面布局和功能），那么这个工具的能力会发生**根本性变化**。
    *   例如，把“优化 Prompt”改为“优化简历”，把“诊断问题”改为“分析技能匹配度”，把“生成优化版本”改为“生成修改建议”。那么，这个页面就瞬间从一个“Prompt 优化工坊”变成了一个“简历优化助手”。
    *   **这揭示了本项目的本质**：页面是一个**通用框架**，通过更换核心的 Prompt，可以快速适配到无数个基于“分析-优化”模式的 AI 应用场景。

## 【五】如何模仿它，做出你自己的版本？

如果你想创建一个类似风格、但解决其他问题的 AI 工具，请遵循以下安全路径：

**第一步：保持结构不变，替换使用场景（最安全）**
*   **做什么**：不要动任何 HTML、CSS 和 Vue.js 的交互逻辑。只修改文字内容。
*   **怎么改**：
    1.  把标题“Prompt 优化工坊”改成你的主题，如“简历优化助手”。
    2.  把左侧输入区的标签“原始 Prompt”改成“原始简历内容”。
    3.  把“使用场景”的选项改成“求职岗位”，如“前端开发”、“产品经理”、“市场营销”。
    4.  把“优化版本”改成“修改建议版本”，如“突出项目版”、“突出技能版”、“通用简洁版”。
    5.  把右侧“诊断报告”改成“简历分析报告”，把“优化版本”改成“修改建议”。

**第二步：调整输入字段或核心 Prompt**
*   **做什么**：在第一步的基础上，根据新场景增加或减少输入字段，并重写发送给 AI 的“元Prompt”。
*   **怎么改**：
    1.  在左侧面板增加新的输入框，比如“目标公司”、“工作年限”。
    2.  找到 `optimizePrompt` 函数里的 `systemPrompt` 和 `userPrompt`，把它们的内容彻底重写。新的 Prompt 要指导 AI 如何分析简历、并根据新增加的输入字段生成建议。
    3.  同时修改结果展示区，确保能正确显示 AI 返回的新 JSON 数据结构（如“分析报告”、“修改建议”）。

**第三步：改变输出形式或展示方式**
*   **做什么**：当基本功能跑通后，可以优化视觉效果和交互，让它更符合你的主题。
*   **怎么改**：
    1.  修改 `style` 标签中的 CSS，更换主题颜色（比如从紫色系改为蓝色或绿色系）。
    2.  调整右侧结果卡片的布局，例如为“简历建议”设计一个更接近文档的预览样式。
    3.  增加新的交互，比如“一键导入到 LinkedIn”或“导出为 PDF”按钮。

**从哪里下手最安全？**
**从第一步开始**。仅仅替换文字和选项，你就能立刻得到一个外观完全不同、但运行逻辑完全一样的工具原型。这能帮你快速验证想法，而不用担心代码出错。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格语气”选择**：
    *   **操作**：在左侧面板“额外要求”上方，增加一个下拉菜单或按钮组，让用户选择优化后的 Prompt 风格，如“专业严谨”、“风趣幽默”、“热情鼓舞”、“简洁中性”。
    *   **效果**：使生成的 Prompt 更贴合用户的实际沟通场景和品牌调性。

2.  **接入多模型 API，并实现对比**：
    *   **操作**：在 API 设置中增加 OpenAI、Claude 等选项。优化时，可以同时（或让用户选择）向两个模型发送请求。在结果展示区，将同一个优化版本的不同模型生成结果并列展示，并标注差异。
    *   **效果**：让用户直观看到不同模型在理解优化指令上的特点，选择最适合自己的。

3.  **拆分为“快速优化”与“深度工坊”双页面**：
    *   **操作**：将当前页面作为“深度工坊”。再创建一个简化版页面，只保留“原始 Prompt”输入框和一个“快速优化”按钮，生成一个通用优化版本。从简化版可以跳转到当前这个功能齐全的页面。
    *   **效果**：满足不同层次用户的需求，新手可以快速上手，专家可以进行精细调整。

4.  **增加“优化历史”与“A/B 测试”功能**：
    *   **操作**：将每次优化的原始 Prompt 和结果保存在本地。新增一个“历史”标签页来回顾。允许用户将历史中的两个优化版本直接发送给 AI 进行对比测试（“哪个版本在实际对话中效果更好？”）。
    *   **效果**：形成学习闭环，让用户不仅能“得到”好 Prompt，还能通过实践“验证”和“选择”出最好的 Prompt。

5.  **优化交互体验：实时诊断预览**：
    *   **操作**：在用户输入“原始 Prompt”时，在文本框下方或旁边，实时显示简单的诊断提示（如通过字数、标点、关键词进行的基础分析），并给出即时修改建议（如“您的指令可能过于简短，建议补充上下文”）。
    *   **效果**：降低用户等待焦虑，在生成前就提供有价值的输入指导，提升工具的专业感和互动性。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **它不是万能的“AI 对话器”**：你不能在这里和 AI 进行多轮自由对话。它的核心是单次的、结构化的“指令优化”任务。如果你想聊天，请直接使用 ChatGPT 等平台。
2.  **它不保证优化后的 Prompt 100%有效**：AI 生成的优化建议基于通用原则，可能不完全适合你的极端特定场景。它提供的是高质量的“草案”和“思路”，最终仍需你在实际使用中微调。
3.  **它无法处理复杂文件或实时信息**：你不能上传文档、图片或让它访问最新网页信息来进行优化。所有优化都基于你输入的文字描述。
4.  **如果你需要的是“内容”而非“指令”**：比如，你最终想要一篇写好的文章、一段可运行的代码、一份数据分析图表，那么这个工具只是你的“第一步”。你需要将优化后的 Prompt 复制到真正的 AI 对话窗口中，才能得到最终的内容产出。

**简单来说**：这个网页是 **“生产优质鱼竿的工厂”**，而不是 **“直接给你鱼的池塘”**。它的价值在于赋能你，让你在任何一个“池塘”（AI 平台）里都能钓到更多、更好的“鱼”。
