# DeepSeek 创意写作专家 - 帮助文档

---

## 【一】这个网页解决了什么问题？

**使用场景**：当你需要快速创作一篇结构完整、内容优质的公众号文章，但又不想从零开始构思大纲、撰写内容、调整格式时，这个工具可以帮你自动化完成整个流程。

**适合的情况**：
- 内容创作者需要快速产出高质量文章
- 自媒体运营者需要保持稳定的内容更新
- 学生或职场人士需要撰写结构清晰的报告或文章
- 想学习如何将AI写作工具产品化的人

**不适合的情况**：
- 需要完全原创、有独特个人风格的文章（AI生成的内容可能缺乏个性）
- 需要高度专业、领域特定的技术文档（可能不够准确）
- 需要实时协作或多人编辑的场景
- 对内容真实性要求极高的新闻报道

---

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **文章主题**：你想写什么内容（如“AI时代如何高效学习”）
2. **类型/语气**：选择文章风格（深度干货、幽默风趣等）
3. **预估字数**：选择文章长度
4. **额外要求**：任何特殊需求（如“需要包含具体案例”）

**用户通常会做哪几步操作？**
1. 首次使用时，点击右上角“设置API”配置DeepSeek API Key
2. 在首页点击“开始创作”进入工作区
3. 填写创作需求（主题、风格、字数等）
4. 点击“启动智能写作Agent”
5. 等待系统自动完成：大纲规划 → 分段写作 → 审查润色
6. 完成后点击“复制到公众号”使用

**输出结果长什么样？**
- 一篇完整的Markdown格式文章
- 自动应用了微信公众号的排版样式（标题、段落、引用等）
- 可以直接粘贴到微信公众号后台

**容易忽略的使用细节**：
1. **API配置是必须的**：没有DeepSeek API Key无法使用
2. **Tavily Search是可选的**：用于补充实时资料，不配置也能用
3. **模型切换**：右上角可以切换V3（常规）和R1（推理）模型
4. **进度日志**：左侧的日志窗口会显示每个步骤的状态
5. **大纲预览**：生成大纲后可以在左侧看到文章结构

## 【三】核心结构拆解（学习重点）

**页面由三个关键模块组成：**

1. **配置与导航模块**
   - **职责**：管理API密钥、切换模型、页面导航
   - **位置**：顶部导航栏 + 设置弹窗
   - **关键设计**：将配置状态全局保存到localStorage，实现一次配置多次使用

2. **输入与控制模块（左侧）**
   - **职责**：收集用户需求、显示进度、预览大纲
   - **包含**：创作需求表单、状态指示器、进度日志、大纲预览
   - **工作流**：用户输入 → 触发工作流 → 实时显示状态 → 展示结果

3. **输出与展示模块（右侧）**
   - **职责**：实时显示生成内容、提供复制功能
   - **包含**：Markdown渲染区、复制按钮
   - **特色**：模拟微信公众号的视觉样式，所见即所得

**输入 → 处理 → 输出 的逻辑链路：**
```
用户输入 → 大纲规划Agent → 分段写作Agent → 审查润色Agent → Markdown渲染 → 样式化预览
```

**最值得学习的设计：**
**多Agent工作流设计**：将复杂的写作任务拆解为三个独立的“智能体”（Agent），每个负责特定阶段：
- **选题Agent**：分析需求，生成结构化大纲
- **写作Agent**：按大纲分段生成内容
- **审查Agent**：对每段内容进行优化润色

这种“分而治之”的思路让复杂任务变得可控，也更容易调试和优化。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是驱动整个工作流的“指令集”，它告诉AI：
1. 扮演什么角色（专业作家、审查专家）
2. 完成什么任务（生成大纲、撰写内容、优化文本）
3. 遵循什么格式（JSON、Markdown）
4. 注意什么细节（风格、长度、额外要求）

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**，但也包含理解：
- **理解部分**：让AI理解用户的需求和上下文
- **生成部分**：指导AI按照特定格式和风格生成内容

**Prompt中的关键变量：**
1. **角色指令**：“作为一个专业的创意写作专家”
2. **任务描述**：“请根据以下要求生成文章大纲”
3. **用户输入变量**：`${input.value.topic}`、`${input.value.tone}`
4. **格式约束**：“请仅返回一个JSON数组”、“使用Markdown格式”
5. **风格指导**：“内容要详实、深入”、“使其更符合公众号阅读习惯”

**如果只改Prompt，不改代码，会发生什么变化？**
1. **改变输出风格**：修改语气指导，文章会变得更正式或更随意
2. **调整结构**：修改大纲Prompt，文章的组织方式会改变
3. **优化质量**：加强审查Prompt，文章会更精炼
4. **切换领域**：改变角色设定（如“技术文档专家”），内容会更专业

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径：**

**第一步：保持结构不变，替换使用场景**
- 最小改动：只改标题和文案
- 示例：将“创意写作”改为“技术文档生成”、“营销文案创作”、“学习笔记整理”
- 保持：三模块布局、工作流逻辑、API调用方式

**第二步：调整输入字段和Prompt**
- 修改输入表单：根据新场景调整字段（如“产品名称”、“目标用户”、“核心卖点”）
- 重写Prompt：保持三段式结构，但调整具体指令
- 示例（营销文案）：
  ```javascript
  const outlinePrompt = `
    作为资深营销专家，请为以下产品生成营销文案大纲...
    产品：${input.product}
    目标用户：${input.target}
    核心卖点：${input.sellingPoint}
  `;
  ```

**第三步：改变输出形式或展示方式**
- 修改CSS样式：调整`.wx-content`的样式，适应不同平台
- 改变复制功能：针对不同编辑器（如Notion、语雀）优化
- 添加新功能：如“导出为PDF”、“分享链接”

**从哪里下手最安全？**
从**修改Prompt和文案**开始，这是零风险、见效快的改动。不需要动代码结构，就能看到明显变化。

## 【六】3–5个可直接尝试的改造方向

**1. 增加更多输入选项**
- **具体操作**：在表单中添加“目标读者”、“关键词”、“参考文章链接”
- **实现方式**：在`input.value`中添加新字段，在Prompt中引用
- **效果**：让生成内容更精准、个性化

**2. 替换或增加AI模型**
- **具体操作**：添加OpenAI、Claude、智谱等模型选项
- **实现方式**：在API配置中添加模型选择，修改`callDeepSeek`函数
- **效果**：比较不同模型的效果，找到最适合的

**3. 拆分为多页面应用**
- **具体操作**：将工作流拆成独立页面：配置页 → 输入页 → 生成页 → 结果页
- **实现方式**：使用Vue Router，每个页面一个组件
- **效果**：体验更清晰，适合复杂工作流

**4. 优化交互体验**
- **具体操作**：
  - 添加“保存草稿”功能
  - 实现“编辑大纲”（可拖拽调整顺序）
  - 添加“重新生成某一段”的按钮
- **实现方式**：为每个大纲项添加编辑控件
- **效果**：用户有更多控制权

**5. 增加后处理功能**
- **具体操作**：
  - 自动添加合适的配图建议
  - 生成文章摘要和标签
  - 检查SEO友好度
- **实现方式**：在工作流最后添加新的处理步骤
- **效果**：产出更完整、可直接发布的内容

## 【七】这个网页不适合做什么？（边界提醒）

**局限性：**
1. **不是真正的“创作”工具**
   - AI生成的内容缺乏真正的个人见解和独特风格
   - 适合内容填充，不适合思想表达

2. **无法保证事实准确性**
   - AI可能生成看似合理但错误的信息
   - **不适合**：新闻报道、学术论文、医疗法律建议

3. **缺乏深度定制**
   - 虽然可以调整参数，但无法像人类作家那样理解微妙需求
   - **不适合**：品牌故事、个人传记、高度情感化的内容

4. **依赖网络和API**
   - 需要稳定的网络连接和可用的API服务
   - **不适合**：离线环境或对延迟敏感的场景

**如果用户想做X，应该换什么工具？**
- **想写代码**：用GitHub Copilot或Cursor
- **想做数据分析**：用ChatGPT+Code Interpreter
- **想创作艺术作品**：用Midjourney、Stable Diffusion
- **想深度研究某个主题**：用Perplexity或传统研究方法
- **想协作写作**：用Google Docs+AI插件或Notion AI

---

**最后提醒**：这个工具最好的使用方式是作为“写作助手”，而不是“写作替代”。用它来克服写作障碍、快速产出初稿、获得灵感，但最终的内容质量和独特性，还是需要你的思考和润色。
