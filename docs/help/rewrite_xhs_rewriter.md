# 小红书改稿机器人 - 学习与使用指南

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你是一个内容创作者，手上有一篇写得特别好的小红书文案（比如一篇爆款笔记），现在你需要为新产品写一篇推广文案。你希望新文案能**模仿**那篇爆款的风格和感觉，但又不能直接抄袭。手动模仿费时费力，还容易“画虎不成反类犬”。

这个网页就是你的“风格模仿助手”。它帮你分析一篇优秀文案的“风格密码”（语气、结构、排版），然后根据你提供的新产品资料，自动生成**4种不同侧重点**的仿写文案。你可以在其中挑选最满意的一篇，或者融合它们的优点。

**适合场景：**
- 需要快速产出符合特定平台（如小红书）风格的文案。
- 手头有优秀的参考案例，希望批量生成不同角度的仿写稿。
- 想学习优秀文案的写作技巧，通过对比AI的仿写结果来加深理解。

**不适合场景：**
- 需要完全原创、无任何模仿痕迹的文案创作。
- 处理高度专业、逻辑严谨的学术或技术文档。
- 需要深度事实核查或数据验证的内容。

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1.  **参考文案**：粘贴一篇你认为写得好的小红书文案。这是AI模仿的“样板”。
2.  **新资料**：输入你想宣传的产品信息、新闻、故事梗概等。这是AI要加工的“原材料”。

**用户通常会做哪几步操作？**
1.  点击右上角“API设置”，填入你的DeepSeek API Key（需要自行申请）。
2.  在左侧分别粘贴“参考文案”和“新资料”。
3.  点击中间的红色大按钮“✨ 生成 4 篇改写文案”。
4.  等待片刻，右侧会并排出现4个卡片，展示不同风格的改写结果。
5.  浏览结果，可以点击卡片右上角的“复制”图标，将满意的文案复制到剪贴板。

**输出结果长什么样？**
右侧会展示4个并排的卡片，每个卡片代表一个版本。每个版本都包含：
-   **标题、正文、标签**：构成一篇完整的小红书笔记。
-   **排版**：模仿了参考文案的Emoji使用和换行习惯。
-   **风格**：四个版本各有侧重（如干货分享、情感共鸣等）。
-   **（可选）深度思考**：如果你选择了“Reasoner (R1)”模型，还会展示AI的推理过程。

**有哪些容易忽略的使用细节？**
-   **API Key是必须的**：不配置就无法生成。Key会加密保存在你的浏览器本地。
-   **模型选择**：默认是“Chat”模型，速度快。切换到“Reasoner (R1)”会看到AI的思考过程，生成速度稍慢，但可能更优质。
-   **输入会自动保存**：即使刷新页面，你之前输入的内容也不会丢失。
-   **导出功能**：可以一键将4个版本的文案导出为一个文本文件。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个模块：

**1. 输入与配置模块（左侧）**
-   **职责**：接收用户的核心指令（参考文案、新资料）和系统配置（API Key、模型选择）。
-   **设计亮点**：将“模仿对象”和“加工原料”明确分开，让AI的指令非常清晰。本地存储功能提升了用户体验的连贯性。

**2. 处理与逻辑模块（看不见的“大脑”）**
-   **职责**：这是页面的核心引擎。它接收输入，构造4个略有不同的Prompt（指令），并发起4个并行的AI API调用，最后将流式返回的结果填充到对应的结果槽位。
-   **关键链路**：
    -   **输入**：参考文案 + 新资料 → **处理**：组合成4个带差异化要求的Prompt → **调用**：并行请求AI API → **输出**：流式接收文本，实时更新到4个结果卡片。
-   **最值得学习的设计**：**“单输入，多输出”的并行处理架构**。它用一个“原料”批量生产了4个“产品”，并通过在Prompt中微调“侧重点”来确保输出的多样性，极大地提高了工具的实用性和灵感激发能力。

**3. 输出与展示模块（右侧）**
-   **职责**：以清晰、直观的网格布局，同时展示所有生成结果。支持复制、导出等操作，并优雅地处理生成中的加载状态。
-   **设计亮点**：**4卡片网格布局**。它让对比变得极其方便，用户一眼就能看出不同风格的差异。流式输出（打字机效果）和加载状态的设计，让等待过程不再枯燥。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt扮演的角色：**
在这个页面中，Prompt是**连接用户意图与AI能力的“翻译官”和“导演”**。它不是一个简单的提问，而是一份详细的**创作任务书**。

**它解决的是“生成问题”：**
Prompt的核心任务是**指导AI生成符合特定格式和风格的新内容**，而不是让AI去理解一个复杂问题。它通过提供“参考文案”和“新资料”，将开放式的创作任务，转变为一个有明确范本的“仿写”任务。

**Prompt中的关键变量：**
1.  **系统角色设定**：`“You are a professional social media content creator.”` 让AI进入角色。
2.  **任务目标**：明确要求“参考风格，改写新资料”。
3.  **差异化要求**：4个版本分别被赋予`“干货分享”`、`“情感共鸣”`等不同侧重点，这是产生多样性的关键。
4.  **参考文案与新资料**：这是Prompt中最核心的变量，决定了生成内容的具体语境和风格边界。
5.  **输出格式指令**：严格要求包含`标题、正文、标签`，并模仿排版，输出`Markdown`。

**如果只改Prompt，不改代码，会发生什么？**
整个页面的行为会发生**根本性改变**。例如：
-   将“小红书文案”改为“Twitter推文”，它就成了一个推文生成器。
-   将“侧重于情感共鸣”改为“用莎士比亚戏剧风格”，生成的文案风格会立刻变得古典华丽。
-   增加一条“限制在100字以内”，所有输出都会变得简短精悍。
**Prompt是控制这个页面产出内容的“总开关”**。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全”路径，逐步打造自己的AI工具：

**第一步：保持结构不变，替换使用场景（最安全）**
-   **目标**：先做出一个能跑通的、属于你自己的工具。
-   **操作**：
    1.  复制整个HTML文件。
    2.  修改标题`<title>`和页面中的品牌名称（如“XHS Rewriter”）。
    3.  **最关键的一步**：修改Prompt模板。将“小红书文案”、“参考文案”、“新资料”这些词，替换成你的目标场景。例如，改成“知乎回答”、“招聘JD”、“产品需求文档”等。左侧的输入框标签也要相应修改。
    4.  此时，你就得到了一个为你新场景服务的“仿写机器人”。

**第二步：调整输入字段或Prompt**
-   **目标**：让工具更贴合你的具体需求。
-   **操作**：
    1.  **增加输入**：如果你需要更多控制，可以在左侧添加输入框。例如，增加一个“目标受众”输入框，并将其加入到Prompt中。
    2.  **细化Prompt**：根据新场景，优化Prompt中的“差异化要求”。比如对于“邮件写作”，可以改成“正式商务”、“友好提醒”、“促销推广”等。
    3.  **修改输出数量**：在`generateRewrites`函数中，将`Array(4)`和`variations`数组的长度从4改为你需要的数字（如3或5）。

**第三步：改变输出形式或展示方式**
-   **目标**：优化结果呈现，提升用户体验。
-   **操作**：
    1.  **布局**：如果生成的版本不多，可以考虑单列大卡片展示；如果版本很多，可以改为可切换的标签页。
    2.  **交互**：为每个结果卡片增加“点赞”、“评分”或“重新生成此版本”的按钮。
    3.  **美化**：使用不同的CSS样式来强化不同版本（如干货版用蓝色边框，情感版用粉色边框）。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“风格强度”滑块**：
    -   **操作**：在输入区添加一个滑动条（range input），让用户控制“模仿参考文案的强度”（例如从“轻度借鉴”到“高度复刻”）。将这个值作为变量插入到Prompt中，例如“请以[强度]%的相似度模仿参考文案的风格”。

2.  **切换大模型供应商**：
    -   **操作**：在API设置弹窗中，增加一个下拉菜单，让用户选择`DeepSeek`、`OpenAI (GPT)`或`Claude`等。修改`callDeepSeek`函数为`callLLM`，内部根据选择拼接不同的API地址和请求头。这能让你对比不同模型的效果。

3.  **拆解为“分析”与“生成”两步**：
    -   **操作**：增加一个“分析参考文案”的按钮。点击后，先调用一次AI，让其总结出参考文案的“风格报告”（如：语气亲切、多用感叹号、结构是痛点-解决方案-效果）。然后将这份报告作为生成新文案时的更精确指导，而不是直接给AI看原文。

4.  **优化交互：增加“灵感续写”功能**：
    -   **操作**：在每个生成结果的底部添加一个“✨ 以此为基础续写/扩写”的小按钮。点击后，将当前卡片的内容作为“新资料”，再混合原始“参考文案”，发起一次新的生成，并将结果追加到页面下方或新卡片中。这非常适合头脑风暴。

5.  **引入简单的“记忆”功能**：
    -   **操作**：将每次用户满意的生成结果（或用户手动修改后的最终版）保存到一个历史记录列表中。在页面侧边栏或新页面展示这个列表，用户可以回顾、复用或基于历史记录再次生成。这能形成你的个人文案库。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合替代人类进行最终的内容审核和定稿**：
    -   **局限性**：AI可能模仿了风格，但无法保证事实准确性、价值观的恰当性，也可能产生刻板印象或无意义的套话。
    -   **正确做法**：将此工具视为“高级灵感生成器”或“初稿撰写助手”。生成的文案**必须**由人类进行审核、修正、润色，并注入真实的情感和洞察。

2.  **不适合处理高度依赖上下文或长逻辑链的创作**：
    -   **局限性**：对于需要严密逻辑推理（如法律文件）、复杂世界观构建（如长篇小说）或深度行业知识（如医疗报告）的内容，单次Prompt的简单仿写模式力有不逮。
    -   **正确做法**：对于这类任务，应使用更专业的工具或方法，例如进行多轮对话、提供详细的背景文档、或使用具备更强推理和长上下文能力的模型进行专项开发。

3.  **不适合作为“原创性检测”或“洗稿”工具**：
    -   **设计初衷**：本工具旨在**学习风格**和**激发灵感**，而非生成难以追溯的衍生内容。
    -   **风险提醒**：直接使用生成内容而不加显著修改，可能存在侵权或内容同质化的风险。请始终尊重原创，将AI产出作为你创造性工作的起点，而非终点。
