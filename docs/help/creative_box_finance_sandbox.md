# 个人理财策略沙盒 - 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

这个网页是一个**个人理财规划模拟器**。想象一下，你每个月有固定的收入和支出，手里有一些存款，但不知道如何让钱更好地增值。你可能会问自己：“我应该存多少钱？”“投资股票还是买基金？”“我的风险承受能力到底怎么样？”

这个工具就是为你设计的。它让你在一个安全的“沙盒”环境中，输入自己的财务数字，然后：
- **立即看到**你的财务健康状况（储蓄率、结余等）
- **模拟不同**投资策略（保守、平衡、积极）的长期效果
- **获得AI**提供的个性化理财建议
- **生成一份**简单的理财报告

**适合使用的情况：**
- 刚接触理财，想了解基本概念和规划方法
- 想快速评估自己的财务状况
- 想对不同投资策略的效果有个直观感受
- 需要一些初步的、结构化的理财建议作为参考

**不适合使用的情况：**
- 需要精确的、专业的财务规划（应咨询持牌理财顾问）
- 涉及复杂的税务、遗产规划
- 需要实时市场数据或具体的金融产品推荐
- 作为唯一的投资决策依据（它只是模拟和教学工具）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你需要填写四个基本财务信息：
1.  **月收入**：你每月税后到手多少钱
2.  **月支出**：你每月大概花多少钱
3.  **现有储蓄**：你目前有多少存款
4.  **风险承受能力**：从“保守型”、“稳健型”、“积极型”中选择一个

**用户通常会做哪几步操作？**
1.  **填写信息**：在左侧“财务状况”区域输入你的数字。
2.  **查看健康度**：观察中间的圆形进度条和下方的储蓄率、结余等指标，了解自己的财务基础。
3.  **选择策略**：在中间区域点击选择一个投资场景（如“平衡配置”），看看对应的资产分配比例。
4.  **运行模拟**：点击“运行模拟”按钮，系统会计算如果你按照这个策略投资，未来1年、3年、5年、10年可能的收益情况。
5.  **获取AI建议**：点击“AI建议”按钮，等待AI根据你的信息生成一段文字建议。
6.  **导出结果**：如果需要，可以点击右侧的“生成理财报告”或“导出数据”按钮保存结果。

**输出结果长什么样？**
- **财务健康度**：一个彩色的圆形进度条和百分比分数，以及“优秀”、“良好”等评语。
- **模拟结果**：以卡片形式展示不同年份后的“累计投入”、“预期价值”和“预期收益”金额。
- **AI建议**：一段蓝色的文字框，包含对你财务状况的评估和几条具体建议。
- **关键指标**：几个彩色的数据块，显示“预期年化收益率”、“投资风险等级”等。

**有哪些容易忽略的使用细节？**
1.  **输入即更新**：只要你修改了输入框的数字，页面上的健康度、指标等都会**实时自动更新**，无需点击“确认”按钮。
2.  **API配置**：右上角的齿轮按钮可以打开API配置面板。如果你有自己的AI API密钥（如DeepSeek），可以在这里填写，让AI建议功能使用你自己的账户。**不配置也能使用大部分功能**。
3.  **投资场景**：点击不同的场景（保守/平衡/积极），中间的资产配置图和预期收益率会立刻变化，但**模拟结果**需要你再次点击“运行模拟”才会基于新场景重新计算。
4.  **数据保存**：你的输入和配置**只保存在当前浏览器的本地**，清理浏览器数据后会丢失。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主模块和背后的处理逻辑：

**1. 输入模块（左侧面板）**
- **职责**：收集用户最核心的原始财务数据。
- **包含**：“财务状况”表单（收入、支出、储蓄、风险偏好）和“财务健康度”展示区。
- **关键设计**：使用 `oninput` 和 `onchange` 事件，实现**数据驱动UI**。用户一输入，健康度计算函数 (`updateFinancialData`) 就立刻被触发，所有相关显示区域同步更新。这提供了极佳的即时反馈。

**2. 处理与模拟模块（中间面板）**
- **职责**：基于输入数据，进行投资策略的配置、模拟和可视化。
- **包含**：投资场景选择器、资产配置图、模拟控制按钮、模拟结果展示区。
- **逻辑链路**：
    - **输入**：用户选择的场景（如“平衡配置”）和左侧的财务数据。
    - **处理**：`updatePortfolioConfig` 函数根据场景加载预设的资产配比（股票/债券/存款比例）和预期收益率。`runSimulation` 函数利用这些比例和用户的月结余、储蓄，进行复利计算，预测未来价值。
    - **输出**：用进度条可视化资产配比，用卡片列表展示不同年份的模拟结果。

**3. 输出与建议模块（右侧面板）**
- **职责**：提供综合性的洞察、建议和导出功能。
- **包含**：AI建议生成器、关键指标汇总、报告导出按钮。
- **逻辑链路**：
    - **AI建议**：`getAIAdvice` 函数将左侧收集的所有数据拼接成一个详细的Prompt，发送给AI API，然后将返回的文本格式化显示。
    - **关键指标**：`updateMetrics` 函数根据输入数据计算出一个综合评分。
    - **导出**：`generateReport` 和 `exportData` 函数将当前所有数据整理成文本或JSON格式供用户下载。

**最值得学习的设计：**
**“沙盒”式的即时反馈循环**。整个应用的核心不是复杂的算法，而是**将输入、处理、输出紧密耦合，并立即呈现**。用户输入数字 → 健康度变化 → 选择场景 → 配置图变化 → 运行模拟 → 看到未来预测。这个快速、可视化的循环让抽象的理财概念变得具体可感，是教育类工具设计的典范。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
它是连接用户原始数据和AI生成建议的**翻译器**和**任务指令书**。它把散落的数字（收入、支出）和选择（风险偏好）组织成一段AI能理解的、带有上下文和明确要求的文本。

**它解决的是"理解问题"还是"生成问题"？**
主要是**生成问题**。AI不需要“理解”这个网页本身，它的任务很明确：接收一段结构化的财务描述和一个具体的指令，然后**生成一段符合要求的、文本格式的理财建议**。

**哪些信息是 Prompt 中的关键变量？**
Prompt中动态插入的用户数据就是关键变量：
- `月收入：${financialData.income}元`
- `月支出：${financialData.expenses}元`
- `现有储蓄：${financialData.savings}元`
- `风险承受能力：${financialData.riskTolerance}`

**如果只改 Prompt，不改代码，会发生什么变化？**
AI建议的内容和风格会完全改变。例如：
- 如果你把Prompt中的“请提供：1.财务状况评估 2.储蓄建议...”改成“请用严厉的口吻批评我的消费习惯，并给出三条省钱妙招”，那么AI返回的建议就会从温和的规划变成犀利的批评和具体的省钱技巧。
- 如果你在Prompt开头加上“你是一位巴菲特风格的价值投资大师”，那么AI的建议可能会更多地引用长期持有、安全边际等概念。
- **这证明了Prompt是控制AI输出行为的“方向盘”**，调整Prompt是成本最低、效果最直接的改造方式。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循这个“替换-调整-创新”的路径，安全地创建一个新工具：

**第一步：保持结构不变，替换使用场景（最安全）**
- **目标**：做一个“个人学习计划沙盒”。
- **操作**：
    - 把“月收入”改成“每日可用学习时间（小时）”。
    - 把“月支出”改成“每日必需活动时间（小时）”。
    - 把“现有储蓄”改成“当前知识储备水平（1-10分）”。
    - 把“风险承受能力”改成“学习偏好”（如“理论型”、“实践型”、“混合型”）。
    - 把“投资场景”改成“学习策略场景”（如“应试冲刺”、“技能深耕”、“兴趣拓展”）。
    - 把“预期收益”改成“预期掌握程度”。
    - 修改所有标题、标签和提示文字。

**第二步：调整输入字段或 Prompt**
- **目标**：让工具更适合你的新场景。
- **操作**：
    - 根据“学习计划”场景，你可能会增加一个“目标技能/科目”的输入框。
    - 重写AI建议的Prompt：“作为学习规划师，请根据用户每日净学习时间、当前水平和学习偏好，制定一个为期3个月的学习计划，包括每日任务、推荐资源和阶段性目标。”

**第三步：改变输出形式或展示方式**
- **目标**：优化用户体验。
- **操作**：
    - 把模拟结果从“1年、3年、5年、10年”改成“1周后、1月后、3月后、6月后”。
    - 把“生成理财报告”改成“生成学习计划表”，并尝试输出为PDF或日历格式（.ics）。
    - 在关键指标区域，把“年化收益率”换成“每周预计进步幅度”。

**从哪里下手最安全？**
从**第一步的文本替换**开始。不要动任何JavaScript函数名和HTML结构，只修改显示在页面上的所有文字内容。这样你能确保整个页面功能完全正常，只是主题变了。这是理解整个项目结构最快捷的方式。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加输入维度，让建议更精准**
    - **操作**：在财务状况区域增加“年龄”、“主要负债（如房贷月供）”、“理财目标（如购房、养老）”等字段。
    - **影响**：这些信息会被加入Prompt，AI给出的建议将更具针对性（例如，为年轻用户推荐更多权益类资产，为有房贷的用户强调现金流管理）。

2.  **更换或扩展AI模型/API**
    - **操作**：在API配置面板的“模型选择”下拉框中，增加新的选项，如 `gpt-4o`、`claude-3-sonnet`，并修改 `saveSettings` 和 `getAIAdvice` 函数中对应的API地址和参数格式。
    - **影响**：你可以比较不同模型生成建议的质量和风格差异，或使用更便宜的模型来控制成本。

3.  **将单页应用拆分为多步骤向导**
    - **操作**：将当前的一个页面拆分成三个子页面（或三个折叠面板）：①信息填写页 ②策略模拟页 ③报告生成页。用“上一步/下一步”按钮导航，并使用 `localStorage` 在页面间传递数据。
    - **影响**：用户体验更聚焦，流程更清晰，尤其适合在手机等小屏幕设备上使用。

4.  **优化交互体验，增加可视化**
    - **操作**：引入一个简单的图表库（如Chart.js）。将模拟结果从文字卡片改造成**折线图**，用一条曲线展示资产随时间的增长趋势；将资产配置从进度条改造成**饼图**。
    - **影响**：数据呈现更直观、更专业，视觉吸引力大大增强。

5.  **增加“假设分析”功能**
    - **操作**：在模拟器旁边增加一个滑块，标签为“如果每月多存XXX元”。拖动滑块时，实时重新运行模拟并更新结果图表。
    - **影响**：用户可以直观地看到微小的习惯改变（每月多存500元）对长期财富的巨大影响，激励性更强。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做真实的投资决策**
    - **局限性**：它的模拟基于固定的历史预期收益率，未考虑市场波动、通货膨胀、黑天鹅事件等真实风险。预设的投资组合也非常简化。
    - **正确做法**：进行真实投资前，应深入研究，咨询专业顾问，并使用正规的金融分析工具或券商平台。

2.  **不适合处理复杂财务状况**
    - **局限性**：它无法处理多收入来源、不规则支出、复杂资产（房产、股权）、税务优化、保险规划等。
    - **正确做法**：需要使用专业的个人财务管理软件（如 Mint、YNAB）或聘请财务规划师进行全面规划。

3.  **不适合作为金融知识的主要学习来源**
    - **局限性**：它提供的解释和AI建议可能过于简化，甚至存在不准确之处，缺乏系统的知识体系。
    - **正确做法**：应通过阅读经典理财书籍、参加靠谱的课程或关注权威金融机构的内容来系统学习。

4.  **不适合替代专业心理咨询**
    - **局限性**：财务压力可能伴随焦虑等情绪问题。AI建议是机械的，无法提供情感支持或心理干预。
    - **正确做法**：如果财务问题已造成严重心理负担，应寻求心理咨询师或社工的帮助。

**总结**：请将这个工具视为一个**引发思考的“起点”**、一个**可视化概念的“教具”**，而不是一个给出终极答案的“神器”。它的最大价值在于帮助你建立规划意识，并对自己的财务状况有一个快速、初步的把握。
