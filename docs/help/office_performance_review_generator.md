# 绩效评估报告生成器 - 帮助与学习指南

## 【一】这个网页解决了什么问题？

想象一下，你是一名管理者或HR，需要为团队成员撰写一份正式的绩效评估报告。你手头有员工的基本信息、工作成果，但如何将这些零散信息组织成一份结构清晰、语言专业、评价客观的报告呢？手动撰写耗时耗力，且容易遗漏要点或表述不当。

这个网页就是你的“智能报告助手”。它适合在以下场景使用：
*   **季度/年度绩效评估时**：快速生成报告初稿，节省大量撰写时间。
*   **需要统一报告格式时**：确保团队内所有报告的结构和风格保持一致。
*   **管理者缺乏写作经验时**：提供专业的框架和措辞参考。

它不适合以下情况：
*   **需要高度保密或涉及敏感信息的评估**：报告内容会发送到外部AI API，存在数据泄露风险。
*   **需要完全个性化、充满细节和具体事例的深度评估**：AI生成的内容基于你提供的有限信息，深度和独特性有限。
*   **作为最终决策的唯一依据**：它生成的是“草稿”或“参考”，最终的评估结论和沟通必须由管理者本人负责。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：打开页面后，点击右上角的齿轮图标（⚙️），在弹出的窗口中输入你的 DeepSeek API Key，然后点击“保存”。这是使用AI功能的前提。
2.  **填写信息**：
    *   **员工信息**：输入员工的姓名和岗位。
    *   **评估周期**：从下拉菜单中选择（季度、半年、年度）。
    *   **工作成果**：在文本框中详细描述员工在本周期内的主要成绩、完成的项目、关键数据等。**信息越具体，报告越有针对性。**
    *   **评估维度**：勾选你希望报告重点涵盖的方面（如工作成果、团队协作等）。
3.  **生成报告**：点击页面左下角紫色的 **“生成评估报告”** 按钮。页面会显示加载动画，几秒到几十秒后，右侧的“评估报告”区域就会显示出完整的、格式美观的Markdown报告。
4.  **查看与下载**：报告生成后，你可以直接在线阅读。点击报告上方的绿色 **“下载”** 按钮，可以将报告保存为 `.md` 格式的Markdown文件，方便你后续编辑或导入其他文档工具。

**容易忽略的细节：**
*   **API Key是必须的**：如果你没配置就直接点击生成，页面会自动弹出设置窗口提醒你。
*   **工作成果描述是关键**：这是AI生成内容最主要的素材来源，写得越详细、越有条理，报告质量越高。
*   **报告是流式生成的**：你会看到文字一个字一个字地“打”出来，而不是等待很久后突然出现一整篇，体验更流畅。
*   **浏览器本地存储**：你输入的API Key会保存在你当前浏览器的本地，下次打开同一浏览器访问此页面时无需再次输入。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

1.  **信息输入与配置模块（左侧）**
    *   **职责**：收集所有生成报告所需的数据和参数。它像一个“表单收集器”。
    *   **包含**：员工信息表单、工作成果文本框、评估维度复选框、生成按钮、以及隐藏在设置窗口中的API配置。
    *   **逻辑**：用户在此模块完成所有“填空”和“选择”。

2.  **报告展示与输出模块（右侧）**
    *   **职责**：动态展示AI生成的过程和最终结果，并提供结果导出功能。它像一个“报告显示器与导出器”。
    *   **包含**：报告标题区、下载按钮、初始占位图、加载动画区、以及最终的报告内容渲染区。
    *   **逻辑**：根据状态（初始/生成中/完成）显示不同内容，并将Markdown文本渲染成美观的HTML格式。

3.  **AI处理与逻辑控制模块（背后的JavaScript）**
    *   **职责**：作为大脑，协调前后端。它负责将输入模块的数据组装成AI能理解的指令（Prompt），调用AI API，处理返回的数据流，并更新展示模块。
    *   **关键函数**：`generate()` 函数是核心，它完成了 **“收集输入 -> 构建Prompt -> 调用API -> 流式接收 -> 更新界面”** 的完整链路。

**最值得学习的设计：**
**“流式响应(Streaming) + 前端状态管理”** 的结合。页面没有在等待AI完整回复期间“卡死”，而是通过 `reader.read()` 逐块获取AI返回的数据，并实时更新到 `this.result` 变量中。配合 Alpine.js 的响应式特性，页面上的报告区域就能实现“逐字打印”的效果，极大地提升了用户体验和感知速度。这是现代AI应用前端的一个经典模式。

## 【四】Prompt / AI 逻辑是如何被设计的？

*   **Prompt的角色**：它是连接用户输入和AI能力的“翻译官”和“任务说明书”。它告诉AI：“嘿，我给了你一些关于一个人的信息，请你按照我指定的格式和角度，写一份专业的评估报告。”
*   **解决的问题**：它主要解决的是“**生成问题**”。它将零散、非结构化的用户输入（姓名、岗位、一段文字描述），转化成一封结构严谨、语言得体的正式文档。
*   **关键变量**：Prompt中嵌入了所有用户输入作为变量：`${this.employeeName}`, `${this.position}`, `${this.period}`, `${this.achievements}`, `${this.dimensions.join('、')}`。这些是每次生成报告时变化的部分。
*   **只改Prompt的效果**：如果你只修改Prompt模板，而不改动任何HTML和JS代码，你可以彻底改变这个应用的功能。例如：
    *   把“绩效评估报告”改成“产品需求文档”，把输入项改成“用户痛点”、“市场分析”，它就能变成一个“PRD生成器”。
    *   在Prompt中增加指令，如“使用更严厉的语气”或“多举具体例子”，生成的报告风格会随之改变。
    *   修改输出的章节结构（如增加“价值观匹配度”部分），报告的内容组织方式就会更新。

## 【五】如何模仿它，做出你自己的版本？

如果你想做一个“XX生成器”，请遵循以下安全路径：

1.  **第一步：替换场景与字段（最安全）**
    *   **目标**：先做出一个能跑通的、属于你自己的工具。
    *   **操作**：
        *   修改网页标题和说明文字（如改为“周报生成器”）。
        *   修改左侧输入模块的表单标签和字段名。例如，将“员工姓名”改为“项目名称”，将“工作成果”改为“本周工作内容”，将“评估维度”复选框改为“汇报重点”（如“进展”、“风险”、“计划”）。
        *   此时先不要动JavaScript逻辑和Prompt。

2.  **第二步：重构Prompt模板（核心改造）**
    *   **目标**：让AI理解你的新任务。
    *   **操作**：找到 `generate()` 函数里的 `prompt` 字符串变量。
        *   根据你的新场景重写指令，例如：“请根据以下信息生成一份项目周报：...”。
        *   将变量引用（`${this.xxx}`）对应到你第一步修改的新字段名。
        *   设计你想要的输出格式，修改Markdown标题结构。

3.  **第三步：调整输出与交互（优化体验）**
    *   **目标**：让成品更符合你的需求。
    *   **操作**：
        *   修改下载文件时的默认文件名（`a.download` 属性）。
        *   可以调整右侧报告区域的默认提示文字和图标。
        *   如果新的场景需要不同的AI模型（比如需要看图），则可以修改 `apiConfig` 中的模型名称，并在设置界面增加对应的配置项。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加历史记录与模板功能**：
    *   **操作**：使用 `localStorage` 保存用户生成过的报告历史（只保存输入参数，不保存结果以节省空间）。在页面左侧增加一个“历史记录”面板，点击可以快速载入之前的输入。甚至可以增加“保存为模板”功能，将一套常用的输入（如某个岗位的固定评估维度）存为模板。

2.  **支持多模型切换与对比**：
    *   **操作**：在设置窗口中增加一个模型下拉选择框（如DeepSeek, GPT-4o, Claude等）。修改 `apiConfig` 和 `fetch` 请求的URL及参数。你甚至可以改造 `generate()` 函数，同时请求两个模型，并将结果并排展示在右侧，让用户对比不同AI的生成效果。

3.  **细化输入，引入“评分”或“关键词”**：
    *   **操作**：在“评估维度”部分，不仅让用户勾选维度，还可以为每个维度增加一个1-5分的滑块评分。将这些评分放入Prompt中，例如：“在‘团队协作’方面（用户评分：4/5），请着重描述...”。这样能给AI更精确的指导信号。

4.  **优化输出格式与一键分享**：
    *   **操作**：除了下载Markdown，可以增加“复制为HTML”、“导出为PDF”（使用浏览器打印功能或jsPDF库）的按钮。甚至可以集成简单的分享功能，生成一个包含报告纯文本的链接（需后端支持）。

5.  **增加输入引导与示例**：
    *   **操作**：在“工作成果”文本框下方，增加一个“显示示例”的小链接。点击后，可以弹出一段写得很好的示例文本，帮助不知道如何下笔的用户参考。这能显著提升输入质量，从而间接提升输出质量。

## 【七】这个网页不适合做什么？（边界提醒）

*   **不适合做最终、正式的评估文件**：AI生成的内容可能存在事实性错误、泛泛而谈或不符合公司特定文化。**它必须经过管理者的仔细审阅、修改和润色**，并加入只有管理者才知道的具体事例和反馈后，才能用于正式沟通。
*   **不适合处理极端敏感信息**：任何输入到网页的信息都会通过网络发送到DeepSeek的服务器。**切勿输入身份证号、薪酬具体数字、未公开的商业机密、涉及他人隐私的负面细节等**。
*   **不适合完全替代人类判断**：绩效评估的核心是沟通、辅导和发展。这个工具解决的是“文书工作”的效率问题，而不是“如何评价一个人”的管理艺术问题。如果用户想进行深入的员工发展对话或解决复杂的绩效问题，应该依靠专业的管理培训、一对一沟通技巧，而不是这个工具。
*   **不适合无网络环境使用**：整个应用的核心能力依赖于调用在线的AI API，没有网络将无法生成任何内容。
