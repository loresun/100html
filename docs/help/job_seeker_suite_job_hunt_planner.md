# 求职行动计划与投递跟进 - 帮助文档

## 【一】这个网页解决了什么问题？

**使用场景：**
当你正在找工作，感到迷茫、没有头绪，或者投递了很多简历却收效甚微时，这个工具能帮你。它就像一个虚拟的“求职规划师”，你只需要告诉它你的目标、可用时间和遇到的困难，它就能为你生成一份结构清晰、包含具体步骤和工具的“作战计划”。

**适合什么情况？**
- 你刚确定要找新工作，但不知道从哪里开始。
- 你投递了一些简历，但反馈很少，想优化策略。
- 你需要一个清晰的日程表来督促自己执行求职任务。
- 你想学习如何系统化地跟进面试机会。

**不适合什么情况？**
- 你需要针对**某一封特定简历**或**某一轮具体面试**的深度修改和辅导。
- 你需要获取实时的、具体的招聘信息（如某公司正在招什么岗位）。
- 你希望AI直接替你投递简历或与HR沟通。

## 【二】使用方式（给第一次接触的人）

**第一步：配置（只需一次）**
1.  点击页面右上角的齿轮图标（⚙️），打开设置面板。
2.  在“DeepSeek API Key”中输入你的API密钥（你需要自行在DeepSeek官网获取）。
3.  （可选）你可以在“自定义提示词”里添加额外要求，比如“计划要更详细”或“多给一些面试话术”。
4.  点击“保存”。

**第二步：输入你的求职信息**
在页面左侧的白色卡片中，依次填写：
- **求职目标**：你想达成的最终结果，例如“1个月内拿到前端开发Offer”。
- **可投入时间**：你每周能花多少时间在求职上，例如“每周20小时”。
- **目标城市/行业**：你的求职范围，例如“北京/互联网/金融科技”。
- **投递渠道**：你打算通过哪些平台或方式找工作，例如“Boss直聘、拉勾、朋友内推”。
- **当前进度/难点**：你目前遇到的困难，例如“简历已优化，但面试邀约少”、“技术面试容易紧张”。

**第三步：生成计划**
点击绿色的“生成行动计划”按钮。稍等片刻（通常10-30秒），页面右侧就会生成一份详细的计划。

**输出结果长什么样？**
结果是一份用Markdown格式写的详细文档，通常包含：
1.  **分周行动计划**：比如“第一周：重点优化简历和筛选目标公司”。
2.  **每周投递目标**：建议你每周在哪些渠道投递多少份简历。
3.  **面试准备节奏**：安排模拟面试和复盘的时间。
4.  **投递跟进表模板**：一个表格，让你记录投递了哪家公司、什么岗位、何时跟进。
5.  **常用跟进话术**：提供一些礼貌、有效的沟通模板。

**容易忽略的使用细节：**
- **模型切换**：页面顶部有“V3”和“R1”两个按钮。“V3”是普通对话模型，响应快；“R1”是深度思考模型，会先展示思考过程再给出答案，计划可能更周密，但耗时稍长。
- **深度思考过程**：如果使用“R1”模型，生成的结果上方会有一个可展开的“🧠 深度思考过程”区域，展示了AI是如何一步步分析你的情况并制定计划的，这对学习规划思路很有帮助。
- **结果导出**：生成计划后，除了直接阅读，你还可以点击“复制”、“导出TXT”或“导出JSON”，将计划保存到本地。

## 【三】核心结构拆解（学习重点）

这个页面可以清晰地分为三个主要模块：

**1. 输入配置模块（左侧面板）**
- **职责**：收集用户个性化的求职信息，是AI生成计划的“原材料”。
- **包含**：5个输入字段（目标、时间、范围、渠道、难点）和操作按钮（生成、清空）。
- **设计亮点**：字段设计非常聚焦，直击求职规划的核心要素（目标、资源、渠道、障碍），没有无关信息，让用户快速聚焦。

**2. AI处理与输出模块（右侧面板）**
- **职责**：向AI发送请求，接收、解析并展示生成的计划。
- **包含**：状态提示区（空状态、加载中）、结果展示区、操作区（复制、导出）。
- **逻辑链路**：
    - **输入**：用户填写表单 → 点击“生成”。
    - **处理**：前端将表单数据拼接成一段给AI的“指令”（Prompt）→ 通过API发送给DeepSeek AI。
    - **输出**：接收AI返回的文本流 → 实时显示在页面上 → 最终呈现完整的Markdown格式计划。

**3. 系统设置模块（弹出层）**
- **职责**：管理应用的“基础设施”，如API密钥和核心指令（Prompt）的微调。
- **包含**：API Key输入框、自定义提示词文本框。
- **设计亮点**：将技术配置（API Key）和业务逻辑调整（自定义Prompt）放在一起，方便高级用户进行个性化定制。

**最值得学习的设计：**
**“流式输出”与“状态分离”**。当AI生成内容时，页面不是等所有内容都生成完再一次性显示，而是一个字一个字地“流”出来。这极大地提升了用户体验，让等待变得可感知。同时，页面明确区分了“空状态”、“加载中”和“有结果”三种状态，并用不同的图标和文字清晰展示，界面逻辑非常友好。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt 在这个页面中扮演什么角色？**
Prompt 是连接“用户输入”和“AI能力”的**翻译官**和**任务指挥官**。它把用户零散填写的几个字段，转化成一个有背景、有角色、有明确输出要求的完整任务，交给AI去执行。

**它解决的是“理解问题”还是“生成问题”？**
主要是**生成问题**。这个工具假设AI已经理解了“求职规划”这件事。Prompt的核心任务是**约束AI的生成方向**，确保它输出的内容格式统一、结构完整、紧扣用户的具体情况，而不是天马行空地泛泛而谈。

**哪些信息是 Prompt 中的关键变量？**
Prompt 中引用了所有5个表单字段的值（`${this.form.goal}`等）。它们是**关键变量**，使每次生成的计划都因人而异。此外，`${custom}`部分允许用户追加额外要求，提供了灵活性。

**如果只改 Prompt，不改代码，会发生什么变化？**
你可以彻底改变这个工具的功能，而无需懂编程。例如：
- 把“求职规划师”改成“健身教练”，把表单字段改成“健身目标、可用天数、现有设备”，它就能变成一个**健身计划生成器**。
- 在输出要求里加上“用表格列出每周食谱”，它就会在计划里增加饮食建议。
- 改变输出结构，比如要求“先做一个SWOT分析”，AI就会调整回答的逻辑顺序。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下路径，安全地创建一个属于你的AI工具：

**第一步：替换核心场景与输入字段（最安全）**
- **目标**：先做出一个能跑通的“新外壳”。
- **操作**：
    1.  想一个新主题，比如“旅行规划师”、“学习计划制定器”或“短视频脚本生成器”。
    2.  修改网页标题和左上角的应用名称。
    3.  **保留左侧面板的5个输入框结构，但修改它们的标签和提示文字**。例如，针对“旅行规划”：
        - `求职目标` → `旅行目的地与目标`
        - `可投入时间` → `旅行总天数与预算`
        - `目标城市/行业` → `偏好景点/活动类型`
        - `投递渠道` → `交通与住宿偏好`
        - `当前进度/难点` → `特别需求或限制`

**第二步：重写核心Prompt**
- **目标**：让AI为你新的主题服务。
- **操作**：找到代码中的 `buildPrompt()` 函数。这是核心！重写里面的提示文本：
    1.  修改角色：“你是一名**资深旅行规划师**...”
    2.  修改指令：“请根据旅行目标与预算制定一份行程计划...”
    3.  修改输出结构：“1) 每日行程概览 2) 交通与住宿安排建议 3) 必打卡景点与美食 4) 预算分配表 5) 行前准备清单”

**第三步：调整输出展示与功能**
- **目标**：让界面更贴合新主题。
- **操作**：
    1.  修改右侧面板的标题和描述，如“旅行行程计划”。
    2.  修改导出文件的默认名称，如 `travel_plan.txt`。
    3.  （可选）更换页面图标和主色调，让视觉风格匹配新主题。

完成以上三步，一个全新的工具就诞生了。代码的主体逻辑（发送请求、流式显示、保存设置）完全不需要动。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“个性化示例”功能**：
    - **操作**：在输入面板旁增加一个“查看示例”按钮。点击后，自动用几个预设的、典型的求职案例（如“应届生找实习”、“程序员跳槽”、“转行”)填充表单。
    - **价值**：帮助新用户快速理解每个字段该怎么填，降低使用门槛。

2.  **引入“多轮对话”与计划修正**：
    - **操作**：生成计划后，在计划下方增加一个输入框，允许用户输入“我觉得第一周任务太重了，能调整吗？”或“可以多给一些Boss直聘的沟通话术吗？”，然后基于之前的对话历史，让AI调整或补充计划。
    - **价值**：使工具从“一次性生成”变为“可交互的顾问”，实用性大增。

3.  **本地化存储与历史记录**：
    - **操作**：将每次生成的计划（连同输入的表单数据）自动保存到浏览器的本地存储（LocalStorage）中。在页面增加一个“历史计划”侧边栏或页面，方便用户查看和回顾之前的规划。
    - **价值**：用户可以看到自己的求职历程，方便追踪进度和复盘。

4.  **优化输出为可交互的看板**：
    - **操作**：不再将AI的输出仅作为Markdown文本展示，而是尝试解析其结构。例如，将“每周任务”解析成一个个可拖拽的卡片，放入一个类似Trello的看板中；将“跟进表模板”直接渲染成一个可编辑的在线表格。
    - **价值**：将“计划文档”变为“管理工具”，用户可以直接在工具内执行和跟踪计划。

5.  **切换或聚合多个AI模型**：
    - **操作**：在设置中，除了DeepSeek，增加对OpenAI GPT、Claude或国内其他大模型API的支持。甚至可以设计一个“模型对比”功能，对同一个问题，同时请求两个模型，将结果并排展示。
    - **价值**：让用户选择自己信任或效果更好的模型，并直观比较不同AI的规划风格。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合替代专业的职业咨询**：它生成的计划是基于通用逻辑和你的输入，无法像人类顾问那样进行深度的心理辅导、行业人脉牵线或极其个性化的职业路径设计。
2.  **不适合获取实时、具体的招聘信息**：它不知道“腾讯今天发布了哪些新职位”。如果你需要这个，应该使用招聘平台（如Boss直聘、猎聘）或公司官网的招聘频道。
3.  **不适合直接生成高质量的简历或求职信**：虽然计划中可能包含优化建议，但它无法直接产出一份排版精美、内容扎实的简历文档。你需要使用专门的简历编辑器或请专业人士修改。
4.  **不适合处理极其复杂或非标准的求职场景**：例如，“我想一边在非洲做志愿者，一边远程找一份欧洲的区块链工作，并且每周只工作20小时”。这种高度定制、涉及多重约束的场景，超出了当前Prompt设计的处理范围，生成的结果可能不切实际。

**总结**：这个网页是一个出色的**规划框架生成器**和**行动思路启发器**。它最适合作为你求职行动的“起点”和“导航仪”，帮助你从混乱走向有序。但具体的“路”怎么走，车（你的简历、面试表现）好不好，还需要你亲自驾驶和打磨。
