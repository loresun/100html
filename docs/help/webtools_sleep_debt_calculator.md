# 睡眠欠债计算器 - 学习指南

## 【一】这个网页解决了什么问题？

想象一下，你经常熬夜工作或追剧，第二天醒来感觉昏昏沉沉。你想知道自己到底“欠”了多少睡眠，但手动计算很麻烦。这个网页就像一个**个人健康小助手**，帮你快速量化睡眠不足的情况。

**适合的使用场景：**
- 你想了解自己连续几天的睡眠缺口有多大
- 你想设定一个“补觉”目标，需要知道具体要补多少小时
- 你想向朋友解释“为什么我这么累”时，有个直观的数据

**不适合的情况：**
- 需要专业医学诊断（如失眠症、睡眠呼吸暂停）
- 需要记录长期睡眠周期（超过一周）
- 需要结合心率、运动等生物数据的深度分析

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
你会看到几个简单的数字输入框，比如：
- “理想每日睡眠时长”（比如8小时）
- “实际睡眠时长”（比如过去3天分别睡了6、5、7小时）
- “计算天数”（你想回顾最近几天）

**通常的操作步骤：**
1. **填写基本信息**：在对应的框里输入你的睡眠数据
2. **点击计算**：找到“计算结果”按钮并点击
3. **查看报告**：页面下方会显示你的“睡眠欠债”总时长

**输出结果长什么样？**
结果会以清晰卡片的形式展示，例如：
```
睡眠欠债总计：-5小时
平均每日缺口：-1.7小时
```
（数字可能是负数，表示你睡少了）

**容易忽略的细节：**
- 输入数字时可以直接用键盘上下箭头微调
- 所有输入都有最小/最大值限制（比如睡眠时长不会让你填24小时以上）
- 结果会**自动保存**在浏览器里，下次打开还在（除非清空缓存）

## 【三】核心结构拆解（学习重点）

这个页面其实是一个**多功能工具箱**的其中一项。它的设计很聪明：

### 关键模块组成：
1. **导航栏**（顶部）
   - 职责：提供返回入口和设置按钮
   - 设计亮点：使用了毛玻璃效果，现代感强

2. **工具展示区**（中间主体）
   - 职责：根据当前工具类型动态显示不同界面
   - 睡眠计算器只是其中一种类型（`type: 'formula'`）

3. **设置面板**（弹出层）
   - 职责：配置API密钥等高级选项
   - 设计亮点：模态对话框，防止误操作

### 输入→处理→输出链路：
```
用户输入睡眠数据 → Alpine.js监听数据变化 → 
点击“计算”触发函数 → 执行预设公式计算 → 
更新页面上的result变量 → 模板自动重新渲染显示结果
```

**最值得学习的设计：**
**“一套模板，多种工具”** 的架构。页面用 `x-show="tool.type === 'formula'"` 这样的条件判断，在同一位置切换显示不同类型的工具界面。这意味着：
- 添加新工具只需定义好数据结构和处理函数
- 不需要为每个工具写单独的HTML
- 维护成本极低

## 【四】Prompt / AI 逻辑是如何被设计的？

> 注意：当前代码中**没有直接使用AI或Prompt**，但预留了API配置接口。这是一个重要的设计思路。

**Prompt在这个设计中的角色：**
虽然睡眠计算器是纯数学计算，但页面为“文本工具”、“生成器”等类型预留了AI能力。如果扩展：
- Prompt解决的是“理解用户模糊需求并生成结构化建议”
- 比如：“我这周睡得很差，该怎么办？” → AI分析数据后给出建议

**关键变量设计思路：**
从代码中可以看到，每个工具都有：
- `tool.values`：存储用户输入
- `tool.result`：存储计算结果
- `tool.resultLabel`：结果描述文字

**如果只改Prompt会发生什么？**
假设我们把睡眠计算器改成“AI睡眠顾问”：
1. 保持输入字段不变（睡眠时长、天数）
2. 修改计算函数，改为调用AI API
3. Prompt中传入用户数据，让AI生成个性化建议
4. 输出从“-5小时”变成“你欠了5小时睡眠，建议今晚10点前睡，周末补个午觉”

## 【五】如何模仿它，做出你自己的版本？

**最安全的模仿路径：**

**第一步：复制框架，替换场景**
- 保持整个HTML结构不变
- 把“睡眠欠债”改成你的场景，比如“饮水记录器”
- 修改`tool.fields`：理想饮水量、实际饮水量、计算天数

**第二步：调整计算逻辑**
- 在`standalone.js`中找到`calculate`函数（或类似函数）
- 修改计算公式：`欠水量 = (理想-实际)×天数`
- 可以增加更多输出项：缺水百分比、建议补水方案

**第三步：美化展示**
- 修改结果卡片的颜色（缺水用橙色，达标用绿色）
- 增加图标：用水滴图标代替现在的通用样式
- 调整布局：可能需要显示每小时饮水建议

**从哪里下手最安全？**
从**修改`tool`对象的定义**开始。在`standalone.js`里找到`sleep_debt_calculator`的定义，这是最核心且安全的修改点。只要不破坏数据结构，界面会自动适应。

## 【六】3–5 个可直接尝试的改造方向

### 1. 增加“睡眠质量评分”输入
- **操作**：在输入字段中增加一个1-5星的评分滑块
- **效果**：计算公式可以结合时长和质量（比如5星但睡6小时，欠债减半）
- **代码提示**：在`tool.fields`数组里加一项，`type: 'range'`

### 2. 改成“咖啡因代谢计算器”
- **操作**：完全替换使用场景
- **输入**：咖啡种类、杯数、饮用时间、个人体重
- **输出**：当前体内咖啡因含量、完全代谢时间
- **优势**：公式更复杂，能体现计算器的价值

### 3. 增加数据可视化
- **操作**：引入一个简单的图表库（如Chart.js）
- **效果**：把“过去7天睡眠趋势”用折线图展示
- **代码提示**：在结果区域增加`<canvas>`标签，用计算出的数据绘图

### 4. 添加“补觉计划生成器”
- **操作**：利用预留的AI接口
- **流程**：计算欠债后，点击“生成补觉计划” → 调用AI → 输出具体建议
- **Prompt示例**：“用户欠了{debt}小时睡眠，请给出一个3天的补觉计划，考虑周末和工作日”

### 5. 做成“睡眠日记”模式
- **操作**：切换到`type: 'ledger'`（记账工具）的样式
- **效果**：每天记录睡眠时长和质量，自动统计周报
- **优势**：复用现有代码，几乎不需要新开发

## 【七】这个网页不适合做什么？（边界提醒）

### 明确的局限性：
1. **不是专业医疗工具**
   - 所有计算基于简单公式，没有医学模型支持
   - 不能替代医生的睡眠监测或诊断

2. **数据存储脆弱**
   - 数据只存在浏览器本地
   - 换设备或清缓存就丢失
   - **如果需要跨设备同步**：应该用Firebase或Supabase后端

3. **无法处理复杂场景**
   - 比如“我有时差”、“我上夜班”
   - **解决方案**：需要更专业的工具如Sleep Cycle或Apple Health

4. **没有提醒功能**
   - 它不会提醒你“该睡觉了”
   - **如果需要行为干预**：应该做成Chrome扩展或手机APP

### 什么时候该换工具？
- 如果你需要**长期追踪睡眠趋势** → 用Notion模板或专业APP
- 如果你需要**结合智能手环数据** → 用手环厂商的官方应用
- 如果你需要**临床级分析** → 咨询睡眠专科医生
