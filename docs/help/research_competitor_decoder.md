# 竞品拆解器 (Competitor Decoder) 帮助文档

--------------------------------

## 【一】这个网页解决了什么问题？

想象一下，你是一个内容创作者、新媒体运营者或创业者。你看到某个账号（比如一个职场干货博主）的笔记或视频特别火，点赞量很高。你很想学习它的成功秘诀，但靠自己分析，往往只能看到表面（比如“标题很吸引人”），很难系统地拆解出它**为什么能火**的底层逻辑。

这个网页就是你的“AI 分析师”。它帮你：
*   **深度拆解**：将一篇或多篇竞品的爆款内容（文案、标题、脚本）丢进去，AI 会像一位经验丰富的运营专家一样，帮你分析其选题、开头、变现路径和情绪价值。
*   **结构化学习**：将模糊的“感觉它写得好”变成清晰的、可操作的“公式”和“标签”，让你知道具体可以借鉴什么。
*   **快速模仿与创新**：基于分析结果，你可以快速理解对方的打法，并结合自己的定位，创作出有自己特色的内容，而不是盲目抄袭。

**适合场景**：
*   你想学习某个小红书/抖音/B站/公众号博主的爆款内容逻辑。
*   你需要快速了解一个新领域的头部玩家是怎么做的。
*   你想为自己的内容创作寻找可复用的“公式”和灵感。

**不适合场景**：
*   你需要分析**整个账号**的长期数据趋势（如粉丝增长曲线、互动率变化），这需要更专业的数据分析工具。
*   你需要对**图片、视频本身**的视觉元素（如配色、剪辑节奏）进行分析，本工具主要处理文本内容。
*   你需要一个能自动生成完整文章或脚本的“写作机器人”，本工具的核心是“分析”而非“生成”。

## 【二】使用方式（给第一次接触的人）

1.  **首次设置**：打开页面后，点击右上角“设置”按钮，输入你的 DeepSeek API Key 并选择模型（“V3-快”或“R1-深”），然后保存。
2.  **输入信息**：
    *   **竞品账号/品牌名称**（选填）：输入你想分析的博主或品牌名，帮助AI理解背景。
    *   **竞品爆款内容**（必填）：将1-3篇你认为很火的笔记正文、视频文案脚本或标题，粘贴到下方的大文本框中。内容越多，分析可能越全面。
3.  **开始分析**：点击蓝色的 **“🕵️ 开始深度拆解”** 按钮。
4.  **查看结果**：等待几秒到几十秒（取决于内容长度和模型），右侧会逐步显示出结构化的分析报告，包含5个核心模块。
5.  **利用结果**：你可以阅读分析，点击“复制分析结果”将核心结论保存下来，或点击“导出报告”下载完整的JSON数据。

**输出结果长什么样？**
结果会以5张精美的卡片形式呈现：
*   **选题底层逻辑**：一段总结 + 几个关键词标签（如 #焦虑 #职场）。
*   **开头钩子结构**：用1、2、3…列出的具体钩子技巧。
*   **变现与转化路径**：分“流量引入”、“信任建立”、“最终转化”三部分说明。
*   **情绪价值分析**：几个情绪关键词 + 一段分析文字。
*   **可复制的公式**：几条具体的、你可以直接参考的行动建议。

**容易忽略的细节**：
*   **模型选择**：右上角可以随时切换“V3（快）”和“R1（深）”。选择R1时，你可以在结果上方展开看到AI的“深度思考过程”，这有助于你理解AI的分析思路，但速度会慢一些。
*   **内容质量**：输入的爆款内容质量直接影响分析结果。尽量提供完整的、有代表性的文案，而不是只言片语。
*   **配置保存**：API Key 会保存在你的浏览器本地，下次打开同一台电脑的同一个浏览器时无需再次输入。

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的 **“输入-处理-输出”** 左右分栏布局，模块化程度很高。

**关键模块与职责：**

1.  **控制与配置模块（顶部导航）**：
    *   **职责**：提供品牌标识、模型切换入口、全局设置入口。
    *   **设计亮点**：将模型选择做成了直观的标签切换按钮（快/深），并将关键的API配置入口放在显眼位置。

2.  **输入模块（左侧面板）**：
    *   **职责**：收集用户所有输入信息，并触发分析动作。
    *   **构成**：竞品名称输入框 + 爆款内容文本框 + 分析按钮 + 提示信息。
    *   **设计亮点**：按钮有明确的交互状态（悬停、禁用），并给出了具体的输入提示（“建议输入2-3篇”），引导用户提供有效信息。

3.  **AI处理引擎（核心逻辑，不可见）**：
    *   **职责**：将用户的输入和预定义的“分析框架”组合成给AI的指令（Prompt），调用AI API，并处理返回的数据流。
    *   **流程**：`用户输入` + `系统Prompt（分析框架）` → `调用DeepSeek API` → `流式接收数据` → `解析JSON`。

4.  **输出展示模块（右侧面板）**：
    *   **职责**：将AI返回的结构化数据，以美观、易读的卡片形式展示给用户。
    *   **构成**：
        *   **空状态**：引导用户开始操作。
        *   **思考过程区**（R1模型特有）：展示AI的“内心戏”，增加透明度和学习价值。
        *   **结果卡片网格**：5张固定结构的卡片，每张对应一个分析维度，使用不同的颜色和图标进行区分。
        *   **操作栏**：提供复制和导出功能。

**最值得学习的设计：**
**“结构化Prompt + 结构化输出”的闭环设计**。开发者没有让AI自由发挥，而是通过精心设计的系统Prompt，严格规定了AI需要从哪几个维度（选题、钩子、变现等）进行分析，并且要求AI必须以指定的JSON格式返回。这样，前端代码就能像拼积木一样，将返回的数据准确地填充到预先设计好的卡片模板里，保证了结果的一致性和可用性。这是将AI能力“产品化”的关键思路。

## 【四】Prompt / AI 逻辑是如何被设计的？

在这个页面中，**Prompt（指令）是AI的“分析框架”和“输出格式控制器”**。

1.  **扮演的角色**：它告诉AI“你是谁”（资深新媒体专家）、“你的任务是什么”（拆解爆款底层逻辑），以及**“你必须怎么回答”**（按给定的JSON格式）。
2.  **解决的问题**：它同时解决了“理解问题”和“生成问题”。
    *   **理解问题**：引导AI从“新媒体运营”的专业视角去理解文本，而不是泛泛而谈。
    *   **生成问题**：强制AI生成一个结构固定、字段明确的JSON对象，方便程序后续处理。
3.  **关键变量**：
    *   **系统Prompt中的分析框架**：`title_logic`（选题逻辑）、`hook_structure`（钩子结构）等，这些字段定义了分析维度。
    *   **用户Prompt中的变量**：`${input.competitorName}` 和 `${input.sourceContents}`，这是每次分析的具体内容。
4.  **只改Prompt的影响**：如果你只修改系统Prompt里的分析框架（例如，增加一个“人设分析”字段，或把“情绪价值”改成“痛点分析”），那么AI返回的JSON结构就会变化。但是，**前端页面不会自动适应**，因为展示数据的卡片是写死的。结果可能导致新字段无法显示，或旧字段找不到数据而报错。因此，改Prompt通常需要同步调整前端展示代码。

## 【五】如何模仿它，做出你自己的版本？

你可以遵循以下“安全路径”，逐步打造一个属于你的分析工具：

**第一步：替换场景，保持骨架**
*   **目标**：最快得到一个能跑起来的、属于你的工具。
*   **操作**：
    1.  复制整个HTML文件。
    2.  修改标题、Logo名称（如改为“小说开篇分析器”）。
    3.  修改左侧的输入框标签和提示文字（如将“竞品爆款内容”改为“经典小说开篇段落”）。
    4.  修改右侧卡片的标题和图标（如将“选题底层逻辑”改为“开篇氛围营造”，“钩子结构”改为“悬念设置技巧”）。
*   **此时**：界面已经是你的了，但AI还在按“竞品拆解”的逻辑思考。

**第二步：重写核心Prompt**
*   **目标**：让AI为你新的分析目标服务。
*   **操作**：找到代码中 `const systemPrompt = ` 开头的部分。这是核心！
    1.  重写角色描述（如“你是一位资深文学编辑”）。
    2.  重写任务描述（如“分析以下小说开篇段落的写作技巧”）。
    3.  **最关键**：重新设计JSON格式的字段。例如，可以定义为 `{"atmosphere": {"keywords": [], "summary": ""}, "suspense_techniques": [], "character_intro": ""}`。
*   **风险提示**：改完Prompt后，前端展示会出错，因为卡片还在找旧的字段名（如`title_logic`）。别急，这是第三步要解决的。

**第三步：调整前端输出模板**
*   **目标**：让界面正确显示新Prompt生成的结果。
*   **操作**：找到右侧结果展示部分（`<div v-if="result">` 里面）。对照你新设计的JSON字段，修改这里：
    1.  将 `result.title_logic.summary` 改为 `result.atmosphere.summary`。
    2.  将 `result.hook_structure` 的循环改为 `result.suspense_techniques`。
    3.  相应地调整卡片的标题、说明文字和图标。
*   **完成**：至此，一个全新的、功能完整的分析工具就诞生了。

**从哪里下手最安全？**
从 **第一步的界面文字替换** 和 **第二步的Prompt重写** 开始。这两步不涉及复杂的JavaScript逻辑，主要是文本修改，风险最低，能让你立刻看到变化并理解核心。

## 【六】3–5 个可直接尝试的改造方向

1.  **增加“内容类型”选择器**：
    *   **操作**：在输入区增加一个下拉菜单，让用户选择内容类型，如“小红书笔记”、“抖音文案”、“公众号文章”、“产品介绍页”。
    *   **进阶**：根据不同类型，动态切换不同的系统Prompt。例如，分析“产品介绍页”时，Prompt可以更侧重“价值主张”、“痛点描述”和“行动号召”的分析。

2.  **增加“对比分析”功能**：
    *   **操作**：在输入区增加第二个文本区域，用于输入“我的内容”。点击分析后，AI不仅分析竞品，还会将你的内容与竞品进行对比，给出“差异点”和“优化建议”卡片。
    *   **价值**：从“学习别人”升级到“诊断自己”，工具实用性大增。

3.  **本地化与隐私增强**：
    *   **操作**：集成一个能在浏览器中本地运行的轻量级AI模型（如通过 WebLLM 运行 Llama 3.2 等）。提供一个“本地分析”模式。
    *   **价值**：用户无需API Key，且分析内容完全不出浏览器，适合处理敏感或未公开的文案。

4.  **结果可视化与灵感生成**：
    *   **操作**：在现有文本分析基础上，增加一个“灵感生成”按钮。点击后，利用现有的分析结果（如选题标签、情绪关键词）作为新的Prompt，让AI生成1-3个符合该逻辑的**新标题或开头句**。
    *   **价值**：将“分析”与“创作”环节打通，形成工作流闭环。

5.  **模板化与批量处理**：
    *   **操作**：增加一个“保存为模板”功能。当用户得到一份优秀的分析报告后，可以将其保存。下次分析同类账号时，可以直接调用模板，AI会基于模板中总结的“公式”进行更有针对性的分析。
    *   **价值**：让工具随着使用越来越智能，越来越贴合用户的个人需求。

## 【七】这个网页不适合做什么？（边界提醒）

1.  **不适合做精确的数据分析**：它无法提供阅读量、点赞率、转化率等精确数据。它的分析基于文本语义和逻辑推理，是“定性分析”而非“定量分析”。如果你需要数据，应使用平台官方的数据分析工具或第三方数据平台（如新榜、飞瓜数据）。
2.  **不适合作为最终决策的唯一依据**：AI的分析是基于你提供的文本和它自身的训练数据，可能忽略行业特定知识、最新趋势或文化背景。它给出的“可复制公式”是参考建议，你需要结合自己的判断和市场验证来使用。
3.  **不适合处理非文本内容的核心分析**：虽然你可以输入视频脚本，但AI无法分析视频的镜头语言、BGM、主播的肢体语言和表情。对于短视频这类强视听媒介，本工具只能辅助分析其文案结构。
4.  **不适合完全自动化的内容生产**：它是一个“分析助手”和“灵感启发器”，而不是“全自动写作机器”。指望它输入竞品内容后直接产出一篇爆款，是不现实的。创作的核心仍然是你自己的思考、融合与再创造。

希望这份文档能帮助你不仅用好这个工具，更能理解其设计精髓，最终创造出更强大、更贴合你个人需求的AI应用。
