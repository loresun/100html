# 个人IP自我介绍生成器 - 学习指南

---

## 【一】这个网页解决了什么问题？

**使用场景：**
想象一下，你是一个内容创作者、自由职业者或创业者，需要在不同平台（小红书、抖音、公众号）展示自己，或者在不同场合（商务合作、演讲、播客）介绍自己。每次都要绞尽脑汁写不同的自我介绍，既费时间又难以突出个人特色。

这个工具就是你的“个人品牌文案助手”。它帮你：
- **一次输入，多场景输出**：填写一次个人资料，就能生成适合12种不同场景的自我介绍
- **告别模板化**：AI会根据你的独特人设，生成有差异化的文案，避免千篇一律
- **快速试错**：每个场景可以生成2-3个不同版本，让你有选择余地

**适合：**
- 个人IP打造者、自媒体博主
- 自由职业者、咨询顾问
- 创业者、企业主
- 需要频繁自我介绍的职场人士

**不适合：**
- 需要高度创意、文学性的文案创作
- 需要完全控制每个字词的场景
- 需要生成长篇内容（如文章、报告）

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
1. **你的个人资料**（昵称、定位、背景故事、标签等）
2. **使用场景**（从12个选项中选择，如“小红书主页简介”、“商务合作介绍”等）
3. **生成偏好**（每个场景要几个版本？想要什么风格？）

**用户通常会做哪几步操作？**
1. **填写人设**：在左侧输入区填写你的基本信息，或者直接导入“人设打造师”的JSON数据
2. **选择场景**：勾选你需要自我介绍的场合（可以多选）
3. **设置偏好**：滑动选择每个场景生成几个版本，选择喜欢的风格
4. **点击生成**：等待AI为你创作
5. **挑选使用**：在右侧结果区浏览生成的文案，复制喜欢的版本

**输出结果长什么样？**
- 按场景分组展示，每个场景下有1-3个不同版本
- 每个版本是一段完整的自我介绍文字
- 如果使用“深度思考”模型，还能看到AI的思考过程
- 显示字数统计，方便你控制长度

**容易忽略的使用细节：**
1. **场景可以多选**：很多人只选一个，其实可以一次性生成多个场景
2. **版本数可调**：滑动条可以控制每个场景生成1-3个版本
3. **风格偏好可选**：不选就是“自动匹配”，选了会按指定风格生成
4. **导入功能**：如果你用过“人设打造师”，可以直接导入JSON，不用重复填写
5. **单个重生成**：对某个版本不满意？可以单独重新生成，不用全部重来

## 【三】核心结构拆解（学习重点）

这个页面采用了清晰的**左右分栏结构**：

### 模块1：左侧输入面板（控制中心）
- **职责**：收集用户的所有输入和配置
- **子模块**：
  - 人设信息区（手动输入或导入）
  - 场景选择区（分类展示12个场景）
  - 参数配置区（版本数、风格偏好）
  - 生成按钮（状态控制）

### 模块2：右侧结果展示区（输出中心）
- **职责**：展示和管理AI生成的结果
- **子模块**：
  - 空状态/加载状态提示
  - 结果分组展示（按场景）
  - 版本卡片（含操作按钮）
  - 顶部操作栏（导出、清空）

### 模块3：辅助功能层（弹窗系统）
- **职责**：处理设置、导入等次要但必要的功能
- 包括：API设置弹窗、JSON导入弹窗、复制成功提示

### 输入 → 处理 → 输出 的逻辑链路：
```
用户输入人设 + 选择场景 + 设置参数
    ↓
点击“生成”按钮
    ↓
前端组装Prompt（系统指令 + 用户信息 + 场景要求）
    ↓
调用DeepSeek API
    ↓
接收AI返回的文本
    ↓
前端解析、分组、展示结果
    ↓
用户操作（复制、重生成、导出）
```

### 最值得学习的设计：
**场景化的Prompt工程**。这个工具的核心不是简单的“写一段自我介绍”，而是：
1. **场景分类**：将12种场景分成3大类（平台、合作、演讲）
2. **场景特定指南**：每个场景都有不同的写作要求（字数、语气、格式）
3. **差异化生成**：通过版本提示“请确保与其他版本有明显差异”
4. **风格控制**：可选的风格偏好，让AI按指定方向创作

这种“场景+风格+差异化”的三层控制，是生成高质量、实用文案的关键。

## 【四】Prompt / AI 逻辑是如何被设计的？

**Prompt在这个页面中扮演什么角色？**
Prompt是连接用户需求和AI能力的“翻译官”。它把用户的简单选择（“我要一个小红书简介”）转换成AI能理解的详细指令。

**它解决的是“理解问题”还是“生成问题”？**
主要是**理解问题**。用户可能不知道“小红书简介”应该怎么写（字数多少？用什么语气？突出什么？），Prompt把这些隐含的要求明确告诉AI。

**哪些信息是Prompt中的关键变量？**
1. **场景标签**：如“小红书主页简介”
2. **场景特定要求**：如“控制在80字以内，使用分行+emoji”
3. **人设信息**：昵称、定位、背景等
4. **风格偏好**：如“专业权威型”
5. **版本提示**：如“这是第2个版本，请确保差异”

**如果只改Prompt，不改代码，会发生什么变化？**
- 改**场景要求**：AI会按新要求生成（如把“80字以内”改成“150字以内”）
- 改**风格描述**：输出的语气会变化（如把“专业”改成“幽默”）
- 改**输出格式**：AI可能从纯文本改成带emoji或分行的格式
- 加**限制条件**：如“不能使用‘专家’这个词”，AI会避开

## 【五】如何模仿它，做出你自己的版本？

### 模仿路径（从易到难）：

**第一步：保持结构不变，替换使用场景（最安全）**
- 把“个人IP自我介绍”换成其他垂直领域
- 例如：“产品描述生成器”、“活动文案生成器”、“邮件模板生成器”
- 只需修改：页面标题、说明文字、场景选项的标签

**第二步：调整输入字段和Prompt**
- 根据新场景，设计合适的输入字段
- 例如“产品描述生成器”需要：产品名称、目标用户、核心功能、价格区间
- 修改Prompt中的系统指令和用户模板

**第三步：改变输出形式或展示方式**
- 当前是纯文本，可以改成：带格式的HTML、分点列表、表格
- 可以增加：一键复制为Markdown、导出为图片、分享链接

**从哪里下手最安全？**
从**修改场景选项**开始。比如：
1. 打开代码，找到`sceneOptions`对象（大约在Vue的`setup()`函数里）
2. 把`platform`数组里的选项换成你需要的
3. 修改对应的`getSceneGuide()`函数中的写作要求
4. 运行看看效果——这是风险最小的改动

## 【六】3–5个可直接尝试的改造方向

### 1. 增加“语气强度”滑块
- **现状**：风格偏好是下拉选择（专业、幽默等）
- **改进**：增加一个滑块，控制“语气强度”
- **实现**：在Prompt中加入“请使用[强度]%的[风格]语气”
- **效果**：让用户更精细地控制输出风格

### 2. 支持多模型切换（不只是DeepSeek）
- **现状**：只支持DeepSeek的V3和R1模型
- **改进**：增加OpenAI GPT、Claude、国内大模型等选项
- **实现**：在设置弹窗增加模型选择，修改`callDeepSeek()`函数为通用的`callAI()`
- **效果**：用户可以根据需求选择最适合的模型

### 3. 增加“历史记录”功能
- **现状**：生成结果只在当前页面，刷新就没了
- **改进**：自动保存到localStorage，增加历史记录页面
- **实现**：每次生成时保存时间戳和人设概要，新开页面展示历史
- **效果**：用户可以回顾和复用之前的生成结果

### 4. 优化为“工作流”模式
- **现状**：一次性生成所有场景
- **改进**：分步骤引导用户
- **实现**：
  - 步骤1：填写人设
  - 步骤2：选择场景（根据人设推荐场景）
  - 步骤3：预览并微调（实时预览效果）
  - 步骤4：批量导出
- **效果**：体验更流畅，适合新手

### 5. 增加“A/B测试”功能
- **现状**：生成多个版本，但需要人工判断哪个好
- **改进**：生成短链接，让用户分享给朋友投票
- **实现**：为每个版本生成唯一ID，创建简单的投票页面
- **效果**：数据驱动决策，知道哪个版本更受欢迎

## 【七】这个网页不适合做什么？（边界提醒）

### 局限性：
1. **不是创意写作工具**
   - 适合生成“标准化”的自我介绍
   - 不适合需要高度文学性、诗意的文案
   - **替代方案**：使用专门的创意写作AI工具

2. **无法保证绝对准确**
   - AI可能生成不符合事实的内容
   - 需要人工审核和调整
   - **正确用法**：把AI输出当作“初稿”，而不是“终稿”

3. **不适合长篇内容**
   - 设计目标是生成100-200字的简介
   - 生成长文章会超出Prompt的设计范围
   - **替代方案**：使用文档生成工具或专门的文章AI

4. **不能替代深度思考**
   - 工具帮你“怎么写”，不帮你“写什么”
   - 你的人设定位、核心价值需要自己思考
   - **建议**：先用“人设打造师”明确定位，再用这个工具生成文案

5. **有API限制和成本**
   - 依赖DeepSeek API，需要网络和API Key
   - 大量使用会产生成本
   - **替代方案**：对于简单需求，可以使用免费的ChatGPT网页版手动操作

### 什么时候应该换工具？
如果你想：
- 写一篇完整的文章 → 用Notion AI、ChatGPT文档模式
- 设计视觉形象 → 用Canva AI、Midjourney
- 做深度个人品牌策划 → 用专业顾问或系统课程
- 生成完全原创的创意 → 自己动手或找专业文案

---

**记住**：这个工具最好的使用方式是——**把它当作你的“写作助理”**，而不是“写作代笔”。你提供方向和素材，它帮你快速产出多个选项，最后由你做选择和调整。这样既能提高效率，又能保持你的个人特色。
