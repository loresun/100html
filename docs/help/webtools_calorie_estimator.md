# 热量估算器 - 学习指南

## 【一】这个网页解决了什么问题？

**使用场景**：当你需要快速计算日常活动或运动消耗的热量时，这个工具可以帮你省去手动计算的麻烦。比如，你想知道自己跑步30分钟消耗了多少卡路里，或者想比较不同运动的热量消耗效率。

**适合情况**：
- 健身爱好者想了解运动效果
- 减肥人群想监控热量消耗
- 教练为客户制定运动计划
- 日常健康管理

**不适合情况**：
- 需要精确医学级热量计算（如临床营养）
- 涉及复杂身体状况（如特殊疾病）
- 需要长期数据追踪和分析
- 需要个性化饮食建议

## 【二】使用方式（给第一次接触的人）

**页面输入是什么？**
- 运动类型选择（如果有）
- 运动时长（分钟）
- 体重（公斤）
- 运动强度（如果有）

**操作步骤**：
1. 在对应输入框中填写你的信息
2. 点击“计算结果”按钮
3. 查看显示的热量消耗数值

**输出结果长什么样？**
- 一个清晰的数字显示，如“消耗热量：245 千卡”
- 可能附带其他相关信息（如运动效率评级）

**容易忽略的细节**：
- 单位要正确（公斤 vs 磅）
- 时长通常以分钟为单位
- 某些运动可能需要选择强度级别
- 结果会根据输入实时变化

## 【三】核心结构拆解（学习重点）

**关键模块组成**：

1. **输入模块**
   - 职责：收集用户数据（体重、时长等）
   - 实现：表单输入框，有标签和单位提示

2. **计算引擎模块**
   - 职责：根据公式处理输入数据
   - 实现：JavaScript函数，执行数学运算

3. **结果显示模块**
   - 职责：清晰展示计算结果
   - 实现：样式化的结果卡片，突出显示数字

4. **页面框架模块**
   - 职责：提供统一的界面布局
   - 实现：导航栏、设置面板、响应式设计

**输入→处理→输出链路**：
```
用户输入 → 表单收集 → 计算函数处理 → 结果渲染 → 界面展示
```

**最值得学习的设计**：
- **模块化工具架构**：页面支持多种工具类型（公式计算、计时器、清单等），通过`tool.type`切换显示，这种设计让一个页面可以承载多个功能
- **响应式数据绑定**：使用Alpine.js实现数据和UI的自动同步，代码简洁
- **统一的样式系统**：使用Tailwind CSS，保持界面一致性

## 【四】Prompt / AI 逻辑是如何被设计的？

**注意**：当前代码版本没有显示AI集成部分，但根据设置面板的API配置，可以推断设计思路：

**Prompt可能扮演的角色**：
- 将用户输入的自然语言转换为结构化数据
- 提供更智能的热量估算建议
- 生成个性化的运动建议

**解决的问题类型**：
- **理解问题**：理解用户描述的“中等强度游泳”
- **生成问题**：生成“基于你的体重，建议...”

**Prompt中的关键变量**：
- 用户输入数据（体重、时长）
- 运动类型和强度
- 可能的个性化因素（年龄、性别）

**如果只改Prompt**：
- 可以改变AI的“语气”和详细程度
- 可以添加更多解释性内容
- 可以调整建议的保守/激进程度
- 但核心计算逻辑不变

## 【五】如何模仿它，做出你自己的版本？

**安全模仿路径**：

**第一步：保持结构，替换场景**
- 复制整个HTML结构
- 修改标题和描述为你的工具（如“睡眠质量计算器”）
- 保持相同的CSS类和布局

**第二步：调整输入字段**
- 在`tool.fields`数组中修改字段：
  ```javascript
  // 原版可能是：体重、时长
  // 你的版本：睡前时间、睡眠时长、醒来次数
  fields: [
    { key: 'bedtime', label: '上床时间', type: 'time' },
    { key: 'duration', label: '睡眠时长(小时)', min: 0, max: 24, step: 0.5 }
  ]
  ```

**第三步：修改计算逻辑**
- 在`calculate()`函数中替换公式：
  ```javascript
  // 原版：热量 = 体重 × 时长 × 系数
  // 你的版本：睡眠分数 = f(时长, 连续性, 时间点)
  ```

**第四步：调整输出展示**
- 修改`resultLabel`为你的场景
- 可能需要改变结果显示方式（分数、评级、建议列表）

**从哪里下手最安全**：
1. 先只改文字和标签，确保页面能运行
2. 然后改输入字段，测试数据收集
3. 最后改计算逻辑，一小步一小步测试

## 【七】这个网页不适合做什么？（边界提醒）

**局限性说明**：

1. **不是专业医疗工具**
   - 不能替代医生或营养师建议
   - 计算结果有误差范围
   - 不适合特殊健康状况人群

2. **不是长期追踪系统**
   - 没有用户账户系统
   - 数据只保存在当前浏览器
   - 无法多设备同步

3. **不是个性化教练**
   - 无法考虑你的具体运动技巧
   - 不考虑天气、场地等环境因素
   - 没有动作纠正功能

**如果你需要...应该换用**：
- **精确饮食管理** → MyFitnessPal等专业App
- **运动动作指导** → Keep、Nike Training Club
- **长期健康追踪** → Apple Health、Google Fit
- **专业训练计划** → 聘请教练或使用TrainingPeaks
