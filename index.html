📌 如何获取 API Key？
前往 DeepSeek 开放平台 注册账号，在「API Keys」页面创建密钥即可。

Key 仅保存在你的浏览器本地 (localStorage)，不会上传到任何服务器。所有工具共享使用。

全局兼容层自动生效：Flash 默认非思考模式，Pro 默认思考模式（High）。旧版 V3/R1 已自动迁移至 V4。

High 适合大多数任务，Max 适合极复杂推理。
